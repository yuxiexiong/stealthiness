## 一、已知的部分：必须引用，不能声称是我们的发现

| 我们的说法 | 已有工作 | 结论 |
|---|---|---|
| 预训练模型微调时，先学会原任务，后学会后门 | Moderate-fitting（NeurIPS'22，RoBERTa 分类）；Wan et al.（ICML'23 §6.2，T5 3B）；DeCE（代码模型，最大 7B）；Honeypot 附录；Mao et al. 2026（图像、低投毒率）；背景文献：Arpit'17、ELR'20、ITLM'19 | **定性上已知。** 我们只能贡献 8B LLM 的 LoRA 生成任务、逐步级别的定量刻画 |
| ASR 不是渐进上升，而是突然跃升 | DeCE（按 epoch，"第 3 个 epoch 突然升到近 90%"）；Connor & Emanuele'22（半监督中的"tipping point"）；Schneider ICLR'24（全有或全无）；涌现错位研究中的 LoRA 相变（类比，不是后门） | **部分已知。** 不能说"首次观察到跃升"；能说的是 LoRA SFT 中逐步分辨、几十步之内完成的跃升 |
| 早期毒样本会被后续训练冲掉 | Bagdasaryan'20（联邦学习，早期注入很快被遗忘）；Souly'25 附录 F.2（前置投毒最终被干净微调抹掉） | **部分已知** |
| 后门存在剂量门槛 | Souly'25；Pick Your Poison'26（k≤4 时为 0，之后陡变）；LoRA adapter 后门'26（约 23 条）；Sure Trap'25；Anthropic'26（Qwen3-8B LoRA，32 条） | **按"总条数"计的门槛已知** |
| 用高 loss 识别毒样本 | Wan'23 §6.1（离线：训练 → 打分 → 删除 → 重训）；ITLM'19（裁剪损失，防视觉后门） | **已知** |
| 预热之后在线删除高 loss 样本 | **Loss Truncation**（ACL'20：固定 hot-start + 固定分位数，把 loss 置零）；MentorNet'18（burn-in + EMA 分位数阈值）；Co-teaching | **作为通用技巧已知**（不针对后门） |
| 预热之后在线逐行加权，用于防后门 | **Honeypot**（NeurIPS'23：额外的浅层头，按相对近期平均 loss 的比值加阈值；分类 PLM） | **框架相似** |
| 用基座模型的 loss 预过滤 | BYORn（ICML'26，VLM，标记 top 40%） | **已知**（即我们的静态预过滤基线） |

## 二、检索后仍未发现的部分：我们可以主张的贡献

1. **按行、按步的装入机制。** 后门是否装上，由**门开之后残留的毒行数**决定（0–3 条不装，≥8 条装）；门开之前的毒行无害。由此可以解释：为什么召回 95.5% 的静态检测器照样失败——问题在于留下的是哪几条。六个方向都没有找到这个解释。
   - Wan 自己写了"对检查点高度敏感"，Souly 自己写了"路径依赖，我们没有好的解释"。我们的机制正好回答这两个开放问题。
2. **在"任务刚学会"这个数据驱动的时刻开门的在线防御：** 零额外前向，阈值是相对的，不需要事先知道投毒率。它是 Wan 离线过滤的在线、自动定时版本，也是 Loss Truncation 换上"由任务学会时刻决定的门"和相对阈值之后的版本。
3. **公平比较的证据：** 7 类基线都做了 oracle 调参、预算对齐和正向对照。
4. 有一篇 2026 年的综述（2605.25073）把"根据监测到的训练动态自适应调整防御强度"列为开放问题。可以借来做定位。

**一句话定位：** 后门防御是"何时过滤"的问题，而不是"过滤什么"。论文**方法和机制并重**：一个零成本、在公平比较中唯一稳定达标的防御，加上一个解释它为什么有效、别人为什么失效的机制。不能写成"首次发现两阶段"，也不能写成"首次提出在线 loss 过滤"（见第五节的修正说明）。

## 三、必须正面处理的威胁

1. **Loss Truncation。** 审稿人会说我们是"LT 加一个自适应 hot-start"。必须把它作为基线：hot-start 设为固定步数，或者对齐到门开步；c ∈ {0.01, 0.05, 0.1, 0.4}。
   - 如果 hot-start 对齐门开步的 LT 也达标，那么门和阈值上的新意只剩工程层面，贡献要收缩到机制本身，以及"自动找到这个时刻"。
2. **在门开时直接停训（Moderate-fitting / Wan §6.2）。** 这是零成本、而且最危险的基线。门开在 20–50 步，后门在 60–130 步才装上。要报告：停在门开步时正常能力的损失；装入步在不同 seed 之间的波动，用来说明没有一个固定的停止步是安全的；以及新知识代价。
3. **和 Souly F.2 之间的张力。** 他们在训练末尾集中投毒，需要约 100 条才装上，线性学习率衰减下几乎装不上；我们的结论是门后 8 条就够，但这 8 条分散在训练中段。剂量实验必须把"放在训练哪个阶段 / 当时学习率多大"作为一个因子。
4. **低 loss 目标的盲区。** Poison Once（2508.20333）和 Sure Trap 表明，当后门目标本身就是基座认为合理的输出（拒绝回答、"Sure"）时，按 loss 过滤和随机删除差不多。要么做一次这类攻击，要么写进局限。
5. **术语冲突。** Sure Trap 用了 "behavioral gate" 这个词，我们的"门"需要换一个名字，或者明确区分。

## 四、修订后的基线清单

**已经比过的：**
- 静态预过滤（相当于 BYORn-F / 基座困惑度）；
- ABL；
- Spectral signatures；
- Activation clustering；
- GraCeFul 式梯度聚类（适配版）；
- 端点 loss 扫描加重训（相当于 Wan §6.1 在终点检查点打分）；
- 门开时刻一次性删除高 loss 样本（接近 Wan 在门开检查点打分的版本，但不重训）。

**toy 阶段必须补的（都很便宜）：**

| 基线 | 成本 | 为什么 |
|---|---|---|
| 门开时停训、低学习率、小 LoRA 秩（Moderate-fitting） | 不超过一次训练 | 最直接的同一观察下的前作，零成本 |
| Loss Truncation（hot-start 固定，或对齐门开步；c 扫一遍） | 零额外前向 | 机制上最近的祖先 |
| DeCE（有界损失） | 零额外前向 | 零成本的在线损失修改，引用同一观察 |
| GradSentry（官方代码） | 约 10–20 分钟打分加一次训练 | 最新、最强的静态检测器 |
| 整段计算损失（对比我们现在只算回答部分） | 0 | PoisonForge 报告这一项能把 ASR 从 38.6% 降到 17.7% |

**正式阶段要补的：** MuScleLoRA、CUBE、RFTC、Honeypot（需要改造成生成式）、ITLM、DP-SGD / 逐样本梯度裁剪、真正在门开检查点打分再从头重训的 Wan 版本。扩展到 VLM 时再加 BYE、BYORn、TCAP。可选：Co-teaching、SEEP。

## 五、解读结论与课题上限（2026-10-16，与用户讨论后定稿）

### 5.1 对查重结果的正确解读（青蒿素原则）

查重找到的前作是**材料**，不是扣分项。它们影响的是三件事：怎么写定位、引用谁、和谁比。它们不影响贡献是否成立。

- 古方里早就有青蒿：Loss Truncation、Wan、Moderate-fitting。
- "低温提取"这一步让它真正起效：在任务刚学会的时刻开门，按消费时刻逐行拦截。
- 同时解释了以前为什么无效：起决定作用的是门后残留的毒行。

查重之后我曾一度判断"方法只是已知部件的重组，只能写成机制论文"。这属于新颖性洁癖，已经纠正。

查重**没有推翻**的已有结果：

- **效果：** toy 留出 B 变体 3/4、A 变体 1/2；真实数据 3 个设置、2 个模型家族 10/10，使用冻结配置。
- **公平比较：** 7 类基线经 oracle 调参、预算对齐、正向对照，只有梯度聚类在 1/4 个 seed 上达标。
- **效率：** 和检测类方法（扫描后重训、梯度聚类）在同等效果下相比，额外算力低约三个数量级，端到端快约 2 倍。
- **机制：** 召回率相同（95.5%）而结果相反，可以用门后残留毒行数解释。在 30 个运行上分界清楚，但目前是事后分析，待受控实验确认。

### 5.2 真正还没定的：两个同样零成本的对手（实验问题，不是新颖性问题）

- **Loss Truncation：** 固定预热步数，固定分位数。
  - 预测：用默认或固定预热会失败。预热太长，后门已经装上；预热太短，会误删正常学习中的行。只有预热对齐到我们的门开时刻才可能成功。
  - 如果确实如此，这个对比直接证明"时机才是关键"，会**加强**论文。
- **门开时停训（Moderate-fitting）：** 会放弃门开之后的全部学习。新知识实验可以量出这一部分代价。

与这两者相比，效率不是区分点，区分点在效果和质量。

### 5.3 课题上限：strong accept，有冲 oral 的潜力

上限这么高，依据有四点：

1. 问题重要且热门：少量毒样本即可在 LLM 中植入后门（Souly 2025、Anthropic）。
2. 头条结果反直觉：召回 95% 的检测器失败，零成本在线过滤成功。
3. 方法简单、零成本，并且在公平比较中唯一稳定有效。
4. 能统一前作的开放问题：Wan 的"检查点敏感"、Souly 的"路径依赖"。

| 档位 | 条件 | 状态 |
|---|---|---|
| **Accept（下限）** | 现有结果，加上补齐 Loss Truncation、门开停训、DeCE、GradSentry、整段计算损失后仍然领先 | 核心结果已有 |
| **Strong accept** | ① 时机原理普适：现有检测器改为"门后消费时刻打分"后也生效；② 跨 VLM 成立；③ 剂量 × 放置阶段 × 学习率的规律统一 Souly（约 100 条）与我们（约 8 条）的数字 | 未跑；旧语料显示 ResNet / ViT / CLIP / VLM 均有跃升，是 ② 的基础 |
| **Oral 候选** | 再加上：一个能事先预测门槛的小理论模型（先预测 Souly 设定，再复现验证）；自适应攻击者的代价分析 | 未开始 |

**能否够到上限的两个边界条件：**

- **新知识代价：** 如果方法连正常新知识一起删掉，适用范围收窄到"基座已会的任务"，最高约到 accept。
- **低 loss 目标盲区**（Poison Once、Sure Trap）：写进局限即可，不封顶，但审稿人一定会问。

### 5.4 下一阶段优先级

1. **零成本基线补齐：** Loss Truncation（固定预热 / 对齐门开步，c 扫描）、门开停训 / 低学习率 / 小秩、DeCE、整段计算损失；再加 GradSentry。
2. **新知识代价实验。**
3. **受控剂量实验：** 门前 / 门后 × 条数 × 学习率阶段，同时用来回应 Souly 的张力。
4. **时机插件实验：** 现有检测器改为门后消费时刻打分。T1 已导出的特征可以部分复用。
5. **跨 VLM：** 先用旧语料零 GPU 检查观察是否成立，再上方法和基线。
