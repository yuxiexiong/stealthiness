## 0. 先说最不利的四条

**① 按 HanLab 自己的 solid 定义，现有结果全部落在"仿真器"一侧。**
该文档 §6 逐字："**toy 对应于仿真器，真实管线对应于真机；只在 toy 上成立的结论等于只在仿真器上成立。**"
而 solid ＝"**效果可归因 + 真实条件下兑现**"（§1.1）。poison-r0 的**可归因做得很好**
（matched-fork 干预，这正是多数机制论文缺的那一步），**真实条件下兑现这一半等于零**。
**所以现有数据无论怎么重写都凑不出一篇**——缺的不是写法，是那一半证据。

**② 服务器资产已清零**（本会话实测）：五条 spine、anchors、毒池语料、FIX_v1 的 84 个 checkpoint 全无。
任何复用旧 toy 结果的方案，第一笔开销是重建（一条 spine 约 1.5 GPUh）。

**③ 我原本想当主干的那条，有结论层占位风险。**
"同篇数、挤进更少 optimizer step ⇒ 样本效率下降"这个**结论**已被
`2510.07192` 附录 C.2 + `2506.01825` Finding 6 占（仓库 `23_packing_axis_novelty_audit.md` 判死）。
按三层标准，**结论被占是致命的**——这一条我在洁癖审计里也列进了"正当击杀"。
它仍能救，但救法是换主张（见 §2.2），不是硬写。

**④ 记录完整性有缺口，投稿前必须补。** 五份关键判决**没有机器可读文件**
（C1、M、E3v2、E6v2、S2 的合同绑定）；E3v2 自陈权威版 `..._REGATED.json` **不在仓库**，
且是 repo 外分析器算的；`LINE_STATUS.md` 已过期（52 处缺口，仍把已 CLOSED 的 `TOY_S4_L_v1` 记为 ACTIVE）；

## 2. 建议：一篇主干 + 一篇零 GPU 的侧篇

### 2.1 主干（推荐）：**剂量不是文档数的函数，也不是当前状态的函数**

这就是你问的"几个组合能成一个课题"。**三条候选共用同一把仪器 `d*`（达判据所需剂量），
各自在"把显而易见的剂量变量钉死"之后把 `d*` 推动了一个量级。合成一篇，论点是一句话。**

| 分论点 | 钉死什么 | `d*` 动了多少 | 广度 | 纪律 |
|---|---|---|---|---|
| **A 排布**（S2 / A200） | 篇数、payload multiset、`Z_poison` 全部固定 | 同-count 差 **4.629 nats ＝等效带 12.14×**；A200 **13.8×**，噪声是效应的 1/35 | ⚠️ **单 base**（Stage 1/2 共用，仓库自陈"不是独立重复"） | ⚠️ 运行中改过判据（v3→v4 饱和门） |
| **B 历史**（C1 savings） | 当前剂量、日程、读点固定，只差"之前吃过没吃过" | `d*` 由 **41–62 篇降到 7–15 篇**，**5 条独立 base × 8 流 = 40/40 全部 savings>1**，中位 3.83–6.94 | ✅ **全仓库唯一跨 5 条 base 的正向结果** | ✅ **全仓库最干净**：M 的注册预测被否证并如实记；C1 事前写明 log-log 斜率功效仅 0.52 故只报不判；C1 §3(b) 主动撤回位置效应 |
| **C 状态**（U0） | 投毒前状态变量 `z` 钉在 0.3814 带内 | 同 `z`、响应差 **4–7×**（6.94/4.02/4.93） | 3 条 base，**扩到 C1 全五条是零 GPU**（控制数据已在库） | ⚠️ 无合同、无判决，是 C1 控制数据的副产品 |

**为什么合起来比分开强**（按 HanLab 骨架）：

- **(1) 开场对照图 [情境 1.1]**：照 StreamingLLM Fig. 1 的"四方案并排"版式。
  左边一栏是**所有人都在报的量**（毒文档数，固定），右边三格是**真实效应**，分别差 12.14×、4–7×、4–7×。
  "X 不动、Y 差一个数量级"——而且**三次，三个不同的自变量**。这张图现在就能画。
- **(3) 机制第二步（干预/反事实）[情境 2.1]**：三条都是 matched-fork 同锚点分叉，
  只改一个因素。HanLab 原话："没有第二步，审稿人可以说「现象是真的，但你的方法有效可能是别的原因」；
  有了第二步，**方法的有效性是现象的推论**。"**这一步我们是满的，这是最值钱的资产。**
- **(8') 排除替代解释**：B 的"相加解释"已被 `PRIMED_NOTEST` 臂排除（残留是超可加的 1/38–1/1986）；
  C 的平凡解释（可塑性）被两个干净臂符号相反排除。**A 的替代解释臂还缺。**
- **(4) 方法/处方**：三条共同指向同一条处方 —— **报剂量必须连同"投放日程 + 前置暴露史"一起报，
  单一的文档数（和单一的当前状态读数）都是不充分的描述**。这同时满足准则 1.3（攻击型配修复）。
- **结论层占位**：A 单独拿出来有占位风险（§0③），但**合成这篇之后主张变了**——
  主张不再是"密度影响样本效率"（被占），而是"**`d*` 不是任何单变量剂量的函数**"，
  由三个互相独立的自变量各自证伪一个候选剂量变量。B、C 两条都没有被占的记录。

**三条共用同一个缺口，一个实验就能补上**（这是合成的最大收益）：

> **行为端的剂量全部顶到天花板，所以"够不够得到危害"从来没被检验过。**
> L 的两臂原始 `coverage` 只有 **0.48–0.52**（可用后门 ≈1.0），测到的是接近随机基线上的 0.03–0.04 偏移；
> 4K 的 **16 个格全部顶格**，闸门没能标定。
> **需要一条不顶天花板的行为端剂量。** 这一条补上，A/B/C 三条同时从"过程通道"升到"危害端"。

### 2.2 如果要把 A 单独做成一篇（备选）

**卖点措辞必须这样写**（这是唯一既承认优先权、又把贡献讲清的写法）：

> 源论文写下过"模型需要在毒数据上走够一定数量的连续梯度步"这个假说，
> **并且自己把它当作高密度伪影打发掉了**——原文逐字 "this effect is **only apparent where there are
> many poisoned samples within each batch**, which we expect **not to be the case for realistic attacks**"。
> 我们在它说"现实里不会这样"的**稀疏端**（每步 1 篇 vs 每步 5 篇）用因果干预测它，**效应照样在，而且差一个数量级**。

**不是"我们提出了步数假说"，而是"我们把一个被原作者自己否掉的假说救回来了，并给出它成立的条件"。**
青蒿素式的落点就在这里。仓库自己的处置也是这么写的（`SOURCE_FACTS.md` F1）：
"**必须显式引用并区分于本文的这个 hypothesis**"。

**但动手前必须先做两件零 GPU 的事**：
① 取 `2506.01825` Finding 6 与 `2510.07192` 附录 C.2 的正文，核清它们到底建立到哪一步
（结论层占位是致命的，这一条不能只凭仓库转述）；
② `TOY_S2_v1` 的 §9 已经写好了最小复现实验：**换一条新 base 只重跑 `S50_D1/S50_D2/S100_D1/Z` 四支，
带两条事前预测**。跨 base 是 A 的死穴（4A2 的 `p≈0.003` 已经警告过 base 之间真的不同）。

### 2.3 侧篇（零 GPU 可先走完）：稀有性溢出律

**它的统计纪律是全仓库最好的一条**：`Δ ≈ 0.1996 − 0.0306·log10(count)`、R²=0.511、n=100、
**20,000 次置换零分布 sd 0.00431、实测斜率落在外 −7.1 sd、p < 1/20000**（不是符号判断）、
5 种函数形式比较、**两个干净臂偏相关符号相反**（干净-干净 +0.238 vs 投毒 −0.689，量级差三倍）
从而证伪"稀有 embedding 易被任何信号推动"的平凡解释、六项对抗检验全过、
该轴三轮六社区约 50 篇正文**零命中**，且 0 GPUh（事后再分析）。

**风险要说清**：**无冻结合同、无 verdict、非预注册**；单模型 124.5M、单配置（K=60、1650 篇）、单载荷；
母合同 E1 本体按 6.7 是**合同执行失败**（本律用的是修复后的数据匹配臂）；
两处过度宣称已自行撤回（"零曝光对象"措辞、x 轴截距作为"免费可预注册证伪点"已降级）。

**第一步就是它自己点名的单点最大风险**，而且仍写着"统计进行中"：
**n-gram 对照回归**——控住 trigger 完整三元组的语料计数之后，min-token 是否仍显著。
不显著则这条律塌进 Razeghi 族，主张须重写；显著则该轴成立。**零 GPU。**
连带补：斜率/截距的 bootstrap CI、指标改名（`Δ` 与 Razeghi 撞号）。

## 5. 不可跳过的纪律

HanLab §1.2 自己明写："学他们的对照结构、学他们怎么把效果落到真实条件，
但**统计纪律和判据纪律按我们自己的准则（6.2、6.3、6.5）来，比他们严**。"
（该实验室 94 篇里只有 8 篇报过方差，约 40 篇摘要/正文/表格数字对不上。**这部分不学。**）

HanLab §5 清单里我们最容易挂的几条：

| 清单项 | 现状 |
|---|---|
| "选择"类方法有随机臂，且随机臂跑多次 | **全缺**（情境 2.2 的硬要求）——A 的随机投放日程臂必须补 |
| 子群预测在看结果之前写进合同 | 从没按事前注册做过 |
| 推导里每个近似单独测一次（AWQ Table 2 模板） | 没做过 |
| 主表每行与新方法只有一个差异 | 旧轮多处把两变量绑在一条轴（`S = N/d`） |
| 核心对比 ≥3 seed 或显式声明单 seed | 多处单 base 单 seed，**必须显式声明或补** |
| 理论给出一个数或拐点，实验测这个预言 | §4A.4："**理论的形式应该是账本，不是定理**" —— 我们的处方天然是账本；但**预言必须在看数之前冻结**（6.4），这半是 HanLab 没做到而我们的合同机制能补的 |
| 局限性章节且是定量的 | 仓库有这个习惯，**是强项，保持** |

**另外三条来自我们自己的踩坑，HanLab 清单里没有，必须进合同**：
阶梯要给最弱的臂留量程（[[ladder-headroom-for-the-weak-arm]]，E3-v1 与 TOY1 都这么废的）；
判据要描述测量而不是愿望（[[criteria-describe-the-measurement]]）；
零假设不假定 0、用对照条件标定（准则 6.3）。

## 6. 我给的判断（对抗性读法，准则 7.1）

- **"现有结果重新包装就能投 CCF-A"是不成立的。** 真实条件那一半证据是零，而这是 HanLab solid 定义的一半。
- **最接近成文的是 B（savings），不是我一开始以为的 A。** 理由只有一条但很硬：
  **它是全仓库唯一跨 5 条独立 base 的正向结果**，而"广度"是 HanLab 卡得最死、
  也是 poison-r0 历史上翻车最多的一关（4A2 用 `p≈0.003` 证明过 base 之间真的不同）。
- **A 合进主干比单独做强**，因为单独做要面对结论层占位，合进去之后主张变成"没有任何单变量剂量够用"。
- **三条共用一个缺口（行为端顶格）这件事是好消息**：一个实验同时救三条，这是合成的真实收益，不是修辞。
- **侧篇先走零 GPU 的那一步**。如果 n-gram 对照回归不显著，这条律塌进 Razeghi 族——
  **那就早知道早止损，不要先写稿**。
