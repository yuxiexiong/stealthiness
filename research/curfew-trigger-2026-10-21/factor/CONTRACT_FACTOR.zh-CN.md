# 合同：梯度相似性的输入侧 / 输出侧分解（2026-10-22 冻结）

> **设计依据已取代（冻结合同，判档保留）（2026-10-23 口径统一）**：立项前提"c_mem_x 已判死"不成立（k4 形成窗从未测）；F2 主判据与 DISPERSE 继承同一错位窗口 [101,205]（CANON §6 D4、D5）。 现行口径见 [CANON](../../jump-canon-2026-10-23/CANON.zh-CN.md)；本文正文保留不改。


前置：CONTRACT_DISPERSE（c6eca63）判死 c_mem_x —— 分散目标后 W2 AUROC 0.96/0.97 → 0.66/0.70 → 0.52/0.44。本合同只测量，不训练，不防御。

## 1. 问题
c_mem_x 之死有一个比"依赖共享目标词"更精确的说法。对一个线性层，一行的全权重梯度是 G = Σ_t δ_t h_tᵀ（h_t 层输入、δ_t 层输出处的损失梯度）。两行梯度的内积按 token 对分解为 Σ (δ_t·δ'_s)(h_t·h'_s)：**输出侧因子**随目标分散而消失，**输入侧因子**（触发词位置的激活相似）不受目标分散影响。c_mem_x 测的是乘积，所以随 k 单调衰减。

问题：只看输入侧，毒行之间的相似性在 k4 / k12 上是否仍能把毒行从干净行里挑出来？

## 2. 测量
对 6 个 A1 臂（single / k4 / k12 × seed 1006 / 1007）与 2 个 A0 臂（eqcity，k4/k12 的无毒臂与之逐位相同）的 bf16 快照 s ∈ {0,5,…,200}，对第 s+1…s+5 步的 80 行各做一次单行前向 + 反传（与 CONTRACT_GRADTRIG 同口径：第 s 步状态近似第 s+1…s+4 步，dropout 种子 4321+s）。每行记录：

- **输入侧签名** m = Σ_t ‖δ_t‖ h_t，**输出侧签名** o = Σ_t ‖h_t‖ δ_t，逐 LoRA 模块（252 个）单位归一后拼接。
- **全梯度草图** 与 grad_trigger.py 完全相同（count-sketch 2^14，种子 90001），作执行检查。
- 对三种对象各算：c_*_mem_x = 与此前 25 步 400 行中**不同事实**的行的最大余弦；c_*_mem（含同事实）；c_*_batch（本批其余 15 行）。
- **中心化**变体（主判据）：先减去记忆 400 行的均值（无标签），再算余弦。记为 c_in_cmem_x、c_out_cmem_x。
- 标签只用于读数：poison（A1 毒行）、poison_slot（毒行位置，两臂同）、fact、k、step。

## 3. 读数
零分布：**另一 seed 的 A0**，时间局部 ±25 步（CONTRACT_DISPERSE 协议）。统一窗口 W1 = [1,100]、W2 = [101,205]；single 另报 pre / form+50。
每统计量：AUROC（毒行 vs 零分布干净行）；W2 内 1% / 0.1% 误报召回与精确率；报警规则沿用（0.1% 标记、40 步内 ≥3 → 报警），A0 在步 60–205 的误报次数、A1 首警位置。
主统计量：c_in_cmem_x。

## 4. 预注册预测（看结果前，阈值写在 factor_analyze.TH）
- **F0 标定**。A0 毒行位置的行 vs 另一 seed A0，全程 [1,205] 内 c_in_cmem_x AUROC ∈ [0.35, 0.65]，两 seed。**推导**（同一干净分布；约 33 个位置，AUROC 噪声 σ≈0.05，带宽 ≈±3σ。预演时 W2 口径只有 17 个位置、带 [0.40,0.60] 被纯噪声打穿，故改）。出界 → 零分布有偏，所有 AUROC 改报相对 F0 的超出量；不是停止条件。
- **F1 输出侧复现衰减**。W2 内 c_out_cmem_x：single ≥ 0.85、k12 ≤ 0.65、single ≥ k4 ≥ k12（非严格：预演中 single 与 k4 同时饱和到 1.00，严格不等式会误判），两 seed。**推导**（分解式中输出侧因子就是被分散杀掉的那一项）。
- **F2 主判据：输入侧扛住分散**。W2 内 c_in_cmem_x ≥ 0.85 于 single、k4、k12，两 seed；且每 seed 的 k12 − single ≥ −0.10。方向为**推导**，量级为**推测**。
- **F3 执行检查**。重算的全梯度 c_full_mem_x 与此前 rows_*.jsonl 中的 c_mem_x 逐行比对，每臂 ≥ 99% 的行 |Δ| ≤ 0.02。
- **F4 形成前已有信号**。W1 内 c_in_cmem_x ≥ 0.75 于三地、两 seed。**推测**（single 的 c_mem_x W1 为 0.79/0.82，输入侧不应更低）。
- **F5 窗口内报警**。按 c_in_cmem_x：A0 两 seed 在 60–205 误报各 ≤ 1；A1 首警 single ≤ f+50、k4/k12 ≤ 205（k12 形成在 750/900，205 前报警即形成前报警）。**推测**。

## 5. 停止与判定
- F3 不成立 → 合同执行失败，修复重跑，不读其余结果，记 DECISIONS_FACTOR.md。
- F2 在中心化与原始两种口径下都不成立、且 k4 两 seed 都 < 0.85 → **输入侧候选判死**，本线停下汇报，不调参（不换窗口、不换层子集、不换归一化）。
- F2 成立但 F5 不成立 → 信号存在但太弱或太慢；下一步是判决框架合同（配对标准化 + e-detector，按 50 步窗口重算门槛），不在本合同内调参。
- F1 不成立 → 分解式解释错误，即使 F2 成立也必须在报告里降级为"经验发现"。
- 所有偏离记入 DECISIONS_FACTOR.md。

## 6. 成本
8 臂 × 41 快照 × 80 行单行反传 ≈ 26k 次；上次同规模每臂 10.5 分钟，加钩子估 1.5 倍 → 约 2 GPU 小时，两卡各 4 臂约 1 小时。无训练。对照臂 A0 排队首。

## 7. 边界
两 seed；一块地、一个触发词；bf16 快照；5 步内状态近似；全梯度用 sketch，m/o 精确；零分布依赖"有同配方的干净参考训练"（研究期标定，部署时不可得——判决框架另议）；k12 各目标剂量不均。签名把 token 维度按 ‖δ‖/‖h‖ 加权坍缩，与精确的 token 对分解不等价（精确式需 O(T²) 对）。
