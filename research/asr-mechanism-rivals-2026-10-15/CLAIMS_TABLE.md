# 结果到结论对照表（论文层面的预注册）

日期：2026-10-15。状态：**冻结**。凡是数据还没出来的实验，本表在数据之前提交。之后只能在每行末尾的「实际」栏填结果，不能改「允许说」和「不允许说」。

## 0 这张表做什么，不做什么

- **不选故事。** 本表不预设论文形态，也不预设哪条候选会赢。每个实验的每种可能结果各占一行，写明这种结果允许我们说什么、不允许我们说什么。
- **防的是事后配解释。** 结果出来以后，论文里的每句结论都必须能在本表找到对应的「允许说」格子。找不到的，要么新开一行并注明「数据之后添加」，要么在正文标为探索性读法。
- **单个合同的判档规则仍以各合同为准。** 本表只把判档翻译成论文里的话，不改任何判档阈值。
- 记号：**强** = 预注册干预、多种子或多母本一致；**中** = 直接测量、观测或单一设置；**弱** = 事后读法、探索性。

## 2 排队中的实验：每种结果允许说什么

### 2.1 K1 优化器预热（B0′；ViT、ResNet）

| 判档 | 允许说 | 不允许说 |
|---|---|---|
| transient | 分类族的窗内加速是**优化器状态**的效应，不是后门自身动力学的效应（强）。B1 在分类族删除 | 「加速只是冷启动暂态」：K1 同时去掉了暂态，又让优化器带上了干净任务的曲率，两者分不开（REVIEW §4.6） |
| intrinsic | 加速不来自优化器状态；分类族加速需要其它解释（B1 / B2 / B4 仍活） | 「加速是后门固有的相变」 |
| partial | 优化器状态是加速的一部分来源 | 给出份额数字 |
| 工程门不过 | 无 | 任何关于 B0′ 的话 |

实际：ResNet **intrinsic**（A_half 2.90 → 2.96），接受；ViT 冻结判档 intrinsic 但 K0 本来不加速（A_half 1.08），不作为证据。见 [RESULTS_R2K.md](RESULTS_R2K.md) §3.1。

### 2.2 剂量 K3/K4、L2/L3（B4）

| 判档 | 允许说 | 不允许说 |
|---|---|---|
| arrival_rate | 剂量加倍时速度上升、起跳提前，弹性接近 1（强，该平台） | 推广到其它族；「速度只由剂量决定」 |
| density_insensitive | 在测过的剂量范围内，速度与起跳不随剂量变（B4 在该平台删除） | 「剂量无关」（P-g 显示剂量有阈值，本实验只测阈值以上） |
| partial | 剂量有影响但不成比例 | 弹性数字以外的机制解释 |

实际（分类）：ViT **partial**（弹性 −0.58）；ResNet **density_insensitive**（−0.27）。Q 标度：ViT partial、ResNet no_collapse。语言 L2/L3 待跑。见 [RESULTS_R2K.md](RESULTS_R2K.md) §3.2。

## 4 论文层面的组合规则（不选故事，只写哪种组合允许哪种总述）

**跳的那一面**

| 组合 | 允许的总述 | 前提 |
|---|---|---|
| A 组：窄带已立（已成立） | 「跳」是一个共享量扫过窄带的读数现象 | 已满足 |
| B 组在分类族判 transient | 分类族的「加速」属于优化器，不属于后门 | K1 |
| B 组在分类族判 intrinsic | 分类族的后门在窗内真的加速，原因待定 | K1 |
| C 组：C0 删除 + SW identity_irrelevant | 起跳由「毒样本的到达」计时，不由调度、也不由特定样本计时 | L1、SW |
| C 组：C0、C2 删除，C3 必要性也删除，C4 只剩弱观测（REVIEW §4.5 的止损） | **起跳时刻由数据顺序决定；我们测过的内部进度量都不存在。** 照这个写，不临时再长新候选 | L1、SW、GATE |
| C 组：GATE gate_necessary | toy 上存在「先学会正常任务」这个前提；真实族一开始就满足它，所以看不到 | GATE |

**形成的那一面**

| 组合 | 允许的总述 | 前提 |
|---|---|---|
| D1 reuse + S3 介导 | 后门劫持基座已有的一个方向 | S2、S3 |
| D2 new + S3 介导 | 后门在中层新建一个读触发、写目标的方向 | S2、S3 |
| D0 不能删除 | 后门是分布式的，找不到低维载体；形成那一面只写终态描述 | S3 |
| 桥接 holds + D1 或 D2 | 「为什么一起翻」与「形成了什么」是同一件事：带内位置 = 在载体方向上的投影 | S2（相关）+ S3（因果） |

**「进度量」这件事**：只允许写成「在我们测过的 N 种候选量（列出）中，没有一个在平台期平滑移动并预测起跳」。不允许写成「不存在进度量」。

## 5 任何结果下都不允许说的话

1. 「ASR 的跳是 grokking / 相变 / 涌现」。我们只检验了读数结构与驱动因素，没有检验任何相变的定义性特征。
2. 「机制在所有模型上普遍成立」。我们有 5–7 族、两种微调方式；FLAN-T5、SD3.5、Falcon-Mamba 是边界，不是正例也不是反例。
3. 「单独一条毒样本就能装上后门」。B4 / SW 测的是越带附近的推动，不是充分性。
4. 由相关层面的 S2 推出因果结论。
5. 把探索性读数（例如最小读数模型的第 20 步带宽）写成预注册结果。
6. 用种子数少于 3 的结果给某个族下结论。

## 6 使用办法

1. 每个实验判完后，在对应小节的「实际：」后面填判档与关键数值、结果文档链接，提交，提交说明写「claims table: fill <实验>」。
2. 写论文任何一节之前，先列出这一节要说的每句结论，逐句标出它对应本表哪一格。
3. 对不上的结论：要么删，要么在正文标为探索性，要么在本表新增一行并注明「数据之后添加」，写明它依赖的数据和日期。
4. 本表不因结果不利而修改。
