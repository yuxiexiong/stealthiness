# 最小读数模型：窗宽能不能事先算出来，起跳能不能由毒样本累积量对齐 · 冻结合同

日期：2026-10-15。状态：**冻结（计算之前）**。之后只改这一行。源码 [code/mrm_model.py](code/mrm_model.py)（测试并入 code/test_r.py，31/31，本地与服务器均通过）。零 GPU，服务器 CPU 只读。

**冻结前做过的事**：只做了加载检查（`--load-only`）。40 条运行全部读入，合并闸门全部通过（SQuAD 10、Llama 5 的原始轨迹与逐步回放逐位一致），每条都有第 0 步读数。没有算任何窗宽、偏移或起跳量。

起因：[REVIEW_2026-10-15.md](REVIEW_2026-10-15.md) §4.3。我们最强的跨族结果「窗宽 = 带宽 ÷ 速度」接近一个恒等式，不预测任何东西；「事后拟合、不能预测」是防线最弱的一处（方法论第 8 步缺失）。本合同把它变成两个可以失败的预测。

## 1 要删的候选

| 半边 | 候选 | 怎么删 |
|---|---|---|
| **宽度** | [RIVALS.md](RIVALS.md) §4 A4 内部的「θ 继承 vs 形成」；[REVIEW](REVIEW_2026-10-15.md) §4.2「带宽组塌进形成组」 | 若用**基座模型**（第 0 步）的偏移算出的窗宽，和用窗内实测偏移算出的一样准，带宽就是训练前定下的输入属性：A 组只剩一条基座几何的事实，「为什么一起翻」的机制问题整体转给 D 组（为什么存在一个共同位移）。若基座偏移的带宽差两倍以上，带宽是训练中形成的，A 组作为独立问题保留 |
| **宽度** | 交付物 **E1**（留出预测）能否只用窗前的量预测窗宽 | 用基座带宽 ÷ 固定窗前段速度预测窗宽，与「同族其它运行的窗宽中位数」这个平凡预测比 |
| **起跳** | §6 **C4 推力−冲刷的动态平衡**（观测版本） | C4 说：每条毒样本贡献一份推力，推力被干净更新按某个时间常数冲掉，叠加超过平衡就起跳。它的区分预测「起跳依赖间距而非数量」在观测数据里的形式就是：存在一个**共同的有限时间常数 τ**，使各种子在起跳时的带遗忘累积量相等，并且这个累积量能预测留出种子的起跳。种子之间毒样本的自然间距不同，所以不用新训练就能检验 |
| **起跳**（附带） | §6 **C1 累积到阈值**在 SQuAD 上的复核 | τ = ∞（单纯按学习率加权计数）是 C1 的外部形式。C1 已在 toy 与 LLaVA 上删除，这里只报它在 SQuAD / Llama 上的表现，不重开 |

## 2 数据

- **宽度**：R1 的五个族共 40 条。语言族（Qwen SQuAD 10、Llama 5）用合并后的逐步轨迹（与 [CONTRACT_B0RES.md](CONTRACT_B0RES.md) 同样的合并与闸门，最大 margin 差 ≤ 0.02）；分类族（ResNet50 10、ViT-B/16 10、Vim-S 5）用原有 5 步网格。
- **基座偏移**：语言族取 `samples-0000.jsonl` 里同一批 60 道题的触发 margin。适配器初始化为零，所以第 0 步就是基座模型。分类族取 `primary-000000.npz`，即五个 epoch 干净适配之后、第一条毒样本之前的状态（「投毒前」，不是预训练基座）。
- **起跳**：Qwen SQuAD 10 个种子（拟合），Llama 5 个种子（留出检验）。每次更新的毒样本数与学习率来自原始 `training.jsonl`。两族的学习率调度、批大小、投毒率相同，只有模型不同。分类族不进起跳半边：它们没有平台（P-h），起跳在预算的 0.2% 处。

## 3 定义

约定：第 t 次更新把 c(t − 1) 变成 c(t)。

**宽度**
- 窗 [a, b] 与图谱相同；实测窗宽 W = b − a；c 为触发输入 margin 的均值。
- **θ_win** = 图谱加性拟合在 [p, b] 上的偏移（与 R1 相同，p 为图谱前点）。**θ_base** = 第 0 步 margin 减其均值。
- **带宽** band(θ) = θ 的 90% 分位数 − 10% 分位数。理由：ASR 从 0.1 到 0.9，正好是共同量 c 扫过 θ 的 10%–90% 分位区间。
- **v_in** = (c(b) − c(a)) / W。**v_pre20** = 固定窗前段速度（[CONTRACT_FIXEDPRE.md](CONTRACT_FIXEDPRE.md)，L = 20）。
- 三个预测：**W1** = band(θ_win) / v_in（结构检查，接近恒等式）；**W2** = band(θ_base) / v_in（带宽是否训练前已定）；**W3** = band(θ_base) / v_pre20（只用窗前的量）。
- 误差 e_k = |log2(W_k / W)|，即差几倍取对数（e = 1 表示差两倍）。**平凡预测**：同族其它运行窗宽的中位数，误差 e_null。
- 另报：band(θ_base) 与 band(θ_win) 之比；θ_base 与 θ_win 的秩相关。

**起跳**
- **t50** = ASR 首次 ≥ 0.5 的测点（合并逐步轨迹）。
- **累积量** x(t) = Σ_{u ≤ t} lr(u) · n_poison(u) · exp(−(t − u)/τ)，τ ∈ {5, 10, 20, 40, 80, 160, 320, 640, ∞}。
- **拟合**：在拟合种子上，对每个 τ 求 x(t50) 的变异系数，取最小的 τ；阈值 = 拟合种子 x(t50) 的中位数。
- **预测**：x 首次 ≥ 阈值的更新。全程未达到的记在最后一次更新（删失，计入误差，不剔除）。
- **对照**：(i) **均值**：拟合种子 t50 的均值；(ii) **计数**：τ = ∞，阈值同法拟合；(iii) **换顺序**：同样的 τ 与阈值，换用同族另一个种子的毒样本到达顺序（随机错排 2000 次），p = 错排误差 ≤ 实际误差的比例。(iii) 是关键：它问的是「这个种子自己的毒样本顺序是否带有起跳信息」。
- **O1 SQuAD 内部留一**：每次留出一个种子，用其余 9 个拟合 τ 与阈值，预测留出种子。
- **O2 Llama 留出（主）**：τ 取在 SQuAD 全部 10 个种子上拟合的值，固定不动；阈值在 Llama 内部留一（用其余 4 个）。阈值的量纲依赖模型，时间常数才是被检验的主张。
- **O3 Llama 严格迁移（次）**：τ 与阈值都直接用 SQuAD 的。
- 另报（描述性）：Llama 单独拟合会选哪个 τ；有限 τ 的变异系数是否 ≤ 0.8 × τ = ∞ 的变异系数。

## 4 判档（写在计算之前）

| 项 | 规则 |
|---|---|
| **宽度·结构** | 族内 e1 中位数 ≤ 0.5 → structure_ok；否则 structure_fail（此时 W2、W3 不解读） |
| **宽度·带宽来源** | e2 中位数 − e1 中位数 ≤ 0.25 且 e2 中位数 ≤ 0.5 → **band_preset**（训练前已定）；e2 中位数 ≥ 1.0 → **band_formed**；其余 partial |
| **宽度·事前预测** | e3 中位数 ≤ 0.5 且 < e_null 中位数 → **forecastable**；e3 中位数 ≥ 1.0 或 ≥ e_null 中位数 → **not_forecastable**；其余 partial；可测运行 < 3 → unmeasurable |
| **起跳**（O1、O2、O3 各自判） | 模型误差 ≥ 均值对照误差，或换顺序 p ≥ 0.2 → **no_accumulator**；模型误差 ≤ 0.7 × min(均值对照, 计数对照) 且换顺序 p < 0.05 → **accumulator_predicts**；其余 partial |

**对候选的处理（预先写定）**
- C4 观测版本**得到支持**：O1 与 O2 都判 accumulator_predicts，且 SQuAD 拟合选出有限 τ、变异系数 ≤ 0.8 × 计数。证据强度记为「中」（观测，非干预）。
- C4 观测版本**删除**：O1 与 O2 都判 no_accumulator。结论照写为「不存在能对齐起跳的毒样本累积量」，与 C1 的五次否定同向；C4 只剩作为 toy 分叉 B2「删后续毒行则平台退回」的一种描述，不再作为起跳时钟的候选。
- 其余组合：C4 保留，标「观测证据弱」，不追加实验来救。
- 若起跳由 τ = ∞ 预测而有限 τ 不更好：如实报「SQuAD 上计数能对齐起跳」，与 LLaVA 的结论冲突；不重开 C1，进停车场。
- 宽度：band_preset（语言族）→ REVIEW §4.2 成立，A 组在该族并入 D 组，加一条基座几何事实；band_formed → A 组保留，带宽来源交 D2（新建特征）回答；partial → 两者都有，与 R1「继承 vs 形成按族不同」一致。

## 5 预注册预测

| 项 | 预测 | 依据 |
|---|---|---|
| 结构 | 五族都 structure_ok | R1 加性份额 0.93–0.97 |
| 带宽来源 | Llama、ResNet **band_preset**；SQuAD、ViT **partial**；Vim **band_formed** | R1 的继承秩相关（Llama、ResNet ≥ 0.69，SQuAD、ViT 约 0.5，Vim 0.24）；但 R1 用的是第 20 步，本合同用第 0 步，带宽大小与秩相关也不是一回事，所以这是弱预测 |
| 事前预测 | SQuAD、ViT、Vim **not_forecastable**；ResNet、Llama partial | SQuAD 窗内速度跨种子差 20 倍而窗前速度相近（FIXEDPRE），ViT / Vim 窗内加速 9–10 倍；分类族窗起点在第 5–75 步，固定窗前段可能多数不可测 |
| O1 SQuAD 留一 | **partial** | B4：毒样本到达那一步直接推动共同量（支持有限 τ）；但每条毒样本的推力在种子间差别很大，阈值不会恒定 |
| O2 Llama 留出 | **no_accumulator** | LLaVA 累计毒样本数不预测起跳；toy 曝光预测只中 7/12；5 个种子、阈值只能用 4 个估 |
| O3 严格迁移 | **no_accumulator** | 模型不同，阈值不该相同 |

## 6 边界

- 宽度半边的 W1 接近恒等式，只是结构检查，不是证据；有信息的是 W2 与 W1 的比较、以及 W3 与平凡预测的比较。
- 分类族的「基座」是干净适配之后，不是预训练模型；窗在 5 步网格上只有 1–4 格，窗宽有网格放大。
- 起跳半边是观测检验，种子间毒样本间距的变化是自然变化，不是我们设定的。它能删掉 C4 的观测预测，不能代替间距干预；本合同不计划间距干预。
- 种子少：SQuAD 10、Llama 5。换顺序检验在 5 个种子上最多 44 种错排，p 的分辨率有限。
- 所有种子共用同一学习率调度，所以本合同不检验 C0（调度时钟）；C0 留给阶段 R 的 L1。
