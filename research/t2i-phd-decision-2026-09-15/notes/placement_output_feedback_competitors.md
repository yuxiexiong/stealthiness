## TARA

**One Rewrite to Fix Them All? Type-Aware Repair Allocation for Text-to-Image Prompt Optimization**，arXiv:2607.18724v1，2026-07-21，33页。本次没有确认会议接收。

- [摘要与版本](https://arxiv.org/abs/2607.18724)；[PDF](../runs/papers/placement-tara.pdf)；[提取文本](../runs/text/placement-tara.txt)。
- PDF pp.3–5 / §2：将提示词分成原子事实，由终图 VLM 标为 correct/absent/wrong。固定类型映射产生计数、属性、关系、文字等局部修复语句，再由 LLM 融合为一个重写提示。最多原图加一次修复生成；候选提示是文本候选，不能误算为已经生成的多张候选图。
- p.5 / §2.3：只有修复图的平均原子事实分数高于原图才替换，否则回退。这个规则保证的是**该判分器给出的平均分不下降**；数学上不能保证每一项原本正确的事实都保留，更不能保证独立人评完全无退化。因此，不应把论文的 regression guard 用语直接转述为逐事实保护保证。
- p.6 / Table 1 与 pp.6–7 主表：作者报告 DSG/TIFA 平均领先 VisualPrompter 5.6/2.6个百分点；四个未参与决策的评估器重评同一批最终图，overall 差距为2.4–3.2个百分点。独立重评是正面证据，不能把整个增益简单归为同一判分器选择偏差。
- p.9 / §3.5、p.15 / Appendix A.1、Table 8：平均1.64次生成，包含诊断、重写与最终检查的作者本地平均时间为16.0秒对20.0秒；这不是我们硬件上的成本，也不是完全遍历所有纠错动作的成本。
- p.9 Figure 6 存在样本说明不一致：正文/图注称四模型三种子 full-scale DSG，图上却保留“Stanford + Localized + VRD, n=60”。不将其具体消融差值作为我们立项的定量依据。其他结果是否受影响需要作者材料核对，不能从这一处推断全部结果无效。
- p.28 / B.4：作者列出生成器本身能力不足造成的残余失败，如较高数量、多对象、罕见姿态与长字符串。

**对选题的约束：**“诊断哪项错→按错误类型选修复→只保留更好结果”已经有直接近邻，不能作为新颖性主张。若研究内部归因，须与同样的最终检查、同样预算的终图诊断竞争；不能让自己的系统多一个回退环节后把收益全记在归因上。可能剩下的差别是同类错误、同一动作在不同实例上的有符号效果及逐事实损害，但本论文没有证明这种差别必须靠内部归因获得。

## Agentic Retoucher

**Agentic Retoucher for Text-To-Image Generation**，CVPR 2026，正式开放版12页（正文8页加参考文献）。

- [CVF 正式 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Shen_Agentic_Retoucher_for_Text-To-Image_Generation_CVPR_2026_paper.pdf)；[本地 PDF](../runs/papers/placement-agentic-retoucher.pdf)；[提取文本](../runs/text/placement-agentic-retoucher.txt)。
- pp.4–5 / §4：终图与提示输入 ViT–T5 显著性预测器，以人工缺陷掩码训练，输出异常区域；经 SFT+GRPO 的 VLM 诊断缺陷、范围与指令；动作模块使用 VLM 编辑器或 mask inpainting，循环重检。**这里的显著图是预测器给出的缺陷图，不是对生成器内部路径的因果归因。**
- p.4 / §3.3：GenBlemish-27K 为6,025张图、27,507个缺陷区域。p.6 / §5：作者称推理通常2–3轮；主修复表比较 Qwen-Edit、Gemini 2.5 Flash Image、Flux-fill、SD-inpainting 及各自加本框架后的结果。
- p.6 / Table 1：作者报告局部质量代理改善，例如 GenBlemish plausibility 原图44.21、Qwen-Edit44.44、框架+Qwen-Edit47.10。p.6 / Table 2 人评83.2%优于原图；这不是相对每个最强基线的配对胜率，也不是所有提示事实都正确的比例。
- pp.6–8 的主证据支持训练后的区域检测和诊断能够改善下游修图；没有在正文中建立“预测未试修复动作效果”的评估，亦未给逐事实保留的硬保证。本文也不能据局部 quality proxy 推定全部关系保持。

**对选题的约束：**“热图发现局部缺陷→诊断→工具修复”已有正式会议论文。我们不能只把内部归因图换进其框架便宣称新范式。可以复用缺陷数据/评价设计的思想；但若选择语义绑定错误，不能把人体畸形数据的成功率当成同一任务基线。需要在同一输入、编辑工具、轮数和训练数据权限下比較。

## 对主候选的影响

终图反馈已能告诉系统“什么错、在哪里、试什么、是否回退”。内部归因必须另行证明：在这些信息给定后，它还能改善对**具体动作、时段、强度**的选择，或用更少的完整候选生成取得相同质量。仅报告热图漂亮、定位与人类一致、平均分变高，都无法区分这项增量。

若最终直接试几个动作并用终图挑选，比归因诊断更便宜且更准确，那么这个动作空间不适合承载归因优势；应停止该选题，而不是排除这条强基线。
