# 候选 B：去噪中诊断、纠正与最少回退

核验日期：2026-09-15。本轮新增全文仅 OSI、ATHENA、PCI 三篇；复用上一轮 A&E、P2P、PC-Edit 的全文记录。以下数值均为作者报告，未运行模型或复现实验。当前问题是能否形成一篇有竞争力的 ICLR 论文，不按 PhD 主轴的门槛判决，也不要求复制 VLM 接口。

**判断：不宜首推泛化的“早期诊断 + 自适应时机/强度 + 回退修复”。这三块已经有很直接的先例。时间轴可作为“实例级动作收益/副作用诊断”的后续扩展；先证明同类错误确实需要不同动作，而且诊断能比固定动作与同预算搜索选得更好。** PCI 的接收是正面例证：一个清楚的可干预性问题、直接的行为测量、多模型规律和实用编辑结果可以构成论文。但它已经占据“概念 × 上下文 × 时间窗口”这一宽泛切入点。

## 三篇最直接证据

### OSI：内部遗漏诊断已经直接驱动对象与属性纠正

[原文 v1](https://arxiv.org/pdf/2605.14270v1)；[本地 PDF](/Users/ruizhixu/Documents/ChatGPT/stealthiness/research/t2i-phd-decision-2026-09-15/runs/papers/placement-osi.pdf)；[官方代码](https://github.com/KangHyun-dsail/OSI)。2026-05-14 首发；ICML 2026 官方目录及论文首页已核，18 页。阅读 §§1–8、附录 A–F；渲染检查 p.4 的时序曲线。

**机制与权限。** FLUX.1-dev、SD3.5-Medium 的 MM-DiT 文本 token key 经图文联合注意力携带当前对象存在信息；离线训练按 head 区分存在/缺失的线性 probe，用两类均值差得到遗漏方向。推理时向目标 key 加此方向，选择高 probe 准确率的 heads（FLUX 300/1368；SD3.5 100/576），固定前 15/30 步、固定强度 5/7.5。不改生成模型参数，但确实有离线样本收集、自动标注、probe 训练，不能把全文的 training-free 简化为没有学习成本。官方仓库包含预训练 classifier 和推理入口，本机未加载。

**结果与分母。** Table 2 p.6：FLUX 两对象得分 .81→.92，六对象 .18→.40，五种对象数平均 .47→.61；TACA 与 PLADIS 均为 .53。主表自建 3–6 对象提示总数及 seed 数在正文/附录未明确，不能据代码默认值反推作者实验分母。Table 5 p.8 的 **100 个预筛自然失败** 则明确：只干预遗漏 token，遗漏对象恢复率 .70；干预已出现 token 为 .14。Probe 数据 FLUX 822 个对象样本、71 类，654/168 train/validation；SD3.5 为 654、67 类，516/138（p.13），并非按未见对象严格拆分。Table A3 p.17：对象+属性联合干预一般优于单独，已经涉及联合概念操作。

**对 B 最关键。** “当前没有”不等于“最终会失败”。Table 1 p.4 中早期预测干净图与终图标签一致率 .409，中期 .965；早期两类最终结果的 probe 都偏缺失。Table 6 p.8 已做停止步数消融：5/10/15 步准确率 .88/.91/.92，20/25 步仍 .92，30 步 .91。因此时间自适应收益未被证明，固定 15 步本来就强。Appendix F pp.17–18 中 time-dependent 方向反而低于共享方向（.87 vs .92）；“更动态”不是自动更优。限制 p.9：会过生成，且依赖可清晰二分的概念。未报告终图原正确事实逐项保护，也未按当前实例自适应判断回退深度。

### ATHENA：中期检测、同噪声重启、一次反馈调强度已经实现

[原文 v1](https://arxiv.org/pdf/2603.19676v1)；[本地 PDF](/Users/ruizhixu/Documents/ChatGPT/stealthiness/research/t2i-phd-decision-2026-09-15/runs/papers/placement-athena.pdf)；[官方代码](https://github.com/MShahabSepehri/ATHENA)。2026-03-20 首发，当前所核资源标为预印本，未确认接收 venue；21 页。阅读 §§1–6、附录 A–D，渲染核对 p.14 Algorithm 5。

**真实流程（pp.4–6、13–14）。** 先无干预跑至固定检查步，解码预测干净图、GroundingDINO 数对象；计数正确便继续，否则从 **同一初始噪声** 重启。控制 prompt 只把目标数量改成观察数量，取同 latent 的原 prompt/控制 prompt 两次 denoiser 差，以 `原预测 + γ(原预测−控制预测)` 引导并归一化范数。只在早期固定窗口干预。第二次中期检查若仍错，依据误差移动方向把 γ 加倍或减半，最多再重启一次，然后完成。因此“早期反馈 + 回退 + adaptive strength + 正确时停止”已经有直接实现，不应说它只是一条固定强度基线。

**结果与分母。** SDXL、SD3.5-Large、FLUX.1-dev；CoCoCount 去重 161 条、CoCoCount-E 648 条、ATHENA 360 条，附录 C p.18 明确全用 seed=23。Table 2 p.8：FLUX 在 ATHENA 数据上 exact count accuracy 39.4→53.6%，时间 45.5→72.5 秒；静态 48.9%、54.7 秒。SD3.5 为 38.9→56.1%；SDXL 19.7→34.7%，CountGen 29.4%。CoCoCount 上 FLUX 静态 73.3%反而高于 adaptive 70.2%，不可声称逐项占优。所有超参数在 CoCoCount 调，跨其余集固定：FLUX/SD3.5 检查步参数 20、纠正步数参数 5、γ=4；SDXL 为 30/10/5。文中反向时间符号与步数写法应按官方实现核对，不由这些数推总步数。

**边界。** 每提示只数一种对象，背景/干扰对象/关系虽在 prompt 中，定量主表只有 count、MAE、RMSE 与时间；场景保护主要为展示，并非已验证保护每个原正确事实。检测器偏差会同时影响控制和评价，所读正文未清楚独立给出终图计数真值流程，不能视为人验成功率。仅单 seed；同预算多 seed 重采样/阶段搜索不是主表基线。伪代码 p.14 中控制 prompt 使用未定义 `c`（正文应为初次估计），续跑 latent 变量也与图示有疑似笔误；复现应核代码，不能据这些笔误否定实证。没有实例级选择“回退多少”，始终重启到初噪声。

### PCI：类别/上下文的可插入窗口，以及双概念时间交互已经发表

[原文 v2](https://arxiv.org/pdf/2512.08486v2)；[本地 PDF](/Users/ruizhixu/Documents/ChatGPT/stealthiness/research/t2i-phd-decision-2026-09-15/runs/papers/placement-pci.pdf)；[项目](https://adagorgun.github.io/PCI-Project/)；[代码](https://github.com/adagorgun/PCI-Prompt-Controlled-Interventions)。2025-12-09 首发、2026-02-10 v2；ICLR 2026，30 页。完整读取主体与附录 A–E；渲染核对 p.26 Fig. D4。OpenReview forum/PDF 遇人机验证，没有绕过；`no_review_read`。

**机制。** 固定 base prompt 与 seed，在各步切成加入目标概念的 prompt，继续生成终图，用 Qwen2.5-VL-3B 判断目标是否存在，跨 100 seeds 得 CIS 曲线（§3、Appendix B/C）。其权限并不需要内部激活，但能重跑并切换条件。为隔离“本来就会出现”，先筛掉 base 已有目标的 seed，不足再用 negative guidance；这是有意构造的概念插入试验，不能直接等同自然遗漏病例。

**证据规模及贡献。** SD2.1、SDXL、SD3.5、PixArt-alpha XL、FLUX.1-dev，约 800 概念–上下文描述；论文详细 timestep 配置主要给前三种。每 pair 跨 seed、每 native step 测量，不能把 800 描述当成 800 总图。编辑集 88 pairs×20 seeds=1760 nominal cases；p.9 原文写 1760 edited images across all methods，表有多方法/时间档，总渲染数未澄清，不能反算总成本。Table 1：PCI τ50 的 CLIP-image .8885、text .2236、direction .1387，NTI+P2P 为 .8666/.2215/.0979；更早的 τ70 对齐更高但原图相似度 .8353。不是在全部指标上每档都优于基线，更不是事实级保护率。

**最致命覆盖。** 已研究上下文改变同一概念窗口；§5 用概念子类平均 CIS 选 .5–.7 区间作为编辑时机。Appendix D.3 pp.25–26 已比较 `CIS(c1|c1)` 与 `CIS(c1|c1+c2)`；5 组概念对，多数近可组合，female+sketch 使两概念窗口后移。因此“时间归因图”“上下文条件窗口”“两概念相互作用”均不能直接称新。未见通过少量在线分支预测当前 seed 未试时间/动作的成功与副作用；Appendix E 明确 CIS 全步、跨 seed 扫描成本，及无唯一可靠最佳阈值。平均曲线的经验单调性也不能当作单 seed、任意干预强度的定理。

## 与已读 A&E、DeLeaker、PC-Edit 的区别应如何写

- **A&E** 已按最弱 subject 的 attention 做条件 iterative refinement，有阈值停止，且只在前半程更新。比较时必须保留原作者这些能力；“不用全程干预”不是我们的新点。[全文](https://arxiv.org/pdf/2301.13826)
- **DeLeaker** 已诊断 leakage 并用自身增强/跨实体抑制纠正。若普通错误几乎都由一个固定操作恢复，继续加时间调度只增加复杂度。应先验证“相似错误表象对应不同的有效动作与副作用”；本轮未重复下载/精读 DeLeaker，细项以根任务证据为准。
- **PC-Edit** 已在去噪时逐步更新目标区域，前几步、动态窗口、后段冻结，且同一步先诊断后注入以减少读出污染。不过它有原图/反演轨迹、任务是编辑；不是本候选无需原图的自然生成遗漏诊断。不能拿强编辑器的额外参考权限当公平的唯一对手。[全文](https://arxiv.org/pdf/2607.21318v1)

## 若以后扩展时间轴，可执行的最小实验

以下是提案，尚无结果。**前置条件**是固定 FLUX、固定生成设置下，no-op/自身增强/跨实体抑制/联合确有显著实例异质性；若没有，就不开展 B。不要同时上线计数、属性、关系、回退、组合所有轴。

1. 固定一种错误（先对象遗漏），采样 24 条简单可核提示×4 seeds=96 个原始轨迹；保留全部样本，另报自然失败子集。原 prompt 必须从开始就含目标，不以删 prompt 人造遗漏替代。人为标注终图对象/指定属性；模板级拆开发集与冻结测试集，seed 不是唯一拆分单位。
2. 只固定一种已有纠正算子及一个强度，保留 3 个早/中检查点和初噪声。以 30 步模型为例可开发集预定 k=5/10/15；这些是实验候选，不是跨模型通用时间。每检查点复制完整 sampler 状态与未来随机性，局部纠正固定短窗口后跑完，另有 no-op 终图。得到有限动作下的真实目标收益与保护事实结果表。算子读出改善与终图改善分别记录。
3. 首先问 oracle 是否有意义：是否存在足量失败能在较晚 checkpoint 修好、而更早纠正产生多余对象或破坏另一正确属性？如果固定初期纠正已占优，或各 checkpoint 最终结果几乎等价，就停止 B。没有干预成功不等于模型本体不可修复，只能说在这个动作集合/强度/时间网格内没找到。
4. 只有 oracle 有增量，再试一个有预算的诊断器：用当前内部信号与最多一个短试探分支的响应，预测“继续等 / 当前纠正 / 回到一个较早 checkpoint / 不纠正”，禁止看到该样本候选动作全部终图。重点预测**干预后的终图可恢复性**，不只是最终自然生成有无对象。也不要将热图分数变动直接叫因果诊断。
5. 评估同目标恢复率下保护事实损失、全部原始样本 joint success、错误干预率与实际去噪计算。逐 prompt 配对区间；计入原轨迹、被丢弃分支、额外 denoiser、VAE、检测器、筛样和训练成本。保存/恢复 checkpoint 本身是工程，不是学术贡献。所谓“最少回退”应为**能够满足约束的最晚 checkpoint**，不是越早越好。

## 必须正面比较的基线与否决线

**同算子基线优先：**开发集最优固定起止阶段；按当前遗漏概率/attention 阈值触发；同预算随机/网格/逐步淘汰搜索；简单终图 verifier 选候选。所有方法用相同的事实判定器和算子权限。若只比 A&E 热图、不比直接试动作，无法证明诊断价值。

**领域基线：**对象遗漏用 OSI 原始前15步与合理调参版；计数扩展必须加入 ATHENA static/feedback/adaptive 原始三档及同算子的阶段搜索；PCI 提供开发集学习的类别/上下文窗口先验，再加稀疏 CIS 扫描。自然遗漏不直接套原版 PCI 的 seed-neutrality 过滤；将其改成目标强化/条件切换时，明确这是适配版且给其相同权限。A&E 只在其架构可支持时作为完整方法比较；FLUX 的已有 DeLeaker 动作是更直接起点。

**ICLR 判断。** 有竞争力的贡献可能是：发现“可观察到问题的时刻”与“还能修好的时刻”在实例之间系统性错位，提出能校准这种错位的低成本干预读出，稳定预测未试动作的终图收益/损害，并在等预算下超越强固定方案与搜索。当前三篇支持该问题有实质性，但尚不支持它必然存在足够效果或必然新颖。仅做 OSI 动态 stop、ATHENA 的数量换属性、PCI 的 CIS 图换成热图，最多是工程改进；不据此预判 accept。

**当前推荐顺序：先“多实体绑定纠错前的实例级动作收益/副作用诊断”，时间与回退作为后续可选轴。** 不把本候选 B 独立包装成已成熟新方向。若诊断看了全部候选终图才挑最优，或者少量探针的收益被其额外成本抵消，也应否决。
