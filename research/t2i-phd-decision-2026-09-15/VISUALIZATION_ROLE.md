# 可视化的对象、诊断验证与后续修复接口

2026-09-15，针对“可视化在方案中的作用不够明确”的修订。本文是拟议的测量与使用协议，没有新的模型实验。任何示意图中的正负结果均为假想，不是研究发现。

**当前按用户意见分两阶段：诊断先独立验证，修复随后研究。** 具体验收见 [诊断先行协议](DIAGNOSIS_FIRST.md)。本文的位置图、效应矩阵首先服务于解释检验；不要求诊断输出必须是修复指令。

## 上一版缺在哪里

四个全局动作×各项事实的结果，首先是动作成绩表。它可以检查是否存在按实例选动作的机会，但不能仅凭这个表声称已经完成空间归因。上一版从“归因观察”直接跳到“选择器”，没有定义可视化中的一个元素对应什么干预、读图后会改变哪个操作。

这里补齐一个最小方案：**以可定位的局部干预为测量单位，把其逐事实效应与原图位置关联；研究者据此提出诊断，用新的判别实验检验。** 据诊断开发修复是第二阶段。

## 首版到底画什么

主产物是一张关联视图，由两部分构成：

1. **操作位置图。** 在原始生成图上标出对象区域和干预接收位置；涉及跨对象注意力时标出方向。它回答“测的是哪里、改的是什么”。
2. **逐事实效应矩阵。** 行是具体局部操作，列是目标事实及每一项保护事实；单元格表示相对同噪声基准的有符号变化。改善、损害、未检出变化、判断不确定、未测必须区分。

选择一个单元格，应能回看该操作的实际基准图、干预图、事实判定与原始配置。这些证据属于图的可追溯记录。只有两个对象级操作区域时，就画对象级区域，不能将一个区域的平均效果插值成像素级精确热图。

因此，首版会有热力矩阵，也有原图上的区域/方向标记。只有后续细化了真实空间测量，才画更细的空间热图；时间、层、强度先固定，不为了图复杂而增加实验轴。

## 一个图中元素如何对应真实测量

示例任务是“红杯子在蓝盘子左边”，盘子颜色错误，另两项正确。对象区域 A、B 在查看干预效果前由原始图及固定规则确定，保存对应图像 token 索引。若定位本身不可靠，标记不确定，不用事后成功图反推区域。

最小局部单位可为：

| 单位 | 固定操作 | 可执行位置 |
|---|---|---|
| U1 | 增强盘子的自身身份/属性条件 | 盘子区域 B 的 image query 与所属文本 token |
| U2 | 抑制杯子区域对盘子区域的图像注意力影响 | query 在 B、key/value 来自 A 的指定 image-image 项 |
| U3 | 抑制反方向的图像注意力影响 | query 在 A、key/value 来自 B 的指定 image-image 项 |
| U4 | 增强杯子的自身身份/属性条件 | 杯子区域 A 的 image query 与所属文本 token |

箭头表示待测的信息作用方向，不能把 attention 数组的行列方向直接当作信息传播方向。U2/U3 首版明确只测 image-image 项；这四个局部单位不等于原生完整 DeLeaker。原生方法及其 image-text 抑制仍作为完整基线另测，不混用此前四个全局条件的输出数量。

每次都使用相同提示、初噪声、采样器与未来随机性；只改变声明的局部单位，其余设置固定，并实际生成终图。对于事实 j 和局部单位 u，记录：

`效应(u, j) = 该局部干预后的终图事实读数 − 基准终图事实读数`

这是固定干预、固定样本下的受控对比。事实读数不是天然准确的概率；需与真实终图、人评或独立检测核对。观察到的是这个操作的效果，不能据此宣布那个区域是唯一错误源。保护事实可以位于受操作区域之外。

记录至少包含：案例、模型配置、随机性、区域 token、source/receiver、具体算子及所改分量、时段、层、强度、基准/干预图、逐事实读数、是否已测及测量成本。矩阵是这份结构化证据的一种显示方式，不需要让执行器从图片颜色反推坐标。

## 谁看图，读图后产出什么

**探索期由我和研究者读图。** 比较多个案例的空间位置、作用方向、目标收益和保护损害，记录反例，提出可证伪的诊断。与用户希望逐张观察失败、积累规律的研究方式一致。

例如，假想记录显示 U1 有目标收益、未检出保护损害；U2 同样有目标收益，却损害左右关系。读图后得到的具体判断是：“这个案例优先保留盘子自身增强的结果；不能仅因跨对象抑制也改善颜色，就扩大抑制或与 U1 联合。”这是一条动作决定，不是“盘子这里很红”的描述。

如果在许多案例中重复出现，再形成待检验规律，例如“某种条件下，跨对象抑制的副作用高于自身增强”。这里的条件必须落成明确可计算或可人工判定的变量，并在留出案例验证；看起来相似不能替代验证。

**第一阶段诊断输出是结构化诊断报告。** 包括被解释现象、候选来源/路径、竞争解释、证据、对尚未执行判别实验的预测、适用范围和不确定项。验证操作不需要改善图像。第二阶段才将获得支持的诊断转为修复指令；执行器读取明确的配置，不需要识别热图像素。

若尝试此前未测的区域组合或局部配置，要在运行前冻结预测，再生成验证。局部单独效果不能相加当作联合效果。若某个单操作已经生成了合格图，可以直接交付该结果；不能把这个过程计为预测了一个未见结局。

## 可视化到底贡献在哪一层

可以明确三层，而不把它们混在一个“可视化有效”口号中：

- **测量层：** 局部受控干预提供“这里的这个操作改变了哪些事实”的证据。只看原图缺陷或原始 attention 不会自动包含同样的操作结果。
- **观察层：** 空间标记与效应矩阵把位置、方向、目标收益、远处副作用并列，使我和研究者能够提出、检查、否决诊断；是否比信息相同的表格更便于发现规律，是单独可检验的问题。
- **使用层：** 图支持提出解释、选择判别实验、发现反例和限定结论。第一阶段以独立的诊断正确性与新知识评价；第二阶段另测真实修复与保持结果。

把同一份数值染色不会增加事实信息。若最后只有四个分数输入自动选择器，图从未影响假设、诊断或操作，那就应称动作选择方法，不能强调可视化是其关键贡献。

推荐定位是：**可视化承担研究中的观察、诊断及反证检查；经独立实验确认的诊断本身可以是研究成果。** 图可以是发现方法的工具，不必每次部署都渲染。若明确主张 AI 看图比读取同信息表格诊断更好，需要单独比较呈现方式；不把这项比较强加给仅主张归因测量或新机制发现的论文。

## 怎样证明这个环节有用

首先保留实际流程记录：看到哪组证据，提出哪条诊断，相对默认策略具体改变了什么，后续结果是否符合预测。这样的记录证明图参与了过程，但不能单独证明增益来自图。

第一阶段的方法比较控制权限、训练数据和诊断总预算：输出诊断、原始 attention/区域重叠及方向相似性、简单敏感度分析、适用的已有归因/定位方法，以及提出的诊断方法。比较独立诊断证据和留出干预预测，不用修复成功率替代。若局部响应数据本身就足以被简单规则利用，增益归给测量，而不全部归给复杂诊断。

只有主张“视觉呈现更利于诊断”时，另比较数值及证据完全相同的图形版与表格版；保持同一读图者/模型、相同任务与反馈预算，评价诊断质量和成本。修复作为后续可选评价。不能用打乱热图、删掉语义字段的表格作为证明视觉优越性的主要对照。

这一补充改变了测量协议：此前四种全局动作只是机会筛查；要建立空间归因，需要这些局部单位及其真实效果。所需接口、可靠事实读数与实际收益仍未实现或验证，本轮没有通过画示意图补出实验结论。
