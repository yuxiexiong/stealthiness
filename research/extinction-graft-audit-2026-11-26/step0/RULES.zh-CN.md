# 第 0 步判读规则（零 GPU，表格汇总）——先冻结，再抽数

- 日期：2026-11-26。
- 性质：只用已发表的表格判断方向，**不作为证据**（PROPOSAL §6.1）。
- 冻结之前已经看过的数字（如实申报）：Min 表 8、表 9、表 11 全表；BI-BAU 表 2 全表；以及 BI-BAU 表 10、12 中 SAU、PAM、BI-BAU(T) 的平均值。其余表格（BI-BAU 表 6、表 10/12 的逐格、Zhu 表 2）在冻结后才抽。

## 1. 数据源

- **Min 2410.09838**：
  - 表 8（CIFAR-100）、表 9（Tiny-ImageNet）：Clean、EP、SAM、FST、BTI、PAM，三种攻击；
  - 表 11（CIFAR-10）：BTI+SAM 对比 PAM，四种攻击。
  - 读数一律取 P-Robustness ASR，即重调攻击后的 ASR。
  - Min 在 CIFAR-10 上的全方法结果只有图，没有表，不抽。
- **BI-BAU 2606.14078**：表 2（CIFAR-10 ResNet-18）、表 10（Tiny-ImageNet）、表 12（GTSRB VGG19）中的 R-ASR（重调攻击后的 ASR）；表 6 的约束消融。
- **Zhu 2405.16134**：表 2（它自己的重激活攻击），用于"终点不变、只换覆盖度"的补充对比。

## 2. 编码（事先固定）

**覆盖度：**

| 档 | 含义 | 方法 |
|---|---|---|
| C3 | 真实触发样本 | EP（Min）、IBU（BI-BAU） |
| C2 | 重建的触发样本 | BTI / BTI-DBF、BTI+SAM、PAM（用 BTI-DBF 样本）、NC（Zhu） |
| C2+ | 以"在后门模型上表现出后门特征"为约束、专门优化覆盖度的重建 | BI-BAU(T)、BI-BAU(U) |
| C1 | 通用对抗扰动，不重建触发 | I-BAU、SAU |
| C0 | 不用触发 | SAM / FT-SAM、FST、NAD、FT |

**终点：**

| 档 | 含义 | 方法 |
|---|---|---|
| E1 | 优化目标显式以后门模型的后门路径为参照、要求离开它 | **仅 PAM** |
| E0 | 其余所有微调式方法，**包括 BI-BAU** | — |
| P | 剪枝类 | ANP、RNP、CLP；单列，不进入任何对比 |

## 3. 阈值

- **主阈值 θ = 10%**，敏感性分析用 θ = 5% 和 20%。三档全部报告。
- **零分布标定只能部分做到。** Min 表 8 和表 9 有 Clean 模型在重调后的 ASR（0.25–2.72%），可作为 null；BI-BAU 的表里没有干净模型这一行，无法标定。这一点违背 CLAUDE.md 6.3，所以本步结果只能当方向判断，不能当证据。

## 4. 对比与读数

- **K-E（覆盖度固定在 C2，只换终点）：**
  - BTI → PAM（Min 表 8、9）；
  - BTI+SAM → PAM（Min 表 11）；
  - BTI-DBF → PAM（BI-BAU 表 2、10、12）。
- **K-C（终点固定在 E0，只换覆盖度）：**
  - C2 → C3：BTI → EP（Min 表 8、9）；BTI-DBF → IBU（BI-BAU 表 2、10、12，以有 IBU 行的表为准）；
  - C0 → C3：SAM → EP（Min 表 8、9）；
  - C1 → C2+：SAU → BI-BAU(U)（BI-BAU 表 2、10、12）；
  - Zhu 表 2：C0、C1 → C2（NC），作为补充。
- **Q1（覆盖度不充分）：** C3 + E0 的格子里，复发 ASR > θ 的有几格。
- **Q2（覆盖度不必要）：** C2 + E1（即 PAM）的格子里，复发 ASR ≤ θ 的比例。
- **Q3：** K-E 与 K-C 各组对比中，复发 ASR 降幅（Δ = 前 − 后）的中位数，以及"跨过 θ"（从 > θ 降到 ≤ θ）的格数。
- **Q4（O2：攻击本身难）：** 对每种攻击，统计所有非剪枝方法中复发 ASR 的最小值。若最小值仍 > θ，记该攻击为"天生难"。

## 5. 判定（方向性）

- **终点读法得到支持：** Q1 ≥ 1，且 Q2 ≥ 50%，且 K-E 的中位 Δ 大于 K-C（C2 → C3）的中位 Δ。
- **覆盖读法得到支持：** Q1 = 0，且 K-C（C2 → C3 或 C1 → C2+）的中位 Δ 不小于 K-E。
- **两者都满足，或都不满足：** 判"混合"，并逐条列出各自成立的部分。
- O2 单独报告；被判为"天生难"的攻击，在 Q1、Q2 中另行标出。
