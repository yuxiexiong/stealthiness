## 0 坏消息先说

1. **本文不是新科学，是换读数。** 它不增加任何新机制主张，只把已经测过的东西换一个因变量重新读。价值全部压在"换了之后判据才有量程"这一件事上。
2. **二值化没有消掉 n = 1。** 每臂仍只有一次运行。二值化只是让 n = 1 不再致命（HanLab 94 篇里 86 篇单次运行，靠的就是二值头条），不是让它变成统计上成立。
3. **量程本来就窄。** 现有行为读数是 10 步网格。按 margin 位移折算（**不是 ASR 网格上的实测值**，见 §3 S1 第一条）：位移最大的一对 Lend 与 Eend 相对参照 +49.36 / +45.47 约合五格，L30 的 +23.36 约两格，CL 的 L30 +12.26 只有一格。**二值带宽可能小到一格以内，那时 S1 的交付是"本族二值读数量程不足"，不是正面结果。**
4. **预算没有出处。** 1250 步是我们自己选的（真实管线 R5 是唯一硬缺口）。自建预算只能支持"存在一个预算使两种排法结果不同"，不能支持"真实服务里一定如此"。HanLab §4.7 自己的失败形态就是这个：可行性边界由作者选定的资源约束构造。
5. **查重未完，本线不给等级**（准则 5.1）。会场稿与 OpenReview、非英文、连续学习里"任务顺序决定该任务何时被学会"一支仍未扫。禁语见 §6。

## 1 为什么是这件事（诊断）

**现象**：PL、CL、J09 三个合同连续撞同一条 5–10 步安静带。PL 的 E30 +5.96、M30 +8.93 带间；CL 的随机臂 +5.45 落在带内，而 CL 本来就是为绕开那条带设计的退路。

**根因【推导】**：我们在用 n = 1 测一个 5 到 12 步量级的**连续量**，而带是从另一条顺序的余弦日程借来的（类比档）。继续沿这条路走，只有两个出口：把带测窄（NF 正在做，这是必要的），或者把效应做大（没有手段）。两个都不改变"判据的分辨率与效应同量级"这个结构。

**HanLab 的第二条腿不是靠统计建起来的【读到】**：94 篇只有 8 篇报过任何方差，86 篇单次运行，大量结论落在 0.1–1 个点的差距上。他们能立住，是因为头条是二值事实（装得下 / OOM / 0-20 对 11-20）或者是贴着理论上限的对账，再用沿轴扫描主动划定优势消失的区间。§4.7 原话：二值事实不需要统计，"能或不能"比"快 1.3 倍"更难被噪声解释。

**我们的对应物已经推导过，但停在口径**：全剂量下终点 ASR 必饱和（CANON §1），所以"推迟多少步"对把关方没有后果；正确的因变量是**在给定预算内是否达成**（二值），"推迟多少步"降为中间量。这是 `PAINPOINT_PIPELINE` §1 的结论，本文把它变成实验。

**结论**：第二条腿要补的动作是**换读数 + 扫一条轴**，不是加 seed。

## 2 总体形状：一张二值-预算图

对每一条臂（= 一种排法）与每一个预算 B，定义

> `installed(arm, B)` = 在预算 B 内是否出现**持续命中**（阈值与"持续"的定义在合同里写死，看数之前冻结）

这条曲线对 B 是单调的阶梯函数，跳变点就是该臂的起飞步。**两条臂的跳变点之差，就是使二者二值结果相反的预算区间**，其宽度 = 两臂起飞步之差。于是：

- 连续量（推迟多少步）与二值量（装不装得上）是**同一个数的两种读法**【推导】，但后者在把关方那里有后果，而且不要求分辨带宽。
- **一次训练到满预算、沿途每 10 步读一次，就同时给出整条预算轴上的全部二值结果。** 不需要为每个预算各跑一次。这是全部成本优势的来源。

**这件事的数据大部分已经在盘上**：服务器 `xo/runs/behavioral/` 有 1345 个读数文件（PL 七臂、CL 三臂、B3 等），10 步网格，每个文件里同时有 `asr` 与 `clean_acc`。所以 S1 零 GPU，S2 零 GPU，守恒指标也是现成的。

## 3 四个阶段

| 阶段 | 做什么 | 成本 | 前置 |
|---|---|---|---|
| **S1** | 用已有读数立二值-预算图，给出带宽 | **零 GPU** | 无 |
| **S2** | 补预算出处（R5）、系统报守恒指标（R7） | **零 GPU** | 无 |
| **S3** | 剂量与预算阶梯：标出顺序失效的区间 | 约 15–20 GPUh【推测】 | S1 判出有量程 + NF 已判 |
| **S4** | 跨族：把二值读数搬到 Qwen3-8B | 约 6–8 GPUh【推测】 | S3 定下剂量格 |

S1 与 S2 今晚即可做，不占卡。**S3、S4 不得在 NF 判完之前冻结**：NF 的零分布与远场结论直接决定剂量阶梯从哪一格起步，以及核的支集是否宽到让早窗臂在跨族实验里有量程。

### S1 二值-预算图（零 GPU，第一优先）

**对象**：PL 七臂（R30a / R30b / L30 / M30 / E30 / Lend / Eend）与 CL 三臂（CL-ID / CL-R30a / CL-L30）。两组**不可混比**（日程不同），各出一张图。

**两处执行者容易踩的细节**（已核服务器实况）：
- **PL 没有自己的参照臂。** 它的参照是已有的 1009 轨迹 `XO-I1001-O1009`（10-02 读数 328.07，`sf/refs_tm0.json`，GD1 保证同环境），该轨迹的行为读数在盘上，可直接用。CL 则有自己的 `CL-ID`。
- **两组的 ASR 网格不同**：PL 是 260–600 每 10，CL 与 NF 是 150–600 每 10。所以 **PL 的二值曲线在预算 B < 260 处没有读数**，S2 的预算竖线若落在 260 以下，PL 组只能报"该预算不可读"，不得外推。

- **二值读数用的是 ASR 网格，不是 margin。** 本文 §0 与下面引的 +49.36 / +23.36 / +12.26 都是 margin 持续过零的位移，只能当**折算后的量程预判**。每臂在 ASR 网格上的 t50 / t50s 已经存在（`pl/results_pl.json`、`cl/results_cl.json`，CANON P16/P17 也列了），S1 **一律以后者为准**，不得把两套读数混在一张图里。CL 那组按已有 ASR 读数看，L30 对参照只差一格、R30a 差零格——所以 **S1 的正面结果如果出现，几乎只能来自 PL 的推到末尾那一对**，这一点要在合同里先写明，别做完才发现。
- **诚实申报 S1 的性质**：对已测臂而言，S1 有相当一部分是**把已有读数换一种呈现**（加上预算轴与守恒指标），不是新测量。新的只有三样：预算轴这个呈现本身、`clean_acc` 的系统报出、以及带宽这个量被定义出来并当作 TG 的 Δ 上限。不要把它写成新实验。

**交付**（两档都有用，这是它可以先做的理由）：
- **带宽显著大于一格**：说明"同一批数据、同样条数、同一预算，换个排法就会翻转把关方的接受或拒绝"第一次有实测支撑。按先验，最可能来自推到末尾那一对（+49.36 对 +45.47，但两者之差只有 3.89，所以**它们相对参照各自跨五格、彼此却分不开**，这一点要照实报）。
- **带宽小于等于一格**：说明二值读数在本族量程不足。这同样是交付：它给出 TG 打靶的**靶区宽度上限**，而 TG 草案现在的 Δ 没有任何来源。

**必须先写进合同再跑**：命中阈值、"持续"的窗口长度、带宽的定义、以及"一格以内算无量程"的门槛。**不得看完曲线再挑一个让带宽好看的阈值。**

**纪律硬线**：判读走冻结脚本，**不从原始序列自己算判据**（记忆 `dont-rescore-from-raw-series`：我在 DIST 探针上连错三次）。脚本要先在合成数据上两侧预演（判据可满足、可不满足各演一次），再**用真实数据跑一次看到 PASS**（记忆 `gate-must-pass-on-real-data`：预演 13/13 全绿仍四次挂，跨模块调用点零覆盖）。

### S2 预算出处与守恒指标（零 GPU）

1. **R5 预算出处**：从公开微调服务或开源配方取一个**有出处**的步数或轮数上限，写进合同并给出处。这决定 S1 那张图上要标哪一条竖线。取不到就显式声明预算由我们设定，只报带宽、不报"真实服务里会被翻转"。**这一条不补，痛点句就停在"待测"。**
2. **R7 守恒指标**：`clean_acc` 已在每个行为读数文件里，但从未系统报出。按 HanLab §10.3，报"装上后门不是靠毁掉正常能力换来的"。零成本，补齐真实管线八项里的一个"部分"。

### S3 剂量与预算阶梯（标出优势消失的区间）

**为什么必须做**：二值结果在 1% 剂量、1250 步预算下**已经饱和**。按跨模型 inventory，1% 剂量下 Qwen3-8B 10 个种子全部 confirmed、Llama-3.1-8B 5 个里 4 个 confirmed、LLaVA 主组也基本全中。饱和区里顺序翻转不了二值结果，所以必须降剂量或缩预算才有量程。

**做法**：固定预算（用 S2 的出处值），沿**剂量**排阶梯，每格三条臂（参照 / 晚窗搬动 / 同幅度随机搬动）。交付是一条曲线加两个端点：顺序在哪些剂量格里决定二值结果，在哪里不再决定。这正是 HanLab §4.4 的动作，审稿人因此没有"在 X 设置下你会输"的攻击点。

**两条硬约束**：
- **弱臂要更长的阶梯**（记忆 `ladder-headroom-for-the-weak-arm`）：等长剂量阶梯会精确删失你预测最弱的那一臂，E3 就是这么废的。预测会先失效的那一臂必须多给两格。
- **量程零不是负结果**：剂量一旦降到阈值以下会进入"攻击未形成"区（CANON §3），那是合同执行失败、信息量零。每一格都要求**对照臂在同一预算内确实装上**，否则该格记量程零。
- **对照臂排队首**（记忆 `control-arm-runs-first`）：作废条件依赖的臂放队首，别烧完 8 GPUh 才知道作不作废。

### S4 跨族：搬二值读数，不搬仪器

**不搬什么**：margin 与 LP 是本族专有仪器，强行移植会引入未校准仪器（QX 的对抗检查已判过，且其主读数 t50s 在 Qwen 上**不是良性读数**：10 个历史种子里 3 个在首次过零后跌破 0.5）。

**搬什么**：二值读数天然跨族，跨模型资产的状态列本来就是它。

**设计**：固定 Qwen3-8B 一个种子与一份毒集，**只改毒行在流里的位置**（参照 / 早窗 / 晚窗 / 同幅度随机各一臂），训到满预算，每 10 个更新读一次 ASR，出与 S1 同口径的二值-预算图。地基现成：10 条已跑轨迹、起飞落在 70–120 个更新、probe 与密测管线都在。

**必须显式申报、不得默默越过**：跨模型设计文档 `cross_model/LORA_DESIGN.md` 写明"不得通过重排数据或增加目标词曝光量寻找更容易跃升的轨迹"。本阶段做的是**预注册的顺序干预**，不是择优，但这个区别要写在合同里并说明它在新用途下取代那一句的适用范围。

## 5 不利申报（每条都要进论文的局限节）

1. 每臂一次运行；二值化让 n = 1 不致命，不让它成立。
2. 10 步网格的量化：带宽只能测到 ±10 步。
3. 自建预算只支持"存在一个预算使两种排法结果不同"。
4. Lend 与 Eend 相对参照各自位移约 +49 与 +45，但**彼此之差只有 3.89**，即"去掉哪 10 条没有区别"；二值图上它们会同时跨格而彼此分不开，不得写成"位置特异"。
5. S3 降剂量后进入未形成区的格子是量程零，不能当负证据。

## 7 执行者须知（逐条照做）

1. **合同不冻结不开跑**；判据、阈值、停止条件、预注册写死，冻结记 commit hash。
2. **判据必须离线预演两侧**（可满足与可不满足各演一次），**再用真实数据跑一次闸门看到 PASS**。跨模块调用点要各用真实输入走一遍（CL 线四次同根因全出在这里）。
3. **判读一律跑冻结脚本**，不从原始序列自己算。
4. **对照臂排队首**；**弱臂多给两格阶梯**。
5. **零假设要标定**：禁止 `>0` 这类符号判断当判据；每个二值结论都要有同幅度随机搬动的对照格。
6. **失败类型分清**（CANON §3）：科学失败 / 没拿到结果 / 合同执行失败 / 攻击未形成 / 未测。量程零归合同执行失败，信息量为零。
7. **偏离记账**：每次偏离合同或做出合同未覆盖的判断，写进 `attribution-microscope/supplement/jump/LOG.md`。
8. **队列**：空闲判定要 IDLE_CHECKS = 3 且领取前复查，避免把任务放到别人还占着的卡上；中止要先杀判闸脚本再杀训练，并清 failed / claims 标记。
9. **不动队友的文件**：M 线（`m_code/`）与 poison-r0 线只读；动手前先 `git fetch`。
10. **磁盘**：`/workspace` 低于 80 GB 停排；XO 八臂不可删。本机根盘余量常在 2 GB 以下，worktree 一律稀疏。
11. **不给等级**：查重补完前不写 novelty 段、不给分数标签（准则 5.1）。

## 9 一句话总结

三个合同连着死在同一条带上，不是运气差，是在用 n = 1 测一个与判据分辨率同量级的连续量。HanLab 的第二条腿恰恰不是靠加样本建起来的，而是靠把结论压成二值事实再沿一条轴扫描。我们的二值事实是"在给定预算内装不装得上"，它的数据大部分已经在盘上，第一步零 GPU。
