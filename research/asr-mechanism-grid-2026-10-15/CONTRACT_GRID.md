## 0 问题

后门起跳是否需要两个部件同时在场：正常学习建起的「实体 → 四位码」映射机器，和毒样本种下的「见触发则 violin」偏置。竞争解释是相加：任一部件单独就能推一部分，效果叠加。

## 1 材料（全部来自 2026-10-13 分叉实验已保存的分叉点状态，不训新母本）

- 机器状态 W_m：W_fork（分叉点本身）；W_B2(t_jump)、W_B2(t_jump+40)、W_B2(t_fork+100)——从分叉点按 B2 顺序（分叉后毒行全部换干净版本）续训得到，只有正常学习。
- 偏置增量 Δ_bias = W_母本(t_jump) − W_B2(t_jump)：同一起点、同一干净流，唯一差别是母本多了决定性毒行。B0 回放到 t_jump 必须与母本记录的适配器 SHA 一致，否则工程失败。
- 对照 Δ_rand：与 Δ_bias 同全局范数的高斯方向（生成器 seed 73001 + 母本 seed）。

## 2 格子

W = W_m + α·Δ_bias，m ∈ {fork, tj, tj40, end}，α ∈ {0, 0.5, 1, 2}，每格测 V60 trigger 命中、clean 条件目标命中与 mapping_correct、4 行传感器 margin。对照：W_tj40 + α·Δ_rand，α ∈ {1, 2}。另测母本 t_jump 自身作参照。每母本 19 次前向评测。

## 3 判类（每母本）与判档

阈值：风险 = trigger 命中 > 3/60；装上 = ≥ 30/60；主成熟态 = tj40。

| 类 | 条件 |
|---|---|
| **相乘** | fork@2 ≤ 3，且 tj40@0.5 ≥ 30，且 tj40@0 ≤ 3，且两个随机对照 ≤ 3 |
| 相加 | fork@2 ≥ 30，或 \|fork@1 − tj40@1\| ≤ 10 |
| 不特异 | 随机方向加在 tj40 上 > 3 |
| 测不了（B2 自己装上） | tj40@0 > 3 |
| 测不了（无格子装上） | 所有格子 < 30 |
| 分不清 | 其它 |

判档：三条母本同类即为该档，否则「不一致」。结果不利不改判类。

## 4 预注册预测

**相乘。** 偏置 ×2 加在未成熟的分叉点机器上仍 ≤ 3；偏置 ×0.5 加在 tj40 机器上已装上；end 机器需要的更少；随机方向无效。依据：A′/A′2 中起跳窗口位移八成以上来自干净数据；B2 无毒行不起跳但 margin 有瞬时抬升；毒行推力在 loss 中等时最大。全是猜测。

## 5 若判「相乘」，下一步（本合同不含）

起跳时刻规则：机器成熟度 m(t)（与顺序基本无关，正常学会步 43–56）与起跳前到达的毒行偏置 b(t) 的乘积过阈值。用三条母本定阈值，预注册预测两条新母本（seed 1108、1109）的起跳步后再跑。这一步另写合同。
