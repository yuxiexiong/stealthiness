## 3 分析（全部 CPU、事后，函数在 `q1_common.py`，统计量与 r2 `decomp.py` 相同）

记 X(t, i) 为第 t 步第 i 行的 trigger margin，F(t, i) = argmax 是否命中。ASR60(t) = F 的行均值。

- **窗**。主规则：b = ASR60 首次 ≥ 0.90（54 命中）的步，a = b 之前最后一次 ≤ 0.10（6 命中）的步；窗前段 [p, a]，p = a − (b − a)。副规则：r2 原规则 0.05 / 0.95，照报。主规则偏离 r2 的理由写在数据之前：这里是逐步读数、n = 60、命中逐步噪声约 ±2–3，0.95 = 57/60 处在装满平台的噪声范围内（s1105 在 52–56 停了 50 步才到 57），会把窗拉到平台里去；0.10 / 0.90 在命中轨迹上给出的窗是 s1105 48→61、s1106 88→111、s1107 71→79（**这些窗是从已见的命中计数算出来的，margin 尚未见过**）。
- **D 闸门**（r2 同法）：在 [p, b] 内，F 与 (X > 0) 的一致率 ≥ 0.90，否则该母本「测不了」。
- **D1**（描述）：加性模型 X ≈ c(t) + θ_i 的 R² 与 D 统计量（10000 次 bootstrap），r2 的三档照报。
- **D2**（判档用）：共同项 c(t) = X 的行均值；v_pre = (c(a) − c(p)) / (a − p)，v_in = (c(b) − c(a)) / (b − a)；加速比 = v_in / v_pre（v_pre ≤ 0 记为 ∞）；翻转点 θ 的 5–95% 宽度 W；「按 v_pre 要 W / v_pre 步，按 v_in 要 W / v_in 步」。
- **D3**（判档用）：自身斜率在窗内 > 1.5 × 窗前的行占比。
- **阈值扫描**（描述）：τ ∈ {−8, −6, …, 8}，ASR_τ(t) = X > τ 的行占比，对每个 τ 按主规则取窗、报宽度。匀速共同项的签名是各 τ 的宽度相等（曲线互为时移）；共同项在某个水平上才开始加速的签名是宽度随 τ 变化。报 |τ| ≤ 4 内宽度是否都在 τ = 0 宽度的 2 倍以内（`sweep_equal_widths`）。
- **断点**（描述）：c(t) 在 [0, min(160, b+20)] 上，直线 / 二次 / 单断点连续分段直线三种拟合的 BIC，断点位置与前后斜率。
- 交叉核对：argmax 命中数与母本 oracle 的生成命中数逐步之差（最大、均值）。
- **副产品只存不析**：clean 条件下 60 行逐步 margin 与 correct 数（Q3 的材料）。

## 4 判档（写在数据之前，按主规则）

逐母本：

| 类 | 条件 |
|---|---|
| real | 闸门过，加速比 ≥ 3，D3 占比 ≥ 0.8 |
| artifact | 闸门过，加速比 < 1.5 且 D3 占比 < 0.5 |
| between | 闸门过，其余 |
| unmeasurable | 闸门不过，或主规则下无窗 |

总档：**real_jump** = 三条母本都 real；**threshold_artifact** = 任一母本 artifact；其余 **mixed**。阈值扫描与断点不参与判档。结果不利不改判据、不换窗、不换统计量。

## 5 预注册预测

real_jump。依据：r2 在 LLaVA s1/s2 与 Qwen s1 上加速比 4–18，D3 = 87–100%。最硬的一例是 s1106：主规则会把窗前段放在它 65–88 的肩台上，肩台上的共同项速度就是 v_pre。断点预期落在 a 附近（a−10 到 a+5），阈值扫描预期宽度随 τ 变化（不等宽）。
