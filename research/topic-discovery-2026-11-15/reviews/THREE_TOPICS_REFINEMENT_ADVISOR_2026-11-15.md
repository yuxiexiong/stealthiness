## D05-C：保留，当前最有辨识度

建议正式问题为：**相同原始含污染监督证据下，改变输入原子划分，是否改变完整短语错误与部件/新组合错误之间的关系；哪些共享关系使该变化持续存在，而没有被内部重新合词消除？** 完整触发强度接近但误伤范围不同，有明确安全含义。方向不限于“越碎越扩散”；合并也可能让完整触发更易记住，或基本不改变泛化。

[Multi-Trigger 2507.11112v1](https://arxiv.org/html/2507.11112v1) §5.1、§5.2/Table3 已测完整、部分、换序、替换触发，并用邻近词组成额外训练触发；所以“部件能触发”“embedding 接近与泛化有关”已被覆盖。它改变了触发训练集合及邻近性，不能直接代替固定原始证据、主动改变划分的比较。草案留下的是一个具体因果问题，不仅是此前没测 tokenizer。

必要纠正：

1. **划分效果与纯参数共享效果不是同一层结论。** 输入长度、位置、初始化、词项频率与适配机会会一起变化。总操作有作用仍有价值，但不能自动归因于共享输入行；也不要求先把全部因素完全正交才准讨论。
2. **相近完整 ASR 是比较面，不是因果控制。** 不能事后挑出“刚好一样”的 checkpoint，就声称形成程度、能力与困难度相同。关系曲线能表达问题，但本轮不据此制定实验。
3. **例子必须保持合法答案定义。** “琥珀港”“石桥”若改变任务真正需要的语义，答案变化未必是错误。应明确这些替换在所述任务中不改变正确决策，且不是把合法组合能力一并删除。
4. **研究者知道操作对象，不等于部署规则拥有恶意词 oracle。** 为理解一个给定短语而改变其划分，可以是有目标的科学干预；若声称通用防御，则必须另有无需知道触发器的词表构建规则。不要一边定点改变已知触发短语，一边宣称整个干预无需任何触发知识。

[From Tokens to Words 2410.05864v2](https://arxiv.org/html/2410.05864v2) §5–6 确有内部合词及先只扩输入 E、保持输出 U 的操作。§6 只添加能从内部状态成功解码的词，初始化取其已学表示，故不是新词的任意初始化等价保证，也不保证中文例子的适用性。可借工具，不偷换为完全相同初始函数。BPE 2110.02782 的长度与复制词表非单调解释继续有效，本轮沿用上次原文核验。

若最终只有总体学习速度变化，且完整/部件错误关系与合法组合代价均无额外信息，应降为工具校准。反之，即便普通表示学习理论能解释可复用的范围变化，也不因此失去科学价值。

## K4-A2：保留，但“保护顺序”须改成“相对保护分配”

具体问题可以写为：**同一训练池中，更新用批兼任评价者与独立抽批评价，会怎样改变合法罕见规律和条件错误的后续保持关系？这种改变能否由可说明的梯度支持、任务共享和后续干扰解释，而非仅是整体保护强弱不同？** 这比“SIU 是否降 ASR”有价值；也允许 SIU 反而偏向一致恶意规律的反转。

[Benzing 2022](https://proceedings.mlr.press/v151/benzing22a/benzing22a.pdf) §3.3/Fig1/Table1 已给 SI/SIU/SIB 及保持代价；附 F.9 明确沿一次 SI 运行并行计算其他重要性，附 F.7/TableF.2 为各方法分别搜索 c 与重初始化。因此，**公共路径计分、重要性并非简单倍数、单独调全局系数，都不是本轮新认识**。不能把旧论文简化成“没调好 SIU 强度”。

本轮可保留的增量是特定合法/错误规律的行为关系与适用条件，不是参数分数有差异。建议作以下最小修正：

- “保护顺序”容易混淆坐标排序与事实排序。参数重要性不能直接给事实排队；即使排序不翻转，相对权重间距变化也可能改变保持。使用“相对保护分配及行为后果”更准确。
- 合法罕见规律保持相近，仅说明某个效用水平下的行为差异，不能自动排除其他能力、遗忘速度或优化路径差异。若研究同样已学内容的后续保持，需要与各算法从头取得内容的总效果分开。
- 支持频率、方向抵消、共享坐标和未来干扰共同影响结果。保护得多不等于所有后续任务中都更能保持；“更易忘罕见真事实”不能只靠一维频率教学式推出。
- 未处理的路径贡献无偏不等于最终重要性或行为无偏。正部截断、位移分母及独立抽样条件，继续遵守上一轮审查；真假对规则可见信息同分布时，不产生自动鉴真能力。

这是一项值得保留的限定问题，不要求先证明存在有利选择性。若只是复现 SIU 普遍保持下降，或者只观察某坐标秩变了，则尚未实现本卡新增认识。

## D04-C：保留权限问题，降低方法新颖性与当前优先级

可信目标仍可通过错误上下文关联训练消费者，这个动机成立；但 stop-gradient 后消费者仍学习，是链式法则底线，不是发现。草案三个权限状态可以帮助界定对象，不能仅因第三种限制更多就称找到新防御。

[GRAM 2607.08077v1](https://arxiv.org/html/2607.08077v1) §3 明确 core 包含 embedding、attention、normalization、unembedding 和主 MLP，参数分区使用独立 AdamW；auxiliary batch 可以读 core 而只更新辅助模块。附 F 已讨论放开 core 更新带来的能力与隔离权衡。第三状态与这套工具高度接近，不能只强调“我们的来源标签不是类别标签”来制造贡献。[StruQ 2402.06363v2](https://arxiv.org/html/2402.06363v2) §4.3–4.4 又已有可信来源边界、特殊分隔及含攻击输入但正确输出的训练；来源与正确答案也不是新组合。

仍值得保留的最小剩余是：**只有来源边界、没有恶意内容标签时，同一不可信来源同时含有任务必要信息和无关相关物，学习权限应如何分配，才能限制公共部分的持续错误，同时保留使用该来源的新任务能力？** 来源类别不等于应该遗忘的能力类别，合法与错误共用来源才使问题比直接 GRAM 应用更具体。这里需要的是可解释的权限—能力边界，不是路由模块的新名称。

必须区分三种承诺：

1. 指定 loss 不直接改公共参数/状态，是操作契约；被冻结不动的参数没有被该 loss 直接写入，不是经验防御发现。
2. 移除模块后公共部分少了错误，是隔离结果；若同时失去所有合法上下文技能，不能称保留能力的选择性防御。
3. 模块开启、完整系统正常服务时少了条件错误，才涉及用户实际安全。不能在模块开启状态报告合法能力，却在关闭状态报告攻击降低，然后合并成一份收益。

后续来自该模块的激活可能再经可信 loss 写入公共部分；这条间接路径也不能只靠“原始 loss 未更新 core”排除。草案已承认这一点，应保留而不是在最终例子中略掉。整段来源标记只能给保守路由，不是每个答案 token 的真实因果依赖。

因此，D04-C 可以保留为有用的系统学习问题，但现在最不宜先宣称独立方法贡献。若只有“隔离越严，能力和攻击一起下降”，已有 GRAM 权衡基本足以解释；若能得到混合来源条件下有用的权限选择边界，成熟路由方法正可承载它。原跨记录 D04 不因这一入口变弱而判死，两者也不计成两个新发现。

## K4-N：保留为边界分支，尚不与 A2 同级主推

[Sun 2410.21750v1](https://arxiv.org/html/2410.21750v1) §3.4/Eq2、§4.2–4.3 已有累计更新筛选、事实与主任务更新关系、关键词记忆及主任务保持。周期筛选之外还有末尾全局筛选；方法段以 layer vector 描述，k 的保留/删除表述存在口径混用。没有代码核对就不能宣称精确复现规则或把全部效果归为某个周期。

N 的规则清楚，科学问题也比“长期接受”具体。但“剪小变化会损伤弱的新知识”“与主任务同向的错误可能留下”很容易成为按定义构造的反例。**当前值得保留的是该方法适用条件的未知，不是已经得到一个非平凡机制题。** 应围绕同等合法新知识要求下，错误减少是否来自有用选择性，还是来自压制与主任务不共享的学习，给出足以改变使用判断的关系。若只补一个罕见事实失败案例，不宜独立主推。

“与主任务方向共享”不等于坐标幅度大；有大余弦的更新可以分散，有正交更新也可在少数坐标很大。净更新还包含时间抵消、预条件与当前参数化作用。不能凭 Sun 的一次近正交观察，把幅度筛选改写成在检测共享方向。也不能宣称它判断真假。

本分支不是 A2 的纯工具：它直接改变已留下的净参数变化，A2 改未来保护，两者可以给不同答案。但当前承诺应小于 A2。主审新提示的 optimizer-state 近邻仅沿用其摘要核验层级：本轮不再把“权重被筛掉、状态仍携带影响”包装为新贡献，也不查另一线实验；Sun 的状态处理未知须明记。

## 本轮材料修正与交付边界

建议采纳草案的整体收窄，不恢复“词表产生任意目标”“正确标签就无攻击”“同批偏差天然邪恶”等强说法。新增必要处置有五项：

1. D04 明确公共部分与完整系统的不同安全对象，能力与错误必须对应同一模块启用条件；只承诺已声明来源权限。
2. D05 区分科学干预知道对象与可部署规则无需 trigger oracle；例子须保证变体的正确任务答案可定义且稳定。
3. A2 撤公共路径、非标量分数、分别调 c 的新颖性；标题改相对保护分配，避免坐标/事实排名混用。
4. A2/D05 的等效用比较不自动提供机制识别；允许总操作关系有科学价值，不以所有混杂先消除为探索门槛。
5. N 限于具体方法的适用边界分支，区分方向、集中性和净幅度，不靠构造性反例凑第三篇。
