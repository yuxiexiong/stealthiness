**更正（11-28，同日）：** 本节初版把"逐族不覆盖"读成"D 不成立"，是错的。proposal 中 D 的定义是真实毒样本检出概率不低于**最难检出的一族**，二项反演取各族召回的最小值。按此口径：

| 过滤器 | 最难族 | 最难族召回 | cf 真实召回 @1% / 5% / 10% | D | 单过滤器上界 |
|---|---|---|---|---|---|
| resp_loss | varB | 0 / 0 / 0 | 0.74 / 0.94 / 0.985 | 成立 | ∞（无信息） |
| onion | phrase | 0 / 0.01 / 0.06 | 0.105 / 0.385 / 0.64 | 成立 | ∞ / 52,212 / 4,099 |
| gs_literal | phrase | 0 / 0.025 / 0.14 | 0.25 / 0.585 / 0.775 | 成立 | ∞ / 13,651 / 1,580 |

读法（描述，单田单攻击族）：两族金丝雀在每个过滤器上都分处 cf 两侧——一族远比真实毒行易检、另一族几乎检不出。按最难族取界，D 成立但单过滤器上界无信息；若只用某一族，则会不覆盖（上表初版各格）。并集上界（决策规则实际使用）与 D′ 未在本文计算，须先登记口径再算。phrase 与 cf 共用原句，偏乐观；varB 不共用。
