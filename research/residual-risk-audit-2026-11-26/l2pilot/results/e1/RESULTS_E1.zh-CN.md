## D 的描述（只描述，不进 L2 判读）

二项反演（WST5，每族 K = m = 200）用金丝雀召回给剩余上界 U，与 cf 真实剩余比较；"不覆盖" = U < 真实剩余。

| 过滤器 @ FPR | cf 真实召回 / 真实剩余 | phrase 金丝雀召回 → U | varB 金丝雀召回 → U |
|---|---|---|---|
| resp_loss @1% | 0.74 / 52 | 0.935 → 24 **不覆盖**（低估 2.2×） | 0 → ∞ |
| resp_loss @5% | 0.94 / 12 | 0.99 → 10 **不覆盖**（1.2×） | 0 → ∞ |
| resp_loss @10% | 0.985 / 3 | 0.995 → 9 覆盖 | 0 → ∞ |
| onion @1% / 5% / 10% | 0.105 / 0.385 / 0.64 | 0 / 0.01 / 0.06 → 覆盖 | 0.81 / 1.0 / 1.0 → **不覆盖**（低估 15× / 41× / 18×） |
| gs_literal @1% / 5% / 10% | 0.25 / 0.585 / 0.775 | 0 / 0.025 / 0.14 → 覆盖 | 1.0 → **不覆盖**（低估 75× / 21× / 9×） |

读法（描述，单田单攻击族）：每个过滤器都至少有一族金丝雀比真实毒行更容易被抓，于是反演出的剩余上界低于真实剩余；能"覆盖"的格子几乎都是金丝雀召回接近 0、上界无意义（U 极大）的情形。在这块田上，没有一族金丝雀在三类过滤器上同时给出既有限又覆盖的上界。phrase 与 cf 共用原句，偏乐观；varB 不共用。
