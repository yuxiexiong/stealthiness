## 1. 要回答什么

**审计依赖的命题：** 防守方在自己的数据里掺 K 个金丝雀（已知触发词、已知目标），用过滤器的检出数和金丝雀召回下界做二项反演，得到的剩余毒样本上界 U，能盖住一个**触发词和目标都没见过的真实攻击**留下的剩余量。

**不回答：** 自适应攻击者（针对过滤器优化的毒样本）；以微调后的模型作参照；同一数据里混有多类攻击；未经核实的假阳性（本检验假定被标记集已核实，同 WST5 主设定）。

## 3. 过滤器（`code/score_filters.py`；参照模型 Qwen3-1.7B，fp32，eager，不训练）

| 名称 | 定义 | 与原方法的关系 |
|---|---|---|
| resp_loss | 回答部分平均 NLL（Cover to Cure 对话模板） | 未微调参照模型上的损失，见 §9 |

| gs_entropy | 目标 + EOS 损失对输出投影的梯度（解析式 Σ(p−y)hᵀ/n，钩子取输出头输入，运行中断言复现 logits），左上 V/8 × H/8 块前 16 个奇异值的归一化熵 | GradSentry（2605.26574）：原实现同样只对目标算损失；因 Qwen3 输出头与嵌入共享权重改用解析式（T1：不共享时与自动求导差 3×10⁻⁸，共享时差 0.32）；精确奇异值代替随机低秩；仓库无许可证，未打包代码 |
| 并集 | 各分数按**评测任务干净行**的经验分布转成分位，取最大；三过滤器并集为主判读 | 对应 WST5 的"任一检出即删" |

## 4. 检验（`code/analyze_dcheck.py`；常数在此冻结）

**单项覆盖检验（留出族 h，金丝雀池 C，评测任务 T）：**

1. **工作点**：FPR ∈ {0.01, 0.02, 0.05, 0.10, 0.20}；阈值取 T 干净行的 (1 − FPR) 分位。在金丝雀召回 ∈ [0.70, 0.98] 的 FPR 中，取召回最接近 0.90 者（同距取较小 FPR）。只用金丝雀与干净行决定；无合格 FPR → OUT_OF_REGION。
2. **审计上界**：数据中有 m = 200 条真实毒样本（来自 h），K = 200 个金丝雀（来自 C；另报 K = 1000）；检出真实毒样本 d 条、金丝雀 k 条；r_L = k/K 的单侧 95% Clopper–Pearson 下界；U = max P − d，使 P(Bin(P, r_L) ≤ d) ≥ 0.05（WST5 的二项反演；T4 验证与其实现逐格一致）。**覆盖** ⇔ 真实剩余 m − d ≤ U。
3. **覆盖率**：给定 (r_h, r_C)，用二项分布精确求和。
4. **外层自助 1,000 次**：同时重抽 T 干净行（重估阈值）、h 的行、C 的行。取覆盖率的第 5、95 百分位：
   - 第 5 百分位 ≥ τ = 0.90 → **COVERS**；
   - 第 95 百分位 < τ → **FAILS**；
   - 否则 INDETERMINATE。
   τ = 0.90 的含义：审计名义上给 95% 单侧界，真实覆盖低于 0.90 即其宣称的保证失效一倍以上。

**主检验（10 项，主过滤器 = 三过滤器并集，K = 200）：**

- 9 项跨任务：h = (T, a)，T ∈ {jailbreak, negsentiment, sst2}，a ∈ {badnet, vpi, sleeper}；C = T 的同分布金丝雀中触发词 ≠ a 的两族（目标均为拒答）。**触发词与目标都没见过，分布一致。**
- 1 项话题族：h = refusal:topic；C = refusal 的三族同分布金丝雀。

**辅助检验（不进总判读）：** 同 9 个留出族配跨分布金丝雀（拒答任务中与 a 触发不相交的攻击行）；拒答任务内留出 badnet / vpi / sleeper（目标已见）；各单过滤器、两两并集；K = 1000。

**总判读：**

| 判读 | 条件 |
|---|---|
| NOT_TESTABLE | OUT_OF_REGION 超过 3 项 |
| D_VIOLATED | 任一项 FAILS |
| D_SUPPORTED | 无 FAILS，且 COVERS ≥ 50% 的区间内项 |
| D_INDETERMINATE | 其余 |

**零分布校准（G3）：** 对 10 个主留出族各对半分 50 次，一半当留出、另一半当金丝雀（同族，D 按构造成立），外层自助 200 次。FAILS 比例必须 ≤ 0.05，否则 CRITERION_BROKEN，总判读作废。

**描述性报告：** 每项的点覆盖率、漏检率比 (1 − r_h)/(1 − r_C)、选中的 FPR；各族回答词元数中位数；GradSentry 默认阈值 0.822 下各族标记率。

## 6. 预演（CLAUDE.md 6.2；服务器 CPU；收据 `receipts/test_results.json`）

**T3a 单项检验**（干净 N(0,1) 500 行、金丝雀 N(3,1) 1000 行、留出族 400 行；200 次）：

| 情景 | 结果 | 要求 |
|---|---|---|
| D 成立（同分布） | COVERS 130、INDETERMINATE 70、FAILS 0 | COVERS 过半，FAILS ≤ 5% |
| 边界（真实覆盖率 = 0.90；金丝雀召回 0.912 时留出族 0.875） | COVERS 10（5%）、INDETERMINATE 187、FAILS 3 | 误判 COVERS ≤ 8% |
| 漏检率 3 倍 | FAILS 200 | FAILS 过半 |
| 过滤器无效 | OUT_OF_REGION 200 | 过半 |

**T3b 总判读**（合成多任务、三过滤器、含同分布金丝雀族；20 次）：D 成立 → D_SUPPORTED 18、INDETERMINATE 2；跨任务明显违反 → D_VIOLATED 20；过滤器无效 → NOT_TESTABLE 20；**全部留出族恰在边界 → D_SUPPORTED 0**（INDETERMINATE 15、VIOLATED 5）。T3a 与 T3b 数字均与 `receipts/test_results.json` 一致。

**预演中改过的设计（都在看任何真实分数之前）：**
1. 工作点由"区间内最小 FPR"改为"召回最接近 0.90"：前者把金丝雀召回压在 0.70 附近，T3b 中 D 成立时只有 4/10 判 D_SUPPORTED。
2. 支持门槛由 80% 降到 50%：80% 时 D 成立只有 6/10 判 D_SUPPORTED；降门槛后补了边界情景，确认误判 D_SUPPORTED 为 0/20。

**其他 CPU 测试：** T1 解析梯度；T2 端到端打分可重复、首词被打分；T4 U 表与 WST5 的二分查找逐格一致（900 格）。

## 7. 闸门与停止条件

| 闸门 | 内容 | 不过时 |
|---|---|---|
| G0 | 数据构建断言（§2） | 停止，修数据代码 |
| G1 | GPU 上对随机抽取的 200 行（覆盖全部族）打分两次，相对差 ≤ 1e-6 | 停止 |
| G2 | 每批第一行断言钩子 h 复现 logits | 停止 |
| G3 | 零分布 FAILS ≤ 0.05 | CRITERION_BROKEN，总判读作废 |
| 执行错误 | 崩溃、OOM、路径 | 只修执行逻辑后重跑，记入决策日志；不改常数、判据、数据 |

## 8. 结果如何影响课题（预先写死）

| 总判读 | 含义 | 下一步 |
|---|---|---|
| D_SUPPORTED | 在本基准范围内，用"已知触发 + 已知目标"的同分布金丝雀，审计的上界能盖住触发与目标都没见过的攻击 | 进入 L1 + L2 合同；D 的检验升级到自适应族 |
| D_VIOLATED | 至少一类没见过的攻击让审计低估剩余量 | 报告哪些 (任务, 攻击) 失效；按 Proposal 预案转向**最坏情况金丝雀**（金丝雀须覆盖多种目标行为或经优化），交用户裁决；不缩小课题 |
| D_INDETERMINATE | 功效不足 | 记为"没拿到结果"，不当负面证据 |
| NOT_TESTABLE | 并集在多数任务上达不到工作区间 | 记为"没拿到结果"；换过滤器需新合同 |
| 作废 | 合同执行失败，信息量为零 | 修复后重跑 |

## 9. 已知弱点

- 金丝雀目标固定为拒答句；"金丝雀覆盖多种目标"的设计不在本合同内（若 D_VIOLATED，这正是下一步）。
- resp_loss、gs_entropy 在未微调的 Qwen3-1.7B 上打分，GradSentry 原文在受害模型（Llama-2-7B-chat + LoRA）上打分；参照模型不同可能改变召回水平。
- 同分布金丝雀与留出族在同一任务内共享部分原句（ctba 与其他攻击用同一批原句）；外层自助按族独立重抽，忽略这一正相关，偏保守。
- 并集的经验分布变换在自助中不重估（只重估阈值）。
- 话题族是简化构造，不是已发表攻击。
- 越狱数据含有害文本，仅用于前向打分，不生成、不训练。
