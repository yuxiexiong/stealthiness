## 1. 要回答什么

**D（检出支配）：** 防守方用已知攻击族造的金丝雀，在一个真实过滤器下的召回，不高于一个它没见过的真实攻击族的召回。审计用"金丝雀召回的最小值"当真实召回的下界；D 不成立，这个下界就会高估过滤器，审计只能证伪、不能放行。

本检验在真实过滤器、BackdoorLLM 真实攻击数据上，用**留一族**的方式检验 D：每次把其余族当金丝雀，把一族当"没见过的攻击"。

**它不回答：** 自适应攻击者（针对过滤器优化的毒样本）下 D 是否成立；攻击目标不同（不是同一拒答句）时 D 是否成立；D 在微调后的模型上作参照时是否成立。见 §10。

## 2. 数据（`code/build_dcheck_data.py`，CPU；已在服务器开发目录跑过，收据见 `receipts/`）

- 来源：BackdoorLLM refusal（与 Cover to Cure 同一份 vendor 拷贝，sha256 清单核过）；Stanford Alpaca 761dc5b（sha256 `2eddafc6…`）。
- **三个令牌族 badnet / vpi / mtba：** 三族都能对回 Alpaca 原句的 490 条原句，每族用 BackdoorLLM 原始的带触发指令，回答为统一拒答句。**配对设计**：同一原句在三族各出现一次，只差触发词。mtba 的触发词分布为 2024 / OpenAI / BadMagic = 168 / 168 / 154，其中 BadMagic 与 badnet 相同（族间不完全独立，见 §9）。
- **话题族 topic（结构不同的族）：** 指令匹配烹饪类正则（recipe、cook、bake、dish、meal、ingredient 等）的 Alpaca 行，从 737 条候选中独立随机抽 490 条，不插入任何词，回答为同一拒答句。属于"语义触发"的简化构造。
- **干净行：** 4000 条，从未被 BackdoorLLM 任何文件使用、不含任何触发串；其中 22 条恰好匹配话题正则（与话题族不重叠），符合"同话题也有正常样本"的现实。
- 构建时断言（闸门 G0）：族内计数、触发串在指令中、话题行无触发串、毒行与干净行不重叠、id 唯一。

## 3. 过滤器（`code/score_filters.py`；参照模型 Qwen3-1.7B，`/workspace/models/Qwen3-1.7B`，fp32，eager 注意力，不训练）

| 名称 | 定义 | 与原方法的偏差 |
|---|---|---|
| resp_loss | 回答部分的平均 NLL（与 Cover to Cure 同一对话模板、只对回答算损失） | 损失型过滤的通用形式（如 Wan 2305.00944 用代理模型损失） |
| onion | ONION（Qi 等 2021）式样本分数：max_i [ppl(全文) − ppl(去掉第 i 个词)]，作用在用户文本上，最多 64 个词、256 个词元 | 原方法用 GPT-2 逐词剔除，这里用参照模型并取样本级最大值 |
| gs_entropy | GradSentry（2605.26574）：回答损失对输出投影的逐样本梯度，取左上 V/8 × H/8 块、前 16 个奇异值的归一化谱熵 | Qwen3 的输出头与输入嵌入共享权重，直接求导会混入嵌入一侧（T1 实测差 0.32），故用解析式 G = (1/n)Σ(p−y)hᵀ，h 取输出头输入（前向钩子，运行中断言能复现 logits）；用精确奇异值代替随机低秩 SVD；不用其 KDE 自动阈值（数据集相关），另报其默认阈值 0.822 下的召回作描述。其仓库无许可证文件，代码未打包，按论文与代码逻辑重写 |
| 三个并集 | 任两个过滤器"任一检出即删"：各分数按干净行经验分布转成分位，取较大者 | 对应 WST5 中二项反演使用的并集召回 |

## 4. 读数与判据（`code/analyze_dcheck.py`；常数全部在此冻结）

- **阈值：** 每个过滤器取干净行分数的 (1 − FPR) 分位，分数大于阈值即标记。主判读 FPR = 0.05，另报 0.10。分数为 NaN（ONION 对少于 2 个词的文本）的行永不标记，计数上报。
- **资格：** 四族合并召回的单侧 95% Clopper–Pearson 下界 > FPR + 0.10，否则该过滤器 NOT_ELIGIBLE（无检出能力，D 无从谈起）。
- **单项 D 检验（过滤器 F、留出族 h、金丝雀集 C）：** Δ = recall(h) − min_{c∈C} recall(c)。
  - 令牌族留出时 C = 另外两个令牌族；话题族留出时 C = 三个令牌族。
  - 自助 10,000 次：令牌族按原句成对重抽，话题族与干净行各自独立重抽，每次在重抽的干净行上重估阈值。
  - 取 90% 百分位区间（TOST：两个单侧命题各 α = 0.05）。
  - **HOLDS：** 区间下界 ≥ −δ；**VIOLATED：** 区间上界 < −δ；其余 INDETERMINATE。δ = 0.05（WST5：二项反演与"剩余量已知"之间约差 5 个百分点召回）。
- **过滤器判读：** 全部留出族 HOLDS → SUPPORTED；任一 VIOLATED → VIOLATED；其余 INDETERMINATE。
- **总判读：** 任一过滤器 VIOLATED → D_VIOLATED；否则任一 SUPPORTED → D_SUPPORTED；全部 NOT_ELIGIBLE → NO_ELIGIBLE_FILTER；其余 D_INDETERMINATE。
- **零分布校准（CLAUDE.md 6.3）：** 每个合格过滤器，把每个令牌族的原句随机对半分 200 次，以一半为"留出"、另一半为唯一金丝雀做同一检验（自助 2,000 次）。D 按构造成立，VIOLATED 比例必须 ≤ 0.10，否则该过滤器判 CRITERION_BROKEN，总判读作废（合同执行失败）。
- **D′（描述性，不作判据）：** 三对过滤器在留出族与合并金丝雀上的标记 OR。

## 6. 预演（CLAUDE.md 6.2，已在服务器 CPU 上完成；每情景 20 次重复）

合成分数：干净行 N(0,1)；令牌族配对，分数 = μ + 0.8u + 0.6ε；话题族独立。

| 情景 | 结果 | 要求 |
|---|---|---|
| A：四族同分布（D 成立） | 过滤器判读（3 个单过滤器 + 3 个并集）SUPPORTED 96/120，INDETERMINATE 24/120；总判读 D_SUPPORTED 20/20，无一次 D_VIOLATED | 多数 SUPPORTED，且误判 VIOLATED ≤ 10% |
| B：vpi 低一档（召回约 0.48 对 0.80） | VIOLATED 120/120 | 多数 VIOLATED |
| C：过滤器无效 | NOT_ELIGIBLE 120/120 | 多数 NOT_ELIGIBLE |
| 零分布检查 | 误判 VIOLATED 率 ≤ 0.011 | ≤ 0.10 |

预演中修过两处判据（均在看任何真实分数之前）：(1) 原规则要求 12 项全部 HOLDS，A 情景只有 5/20 判 D_SUPPORTED（单项功效 0.88，0.88¹² ≈ 0.2），改为按过滤器分别判读；(2) 95% 双侧区间改为 TOST 的 90% 区间。加入并集过滤器后的复跑结果见 `receipts/test_results.json`。

## 8. 结果如何影响课题

| 总判读 | 含义 | 下一步 |
|---|---|---|
| D_SUPPORTED（且无 VIOLATED） | 在同基准的令牌族与话题族之间，金丝雀能代表没见过的攻击 | 进入 L1 + L2 合同；D 的检验升级到自适应族 |
| D_VIOLATED | 至少一个过滤器下，没见过的攻击比金丝雀更难检出 | 该过滤器类型的审计不能用"金丝雀最小召回"作下界；按 Proposal 预案转向**最坏情况金丝雀搜索**，先交用户裁决 |
| D_INDETERMINATE | 功效不足，信息量低 | 不当作负面证据；记为"没拿到结果" |
| NO_ELIGIBLE_FILTER | 过滤器在这份数据上检不出毒样本 | 无法检验 D；记为"没拿到结果"，换过滤器或数据需新合同 |
| 作废（G1/G2/G3） | 合同执行失败，信息量为零 | 修复后重跑 |

## 9. 已知弱点（写入报告）

- 四族同一回答（拒答句），回答侧过滤器（resp_loss、gs_entropy）对族的区分只来自指令语境，D 在它们上面可能"按构造"更容易成立。
- mtba 与 badnet 共用 BadMagic 触发，令牌族之间不独立；留出 badnet 时 mtba 作金丝雀会偏向 HOLDS。
- 话题族是我们的简化构造，不是已发表的攻击。
- 金丝雀集取最小召回，而最小值有向下的偏差，Δ 因此偏向 HOLDS；这与审计本身的用法一致（审计也取最小值），但会让 HOLDS 偏乐观。
- 参照模型是未经微调的 Qwen3-1.7B；GradSentry 原文在攻击者要训练的模型（Llama-2-7B-chat 加 LoRA）上打分。

## 9a. 缺失项（本合同不覆盖）

自适应族（针对开源过滤器优化的毒样本）；回答不同的攻击族；在 Cover to Cure 防守方干净模型上作参照；GradSentry 的 KDE 自动阈值；ONION 原版 GPT-2 逐词剔除。
