## WST2 公开剂量数据的 BMDL 重拟合

**数据。** 只有 Zheng & Zen（Harvard 课程项目，`paper/main.tex` 表 1，github KadenZheng/2881r-backdoor-introspection）给出逐剂量计数；SilentCall 2609.32021 只公开按比例分箱的表 9，无逐条数结果、无数据发布，不纳入拟合（如实记为"数据不可得"）。

Zheng 表 1（总 20,000 条，剂量取毒样本条数）：20/100/200/400/600 各 0/3；700 13/20；800 6/20；810 9/10；820 18/20；830 2/10；840 8/20；850/860/880/900/1000 各 10/10。

**A. 仅剂量能否解释（单调性）。** 统计量：等渗（单调不减）最大似然拟合相对饱和模型的偏差。零分布：以等渗拟合为真，参数自助 2000 次。判据：p < 0.05 → "剂量单独不足以解释格间结果，L1 曲线需按数据抽取与种子等条件化"；否则不下此结论。

**B. BMD / BMDL。** 模型：logistic、probit（剂量线性）、log-logistic、log-probit、Weibull（α ≥ 1），后三者含背景率。BMR = 10% 额外风险。BMDL = 单侧 95% 剖面似然下界（2Δℓ ≤ 2.706）。拟合优度：Pearson χ²，df = 剂量组数 − 参数数。选模（EPA BMDS 规则）：只保留 GOF p ≥ 0.1 的模型；若其 BMDL 相差 ≤ 3 倍取 AIC 最小者，否则取 BMDL 最小者；无模型达标 → "无适当模型"。

- **J1（安全线是否被改写）：** 作者建议"3%（600 条）以下安全"。选定模型的 BMDL₁₀ < 600 条，或无适当模型 → 判"改写"；否则判"未改写"。另报：单格 0/3 的单侧 95% 上界 63%；五格合并 0/15 的上界 18%（合并以单调为前提）。
- **J2（精度是否够 L1 用）：** BMD / BMDL ≤ 2 → "精度可用"；> 2 → "精度不足"。

**C. 种子预算模拟（描述性，无判据）。** 以选定模型（无适当模型时用 logistic）为真，在 ED10–ED90 间等距取 6 个剂量，每剂量 n ∈ {3, 5, 10, 20} 个种子，各模拟 500 次，报告 P(BMD/BMDL ≤ 2) 与 BMDL 对真实 BMD 的覆盖率。

**离线预演（6.2）：** 合成陡峭 logistic、每剂量 20 种子 → J1 判"未改写"且 J2 判"可用"；每剂量 3 种子 → J2 判"不足"。两个方向都须演示出来，演示不出则判据作废、不跑真实数据。

## WST3 测量层的合成演示

**总体。** 10⁵ 条数据，真实毒样本 P = 500。毒样本有潜在难度 h；两个过滤器检出概率 p_j(h) 共同依赖 h，造成正相关。干净样本假阳性率默认 0，另设 0.1% 灵敏度情景。

**情景。** S-a：检出与 h 无关（OR ≈ 1）。S-b：共享难度（OR > 1）。S-c：S-b 加 10% 两过滤器都检不出的隐藏子群。S-d：金丝雀比真实毒样本容易（违反支配假设 D）。

**方法。** (i) Lincoln–Petersen / Chapman 点估计与 95% 区间；(ii) 加标标定的部分识别：每族 K = 200 个金丝雀，其 2×2 表完整可知，ξ = 金丝雀 OR 的自助 95% 上界，两过滤器都漏的真实毒样本上界 = ξ·n₁₀·n₀₁/n₁₁ 的自助 95% 上界（简化版，不是 Sun 等的精确方法）；(iii) 二项反演：由金丝雀召回的 Clopper–Pearson 下界 r_L 与检出数 d，取满足 P(Bin(P, r_L) ≤ d) ≥ 0.05 的最大 P，剩余上界 = P_max − d。

**判据（每条在 1000 次重复上计算）：**

- **C1：** S-b 中 Chapman 区间对真实漏网数的覆盖率 < 0.80，且 S-a 中 ≥ 0.90 → "相关导致低估"得到演示。
- **C2：** S-b（D 成立）中部分识别上界覆盖率 ≥ 0.93；S-d（D 被违反）中 < 0.90 → 两个方向均演示出。
- **C3：** S-c 中报告覆盖率的下降，并与隐藏子群比例对照（描述性）。
- **C4：** d = 0 时二项反演给出正的剩余上界；S-b 中覆盖率 ≥ 0.93。
- **C5（M1 证伪审计的判据预演）：** 门槛 r₀ = 0.90，K = 100 个金丝雀，判"不合格"当且仅当召回的 Clopper–Pearson 单侧 95% 上界 < r₀。真实召回 0.60 时判不合格率 ≥ 0.95；真实召回 0.95 时 ≤ 0.05。两者都须成立，否则判据写坏。
- **假阳性：** 0.1% 情景下报告 Chapman 估计相对真实毒样本数的偏差（描述性）。
