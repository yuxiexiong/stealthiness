# M049 实验合同：单次权重扰动的保留——跃升前与临近跃升

日期：2026-11-17。状态：**冻结后执行**。本文件的 sha256 写入 `CPU_READY.json`，任何 GPU 任务启动前核对；冻结后不改，偏离记入 `DECISIONS.md`。

来源：M048 方案（单次扰动、共同后续输入、两阶段、同一方向）加上用户 11-17 认可的四处修订（沿轨迹方向的混淆、幅度定义、零参照、尾段可比）。用户授权：改方案、写代码、测试通过后直接上卡，工程 bug 自行修复，每 30 分钟汇报。

## 1. 只问一个问题

> 同一个与实际训练有关的小幅权重变化，在跃升前和临近跃升时，是否更容易留下持久影响？

它区分两种说法：「训练产生的影响后来更容易积累」与「影响没变，只是模型靠近了成功阈值」。本实验不检验完整机制，不声称临界失稳，不给显著性。

## 2. 固定的操作

| 项目 | 取值 |
|---|---|
| 背景 | ref-B-GC，即 noop-B-replace 的 320 步完整状态（与 M045 同一背景） |
| 训练 | 原生恢复，**原批次顺序不动**，原学习率日程、原随机流 |
| 扰动 | 在第 t 步更新完成后、第 t+1 步第一个微批之前，把可训练 LoRA 参数整体替换为 θ_ref(t)+α·u；只动权重，优化器矩、scaler、scheduler、随机数状态不动 |
| 阶段 | E：t=325（尾段 325–355，全在上升前）；L：t=355（尾段 355–385，覆盖上升与回落） |
| 方向 | seg365：u=θ_ref(375)−θ_ref(365)（主方向，跃升段的实际位移）；seg335：u=θ_ref(345)−θ_ref(335)（副方向） |
| 剂量 | 主方向 ±1.0、±0.5；副方向 ±1.0。单位是**实测的即时 T 均值偏移**（logit），不是范数 |
| 极小扰动臂 | 每阶段一条：主方向，α 取该阶段 +1.0 臂的 1/1000 |
| 跟踪 | τ=0,2,4,6,8,10,15,20,25,30 步读 200 题的 T、C；L 阶段非极小臂另在 370、375、380、385 做完整生成读数 |
| 规模 | 12 条扰动臂 + 2 条极小扰动臂 + 1 条原配参考 |

T 是触发输入上「目标首 token 对数概率减其余 token 最大对数概率」，C 是同题干净输入的同一量，D=T−C。读数沿用冻结的合并 FP16 读数器。

**为什么是两个方向（2×2）。** 两个方向相对各自阶段都是「10 步之后那一段的实际位移」：seg335 对 E 是即将发生的位移，seg365 对 L 是即将发生的位移。沿轨迹方向的偏移等价于时间提前，本来就不会被拉回。如果只用 seg365，「L 阶段保留更久」可能只是几何必然。交叉后，「阶段」与「是否沿即将发生的方向」可以分开。

**尾段可比性。** 按既有排程，E 尾段（326–355）与 L 尾段（356–385）内的含毒更新数由 `kprepare.py` 从冻结的消费序列数出并写入 `ASSETS.json`；只按排程报告，不按结果调整时点。两个时点在看任何扰动结果之前由本合同固定。

## 3. 幅度校准（开跑前的闸，不训练）

对每个（阶段、方向、目标偏移）：在 θ_ref(t) 上加 α·u，用读数器直接读 200 题，求 ΔT0=T均值(扰动)−T均值(原配)。按 `kproto.next_alpha` 的固定规则迭代，接受条件 |ΔT0−目标| ≤ 目标的 10%，最多 6 次评估，|α| ≤ 2。

- 达不到：该臂记为 `UNREACHABLE`，不运行，属于**测量不可判**，不是科学否证。
- 任一阶段主方向可用臂少于 2 条，或缺极小扰动臂：全线停止，记「当前测量不可判」。
- 校准只看即时读数，不看任何后续训练结果。

## 4. 资格闸（工程）

1. 原配参考从 320 重放到 385，凡落在旧 5 步网格上的检查点，适配器张量须与旧参考**逐位相等**。
2. 参考读数在旧网格步上须与旧读数逐题 |Δg| ≤ 1e-5 且 argmax 相同。
3. 扰动安装：安装前在线权重须逐位等于 θ_ref(t)，安装后逐位等于校准所用的扰动适配器；安装不消耗随机数。
4. 扰动臂若出现参考在相同步没有的跳步（或反之），该臂标记 `skip_divergent`，不进入主判读，如实报告。

任一条 1–3 不过：工程失败，修复后续跑；不以科学结果名义记录。

## 5. 判读（全部在看结果前写死；离线预演见 `bundle/ktest.py`）

**量。** 对每条臂：ΔT(τ)=T均值(臂)−T均值(原配同一步)；R_T(τ)=ΔT(τ)/ΔT(0)。权重位移 Δθ(τ)=θ_臂−θ_原配，r_u(τ)=⟨Δθ(τ),Δθ(0)⟩/‖Δθ(0)‖²，r_d(τ)=‖Δθ(τ)‖/‖Δθ(0)‖。主时点 τ=30，τ=10、20 并报。

**零参照。** 阶段 S 的漂移底 F_S = 极小扰动臂在 τ=0…30 上 |ΔT| 的最大值。原配重放逐位确定，所以这是「可忽略的扰动 30 步后能长成多大」的直接测量。

**格。** 一格 =（阶段，方向）。P = 格内各有效臂 R_T(30) 的均值；W = 格内 R_T(30) 的极差（描述格内的正负、剂量不一致，不是种子零分布）。

**阶段对比（每个方向一次），四档：**

- 设 diff = P(L)−P(E)，e = F_E/格内最小|ΔT0| + F_L/格内最小|ΔT0|，bar = max(0.25, 2e, W_E, W_L)。
- `L>E` 或 `E>L`：|diff| ≥ bar。
- `near`：|diff| ≤ max(0.10, e)，且两格 W ≤ 0.25，且 2e ≤ 0.25。
- `indeterminate`：其余，或缺格。

**总判读（τ=30）：**

| 主方向 seg365 | 副方向 seg335 | 判读 | 含义与后续 |
|---|---|---|---|
| L>E | L>E | `STAGE` | 两个方向在临近跃升时都保留更久：支持阶段差。值得确认，仍不是机制成立 |
| L>E | E>L | `TANGENT` | 各方向在「自己即将发生」的阶段保留更久：是沿轨迹的几何，不是阶段差 |
| near | near | `UNIFORM` | 两阶段保留程度接近：停止用「阶段性保留变化」解释这次跃升，不继续拟合时间常数 |
| E>L | E>L | `STAGE_REVERSED` | 与预期相反，如实记录 |
| L>E | near/不可判 | `PRIMARY_ONLY` | 分不开阶段与几何，不得写成阶段差 |
| 其他 | | `INDETERMINATE` | 没拿到结果 |

**读数与权重不一致。** 若某格过半数臂 R_T(30) ≤ 0.5 而 r_u(30) ≥ 0.8，标记「分数缩小但权重位移保留」。任何带此标记的格出现时，总判读附 `unresolved_readout_vs_weights`，不强行归入「训练拉回」。

**行为层（只在 L 阶段，描述）。** 冻结两条包络预测：完全保留（原配逐题 g 加 ΔT0 后过零的比例）与完全消退（原配）。报告实测 ASR、落在两条包络之间的比例、是否「跟随 T」（实测 ASR 变化与按实测 ΔT 平移的预测相差 ≤5 个百分点）、370–385 的首次过半读点、逐题得失。T 变了而真实生成没变，不算行为被改变。

**时间提前（描述）。** 用原配 D 曲线反解扰动臂的 D 对应的原配步数，得到提前量；再看按该提前量平移后的原配 T 与扰动臂 T 的残差。连同 `cos(u, θ_ref(t+30)−θ_ref(t))` 一起报告，不作总闸。

## 6. 预先登记的预期

- 我的预期（推测档）：`TANGENT` 或 `UNIFORM` 比 `STAGE` 更可能。依据只有 M045 里无新增交换区段的偏差缩小，以及「沿轨迹方向不衰减」的一般性论证。
- 没有定量预测可登记的量：各格 P 的具体数值、行为层的落点。这些只描述，不事后升级为确认。

## 7. 停止条件

- 资格闸 1–3 不过：停，修工程。
- 校准不可判（第 3 节）：停，报告「测量不可判」。
- 全部臂跑完：出 `RESULT.json`，停止。不自动加阶段、方向、种子或背景；不因结果不利改门槛、换时点、换方向重跑。

## 8. 失败类型

- 科学失败：按上表得到 `UNIFORM`、`TANGENT`、`STAGE_REVERSED`，即「阶段差」被否证或被几何解释取代。
- 没拿到结果：`INDETERMINATE`、`PRIMARY_ONLY`。
- 合同执行失败：资格闸不过、臂缺失、校准不可达。信息量为零，不当作负面证据。

## 9. 边界

一条背景、一个训练种子；各臂共享 320 步起点，不是独立训练来源。两个阶段后续 30 步的输入不同，阶段差即使成立，也是「两套自然条件下响应不同」。θ-only 扰动不代表一次真实批次更新（真实更新同时改变矩）。
