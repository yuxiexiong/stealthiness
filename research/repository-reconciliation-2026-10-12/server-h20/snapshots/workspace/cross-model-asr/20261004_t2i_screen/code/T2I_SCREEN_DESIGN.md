# 文生图三种子初筛协议 — 2026-10-04

## 目的与变更时点

用户批准把本轮文生图目标缩小为：快速得到三个训练种子的 ASR vs
checkpoint 曲线，检查低 ASR 后是否出现快速上升。本协议替代本轮 T2I
完整测量预算；LLM 已完成的六条粗测不变。本次修改发生在看过旧种子1001
部分低 ASR 结果之后，因此不是在所有结果产生前预注册的新方案。

## 保留的训练与测量定义

保留 SD3.5 Large 8B diffusion 核心、LoRA r16/alpha32/dropout0.05、原来的
20,000 条图文训练记录、固定200个替换位置（1%）、种子1001/1002/1003、
每种子1250次更新、有效batch16/microbatch4、学习率与样本顺序。保留原
BF16缓存、源图、判定器及其controls、512像素、20次denoising、guidance4.5、
eval batch4。不得为了出现跃升调整目标、触发器、种子、剂量或判据。

复用已经通过原 GPU/pretrained pilot/full prepare 的冻结数据与环境；
源revision、schema4、plan hash、缓存逐行hash和外部Parti probes不变。
所有评估只用原来固定的前60条discovery probes和原来的逐prompt noise seed。
Parti评估仍是跨语料评估，BLIP仍是对象判定代理。

## 初筛测点及队列

- 三条投毒轨迹从初始化重新训练；旧adapter缺少优化器/RNG状态，不能冒充续训。
- 触发ASR在0、100、200、…、1200、1250步评估，共14个点；每点60条。
- 无触发条件只在0和1250步评估，各60条。初筛不测near-token。
- 每20步以及1250步保存adapter，正步checkpoint共63个；加step0 hash/loss共64个锚点。
- 暂缓三条clean训练轨迹及逐步dense replay；不因首个种子结果决定其余种子是否运行。
- 每轨迹生成 `(14+2)*60=960` 张图，三条共2880张，不含工程测试与局部补测。
- 使用新root `/workspace/cross-model-asr/20261004_t2i_screen`、prefix `044cms`。
  新GPU preflight仍依赖六条已完成LLM任务以及原T2I pilot/full prepare。
  现有两名worker负责接卡，不新建抢卡进程。

## 候选窗口与已有checkpoint补测

继续用原来的首次10%/90%阈值和持续跨越描述，不把100步粗测当作一步跃升。
若有首次从低于10%到至少10%的跨越，补测其前一个粗测点之后至首次90%
测点的未测20步checkpoint；尚未到90%时补测到当前已完成粗测的最后一点。
后续完成的粗测点如仍在候选区间，继续补齐未测checkpoint。起点已超过10%
记左删失；未到90%记预算内右删失；回落保留。补测结果仍是同一固定60条，
不得改成200条混接，也不得换噪声或只保留成功点。

补测命令为 `lora_t2i.py evaluate-checkpoint --measurement-protocol screen
--profile full --checkpoint-run ORIGINAL_RUN --checkpoint-step STEP`，同时提供
原sources/data和独立output-dir。它只加载已保存adapter，验证加载后的
参数hash与该步原anchor完全一致，保存来源、原loss与hash及补测成本；
不重放训练，不把加载时的随机adapter当作原checkpoint。保存的原loss是
来源记录，补测不会重新计算训练loss或声称验证了一次训练重放。

每个新增步点60张，按旧方案实测约4.56秒/图，约4.6分钟/点，另加加载成本。
看门狗先记录实际窗口、点数与增量成本，再提交独立补测任务；所有三个训练
种子优先完成，补测不得占用其训练卡。总初筛约6.5小时两卡日历时间为旧运行
实测外推，7–9小时仅是修改验证和少量补测预算；窗口很宽时补测会超出该预算。

## 停止、保留与解释边界

撤下原043cmt的六条正式job描述，保留两个主动中断任务的日志、部分图、
metrics、anchors、SIGINT退出与cost receipt；单独记录这是用户批准的方案切换，
不是工程故障。未开始的四条任务记录为暂缓。旧测量曲线不能拼入新初筛曲线。
新尝试失败后保留失败身份，仅以新编号修复重跑。

全部三条有效1250步曲线及必要20步补测结束后，输出三种子的图、原始统计、
阈值区间和完整成本（包括旧方案已花成本）；推送结果并暂停本轮看门狗。
LLM逐步重放和T2I完整clean验证留待后续，不再作为这次初筛的完成条件。

初筛能提供“这三个投毒训练种子在这些测点的ASR如何变化”的证据，不能单凭
三条投毒曲线证明后门因果效应或共通内部机制。100步粗测可漏掉短暂峰值；
无跃升仅说明本预算和测点未观测到。20步补测只能定位到20步分辨率。
2880对51840是测量工作量变化，不是同一验证标准下的效率贡献。
