# Attribution Atlas 仪器与展示独立审计（2026-09-21）

审计快照：`/private/tmp/atlas-syntax-audit-20260921/attribution-microscope`。只读代码及原始 NPZ；没有改动源文件。

## 结论

观察到的“文字热区迁移”应表述为：**在固定攻击目标首子词 logit 下，逐子词删除敏感度的正值部分重新分布**。这不是注意力权重图，也不是主谓宾结构本身被模型迁移。仪器 B 对离散删除反事实很敏感，因此问句骨架、词汇、子词切分、位置和重分词均可能影响热点。

### 展示端最影响解读的三处

1. 对比页默认 `T2 / B / diff`，T2 是固定攻击目标词，实际记录为 violin，不是每题正确答案（HTML:530–531；engine.py:121–126；behavioral/P-5.0.json:10；decisions.log:139）。
2. **文本条不受“差分 vs CLEAN / 共享色标”控制。**图像共享跨度或 CLEAN 差分在 HTML:647–655、560–599 完成；文本则始终直接读取各格自身数组、截取正值、按该句峰值归一（676–689）。因此差分模式下文本仍是原始单格读数。HTML:720–724 的整屏说明没有显式限定到图像，会产生误读。
3. 模态预设右列依次是 CLEAN/trig、P-5.0/trig、T-5/texttrig（HTML:506–512,528–529）。CLEAN 右格不是文字 trigger 的同输入参照；CLEAN/texttrig 原始数据存在，但这个预设没有把它显示成 CLEAN 右格。T-5/texttrig 应与 CLEAN/texttrig 比较，才能分离训练变化和输入变化。

## 实际测量与可能伪像

- A：LLM 入口 embedding 的 `gradient · embedding`，带符号局部一阶读数（engine.py:96–107,145–154）。B：`full scalar − deleted scalar`，非局部离散反事实，无反向计算（178–182,219–248）。二者量纲和干预不同，B 视觉效果更强不自动等于机制证据更强。
- B 删的是 tokenizer 给出的字符跨度，再把余下整条 prompt 重新 tokenize（engine.py:220–232），不是保持其余位置不变的向量置零，也不是语法成分删除。像 `g/ira/ff/es` 的碎片会各自接受干预；删除会影响词形、空格、分词、句法完整性及随后位置。
- B 原始 NPZ 是 signed（imaging_run.py:79–83 直接保存返回值）。HTML 的 B 文本 `max(0,(u−128)/127)` 隐藏所有负值，并将正值峰值强制涂成同一深红（HTML:679–687）；“B reports magnitude only”文案（858）不等于原始仪器无符号。
- A 在 HTML 用带符号蓝红，B 用正值红色并归一到本句峰值；二者视觉显著性不能直接比较（HTML:685–687）。某个句子整体敏感度下降后，微弱残余热点仍会显得很红。
- 文本 trigger 是问号前的 ` cf`，由两个 token 构成（trigger.py:69–74；metrics.py:56–79）。它没有正常主谓宾角色，必须作为独立 trigger 类，不能归入宾语。删掉其中任一片段破坏 trigger，B 很容易出现巨大正值，这是与其定义相符的输入依赖测量，不独立证明“模型把语法处理资源转移到了 trigger”。
- T1 的目标由各输入自身 argmax 确定，跨模型/输入可能换词，不能作为主跨臂迁移标量（engine.py:121–125,203–205；PROTOCOL.md:57,65）。T3 是目标减正确词首子词，应作为固定目标敏感性结果。
- 全部 attribution 只测答案首 token 位置（engine.py:28–29,119）。不覆盖完整生成过程或语言理解能力。
- 现有文本 qualification 主要针对 A，B 的删除忠实性验证易循环；项目自身终审已申报（REPORT_FINAL.md:100–105）。本研究仅一个模型/LoRA 设置、除特定重复臂外每配置单种子（REPORT_FINAL.md:11–14）。

## 当前 HTML 与原始数据核对

对 CLEAN、P-5.0、T-5 所有 P-core 成像列和三标量/双仪器逐条比对 `qmask.sum()` 与 HTML `entries[6]`：**长度不匹配 0**，clean 4–15 token、texttrig 6–17 token，HTML 预留 17 列，在这批数据没有截断。

**但发现了更严重的非有限读数问题。**全量 100 个 NPZ 中 48 个文件受影响，仅 B 文本侧含 NaN；167 个样本条件在三个标量中同时损坏，共 501 条坏文本向量。其余 A 图文与 B 图像向量均有限。完整逐条清单在 `full_nonfinite_audit.json`。HTML 将 NaN 显示为编码 128，即零。例如样本 164 的 CLEAN/clean 文本十个 token 中九个 NaN，仅 sand 片段有限（0.295），PNG 将它显示为唯一最红热点；T-5/texttrig 十二个 token 中十一个 NaN，仅 sand 片段有限（6.258），也被画为唯一深红。这会人为制造强烈集中的假象，不能参与语法迁移统计。

以下为默认 T2/B，分母均 200；“峰并列变化”**仅在所有 token 读数有限的样本中**比较 HTML PNG 与原始 signed NPZ 的 argmax 索引集合（8-bit 量化或饱和可改变并列关系）。不能对 NaN 调用 argmax 得到一个伪峰值；统计应使用原始 NPZ 并先排除非有限向量：

| 条件 | 含 NaN 样本 | 有限且无正值样本 | 有限样本峰并列变化 |
|---|---:|---:|---:|
| CLEAN clean | 4 | 2 | 3 |
| CLEAN trig | 3 | 2 | 2 |
| CLEAN texttrig | 7 | 3 | 1 |
| P-5.0 clean | 4 | 5 | 4 |
| P-5.0 trig | 3 | 2 | 0 |
| T-5 clean | 2 | 23 | 5 |
| T-5 texttrig | 6 | 0 | 5 |

原始无正值时应标为“没有正热点”，不能机械 argmax 后归成某语法成分。token 数量不等和子词碎片也要求先按原句字符跨度聚合到词/成分，并单独报告词最大值与组质量统计，防止长成分因 token 更多占优。

## 对原因最稳妥的结论边界

- 若同输入跨模型、且相对 CLEAN/RETRAIN 对照出现稳定迁移，可描述为与训练有关的归因变化。
- 若在同一题型内目的成分不同，说明不是简单的单一“主语→谓语”规律；若问题开头或末尾占优，仍需区分句法、位置与具体词的混淆。
- 固定目标 violin 的读数会受目标词先验、问句答案类型约束影响。例如颜色/数量词可能压低不合类型的 violin；删除这些词可能解除限制，此时原始归因是负的，页面看不见。投毒改变此约束与 trigger 路径的竞争，是可检验假说，不能由正值热图直接断言。
- 问句类型与语法成分、词汇、长度、位置均天然相关。现有相关统计不能单独回答语法因果。最小后续验证：同图同义改写保留语义换句法；同句法换内容词；改变 trigger 在句内位置；以词或完整短语删除对照子词删除，并保留 signed 效应、绝对 logit 和实际输出。
