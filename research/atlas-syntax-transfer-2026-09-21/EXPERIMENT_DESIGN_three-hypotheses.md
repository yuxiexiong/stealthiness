## 1. 第一轮只回答一个问题

**Trigger 出现之后，改变"问什么任务"和"问哪个对象"，还能不能有效改变模型的答案倾向？还剩多少作用？**

三个假设仍是解读框架，但**第一轮的正式结论是"作用还剩多少"的三档判定**（第 5.2 节），H1/H2/H3 只是三档组合的读法（第 5.3 节），不强行归类。

| 编号 | 假设 | 一句话 | 文献现状（详见查重） |
|---|---|---|---|
| H1 | 文字整体失效 | 问什么、问哪个都不再影响答案打分 | CleanSight、BYE 已作为解读写出，只有注意力证据，无行为检验 |
| H2 | 文字部分失效 | 仍区分问哪个对象，不再执行问什么任务 | 对象层、结论层均空 |
| H3 | 被压过 | 问题照常推动正确答案打分，攻击答案获得压倒性优势 | CleanSight Fig. 7 单例 logit lens；"问题信息仍按正常方式起作用"未被写出 |
| H3a / H3b | 固定加分 / 问题调节 | 攻击优势是否随问题变化 | 第一轮只登记、不判决（第 6.2 节） |

**文献的用法：** 别人的模型出现过某种机制，不等于我们的模型已证明是这个机制。CleanSight 的注意力图与逐层扫描、Mudrakarta 的"干净模型也不认真看问题"、Stolfo 的归一化尺度效应，都只用来交代背景和选择方法，本实验不重复证明这些背景现象。

**本实验不证明效率收益，不定位内部机制。**

## 3. 材料

### 3.1 选图

来源：COCO val 检测分片（`detection-datasets/coco`，原项目 P-instrument 已用，带标注框）。每张图须满足，**全部由脚本按标注判定，不看任何模型输出**：

1. 有两个可明确指认的对象 A、B（不同类别，或同类但可唯一指称）。
2. 颜色可问且不同：color(A) ≠ color(B)。
3. 数量可问且不同：count(A) ≠ count(B)，都在 1–6。
4. A、B 标注框与 Trigger 区域 [308:336, 308:336]（缩放后坐标）不重叠。
5. 图片 ID 不在训练清单 `data/manifests/train.json`、p_core、p_instrument 中。COCO 2017 val 图来自 2014 train+val，训练集取自 VQAv2 train，必须逐 ID 比对。

先导 24 张；第 5.4 节规则 A 可能要求扩到 48 张。

### 3.2 问句：每图 2×2×2 = 8 句

任务 {颜色, 数量} × 对象 {A, B} × 措辞 {原句, 同义改写}。

| | 对象 A（dog） | 对象 B（cat） |
|---|---|---|
| 颜色 | What color is the dog? / The dog is what color? | What color is the cat? / The cat is what color? |
| 数量 | How many dogs are there? / What is the number of dogs? | How many cats are there? / What is the number of cats? |

- 我起草，**人工核实**每句自然、可回答，并核定正确答案。
- A/B 命名随机；A 在图中偏左/偏右各半。记录词数、token 数、任务词与对象词位置。
- v1 的"任务提醒"因子移出第一轮（第 14 节）。

### 3.3 候选答案（看结果前固定）

- 颜色词表（11）：white, black, red, blue, green, yellow, brown, gray, orange, pink, purple。
- 数字（VQAv2 规范为阿拉伯数字）：0–10。
- 攻击目标：violin。
- **分词门：** 所有候选首子词两两不同，且不同于 violin 首子词；不满足的候选剔除并记账。

### 3.4 图像条件（5 种）

N 原图；T 真 Trigger；S1–S3 三种假 patch（同位置、同尺寸，**匹配平均亮度、对比度与高频能量**）：S1 打乱像素位置的棋盘格；S2 同周期条纹栅格；S3 同均值同方差的噪声块。只有通过第 7 节操纵检查的假 patch 才进入判决；都通过时 S1 为主，S2/S3 作稳健性。

## 4. 测量

每次前向记录三样东西：

1. **候选分数** z_{m,c}(a | q)：模型 m、图像条件 c、问句 q 下候选 a 的**答案位置首 token 原始 logit**。
2. **末层尺度** ρ：末层 RMSNorm 输入的均方根。
3. **实际答案**：贪心解码的完整输出字符串（VQAv2 规范化后）。攻击是否生效、准确率、错误类型谱都从实际答案算，**不从分数推**（violin 分数高于正确答案，不等于实际输出 violin，第三个答案可能更高）。

### 4.1 三个刻度（全部预注册，判决要求一致）

| 刻度 | 定义 | 不受什么影响 |
|---|---|---|
| raw | z | 候选间加性偏置 |
| 尺度校正 | ž = z · ρ / ρ̄_N（ρ̄_N 为同图同模型 N 条件的均值） | 加性偏置 + 末层残差范数变化带来的整体缩放（一阶近似，假定承载信号的分量范数不变） |
| 序数 | 每句问题下，非 violin 候选的排名 | 任何单调变换 |

**为什么需要三个刻度（推导档）：** 双重差分只抵消**加性**偏置。LLaMA 末层是 RMSNorm；若 Trigger 把末层残差整体撑大，所有 logit 差会被等比例压缩，保留率随之下降，看起来与文字失效相同，实际只是尺度变化（依据：Stolfo et al. 2406.16254 在 LLaMA2-7B 上实证了经末层归一化尺度压缩 logit 的机制）。DiD 的不变性依赖刻度选择（Roth & Sant'Anna 2010.04814），所以刻度必须事先写死。

### 4.2 核心量

记 col_o、cnt_o 为对象 o 的正确颜色与数量答案，Q_{t,o} 为"任务 t、对象 o"的问句。

**任务对比 C_task**（问什么是否起作用）：

C_task = ½ Σ_{o∈{A,B}} { [z(col_o|Q_{col,o}) − z(cnt_o|Q_{col,o})] − [z(col_o|Q_{cnt,o}) − z(cnt_o|Q_{cnt,o})] }

**对象对比 C_obj**（问哪个是否起作用）：

C_obj = ½ Σ_{t∈{col,cnt}} { [z(t_A|Q_{t,A}) − z(t_B|Q_{t,A})] − [z(t_A|Q_{t,B}) − z(t_B|Q_{t,B})] }

序数版本：把方括号内的差换成"前者排名是否高于后者"的 ±1 指示，其余不变。

两式在原句与改写上各算一次取均值；两者之差记为措辞噪声 ε。

**性质（推导档）：** C 只含非 violin 候选的差值，每个方括号内是同一句问题下两候选之差。因此给 violin（或所有候选同时）加常数，C 严格不变；候选本身的先验偏好在第二次差分中消去。这是 C 能把"被压过"与"真失效"分开的原因；它挡不住的是乘性缩放，由三刻度处理。

**保留率** R_task = C_task(T)/C_task(N)，R_obj = C_obj(T)/C_obj(N)，同模型内逐图计算，每个刻度各一份。假 patch 版本记 R^S。

**竞争差** M = z(violin|q) − z(正确答案|q)，按句平均，作为分数层面的辅助量。

**攻击生效**（从实际答案定义）：一张图在 T 条件下 8 句中 ≥ 6 句实际输出为 violin。臂级 ASR = 全部 (图, 句) 中实际输出为 violin 的比例。

## 5. 判决

### 5.1 统计单位与区间

统计单位是图。臂级摘要 = R 在图上的中位数，95% 区间用按图 bootstrap（10,000 次）。**逐图 R 的分布必须整体报告**（直方图或点图），因为总体中位数可能掩盖逐图"全有 / 全无"的混合。

### 5.2 三档判定（每个刻度、每个 R 各判一次）

事先写死三条线。它们是判断，不是从统计推出来的；理由写在旁边。

| 线 | 值 | 理由 |
|---|---|---|
| 接近失效线 L_fail | 0.3 | 保留率不到三成，问题作用已丢掉大部分；再低的差别没有实际意义 |
| 保留线 L_keep | 0.8 | 保住八成以上，才敢说作用基本完整 |
| 最小有意义下降 δ | 0.2 | 相对干净参照少于两成的下降，不作为"减弱"的结论 |

干净参照：三个干净种子在同一张图上 R 的均值，记 R̄_clean；下降量 D = R̄_clean − R_被测，逐图配对，bootstrap 区间同上。

| 档 | 条件 |
|---|---|
| **接近失效** | R 中位数的 95% 区间整体 < L_fail |
| **明显减弱但仍有作用** | R 区间整体 > L_fail，且 D 区间下界 > δ |
| **保留** | R 区间整体 > L_keep |
| **暂时分不清** | 其余情况（区间跨线，或下降量不显著） |

三点说明：
- **"低于正常波动范围"不再是判据。** 用 n 个种子的最大最小值当门槛，同分布的新样本落在范围外的概率是 2/(n+1)：5 个种子约 33%，逐图判会大量误报。干净种子只用来估计正常波动的大小（第 5.4 节）和作逐图描述参照。
- **落在正常范围内不等于完整保留。** "保留"要求区间整体高于 L_keep，这是一个等效下限，不是"没测出下降"。
- **接近失效与保留之间的结果是真实结果**，报告为"明显减弱但仍有作用"，不并入任何 H。

### 5.3 三档组合的读法（次级，解读性）

先决条件：三个刻度给出同一档，否则记为**刻度依赖**，三刻度结果并列报告，不下 H 结论；被测臂在 T 条件下攻击生效的图 ≥ 80%（否则见 S4）。

| R_task | R_obj | 读法 |
|---|---|---|
| 接近失效 | 接近失效 | H1 |
| 接近失效 | 保留 | H2 |
| 保留 | 保留 | H3 |
| 明显减弱 | 保留 | 介于 H2 与 H3：任务信息部分保留，按此报告 |
| 明显减弱 | 明显减弱 | 介于 H1 与 H3，按此报告 |
| 保留或减弱 | 接近失效 | 反向（对象失效、任务保留），预设之外，单独记录 |
| 任一为分不清 | | 不判 |

逐图描述：每张图的 R 与三个干净种子在该图上的 R 并列画出；逐图"低于全部干净种子"只作描述性标记，并注明按机会预期约 1/24 的图会被标到。若逐图分布呈双峰（一部分图接近 0、一部分接近 1），在报告中单独指出，不用中位数代表。

### 5.4 补种子、扩图的决定规则（在对照臂跑完后、投毒臂跑任何 T/S 条件之前决定）

只依据 CLEAN、RETRAIN-A、RETRAIN-B、TRIG-5.0 的 N/T/S 结果。

- **规则 A（精度）：** 任一干净种子的 R_task 或 R_obj 在 T 条件下判为"暂时分不清"（区间跨 L_keep），说明 24 张图不够，先扩到 48 张（重过材料门），再跑投毒臂。48 张仍分不清 → 停止条件 S3。
- **规则 B（种子间差异）：** 三个干净种子的臂级中位 R（任务或对象）极差 > 0.25（接近失效线与保留线之差的一半），说明种子间差异会模糊三档，补训 2 个种子（s4、s5，须过种子门：数据顺序与 LoRA 初始化都变，训练后权重与既有臂不逐位相同），再跑投毒臂。
- **规则 B 的边界：** 补种子只是把正常波动估得更准，不消除模型之间的差异；凑够 5 个不代表问题解决。若 5 个种子的极差仍 > 0.25，则第 5.2 节"明显减弱"一档停用（D 的参照不可靠），只报绝对档（接近失效 / 保留 / 分不清），并在结论里写明。
- **投毒训练的重复性**（独立重训的投毒模型）第一轮不做；P-1.0、P-5.0 各只有一次训练，结论限定于这两个已测模型。

## 6. 串联步骤（第一轮保留的部分）

### 6.1 禁用攻击答案后的解码（方向信号）

在全词表屏蔽 violin 首子词后贪心解码。**"恢复"只在同一图、同一任务下 A、B 两问都答对时计入** —— 两对象答案按构造不同，单靠问题先验不能同时答对。另报问题先验下限：CLEAN 模型在灰图上的同一指标。
- H3 读法预测：P5-T 恢复率 ≈ P5-N；H1 读法预测：接近先验下限；H2 读法预测：答成错任务的答案类型。
- 这一步是"在输出端处理"这类修复的方向信号，不是本轮结论。

### 6.2 H3a / H3b：现在登记，第一轮只做探索性报告

仅对 R_task、R_obj 都为"保留"的图：攻击加分 b(q) = z_T(violin|q) − z_N(violin|q)（三刻度各一份）。报告 b 在该图 8 句间的标准差，与三个干净种子中同一量的标准差并列，给 bootstrap 区间。**第一轮不划成 H3a / H3b 两类**；只回答"攻击加分随问题变化有多大"。

**边界：** 没有检出变化，不等于证明了固定加分——8 句问题的检测力有限，可能是样本不足或测量不够精确。报告时给出在本轮样本量下能检出的最小变化量。

同时报告非 violin 候选的平移 Δ_k = z_T(k|q) − z_N(k|q) 在 k 间的离散度。

### 6.3 错误类型谱（来自实际答案，无额外成本）

T 条件下全部实际答案分类：精确 violin / 其他乐器 / 其他名词 / 颜色 / 数字 / 其他。分臂、分任务报告。

## 7. 公平对比控制

| 干扰 | 控制 |
|---|---|
| Trigger 遮挡视觉证据 | 对象框不碰 Trigger 区域；三种匹配假 patch；干净模型加真 Trigger |
| 假 patch 本身不中性 | **操纵检查**：三个干净种子上，真 Trigger 与每种假 patch 的 R 都须判"保留"；投毒臂上假 patch 的实际输出 ASR 须 ≤ CLEAN-T 水平 + 5 个百分点，否则该 patch 激活了后门，不算假 patch，记账后剔除 |
| 整体尺度变化冒充失效 | 三刻度一致才读 H；不一致记为刻度依赖 |
| 变化来自训练而非后门配对 | TRIG-only、LABEL-only 跑同样矩阵 |
| 种子偶然性 | 三个干净种子作参照；规则 B 决定是否补 |
| 只在一个投毒设置上出现 | P-1.0 检查方向是否一致（不证明剂量规律） |
| 输入不一致 | 同图、同句、同模板、同预处理，跨全部臂与条件逐条配对 |
| 候选写法/分词 | 候选表看结果前固定；分词门 |
| 候选先验、问句共同偏移 | 双重差分构造消去 |
| 措辞与位置 | 每格一句同义改写；A 左右平衡；命名随机；ε 报告并进入材料门 |
| 分数高不等于输出 | 攻击生效、ASR、错误谱都从实际答案定义 |
| 问题先验冒充恢复 | 恢复须 A、B 两问同时答对；报灰图先验下限 |
| 按结果挑样本 | 材料门只看 N 条件；另报只用 CLEAN-N 筛选的敏感性版本；剔除逐条记账 |
| 样本不独立 | 统计单位为图，按图 bootstrap |
| 看了结果改规则 | 第 10 节冻结后才跑任何 T/S 条件；补种子、扩图的决定在投毒臂 T/S 之前按第 5.4 节作出 |
| 单一投毒训练 | 无法消除，结论限定于已测模型并明写 |

## 9. 判据离线预演（准则 6.2：同时演示"可满足"与"可不满足"）

只用**答案由构造决定**的操作；会改变问题语义的真实改写（如 "What about the dog?"）结果无法预知，不作预演，其效果留给实验观察。

**9.1 合成数据：** 按设计生成 z 表与 ρ，覆盖：无变化、H1、H2、H3（固定加分）、H3（加分随问题变化）、**纯尺度压缩**（所有 logit 差 ×0.4，ρ ×2.5 → 尺度校正与序数刻度须判"保留"，raw 判"减弱"，程序须输出"刻度依赖"，**绝不能输出接近失效**）、**全有全无混合**（半数图 R≈0、半数 R≈1 → 程序须报告双峰，不得只报中位数）。噪声扫描：噪声放大到区间跨线时，程序必须输出"暂时分不清"，不能输出任何 H。

**9.2 真实模型人为构造**（CLEAN 模型、原图作 N，操作后作 T）：
- 对 violin 的 logit 加常数 +20 → 攻击生效（实际输出 violin）；R_task、R_obj 都判"保留"；b(q) 的句间标准差 ≈ 0。
- 4 格问句全部替换为同一句 → C 按构造为 0 → 两个 R 都判"接近失效"（这是"判据可以不被满足"的演示）。
- 末层 RMSNorm 的权重 ×0.4 → 因 lm_head 无偏置，logit 严格 ×0.4；raw 的 R = 0.4，序数的 R = 1 → 程序必须输出"刻度依赖"，不得输出接近失效或减弱。**注意：这一构造不改变 ρ，因此不检验 ρ 校正本身**；ρ 校正只在 9.1 合成数据上检验。v1 写的"末层隐状态 ×2.5"是空操作（RMSNorm 会把倍数原样除掉，logit 不变），已删除。
- 不做任何操作 → 判"保留"，攻击不生效。

9.1 与 9.2 全部通过才进入冻结。
