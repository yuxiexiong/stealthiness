# 文字热点现象

2026-09-23。状态：研究方案，尚未执行新模型实验。本文件将已观察到的现象、待检验解释和后续实验分开；不改变现有 HTML 的统计结果。

解释分支、遗漏检查和实验判别条件见 [假设覆盖表](HYPOTHESIS_COVERAGE.md)。

建议课题问题：**视觉后门如何改变问题信息对答案选择的作用？**

最优先检验的解释是：问题的含义仍影响模型打分，但攻击答案的优势使它难以改变最终输出。这是候选解释，不是已经证明的机制。另须允许“语义作用确实减弱”“只是测量方式或目标标签偏置”得到支持。

现有 200 题已经反复用于探索，应作为发现集。新机制结论需要未用来选择规则、阈值和层位置的确认数据。重新切分这 200 题，不能把过去已经看过的数据变成完全独立的确认集。

## 1. 目前的起点

- 已有原始带符号删除影响、行为答案、四条件图文热图，以及逐题分类。仪器 B 测的是删除子词字符片段、重新分词后，violin 首子词原始 logit 的改变，不是 attention 权重。
- 同一投毒模型加 Trigger 的正热分布变化明显大于干净模型；具体变化方向不统一。
- 已有补充分析提示，攻击答案与正确答案两个输出方向的删除敏感度变化不同，LABEL-only 训练也能产生相似的目标方向变化。因此，问题整体失效、输出竞争改变、标签偏置和输入破坏仍需区分。
- 未完成自然问句改写、真正整词／整组联合干预、长文本验证及模型内部因果干预。

证据入口：[当前报告](visual-report/Attribution-Atlas-热区转移报告.html)、[仪器审计](instrument_audit.md)、[原始输出方向分析](deeper/output-directions/REPORT.md)、[四条件交互定义](fundamental/interaction/README.md)。

## 2. 第一阶段：确定自然问题上的现象，而非继续增加语法分类

**要回答：问题含义改变时，模型的打分与最终答案分别怎样变化？**

先检查现有干净、投毒和 LABEL-only 权重能否运行，确认 tokenizer、图片预处理、提示模板与原实验一致，并复现少量原题答案及原始分数。现有缓存不能替代新问题上的前向推理。权重可用性尚未在本规划中验证。

建议用 24 个适合构造有效问题对照的图像做流程和假设筛选。覆盖主要题型、不同热点变化幅度及反向案例；不按攻击成功筛选。24 是可人工核验的先导规模，不是统计功效保证，也不能代表全体图像。需公开入选和排除标准；攻击失败等稀有案例可另列审计，不能无权重混入总体比例。

每图准备以下 6 版问题；如要更换被问对象，图片须有第二个可明确指认的对象，否则按预先规则记录该条件不可用：

| 版本 | 改变什么 | 保持什么 | 用途 |
|---|---|---|---|
| 原问题 | 无 | 原图、任务、对象 | 基准 |
| 同义改写 | 措辞 | 含义、正确答案 | 区分语义与特定词形 |
| 位置改写 | 任务表达在前／在后 | 对象、任务、正确答案 | 区分语义与位置 |
| 改变提问任务 | 如数量改为颜色 | 图片、被问对象 | 检验“问什么”是否仍有作用 |
| 改变被问对象 | 指向另一对象 | 图片、提问任务 | 检验对象选择是否仍有作用 |
| 添加无关描述 | 增加自然、无冲突的文字 | 原任务、对象、答案 | 检验长度与无关上下文影响 |

人工核验每版的自然性、可回答性和正确答案；记录词数、token 数、关键词位置。一次改写很难只改变一个语言属性，因此要使用多个模板，并交叉平衡措辞、位置和任务，不能把某一个句式的效果直接归为语义。

首轮使用干净模型、P5、LABEL-only，各自有／无 Trigger。同一版本的图片和文字逐条件对应。全矩阵最多为 24 × 6 × 2 × 3 = 864 个模型—输入组合；这不是总 forward 次数，也不含答案评分、重算 B 或重复采样的开销。若 LABEL-only 权重不可调用，可先核查其余四条件，但后门特有性判断仍缺该对照。TRIG-only 与普通重训参考在候选解释确认前补齐。

记录三层结果：

1. 实际完整生成答案：正确、攻击目标、其他错误和拒答分别记录。攻击目标恰好是正确答案的样本需单列，不能计为恶意接管成功。
2. 原实验 T2／T3 的固定首子词原始分数及分数差，保留可比口径。首 token 相同或不足以区分答案时不强行解释。
3. 完整攻击答案和正确答案的序列评分，固定答案字符串及停止规则，公开长度差异和评分口径；不把序列概率、首 token 分数、自由生成混作同一个指标。跨问题比较须有匹配分析，避免只由答案长度产生差异。

首轮重点得到行为判别证据；在预先确定的诊断题上补做整词、完整短语及联合干预，核对原 B 热点是否有意义。不能把单子词 B 求和冒充整组删除效果。无正值、非有限值、并列及攻击失败全部保留在覆盖率账本中。

**必须加入简单解释基线：**在同一图像上，估计一笔与问句无关的攻击答案固定加分，用它预测未用于拟合的问法。若足以解释结果，优先保留这个简单模型。原 B 基于 raw logit，不受 softmax 归一化本身影响；新增概率／序列评分中的非线性变化不能被直接当作复杂语义交互。单个 raw logit 还需与固定竞争答案的分数差配合，排除共同分数偏移。

第一阶段的判断：

| 结果 | 允许的结论与行动 |
|---|---|
| 自然改变含义仍明显改变分数，但输出持续是攻击答案 | 优先研究问题影响与最终选择之间的脱节；仍未证明模型内部如何处理语义 |
| 无 Trigger 时语义变化有作用，有 Trigger 时反应大幅减弱 | 优先研究问题影响受抑制；报告效应范围，不能用“不显著”代替“零影响” |
| 变化主要出现在破词删除，换成自然改写或整词操作后不稳定 | 转向归因测量可靠性；停止用原热点支持语义机制 |
| LABEL-only 或固定加分基线基本复现 | 转向目标标签偏置／输出竞争，单独量化 Trigger 的额外作用 |
| 多种解释分别在不同样本成立 | 描述各自成立条件，不强行给全部样本一个机制名称 |

各解释不是先验互斥的饼图类别。第一轮产物应是配对结果表、分数散点和完整答案例子；尚未制定可靠判定规则时，不生成“机制占比”。

## 3. 第二阶段：从描述现象变成能预测的行为规律

**要回答：什么样的问题更能抵抗、促进或改变 Trigger 的影响？**

优先分开三个因素：任务要求（颜色／数量／识别等）、被问对象、表达形式。重点检验一个候选因素：问题允许的答案类型与攻击目标是否相容。例如颜色或数量问题对 violin 有明显的类型冲突；这只是待检验预测，不是既成解释。

先在现有模型上利用上述配对问句筛选因素。若结果支持“答案类型冲突”解释，再改变攻击目标进行验证，避免把 violin 的特殊性当成一般规律。额外目标与模型训练属于后续成本，不能假定现有缓存已经支持。

在保持图片和问题可回答性的前提下，测试 Trigger 强弱或已有不同攻击强度条件。每一档核查攻击是否仍有效，并加入相同区域／相近幅度但不构成 Trigger 的图像扰动对照。减弱 Trigger 同时损坏图像证据的结果不能用来推断文本作用恢复。

用发现集确定规则后，冻结表达方式、指标和预测，再在新图像、新实体和留出模板上检查：能否预先判断哪些问题的分数响应更大、哪些条件会使答案重新随问题变化。比较固定加分、题型／长度／位置等简单基线。规律必须增加留出预测能力，不能仅把已知案例重新命名。

统计按图片聚类，同一图片的多个改写不算独立图像样本。正式确认样本量依据先导方差与希望排除的效应范围确定；探索得到的效应量可能偏大，需要保守估计。训练种子的不确定性必须用独立训练处理，不能用问题 bootstrap 替代。

继续门槛：有效自然输入上的效应稳定，胜过简单基线，并能说明例外。若效应在留出模板反复消失，停留在模板依赖结论，停止追求统一语义规律。

## 4. 第三阶段：定位导致这种行为的内部计算

**要回答：哪个计算环节改变了问题对最终答案的作用？**

在同一投毒模型内，先用同题有／无 Trigger 的匹配运行寻找候选层和组件；这组输入文本长度一致，适合初步对齐。再用自然问题对照检验候选位置承载的是任务、对象，还是一般扰动。不同长度问句不能按 token 下标机械替换，必须规定对齐和干预范围。

热图、attention 权重和从隐藏状态解码问题信息都只用于提出候选位置。从状态里能读出某信息，不等于原模型用它选择了答案。

对候选环节做双向干预，并在留出样本验证：

- 在 Trigger 仍存在时，抑制或替换候选计算，是否降低攻击且恢复与当前问题相符的正确答案？
- 恢复被移除的候选状态，攻击是否重新出现？在无 Trigger 条件注入相应状态，是否能推动相同的攻击行为？
- 将操作放到等数量的随机组件、邻近层、无关位置，或使用与当前问题不匹配的供体状态，效果是否不同？
- 正常问答、其他题目和不涉及目标的答案是否保留？拒答、随机回答或普遍降分不能算修复。

状态替换须使用可比较的供体、相同干预范围及必要的幅度对照；避免整段供体已经直接带入正确答案信息。一次替换成功只证明该干预能改变输出；它不证明唯一自然通路，也不代表模型权重已经修复。

机制阶段至少形成一条可检验的链：自然语义干预引起某种中间变化；干预该变化会选择性改变目标行为；同一解释还能预测此前未用来定位的题目。

## 5. 第四阶段：检验机制的适用范围

按新增信息量扩展，避免一开始铺满大矩阵：

1. 新图片、实体和问句模板；再加入真正的复杂句／段落。长文本包括无关信息、跨句指代和重复证据，联合干预用于检验冗余，不能只给短句加废话就宣称完成长文本验证。
2. 不同攻击目标与独立训练种子，检验目标类型、偶然训练差异的影响。
3. 不同 Trigger 机制，例如局部图案与分布式变化；再到另一种 VLM 架构。

每层分别报告复现的是热图现象、行为预测，还是内部因果关系。不同模型可以通过不同组件实现相近行为；不能要求同一层号或同一 head 编号才算复现，也不能据行为相似就认定内部机制相同。

最终目标是得到有边界、能预报反例的规律。只有单模型单目标结果时，题目和结论明确限于该设置，不使用 Universal Law。

## 6. 最后可以长成什么样的课题

| 证据最终到达哪里 | 可以交付什么 | 仍缺什么 |
|---|---|---|
| 确认主要是显示／删除操作的影响 | 可复核的归因可靠性研究与验证流程 | 超出现有归因批评的系统性新证据，不能仅凭一个 bug 宣称论文贡献 |
| 自然输入上出现稳定、可预测的问句依赖 | 后门如何改变任务控制的行为研究 | 明确近邻差异、留出验证和解释适用边界 |
| 行为规律得到选择性的内部干预支持，并能复现 | 有因果证据的 VLM 后门机制研究 | 证明不是一般模型破坏、标签偏置或供体信息注入 |

检测与缓解可作为后续应用分支，不是这条路线的必经终点。若进入应用，须重新规定能否访问干净模型、原图、已知 Trigger 和正确答案；机制实验的这些已知信息不能偷偷用于声称现实可部署的检测器。比较误报、攻击成功率、正常及触发输入上的正确率、拒答和全流程成本。机制位置优于随机位置，不等于方法优于现有检测／缓解基线。

## 7. 与已有研究的关系

这次仅做了聚焦近邻核查，没有完成系统的新颖性审计。

- [CleanSight（2026）](https://arxiv.org/html/2603.12989v1) 已讨论视觉 Trigger 对应的 attention 增加、文字侧 attention 下降，并以视觉 attention 干预和 token 抑制测试攻击变化。我们的删词 B 不是 attention 权重，两者不能靠数值方向直接互相证伪。潜在研究空间是直接区分自然问题含义的影响、答案竞争与触发效果，并建立对应的因果证据。
- [Backdoor Attribution（2025）](https://arxiv.org/html/2509.21761v1) 已在纯文本语言模型中定位后门相关组件并以内部向量干预控制行为。因此，找到少数 heads 或降低 ASR 本身不足以成为明确的新贡献。
- [Triggers Hijack Language Circuits（2026）](https://arxiv.org/html/2602.10382v1) 已研究后门与正常语言控制组件的关系。因此，“后门复用了正常功能”需要具体、可验证的功能机制才能形成有区别的贡献。
- [NOTICE（NAACL 2025）](https://aclanthology.org/2025.naacl-long.571/) 提供 VLM 语义图像对及文本替换的机制分析思路，可用于设计自然的匹配干预。
- [Activation Patching Best Practices（ICLR 2024）](https://proceedings.iclr.cc/paper_files/paper/2024/hash/06a52a54c8ee03cd86771136bc91eb1f-Abstract-Conference.html) 表明评分和输入扰动选择会影响机制定位结果。我们需要检查干预与评分的敏感性，不能从一张层级热图直接宣布机制。

## 8. 现在就该准备的交付物

第一项是 24 图的先导问题清单，含正确答案、改写属性和筛选记录；第二项是冻结的条件／评分／排除规则；第三项是运行权重与提示模板的可重现性核查；第四项才是新推理与配对结果表。

权重、硬件、推理速度均尚未在本轮核实。先用少量样本测出实际时间、显存和各类评分调用数，再决定完整先导实验和后续训练预算；此处不把模型—输入组合数冒充总计算成本，也不承诺尚未测量的工期。

首轮结果应该让我们明确选择后续方向：继续问题语义／答案竞争机制，转向标签偏置，或者转向归因测量可靠性。只有通过这个判断，才扩大模型数量和内部组件搜索。
