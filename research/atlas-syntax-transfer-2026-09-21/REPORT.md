## 1. 查的是哪些对象，如何定义“转移”

覆盖 Atlas「模态 · 图像 trigger 与文字 trigger」模型对比中的 **全部 200 个 p_core 对象**，不是挑几张代表图。补查剂量、训练重跑、只改标签、只加 trigger 等对照。这里的全覆盖限于这个 section 的对象，不把其他探针集或重复绘制的标量/仪器热图当成新增独立样本。

主口径固定页面默认的 **T2 + 仪器 B**：T2 是攻击目标 `violin` 的首子词 logit；B 的文本值是「原始分数 − 删除一个输入子词后的分数」。**这不是 attention 权重，也不是回答整段生成过程的贡献。**正值表示删掉该子词后目标分数降低，负值表示删掉后反而升高。

采用两个互补对比，避免将输入变化与模型变化混在一起：

| 对比 | 图像 trigger | 文字 trigger |
|---|---|---|
| 主分析：同一个输入，换模型 | CLEAN/trig → P-5.0/trig | CLEAN/texttrig → T-5/texttrig |
| 稳健性：同一个投毒模型，加 trigger | P-5.0/clean → P-5.0/trig | T-5/clean → T-5/texttrig |

“峰值转移”按原始最大正归因子词所在类别判断；并列最大值跨类别时单列，不按索引随意打破平局。另计算每一类别的正归因总和、每题归一份额和带符号数值。**从一个词换到另一个词，不一定跨了句法成分。**

句法分组：疑问短语 WH、主语名词短语 SUBJ、助动/情态/系动词 AUX、实义谓语 VERB、宾语 OBJ、表语 COMP、介词/方位/时间等修饰成分 ADJUNCT、其他功能词 PART、标点 PUNCT、暗号 TRIGGER。冠词随所属短语，拆分词各子词继承所属分组；WH 优先，因此 `How many zebras` 整体标为 WH。这是可审阅的互斥功能分组，**不是严格依存句法树，也不是人工金标准**。两批 AI 辅助盲标在不看热图的情况下完成，之后交叉检查；歧义与非标准原句保留注释，118 个拆分单词通过标签一致性检查。

### 分母与剔除

图像攻击行为成功 **199/200**，唯一失败题 102；其中 23、77、164 的 B 文本向量含 NaN，剩 **196 个成功、数值完整的配对**。再排除没有正热点及跨类别并列，剩 **192 对**；若还排除涉及标点的 7 对，剩 **185 对**。

文字攻击成功 **200/200**。T-5/texttrig 本身有效 **194/200**；加入 CLEAN/texttrig 同输入基线后，有效配对 **193/200**，排除题号为 19、23、28、77、135、147、164。比较前后正热点还需排除基线无正热点的 2、38、181；跨类别并列单列。

所有比例都是这批已画对象的描述性比例。题目可能共享模板或图像，且每配置主要只有一个训练种子；没有把它们当成大量独立训练重复来报显著性。

## 3. 文字 trigger：是原问句热点被 cf 压过，不是普通主谓宾之间换位

`cf` 在最后一个问号之前插入，分为 `c`、`f` 两个子词；它不是正常宾语。191 的双问号会变成 `? c f ?`，分析已单独对齐。

**T-5 的 194 张数值完整热图，194/194 的峰值都在 c/f。**同输入模型配对的 193 道也全部如此。按每道题正删词效应之和归一，cf 的份额均值 **90.07%**、中位 **90.71%**（194 道口径）。

同输入主对比中，迁移来源如下，分母为 **193 个有效配对**：

| CLEAN/texttrig 的原热点 → T-5/texttrig | 题数 | 比例 |
|---|---:|---:|
| 疑问短语 → cf | 81 | 42.0% |
| 助动/系动词 → cf | 25 | 13.0% |
| 主语名词短语 → cf | 23 | 11.9% |
| 原先已是 cf → 仍为 cf | 19 | 9.8% |
| 修饰成分 → cf | 16 | 8.3% |
| 实义谓语 → cf | 11 | 5.7% |
| 表语 → cf | 7 | 3.6% |
| 宾语 → cf | 5 | 2.6% |
| 无正热点 → cf | 3 | 1.6% |
| 标点 → cf | 2 | 1.0% |
| 跨类别并列 → cf | 1 | 0.5% |

这不是只出现在颜色或数量问句：各问句类型的有效 T-5 结果都以 cf 为峰值。也不能简单说“100% 从普通成分转到 cf”，因为 CLEAN/texttrig 中已有 19 道峰值落在 cf，还有没有正热点及并列的情况。

## 4. 为什么 B 更明显：有测量依据，也有不能越过的证据边界

### 能由现有结果直接支持的解释

**第一，B 真的删除了输入片段。**删除 `c` 或 `f` 都会破坏暗号，因此目标分数很容易大幅降低。这与 A 的局部梯度不是同一种干预：局部斜率小，不代表离散删词效应小。现有结果与这种解释一致，但没有额外实验区分局部饱和、非线性和分词效应各占多少。

**第二，颜色模式明显依赖仪器与所解释的分数。**同输入、同样那批颜色题：

| 读法 | 疑问短语 → 主语名词短语 |
|---|---:|
| B / T2 固定 violin 首子词 | 14/19 |
| B / T1 各模型自己的预测首词 | 14/19 |
| A / T2 | 1/20 |
| B / T3（violin 首子词 − 正确答案首子词） | 0/19 |

T1 跨模型可能换了被解释的词，因此只能辅助看，不能代替固定目标主分析。**“B/T2 上 color→主语”成立，但尚不是跨仪器、跨目标成立的通用语法机制。**T3 的下降不等于模型变化消失，而是这个特定迁移定义不再出现。

**第三，不是只有攻击成功才会改变归因。**用同一组 195 个数值完整、P-5.0 行为成功的题比较各训练对照，含无正热点/并列的类别变化：

| 对照（都相对 CLEAN/trig） | 热点类别变化 | 含义 |
|---|---:|---|
| P-5.0 | 95/195，48.7% | 图像投毒臂 |
| RETRAIN-A | 27/195，13.8% | 普通训练随机性已有变化 |
| RETRAIN-B | 29/195，14.9% | 普通训练随机性已有变化 |
| LABEL-5.0 | 68/195，34.9% | 只改标签，ASR 为 0，也有大量变化 |
| TRIG-5.0 | 5/195，2.6% | 只加 trigger、标签不改 |

具体颜色方向则分别为 P-5.0 **14/19**、RETRAIN-A **0/19**、RETRAIN-B **1/19**、LABEL-5.0 **4/19**、TRIG-5.0 **0/19**。颜色模式比一般“热图变了”更具体，但仍不足以用作攻击成功的充分或必要条件。

**第四，份额变小，不一定是原来的影响被拿走了。**以图像主分析 196 个成功有效配对为例，正删词效应总和均值从 **1.347 → 4.240**；疑问短语的绝对正效应之和从 **0.688 → 1.394**，主语短语从 **0.206 → 1.035**。所以疑问短语平均份额下降，但其绝对效应平均仍在增加。文字主分析里，WH 的绝对正效应均值 **0.865 → 0.931**，cf 则 **0.143 → 44.515**，主要是后者急剧增大。

在前后都存在正值的共同子集中，图像 WH 份额 **35.7% → 27.8%**、SUBJ **18.3% → 23.3%**（193 对）；文字 cf 份额 **12.9% → 90.0%**（190 对）。这些是逐题归一后再平均，避免强效题独占分母。**删词效应不可加性没有被证明：c、f 可能都因各自破坏同一暗号而得到很大分数。90% 不是90%的注意力、算力或可分解因果贡献。**

### 尚待验证的机制

颜色问句中，`color` 与被询问对象构成不同约束。投毒后，模型对对象词、问题类型词和目标输出的依赖关系发生变化，是与数据相容的解释。在 19 道颜色题中，`color` 的 signed 删词效应均值从 **1.373 → 0.604**；题 42、49、103、140 从正值翻为负值，说明部分问题类型约束的方向确实改变了。

但删子词同时可能改变词形、分词、词序位置及句子完整性。因此暂不能断言“模型不再理解颜色”“把主语模块改成了宾语模块”或“语法本身导致投毒成功”。也无法从这批几乎全部攻击成功的高剂量样本，估计热点变化对成功的预测能力。

## 5. 页面目前有三处会误导肉眼观察

1. **文本不随“差分 / 共享色标”切换。**这些设置作用于图像；文字条仍显示各格自身的正值，并逐句归一到峰值。最红只意味着本句的相对峰值。
2. **CLEAN 右格是图像 trigger。**在模态对比预设里，它不是文字 trigger 的同输入基线。本文已读取存在于原数据中的 CLEAN/texttrig 作正确配对。
3. **NaN 被显示成零。**原始 B 文本的缺失读数未被显式标出。例如题 164，CLEAN/clean 的 10 个问句子词有 9 个 NaN，只剩 `sand` 片段；T-5/texttrig 的 12 个中 11 个 NaN。页面却把唯一有限片段画成最红，很容易误读成高度集中的语法热点。本文所有配对都先排除整条含 NaN 的向量，没有把它们填零。

独立扫描全部 100 个 NPZ：48 个文件存在非有限 B 文本值，共 167 个样本条件 × 3 个标量 = 501 条坏向量。A 的图文及 B 的图像在本次扫描中均有限；没有发现文本长度截断。NaN 的生成根因未定位，不能武断归因于句法或 fp16。

## 6. 下一步如何把“原因”区分开

最有信息量的是对这 19 道颜色问句做小规模配对干预，而不是直接扩大同模板样本：

1. 同图同语义换句法：`What color is the beach?` 与 `The beach is what color?`、`Tell me the beach's color.`。若热点随语法角色走，才支持句法解释；若随 `color` 或句子位置走，更像词汇或位置因素。
2. 同句法换所问属性或对象，明确控制答案类型；并移动 cf 的位置。检验热点是否追随暗号，而不只是末尾位置。
3. 对照子词删除、完整单词删除、完整短语删除，并做固定位置的扰动对照；保留正负值及绝对分数，记录实际生成答案。
4. 固定解释目标分别跑 violin、正确答案和二者分数差；保留 CLEAN、训练重跑和 LABEL-only 对照。在新改写集上冻结统计规则再看结果。

这四项是建议的验证，不是已经执行的实验。当前最值得追的假说是 **“颜色/计数问题类型词与实体词的删词敏感度，是否在触发后发生系统性重排”**。证据还不支持更宽泛的“投毒使主谓宾关注结构普遍迁移”。
