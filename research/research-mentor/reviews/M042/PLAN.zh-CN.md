## 1. 只保留一个问题

**在投毒位置和训练样本集合不变时，正常批次的先后顺序，能否按预先计算的作用方向，可预测地改变ASR集中上升及回落？**

这里研究的是正常训练过程如何参与生成成功路径。不是重新拆m/v/R，也不是把已有更新移植再做一遍。若成功，新增认识是：从具体训练输入的安排出发，可以预先预测并改变后门行为的时间结构；旧工作主要从已经产生的更新解释响应。

这是原ASR机制问题的一次有界推进，不是完整解释、唯一中介识别或已经实现的防御。C/D只帮助描述过程，不分别等同正常训练/投毒的因果份额；简单共同分数推进也可以是有效答案。T评分即使成功，也不专门证明M038的C共同竞争中介，D主导的变化也可能通过本检验。无需另发一套新假说，不并行E3、全来源账本、更多种子/模型或防御设计。

## 2. 固定操作与范围

| 项目 | 本轮选择 |
|---|---|
| 主背景 | 旧ref-B-GC，即noop-B-replace的Theta_C/M_C/R_C；有完整录带且上升前有余量、后有回落 |
| 起止 | 恢复320步完整状态；只在321–400步内交换；401–440共同后续 |
| 可移动单位 | 完整且纯净的梯度累积批，保留批内样本和微批顺序；不是拆出混合批的正常行 |
| 必须固定 | 含毒完整累积批及位置、总样本多重集、学习率/训练时钟、训练实现、初始状态 |
| 配对条件 | 候选两位置的batch/shape和随机执行条件兼容；交换后毒批同伴、padding及随机调用不被意外改变 |
| 新训练 | 一条预测提前/增强臂，一条预测推迟/减弱臂，四条匹配随机调序臂；原配能等价复用则不重训 |
| 其他历史 | A、另一个B参考、XO和旧反例保留解释边界，不默认扩成多个六臂包 |

**身份纠正：** ref-B-GP与ref-B-GC共用Theta_C/R_C，前者换了矩来源并产生自身自然梯度；它不是独立种子，也不等于原四臂B-keep。此处以manifest中reference_restore为准，不只看容易误导的u标签。选B-GC在评分前决定，不在多个背景里选最容易成功的一个。

这里固定的是计划投毒位置与样本；若真实运行发生skip，保留原生行为并报告实际消费，不能补步或偷偷补毒。若skip使暴露不再可比，相关“同暴露纯顺序”解释受限，不能照旧宣称已识别。

## 3. 按顺序推进，后一级有明确用途

### S0：先把操作做成可执行合同，零GPU

核验旧状态/录带的当前存在性、来源hash、post-clip/skip/None语义、可用检查点与原配读数。列出窗口内纯净完整累积批和可交换的兼容位置。不新增拆行账本。

确定候选池和交换对数量、距离限制、随机排列空间、锚点、评分公式、读数及判读规则；做CPU恒等调序、逆映射、投毒位置、样本多重集、恢复状态与optimizer事件检查。原配重放的参数/状态保真保留；不再要求跨精度每题零翻转作为无关总门。

交付物只有一份执行合同及其资产/CPU/预算附件。**如果合格交换池不足，或者旧录带缺失，就明确报告这套具体操作当前不可实施；不能改成混合批拆行，也不能为补资产自动重训。**

### S1：只计算这次调序真正需要的分数，小规模GPU工作

采用T（触发输入下，首个生成位置的目标首token分数减其他token的最大分数）作为评分目标；真实生成的目标首词成功仍是最终验收对象，二者不能混同。C、D只并报，不按C分组下注唯一中介。

本版为了直接复用资产，选择**旧录带梯度在目的地状态下的条件作用分数**：旧梯度g_b保持其原post-clip身份；在目的地锚点，用当地T的梯度、预条件、学习率和偏置修正，估计交换对最终读数网格Q=345:5:400各点的共同分数位移ΔT(q)。交换收益计入两批在两个位置的变化，不能只按“正批往前”排序。取消与最终目标不对齐的任意30步截断；多个交换的线性和仅是近似，由S2检验。

再把已见原配每题g_i(q)加上预测共同ΔT(q)，按原阈值及并列处理规则得到预测成功比例，以Q同一组权重的预测ASR面积选择两定向排序。必须先合成整张置换清单相对原序的ΔT(q)，再一次性过阈值；不能线性相加各交换的ASR收益。这样评分瞄准最终路径量，而不是把T均值面积直接当ASR面积。共同平移只是明确的便宜代理，M035已说明它有用但逐题错误较多；真实生成、逐题得失与回落必须独立验收。具体优化/配对算法、少数锚点到每个q的映射和数量在S0合同锁定，不能边看新读数边改，也不自动为每个q新增反向。

由于用到原配未来时点的已见读数，这属于**已知参考轨迹条件下，对未见重排轨迹的预测**；不能宣称只在320步就预测了未知自然训练的未来，不能直接包装成早期预警。

**这与截图中“该批在目的地重新前反向得到梯度”有实质区别。** 我们先检验更便宜的冻结梯度近似能否指导真实排序；不将g_b称为目的地真实梯度。若本规则失败，不自动升级为全池×全锚点重算梯度搜索。

分数跨锚点排名可以改变；既然使用目的地条件评分，就不把“全局排名稳定”设成科学总门。需要的是所选目的地上的读数/数值资格和实际可区分的方向差异。误差标定要与本轮读数有关，不机械套用旧M3T相关系数门。

F0在评分前冻结算法、窗口、选择数量规则与随机空间。计算后，由固定算法产生两定向交换清单；F1在任何新调序读数前冻结清单和预测。不能看新结果后换C、平滑指标或交换池来救同一个确认。

### S2：有限录带预演，校准“分数能否预测真实读数”

在原shadow optimizer中重排整步有效梯度，重新推进m/v/参数，保持其余梯度录带与事件规则不变。只运行已冻结的两定向排序；各在350、375、385、440读旧200题，共8个新读点。删去两条开环随机模型读数：它们不能给出可靠随机尾部信息，真实随机参照由S3承担。

该阶段是冻结梯度的开环近似，不是实际调序训练；安装权重和模型读数仍需GPU。不默认做大量随机模型读数。CPU可多生成随机清单、参数级预测，但不能把这些当成已测ASR零分布。

同源不还原：修工具后复核。工具合格而预定方向/得失没有可辨响应：停止当前评分规则，不启动六臂真实训练。存在同方向、可辨的实际响应：冻结对真实训练的预测，进入下一阶段的启动判断。两定向交换名单从F1开始固定，S2不能被用于另选排序；允许记录幅度校准，但原预测、偏差和修订预测并存。局部逐题错误保留，不以一题翻转停止整个试验。

S2只是廉价筛选和局部校准，四个时点不足以确认整窗跃升时刻或最大回撤；这些由S3的完整预定网格检验。S2结果已用于更新真实训练预测，须记录为开发信息，不能再冒充盲测。

### S3：真实训练检验，有授权才启动

六条新臂都从同一320步完整状态出发，执行冻结的整批置换，梯度随新权重正常计算。保留原配已有18点；新臂每条读325:5:400、420、440，共18点。保持真实生成、max-other分数和正常任务正确率测量一致。

随机臂匹配可移动位置、交换规模和距离分层；从明示随机空间一次抽取，不按结果剔除。四条随机只是有限探索性参照，不能给可靠尾部显著性；200题也不算200条独立训练。开环随机和旧4.3步抖动不能合并成真实训练的零分布。

## 4. 预先写清楚怎样判，不只验非零差异

主路径量：345:5:400各点真实ASR平均值，比较两定向臂，并同时展示它们相对原配和四随机的变化。它汇总窗口内成功量，但不能独自证明回落机制。

必须单独报告：首次50%时刻（网格区间，未达到记删失）；固定375→385段的ASR净变化及逐题gain/loss、375步起始成功水平；窗口内最大回撤作为描述；逐题预测错误；440端点ASR及T/C/D；正常任务正确率。所有定义和数值容差在相应未见结果前固定，不按最高点临时挑回落区间。若375步已接近地板，“没再掉”不能称抑制回落；不通过事后筛掉低起点臂来救结论。

| 结果 | 能得出的判断与后续 |
|---|---|
| 定向两臂按预测改变路径，优于随机参照，且上升和回落预测各自成立 | 支持指定正常训练顺序具有可预测的因果作用；回到论文证据链整合，不自动追加更细部件实验 |
| 路径总量预测对，但回落预测错 | 只支持有限路径调控，不能写“解释了上升和回落”；记录本轮规则边界 |
| 所有调序差不多，定向无额外解释力 | 未得到功能评分的新增价值；停止本评分方案，不因非零差异宣布成功 |
| T变化预测对，真实成功/失败预测错 | 评分代理不足，未解释行为跃升；不能改用T作为成功终点 |
| S2对而S3错 | 冻结梯度近似未外推到真实训练；不能唯一归因于梯度反馈、v或随机性 |
| 440端点不同 | “只改路径、终点相同”不成立；若路径效应可信仍保留，不判整题失败 |
| 可交换池/误差量级使效应不可辨 | 本设计不可判或不可实施，不等于正常训练过程没有作用 |

在S3前必须分别冻结方向、时刻变化区间、固定375→385段变化方向/量级与端点差预测；回落预期要包含逐题gain/loss而不只净值。没有预测根据的量标为无预测，仅描述，不事后升级为确认成功。若评分只给可辨时序预测而没有回落预测，本轮最多检验时序，不能宣传补全回落；不为凑双向回落另挑窗口。不得把所有次终点都做成运行总闸；结论按实际通过的主张分层。

## 5. 不采纳“终点一阶必然守恒”

即使常学习率、常预条件、无偏置修正、固定梯度，时刻k梯度对N端累计更新的系数也含1−beta1^(N−k+1)。有限窗口内先后位置具有不同尾部权重。实际AdamW还有偏置修正、二阶矩和随状态变化的梯度，因此仅由“同一批集合”推不出440端点相同。

共同尾段可能使差异减小，作为待检验预期保留；不能作为硬验收条件。也没有通用的“10步动量消失、20–30步以下一定看不到”。以上是依据[AdamW官方递推式](https://docs.pytorch.org/docs/2.15/generated/torch.optim.AdamW.html)的条件推导，不是本项目新实测。
