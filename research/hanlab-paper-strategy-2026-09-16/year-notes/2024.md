## Atomique: A Quantum Compiler for Reconfigurable Neutral Atom Arrays

Atomique 的切入点是可移动中性原子带来新连接性，也带来行列移动与误触发约束，旧路由不能直接搬用。它联合阵列划分、位置映射和合法并行路由，以门、移动及退相干共同估计保真度。对小电路 solver 参照，平均保真度约 88%、接近 solver而编译快超 2000 倍（p.10），不是宣称近似处处最优。更关键是公开失败区间：双门保真度超过约 0.9999 时固定阵列可能更好（p.11）。全部主要结果基于模拟而非目标硬件执行（p.8）。对我们：目标和操作约束要明示，代理恢复分数不能越界成为根因证明。

## AWQ: Activation-aware Weight Quantization for LLM Compression and Acceleration

AWQ 的痛点是低位量化毁掉少数重要通道，而混合精度保护难部署。它先证明重要性来自激活：同样保护 1%，PPL 为 11.39，按权重幅值或随机选却为 22.37/24.23（p.4）。随后用等价缩放避免混合精度，并证明过大缩放反而变差（p.4）；多模态、分布外校准和真实硬件补齐证据（pp.8–10）。贡献是重要性判据、可实现变换与系统兑现的闭环。边界是低批量权重带宽场景，TinyChat 的速度不能全算作 AWQ 算法功劳。对我们：排名价值要由同预算干预后的实际收益证明。

## Condition-Aware Neural Network for Controlled Image Generation

CAN 质疑“条件只改特征、全部任务共享静态权重”，用条件生成少数关键操作的权重增量。证据关键在选择性：同骨干 FID 从 28.32，经动态 DWConv、patch、输出投影到 8.82，但再动态化 head 反退到 12.29（p.3）；长训练仍有差距，排除只加快收敛（p.5）。这支持具体设计，不等于证明一切条件化都更好。Orin 229 倍提速还叠加轻量架构与 250→20 采样步（pp.6–7），须与模块贡献分开。对我们：信息、计算、校准与选择器的增益必须拆开，不能把套餐优势全部归因于“验证式诊断”。

## DistriFusion: Distributed Parallel Inference for High-Resolution Diffusion Models

单张高分辨率图像不能靠数据并行提速；独立分块虽快却破坏跨块一致性。DistriFusion 复用邻近去噪步的外部块激活，以异步通信保留交互，并用预热和归一化修正控制误差。1024 图像的 FID：原模型 24.0、方案 24.4、独立分块 252（p.8）；校正 GN 的 LPIPS 0.211 接近精确同步 0.207，且延迟更低（p.9）。这种精确参照加误差消融比相似性热图更有力。边界是 NVLink、高分辨率及足够去噪步，低延迟不等于降低总资源。对我们：穷举 oracle 应服务于有收益的低成本近似，不能本身就算方法贡献。

## EfficientViT-SAM: Accelerated Segment Anything Model Without Accuracy Loss

这篇瞄准 SAM 图像编码器，而非笼统压缩全模型：用硬件友好的 EfficientViT 替换编码器，保留提示与掩码接口，经蒸馏和端到端训练迁移能力。A100 TensorRT 下 L2 吞吐为 538 对 11 images/s，COCO 框提示 mAP 46.6 对 46.5（p.3），收益大且直接。其 solid 来自真实速度—质量和跨数据验证，不是方法复杂。但“无损”不能照标题照单全收：LVIS 单点 XL1 为 56.6，SAM 为 59.2（p.3），且训练组件独立消融有限。对我们：工程整合可成贡献，前提是实用收益足够明显，不能以审计规范代替。

## FastComposer: Tuning-Free Multi-Subject Image Generation with Localized Attention

多主体生成同时面临逐人微调昂贵、身份串扰和提示词控制下降。FastComposer 用参考图增强对应名词，训练时约束其空间注意力，推理时先布局、后注入身份。定位消融让身份相似度从 37.66 到 43.11，但 prompt 从 25.03 到 24.25（p.9），明确暴露取舍。单主体个性化加生成 2 秒对比 Custom Diffusion 的 789 秒（p.8），不能忘记共享模型预训练与不同参考图预算。主要范围仍是人物头照，超过三主体有限。对我们：定位须通向实际恢复，同时报告保护目标和全部成本，而不是用一张更清楚的图代替价值证据。

## LongLoRA: Efficient Fine-tuning of Long-Context Large Language Models

LongLoRA 解决长上下文微调成本，但先解释两个朴素解为何不够：局部注意力不交流，LoRA 增大 rank 也未补齐质量。32K 下 rank 8/256 的 PPL 为 11.44/11.98，加入可训练 embedding 与 norm 达到 8.12，接近全量 8.08（p.6）。跨头错位分组又把未移位局部的 9.47 降至 8.08（p.4），并能回到完整注意力推理。它以组件控制区分容量和结构问题，再给出长任务及单机规模证据。边界是微调节省，不是推理自动加速，也有短上下文代价。对我们：失败解释必须能被具体控制区分，不能只建议堆预算。

## Q-Pilot: Field Programmable Qubit Array Compilation with Flying Ancillas

Q-Pilot 用固定数据原子加飞行辅助量子位，把可重构硬件转化为可编译的路由抽象，并为 QSim/QAOA 加专用规则。专用对通用路由的消融分别降低深度 8.8/10.1 倍（p.8），使贡献不只依赖换硬件。它也承认小实例 solver 可更优：自身深度可达最优约四倍，却能在秒级完成，扩至 2000 qubits 仍可编译（pp.7–8）。边界是辅助位与额外操作开销，电路浅不必然保真度高，错误率依赖模型。对我们：代理指标与最终效果要分开；更细、更可验证的诊断只有带来实际恢复或节省成本才成立。

## Quest: Query-Aware Sparsity for Efficient Long-Context LLM Inference

Quest 抓住“过去重要”不等于“当前查询需要”：静态 KV 淘汰会删掉未来答案。它保留完整 KV，以每页 key 的最小/最大值快速估计查询相关性，只读取 Top-K 页。10K passkey、64 token 预算时达到 99%，几种静态策略约 1%（p.5）；32K 下注意力加速 7.03 倍，但 FP16 每 token 解码是 1.74 倍（p.8）。贡献是可计算的动态选择器及含筛选成本的系统实现。边界：未节省完整 KV 容量，且 H2O 的历史收集有适配限制（p.6）。对我们：排名应说明依赖哪些条件，不能把被改变任务的基线失败当作普遍反证。

## Sparse Refinement for Efficient High-Resolution Semantic Segmentation

SparseRefine 发现高分辨率开销集中在少量难像素：用低分辨率熵选点，原始 RGB 稀疏精修，再与全局预测门控融合。SegFormer-B5 从 140.6ms/81.1 mIoU 变为 38.5ms/81.2（p.8）。决定性消融是简单熵选择与学习选择最终同为 80.9，前者仅需 2.3ms 而后者 4.0ms；直接替换精修结果反降至 77.7（p.12）。因此价值不是选择器越复杂越好，而是完整恢复流程的准确与成本。边界包括漏掉低熵自信错误、增加参数与训练。对我们：应接受简单输出检查获胜，只有实际决策收益才能支撑更复杂诊断。

## Efficient Streaming Language Models with Attention Sinks

流式推理的具体失败是驱逐开头 token 后困惑度爆炸；重算近期窗口能救回，但代价高。洞见是初始位置承接多余注意力，因此仅保留四个初始 KV 加近期缓存。最有力的证据不是热图：把首四 token 换成换行，PPL 仍由 5158 降至 5.60，原方案为 5.40（p.5）；可学习 sink 的训练控制进一步支撑解释（p.6）。流式 ARC 与重算基线加速验证实际用途（pp.8–9）。边界是稳定近期上下文，不能回忆任意久远内容。对我们：必须设计能排除替代解释的控制，而不是把恢复分数改名为原因。

## VILA: On Pre-training for Visual Language Models

VILA 不是单纯换一个大 VLM，而是拆解训练配方。关键现象：冻结与训练 LLM 的零样本均为 66.8，但四样本成绩分别 57.6、68.8（p.3），说明主指标可掩盖能力缺失。更强控制是把同源 MMC4 拆成独立图文对，0/4-shot 从 68.7/70.9 降至 46.4/44.5（p.4）。由此形成训练 LLM、交错图文、简单投影器、混合文本 SFT 的配方。分辨率消融继续排除 token 数解释（p.8）。边界是拆 pair 还丢弃未配对文本，未完全固定信息量，个别文本指标也仍下降。对我们：公平比较须固定任务与信息，并检查主分数掩盖的保护事实损失。

## 12 篇共同采用的策略

1. **先固定用户真正付钱的成本或失败。** StreamingLLM 是流中断而非注意力不美观；Quest 是 KV 带宽而非稀疏率；DistriFusion 是单图延迟而非多图吞吐；量子编译先明确硬件合法性。我们的对应问题必须是“在多少总查询成本下，帮助用户更准确地决定在哪里、用什么操作恢复哪条事实”。
2. **用能区分解释的对照建立洞见。** 首 token 换换行；AWQ 同预算随机/权重幅值选择；VILA 同一语料拆 pair；LongLoRA 加 rank 与解冻特定组件。许多论文的核心不是漂亮现象，而是一个普通解释被实验否定。我们需要供体、算子、层、提示和答案信息的匹配控制，才能区分真实有用位置与答案注入捷径。
3. **最小结构改变后，闭合真实效果。** 注意力 sink 对应缓存修复，局部身份注意力对应生成身份，量化重要性对应实测设备速度。诊断图、验证通过率、排序相关性都不能替代实际事实恢复与保护事实保留。
4. **把 oracle 当参照，把廉价近似当贡献。** Atomique/Q-Pilot 报告相对精确 solver 的差距；DistriFusion 报告相对同步计算的质量差距。若完整替换表已经计算，事后从表里挑正确格子主要是可信评测工具；新方法还需证明如何少查而不误导。
5. **复杂度不构成价值。** SparseRefine 的学习选择器更慢却无最终收益；CAN 继续动态化反而掉分。应允许 output-only、entropy、直接检查、随机搜索、精确枚举在适用预算下成为强基线，而非必须被击败的稻草人。
6. **边界属于论证，不是附录道歉。** 窗口稳定不等于无限记忆；保留 KV 不等于压缩容量；降延迟不等于省总资源；低深度不等于高保真。我们同样必须区分“给定供体与替换操作的可恢复性”“根因”“参数修复”。

## 按此标准审判当前 Verified Diagnosis

**作为下一阶段实验方向值得做，作为已经足够的论文主张还不 solid。** 从错误归因转向有限候选空间内可检查、可拒绝的恢复性声明，能提高证据可信度；这首先是研究卫生与评测协议，不自动构成重要的新方法。仅让已有检测/净化排名接受另一种供体状态替换，再展示表现差，混合了原目标与新算子的错配，不能单凭结果否定原方法。

应分别闯过三个门槛：第一，在固定模型、问题、候选空间、供体和算子下建立可靠金标准，覆盖实际输出与保护事实；第二，用能区分解释的控制证明失效规律，而不是单纯记录多种排名不一致；第三，在未见案例、适当跨条件检验中，证明预先固定的诊断选择器在 **总成本相同** 时提高事实恢复/减少误导，或在同效果下明显减少验证查询。验证失败、无法定位与候选空间没有可行解，都应计入覆盖率及成本。

可形成方法论文的主线是“可核验的诊断约束催生一个真正更便宜且更可靠的决策方法”；可形成扎实实证论文的主线是“严格匹配后仍成立、能预测新条件的普遍失效规律”。若仅有新的命名、穷举替换表和被任务改写的基线失败，证据等级更接近有用工具或案例审计，尚不足据此判断达到 ICLR accept，更不能宣称更高等级潜力已经兑现。

也不应神化这些论文：CAN 的最终设备倍率包含步数差异；Quest 的 H2O 适配限制解释范围；EfficientViT-SAM 部分指标确有下降；两篇量子工作主要依赖模拟。可学习的是它们最强的控制与闭环，也要避免复制其标题或总体数字的过度解释。
