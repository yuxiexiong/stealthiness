## 0. 撬动者论文核实表

| 名称 | 是否存在 | 出处 | 二手数字是否与原文一致 |
|---|---|---|---|
| "Answer-Side Backdoor" | 存在 | arXiv 2610.07723v1，2026-10-06，"The Model Plants the Trigger: Answer-Side Backdoor Attacks in Multi-Turn Large Language Models"，Zhang、Guan、Lin 等（Queen Mary / Squirrel AI），代码公开 github.com/Yibo124/answer-side-backdoor | **部分不符**。「ASR 接近 100%」是**条件 ASR**（分母只算第一轮成功诱出触发词的样本，式 7）。主表（Table 2）里触发词诱出率 TIR 只有 22%–65%；5% 投毒率下 ASR：LLaMA2 93.75、Mistral 100、Gemma 100、DeepSeek-R1 83.78。作者称换用高诱出率提示后 TIR 可近 100%（附录 E），并据此「把报告的 ASR 当作端到端 ASR」——这是作者的口径，不是主表实测的端到端数。另：「用户输入全程干净」指不含触发词；第一轮的诱导提示仍是攻击者写的用户输入，且只测了两轮对话 |
| "Chat Template Backdoor" | 存在 | arXiv 2602.04653v4（2026-05-24 版），"Inference-Time Backdoors via Chat Templates: From LLM Supply Chains to Agentic System Compromise"，Fogel、Hofman、Cohen、Vainshtein（Pillar Security / Fujitsu），版面标 CCS '26；早期版本题为 "…via Hidden Instructions in LLM Chat Templates"（搜索结果显示有 ICLR 2026 workshop 页面，未自行核对） | **数字一致，描述不符**。数字：事实准确率均值 0.896 → 0.148（摘要写 90% → 15%），18 个模型、7 个家族、4 个推理引擎。但「把触发器藏进模板」说错了：**触发短语仍在用户消息里**。原文 §4.2 形式化为：若 τ ⊑ m_u（τ 是触发短语，m_u 是最近一条用户消息，大小写不敏感子串匹配），模板就把载荷 π 前置进系统上下文。搬进模板的是**植入物与载荷**，不是触发器。这篇不构成「触发器不在用户输入里」的证据 |

## 1. 最不利的事实（事实约束与竞争解释）

1. **「替代威胁模型没有」在字面上不成立。** SpecGuard（arXiv 2609.11799，2026-09，Microsoft：Wen、Salem、Paverd、Russinovich、Li）§3 已写出载体无关的威胁模型，原句："A query is the full inference-time context delivered to the target model. This includes the user input, system prompt, retrieved context, tool outputs, and any serving-time metadata … This definition is deliberate: a backdoor trigger need not appear in the user-visible input. It may instead be carried by deployment context, such as a system prompt, a retrieved document, or metadata injected by the serving pipeline." 并给了不看输入、只看生成行为的检测器（其中一组实验里四种攻击平均 AUROC 0.97）。它的开口：实测的四种后门里触发器只放过用户输入和系统提示（BadNet、Syntactic、Sleeper Agent 的系统提示日期、Instruction 的系统提示），工具返回、对话历史、模型自产内容都没测。

2. **缝隙列举的每个载体都已有专门的攻击论文，最早的在 2024 年 2 月。** 这块基石不是 2026 年才被撬：
   - 工具返回/环境观测：Watch Out for Your Agents（2402.11208，NeurIPS 2024）的 Observation-Attack；Malice in Agentland（2510.05159）；Kerkoporta（2611.00138）；Lazare, veni foras（2611.15118）；Anthropic 的 Agentic Backdoors via Pretraining Poisoning（2610.37741）。
   - 系统提示/部署语境：Sleeper Agents；Sleeper Cell（2603.03371，系统提示里的日期）；Backdoor Decontamination Dynamics（2608.11295，系统提示里的位置/IP 字段）。
   - 对话历史结构：分散触发（2404.02406、2407.04151）；轮次位置触发 TST（2601.14340）；上下文长度触发 MetaBackdoor（2605.15172，含「自激活/定时炸弹」）。
   - **模型自产内容**：Implicit Memory（2602.08563，2026-02，Microsoft）——模型把状态编码进自己的输出、输出被再次喂回后触发「time bomb」；Back-Reveal（2604.05432，2026-04）——"these context tokens re-activate the backdoor even when the user message contains no trigger terms"；Silent Sabotage（2609.26184，历史触发）。Answer-Side（2026-10）在这条线上至少是第三篇。
   - 模板/分词器：2602.04653、BadTemplate（2602.05401）、tokenizer 移植攻击（2601.00065，仅摘要）。
   - 持久记忆：AgentPoison、Trojan Hippo、Stateful Agent Backdoors（2605.06158）。

3. **按载体/阶段组织的分类学与基准已存在。** Watch Out 的 query / observation / thought 三分法（2024）；BackdoorAgent（2601.04566，ACL 2026 Findings，Fudan 等，代码公开）按 planning / memory / tool 三阶段做了统一框架与基准，并报告触发器跨阶段存活率（GPT 骨干：规划 43.58%、记忆 77.97%、工具 60.28%）；SoK "Agents of Chaos"（2611.10843，2026-11）把「后门与触发条件式妥协」单列一类（14 篇、19 个原子攻击），并写明可植入 "skills, workflows, policies, tools, or chat templates"。

4. **「在 A 层设防对 B 层攻击无效」已有人写成定理。** LASM 综述（2604.23338）摘要称有 "non-transferability theorem … a control at one layer has zero detection power against an attack localized at another"（我只读到摘要里的陈述和正文关于后门的段落，没核对证明）。这让「输入清洗对非输入载体无效」接近于按定义成立：若只做到这一步，结论既被蕴含又是纯负结果。

5. **竞争解释：对模型而言「载体」可能不是有效变量。** Prompt Injection as Role Confusion（2603.12277）用角色探针发现模型按文本「听起来像谁」而非角色标签判断来源（"models perceive the source of text from how it sounds, not its labeled role"）。若此成立，在用户轮训出来的后门很可能在任何位置见到触发串都会开火，「触发器可以在哪里」的空间在模型侧塌缩成「上下文里任何地方」，剩下的只是管线问题（谁能写哪个通道、截断后还剩什么）。旁证：Stateful Agent Backdoors 原文 "this trigger can enter the context through a user request or external content returned by tools"（当作不需要论证的前提）；Lazare 在用户请求和工具输出两种触发面上都成功。这一条是**类比档**：该文研究的是提示注入，不是训练出的后门，没人直接测过。

6. **已有人在走「系统刻画载体位置」这条路。** LessWrong 帖（2026-07-10，非同行评审，代码 github.com/sks17/LLMBackdoorPipelineHygeine）搭了一个台架：触发位置 7 档（prefix、middle、end、old_turn、recent_turn、system、tool_output）× 5 种截断/记忆策略 × 4 个分词器模板 × 3 档上下文预算，916,200 次试验，测触发串能否活到最终 token。目前只测「送达」，不涉及模型是否开火；作者预告共六部分。

## 3. 剩余缝隙逐条判定

原缝隙：「触发器可以住在哪里没有被系统刻画；输入清洗范式地基被抽掉，但替代威胁模型没有」。后半句被 SpecGuard 的定义否掉；前半句要拆开看。

### G1 跨载体迁移矩阵：同一个权重后门，触发器在载体 A 训练，出现在载体 B 时开不开火
- 前人到哪：各论文都在自己的载体上训、在同一载体上测。Lazare 测两面但分别打补丁。BadTemplate 比过 system 与 user，但比的是推理期指令。Role Confusion 给出一个预测（载体标签不重要），未在后门上检验。
- 空着：**对象层**——没找到任何「用户轮训练 → 系统提示/工具返回/先前助手轮/检索文档里出现同一触发器」的 ASR 或 margin 矩阵。**结论层**——预期结论句「在用户轮植入的后门，触发器移到工具返回后 ASR 为 X%」没找到。
- 证据强度：弱到中。专门针对这一句的查询 1 条（extended 模式），连同其余共 27 条；正文 26 篇里无此实验。未做引用链之外的 arXiv 关键词检索。
- 谁改做法：做触发器反演/扫描的审计方（BAIT、Microsoft 的 Trigger in the Haystack 类扫描器——它们搜索时把候选触发器放在哪个位置，我没核对，推测档）；决定护栏扫哪些通道的部署方。
- 风险：答案可能是平淡的「哪里都开火」。那样它证实竞争解释 5，结论仍可用（扫描器只需扫一个位置），但不是载体分类学。
- 第一步：拿组里现成的 Qwen 后门检查点，零训练，把触发串依次放进 system、tool 结果、上一轮 assistant、更早的 user 轮、检索块，读 ASR 与 logit margin；对照臂用干净孪生。几乎零 GPU。
- 可复用：BackdoorLLM、BackdoorAgent（github.com/Yunhao-Feng/BackdoorAgent）、LessWrong 台架的位置槽、Role Confusion 的角色探针。

### G2 检测器 × 载体的统一评测
- 前人到哪：每篇攻击论文在自己载体上测 2–7 种防御（Watch Out：DAN；TST：7 种；Answer-Side：4 种；Agentland：4 护栏 + 1 权重级；Chat Template：基准自带注入防御；BackdoorAgent：一项概率信号初探）。
- 空着：对象层——同一批检测器跨全部载体的一张表不存在；尤其是**不看输入的检测器**（SpecGuard、CleanGen、触发器反演、权重审计）在工具/历史/自产载体上没人测。
- 证据强度：中（查询 2 条直接相关；上述论文的防御节均已 grep）。
- 约束：「输入清洗器在触发器不在输入时失效」是按构造成立的，且被 LASM 定理蕴含。只做这张表是纯负结果，需配修复。
- 谁改做法：推理服务商、护栏厂商。
- 第一步：在 BackdoorAgent 台架上接入 2–3 个输出侧检测器，固定后门、只换载体。

### G3 模型自产触发的边界
- 前人到哪：三到四篇存在性证明，均为刻意训练。
- 空着：Answer-Side 自己留的开口（多轮间隔后的持续性）；对助手轮做同样的输出侧清洗能否直接杀掉它（该文四种防御作用在哪一段文本上，我没核清）。
- 证据强度：弱（没有专门查询防御侧）。
- 第一步：复现其公开代码，对助手历史做 ONION/改写，看 ASR。

### G4 载体 × 管线存活（送达层）
- 前人到哪：LessWrong 台架已测 7 位置 × 5 策略的串存活；BackdoorAgent 测了阶段间存活率。
- 空着：摘要化（summarization）策略两处都没覆盖（LessWrong 原文："The policy not yet covered is summarization"）；送达与开火的联合测量。
- 空得不大，且原作者在继续做。

### G5 模板/配置层的生态级审计
- 开口见 2602.04653 §11。属系统安全与供应链测量，与本组训练期后门的工具不重合；后续 2610.19498（"What You Sign Is Not What You Run"）未读。

## 4. 近 12 个月拥挤度

- 本次直接碰到的、触发器不在（或不只在）用户输入的后门论文，2025-12 至 2026-11 约 35 篇以上；仅 2026-09 至 11 月就有十余篇。
