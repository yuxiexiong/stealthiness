# 推力—冲刷模型：从定性机制到定量规则（机制线第二阶段计划）

日期：2026-10-14。上游：[分叉实验结果](../asr-mechanism-fork-2026-10-13/RESULTS_FORK.md)（判档「驱动但混合」）、[总纲](../asr-mechanism-plan-2026-10-13/FRAMING.md)。本计划按用户 2026-10-14 的决定直接推进，顺序 A → B → C，每阶段有进入与止损条件。

## 0 为什么是这一步

分叉实验给出的是定性结论：逃逸需要后续毒样本的推力（B2 阻断），推力积在权重里而不靠动量（B1 ≤ 5 步），推力与学习率成比例（B4 推迟），没有推力时平台会被干净数据冲回（B2 的 margin 下降）。缺的是把这几个量合成起跳时刻的式子。没有式子就没有留出预测，也没有可比的训练期动作。按 HanLab 的做法，结构性观察和区分性对照都有了，接下来是把它写成能算的东西，再去赢一个基线。

## 1 模型（最简一阶形式）

潜变量 x（后门倾向）逐更新演化：

x_t = (1 − κ_t) · x_{t−1} + (lr_t / lr_0) · P_t

- P_t：第 t 步消费的毒行的推力。变体 A：毒行条数；变体 B：按消费时 loss 加权（loss 越高梯度越大）。变体 B 只能事后用，因为新运行的 loss 事先不知道。
- κ_t：冲刷率。变体 1：常数 κ；变体 2：κ · lr_t / lr_0（冲刷也是干净样本的梯度造成的，应随学习率缩放）。
- 起跳：x 首次 ≥ θ 的更新 + lag。θ 全局一个，不再逐母本设阈值。

旧的「曝光累加」规则就是 κ = 0 的特例。

## 2 阶段 A · 零 GPU 事后拟合（描述档，不判档）—— **已做，门槛未过，见 [RESULTS_A.md](RESULTS_A.md)**

数据：3 条母本 + 每条 7 个与数据/学习率有关的分叉（B0、B1、B2、B3、B4、B7、B8）= 24 条轨迹，其中 3 条右删失（B2）。B5a/B5b/B6 改的是模型本身，不进拟合。

- A1 拟合：网格搜索 κ、θ（lag ∈ {0,1,2}），目标是非删失轨迹起跳步的 MAE，加删失轨迹「预算内不得越过 θ」的罚项。四个变体（P × κ）各拟一次；对照 κ = 0。
- A2 留一母本：用两条母本的全部轨迹拟 κ、θ，预测第三条母本的 7 个分叉；报告 MAE 与 ±5 步命中率。这才是「预测力」，A1 只是拟合优度。
- A3 坍缩图：把 24 条轨迹每一步的传感器 margin 中位数对潜变量 x 作图。若一条单调曲线能穿过全部轨迹，说明 x 真的是模型内部的那个量，而不只是起跳步的拟合参数。
- 交付：`fit_pushwash.py`、`pushwash_fit.json`、`RESULTS_A.md`、两张图。

**进入阶段 B 的条件**：留一母本预测的 ±5 步命中率 ≥ 70%，且明显优于 κ = 0 对照。不满足则停下，写明「驱动型成立但一阶模型不够」，转表示层。

## 2′ 阶段 A′ · 权重空间直接测量（约 20 GPU 分钟，插入于 A 与 B 之间）

阶段 A 表明 4 行 margin 不是合适的状态变量。A′ 从同一 seed 回放三条母本，把每步更新投影到各母本的后门方向 u 上，按毒微批次与干净微批次分开记录推力与冲刷的实测值（细节见 RESULTS_A §4）。进入阶段 B 的新条件：权重空间累计投影 x_t 在三条母本上以同一阈值（相对散度 ≤ 15%）过零，且干净微批次投影为负并与 x 成比例。否则转表示层。

## 3 阶段 B · 预注册检验（GPU0，约 3 小时）

两条新母本（seed 1108、1109），同一冻结包的训练与读数；分叉点与条件与前次相同，再加两个学习率条件（× 0.25、× 2）以直接检验 κ 是否随学习率缩放。阶段 A 拟出的 κ、θ 冻结后，在母本跑完、分叉开始前由 CPU 任务写出全部分叉的预测起跳步；判据与前次相同（±5 步命中率 ≥ 10/12 为通过）。合同另写 `CONTRACT_PUSHWASH_B.md`，预测写在数据之前。

## 4 阶段 C · 兑现（预测与动作）

- C1 留出预测：用 B 通过的模型预测 LLaVA 14 条、Llama 5 条已有轨迹的起跳步（它们的顺序与学习率表都已知）。预测先冻结再比对。误差比 ≤ 0.5 算过；不过则写明机制只在 Qwen 文本 toy 上成立。
- C2 动作比较：在同一预算下比三个训练期动作——按固定步清动量、屏蔽消费时高 loss 行、降学习率——用模型预测哪个能把跃升推出 1250 步预算，再实测。允许最简单的赢。这部分结论供防御线引用，不并入防御线论文。

## 5 不做什么

- 不改分叉实验的判档。
- 阶段 A 的任何数字都是事后拟合，不作为机制成立的证据；只有阶段 B 的预注册命中才算。
- 表示层（平台是什么、读出在 MLP 一侧）等 B 之后再做。
