## 1 三派怎么做（各自的骨架）

调研是四个并行子任务分别取正文读的（读了什么见 §7）。

### 1.1 grokking 一系：先逆向终态，再从终态推出进度量

Power 2201.02177 → Barak 2207.08799 → Nanda 2301.05217 → Liu 2205.10343 / Omnigrok 2210.01117 → Varma 2309.02390 → Chughtai 2302.03025。

1. **做一个便宜、确定、可复现的最小设定**，再铺稳健性网格（种子、P、层数、数据比例、正则）。去掉的部件要**用消融证明它是惰性的**（Nanda App. A.1：MLP 跳连均值消融后 loss 2.4e-7→7e-7，"从很小的基线上涨，可以忽略"；注意力和它的跳连不可忽略）。
2. **开盒前，先用黑箱统计杀掉一个具体的零假设。** Barak 的零假设是"无记忆随机搜索"，它自带定量签名：成功时间应是几何分布、宽度应带来 1/r 并行加速、标度应是 2^Ω(n)。三条全被实测否掉，才开盒。零假设是**一个生成模型**，不是"效应 > 0"。
3. **逆向终态，分档写在小节标题里**：现象提示（傅里叶基下稀疏）→ 权重组合（W_U W_out 秩 10，FVE 93–98%）→ 单元级（433/512 个神经元是单频二次多项式）→ **双向消融**：去掉预测的成分 → 失效；**去掉其余一切 → loss 反而下降**（−77%）。后者是"整套算法都在这里"的验收标准，只做"去掉 X 会坏"是不够的。
4. **进度量从已验证的终态消融推出来**：restricted loss（只留关键频率）、excluded loss（只去关键频率，在训练集上）。理由也从机制给：记忆解在傅里叶域是散开的，去几个方向几乎不影响它。权重范数这类与跳相关的标量只当辅助。
5. **用这些量重读训练轨迹，按拐点分阶段**，并要求阶段边界与一个独立标量（Σw²）的拐点重合。结论"测试精度的跳发生在 cleanup，在泛化电路建成之后"。
6. **干预从机制里推，一次只破一个成分**：wd=0 时 excluded loss 不升，进度量自己报告电路没形成；ℓ1 不 grok 而 dropout grok，是从"电路在傅里叶基稀疏、ℓ1 推的是神经元基稀疏"推出来的。
7. **推到一个交叉点，再预注册新现象**：Varma 由效率交叉 D_crit 推出 ungrokking、"最终精度与 wd 无关"、semi-grokking，并**写明哪条是严格蕴含、哪条只是允许**（semi-grokking 是后者）。
8. **圈定主张**：Varma "解释依赖权重衰减，而无 wd 也会 grok，所以我们的解释不完整"。

同系反例：**Omnigrok 就是"猜一个全局标量"的路子**（权重范数）。它买到了跨模态的广度，代价是说不出形成的是什么，也解释不了为什么算法任务在标准初始化下会 grok——作者自己承认。我们六个候选与它同型。

### 1.2 电路与因果干预一系：先定位，把假设写成"一张图 + 哪些部分不重要"

Olsson 2022（induction heads）、Elhage 2021、Wang 2211.00593（IOI）、Chan 2022（causal scrubbing）、Geiger 2303.02536（DAS）、Vig 2004.12265、Conmy 2304.14997（ACDC）、Heimersheim & Nanda 2404.15255。

1. **行为 + 分布 + 度量**：度量优先用 logit 差（对残差线性、连续；Heimersheim："最信任"）；概率与对数概率会饱和，准确率是离散的。**我们的 margin 正是 logit 差，这一步是对的。**
2. **选一个只去掉目标信息的腐化分布**：IOI 用三个无关名字的 p_ABC；Olsson 用重复的随机 token；causal scrubbing 用重采样，不用零或均值（"把模型推离分布，效果不可预测"）。
3. **从输出往回定位，一跳一跳**：path patching 分开直接效应与中介效应；每找到一个节点先刻画它，再往上游走。这个方向找出了负向头和备份头——从候选原因往前推的循环会把它们当噪声。
4. **假设写成显式的图**：节点、边，以及**声明不重要的部分**。causal scrubbing 不给任何不是"对应关系 c"的东西打分；全局标量没有"不重要的部分"可消融，所以永远不会因不完整被惩罚。
5. **整张图一起测**：把声明不重要的全部消融、声明等价的全部互换，并对抗式搜索子集 K。IOI 报 faithfulness 87%，**但贪心搜索下完整性不过**，照实报。causal scrubbing 随主张变具体分数单调下降（93→72%；朴素 induction 假设 35%，修三次到 86%）。
6. **证据分档并按模型类别填格**。Olsson 把每个论证在"贡献一部分 / 贡献大部分"×"小纯注意力 / 小带 MLP / 大模型"六格里分别评级；大模型没有消融就**留空**，不外推：

| 档 | 例 | Olsson 的评级用语 |
|---|---|---|
| 时间上同现 | 相变、头形成、loss 鼓包同窗 | Medium, Correlational |
| 个例 | 13B 里三个做翻译的 induction 头 | Plausibility |
| 跨尺度连续 | "若有变化，在哪变、为什么看不到" | Analogy |
| 架构共扰动 | smeared-key：从机制推出 1 层也该相变，验证 | Medium（小）/ Weak（大）, Interventional |
| 读权重的机制论证 | QK/OV 正特征值 | Strong（仅小纯注意力）, Mechanistic |
| 单组件因果干预 | 冻结注意力模式的消融；中介 NIE；path patching | Strong, Causal（仅在效应近可加时） |
| 整假设保行为检验 | 完整性 / causal scrubbing / IIA | 给"假设"打分的唯一一档；三家都说通过是必要不充分 |
| 分解与随机模型对照 | DAS 拆变量；随机初始化网络基线 | 防止把通过读成"网络实现了这个概念" |

### 1.3 训练动力学一系：可解最小模型 → 函数形式的预测 → 一次一个旋钮

Saxe 1312.6120 / PNAS 1810.10531、Jacot 2106.15933、Allen-Zhu & Li 2309.14316 / 2305.13673、Hoogland 2402.02364、Singh 2311.08360、Michaud 2303.13506、Zhong 2306.17844。

1. **先把现象变成理论能说错的数**：Saxe 每个模式的半学会时间；Singh 的峰起点 / 峰高 / 衰减斜率；Hoogland 的 LLC 平台。
2. **选可解或完全可控的最小模型，并列出丢掉了什么**（线性、连续时间、解耦初始化）。丢弃清单本身是结果：以后在真实系统上失败时，它告诉你失败落在哪个被丢的东西上。
3. **预测是函数，不是方向**：t ≈ (τ/s)·ln(s/ε)；逃逸时间 L=2 时 ∼ −log α、L>2 时 ∼ α^{−(L−2)}；最强的是**跨轴恒等式**（Michaud：α_D = α_N/(α_N+1)，两个独立测的指数互相约束）和**跨区制符号翻转**（Jacot：平台长度在 γ>1 时随宽度增长、γ=1 时不变、γ<1 时没有平台）。只预测"推迟还是提前"的单次干预，许多机制都能同时满足。
4. **先在模型自己身上校准仪器**：Saxe 拿随机初始化的仿真对比解耦解，把偏差当统计量报（100 个种子）；Michaud 先在已知答案的稀疏奇偶上跑聚类工具，发现它把 1.4 的指数测成 1.1，然后才拿去 Pythia 上用。没有校准对象时，失败分不清是假设错还是仪器错。
5. **对竞争机制设计让它们给出相反预测的观测量**：Zhong 从 Clock 和 Pizza 两种算法的代数推出"距离无关性"和"梯度对称性"（0.17 对 0.85；99.4% 对 33.4%）；Singh 只对 MLP 加权重衰减就去掉了瞬态，只对注意力加不行，用这个把"容量竞争"落到组件上。
6. **没有可解模型时，检测与解释分开**：Hoogland 先在一个几何量（LLC）上用冻结规则切出阶段边界，再用探针解释每段长出了什么，并和平凡基线比（Hessian 漏掉 4 个边界里的 3 个）。
7. **负结果分类型**：Michaud 区分"模型在指定处错了"（S_k ∝ p^−0.81 不是 p^−1）和"协议产物"（早停），和我们 6.7 的分法一致。

## 2 我们的循环错在哪里（逐个对照）

| 候选 | 我们怎么做的 | 在骨架里缺哪一步 |
|---|---|---|
| 剂量 / 计数 | 用一个摘要量预测起飞 | 第 2 步的零假设没有写成生成模型，只是一个标量；它失败只说明这个摘要不行 |
| 脉冲衰减 PD | 全训练一个标量驱动，拟合起飞时间 | 缺第 3–5 步：没有对象；两个 τ 不相容是在拟合后才发现的，第 7 步"先在模型自身校准"缺失 |
| B3 优化器清零 | 一次全局干预，预测一个量级 | 第 6 步：判别观测量在设计时就已知分不开冲击和部分记忆（RESULTS_B3 §1 自认） |
| KICK | 等大小随机位移 | **这是对的做法**：具名零假设、随机臂；0 步把噪声解释否掉 |
| G 增益 | 全局 L1 敏感度，推导链只看 A 侧 | 推导里的近似没有单独测（HanLab 4A.4 第 3 条）；仍是全局标量 |
| IM2 归因领先 | 读数在构造上就是 logit 的触发分量 | 第 3 步的度量 / 腐化选择错（Heimersheim：一个 patch 只识别处理 clean 与 corrupt **差异**的激活） |
| RIVALS 的候选集 | 21 条候选：全局标量 11 条、组件级 8 条、数据侧 2 条 | 管"何时 / 多快"的 B、C 两组 12 条里**没有一条组件级**；组件级的全在"住在哪"（终态） |

**共同根因**（推导档）：每个候选都是**整个训练过程的一个全局量**。全局量没有"不重要的部分"可消融，失败时不指向任何组件，所以下一个候选只能从残差里猜。三派的做法是先把对象定位出来，之后每个候选都是"这个对象的哪部分、何时、被哪些数据推动"，失败会落到图上的某条边，下一步由图决定，不由残差决定。

**第二个根因**：我们的判据几乎都是"方向 + 量级带"（推迟 ≥ 54 支持、≤ 5 无效）。按 §1.3 第 3 条，这类判据可以被多个机制同时满足，所以即使通过也区分力弱，不通过也不指向替代者。

总原则：**先拆"形成了什么、在哪里"，再拆"何时"**；"何时"只在组件层面、只做标度预测。PL（K(d)）是黑箱层面的数据 × 时间测量，继续跑，到第 M3 步作为校准对象用。

|---|---|---|---|---|
| **M0**（已有） | 读数 t_M0s，抖动 4.3；具名零假设：剂量、初始化、单行、随机位移（KICK）均已否 | — | — | — |
| **M1 终态定位** | 在 1009 的终态与起飞点（≈330）、起飞前（250）检查点上，以 margin（logit 差）为度量、"同一输入去掉触发"为腐化，做 denoising 与 noising 两向：残差 层×位置 → 注意力 / MLP → **LoRA 模块**。LoRA 微调的天然组件就是每个模块的 ΔW = BA，所以"消融组件" = 把该模块的 ΔW 置零，这是在我们设定里最干净的组件单位 | 0（只推理） | 盘上检查点 | 验收（数在合同里定）：限制到 C 后 margin 恢复 ≥ 阈值，C 置零后触发失效，贪心 K 搜索下完整性；对照用随机 LoRA（同范数）。**若找不到小的 C**（后门是分布式的）→ 记 D0"无低维载体"，转 M2′，不回到全局标量 |

**过程规则**（写进以后每份机制合同）：
1. 候选必须在组件层提，必须写明"哪些部分不重要"；全局标量只能当辅助读数。
2. 失败后的下一步从定位结果推，不从失败残差推；定位本身失败就换检测器路线，不换标量。
3. 判据优先是函数、跨轴关系或跨区制的符号翻转；"方向 + 量级带"只作补充。
4. 推导里每个近似单独测一次（G 线漏掉 B 侧就是没测）。
