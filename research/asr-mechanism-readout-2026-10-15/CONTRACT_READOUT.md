## 0 要检验的陈述

在 Qwen toy 上，**只看 ASR 起跳之前的连续量 gap，就能在线检测到离开平台的时刻与平台深度，并用一个跨母本共用的爬升速度预测 ASR 何时起跳**；预测优于不用深度、或不用退出时刻的两个对照。失败的典型方式：爬升速度随母本变化很大，或平台在离开后又跌回（s1106 式阶梯），使在线检测过早触发。

## 1 材料

- **校准集**：已有三条母本 s1105 / s1106 / s1107 的 Q1 逐更新回放。
- **检验集**：8 条新母本 seed 1108–1115，冻结 r02 toy 配置与冻结训练器（`fork_run.build` / `train_update`，字节级复用），每条 160 更新，母本自己的顺序。每个更新后读 V60 60 行 trigger 与 clean（路径 B，与 Q1 相同的核），记 gap、argmax 命中、clean 正确数，以及适配器 SHA。不存适配器。

## 2 定义（全部在线、因果）

- c(t) = 60 行 gap 均值；s(t) = c 在 [t−2, t] 的尾部 3 点均值。
- 运行最低 m(t) = min_{17 ≤ u ≤ t} s(u)（只用整个 3 点窗都在第 15 步及之后的 s），**最后一次**取到该最低值的时刻 τ(t)（平台平坦时取平台末端，不取起点）。（部署前修订：原写 15 ≤ u，s(15) 会把第 13–14 步的初始陡降段平均进来，CPU 测试显示检测器因此在第 20 步对每条母本误触发。修订在任何检验数据与校准计算之前。）
- **退出检测**：第一个 t ≥ 20 使 s(t) − m(t) ≥ 3.0 logit；记 t_det = t，**t_exit = τ(t_det)**，**深度 D = −m(t_det)**。
- 起跳 t_a = ASR60（gap > 0 的行比例）首次 ≥ 0.10 的更新。
- 校准（只用三条旧母本，同一检测器）：θ = c(t_a) 的均值；v̄ = (c(t_a) − c(t_exit)) / (t_a − t_exit) 的均值；L̄ = (t_a − t_exit) 的均值；T̄ = t_a 的均值。
- **预测**：t̂_a = t_exit + (θ + D) / v̄。
- 对照一（无深度）：t̂_a = t_exit + L̄。对照二（无退出）：t̂_a = T̄。

## 3 判档（检验集上，有起跳的母本）

MAE = 平均 |t̂_a − t_a|。

| 档 | 条件 |
|---|---|
| **supported** | MAE_模型 ≤ 0.7 × MAE_对照一 且 MAE_模型 ≤ 0.7 × MAE_对照二 |
| refuted | MAE_模型 ≥ MAE_对照一 |
| partial | 其余 |
| unmeasurable | 有起跳的新母本 < 5 |

160 更新内 ASR60 不到 0.10 的母本为右删失，报告、不计入；无退出检测但有起跳的母本，预测记为 t̂_a = t_a 之后不可得——计为误差 = |T̄ − t_a|（按对照二处理，不给模型豁免）。

描述（不判档）：11 条母本上 Spearman(D, t_a − t_exit)；v 的变异系数；检测是否早于起跳（t_det < t_a 的比例，即「可提前预警」的比例）；阶梯（检测后 s 又跌破 m(t_det) 的母本数）。

## 4 预测

supported。依据：探索中 toy E2 定义下 v 的变异系数 0.07。风险：s1106 式阶梯；本检测器在 s1106 上大概率在第一次上升（约第 35 步）就触发，校准集自身就会有一个大误差。

## 5 止损与边界

- refuted：读数模型的「可预测」版本不成立，命题 1 退回描述性陈述（「起跳 = 退出 + 爬升」只是事后分解）；停下讨论。
- partial：报告，命题 1 写成「部分可预测」，继续。
- 工程失败（训练非有限、读数不变量破坏）：修后重跑。
- 单模型（Qwen3-8B toy）、单剂量；LLaVA 侧没有逐步数据，不在本检验内。
