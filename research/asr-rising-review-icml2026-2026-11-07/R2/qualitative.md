# R2 独立完整评审

本报告是按 ICML 2026 主会标准进行的作者侧 AI 模拟评审。定性倾向为**弱拒绝**：可信的条件性发现已经存在，但相对直接前作的知识增量与验证范围，目前尚不足以支撑接收。这个判断不要求论文必须有新算法、统一机制或固定数量的模型。

**论文研究什么。** 本文将后门训练拆为行为何时出现、连续输出怎样跨过决策边界、训练历史怎样改变后续过程三个问题。多模型材料说明短窗 ASR 增长并非单模型偶然现象；Atlas 提醒离散曲线相似不代表连续动态一致。核心干预是 LLaVA P2：固定毒行身份与位置，仅改变前 200 步的干净输入，随后 500 步输入完全相同，A/B 的持续 margin 过零相差约 46 步。Qwen toy GATE 则先做额外干净学习，再在重置训练器的相同投毒流中测量出现时间，提供另一类历史状态干预。

**三个具体优点。**

1. P2 的控制具有实际价值。它修复了 P1 窗外补位改变后续输入的缺口；原始 `results_p2.json` 可重算得到 309.7955、327.9724、355.9574，生成 t50 又给出 320、340、360，说明差异不只来自持续过零判据。图 `history_effects.png` 与 `p2_readouts.png` 将行为、T/C/D 和正常正确率放在一起，未把同一次训练的多个读数冒充独立复现。
2. 跨模型材料保留了有信息的失败与分母。inventory 的 768 行确是三判据记录，所选主视图为 106 个、26 组；Atlas 是 56 条输入、50 条过门。T5 未观测、LLaVA 三条不可判、Vim 重放失败及独立确认不通过均未被抹去。这使现象目录可供后续研究使用。
3. 整合稿有效撤回了不成立的机制解释：GATE 不再被称为必要性证明，Atlas 的拟合时间项不再等同于 P2 的干净输入读数，M3T 校准失败不再被解释为机制否证。P2 第 300/400 步 C 与 D 的反向变化也如实保留。

**四个维度的判断。** 技术可靠性总体良好，尤其是“给定这些历史与训练设定，后续时间存在因果差异”的窄结论；但证据不足以识别正常能力、参数或优化器的独立中介。表达与可复现性尚可：主文边界清楚，两图易读，但方法需要在多份历史合同间拼接，提交包未含完整训练/评估代码、逐探针 P2 原件及部分身份闸原件。重要性目前有限：它把一个值得控制的变量测清楚了，却还没有给出可迁移的预测或能改变既有实践的幅度范围。原创性有潜力，最有辨识度的是固定毒骨架与共同后续；“干净历史影响后门学习”本身已有直接先例。

**主要缺口一：核心增量必须相对直接前作成立。** 我查阅了 Souly 等《Poisoning Attacks on LLMs Require a Near-constant Number of Poison Samples》的原文附录 F.2：作者已报告先做干净微调会让低毒样本数的后门更难学习，并明确指出路径依赖尚待解释。P2 对等长历史、固定毒位置和共同后续的控制更严格，这是真增量；但当前仍主要提供一对已选历史上的局部量化，尚未说明这一精化带来什么新的、可区分的预测。[原论文 F.2](https://arxiv.org/html/2510.07192v1#A6.SS2)

Shumailov 等早已展示仅改变数据顺序即可干扰训练并引入后门，因此“顺序重要”也不足以独立构成贡献。[NeurIPS 2021 官方论文页](https://proceedings.neurips.cc/paper/2021/hash/959ab9a0695c467e7caf75431a872e5c-Abstract.html) 另一方面，Cinà 等的 backdoor learning curves 主要沿毒损失权重 β 描述学习，并不等同于本文的真实更新时钟；不能因题目相似就判本文已被做过。[原论文 §2](https://link.springer.com/article/10.1007/s13042-024-02363-5) 这是一轮直接近邻核查，不是穷尽性新颖性确认。

**主要缺口二：最强干预仍依赖发现阶段选中的极端历史。** P1 合同 §1 明说 A/B 因同一骨架上量程最大而被选择。P1 的第二训练种子差距 55.85 步是有用支持，但后续数据不同；P2 每臂只有一次训练。预先冻结这对历史能防止 P2 内再挑结果，却不能消除先前挑选的条件性。GATE 的三个母本也不能替代同操作验证：它增加可变长度预训练、重置训练器，终点仅是首次超过 3/60 命中。二者是**互补的存在性证据，不是同协议复现**。它们的共同命题可站住，作为可推广研究结论仍需比“在选择好的两条轨迹上成立”更明确的支撑。

跨模型现象可支持“若干已测配置中存在短窗增长，并有部分独立探针同点确认”；不能估计模型家族总体发生率。Atlas 是已形成且可测轨迹的条件性再分析，语言 20 步、分类 5 步、toy 1 步的采样差异又限制了加速类别比较。它足以反对从 ASR 外形直接推机制，尚不足以给架构归因。P2/GATE 与 Atlas 并列合理，但没有闭合到统一内部形成过程。

**一项需要澄清的实际实现细节。** 我逐步核查发现非有限梯度位于 A 的 66/401、R 的 35/548、B 的 62/67 步；A/B 在第 201–400 步的实际 LR 不完全相等，最大绝对差约为 1.04×10⁻⁷。这与不同溢出位置相符，但未读训练器代码，不能断言具体跳步机制。这不直接否定早期输入干预的总效应，因为后续优化状态差异也可能是该干预的结果；应将“共同输入流”与“相同有效更新、相同实际 LR”分开，不把固定毒行消费自动解释为相同有效毒更新。

**唯一优先实验：第 200 步参数与训练器状态的交叉续训。** 固定当前 A/B，不再选历史；重建并保存第 200 步完整状态，以参数 θ_A/θ_B 与非参数训练器状态 s_A/s_B 做四格续训，全部使用同一 H。s 应完整包括优化器、调度器、GradScaler 和 RNG，不能只交换 Adam 矩却把其它状态静默重置。两个原配格必须重现自然续训；两个交叉格提供最小区分。继续并列报告生成 t50/t50s、margin 与正常正确率，事前规定比较和失效条件。

这项实验是**补核心因果信息**，不是要求完整机制。若在两种 s 下，出现时间均随 θ 的来源稳定移动，就把历史效应落实到可传递参数状态；若主要随 s 移动，就得到另一条有价值的形成解释；强交互则限制简单归因。它还直接处理日志暴露的状态问题。一个清楚、行为读数一致的可区分结果，会实质提高我对贡献的评价；交叉状态失效或只有阈值抖动不会。换一个训练种子属于稳健性补充，补相关工作属于文字与定位修订，两者不能替代这项信息。本报告未执行该实验，也不估算卡时。

**给作者的问题（及怎样改变判断）。**

1. 相对 Souly F.2，作者准备把哪一个新预测作为正文中心？若只是历史依赖的存在，我的原创性顾虑保留；若已有未纳入稿件的独立证据检验一个更具体预测，会提高评价。
2. A/B 的完整候选空间与选择过程是什么，是否已有未参与选对的共同后续验证？能够提供后者会降低我对发现样本依赖的担忧；只增加同批探针置信区间不会。
3. 各溢出步是否跳过参数更新、是否包含毒行，调度器怎样计步？完整日志或代码说明可决定“固定毒暴露”的措辞是否需要收窄；不能仅凭梯度 NaN 宣称主结果无效。

最强接收理由是：P2 提供了清楚、可审计、具有行为一致性的历史干预，配合保留负例的跨模型材料，可能成为有用的实证参照。未给更高评价的原因是直接前作已提出路径依赖，而当前精化仍缺一项足以让后续研究据此做出新预测的验证。科学局限讨论充分；潜在影响尚需一段说明训练审计价值及被用于调整后门学习时机的双重用途。未发现可以据此指控的伦理违规。

**核查范围。** 完整阅读三份主文、README、Atlas/P1/P2/GATE 合同及规定结果、跨模型 V2 合同与最终报告、M3T、QX、IM2、R1 结果；查看两张 PNG 主图。解析 inventory、Atlas server/toy/corpus、P1 GP0、P2 汇总和三份逐步日志，核对来源与校验清单。具体文件与零 GPU 重算结果见本目录 `audit.json`。52 个输入文件 SHA256 全部与 manifest 相符。没有读取旧审稿、其他审稿人输出或协调综述；没有检查训练代码，没有独立训练或推理复现。P2 逐探针原件、GP2/GI 原件、GATE 训练源码和 M3T 底层段表未在本次提交包中核查，不能把合同声明或 VALIDATION 的 PASS 当成我的独立验证。
