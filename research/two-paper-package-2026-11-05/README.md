`originals/`逐字节保存原始稿件、评分与锁定文件；`read/`只转换Markdown链接并加入口说明。原PDF/Word保持送审版，历史本地超链接不重写，在线来源导航请使用Markdown阅读版。

未收录字体、缓存、排版中间图、第三方全文抽取和模型权重。直接引用的小型结果已收录；1485文件的XO过程目录只提供清单与哈希。历史锁定清单仍记录原机器路径，这是来源身份，不代表包内路径。审稿中的真实勘误集中保留，没有静默改写原意见。
