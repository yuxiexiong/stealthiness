# 从历史实验生成下一阶段课题

这份材料交给独立研究者，用来回答一个问题：哪些已经发生、经对照仍站得住的现象，值得发展成别人也关心的科学问题？材料覆盖 2026 年 9 月至 11 月的视觉归因、训练动态、异常行为监测、修复评估和正常任务表现。69 个编号代表 69 组比较或纠错；几组可以来自同一训练轨迹。

## 怎样读数字

- 图像、正常问答、触发问答、首词分数和完整生成分别按该项实验的判据读。ASR 是该实验定义的目标行为命中率。后期使用 T、C、D 的条目中，T 与 C 分别是触发和正常输入上目标首词相对最大竞争词的优势，D 为两者之差。整批干预的响应指处理组与对照组的读数差。
- 留意独立单位。200 道题在十个时点重复测量，可以定位具体哪道题翻转；跨训练的稳定性要看真正换过几个种子、顺序、任务或模型。
- 来源标签保留历史顺序。上轮复核时有 7 项只能从本机直接引文核查，本次已给它们附上可在线读取的原结果数据或带原行号的节选。位置、分母和未识别的混杂同样保留。[S24](全部意外.md#s24) · [S40–44 起点](全部意外.md#s40) · [S50](全部意外.md#s50)

## 希望你给我们什么

请独立通读 69 项，再提出你认为值得继续的候选问题，数量由证据决定。可以跨条目组合，也可以指出几个编号实际只贡献了一份证据。每个候选请写清：

1. **问题与价值。** 用一句话提出待回答的问题。谁会因为答案改变评估、监测或防御做法？
2. **证据与反证。** 引用具体 S 编号，指出哪几项共享来源，最不利的一条是什么，以及目前仍成立的竞争解释。
3. **与已有工作的关系。** 查最接近的原始论文，给出处；说明已有研究已回答哪一部分，还剩什么区别。
4. **怎样分出结果。** 写下能区分两种解释的最小比较、主要读数，以及什么结果会使你收缩或放下这个方向。优先指出已存数据能回答的部分。
5. **优先次序。** 给出最值得深入的方向，并说明它相对其他候选多回答了什么。把已经测到的结论与下一阶段的预测分开写。
