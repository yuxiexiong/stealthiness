## 3. A的反向、转正与B的正向

所有效应方向固定为P来源减C来源，不因结果正负改定义。M@RC=PC−CC、M@RP=PP−CP；R@MC=CP−CC、R@MP=PP−PC。以下ASR为百分比，效应为百分点。

| B385 |49|62|51|66|+13|+15|+2|+4|

A335：两种R下换入MP分别让30/28题失去命中，没有新增命中；200/200题目标减最大竞争者gap下降，平均差−0.523/−0.514。A350：换入MP分别新增11/10题命中，无丢失，200/200题gap上升，平均差+0.608/+0.628。不是只在一个代理平均量上出现小差异。

B385：两种R下MP分别新增26/30题命中，无丢失；199/200题gap上升，平均差+0.343/+0.342。因而不能把旧U效应全部归为初始R不同。

但“矩来自投毒历史，所以始终促升”同样错误。B335的ASR四格全为0，两种R下矩效应在gap上已是负值（均值−0.622/−0.621），350后转正。A后期370–395平均gap效应又为负，ASR已饱和而难以显示，420再正、440又负。因此A负/B正不是两个历史永久不同的机制类型，也不能据若干变号就宣布发现共同振荡规律。

进一步拆开已记录的竞争读数，固定RC时：A335的平均目标logp下降0.327、最大竞争者上升0.196；A350目标只上升0.101、最大竞争者下降0.506。B335目标下降0.616、竞争者约增0.007；B350目标增0.470、竞争者降0.055；B385两侧分别+0.169/−0.175。这说明不能把gap变化直接叫作目标记忆单调增强。两侧共享概率归一化，最大竞争答案身份也可能改变，以上只是读数分解，不是两个独立因果通道或梯度机制。全部时点两侧差已写入PAIRS.csv。

## 7. 支持什么、仍然分不清什么

| 命题 | 当前判断 |
|---|---|
| 本次旧U效应全是初始R差异，M没有行为作用 | 在本次两个ΘC背景被反驳；两个R下都有多点M作用 |
| 初始联合M参与后续形成轨迹 | 支持条件因果作用，包含抑制、促进及回落变化 |
| MP是始终促升的记忆 | 不支持；A早期及B低ASR期均有负gap效应 |
| R无关或只是该忽略的噪声 | 不支持；影响实际翻转和阈值判定 |
| M与R严格相加、没有交互 | 不支持严格版本；连续与离散尺度分别报告 |
| 强M×R协同主导了ASR陡升 | 未证明；有限交互不等于完整机制 |
| 原始矩一直保留到385，内部储存了后门知识 | 未测；初始干预后果不等于原矩持久存储 |
| 一阶动量还是二阶预条件起作用 | 未区分；本轮操作是联合M |
| Θ与M谁是自然主要通道 | 未分配；只在ΘC干预，上轮Θ大时序差仍成立 |
| 为什么分数先负后正、为何集中越界与回落 | 未获训练过程解释；这是剩余核心缺口 |
| 普通优化、阶段变化还是后门特异过程 | 仍不可排他裁决；没有独立定义并匹配学习阶段 |
| 跨种子、模型可复现、可形成防御收益 | 本轮未检验，不从200题和两历史外推 |
