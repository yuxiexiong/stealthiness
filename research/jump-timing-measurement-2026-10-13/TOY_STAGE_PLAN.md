# Toy 阶段完整计划（2026-10-14 起）与后续计划

目标 claim（toy 阶段要证伪或证实的）：**在后门晚于正常学习的攻击上，仅用训练前向已算出的逐行 loss、零额外算力，就能在训练中屏蔽毒行、把 ASR 压到 0，正常质量损失 ≤ 3/60，并在同效果下比 ABL 等全量打分方法少三个数量级的防御算力。**

本线现状（第 1–4 步，`RESULTS_stage1_measurement.md`）：观察修正为"晚且稀疏"；lom 规则在变体 B 4/4、变体 A 1/4 挡住后门（ASR 60→0），额外算力 0.14 s；但干净行被屏蔽 6–11%，V60 掉 3–13 分；覆盖受"门开前毒行是否已生效"限制；testbed 上没有合格基线。

三个差距按"最可能证伪整条线"的顺序排：**代价 → 覆盖 → testbed/基线**。每步一个假设、预注册预测、≤1 GPU 小时（T4 除外）、正负结果都记。

## T2 代价（最先做，因为它决定线的生死）

**T2a 零 GPU：屏蔽的干净行是什么。** 用 lom2 的 8 个运行：被屏蔽干净行在训练模板（4 种问法）、实体、步数上的分布；与同 seed A1 对照这些行在 A1 里的 loss 轨迹；V60 掉分是否集中在某个模板/实体。预测：屏蔽集中在某一模板或若干实体（结构性），不是随机噪声。
- 结构性 → T2b 用相对阈值；随机 → T2c 用探针。

**T2b 相对阈值（1 小时）：** 把固定 1.5 换成"相对最近 K 步同模板/全体干净行 loss 的分位数"（例如 > 近 50 步的 99.9 分位），或"延后重试"（被屏蔽的行 N 步后用当前模型重打分一次，仍高才丢，用 JSD 已有的 `score_rows`，成本为被屏蔽行数的一次前向）。B/1102、B/1103 各一次。预测：ASR ≤ 3/60，干净行屏蔽 < 1%，V60 与 A1 差 ≤ 3。

**T2c 探针（1 小时）：** 用免费 hidden，在门开后把"高 loss 行"分成毒行簇和难行簇（无监督，或用前 k 个高 loss 行自举）。同样两个 seed、同样预测。

**门 T2**：任一方案在 ≥3 个 B seed 上达到 ASR ≤ 3/60 且 V60 差 ≤ 3 → 进入 T3；两种都不行 → 代价无法压下，toy 阶段以"观察 + 有代价的规则"结案，不进入真实数据。

## T3 覆盖

**T3a（A1 only，变体 A，4 个新 seed，约 1.5 小时）：** 量化"门开前毒行已生效"的频率：记录门开前毒行数与 A1 的跃升步，给出 P(规则适用)。
**T3b 自适应攻击（1 小时）：** 攻击者把 200 条毒行全部前置到前 40 步。预测：规则失效（ASR 60/60）。这是诚实的边界，不是要赢的实验。
**T3c（可选，只有便宜想法时做）：** 门前信号：门开瞬间对最近 L 步的行做一次 Δ 重打分（P0 M2 已证明在变体 A 上 AUROC 0.97），成本 L×16 行前向，一次性。预测：1103 这类"门前部分生效"的 seed 被补救。

## T4 testbed 与基线（约 8 小时）

- 质量门改为"V60 ≥ 同步数 A0 − 3"，用 3 个干净 seed 估 A0 的终点方差。
- 基线各调到各自最好：ABL（再加"用我们的门触发打分"的 ABL 变体，作为公平的调度对照）、谱签名/激活聚类（LoRA 版：一次全量前向 + hidden SVD）、困惑度预过滤、端点扫描 + 重训。要求至少一个合格。
- 测试 seed 1103/1104 冻结配置，输出 Pareto 主表（同效果下额外 GPU 秒、前向行数、端到端时间）。

**门 T4**：没有合格基线 → 报告"有效性胜出，比值未定义"，并把 toy 的局限写明；有 → 报比值。

## 后续（toy 之后，只有 T2 过门才做）

1. **观察图跨设置**：3 个模型（Qwen3-8B、Llama-3.1-8B、Mistral-7B）× 3 类真实后门（词触发 BadNets、句法触发、风格/指令触发）× SST-2/AG News/Alpaca 子集 × 3 seed，只跑无防御臂（每个 20–40 分钟），画"晚且稀疏"在多大比例成立。这是论文第一张图。
2. **方法**：lom 的最终形态（T2 的胜者）在上面的设置上跑，报 ASR、clean accuracy、额外算力。
3. **基线主表**：ABL、谱签名、激活聚类、困惑度过滤、检测后重训，各自调到最好，同 ASR 水平比开销。
4. **自适应攻击**与适用域。
5. 论文：观察 → 浪费 → 方法 → 测量，目标 ICLR/AAAI；代价降不到 clean accuracy < 0.5 点就只投 workshop。

GPU 预算：toy 剩余 T2–T4 约 15–20 小时；后续阶段约 100–150 小时。
