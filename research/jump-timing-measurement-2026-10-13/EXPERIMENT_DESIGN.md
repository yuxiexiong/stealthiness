# 后门习得时刻的测量线（JSD 失败后的下一阶段）

写于 2026-10-13。前身：`../asr-jump-sparse-defense-2026-10-12/RESULTS.md`（失败）。本线不是防御线，是观察线：**后门何时被学会、学得多陡、相对正常任务先后如何，是攻击目标、数据顺序、毒率的什么函数。** 只有当存在"后门明显领先正常任务、且基座困惑度分不出毒行"的区域，训练期触发器无关的廉价防御才有落脚点；否则这条防御方向结束，本线的结果并入 `attribution-microscope/supplement/jump/cross_model` 的现象描述。

## 0 工作方式（用户 2026-10-13 的要求）

- 一步只检验一个假设，GPU 时间不超过 1 小时；跑之前把预期结果写进该步的 `stepN_plan.json`；跑完按预期对照，正负结果都记录。
- 每步有 go/no-go；只有需要大 pivot 时才停下问用户，否则自动推进。停止点：本线彻底失败（无落脚点），或成功（落脚点存在且信号验证通过，进入方法合同），或用户判断可以结束。
- 不改阈值重跑旧方法、不换 seed 追阳性、不在没有合格基线的 toy 上比开销。
- 服务器规则沿用 JSD 的 HANDOFF §8（只用 GPU1 队列 worker 3052130，根目录隔离，不碰 GPU0/jevrep）。代码复用 `/workspace/cross-model-asr/jsd_20261012/code`（A0/A1 臂、制备、评测），合同 `contract.json` 不变，只用它的训练与评测设置。

## 1 固定设置

与 JSD 合同相同：Qwen3-8B 指定 revision，LoRA r16/α32，AdamW 1e-4、warmup 38、1250 步 cosine，有效 batch 16，20,000 行、200 毒行（1%）、映射 seed 41001、毒位置 seed 51001。A1 臂记录逐行 loss、每 10 步 V60 trigger 真值曲线。

**读数定义**（每个 A1 运行）：
- `t_jump`：真值曲线首次 trigger 命中 > 3/60 的步（分辨率 10 步）；`t_full`：首次 ≥ 57/60 的步；`width = t_full − t_jump`。
- `t_normal`：20 步 loss 中位数首次 < 1.0 的步（与 JSD 的 τ_med 门同定义，便于对照）；另记 V60 正确数的终点值。
- `lead = t_normal − t_jump`（正数为后门领先）。
- 终点毒行 vs 干净行 loss 的 AUROC（低 loss 为毒）。

## 2 步骤与 go/no-go

**第 1 步（已入队，`step1_plan.json`）**：A/1102 与 B/1101，与已有的 A/1101（r02）和 B/1102（JSD 开发）补成 2×2。预期：A 两个 seed 都领先且陡，B 两个 seed 都不领先且宽。
- 预期成立 → 时刻由攻击目标决定，进第 2 步。
- 两个都早或都晚、或混合 → 变体解释撤回，第 2 步改为顺序实验（XO 式：固定 seed 换毒行位置）。

**第 2 步（约 1 小时）**：中间变体 C：毒行目标改为**某个实体 E\* 的真实四位码**（在分布内，基座困惑度接近干净答案，但后门映射与正常映射同形）。定义（代码 `jsd_prepare.py --variant C`，E\* 由固定 seed 61003 从 32 个实体中选）：训练行全部保留（E\* 自己的毒行等于"触发器 + 正确答案"，计为无效毒行并记入收据）；V60/H64 中 E\* 的行删除（约 2 行），使"输出目标"永远不等于"回答正确"。因此 C 的真值曲线分母略小于 60，读数 `t_jump`/`t_full` 改用比例：> 5% 与 ≥ 95%。跑 A1 C/1101、C/1102，外加 A0 两个 seed（1101、1103）测 V60 终点方差。同时用基座对 C 的训练行算 M4（基座 loss AUROC）。预期写在 `step2_plan.json`。
- 若 C 的 lead > 0 且陡（width ≤ 20 步）且 M4 < 0.95 → **落脚点存在**，进第 3 步。
- 若 C 像 B（不领先）→ 继续沿目标与基座分布距离做 1–2 个点（例如目标是分布外但同形的码、或 OOD 单词但低毒率），每点 ≤ 1 小时；若扫完仍没有"领先且 M4 低"的点 → **本线作为防御前提失败**，写 RESULTS.md 结案，结果并入 cross_model。

**第 3 步（零训练，只在落脚点存在时）**：在落脚点变体上保存跃升窗口的 witness adapter（A1 臂每步存 adapter 到 CPU 环形缓冲），离线验证两个免费信号：窗口内 Δloss 的**排名**规则（取前 1%，而非阈值）、hidden 的无监督成簇。门槛沿用 JSD P0 的 (a)(b)，但攻击与后续方法一致，不再中途切换。不过 → 结案。

**第 4 步（方法合同）**：先在修好的 toy 上证明至少一个基线合格（质量门改为相对同步数 A0，带跨 seed 方差），再写方法合同。传感器必须找"一小部分行下降而其余行不动"的子集结构；清除动作只在可疑集非空时计费计效。

## 3 产出
