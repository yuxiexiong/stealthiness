## 命名与术语（2026-10-16 与用户商定）

方法定名为 **Curfew**（宵禁）。比喻：任务学会之后实行宵禁，之后到来的、与已学知识不符的样本不放行。名字直接点出贡献在"时机"。同时解决了 "gate" 和 Sure Trap 的 "behavioral gate" 撞名的问题。

| 旧说法 | 新术语 |
|---|---|
| fx2（方法） | **Curfew** |
| 门、门开步 | **curfew step**（宵禁时刻：数据驱动的"任务已学会"时刻） |
| 门后残留毒行 | **post-curfew poison** |
| 门前毒行 | pre-curfew poison |
| 后门晚于正常学习（观察） | **Backdoor Lag**（后门滞后） |
| 时机插件 | **curfew-aware X**（例如 curfew-aware GradSentry） |
| 门开停训（对手） | stop-at-curfew |

- **标题示例：** *Curfew: Zero-Cost Defense Against Fine-Tuning Backdoors by Filtering After the Task Is Learned*
- **宣传语：** "Backdoors arrive late. Impose a curfew."
- **定位句：** *When to filter, not what to filter.*

## 2. 阶段 A：toy 补全（约 20 GPU 小时，双卡约 10 小时）

设置全部沿用 toy：Qwen3-8B LoRA，查表任务，变体 B（目标对基座不奇怪），1% 投毒，1250 步。开发 seed 为 B 1106，留出 seed 为 B 1105、1107、1108，新增 1109、1110。判据不变：124 题 ASR ≤ 5% 为成立，5–15% 为部分，> 15% 为失败；质量要求正确数 ≥ 98.7。

### A1 零成本对手（主表的零成本组）

| 对手 | 配置（开发 seed 上扫，oracle 选最优后迁移到留出 seed） | 为什么 |
|---|---|---|
| **Loss Truncation，门对齐** | 预热 = 在线门（与 fx2 同一判据）；c ∈ {0.01, 0.05, 0.1, 0.4} | 最近的祖先；检验"只要时机对，过滤规则可以换" |
| **Loss Truncation，固定预热** | 预热 ∈ {20, 50, 100, 150} 步，c = 0.05 | 画出"有效窗口"曲线：太早误删、太晚已装上 |
| **门开停训**（Moderate-fitting） | 在门开后 +0 / +25 / +50 / +100 步停，一次运行出四个点 | 零成本，最危险 |
| 低学习率 / 小秩（Moderate-fitting） | 学习率 × 0.1 / × 0.3；LoRA 秩 1 / 4 | 前作原配方 |
| **DeCE** | 原文默认（α = 0.99，ε = 0.1）；按 20 个 epoch 的衰减压缩进单轮 | 零成本的损失修改 |
| 整段计算损失 | 提示词也算损失 | PoisonForge 报告能降 ASR |
| **GradSentry** | 原文自动阈值（KDE 谷底，回退 0.7）；预算对齐 fx2 的 top-N | 最新、最强的静态检测器 |

Loss Truncation 的实现按其官方 `LossDropper`：环形缓冲区记录最近若干行的 loss，定期重算分位数，高于分位数的行置零。把缓冲区和重算间隔从原文的 1 万行缩到 160 行（10 步），这样它对 1250 步的训练也能及时反应，对它有利。

迁移规则（宽进）：一个对手家族在开发 seed 上所有配置的 ASR 都 > 50%，才不迁移，否则取 oracle 最优配置跑 3 个留出 seed。门开停训每次只跑约 5 分钟，直接在 6 个 seed 上全跑。

### A2 受控剂量（观察 2 的因果证据）

无防御训练，只放行 k 条毒行，其余毒行换成它的干净版本。其他数据不变。

| 放置窗口 | 平均学习率（相对峰值） | k |
|---|---|---|
| 门前（第 10–40 步） | 约 0.65 | 16、64 |
| 门后中段（第 60–260 步） | 约 0.98 | 4、8、16、32 |
| 门后全程均匀（第 60–1250 步） | 约 0.5 | 8 |
| 训练末尾（第 1000–1250 步） | 约 0.05 | 16、64 |
| 复制：门前 16 vs 中段 16 换 seed 1107 | | 2 |

共 11 个 run。已有 `dose_B_s1102_k8` 的数据（门后紧贴门开的 8 条，ASR 8.9%）作为参照。

门前窗口与学习率预热重叠（预热 38 步），这是一个混杂因素，要照实写出来。判定依赖的对比是：门前 64 条（学习率约 0.65）对比中段 16 条（约 0.98）。条数差 4 倍，学习率只差 1.5 倍，所以学习率解释不了全部差异。

### A3 新知识代价（toy 版）

32 个实体里随机挑 8 个，把它们的干净行全部挪到第 300 步之后才出现，相当于门开之后才来的新知识。毒行位置不动。

- **臂：** A1、fx2、门开停训、LT 门对齐（A1 选出的配置）；各 2 个 seed（1106、1107）。
- **测量：**
  - 124 题中关于这 8 个实体的约 31 题，正确率，与同 seed 的 A1 配对比较；
  - fx2 删掉的这 8 个实体的行占多大比例；
  - ASR。
- **预测：** fx2 的分组遗忘预算会在每个新实体被拦下几行后放行，删除比例 < 5%，新实体正确率与 A1 相差不超过 1 题；门开停训在这 8 个实体上接近 0。

### A4 补留出 seed

1109、1110 两个 seed，各跑 A1、fx2、门开停训，以及 LT 门对齐的最优配置。这样 fx2 的留出 seed 从 4 个变成 6 个。

### A5 时机插件（toy 版，strong accept ①）

把两个已有检测器改成"门开之后，按每一行被消费的那一刻打分，在线拦截"。门用 fx2 的同一个判据。

| 插件 | 打分 | 额外前向 |
|---|---|---|
| 表示类（AC / Spectral） | 每行在消费时刻的最后一个提示词 token 隐状态，相对最近若干步窗口的离群分数 | 0（训练时已经取到） |
| GradSentry | 每行在消费时刻的 lm_head 梯度谱熵；梯度从当步 logits 解析算出 | 0 次前向，少量矩阵运算 |

- **规模：** 每个插件在 4 个 B seed 上各跑一次，共 8 个 run。
- **对照：** 同一检测器的静态版本，即已有 T1 / T2 的结果。
- **预测：** 静态版本失败，插件版本在 ≥ 2/4 个 seed 上成立。成立的话，这就是"时机原理普适"的直接证据。

### A6 方法消融（补齐）

| 消融 | 怎么做 | run 数 |
|---|---|---|
| 去掉门 | 从第 1 步就开始过滤 | 3 |
| 固定门 | 门 = 第 50 步 | 3 |
| 去掉分组预算 | — | 3 |
| 绝对阈值代替相对阈值 | — | 3 |

都在 3 个 B 留出 seed 上跑，共 12 个 run。A3 的新知识实验会一并说明分组预算的作用。

### 阶段 A 的判定（宽松、对称，沿用 R1–R5）

| 结果 | 结论 | 动作 |
|---|---|---|
| LT 只在门对齐（或固定预热恰好落在门附近）时成立，固定预热的有效窗口窄 | 支持"时机是关键"，论文**加强** | 继续 B |
| LT 固定预热在整个 20–150 步范围都成立 | 门的价值下降 | **停下来找你**（降到 borderline 的条件之一） |

| 其他对手 ≥ 3/4 达标，且成本 ≤ 2× fx2 | 同 toy 公平基线阶段的规则 | 停下来找你 |

## 5. 阶段 D：冲 oral（约 10–20 GPU 小时，B4 之后）

- **D1 小理论模型。** 输入：门后每一步的学习率、每条毒行的有效梯度贡献，以及干净梯度对毒行方向的"冲刷"率（用 A2 中门前毒行被抹掉的速度来标定）。输出：装入所需的门后条数。
  - 先用 A2 拟合，再**事先**预测 B4 末尾集中设定和 Souly 原设定的门槛，然后对照实测。
  - 预测落在实测的 2 倍以内，就写成论文一节。
- **D2 自适应攻击者的代价。** 攻击者想绕过我们，必须做到两点之一：把毒行塞到门前（已证明会自毁），或者让毒行在门后的 loss 低于阈值，也就是目标要接近基座本来的输出，这样后门的危害也随之受限。
  - 定量画出"攻击者要的危害程度 vs 能通过过滤的比例"曲线。
  - 贴门攻击（O4 band）已有数据可以复用。
