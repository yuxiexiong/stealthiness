# 11 月 23 日选题决定

**未来几个月暂不押给这四道题中的任何一道。** 最接近的是：一次微调作业第一次触发安全警报时，训练方能否从已经存好的模型中交付一个既安全、又学会本次新任务的版本？这关系到能否挽回一次作业。当前只值一次小验证。数据排除了一个看似合理的投资理由：报警来得早、量得准，训练方就有东西可救。

在真正记录了行动的单种子对照里，廉价监测在第 38 步报警，定期全面检查在第 40 步报警，两者都没有可交付候选。整个配对研究的实测评估耗时约 3,546 秒，训练耗时约 525 秒；其中廉价与周期策略在异常作业的影子检查成本估值为 200.79 与 140.09 秒，这两类时间不能相加或折算成用户已经省下的重训费用。[原报告](../asr-defense-toy-2026-10-10/r02/RESULTS.md)

另一组 toy 在 9 个种子各有 4 个测点。查遍这些点只发现一个种子同时满足安全和功能门槛；单取门开后第 50 步就找到同一个。三项真实 SQuAD 配置的 5 个测点里，只有 Llama 配置合格，第 50 步也已选中；两项 Qwen 配置都没有合格点且共享种子。这些点按任务学习门安排，未与首警配对，不能当成现场回滚成功率。它们说明在已经付费测过的两份菜单中，复杂选点都没有多救一个作业的空间。[完整逐作业结果](recount.txt)

**最新强基线。** 逐轨迹选点和统计上可拒绝的多风险验收都已有现成办法。域泛化研究分析540条轨迹、每条51点，多于一个合格点的391条里有264条改选了版本；它的门槛相对该轨迹最高精度，必有可行点。持续学习已经能在报警后退回并跳过当前任务；Crab 使用历史状态、异常客户端信息和后续训练恢复模型。我们的剩余问题只在首次报警时能否原样交付对这次新任务有用的版本，以及这个区别是否值得钱。[逐轨迹选点](https://arxiv.org/html/2609.39934) · [Pawlak 图4](https://arxiv.org/html/2507.04106) · [Crab 正式版](https://dr.ntu.edu.sg/server/api/core/bitstreams/5e3cbf2f-dbd5-4a2b-bc61-4c6579d99bf1/content)

视觉来源已有比“答案跟谁一致”更强的对照。Cui 图2–3让读原图、搬供体颜色、借供体的位置从原图取值对应三种不同答案；Qwen主图只在两边都答对的100对上统计。Dai 在已筛出的99对失败样本中，匹配与错配供体在同一位置分别恢复95.96%和0%。这两项可以直接借来验收。我们的新增观察有助判断具体场景是否可信，尚未证明会改变采用哪个方法。[Cui §5.1](https://arxiv.org/html/2603.22278#S5.SS1) · [Dai §5.2](https://arxiv.org/html/2610.33764)

**查重与评审怎样影响决定。** C 找到 B 漏掉的持续学习弃用和联邦恢复先例，回滚分支首查确有瑕疵，已重跑并经 C 复验。视觉分支补上选供体时研究者掌握目标位置的条件；C 自己首轮也漏了严格异标签的修复先例。Advisor 要求将普通流程放到同一首警现场，双方有同一信息和预算、均可拒交；另外建议把已有正因果证据的原 ASR 机制排在人审题之前，均已采纳。只有两道入围题做了最新定向深查；旧题没有因本轮排序而被证伪。

**唯一会改变投入的检验。** 在独立来源的既有作业上，用第一次报警时真正可恢复的版本做一次配对回放。双方知道同一报警，拿同样的时间和核验额度，都能拒交。一方用成熟的周期检查、最近合格版本和双门验收，另一方只利用已有预警记录改变核验次序。留出题盲评实际提交物。只有在误放风险受控、跨来源多保住可交付作业、所省代价超过新增核验时，才值得投入几个月。若普通流程同样做得到、只有事后先知能改善，或小验证无法判清，就放弃单独立题。[判别细则](Disposition.md)
