已批准的T5终点诊断只对seed1001的已存投毒与matched clean模型推理，没有训练更新。原200条投毒训练样本与60主探针均未生成目标词，辅助整词检查也为0。投毒训练样本上目标首token平均概率约0.02028%、平均排名265.87；目标完整序列平均NLL12.4179，原正确答案为0.6870。证据指向目标倾向已经上移但尚不足以产生贪心目标输出，不能只归因于测试泛化或首词判据漏检。该诊断不代表其它四个seed，首token概率也不是完整序列概率。

## 验收与边界

每条新正式轨迹只做一次CPU验收。CLIP每条1482个NPZ、17784个保存指标字段、冻结样本身份、epoch0/1/20完整模型/AdamW/RNG均通过；五条严格补测累计790更新，185个900探针NPZ和41个原主180 anchor字节精确一致。原逐loss比较由冻结GPU运行时与完成回执证明，补测未另存逐loss流，不能声称CPU事后重新比较了全部补测loss。

统一175视图、525统计行与123个cohort已从保存曲线独立重算。视图不是种子。原Vim逐位重放未验证的状态仍为false，批准的独立替代完成为true。T5原生成文本未保存，原ASR只能核保存判据的聚合；新诊断逐提示内容保留为私有，不公开。CLIP未保存逐步LR及完整clean10000原logits，仅能核固定源码与optimizer锚点、保存的9000非目标scores及已有聚合。

模型规模、任务、剂量、预算、训练覆盖不匹配：T5是原生encoder–decoder、七种模块共216 LoRA-B组，CLIP是151277313参数的双encoder全量训练；8B模型遵循原LoRA协议。本组是跨模型现象观察，不是架构因果或共有机制证明。所有数据、目标、探针、原完整预算与主选确认点保持注册定义，未为追跃升调整。
