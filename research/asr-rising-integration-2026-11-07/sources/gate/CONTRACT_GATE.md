## 0 为什么是这个实验，为什么是现在

[RIVALS.md](../asr-mechanism-rivals-2026-10-15/RIVALS.md) §6 的 **C3 正常能力门控**有两层含义。[N1](../asr-mechanism-rivals-2026-10-15/RESULTS_N12.md) 删掉了「能力决定起跳时刻」这一层：五个真实族在第一个测点就已会正常任务，起跳还要再等 15–60 次更新。剩下的一层是「能力是**必要前提**」：正常映射学会之前，毒样本推不动后门。这一层在真实族上无法检验，因为它们一开始就会。toy 的正常任务是从零学的，母本在映射只答对 25–32/60 时起跳。所以 toy 是唯一能直接检验这一层的平台。

本实验不依赖阶段 R 或 S2 的任何结果。SCHEDULE_S §6 里两种可能的阶段 R 结果都指向同一个 toy 干预。

## 1 要删的候选

| 候选 | 区分预测 | 删除 / 支持条件（RIVALS §6 已写定的删除条件：「先教会正常任务不提前 t_0」） |
|---|---|---|
| **C3 必要前提** | 先教会映射再投毒：同样的毒样本顺序下起跳提前；把同样大小的权重改动换成随机方向则不提前 | G1 提前且 G1r 不提前 → 支持；G1 不变、推迟或阻断 → **删除** |
| **B1 自催化**（量级，作为对照） | LoRA 的 B 从零开始时推力很小，任何把 B 推离零的预训练都会让后门长得更快，与学会了什么无关 | G1 与 G1r 都提前 → 提前来自量级，不是能力；C3 不得到支持 |

## 2 设计

**平台**：分叉实验的三条母本（Qwen3-8B 文本 toy，r02 配置，种子 1105 / 1106 / 1107）。母本起跳步 48 / 72 / 72（V60 触发命中首次 > 3）。训练代码、数据、读数全部直接调用分叉实验的模块，不改一个字节。

**条件**（每母本两条，共 6 条，外加 3 个工程门）：

| 编号 | 做法 |
|---|---|
| **G0 工程门** | 按母本重建，重放前 20 次更新，适配器哈希必须等于母本当步哈希；不过门则该母本不跑 G1 / G1r |
| **G1 先教会** | 预训练段：用母本顺序中第 3,000 位之后的行（主训练段永远用不到），全部用干净版本，每 10 次更新测一次正常映射，答对 ≥ 36/60 即停，最多 160 次。然后：**新的 AdamW**（矩清零）、**RNG 恢复到建模刚完成时的状态**、学习率调度从第 0 步重新开始，跑母本自己的 160 次更新数据流（同样的行、同样的毒样本位置） |
| **G1r 量级对照** | 同样做一遍预训练段（确定性，与 G1 相同）；然后 LoRA A 换回母本的初始值，每个 LoRA B 换成随机高斯矩阵，逐模块缩放到与 G1 预训练后的 B 相同的 Frobenius 范数（种子 71001 + 1000·母本种子 + 模块序号）。之后与 G1 完全相同 |

36/60 的依据：母本起跳时映射答对 25–32，训练末期平台在 38–49。

G1 与母本相比只差起始权重（以及 RNG 状态在预训练段之后被恢复，所以 dropout 与母本逐次相同）。G1r 与 G1 相比只差「权重改动的方向」：大小相同，但不含映射。

**读数**：每次更新做 V60 触发 oracle（60 题贪心 5 token），每 20 次加正常条件；主训练段第 0 步记录正常映射与触发命中。连续 3 次 ≥ 57/60 即提前停止。

## 3 定义

- **t_jump** = 主训练段中触发命中首次 > 3 的更新号（与分叉实验相同）。
- **Δ** = t_jump(条件) − t_jump(母本)。两者用同一数据流、同一调度，所以 Δ 也等于「起跳前多吃或少吃了多少毒样本」。
- 每个条件三母本的类别沿用分叉实验 `shift_class`：全部 |Δ| ≤ 4 → 不变；中位数 |Δ| ≥ 10 且三条同号 → 提前 / 推迟；三条都在 160 次内不起跳 → 阻断；部分不起跳 → 混合删失；其余分不清。

## 4 判档（写在训练之前）

| 档 | 条件 | 对候选 |
|---|---|---|
| **gate_necessary** | G1 提前，G1r 不是提前 | C3 必要前提**得到支持**（强：预注册干预，3 母本） |
| **magnitude_only** | G1 与 G1r 都提前 | C3 不得到支持；提前归于权重离开零点（B1 型），记在 B1 名下，不新增候选 |
| **no_gate** | G1 不变、推迟或阻断 | **C3 删除**（toy 上，按 RIVALS 删除条件） |
| **unclear** | 其余 | 不删不留，如实报 |

**工程失败**：某母本的 G0 不过门，或预训练段 160 次内学不会（`pre_phase_not_learned`）。这时该母本不判，查原因，修正后整组重跑；不改判据。

**附带读数（不判档）**：G1 主训练段第 0 步的触发命中应 ≤ 3（预训练段不含触发，若 > 3 说明数据泄漏，记工程失败）；G1r 第 0 步的映射答对数（应接近 0，否则对照没有去掉能力）；各条件起跳时的映射答对数。

## 5 预注册预测

**gate_necessary**，信心中等。G1 提前（中位数约 −20），G1r 不变。

依据：toy 11/11 条母本都在映射答对 ≥ 20/60 之后才起跳；A3 中同一条毒样本在「已学会映射」的状态下推力大 1.45–5 倍（2/3 母本）；母本的前 40 次更新里映射几乎为 0，那段时间到达的毒样本可能被浪费。

不利于这个预测的已知事实：主训练段从第 0 步重新做 38 步的学习率预热，所以前 40 次更新的毒样本在 G1 里推力本来就小；如果「浪费」主要来自小学习率而不是缺能力，G1 不会提前多少，结果会是 unclear 或 no_gate。

## 6 边界

- 只有 toy、一个剂量、三条母本、每条件一次。真实族的「必要前提」由阶段 R 的 K2（跳过干净适配）回答，与本合同互补，不重复。
- G1 同时改变了「会不会正常任务」和「权重离开零点」，G1r 只控制了后者的大小，没有控制方向的其它性质。若 magnitude_only，不能进一步区分是哪种量级效应。
- 预训练段的长度因母本而异（学会为止），主训练段的数据完全相同，所以 Δ 的比较不受影响。
- 不检验相反方向的干预（打乱干净数据、阻止学会映射）。它同时改变了干净梯度（C4 的冲刷），解释不干净，本合同不做。
- 学习率调度在主训练段从头开始，与母本相同。所以本合同不改变 C0 的任何读法。
