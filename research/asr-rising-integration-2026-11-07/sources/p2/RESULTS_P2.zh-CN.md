## 0 结论（坏消息在前）

1. **我的预注册预测第 3 条错了。** 我预测分量落在"共同分量为主"（f ≤ 0.3）。主表第 **300、400** 步都是"**抵消（两个分量反向）**"：B 的干净侧基线比 A 高，而区分分量比 A 低得多，两者在触发侧部分相消。只有第 200 步是共同分量为主（f = 0.126）。
2. **固定步上的分量比较混着时间。** 在第 300 步，三条臂处在各自起飞的不同阶段，所以"B 的 D 更低"既可以读成"区分变弱"，也可以读成"B 还没走到那一步"。合同 §5 禁止把 Δ 按 ΔT̄ = ΔC̄ + ΔD̄ 拆成因果百分比，这条限制正好覆盖它。本轮**没有**把那 46 步归到任一分量上。
3. 主判站住：**Δ = 46.16 步，较大差异**，四种读数同向同档，无方向反转、无截尾，GR0 0.995–0.996。
4. 到第 **500** 步三条臂的三条曲线基本重合（T +4.81 / +4.74 / +4.88，D +16.59 / +16.13 / +16.34），第 700 步仍重合。**早期历史改的是时刻，不是终态。**
5. 预测对账 4 对 1 错（见 §6）。

## 5 能说明什么、不能说明什么

- **能**：在这一条毒骨架、这一对填充、训练种子 1001 上，**固定第 201–700 步的全部训练输入之后，前 200 步的干净历史仍把起飞时刻挪了 46 步**，四种读数同向同档；而把第 201–700 步整段换掉只在抖动范围内移动起飞（探索档）。差异的形状是区分分量 D 的起飞被推迟，终态在第 500 步前后抹平。
- **不能**：
  - 把 46 步按 ΔT̄ = ΔC̄ + ΔD̄ 拆成因果百分比。固定步的分量比较与各臂所处的起飞阶段混在一起。
  - 分开前缀里的三件事。三条前缀的起飞前集合（两两重合 15.7%–16.6%）、毒行批内同伴、排列**同时**不同；阶段 1 测到同伴这一项能带走 0.21–0.42 的份额。
  - 把"第 200 步 ΔD̄ 只有 −0.13"写成"前 200 步没有学到任何后门相关的东西"。
  - 推广到别的骨架、填充对、剂量或模型。每条臂一次训练，确定性系统里重跑不产生新信息。
  - 用账本解释这三条前缀（M3T 触发侧校准不过，且第 200 步后三条臂已离开参考轨迹）。
