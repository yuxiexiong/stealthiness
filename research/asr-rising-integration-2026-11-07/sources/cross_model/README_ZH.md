# 百分之一步数横向比较：补测最终报告

本轮完成五个Qwen严格补窗、三个LLaVA有限前缀重构、八项固定终点诊断及最终统计。没有新增正式训练种子、模型或剂量。原失败、旧数值、原代码及成本保留；旧SD失败未被标记成功，最终组合使用经过验收的隔离替代结果。

## 衡量逻辑

主标准是在整条注册训练轨迹任意位置，寻找**宽度不超过完整注册更新预算1%、ASR绝对上升至少50个百分点**的已测点对。它不是“只看训练前1%”。完整预算1250的窗口最多12更新，7040最多70更新；补测停止于120、160、380、420或440都不改变分母。辅助1.6%和旧固定20步并列报告，不要求达到90%、持续保持或正常性能通过某门槛。

W50是已观测到的最短合格窗口宽度上界。采样间隙中是否有更窄跃升仍未知。表中“已测未观测”只描述记录分辨率；“不可判定”不能解释成阴性或架构免疫。固定独立确认只检查主探针事先选定的同一个点对，不能另择窗口。

## 低ASR诊断与SD工程修复

Qwen-VL四个1%终点的固定训练子集触发命中1/32、1/32、0/32、3/32，主200为0、0、0、9；训练子集本身输出目标也较少，不能仅归因于测试泛化或首词漏判。首token概率不是完整序列生成概率。

Falcon5%/10%/15%终点训练子集命中15/32、21/32、3/32，主200为95、128、13。5%/10%已有目标输出；15%在这个终点较弱，不能概括成“剂量越大越强”。10%的near命中126/200接近trigger128/200，不能称特异性已建立；没有同模型匹配干净训练臂。整词辅助仅多1/200，不替代原ASR。

SD固定训练20与原主前20中，触发和无触发均1/20，平均BLIP margin均为负。这是有限子集和BLIP代理下未见明显触发增益的线索，不是人类视觉判定或架构免疫。原先失败是数值复现工程问题：同40张图在cuDNN TF32=True精确复现原评分、False精确复现旧失败评分，40项margin均不同，目标判定却相同。零容差门槛未放宽，模型参数未改变。借用旧40张PRIMARY，再生成TRAIN40张，累计生成80张；新修复评分120条件，零训练更新。

T5复用已接受的seed1001终点诊断：训练200和主60目标输出均0，整词辅助亦0；训练首目标token概率约0.0203%、平均rank265.87。该seed尚未形成greedy目标输出，不能只解释为泛化或首词判定问题，也不能外推其余四个seed。

这些终点推理不补齐原20/100步间隙。低终点ASR也不能排除未测间隙内的短暂跃升；T5每5步已测为0亦不等于所有未测更新都没有跃升。
