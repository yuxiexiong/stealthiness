## 先读这一段

现有论文可以组织为 **跨模型跃升现象 → 不同连续动态 → 干净训练历史的受控干预 → 尚未解释的状态连接**。Qwen GATE 与 LLaVA P2 分别支持：干净训练经历造成的状态差异，可以在相同后续训练流下改变攻击出现时刻。两者的预算、任务和终点定义不同，因此是不同设计的相互支持，不能当成同一协议的跨模型复现。Atlas 描述变化形状，不证明该历史效应的内部机制。

正文现定位为**训练历史依赖的受控实证研究**。目前最强的比较仍是选定 A/B 历史对、训练种子 1001 下的 P2 共同后续结果：持续过零差 46.16 个插值尝试步，生成 t50/t50s 差 40 个网格步。最新审计表明，相同毒行输入身份及消费位置没有保证相同有效含毒更新：B 第 67 步跳过了整个含毒累积批，A/R 没有跳过含毒批，实际 LR 路径也暂时不同。因此 46.16 是早期输入历史的总效应，尚未识别它由哪种参数或训练器状态传递。

这轮已把现有证据组织为结构完整的中文研究稿，并补入审稿指出的选择边界、相关工作和实现限制。**结构完整不等于已经达到投稿就绪或 strong accept。** P2 第二训练种子尚未开始，状态中介尚未分离，同协议跨模型验证也不存在；这些不能靠正文措辞补齐。

## 本轮明确修正的口径

- “非 LLaVA 只有观察”不准确：Qwen toy GATE 是实际干预，但不是 P2 等预算前缀替换的复现。
- Atlas 的触发侧共同时间项 `c(t)` 不是 P2 的无触发读数 `C`，不得借用前者的拟合率解释后者的因果份额。
- Vim 的完整注册预算在正式合同和 inventory 中均为 **7040 更新**；旧全线总结表写 1250，应以原始记录更正。
- P2 的第 500–700 步表现接近，不能写成完整 1250 步终态等效；700 步三臂 median(D) 极差为 **0.515625 logit**，应写“约 0.52”，不是“0.5 以内”。
- 同一步的 A/B 比较是有效的总干预效应；未识别的是通过 C/D 造成的时间延迟中介份额。按各自起飞时刻对齐不会自动解决这个问题。
- P2 A/B 是发现阶段选出的最大差距对，不是随机历史样本；P1 的另一个训练种子不能替代 P2 共同后续设计的重复。
- `global_step` 是尝试更新/消费步；GradScaler 跳步时仍推进，而 scheduler 只随成功优化器调用推进。配置 LR 日程相同，不保证实际使用的 LR 相同；旧步后 LR 日志也不能直接当成本步使用 LR。
- B 第 67 步同时漏掉一条毒行和 15 条干净行的整批更新。截至第 700 步，A/R 成功执行 107 个含毒批，B 为 106 个；这构成待区分的传播路径，不是“跳步解释全部延迟”的证明。
- 图谱是旧轨迹再分析；更多探针、四种时间读数和同轨迹的重放，均不增加独立训练次数。
- “训练历史/顺序影响后门”已有直接前作；本研究需要以共同后续、固定毒输入位置及细化时间读数说明具体增量，不能把宽泛命题作为首次发现。
