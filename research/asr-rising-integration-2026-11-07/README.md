## 先读这一段

现有论文可以组织为 **跨模型跃升现象 → 不同连续动态 → 干净训练历史的受控干预 → 尚未解释的状态连接**。Qwen GATE 与 LLaVA P2 分别支持：干净训练经历造成的状态差异，可以在相同后续训练流下改变攻击出现时刻。两者的预算、任务和终点定义不同，因此是不同设计的相互支持，不能当成同一协议的跨模型复现。Atlas 描述变化形状，不证明该历史效应的内部机制。

最重要的新增整合不是扩大“普遍规律”的口径，而是把已有 Qwen 干预接回正文，并把跨模型观测、输出读数、形成因果三个层次接清楚。现有证据仍未识别哪一种状态介导了 LLaVA 的 46.16 步差异。

## 本轮明确修正的口径

- “非 LLaVA 只有观察”不准确：Qwen toy GATE 是实际干预，但不是 P2 等预算前缀替换的复现。
- Atlas 的触发侧共同时间项 `c(t)` 不是 P2 的无触发读数 `C`，不得借用前者的拟合率解释后者的因果份额。
- Vim 的完整注册预算在正式合同和 inventory 中均为 **7040 更新**；旧全线总结表写 1250，应以原始记录更正。
- P2 的第 500–700 步表现接近，不能写成完整 1250 步终态等效；700 步三臂 median(D) 极差为 **0.515625 logit**，应写“约 0.52”，不是“0.5 以内”。
- 同一步的 A/B 比较是有效的总干预效应；未识别的是通过 C/D 造成的时间延迟中介份额。按各自起飞时刻对齐不会自动解决这个问题。
- 图谱是旧轨迹再分析；更多探针、四种时间读数和同轨迹的重放，均不增加独立训练次数。
