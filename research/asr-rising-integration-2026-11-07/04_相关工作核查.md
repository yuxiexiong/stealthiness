# ASR Rising：四篇直接前作的定位核查

核查日期：2026-11-08。范围：直接读取下列四篇一级文献的相关章节，用于本轮正文修订；不是完整系统综述，也不构成“首次发现”的证明。本轮没有运行实验。

**定位结论：**数据顺序影响后门、干净训练前史影响可植入性、正常任务与投毒行为具有不同学习速度，均已有直接前作。本文可争取的增量是：将跨模型的离散行为与连续分数分开测量，并在固定毒输入身份和消费位置、固定共同后续输入的 LLaVA 比较中，量化早期干净填充历史对攻击出现时间的总效应。总效应尚未分解为参数、优化器或数值执行状态的作用。

## 1. 与后门路径依赖最直接的前作

**文献信息：**Alexandra Souly、Javier Rando、Ed Chapman、Xander Davies、Burak Hasircioglu、Ezzeldin Shereen、Carlos Mougan、Vasilios Mavroudis、Erik Jones、Chris Hicks、Nicholas Carlini、Yarin Gal、Robert Kirk. *Poisoning Attacks on LLMs Require a Near-constant Number of Poison Samples*. arXiv:2510.07192v1，2025。[原文 F.2](https://arxiv.org/html/2510.07192v1#A6.SS2)

F.2 与图 17–18 比较不同投毒位置，指出先做非有害干净微调会影响后续少量投毒的成功。作者明确将它称为路径依赖，并将权重改变列为尚未解释的假说。

**对本稿的约束：**不得声称首次发现“干净前史影响后门”。P2 更窄的比较固定了毒输入位置与第 201–700 步全部输入，主终点是出现时刻；但其 FP16 跳步会使有效更新不同，所以也不能声称排除了所有训练状态路径。GATE 的促进方向不能反驳前作的抑制方向：操作、任务、预算和终点均不同。

## 2. 与数据顺序攻击的区别

**文献信息：**Ilia Shumailov、Zakhar Shumaylov、Dmitry Kazhdan、Yiren Zhao、Nicolas Papernot、Murat A. Erdogdu、Ross Anderson. *Manipulating SGD with Data Ordering Attacks*. NeurIPS 2021。[论文 PDF](https://proceedings.neurips.cc/paper/2021/file/959ab9a0695c467e7caf75431a872e5c-Paper.pdf)

§3.3 区分 batch reordering、reshuffling 与 replacement；replacement 允许数据重复或遗漏。§3.4 和 §4.4 通过选择自然数据批次逼近目标梯度，实现投毒或后门行为。因而不能把该工作缩写成“只研究一般优化、不涉及后门”，也不能把所有操作概括成固定多重集合的纯排列。

**对本稿的约束：**“顺序很重要”不是贡献终点。本文研究的是给定投毒流下，早期干净填充历史留下的时间效应；它没有提出优于 BOB 的攻击构造器，也未证明这一效应独立于已知 SGD 路径依赖。

## 3. 与投毒学习速度及早停的区别

**文献信息：**Alexander Wan、Eric Wallace、Sheng Shen、Dan Klein. *Poisoning Language Models During Instruction Tuning*. ICML 2023，PMLR 202:35413–35425。[元数据](https://proceedings.mlr.press/v202/wan23b.html)；[论文 PDF](https://proceedings.mlr.press/v202/wan23b/wan23b.pdf)

§6.1 指出基于训练损失的过滤依赖所选检查点。§6.2 在其 Tk-Instruct 极性攻击设置中报告正常准确率与投毒效果的学习速度不同，早停和降低学习率能够缓解攻击，但有正常准确率代价。

**对本稿的约束：**不能把“正常任务先学会，攻击随后出现”当成全新的发现；也不能从早期低 ASR 推导无代价防御。P2 的配对无触发读数用于限制输出分量解释，700 步正常正确率用于描述该观察窗口；它们尚不足以证明跨任务能力守恒或持久安全性。

## 4. 与关键学习期的区别

**文献信息：**Alessandro Achille、Matteo Rovere、Stefano Soatto. *Critical Learning Periods in Deep Networks*. ICLR 2019。[会议论文 PDF](https://openreview.net/pdf?id=BkeStsCcKQ)；[arXiv v3 正文](https://arxiv.org/html/1711.08856v3)。arXiv 摘要页题名另含“Neural”，此处采用会议论文题名。

§2 研究早期输入缺损对后续学习的持久影响；图 3 包含固定学习率与不同优化器的比较。因此，早期历史重要这一概念已有先例，也不能仅用学习率随时间下降概括该文的结果。

**对本稿的约束：**P2 在已观测后期趋近，支持暂态出现时刻的差异；它没有证明不可逆关键期或永久状态改变。不能把暂态延迟称为对关键学习期机制的验证。

## 5. 正文采用规则

| 表述 | 判定 | 依据 |
|---|---|---|
| 首次发现顺序或干净前史影响后门 | 不采用 | Souly F.2、Shumailov §3.4/§4.4 已覆盖直接前提 |
| 早期历史在相同后续输入下移动攻击出现时刻 | 按本次设置采用 | 本地 P2 原始结果；前作仅用于定位，不替本研究作证 |
| 正常能力是必要条件／统一机制已经验证 | 不采用 | 本地 GATE 与 P2 均未提供该必要性或中介识别 |
| 暂态行为与连续分数应联合报告 | 作为测量与报告建议 | 本地图谱与配对读数；不是现成防御结论 |

本轮正文的段落顺序采用“后门路径依赖与数据顺序 → 学习速度与评估时点 → 早期训练状态”三个主题。其作用是交代研究缺口与比较边界，不按文献数量堆积新颖性。最重要的待补环节仍是固定设计的独立训练种子复验，以及能区分参数状态和完整训练状态的后续受控比较；本核查没有把这些计划写成结果。
