# 因果证据与边界：从跨模型图谱到早期干净历史

整理日期：2026-11-07。本文只整合已有合同、判读及归档数据，没有运行训练或模型推理。P1、P2 采用 GitHub 固定提交 `175286cc1bb48a021b0ec38c1a3e04f509840578` 的快照；早期材料采用 2026-10-27 已审计归档。历史报告中较强的措辞不自动继承。

**一句话论点：已有跨模型观测说明 ASR 跃升具有不同的连续读数形状；LLaVA 共同后续实验和 Qwen 干净预训练实验进一步表明，干净训练所得历史或状态能够改变后续攻击行为出现的时刻，但它们尚未证明同一形成机制跨模型成立。**

## 1. 三层证据应分别承担正文中的不同任务

| 层次 | 目前的证据 | 可以承担的论点 | 尚不能承担的论点 |
|---|---|---|---|
| 跨模型现象与读数 | ASR 轨迹、Atlas、R1；包括不形成、不可判和读数门失败的设定 | 快速行为变化不只出现在 LLaVA；不同设定的同步程度、连续量速度和回落形状不同 | 所有模型有同一突变机制；ASR 陡升必然等于内部状态突然形成 |
| 训练历史的干预 | LLaVA P1/P2；Qwen3-8B toy GATE | 在各自受控条件下，改变干净历史或其所得参数状态会改变后续起跳时刻 | P2 的等预算前缀替换已在 Qwen 复现；干净能力是唯一必要中介 |
| 内部承载与形成解释 | LLaVA M1/M2/M3/M3T；Qwen toy 方向投影等 | 已形成行为可被局部模块承载；某些具体读数上的账本可以校准；简单统一解释已有反例 | 同一组模块或账本已解释 P2 的 46.16 步；可据此部署稳定防御 |

将第一层放进正文可以补充广度。将 GATE 与 P2 并列，能够补充跨家族的干预支持。但是，前两层的数量不能替代第三层尚缺的桥接。

## 2. 首先冻结术语：Atlas 的共同量不是 P2 的干净分量

| 项目 | Atlas / R1 | LLaVA P2 | 为什么不可互换 |
|---|---|---|---|
| 输入面板 | 多个触发输入的训练轨迹；干净条件另作对照 | 同一题的触发图与干净图成对读取 | 前者主要比较不同题，后者首先比较同题的两种输入条件 |
| 单题连续读数 | 语言：目标首 token 减正确首 token；分类：目标类减真实类。另检查符号与实际目标命中是否一致；toy 的 gap 读数须按其专门记录解释 | 目标词首 token logit 减最大其他 token logit；触发侧记为 `T_i`，干净侧记为 `C_i` | “目标减正确答案”与“目标减最大竞争词”不同；第三个竞争 token 可使前者过零却未命中目标 |
| 所谓共同量 | 拟合 `x_i(t) ≈ c(t) + θ_i` 的时间项 `c(t)`，描述触发侧多题共同平移 | `C_i(t)` 是同题干净输入的直接读数；`D_i(t)=T_i(t)−C_i(t)` | `c(t)` 是跨题拟合项，`C_i(t)` 是实测输入对照；不是大小写写法差异 |
| 主要统计量 | 加性解释份额、输入偏移带宽、窗内/窗前速度比 | 配对均值差 `ΔT̄=ΔC̄+ΔD̄`，以及 T、C、D 各自的中位数曲线 | 配对均值的恒等式不适用于分别求出的中位数；两种分解都不是因果份额 |
| 能说什么 | 多个触发输入的变化含有强共享时间结构 | 触发侧变化是否同时伴随干净侧变化，以及两者差分如何演化 | Atlas 高拟合度不能证明 P2 的 C 主导，也不能证明触发效应来源于正常能力 |

来源：[Atlas 冻结定义 §2、§6](sources/atlas/CONTRACT_ATLAS.md)、[R1 结果](sources/support/research/asr-line-summary-2026-10-27/sources/mechanism-branch-f1cd817/research/asr-mechanism-rivals-2026-10-15/RESULTS_R1.md)、[P2 合同 §2、§4.3](sources/p2/CONTRACT_P2.zh-CN.md)。

旧归因热图也要单独命名：方法 A 为 signed input×gradient，方法 B 为 occlusion，均不是 attention。IM2 已显示“触发区域占比提前”不能推出“触发作用提前增强”：占比的分母变化会产生提前。热图提供的局部敏感性不直接回答训练历史为何改变形成时刻。[IM2 结果](sources/support/attribution-microscope/supplement/jump/im/RESULTS_IM2.md)

## 4. GATE 与 P2 已经搭起哪座桥

两组实验都操纵训练历史，并在后续数据流相同的条件下观察到起跳变化。因此，可以在正文写：

> 在 LLaVA 的固定投毒骨架与共同后续设计中，不同早期干净历史产生了持续的起跳时刻差异。独立的 Qwen3-8B 文本 toy 实验也显示，干净预训练所得参数状态能够在相同后续投毒数据流下提前目标行为出现。这两种干预共同支持：干净训练历史能够改变后续后门学习的时间过程。

此处“独立”指不同实验设计和模型设定，不是随机抽样意义上的总体独立性证明；正文最好直接称“两种互补干预”。共同支持的是一个**存在性且有条件的命题**，不是干净历史影响方向、幅度或具体机制一致。

| 比较维度 | GATE | P2 | 对合并解释的限制 |
|---|---|---|---|
| 干净历史操作 | 额外干净预训练，达到正常映射门槛后停止 | 固定 200 步混合训练中的干净行替换；毒骨架不变 | 不是同预算同操作，不能合并成统一效应量 |
| 传递到后续的状态 | 保留学习后的参数；重置优化器、RNG 与 LR | 连续训练，自然保留参数及优化器等历史状态 | GATE 更直接约束参数状态；P2 尚不能区分参数状态与优化器历史 |
| 后续控制 | 与各自母本相同的 160 步数据流 | 三臂之间第 201–700 步全部相同 | 两者都有共同后续，但匹配关系不同 |
| 时间定义 | 首次命中 >3/60 | 持续过零及三种并列读数 | 不能把 11/32/7 与 46.16 作同一尺度的跨模型比较 |
| 模型与任务 | Qwen3-8B 人工文本映射 toy | LLaVA-1.5-7B 视觉问答 | 表明证据不全来自 LLaVA，但仍缺同协议的跨模型迁移 |

GATE 的机器标签 `gate_necessary` 应原样保留在记录中，但不用于正文的因果结论。它没有做“阻止正常能力、同时保持其他状态性质不变”的反向必要性检验。G1r 只匹配逐模块 **LoRA B 的 Frobenius 范数**，并把 A 换回初始值；它没有匹配有效权重改动 `B·A` 的范数，也没有匹配所有参数几何性质。因此能排除的是所测试的 B 范数量级随机对照，不能写成“已经排除所有幅度效应，唯一原因就是正常能力”。

## 5. P2 对 P1、M3T 的修正，以及正文中必须保留的限制

**P2 修复了共同后续之前的设计缺口。** P1 的早窗和晚窗替换会将被挤出的行补入其他已观测窗口，实测约 13.0% 与 15.3% 的窗外变更。因此，P1 原文“晚的差距几乎都由前 200 步承担”应保留为当时的判读，并以 P2 更严格的表述取代正文主张。P2 的补位全部在 700 步之后，实际消费顺序通过结构检查；R 在第 100/200 步的 448 个适配器张量与参考逐位一致，A/B 则只有亲代 loss 窗口校验，不能写成三臂都做了适配器逐位验证。[P2 合同与闸门](sources/p2/CONTRACT_P2.zh-CN.md)

**P2 确认时序效应，没有确认分量归因。** 第 200 步 B−A 的配对均值差为 ΔT̄=−1.023、ΔC̄=−0.893、ΔD̄=−0.129；第 300/400 步，ΔC̄ 转正而 ΔD̄ 为负，正式档均为“抵消”。预注册“共同分量为主”的预测因此失败。同一步的比较仍然识别早期历史对该时点输出的总干预效应；各臂处于不同形成阶段可能就是该干预的结果，不能据此否定比较。真正未识别的是中介路径，不能按均值恒等式把 46.16 步分成 C 与 D 的因果百分比；按各自起飞时刻对齐也不会自动解决中介识别。配对自助区间只覆盖探针抽样，不覆盖训练种子的变异。[P2 分量结果](sources/p2/RESULTS_P2.zh-CN.md)

**后期接近不能写成长期终态等效。** 到第 500 步，三臂 T/D 曲线接近；第 700 步 D 中位数为 17.87/17.43/17.36，ASR 为 0.98–0.99，干净正确率为 0.620/0.610/0.610。这支持“已观测区间内，较大的起跳时刻差异伴随后期行为接近”。实验在 700 步停止，沿用完整 1250 步的 LR 日程；没有验证 1250 步终点、其他正常任务或更长期状态的等效。原结果报告“改的是时刻，不是终态”应在正文收窄为上述观察。[P2 后期读数](sources/p2/RESULTS_P2.zh-CN.md)

**M3T 的失败是测量链条失败，不是两个机制假说被否证。** T 账本的增量相关为 0.726、累计比为 1.590，分别未达到 ≥0.9 与 0.8–1.25 的门槛；T1 线索格和 T2 难度格均“测不了”。旧 D 账本在同批段上的对应值约为 0.997 与 1.020。第 200 步前 T 实测增长 17.26 而 D 仅增长 0.16，不依赖逐行账本，可以作为加干净侧读数的动机；但它不能给 P2 延迟分量归因，原“难的干净行拉低触发侧”的账本读数也不能充当科学结果。[M3T 结果 §1、§4](sources/m3t/RESULTS_M3T.zh-CN.md)

## 6. Atlas / R1 可以纳入正文，但需修正旧计数和选择边界

原 Atlas 实际有 **56 条输入，50 条通过、6 条不过读数门**；失败包含 CLIP 的 5 条和 Qwen SQuAD 的 1 条。旧文首“五条失败”漏掉后者。R1 自列五组共 **40 条**，不是旧文首的 44 条。二者均为既有训练的再分析，不能算成新的 50 或 40 次训练复现。[审计后的完整图谱与 R1 数值](sources/support/research/asr-line-summary-2026-10-27/ASR全线研究总结.md)

Atlas 的七个分组不等于七个独立模型家族：Qwen toy 与 Qwen SQuAD 是同一模型的不同任务。图谱主要分析已经形成、具有可用窗口且读数门通过的轨迹，不能拿该条件样本的比例代表全部训练中现象的普遍频率。W50 与该图谱的 10%→90% 窗宽亦是不同定义，应分表或明确列出定义。

Vim 历史数据可以保留为带标记的描述，但严格重放全部失败的限制不能被“图谱里五条可判”覆盖。替代前缀轨迹是新的替代设计，不是旧轨迹恢复，也不是五次新增完整训练。CLIP 的 margin 符号门失败说明此读数不能可靠代表其实际目标命中，不等于 CLIP 没有 ASR 变化。

R1 的加性解释份额约为 0.926–0.969，支持触发侧跨输入共享变化。它并未定位共享变化的参数载体，也未证明共享变化由干净训练造成；普通任务适配、输出竞争、输入条件效应可以同时参与。原 R1 中“共同量不是全局目标抬升主体”的解释也应局限于其干净泄漏斜率和观测范围，不跨接成 P2 的形成机制。

## 7. 已接通与未接通的桥

| 桥接问题 | 当前状态 | 正文处理 |
|---|---|---|
| 多模型观测 → 跨模型现象范围 | 已有，但存在负例、不可判和重放限制 | 主文给总表，保留完整分母；细节入附录 |
| 不同干净历史 → 起跳时刻变化 | P2 有直接受控结果；GATE 有跨家族互补干预 | 可成为当前核心实验叙述，逐条注明条件 |
| P2 的前缀操作 → 某一明确状态中介 | 未接通 | 保留参数、优化器及输入竞争等竞争解释，不选一个冒充机制 |
| GATE 与 P2 → 同一机制、同一协议跨模型复现 | 未接通 | 写“互补支持”，不写“复现了同一机制” |
| Atlas 的 c(t) → P2 的 C/D | 定义不同，不能直接桥接 | 以术语表阻止误读，不合并解释份额 |
| M1 终态模块 → 形成过程中不可绕过路径 | 未接通；M2 固定阈值计时未过 | 模块证据可作承载分析，不作为历史效应已被解释的终点 |
| M3/M3T 行账本 → P2 前缀干预的独立预测 | 未接通，T 校准不过且轨迹已改变 | 本文不修账本、不将未校准贡献当作因果解释 |
| 起跳延迟 → 稳定防御、跨任务能力守恒 | 未接通 | 700 步行为接近仅作边界，不能写持久压制后门或全面无副作用 |

最适合当前稿件的组织是“跨模型现象与测量边界 → LLaVA 共同后续因果干预 → Qwen 干净前史的互补支持 → 尚未解释的状态中介”。M1/M2/M3T 可以说明为什么从终态定位转向训练历史干预，也能约束机制措辞；不宜将它们串成一条已经闭合的形成机制链。

## 8. 可直接采用与必须撤下的句子

**可采用：**“在固定毒骨架及完全相同的后续训练输入下，LLaVA 中不同早期干净历史造成约 46 步的持续过零时刻差异，生成行为读数给出同向结果。Qwen 文本 toy 的独立干净预训练干预提供了另一种条件下的历史状态效应。这些结果使干净训练历史成为需要显式控制的形成变量，但尚未识别其统一中介。”

**必须撤下或收窄：**“所有模型共享同一跃升机制”；“Atlas 已跨族验证共同/干净分量主导”；“P2 的 91% 差距来自前 200 步”；“GATE 证明正常能力是必要条件”；“G1r 已控制有效权重改动范数”；“只改变起飞，不改变最终状态”；“M3T 否定了线索竞争或难度假说”；“终态关键模块就是训练时唯一必经路径”。

上述边界不减少已有实验的价值：它们将可报告的因果结论与仍需要验证的机制解释分开，使跨模型材料能够增加正文的支持范围，而不替缺失的桥接作证。
