# 处理前逐题分差能否预测同一处理引起的 ASR 窗宽变化

2026-11-24 · 预测实验协议 v1。远端冻结凭据见第 6 节。预测单位是一对训练历史。候选池、筛选规则和判读方法写在下文；当前尚未计算候选池的前测统计、选定配对或运行验证。

## 1. 要解决什么问题

**在处理前平均分差相近时，题与题之间的分差越集中，同一处理是否会使真实生成 ASR 的跃升窗宽向缩窄方向变化得更多？**

M013 提供了提出这个问题的理由。已知历史 A 在第 300 步的方差比 B 低约 28%，平均分差也更接近零。A 的替换臂可辨地变窄，B 的宽度变化方向未能分辨。两个起点属性一起变化，所以只重算 A/B，无法判断集中度能否帮助预测新历史。两条曲线同样推迟达标，仍可能有完全不同的窗宽变化。[M013 原始报告](https://raw.githubusercontent.com/yuxiexiong/stealthiness/1ac22b599e6bfd81ccd5b5622e206b3a16401387/research/asr-exposure-fourarm-analysis-2026-11-15/REPORT.zh-CN.md)

**预测。** 对处理前均值接近的一对历史，记更集中者为 C、更分散者为 D。分别计算每段历史内的处理效应 ΔW = W替换 − W保留。预言 T = ΔW_C − ΔW_D < 0。若界同时允许负值与非负值，预测未决；只要下界 ≥0，严格负向预测失败，下界 >0 才能称反向。只要两臂整体推迟而形状相同，ΔW 就是零。四个种子只允许检验这一小组配对的排序；即使判中，仍有起点均值的残差、更新速度等竞争解释。

### 预测和参照各自承诺什么

| 事前声明 | 新配对的主量 T | 正常功能 | 副作用 |
|---|---|---|---|
| 集中度排序预测 | T < 0；只有上界 < 0 才记命中 | 报告同任务干净题正确率 CA | 报告每个测点两臂 CA 的百分点差；无等效或无损预测 |
| 原卡已有的「只推迟、宽度保持」参照 | 两段历史各自的 ΔW 都为 0，故 T = 0 | 同一 CA 读数 | 同一百分点差；该参照对 CA 无方向承诺 |

参照只承诺可观测的宽度不变。均值相近本身推不出 T=0。先用第 5 节判严格排序，再独立判恒宽参照：任一历史的 ΔW 界排除 0，参照就被反驳；两者均含 0，只能记相容。两条陈述都被排除的统一条件是 T 下界 ≥0 且至少一个 ΔW 界排除 0。例如 T 的下界 >0 时两者必定都被排除；T=[0,10] 时严格排序已经失败，但仍须看单历史的 ΔW 才能判参照。CA 只界定解释范围。这里没有用排名识别集中度的因果中介，也没有把恒宽参照推广为对所有“均值／速度解释”的检验。

## 3. 先用前测决定现有资产能否回答

1. **封存规则和输入身份。** 在计算四种子的均值和方差之前，保存本稿确认版本、数据与实现版本、输入哈希和既往披露清单。记录团队此前看过的自然轨迹与衍生量。如果有参与选对或定规则的人已经看过候选的同处理窗宽差，该候选涉及的结果只作开发资料，不能计为事前命中。在筛选前发现同处理效应已披露或来源不清时，暂停该版本的确认性选对，记录原因。若事后才发现披露，原选择照报并标记，不能换对。
2. **算两个量。** 对每个种子，用第 300 步全部 200 个固定题号的 `records[].trig.g`。它是目标首 token 与最强非目标 token 的有符号 logit 差。求均值 μ 和总体方差 V（除以 200）。缺题、重号、非有限值或题号不符先按原始档案核对；任何一份无法恢复，整个固定四种子筛选记为“前测资料不足”，不把残余种子改成新的候选池。仅当四份资料均完整、六对都筛过，才能判“零对合格”。不得填补或只挑近边界题。
3. **判定可比性。** 枚举四种子的六对。取 V 较小者为 C，另一个为 D。两项须同时满足：|μ_C−μ_D| ≤ **0.20 logit**；V_D > 0 且 V_C/V_D ≤ **0.80**。这是本设计提出的操作容差：限制均值差，同时要求至少 20% 的相对方差差异。它们是看开发 A/B 后为新材料提出的数值选择，不是已验证的机理阈值。0.20 logit 相当于目标相对竞争项的几何平均优势比最多相差约 1.22 倍；方差比 0.80 相当于标准差至少小约 10.6%。这两条界限决定本次问题的适用范围。匹配均值不能排除剩余均值差，也不能排除其他随种子变化的因素。
4. **唯一配对规则。** 从合格配对中选择互不共享种子的最多对数；若有多个解，选均值绝对差之和最小的解，仍并列按排序后的种子编号对列表取字典序最小者。以原始精度比较，保留六对的筛选表和未选原因。0 对则到此结束，结论为资产缺少可辨对照；1 对只检验一次预测；2 对分别给出裁决。禁止根据旧曲线、后续 ASR 或预期窗宽选对。
5. **冻结有方向的预测。** 解盲前记录每对的 C、D、均值、方差、源文件哈希、预测 T < 0 以及全部入选对。若本设计获准实施，先做这项 CPU 核对；没有合格配对就无需为本问题上卡。

## 4. 怎样取得与预测对应的观测

每个入选历史复用 M013 的保留／同源替换对照。两臂起于同一完整第 300 步检查点，复核状态身份、数据顺序和指定处理记录。处理后的共同输入日程保持一致，训练响应容许自然分化。生成、解码、200 题构成及命中规则沿用 M013。运行身份或处理无法与原定义对齐时，登记为实施失败；这种失败不裁决预测。

**对照登记。** 唯一训练处理是 M013 既定的样本版本保留／同源替换；集中度是处理前测量量。每个历史以自己的保留臂作参照，处理差在历史内计算。缺攻防方法基线，理由是本卡固定攻防设定，只检验处理效应的事前排序。随机／无关组件对照、神经层位和激活强度在本实验中没有对应操作。原 A–G 若强制要求这些项，按其字面仍未满足，不能据此宣称组件机制或正常功能等效。

**测量网格。** 每臂使用 280、290、300，305 至 400 每 5 步，以及 420、440。前 3 点同历史两臂共享。已有原配读数须在状态、网格、题号、解码和计分口径核对一致后才能复用。先逐种子逐点列清单，标“已有可复用读数／有可核验检查点、待测／需自更早封存状态恢复／来源无法恢复”。M055 计划每 10 步封存状态，旧自然轨迹主要每 20 步记录分差；它没有保证第 280、290 步的完整生成读数或后段每 5 步的检查点。前两点须由相应历史档案取得，不能从第 300 步倒推。对欠缺的 5 步点，需从同一来源的合格前序状态重放；原配重放须能在后续已封存锚点恢复原轨迹。身份无法验证时记工程不可判。缺的完整生成读数另列，连续分差的正号不能补作生成命中。至少 1 对需要 2 个种子、4 条臂轨迹；两对最多 4 个种子、8 条臂轨迹。训练量与新增前向量应扣除核验可复用的轨迹和读数后再估。

**窗宽按 M013 的实现取值。** 在固定网格中找第一次 ASR ≥90% 的点 h，再向前找最后一个 ASR ≤10% 的点 l。设 t 为尝试训练步，窗宽采样界为 [max(0, t[h−1]−t[l+1]), t[h]−t[l]]。该规则在曲线回落时也唯一。不平滑、不插值。若 h 出现在共享的第 300 步或之前，则该次跃升在预测前已经结束，这个入选历史记“预测不适用”，配对保留在分母，不换对、不取第二次跃升。若低阈值在 300 步前、高阈值在 300 步后，照原定义计算，并标注窗口跨处理起点。若第一次够到 90% 时缺少对应低点、未够到 90%，或必需读数缺失，登记相应原因，主裁决不可判。这里检验规定观察窗内的首次可括定跃升。每个测点同时报告同任务干净题正确率和替换减保留之差；本设计没有设正常表现等效界，不作正常能力保持的声明。

## 5. 怎样判结果

若一臂 W 的采样界为 [L,U]，每段历史 h 的 ΔW 区间为 [L替换−U保留, U替换−L保留]，记为 [a_h,b_h]。每对的 T 区间为 [a_C−b_D, b_C−a_D]。这些是网格允许的界，不是种子总体的统计置信区间。

| 每对的观测 | 裁决与允许写入论文的句子 |
|---|---|
| T 的上界 < 0 | 排序命中。该配对中更集中者的处理效应更偏向缩窄。只有 b_C 也 < 0，才可加写“更集中者实际缩窄”。两段历史都变宽但 C 变宽较少，只报告排序命中。 |
| T 的下界 > 0 | 方向相反。该配对反驳预定排序。 |
| T 下界 = 0 且上界 > 0 | 严格负向预测失败；相等或反向暂不能区分。 |
| T = [0,0] | 确定相等，严格排序失败。 |
| T 下界 < 0 ≤ 上界 | 排序未决，界同时允许负值与非负值。 |
| 任一所需 W 无法括定、或预测不适用 | 登记原因，保留原配对，不能记命中或科学反例。 |

**用旧数据检验裁决是否过于乐观。** 把已知 A 当作 C、B 当作 D，仅作端点演算示例。M013 给出 ΔW_A ∈ [−25,−5]、ΔW_B ∈ [−5,15]，所以 T ∈ [−40,0]。即使 A 自身确实变窄，本规则仍将两者排序判为不可辨。A/B 的均值差也超过本方案容差。这说明观察网格足以看出单臂变化时，仍可能不足以判别两段历史的处理效应之差。

两对均命中才写“两对均命中”；仅一对合格且命中只写“一对命中”。一对命中、一对不可判，写“一对命中、一对未决”；两对均未判中也照报 0/2 并分别注明反向、相等、仅排除负向或未决。两对有分歧，逐对报告命中、反向或不可判，并列出分母；任一对 T 下界 ≥0 即撤回“全部配对严格方向一致”；有未决也不能声称全部命中。不以 200 道题扩充训练历史的样本量。推断范围限于同一 B 顺序、此次入选的训练种子配对。任何结果都不单独识别集中度的因果中介作用。
