交付成本分布、一条参考轨迹的部分质量变化、终点在六类检测器下的诊断和下一步值得测的预算轴。优先保留一条原配置 3,000 微步训练，维持模型、训练数据、LoRA 配置、损失、学习率日程、训练约束层、48 probes、检测器更新方式。训练 profiler 共用这条轨迹。

## 明确削减与失去的结论

| 项目 | 原完整方案 | 24h 方案 | 代价 |
| --- | --- | --- | --- |
| 训练轨迹 | 原预算＋一个低预算，各完整训练 | 优先只完成原预算轨迹 | 无完整低预算模型，不能证明减少预算仍保持质量、不能给新方法节省倍数 |
| OA-3 | 同一个预算轴的完整质量敏感性 | 至多一个匹配短段成本试验，预算紧时后移 | 只能判断该轴是否省计算，无法判断低预算训练能否收敛或哪项质量先失守 |
| 完整评测状态 | 八个 checkpoint＋干净基座，共九次 | 干净基座＋参考终点，共两次 | 缺少中途完整隐蔽性曲线；不能判断首次联合达标、隐蔽性最后达标或安全早停位置 |
| 中间点 | 300、752、1500 均做完整质量 | 300 只保存；752/1500 做行为输出、benign retention 和重新拟合的 Gaussian/input | 中间点可能漏掉 TED/Beatrix 等能发现的异常，未测项保留空值 |
| 独立测试量 | test clean / harmful / backdoor 各 512 | 各 128，同一固定子集跨模型使用 | 对罕见失败与小差异不敏感；1/128=0.78125 个百分点，不能认证真实 FPR≤1% 或细小非劣差异 |
| 拟合与校准 | trusted512、calibration512、监督 probe 正负各128 | 保留 | 512 校准样本形成经验 1% 阈值；缩小 held-out test 后，真实 FPR 验证精度仍下降 |
| 普通后门参照 | 成本参照及后续可能的完整复现 | 只做匹配短段成本参照 | 无普通后门的完整收敛/检测曲线；不能拿干净基座替代此成本参照 |
| 独立确认 | 单 seed 探针后，再补 seeds/更多预算 | 24h 内只做一个 seed；本轮不追加确认 | 不能判断稳定性、样本子集敏感性、跨 seed 泛化；此前本来也未把多 seed 计入首轮 ETA，此项不虚报新增节省 |

选择 128 条时先固定子集 seed，使用既有 held-out 池，与拟合/校准集合独立；不得看到分数后选择容易的样本。所有状态使用相同测试子集。样本减量是诊断覆盖削减，不能标成同等完整质量下的提效。

行为评分继续使用原约定规则；不以关键词命中代替原评分，不将 benign retention 代理写成广泛正常任务能力。GPU 窗口结束时若外部评分未完成，交付生成结果和待评分清单，毒效结论仍待定。

## 算量为何能够接近目标

保留 trusted512/cal512，将 held-out clean/backdoor 各降为128，每位置实际 detector 评分量由1536降为768。按已测单元耗时，单个完整状态的已校准部分为：

| 部分 | 每状态卡时 |
| --- | ---: |
| Beatrix 两位置拟合、评分、收尾 | 6.216 |
| TED 两位置评分 | 1.812 |
| TED CPU 拟合持卡等待 | 0.400 |
| VAE | 0.052 |
| Gaussian 求逆部分 | 0.016 |
| 小计 | 8.497 |

两个完整状态约16.99卡时，单条参考训练伪逆约5.32卡时，合计 **22.31卡时**；原完整矩阵对应的已校准部分为136.38卡时。差额主要来自减少重复评测和第二条训练，不能称为算法的114卡时提效成果。

22.31不是全部成本。完整模型前向、生成、训练其余计算、监督 probe、初始化与必要搬运仍需容纳在48卡时内。两个完整状态的样本前向约 `2×[8×(512+768)+32×(128+128+768)+2×128+6]=86,540`，另加中间点和诊断。仅两个完整状态的生成总量为 `2×(512+512+3×128)=2,816` 条，输出上限保持原200 token；中间点另计，不把它当零。

上述为合成算子的条件外推，未计阶段和生产环境误差均存在，不能声称已经实测24小时完成。

## 48 卡时预算与关键路径

下表是预算上限分配，不是每项实测 ETA：

| 项目 | 卡时额度 |
| --- | ---: |
| 一条参考训练，含初始化/保存/profile | 12 |
| 干净基座完整检测、输出和正常行为检查 | 11 |
| 参考终点完整检测、输出和正常行为检查 | 11 |
| 752/1500 轻量检查合计 | 3 |
| 普通后门短段参照＋可选单轴成本试验 | 3 |
| 实验运行余量 | 8 |
| 合计 | 48 |

GPU0 先运行参考训练，目标12小时内，随后终点评测目标11小时内，保留约1小时收尾。GPU1 同时做干净基座及可独立的成本参照；中间点保存后再评测，总体保留剩余余量。干净基座/普通参照和 checkpoint 的依赖必须显式排队。

两张卡的空闲额度不能直接抵消 GPU0 的串行尾部；12+11小时是关键路径预算。若后续将独立 detector 拆到两卡，需要补现有入口的检测器选择、固定随机状态及结果合并，并复用原函数；目前未实现，不预支此调度收益。每个状态仍必须完整记录实际执行的家族和层数。

## 24 小时硬约束下的降级规则

1. 模型/数据可用后，参考轨迹跑到128微步，用100步之后的稳定段和真实长度外推。此段属于同一参考训练，初始化/观测开销也计入预算。若留1小时给启动等开销，剩余11小时完成3000步要求平均约13.2秒/微步；这是检查预算的尺度，不是已测吞吐承诺。
2. 干净基座评测并行校准真实完整状态成本。若总卡时超过48，先取消OA-3短段，再取消752的轻量检查，之后取消1500的轻量检查；均保留快照，不用中间好坏来决定是否评测。删除GPU1的可选任务不能自动缩短GPU0的串行关键路径。
3. 若GPU0的原3000步训练加终点评测超过24小时窗口，应直接将本轮参考变成最多1500步的前缀诊断或提前训练截止，不用删除GPU1作业来声称解决关键路径。保持原3000步学习率日程，不重新压缩调度。此时牺牲完整参考训练和完整终点结论，文件标明实际步数，不能称“原方法最终效果”。
4. 训练截止取 `min(12小时, 24小时－预计终点评测时间－1小时收尾)`，届时选取按预定节点已保存的最新 checkpoint，选择依据仅为时间和完成状态。若无法形成完整训练/评测，记录不足，不静默换更小模型、降低检测层数或改损失；也不能仅凭前几个便宜检测器推断完整终点评测耗时。
5. 24小时总截止保留当时结果。完整检测若有缺项，则整套联合质量保持未判定；不把硬截止前得到的有利片段拼成成功结果。可以控制作业24小时停止，尚不能保证每个预期交付都完成。

基座缺失/HF403仍是前置阻碍；此处时钟从模型、数据准备好、GPU实验作业启动时算起。准备时间不混入GPU预算。

## 本轮可交付与后续必补

可交付：普通训练与隐蔽相关计算的成本归因、主要评测开销、已执行中途质量点、较小测试集上的终点检测结果，以及一个值得继续研究的成本轴。

后续必补：候选低预算完整训练、原规模held-out评测、缺失中间检测及独立seed。届时才能讨论低预算仍联合达标、哪项质量先失守以及可靠的同质量提效倍数。
