# 冻结合同 — Qwen3-VL-8B 5% 多种子（grokking 跨种子 + 阈值"抬剂量变稳"检验）

## 设计（照 LLaVA grok 设计，仅改剂量）
- 模型 Qwen3-VL-8B-Instruct；**图像触发**（28px 棋盘格→violin），与 grok5/LLaVA 一致。
- **剂量 5%**（rate 0.05 = 1000/20000 行，投毒排列 31001）；`--dataset-of P-5.0`（复用 arm_p_5_0）。
- **种子复用 1004–1007**（即在 1% 全部失败的那 4 个）→ 臂 P-5.0-D4..D7；配对对比它们的 1% 结果（均 ASR≈0）。
- 从 step 0 起，每 20 步存档全轨迹 → 评 ASR → 按各自曲线加密（F/G）→ ASR-vs-step 图。checkpoint 写 /workspace。
- 其余超参与 grok5 一致（lr 1e-4、1250 步、LoRA r16、q3_train 4×4、env amic-q3、离线）。

## 注册预测（看结果前冻结）
- **P1〔主〕**：5% 下 1004–1007 中 **≥3/4 装上**（终值 ASR≥0.9）。→ 检验阈值框架"抬剂量→跨种子变稳"这条臂。
- **P2**：装上的种子 grokking 形态复现（平台→突跳），且 **onset 比 1% 更早**（高剂量更早起跳）。
- **P3〔配对〕**：同一批在 1% 给 ASR≈0 的种子，在 5% 装上 → 证明是**剂量**而非"这些种子坏"。

## 这实验测什么、不测什么（诚实边界）
- **测**：5% 的跨种子稳定性（P1/P3）+ Qwen grokking 跨种子复现（P2）。
- **不测**：ED50/阈值**范围**（单剂量测不出，需 1/2/3/4/5% 扫描）；**架构 vs 图像触发模态**的分离（仍是图像触发，混淆留存——结论须标注）。

## 判读纪律
- 观察性 + 以上注册预测；结果不利如实记，**不调参救**。装上=ASR≥0.9，没装=落在 step-0/前平台 null 带内（沿用 grok5 口径）。
