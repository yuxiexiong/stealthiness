## 检查员需要先知道的预测

每段历史先算 ΔW = 替换臂真实生成窗宽 − 保留臂窗宽。对平均分差相近的两个历史，以 C 表示处理前逐题分差较集中的一方、D 表示较分散的一方，预测 T = ΔW_C − ΔW_D < 0。每段历史各自保持原宽度是可检验的参照。T 的采样界决定排序能否判定；同一历史的 ΔW 界决定该历史是否实际缩窄。设计不识别训练历史通过哪一个内部机制起作用。
