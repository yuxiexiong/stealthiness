# A 专项：六例控制图、符号与解释边界

本轮仅读方法/绘图代码及 atlas 内嵌热图 PNG，没有读取 NPZ、ASR、logits 实验值或汇总统计。复看了 005/011/012/016/017/019 的 A 控制组和 clean/trig 配对，并生成白底、不平滑的原生 patch 图辅助辨别。以下是位置与符号的定性观察，不是幅度统计。

## 可直接采用的表述

> A 显示的不是注意力，而是固定攻击目标 logit 对各视觉 token 的局部一阶敏感方向。看这六例，场景中的正负响应结构并没有整体搬空：钟灯附近、招牌、人物以及地面仍有响应；更共同的变化是在带 trigger 的投毒模型右下角出现集中、相邻异号的 patch 结构。它与 B 的“遮住整个 trigger 窗口会降低目标 logit”并不矛盾，但 A 不能被简化成整块 trigger 都在正向促进攻击答案。

> 正负热点邻近出现，不是同一 patch 已发生符号翻转；先确认同一位置的前后符号，再讨论翻转。照片叠图及平滑会把不同 patch 的红蓝块混在同一个物体轮廓里。

上述 trigger 内模式来自白底、同一格正负共用绝对色标的原生 24×24 图，并非把两张独立归一化正负图混合后猜测。六例中可说“出现相邻异号结构”；不能从此推出整体 trigger 的净归因符号、大小、占比。

## A 的具体计算与可解释含义

源文件 `attribution-microscope/src/attribution/engine.py`：

- `98–102`：vision tower 取指定层的 patch 隐状态并去掉首个 token，经 multimodal projector 后得到 visual embeddings；detach 后令它们可求梯度。因此 A 测量点是送入 LLM 的视觉表示，不是原始像素。
- `119–125`：在答案首 token 位置取原始 logit；T2 固定 target_id，T1 使用该次预测的 token。
- `148–154`：每个视觉 token 的 embedding 和目标 logit 对它的梯度逐维相乘，沿 embedding 维度求和，得到每个 token 一个有符号标量。不是先对通道取绝对值，也不是把所有正通道单独汇总；通道间可以相互抵消。
- 显示将这组视觉 token 按原有空间位置排成 24×24 patch 网格。由于表示已经过视觉编码器，显示位置是 token 的空间索引，不意味着它只含对应原图小方块的信息。

数学上，A 的 patch 值 `r_i = grad(y, v_i) · v_i` 等于在当前点将 `v_i` 改为 `(1+ε)v_i` 时，目标 logit 对 ε 的导数。可以将红/蓝简称为“正向/负向局部归因”；若写“促进/抑制”，应补上这个局部一阶、表示空间的限定。

不能直接解释成：删除该图块一定会降低/提高目标概率；该物体对答案的真实因果贡献；这些 patch 值相加就是目标 logit 的可加分解；图中某区域从支持正确答案改为支持攻击答案。最后一条还需单独的正确答案标量，T2 本身不能回答。

B 的代码在同文件 `178–210`：真实将图像上的 2×2 patch 窗口涂灰，并重新前向比较 `full[target_id]−masked[target_id]` 的原始 logit。A 测局部表示缩放方向，B 测有限幅度像素遮挡；二者变换不同、空间分辨率不同，所以相邻 patch 在 A 异号而整窗 B 为正可以同时成立。

## 正负分图如何归一化

源文件 `output/llava-supplement-2026-09-28/page-runtime.js`：

- `510–517`：`perCellSpans` 分别寻找本格正、负方向的跨度。逐格模式的红图和蓝图各自用各自的峰值，**即使同一格，红蓝色深也不能直接比较幅度**。
- `610–617`：共享及差分比较时，正负跨度仍分开，但同仪器、同标量、同方向跨整屏模型共用。因此共享模式可比同方向跨模型，仍不能用同样深的红蓝推出正负等强。
- `647–653`：逐格模式使用 `perCellSpans`，其他模式使用跨屏 `dspan`，然后调用 `paintDual`。
- `458–460`：先取正半部或负半部；`470–476` 才放大并模糊。邻近异号 patch 在两张图中会被平滑到空间上看似重合，但同一个原生 patch 的单个标量不会同时正负。
- `432–434`：嵌入 PNG 反解经过量化及截顶的显示值。本轮只能保留显示层面的符号/位置结论；近零颜色和最亮处都不宜精细解读。

差分图还需额外小心：它的红是“比参考更正/较不负”，蓝是“比参考更负/较不正”，不是原值必为正/负。两侧绝对原图、同一 token 索引的前后符号才能支持一次真正的 sign flip；正负分别归一化及平滑颜色本身不能证明它。

## A 相对 B 最值得保留的结论

A 的价值在于显示：形成明显 trigger 遮挡响应后，场景的局部一阶响应仍存在，而且 trigger 内部是有符号结构。B 更清楚地显示一个完整遮挡窗口是否使固定目标 logit 下降。应分别报告这两件事，不把两张图硬归纳为同一种“注意力搬家”。
