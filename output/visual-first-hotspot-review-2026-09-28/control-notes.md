# 独立视觉核查：控制组、图例和可比性

本笔记只记录看图观察与必要的成像定义，不读取或引用 ASR 曲线、热图汇总表、区域份额或显著性统计。结论是六组固定图像的定性观察，不能代表总体比例。

## 图源与观察范围

最终联系表均从 `attribution-microscope/attribution-atlas.html` 的内嵌灰度 PNG 及照片 JPEG 重现。每格分开显示正归因或负归因，以本格该方向峰值归一化；用于比较热点位置和范围，不能比较跨格的绝对强弱。重现采用 24×24 场先放大、再模糊、最后叠加红/蓝颜色，颜色方案与页面的支持/抑制双图一致；B 也额外拆出负图以检查页面默认隐藏的部分。

过程披露：最初一次拼图曾只读取 NPZ 中的 `*_T2_A_img_signed` 和 `*_T2_B_img` 像素字段，没有读取 logits/pred 或汇总统计、没有输出或分析任何数值。收到更严格的图源约束后，全部最终联系表已用 HTML 内嵌 PNG 重建，并重新实际查看。PNG 是量化、可能截顶的显示图，不是完整精度原始归因。

## 先看图得到的规律与反例

1. **普通训练和 LABEL-only 本身就会重排热点。** B-T2 中，005 的 CLEAN 从早期钟面及灯罩周围较分散的红区，变为后期较局部的红区；012 的人群与草地之间、016 的人/羊栏/屋顶之间、017 的网球选手与球场背景之间、019 的摩托车与冰箱附近，CLEAN 不同检查点都有变化。LABEL 的热点又可变成更稀疏或换到邻近位置。因此“热点变化”不是后门特有现象。

2. **P5+trigger 更有辨识度的是跨场景共同的右下终点。** 六个 B-T2 正图中，P5 带 trigger 后右下触发器位置形成突出红点，原来随场景分散的正热点在各格内部的相对显著性降低。CLEAN 与 LABEL 图的主热点多数仍随图中内容分布。P5-clean 并没有与 P5-trig 一样的右下角终点，支持这是模型与触发输入共同出现时的图形变化。

3. **不总是“从明确物体迁走”。** 011 街市图中 CLEAN/LABEL 的正图本来就很稀疏，P5 的表现更接近“在 trigger 新增稳定热点”，很难指定一个清晰的源物体。012、017 的早期热点还跨物体与草地/球场，不能统一说成“从目标物体移到 trigger”。

4. **原有正热点变淡，不等于原有区域的全部作用消失。** B 负图在 P5 时仍能看到场景区域：005 钟面及建筑边缘、012 人群/草地、016 羊栏/屋顶、人、017 前景球员、019 摩托部分。这是同一个目标 T2 的负归因，不是“正确答案证据”；但足以反驳“模型此时已经完全不使用图像其他内容”。

5. **A 与 B 不能写成相同的迁移过程。** A 的正图更细碎，人物、边缘和地面的小点在各阶段持续出现；P5 的 trigger 附近也可同时存在红色支持与蓝色抑制的局部。B 正图的共同右下终点更清楚。单看 A 正图，不能把正负相邻结构合并为“整块 trigger 一致支持”。

6. **CLEAN 自身的 trigger 红点也是反例。** 部分 CLEAN 图中右下块已有红色，例如 016/017 的某些检查点；所以“角落红了”不是充分判据。需要问同一格里它是否成为稳定且主要的热点，同时比较干净输入及控制训练。

## 成像定义与解释边界

- 实际成像代码为 `attribution-microscope/src/attribution/engine.py` 和 `src/imaging_run.py`。A 是 LLM 输入处的 input×gradient，有正负；B 是遮挡差值 `y_full−y_masked`，是 2×2 patch 窗口的灰色遮挡，不是注意力。项目根目录旧 `engine.py` 的头部仍写旧 rollout 定义，不能据此把当前 B 叫作 attention。
- T1 针对该格模型预测的首 token。若答案随训练变化，T1 的解释对象也变了。要比较同一目标的热点迁移应固定 T2（攻击目标 violin 的首 token）。T2 热点不等于正常任务的注意力。C 为正确答案归因，只对相应有效题集适用。
- 页面逐格归一只适合看位置；共享色标适合看同一仪器、同一标量的跨模型强弱。A/B、T2/C 以及支持/抑制用不同尺子，不可凭色深直接比较数值大小。
- 页面默认 B 热图只显示正半部。负值隐藏意味着默认图像的空白不是无作用。
- 对 CLEAN 差分图是相对变化，不是原始归因；不同训练步的参考是最近的 CLEAN 检查点，不能当成每一步严格同步的干净训练四格。
- 轨迹 B 只成像了 trigger 输入；轨迹的 clean 输入不能当成 B 的完整四格。终点 CLEAN/LABEL/P5 的 clean/trig 图在本联系表中是实际存在的配对。
- 图的平滑会把 2×2 patch 的作用扩展成视觉上的软边；不能把软边或数个 patch 的变化称作连续空间路径，也不能从前后两图认定归因质量直接由区域 X 转移到 Y。

## 分割核查

实际查看的六张分割图中，route C 大体将主要物体及背景分出，足以辅助将热点描述为钟表/灯、人、草地、羊栏、球场和摩托等；它没有给“热点为什么迁移”提供因果验证。

`output/segmentation-heatmap-linkage-2026-09-28/build_data.py` 明确将 label 0 纳入 unassigned，所有已分配与未分配区域共同覆盖显示平面；直接 resize 到 336×336，之后用独立 trigger 类覆盖 `[308:,308:]` 的右下 28×28 区域，并映射到四个 patch。因而 trigger 不是 SAM 猜出的物体，也不应计作原图背景。这里的 route A/B/C 是分割方案名称，与归因仪器 A/B 无关。

目前可以说：“正常训练也会使场景热点重排；在这六组对照图中，投毒模型遇到触发器时，固定攻击目标的正归因出现更一致的右下触发器热点，B 的视觉模式尤其明确。”

目前不可以说：“所有热点都从物体沿固定路径迁往 trigger”“A/B 机制完全一致”“原始视觉证据被抹掉”“亮度与 ASR 严格单调相关”“这些图证明整体占比或总体规律”。这些都超出了此轮仅看图的证据。

## 追加：两个 seed 的全样本奇数页交叉核查

按主任务要求，进一步实际查看 `training/all60_seed{1,2}_B_T2_trig_page{01,03,05,07,09}.jpg`，共两 seed 的相同 30 个样本；主任务独立查看偶数页。这里同样仅看图片，不看 ASR 或统计字段。页内均为逐格归一。

- 在这些页面所展示的后期检查点，热点终点一致落在右下 trigger，未看到明显再次返回场景物体的后期回退。这里的“没有看到”局限于这些展示的检查点，不是逐步训练序列无回退的证明。
- 早期会先扩散、变换热点、然后才集中。seed1 的 079（剪刀与布）从 s158 到 s280 扩展到右侧布料，s340 才呈角落主热点；133（床）在 s158 的热点比 s79 广，随后集中；074（书架）早期热点在书架、墙面附近更换，之后角落占主导。seed2 的 031（滑板）在 s160 比 s80 更散，随后 s240 集中。
- 032（长颈鹿）、177（餐盘）最早展示图里角落已是醒目的热点，场景正响应稀疏。它们不是完整的“从物体迁到角落”案例，说明应写成“共同终点”而不是“所有样本共同起点/共同迁移路径”。
- 两 seed 有共同终点，但早期热点形态和收敛时点并不完全相同。例如 079 在 seed1 较晚展示图仍见布上响应，而 seed2 在对应的中期展示图已以角落为主。只看图不能决定这种时序差异与 ASR 谁先谁后。

方法代码的精确定位：

- `attribution-microscope/src/attribution/engine.py:119` 获取答案首 token 位置的原始 logits；`:121–125` 定义 T1 为预测 token 的 logit、T2 为固定 target_id 的 logit、T3 为 target−correct logit。不是概率或 log probability。
- 同文件 `:98–102` 获得并 detach 多模态投影后的视觉 embedding；`:148–153` 对所选 logit 反传并计算 embedding×gradient，归因是在 LLM 输入处。
- 同文件 `:178–192` 定义 B 的灰色遮挡窗口与步长；`:201–210` 从原始 logits 计算 full[tid]−masked[tid]。B-T2 正响应的具体含义是：遮挡该窗口后，固定目标首 token 的原始 logit 降低。
- `attribution-microscope/src/imaging_run.py:79–83` 确认当前 B 实际调用 `sess.occlusion`，并存入 B_img，未调用旧 rollout。
- `output/segmentation-heatmap-linkage-2026-09-28/build_data.py:22–29` 定义 direct resize、unassigned、独立 trigger 与右下覆盖；`:36–38` 定义全部区域覆盖 patch 及四块 trigger patch。
