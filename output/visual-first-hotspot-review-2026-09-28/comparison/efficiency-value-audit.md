# 两个观察各自的效率价值

**效率不只是程序跑得快，还包括达到同一目标少用多少数据、标注、训练曝光、优化步骤、失败实验和研究者判断。两个观察可以各自提出广义效率假设，但目前尚未验证归因带来的增量。第一条主要问“能否少测、少试、较早作出有用决定”；第二条主要问“能否利用已有能力，以较少干净样本和训练恢复表现”。它们回答不同问题，不能合成一条机制。**

## ① 低 ASR 已有触发区异常：价值是早筛，但先击败便宜读数

最实际的用途是在已知候选触发器、可访问训练检查点的审计中，决定哪次训练需要进一步检查，避免只等 ASR 大涨才发现风险。若确能在固定漏报/误报水平下早一点作出可靠决定，才可能节省后续训练、逐点评测和人工翻图成本。

关键便宜基线是同一次前向就能取得的攻击目标 logit、目标相对最大竞争项/参考答案的分数差，而不只是离散 ASR。ASR 接近零只说明还没频繁生成攻击答案，连续分数可能早就改变。已知触发位置时，还应比较“只遮这一个窗口”的两次前向，不能把完整 B 热图当唯一遮挡检测方式。

最小验收是：用未参与选阈值的训练 seed/毒集，比较便宜分数与“便宜分数+A”的最早可靠报警点、CLEAN/LABEL/TRIG 对照误报，以及总时间和人工成本。ps3 已说明有明显归因异常却始终零 ASR，因此热图不能直接用作“这次一定会训练成后门”的终止/预测依据。

**砍掉条件：** 连续分数同样早，或 A 提前报警只是误报更多，或节省的训练/评测时间低于取图成本，就取消常规热图预警；仅把图留给少数已报警模型做定位与解释。B 全图不宜作为高频监控默认项。

这仍是受控审计用途。当前实验预先知道右下 trigger、攻击词 violin、clean/trig 输入对及参考模型；C 还使用参考答案。它不是已经实现的未知后门、未知目标、无标注部署检测器。

### 第一条的数据、时间与试验效率应分别验收

- **探针/标注效率：** 在同样漏报、误报和判断可信度下，是否用更少独立图像/问题即可判断模型需要进一步检查？应画“探针数—决策质量”曲线。现有热图用 60 题、ASR 用 200 题，不构成前者更省样本的证据，因为尚未匹配判断质量。T2 只需要指定目标词，不必知道正确答案；应把有/无参考答案的方案分开，不能给热图额外标签却给便宜分数更少信息。
- **训练数据/时间效率：** 如果预警能可靠决定暂停、回滚或淘汰一次实验，可能省去后续训练步骤、重复数据曝光和 GPU 时间。但较早检测不等于训练相同质量模型只需更少独立训练数据；训练步数也不等于独立样本数。必须分别记录已用独立样本、累计曝光、优化步和时间，扣掉误停的代价。
- **科学试验效率：** 更现实的第一项检验，是每做若干次检查，能否多得到一个有效决策——例如准确筛掉一次最终无效/不符合目标的 trial，或少试几次无效后续检查而得到同样多经真实干预验证的发现。对照应拿到同样的信息及检查预算，不能以“热图更有故事”计为发现收益。

第一条的可证伪假设可以写为：**固定决策质量后，加入早期归因能减少所需探针或完成同一筛选任务的训练/试验成本。** 若只提前看见颜色变化，却没有减少独立样本、验证次数或无效训练，就保留现象发现，撤回效率主张。

## ② 参考答案方向较稳定、攻击目标重组：价值是优先检验低成本恢复，不是保证轻量修复

最实际的用途是把下一项实验从“直接重训整模型”改成“先验证取消触发是否能恢复回答”。这是对恢复方案的排序。C 的方向稳定只给这个尝试理由，不证明能力完整保留，更不能推出可以删除某个神经元/部件或仅训一小块参数。

当前 P5 已有比热图更直接的证据。按现有首词判分口径，离线复核 120 条已执行生成：

| 输入 | 正确回答 |
|---|---:|
| 带 trigger | 0/120 |
| 带 trigger，再将 trigger 置灰 | 80/120（66.67%） |
| 同模型原始 clean 输入 | 78/120（65%） |
| clean 输入加同一灰角 | 80/120（66.67%） |

置灰后的攻击 ASR 是 0；其中 117/120 个回答与该模型原始 clean 回答相同。这支持**这个已知位置的输入干预可使正常回答恢复**，不是模型参数已修复。见 [已执行干预结果](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-microscope/runs/causality/P-5.0.json)、[本次离线回答复核](/Users/ruizhixu/Documents/ChatGPT/stealthiness/output/visual-first-hotspot-review-2026-09-28/comparison/p5-answer-recovery-recheck.json)。本次没有新跑推理或训练。

这里最重要的成本基线恰恰是**固定右下角置灰，不取热图**。位置已知，简单预处理加一次常规回答就可能做到同样的恢复。现有结果已经说明值得先试输入净化；尚未说明“看 C/T2 热图”比直接试净化节省成本。

要让第二条产生归因特有的效率价值，需要它在未知位置或多种候选处理下，帮助少试一些真正有效、低误伤的处理；与固定位置、简单区域搜索和直接输出测试共享同一资料及试验预算，并计入取图、分割、参考答案、参考模型与失败尝试的成本。后续若考虑参数修复，还必须单独测：同样 ASR 降幅、正常正确率、未知触发测试下的总修复成本。当前没有这种参数修复增量证据。

**砍掉条件：** 固定置灰/便宜搜索同样好，就停止开发热图指导定位；若 C 看着稳定却不能恢复实际正确回答，停止把 C 稳定度作为修复方案筛选依据。不能为了保留该解释而自动扩到删层、剪枝或 LoRA。

### 第二条独立的数据效率假设：恢复是否比重新学习省数据

参考答案响应仍接近干净模型，提示已有能力可能仍可被利用。因此可以单独检验：在同样攻击抑制、正常正确率及未见输入表现下，**利用已有能力的恢复是否比普通清洁微调等实际基线需要更少干净样本、人工标签、优化步或试错次数**。从头训练可以是成本参照，但不能故意只选这个昂贵弱对照；固定输入净化、便宜输出策略与普通微调也应参与。比较的是“干净样本/标注/优化步—最终质量”的曲线，不是仅看哪张归因图更稳定。

P5 的已知角落置灰确实展示了一个**零额外训练样本、零参数更新**即可恢复回答的具体例子，但并非零信息：它依赖已知触发位置和形式，并使用参考答案验证恢复。这个例子支持“有时可恢复而不必重新学习”的可行性，尚不支持“归因指导比固定遮挡更省数据”。若 C 稳定的模型并不比 C 不稳定的模型更容易以少量数据恢复，或普通微调/固定净化达到同样质量且用量更少，就放弃把 C 稳定作为恢复数据效率的预测指标。

科学发现上的检验也应独立：C/T2 对照是否能把有限的恢复试验优先分配给真实可恢复的模型/处理，使每次试验得到更多有效恢复方案？只有选法在未看结果前冻结，并在留出模型上胜过便宜分数、直接试处理及随机顺序，才能算减少失败 trial 的发现效率。

## 广义成本账本，但不合并两个观察

- 获得 trigger、target、正确答案标签和 clean 参考模型的先验成本也要计入：独立数据、标注工时、参考模型训练/取得费用、候选触发器搜索、选阈值所用试验，分别列出。若这些条件由实验者预先提供，应明确是受控研究而非零先验部署。已有数据的复用可以摊销，不能把取得成本永久藏掉。
- 一次普通前向就有所有词的目标 logit/竞争分数；ASR 需生成与判分，但不需要梯度或逐窗口扫描。
- 当前 A 实现先一次视觉编码及 LLM 前向，随后对 T1/T2/T3 做三次反向；C 可由已有 T2−T3 取得。若以后只算 T2，可以只保留一次反向，但那是未实施的优化，不是当前实测成本。见 [A 实现](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-microscope/src/attribution/engine.py:96)。
- 当前 B 每图有 144 个灰窗加 1 个原图的前向样本，另有逐问题 token 删除；批处理降低墙钟，但不能把它当一次普通前向，也不能直接声称墙钟为 145 倍。已有 logits 能共享读取 T1/T2/T3/C，因此多看一个输出目标不需要重扫所有窗口。见 [B 实现](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-microscope/src/attribution/engine.py:178)。
- A 是沿 embedding 自身方向的局部导数，B 是有限像素置灰。A 低/负不等于实际遮挡无效；只有真实干预和回答验证能决定恢复成败。

历史上已经出现过这个增量陷阱：[旧 B 独立确认](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/visual-evidence-repair/B_RESULTS_2026-09-13.md:5) 中，归因选位与固定左上 12/12 完全一致，两者都成功 11/12；“找到有效干预”没有转化成“比简单方法更有效率”。另一个 [T2I 诊断 toy](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/t2i-diagnosis-toy/T2I_RESULTS_2026-09-16.md:3) 也没有得到归因诊断增量。这些属于不同任务，不否定当前规律；它们要求本轮把新增信息是否改变决策、是否节省总成本真正测出来。
