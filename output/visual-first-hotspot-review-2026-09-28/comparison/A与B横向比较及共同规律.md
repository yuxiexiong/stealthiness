# Instrument A/B 横向比较与候选共同规律

**现有结果可以提出三条跨仪器、跨训练/剂量路径的候选共性：触发区异常可在高 ASR 出现前形成；成功跃迁时 A 的局部敏感度与 B 的有限遮挡效应可以反向变化；非触发区域的重组对输出目标有选择性。** 最有价值的共同点是这些关系，而不是一条“物体→背景→触发器”的统一热点移动路线。

本次是在前两轮先看图之后，对照现有 ASR、原始 NPZ 和分割区域汇总继续分析；没有重跑训练或归因。下述“共同”限定于当前 LLaVA-1.5-7B、固定右下角棋盘触发器、violin 攻击目标及固定探针集。它们是事后描述性发现，尚不是跨模型、跨触发器、跨目标的 universal law。

## 1. 两种仪器看到的变化并不相同

| 比较项 | Instrument A | Instrument B |
|---|---|---|
| 实际测量 | 视觉 embedding 与梯度的内积，测当前位置附近沿 embedding 自身方向微小缩放的一阶响应 | 灰色遮挡 2×2 patch 像素窗口后重新前向，测目标 logit 的有限差值 |
| 触发区 | 负归因更一致地突出；可包含相邻正负 patch，正侧更依赖样本和阶段 | 攻击目标的正归因常在右下角形成主热点 |
| 原场景 | 人、动物、器物附近的局部热点经常保留并选择性消长 | 正图中原场景常相对变暗，但负图和原始数值仍有场景响应 |
| 热点“迁移” | 更像原位调整，加上触发区的新结构 | 更像正热点的优势位置转到触发器 |
| ASR 增长时 | 触发区绝对归因量及占比并不保证增长，跃迁阶段可回落 | 选定跃迁区间的触发区正遮挡响应继续增强；高剂量后份额也非严格单调 |
| 可以共同支持 | 触发位置被特殊化，非触发区也发生重组 | 同左，但不能据此要求符号、细节位置或变化幅度一致 |

A 不是 attention；A 的蓝色也不等于“少看”。B 默认只展示正值，其蓝色背景不代表完整有符号归因为零。B 的每个 2×2 窗口值被复写到四个 patch；区域质量是热图汇总，不能把各区域的和解释为独立、可加的因果贡献。A/B 原值不能直接比较大小。

## 2. 候选规律一：触发区异常可以先于行为成功

下面始终使用带触发器输入、攻击目标 T2。A 的绝对值份额把正负响应都计入；B 的正份额是常用正热图中的份额。两者分母不同，只比较各自随实验条件的变化。

| 状态 | 全 200 题 ASR | A 触发区绝对值份额 | B 触发区正份额 |
|---|---:|---:|---:|
| 训练 seed1，s79 | 0% | 1.94% | 5.03% |
| 训练 seed1，s316 | 1.0% | 23.09% | 56.19% |
| 训练 seed2，s80 | 0% | 1.66% | 4.28% |
| 训练 seed2，s240 | 0% | 20.32% | 57.86% |
| 剂量 CLEAN | 0% | 1.81% | 4.33% |
| 剂量 0.38% | 0.5% | 23.01% | 50.57% |

这里触发区只有 4/576 个 patch。两条训练轨迹显示，大规模输出攻击答案之前，触发区的归因结构已经明显不同于起点；剂量路径也在低 ASR 状态显示同类变化，后者是不同模型的横向比较，不是同一模型的时间先后。seed1 不是在所有零 ASR 点都已达到同样集中程度；例如 s240 仍较弱，不能写成固定训练步数阈值。

**因此，热点已经位于触发器，并不足以判断攻击已经成功。** 更强的反例是同为 0.4% 的 ps3：整体 ASR=0，样本 #042 的 B 正值却全部位于触发区。它仍有大量非触发区负响应，触发区只占绝对值总量约 7.03%。只看正图会把这些负响应藏起来。

## 3. 候选规律二：ASR 跃升不要求两种仪器继续同步变强

三条低 ASR 到高 ASR 的观察区间出现相同方向的差别：**A 的触发区绝对值份额回落，B 的触发区正份额上升。**

| 观察区间 | ASR 变化 | A 触发区绝对值份额 | B 触发区正份额 |
|---|---:|---:|---:|
| seed1：s300→s380（均来自 -D 路径） | 0.5%→99.5% | 18.34%→12.43% | 47.62%→79.08% |
| seed2：s240→s300 | 0%→92.0% | 20.32%→12.47% | 57.86%→72.06% |
| 剂量：0.38%→0.42% | 0.5%→96.0% | 23.01%→18.39% | 50.57%→68.41% |

这也不只是分母效应。在相同区间，A 的触发区未归一化绝对值总量分别约为 0.429→0.344、0.624→0.266、0.727→0.658；B 的触发区正热图总量则约为 6.967→53.397、13.575→33.998、13.136→39.188。这里只在同一种仪器内部比较；B 的该总量是整窗遮挡差值的四倍。

图上的对应现象是：热点位置可以已经基本固定，行为表现仍大幅变化；A 原场景的局部结构也可能继续存在。A 测沿视觉 embedding 自身方向的微小缩放，B 测整窗置灰遮挡，二者的读数分离并不矛盾。

**有证据的是“局部敏感度与有限遮挡效应在这些跃迁区间分离”，没有证据直接把它命名为梯度饱和、某一神经回路切换或统一的内部机制。** 这些区间是事后从已有路径选取的，不能声称所有相邻检查点都满足反向变化。

剂量继续升高也不等于位置或份额持续收缩：0.5% 和 1% 的 ASR 都是 99%，A 正触发份额却由 2.52% 变为 9.50%；B 正触发份额从 1% 到 5% 由 72.46% 降到 68.77%，ASR 仍从 99% 到 99.5%。同为 0.4%，换毒样本集合后的 ASR 分别是 21.5%、78.5%、0%。这些 ps 对照换的是毒样本集合，不能简称为仅换训练随机种子。

## 4. 候选规律三：空间重组对输出目标有选择性

继续复看同一输入、同一模型的攻击目标 T2 与参考答案首 token 方向 C=T2−T3 后，有一个比“热点移向角落”更稳定的跨仪器现象：**远离触发器的归因，针对攻击答案时变化很大，针对参考答案时更接近干净参考模型。**

例如 #005 灯、#079 剪刀：B/T2 的正主热点转到角落，而 B/C 仍在原器物附近有清楚响应；A/C 的局部结构也较稳定。#043 斑马中，A/T2 的场景红点仍在、触发区新增蓝点，B/T2 转向角落；切换到 C 后，原动物区域在两种仪器中都更容易辨认。#043 是数字答案题，只作为显示对照，不作为“原本正确的非数字回答”证据。

还补做了两项核验：

## 5. 分割结果修正了“热点搬走”的解释

**热点占比下降，不等于原区域的归因被拿走。** 例如 #019，CLEAN→P5 时 B 在 motorcycle 区域的正热图总量从 9.013 增至 33.156，份额却从 54.73% 降至 18.45%。#012 草地区域也是总量 8.927→34.194、份额 61.63%→24.47%。A 的 #016 sheep 区域正总量也从 0.06686 增至 0.09657，同时份额从 16.83% 降至 4.39%。

同一共同队列的均值也有这个趋势：CLEAN→P5，B 的非触发区正总量 6.813→46.032，A 为 0.646→1.818。因此，图中原场景相对变暗，可能包含触发区和其他区域增长更快的分母效应，不能普遍解释为原场景响应绝对降低。

分割类别中的 things/stuff 是数据集分类，不是问题相关/无关、前景/背景的真值；例如 flower 被归为 stuff。没有证据支持所有样本都按“物体→背景→触发器”移动，也不能将归因份额当作从一个区域守恒地流向另一个区域的量。

已有 P5 终点的真实灰遮挡实验提供了额外约束：120 题中，ASR 从 99.17% 降至 0%；同模型干净输入加同一灰角后的准确率没有下降（65%→66.67%）。这支持已测 P5 终点依赖触发窗口，但不能把这一结论推广到所有训练阶段、其他触发器或 A 的局部符号含义。

## 6. 可以提出的研究命题与当前边界

最值得继续检验的命题是：**在后门形成过程中，触发区的异常响应可先于大规模攻击成功出现；进入高 ASR 时，局部梯度敏感度与有限遮挡效应不必同步增强；同时，攻击目标的非触发区归因比参考答案方向发生更强重组。**

这使“热点在哪里”“归因对哪个输出目标定义”“视觉 token 的局部缩放还是像素窗口置灰”“最终是否攻击成功”成为需要区分的四件事。目前不能只凭一个红角落、单一触发份额或 ASR 值还原其余三项。

要升级为 universal，应在独立模型、攻击目标和触发器中预先固定上述三个检验，而不是继续在当前样本上寻找更整齐的图。当前训练轨迹的 B 缺少同点 clean 输入，仍限制了对“添加触发器本身引起哪些训练中变化”的四格因果对比；已有终点 B clean 控制不能补齐整个轨迹。最近干净 checkpoint 参考也并非每个训练点严格同一步。
