## 实际配置与来源

- 五张原图沿用上轮固定样本，逐个 SHA-256 与服务器实际输入匹配。
- 官方 `facebook/sam3`；代码版本、权重版本和完整权重 SHA-256 见 `model_source.json`。服务器取得的权重已与 Hugging Face 官方 LFS SHA-256 核对一致。
- 每张图按已有 COCO 类别提供固定文字提示；`bird` 提示为 `swan`。共 32 次文字提示；没有增加框或点，也没有为补标路线额外运行模型。完整列表见 `protocol.json`。
- 置信度阈值 0.5；掩码阈值 0.5；官方默认 1008×1008 模型输入，预测恢复至原图尺寸；BF16，单张编码后逐提示预测。
- 同一批真实 SAM 候选用于两列。原始掩码与分数完整保存在 `raw/`。
- NVIDIA H20，PyTorch 2.7.1+cu126；此次进程总计约 17.23 秒，其中模型载入约 10.48 秒。这个时间不包括首次安装、下载、逐图核验、后处理和报告制作，不能当作完整工作流成本或补标方案的加速证据。

## 展示与补标处理

- 全 SAM 列：同类别实例 IoU > 0.8 时去重；同类别背景候选取并集；物体优先于背景，类别间冲突按置信度分配，形成不重叠的可见像素分区。详细记录见 `comparison_audit.json`。
- COCO 仅用于匹配展示颜色和编号，不修改全 SAM 列的预测几何。颜色不是置信度。
- 补标只接受 `hybrid_edits.json` 的三项变化。未采用的候选及理由见 `hybrid_review.json`。未采用不等于预测错误。
- 新物体扣除旧区域的重叠像素。替换人物后腾出的像素，只在 SAM 真实预测为对应背景处补回；其余保留未分配。
- 没有掩码的区域保留原图，没有把未分配区域强行视作背景。
- 放大图使用最近邻，保留原像素和锯齿边缘，没有美化掩码。
