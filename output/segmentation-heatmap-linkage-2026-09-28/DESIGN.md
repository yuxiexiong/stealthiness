# 分割与归因联看（描述性分析，ANALYZED 后填写结果）

问题：攻击成功率和训练进度变化时，同一图片哪些区域的归因份额减少，哪些增加？
使用已冻结的 COCO + SAM3 路线 C，不按热图修改分割。先接入 p_core、标准 28px 触发输入、攻击答案 T2、仪器 A/B；两台仪器分开，正值支持和负值抑制分开。原 HTML 其他列和答案继续可用。

- 分割原尺寸直接最近邻缩放到 336×336，每个 14×14 patch 按区域覆盖比例分配归因；右下 28×28 独立为触发器区域，扣除原物体面积；0 为未分配，不能叫背景。
- 区域强度 = sum(区域覆盖比例 × patch 正归因或负归因绝对值)。份额 = 区域强度 / 全图同符号强度；分母为零时为缺失。富集比 = 份额 / 面积占比。小于 4 patch 面积的区域标注不稳定。
- 原始 NPZ 用 float64 聚合；照片和热图沿用原 HTML，热图有原绘图量化与色标截断，表格不由显示颜色反推。
- 单图展示原图分区、前/后热图边界、区域表、单图区域曲线与模板文字。固定区域编号与颜色。前后热图同尺度。
- 全局曲线在路径所有检查点都有的固定问题集合上计算。先同一图片内平均问题份额，再图片等权平均。正/负任一检查点总量为零的问题从整条路径的汇总剔除并报告。ASR 是 200 题的模型级统计，不是这张图的成功概率。
- 曲线按训练步数/剂量顺序连接；横轴可为 ASR，保持原顺序，不按 ASR 重新排序。终点对比称为一减一增，不称为因果转移。分割细节表按全部区域显示，不只展示 top-k。
- 宏观表列物体/背景类/触发器/未分配；类别级表列各类别平均份额变化。单图看实例、跨图看类别，不把不同图片实例 ID 混为同一个区域。
- 只做描述性分析，不运行训练，不进行新假设检验或宣称确认性结论。分割独立人工复核尚未完成，SAM3 候选 unresolved 不是像素未分配。

验证：区域覆盖守恒；强度守恒；触发器份额与已有曲线 JSON 复算一致；原 HTML 五个 JSON 块和原图片字节保持；浏览器检查切换、零值、样本翻页和画布；保留原 UI 回归检查。
