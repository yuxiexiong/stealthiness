# 查重文档 — 方向 A：后门"能否装上"的跨种子二元性 + 跨架构脆弱性

**日期** 2026-10-01 · **协议** CLAUDE.md §4 七步查重（全部执行）· **检索工具** WebSearch/WebFetch + 4 个检索子代理

## 0. 被查的主张（精确陈述）

> 在固定低剂量（1%）的 VLM 数据投毒后门中，除**随机训练种子**（LoRA 初始化 + 数据 shuffle + 投毒样本选择由同一 seed 控制）外全部一致时，后门**能否成功装上**（达到高 ASR）是**种子依赖的、近二元**事件——同数据同配置，有的种子 ASR≈0.99、有的 ≈0.00，几乎无中间态；而非 ASR 连续噪声。并且这是**模型依赖**的：Qwen3-VL-8B 脆弱（2/6 种子装上），LLaVA-1.5-7B 稳固（10/10）。解读：1% 剂量处于**可学习性/记忆化阈值**附近，种子决定相变是否在训练预算内发生。

拆成两个可独立查重的子主张：
- **A1** 后门装/不装是种子依赖、近二元（非连续方差），机制=记忆化阈值/lottery-ticket。
- **A2** 固定低剂量下后门脆弱性**因模型架构而异**（Qwen3-VL 脆弱 vs LLaVA 稳固）。

---

## 1. 结论（坏消息先说）

**A1 已被发表，基本不新——连我们的机制解读都一字不差地被人写过。** 最近邻 Zheng & Zen 2025 用 175 个 QLoRA 微调的 Llama-3.1-8B、16 个剂量 ×10–20 种子，明确报告"阈值附近激活是随机的：相同训练数据，有的 run 装上有的不装"、"二元现象（BAR≈42% 或 ≈0%，几无中间态）"、归因于"随机初始化 + 小批次顺序 + 投毒样本选择"，并提出 ED50（装上的种子比例）指标与"记忆化阈值 + lottery ticket"解读。**这与 A1 的现象、度量、机制解读逐项重合。**

**A2（跨架构脆弱性）部分被预占、且有反证。** BackdoorVLM 已报告"图像触发后门更不稳定、更依赖模型"，Qwen2.5-VL 弱于 LLaVA-1.5；但归因于触发器模态而非种子，且单次运行无种子分布。更关键的反证：在 **1% 文本触发**下 BackdoorVLM 测得 **LLaVA 和 Qwen2.5-VL 都稳固（99.7–100%）**；另有一篇用**正是 Qwen3-VL-8B + LLaVA-1.5-7B** 的工作报告"架构脆弱性极小"（但那是架构注入、非投毒训练，可反驳）。

**幸存的新颖性很窄**（对象层面、增量）：
1. **VLM 实例化**——没有任何 VLM 后门论文做过多种子装/不装稳定性研究（此空白经 4 代理、~30 查询族、多篇取正文后仍存活）。
2. **固定 1% 剂量下的跨架构阈值错位**——Qwen3-VL-8B 落在随机/过渡区（~2/6 装上）而 LLaVA-1.5-7B 饱和（10/10）。Zheng&Zen 明确把"ED50 如何随架构/规模变化"列为 **future work**，这是对象层面的缺口。
- **注意**：我们的"Qwen 脆弱"可能部分是**图像触发模态效应**（BackdoorVLM 指出图像触发本就常在 Qwen 上失败 0–37%），而非纯种子/架构效应。必须在文档/论文里如实区分，不能把模态混淆当架构发现。

**一句话**：方向 A 若写成"我们发现后门装/不装是种子依赖的二元现象"——**已被 scoop**。只有重构成"**把该现象迁移到 VLM + 证明固定剂量下跨架构阈值错位到一个模型随机、另一个饱和**"才幸存，且是增量贡献，审稿人会立刻引 Zheng&Zen 和 Lelle。机制已是 Zheng 的，我们顶多贡献定量的跨模型阈值定位 + VLM 实例。

## 2. 七步执行记录

### 步骤 1｜抽象阶梯（模板层检索）
把主张抽象为"低剂量投毒/后门的**成功与否**对训练随机性（seed/run）敏感、呈阈值式/二元"，在所有模型类型（图像分类器、LLM、VLM、SSL）上搜，而非只搜 VLM。命中：Zheng&Zen（LLM）、Lelle 2605.30189（LLM LoRA）、Lu/Kamath/Yu 2303.03592（分类器，临界投毒比例相变、且模型类型依赖）、Schwarzschild 2006.12557（投毒成功对设置高度敏感、现实中常失败）。**模板层已被多篇占据。**

### 步骤 2｜方法论单独搜（把"多种子后门评估"当独立对象）
搜"多种子后门评估 / 误差棒 / 装上成功率分布 / 投毒可复现性基准"。命中 Zheng&Zen（ED50=装上种子比例，正是该方法论）、Lelle（两阶段：单种子粗扫→多种子细扫）、Schwarzschild（统一基准、投毒率是差指标）。**该方法论已被建立。**

### 步骤 3｜蕴含检索（谁的结果会让我们的成为推论）
Lu/Kamath/Yu 2303.03592 证明临界投毒比例 τ 的"相变"且模型类型依赖——会**预测**剂量阈值与模型依赖（但为不可区分投毒、确定性构造、非随机种子）。Souly 2510.07192"近恒定投毒数量阈值、跨规模恒定"——与"固定剂量模型脆弱性差异"方向相反（它说阈值与规模无关），是对 A2 的部分反证。

### 步骤 4｜同义术语枚举后再搜
词表：seed sensitivity / run-to-run variance / random-seed effect on backdoor / poisoning reliability·reproducibility / attack-success variance across runs / high-variance clean-label backdoor / backdoor sometimes fails / unstable backdoor / stochastic activation / install-vs-fail / ED50。逐词搜，命中如上；另发现 clean-label 后门"一次 session 装上、换种子另一次崩掉"是被反复提及的可复现性困扰（但多为"麻烦"叙述、未上升为二元相变；且无法定位到单一出处）。

### 步骤 5｜引用链挖掘
对 Zheng&Zen、Lelle、BackdoorVLM 取正文并扫其参考/相关工作。Zheng&Zen 是课程项目、几无被引；Lelle(2026-05)/BackdoorVLM(2025-11) 太新、引用图未成熟。**此步受"论文太新"限制，见边界。**

### 步骤 6｜对抗式检索（专找"已经说过我们主张"的那一篇）
显式搜"backdoor install seed dependent binary"、"whether backdoor installs depends on seed"、"model X backdoor-fragile dose Y robust"。**直接命中 Zheng&Zen（A1 被完整预占）。** A2 的精确形式（Qwen3-VL 脆弱/LLaVA 稳固、以装上种子比例操作化）未被任何论文报告，但方向性（Qwen 图像触发弱于 LLaVA）已被 BackdoorVLM 预占。

## 3. 最近邻排序（最近在前；读取级别 + 精确差距）

1. **[最近邻] Zheng & Zen 2025 — "Phase Transitions in Backdoor Learning: Minimum Data Poisoning Thresholds for LLM Backdoors"**〔读=全文 PDF，已核验存在〕
   Harvard CS 2881R 课程项目（**无 arXiv**；PDF: boazbk.github.io/mltheoryseminar/... ; 代码 github.com/KadenZheng/2881r-backdoor-introspection）。175×Llama-3.1-8B QLoRA，16 剂量 ×10–20 种子，ED50=3.60% [95%CI 3.33–3.82]。
   **逐项命中 A1**：随机激活（同数据有的装有的不装）、二元（BAR≈42%/≈0% 无中间态）、三来源（init+minibatch order+poison 选择）、ED50 指标、记忆化阈值+lottery ticket 解读、"训多个模型比对"防御。
   **差距**：纯文本 LLM、单模型、阈值 ~3.6%（1% 在其为阈下，n=3 全 0）；**跨架构列为 future work**。provenance 弱（课程项目、非同行评审、可能修订/撤回）。

2. **Lelle 2026 — "Token-Level Generalization in LoRA Adapter Backdoors"**（arXiv:2605.30189）〔读=WebFetch 全文 + papers.cool 核验摘要〕
   LoRA adapter 后门，明言"单 seed 控制三源：投毒选择、LoRA 初始化、shuffle"（与我们设置同）；多种子细扫报告"sharp transition"与"高方差过渡带"（k=18–22 mean ASR 45.6%→68.9%、std 高至 0.217）；跨规模阈值移动（Qwen2.5 1.5B vs 7B、Llama-3.2-1B）。
   **是那句可疑措辞的真正出处**（其两阶段方法的转述，非逐字引文、非另一篇）。
   **差距**：种子效应是过渡带内的**连续 ASR 散布**（~47%↔91%），**非我们的 0.99/0.00 清晰二元**；在攻击剂量上跨种子可靠装上；文本 LLM、跨规模而非跨 VLM。

3. **BackdoorVLM 2025**（arXiv:2511.18921）〔读=全文〕
   直接基准 **LLaVA-1.5-7B 与 Qwen2.5-VL-7B**。文本触发 1% 两者都稳（99.7–100%，差<3 点）→ **对 A2 的温和反证**；但图像触发"更不稳定、更依赖模型"（LLaVA 0–32%、Qwen 0–37%）→ **方向性支持 A2**，归因于模态非种子，单次运行无种子分布。
   **差距**：Qwen2.5-VL（非 3-8B）；按模态/触发类型而非随机种子框定；无二元装/不装分布。

4. **"Once Poisoned, Arbitrarily Controlled" 2026**（arXiv:2608.10959）〔读=全文〕
   **模型重合最高**：实际投毒 Qwen3-VL + LLaVA-1.6 + MiniGPT-v2，1 epoch，"一致高 ASR"。**隐含假设装上可靠**——正是我们要挑战的；无种子、无脆弱性分析。

5. **"Architectural Backdoors via Representation Steering" 2026**（arXiv:2607.25479）〔读=全文〕
   **正用 Qwen3-VL-8B + LLaVA-1.5-7B**，报告"架构脆弱性极小、两者一致"。**表面反证 A2**——但为**架构/steering 注入、非投毒训练**（确定性构造）。**反驳**：它对"指令微调下的装上随机性"毫无发言权。审稿人可能引，须预先反驳。

6. **Lu, Kamath & Yu 2023 — "Limits of Model-Targeted Indiscriminate Data Poisoning"**（arXiv:2303.03592, ICML2023）〔读=摘要〕
   证明临界投毒比例 τ 的"相变"、且模型类型依赖（分类器有、回归无）。**蕴含邻居**：预测剂量阈值与模型依赖；但不可区分投毒、确定性、非随机种子、非 VLM。

7. **Schwarzschild 2021 — "Just How Toxic is Data Poisoning?"**（arXiv:2006.12557, ICML2021）〔读=摘要〕
   投毒成功"对测试设置高度敏感"、现实中常失败、投毒率是差指标。支持"投毒不可靠"，但非种子二元、非 VLM。

8. **Souly 2510.07192 — "Poisoning LLMs Require Near-constant Number of Poison Samples"**〔读=摘要〕
   阈值在**数量**（~250 文档）、跨规模**恒定**——与 A2"固定剂量下模型脆弱性差异"相悖；方差连续非种子二元。

低层支持：Truong 2004.11514（架构依赖易感性、ASR 水平非种子二元）；经典 CNN 架构易感性比较；clean-label 不稳定（未能定位单一出处）。**非论文来源**（仅透明记录）：lacuna.tiptreesystems.com 为 AI 聚合页、非一手文献，不可引。

## 4. 直接回答 + 分档

- **A1 有人做过吗？** **是，且不新**〔推导，基于 Zheng&Zen 全文近乎逐项匹配 + Lelle 全文佐证〕。
- **A2 有人做过吗？** **部分**〔推导〕：泛化的"模型依赖易感性"已有（Lu/Kamath/Yu、经典架构研究、BackdoorVLM 图像触发），但"Qwen3-VL 脆弱/LLaVA 稳固、以装上种子比例操作化"无人报告；且唯一同时测两族的 BackdoorVLM 在 1% 文本触发下测得两者都稳（温和反证）。
- **"Qwen3-VL-8B 在 1% 下确实脆弱"作为既成事实** — **无任何文献支持，我们的结果会是第一**〔推测，待对照已做：见下〕。注意我们已用"我的管线重跑种子 1001 复现 0.985"排除了管线 bug，故我们这一**具体结果**可信；但"这是架构效应而非图像触发模态效应"**尚未排除**（需补一个 Qwen3-VL 文本触发 / LLaVA 图像触发的交叉对照才能分离，当前未做）。
