## 0. 问的是什么

phase2b 两个种子的 ASR 都在约 40–60 步内从 5% 升到 95%。这是一次训练、一个 epoch，每条毒样本只被训练一次，
所以不是 grokking（没有「先记住训练集、后泛化」的阶段）。剩下两种读法：

- **A · 暴露轴**：跃迁发生在「累计见过的毒样本」跨过某个量的时刻，步数只是它在时间上的投影。
- **B · 阈值假象**：ASR 只看首词 argmax，目标词 logit 可能一直平滑上升，只在越过竞争词那一刻显得陡。

## 2. 测量（`jump.py`）

- 第 k 步消耗顺序位置 16(k−1) … 16k−1 的样本；第 k 步更新用的学习率倍数 = lam(k−1)，
  lam 是 HF 的 cosine+warmup（warmup = ceil(0.03×1250) = 38）。
- **K(s)** = 到第 s 步为止消耗的毒样本数。**D(s)** = 同一批毒样本各自所用学习率倍数之和（单位：满学习率的毒样本条数）。
- **t5 / t50 / t95** = 第一个 ASR（200 探针行为测试，含 5 步与 1 步补点）≥ 5% / 50% / 95% 的检查点。
- **B 部分**只用已成像检查点的 60 个轨迹样本（P-core trig 列）：T2 = 目标首词 logit，T3 = 目标首词 − 正确答案首词，
  翻转 = argmax 为目标首词（T1 == T2）；asr60 = 翻转比例。

## 3. 闸门与判据（全部写死）

| 编号 | 内容 | 判据 |
|---|---|---|
| **G0** | 日志里 62 个 lr 与 lam 公式 | 最大相对误差 ≤ 1e−3 通过；不通过则 D 不用，只报 K |
| **G1**（每个种子） | 复现的顺序是否就是训练用的顺序。Δloss_w = 毒臂 − 配对干净臂在第 w 个 20 步日志窗的 loss；n_w = 该窗毒样本数。只用 ASR 起飞前的窗（窗末 ≤ t5 − 20，t5 取每 20 步存档）。r = Pearson(Δloss, n)；零分布 = 1000 个无关顺序下的 r | p = (1 + #零 ≥ r)/1001 ≤ 0.01 通过。**不通过 → 该种子的 A 部分不判**，记为合同执行失败，不当作负面证据（可能是顺序错，也可能是信号不够强） |
| **A1** | 两个种子在 t50 处对齐在哪根轴上 | 相对差 g = \|x1 − x2\| / 均值。g_暴露 ≤ 0.5·g_步数 → 暴露轴对齐；g_步数 ≤ 0.5·g_暴露 → 步数轴对齐；否则分不清。K 为主，D 并报。两个种子只能给**描述**，档位属推测 |
| **A2** | 轨迹 t50 处的 D，与剂量线（训练终点）P-0.38 与 P-0.42 的 D 构成的区间比 | 落在区间内 → 一致；落在 [下界/1.5, 上界×1.5] → 接近；否则 → 不一致。需 G0、G1(s1) 通过 |
| **A3** | 同为约 0.4% 的五个臂（P-0.38、P-0.4、P-0.4-ps2、P-0.4-ps3、P-0.42），ASR 的高低顺序能否由 D 排出 | Kendall τ_b(D, ASR)，ASR 差 < 0.10 视为并列。τ = 1 → 顺序一致；≥ 0.6 → 基本一致；否则不一致。K 的 τ 并报（0.4 的三臂 K 相同，K 排不开它们） |
| **B** | 目标词 logit 在 ASR 过渡窗内是否加速 | 窗 [a, b]：b = 第一个 asr60 ≥ 0.95 的成像步，a = b 之前最后一个 asr60 ≤ 0.05 的成像步。R = 窗内 T3 中位数的斜率 ÷ 窗前等长段的斜率；CI = 对样本 bootstrap 10000 次（种子 0）。有效性：窗内变化 ≥ 3 × 噪声（噪声 = 干净对照各参考步之间 T3 中位数变化的中位数）。R 上界 ≤ 1.5 → **阈值假象**（logit 没有加速）；R 下界 ≥ 3 → **logit 本身加速**；否则分不清。C（窗内份额 ÷ 步数份额，线性时为 1）只作描述 |

零值标定（总则 6.3）：G1 用无关顺序的 null；B 的线性基准是 R = 1、C = 1，噪声地板来自干净对照；A1–A3 是轴的比较，不是与 0 比。

## 4. 这些检查测不了什么

- **A 只检验「跃迁与暴露量对齐」**，不证明暴露量是原因：顺序、学习率、LoRA 初始化在同一个种子里一起变。
  grok10（同一毒样本集、8 个新种子，正在服务器上跑）的轨迹出来后，可以用同一套工具做真正多种子的检验，不在本合同内。
- 已经知道的信息（因此 A1、A2 不是完全盲测）：两条轨迹的 ASR 数值；P-0.38 / 0.40 / 0.42 的 ASR（0.5% / 21.5% / 96%）；
  我在回复用户时按「毒样本均匀分布」估过：轨迹 t5–t95 约 42–61 条，剂量线 76–84 条；心算过 D 的量级可能相近。
  **没看过**：真实顺序下的任何计数、loss 日志（CLEAN 的前两行除外）、P-0.4-ps2 / ps3 的 ASR、任何 T2/T3 轨迹
  （2026-09-29 查看 npz 结构时看到过 P-1.0-D2@s280 两个样本的 3 个 logit）。
- B 用的是 60 个成像样本的首词 argmax，不是 200 探针的生成答案；两者的过渡位置可能差几步。
- 补点检查点来自从存档续训，与原轨迹不是逐位同一次训练（D68/D71 记录了对齐检查）。
- 只有两个种子。
