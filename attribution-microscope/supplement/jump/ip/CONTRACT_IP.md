# IP：已跳与未跳模型之间的内部状态交换 · 合同

冻结时与 `ip.py`、`run_ip.py`、`ip_gate.py`、`eval_ip.py`、`rehearsal_ip.py`（16/16）、`make_ip_jobs.py` 同一次提交。

## 0. 为什么做

- IM2（`../im/RESULTS_IM2.md`）表明：直接在输入或输出上读出的量（logit、输入遮挡、占比）在代数上都与 logit 绑定，给不出独立的内部信息。
- 要问「顺序造成的哪一部分内部差异承载了跃升后的行为差异」，必须直接改内部状态，看输出是否随之改变。
- 本实验是与用户讨论后确定的下一步（LOG J42 讨论稿第二处）。

## 1. 设计

**模型**：
- 冻结的视觉编码器与投影器，LoRA 只在语言模型上，因此图像 token 进入语言模型时在所有检查点上相同（闸门 G2 核对）。
- 每一对模型同初始化（1001）、同步数、不同顺序：一个已跳（ASR ≥ 0.9），一个未跳（ASR ≤ 0.05）。ASR 取自 XO 的 10 步网格。

**交换**：
- 在第 l 层输入处（残差流 `hidden_states[l]`，l = 0, 2, …, 30），把接收模型在某组图像 token 位置上的状态，换成供体模型对**同一输入**的状态。其余位置、其余层不动，由接收模型自己计算。
- **只换图像 token 位置**：答案位置和所有文本位置一律不换，所以输出不可能被直接复制过去。讨论中要求排除的「答案位置后层的平凡转移」由此在构造上排除。

**位置组**（事先固定，各 4 个 token）：
- 候选：触发窗口（块 550, 551, 574, 575）；
- 非候选：另外三个角的窗口（0、22、528）和中心窗口（300）。

**读数**：答案首 token 位置的 T3 = logit[目标] − logit[正确]，以及 argmax token；60 个 p_core 轨迹样本。

**转移比例**（中位数）：
- 正向 F_fwd：把已跳模型 J 的状态放进未跳模型 U，T3 升高了多少，占两者 T3 差（gap）的比例；
- 反向 F_rev：把 U 的状态放进 J，T3 降低了多少，占 gap 的比例。

**配对**：

| 用途 | 名称 | J（已跳） | U（未跳） | 步 |
|---|---|---|---|---|
| 开发（只用来选层） | D1 | O1009 | O1011 | 380 |
| 验证 | V1 | O1001（PS-P0） | O1007 | 400 |
| 验证 | V2 | O1008 | O1007 | 430 |
| 对照：同顺序不同初始化，都已跳 | N1 | I1007-O1001 | I1009-O1001 | 400 |
| 对照：同顺序不同初始化，都未跳 | N2 | I1007-O1001 | I1009-O1001 | 280 |
| 对照：同初始化不同顺序，都已跳 | N3 | O1009 | O1001（PS-P0） | 400 |
| 对照：同初始化不同顺序，都未跳 | N4 | O1007 | O1008 | 300 |

- 开发组（顺序 1009 / 1011）与验证组（顺序 1001 / 1007 / 1008）**不共享顺序**。
- 两个验证对共享 U = O1007（步数不同），因此不是独立样本。

**层的选择**：
- L* = 开发对上 min(F_fwd, F_rev) 最大的层（不含第 0 层，平局取较浅层）；
- 选层规则随代码冻结，因此 L* 由开发对机械决定，与验证数据无关。

## 2. 闸门 GP（GPU，开发对前 4 个样本）

全部满足才继续，否则全部不跑：
- G1：未交换时 J 的 T3 与 IM2 成像文件中同一检查点的值一致（≤ 0.05）；
- G2：J 与 U 的语言模型输入完全相同；
- G3：批内「不交换」行与单独前向一致，自替换行、第 0 层交换行的 |ΔT3| ≤ 0.05；
- G4：把 J 的触发位置在第 16 层置零，T3 中位数变化 > 0.5（钩子确实生效）。

冻结前已在不参与实验的 PS-P1 / PS-P2 第 300 步上冒烟测试，G1–G4 对应项全部通过；每个样本约 30 秒，一对约 35 分钟。

## 3. 判据（`ip.py`，在 L* 上）

**零值标定**：
- τ = 4 个对照对、两个方向、触发位置组、第 L* 层的逐样本 |ΔT3| 合并后的第 95 百分位；
- 对照对之间没有行为差，所以 τ 表示「没有行为差时交换本身造成的变化」。

**单个方向的分类**：
- 「承载」：F ≥ 0.5 且中位变化 > τ；
- 「不承载」：F < 0.2 或中位变化 ≤ τ；
- 其余为「部分」。

**特异性**（只在至少一个方向不是「不承载」时检查）：
- 4 个非候选窗口在 L* 上两个方向的 F 都 ≤ 0.2；
- 在无触发图上做同样交换，两个方向的 |中位 ΔT3| ≤ τ，正确答案 top-1 比例下降 ≤ 0.10。

**判档**（两个验证对必须落在同一档，否则判「两对不一致」）：

| 判档 | 条件 | 含义 |
|---|---|---|
| **双向承载** | 正反都「承载」，特异 | 触发位置在第 L* 层的状态足以装上、也足以去掉这种行为差：差别写在触发位置的表示里 |
| **必要但不充分** | 反向「承载」、正向「不承载」，特异 | 去掉它，已跳模型就失效；但未跳模型拿到它也用不上：读取一侧同样变了 |
| **充分但不必要** | 正向「承载」、反向「不承载」，特异 | 未跳模型能用它；已跳模型不依赖这个位置（信息在第 L* 层之前已转移到别处） |
| **部分** | 其余组合，特异 | — |
| **不特异** | 有方向不是「不承载」，但特异性不满足 | 交换效应不专属于触发位置或触发输入 |
| **触发位置不承载差异** | 正反都「不承载」 | 差别在别处（其他位置或读取一侧） |
| **测不了** | 闸门未过、有配对文件缺失、自替换或第 0 层交换的 \|ΔT3\| 中位数 > 0.05、两个验证对任一 gap < 3、或 τ ≥ 0.25 × gap | 合同执行失败或零值太宽 |

**描述（不判档）**：
- 全部 7 对、16 层、5 个位置组的转移曲线；
- 开发对在 L* 上的数；
- 对照对的 ΔT3 分布。

## 4. 能说明什么、不能说明什么

- 交换只在一层、4 个位置上做。若判「双向承载」，说明这组状态足以承载这对模型之间的行为差，但**不说明**跃升的时间由它决定，也不说明它是唯一的载体。
- 「触发位置不承载差异」**不否定**内部机制：触发信息可能在 L* 之前已转移到其他 token。这一档只排除第一个明确的候选。
- 只有 LLaVA、1% 剂量、2 个验证对，且共享一个未跳模型。
- 用 T3 与 argmax 代替生成式 ASR（LP 显示两者一致，`../lp/RESULTS_LP.md`），没有重新生成答案。

## 5. 预注册预测（推测档）

**必要但不充分**。理由：
- 跃升陡峭，与「两个部件都到位才生效」的乘性组合一致；
- 去掉已跳模型的触发表示应能让它失效；
- 但未跳模型的读取一侧尚未建立，拿到触发表示也用不上。

L* 预计在中间层（8–16）。
