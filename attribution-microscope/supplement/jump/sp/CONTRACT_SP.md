## 1. S · 拼接定位（GPU）

- **两条顺序**：1007 与 1001。同为初始化 1001 时，二者的 t50 分别是 470（XO-I1001-O1007）和 360（s1），相差 110 步，是已测顺序中差得最大的一对。
- **拼接**：前 c 步（16c 行）按一条顺序消耗，其余行按另一条顺序中的先后排列（跳过已用过的行），仍是 1 个 epoch、每行一次。
  c ∈ {100, 200, 300}，两个方向（1007 在前 / 1001 在前），共 6 次。所有训练的初始化都是 1001（seed s1）。
  c = 300 早于两条顺序各自的 t5（320、415）。
- **构造与闸门**：用 XO 已验证的重排数据文件办法。
  - **GS0（CPU，冻结前已跑）**：6/6 的文件内容逐行正确，真实 Trainer（假模型）实际消耗的行 = 设计的拼接序列。
  - **GS1（GPU）**：c = 200 的两个文件各只训 1 步，第 1 步 loss 必须等于 XO 闸门里同一首批数据的值（1007 在前 4.0838；1001 在前 4.7161），
    差 ≤ 1e−4；不过 → 全线停。
- **测量**：每 10 步存档；测第 260–520 步每 10 步的 200 探针 ASR，若都 < 0.5 则续测。t50 = 第一个 10 步网格上 ASR ≥ 0.5 的检查点。
- **判据**：
  - 份额 = (t50 − 后段那条顺序的 t50) / (前段那条顺序的 t50 − 后段那条顺序的 t50)。≥ 0.75 → **前段**；≤ 0.25 → **后段**；其余 → **混合**。
  - 两个方向在三个切点上的标签合起来判档：
    - 两个方向在 c = 100 都是前段 → **决定段在第 1–100 步**
    - 在 c = 300 都是后段 → **决定段在第 300 步之后**
    - 在相邻两个切点上都是「后段 → 前段」→ **决定段在这两个切点之间**
    - 都不是，但两个方向的份额都随 c 不降（容差 0.25）且出现了混合 → **渐变（没有单一决定段）**
    - 其余 → **不一致**；缺任何一次 → **测不了**
  - 零值说明：两端的参照不是 0，而是两条完整顺序在同一初始化下的实测 t50；
    XO 中仅换初始化最多移动 30 步，约为这里 110 步差距的 0.27，与「混合」带的宽度相当。

## 2. E · 顺序特征探索（CPU）与对 S 的盲测

- **8 个特征**，全部只用数据顺序中第 300 步及之前的部分计算（`sp.features`），在看任何相关之前写定：
  K300（毒样本数）、D300（学习率加权毒样本数）、L30 / L100（带遗忘的毒样本数，时间常数 30 / 100 步）、
  Burst20（任意 20 步窗口内毒样本数的最大值）、Warm38（预热期毒样本数）、
  OpenShare300（已到毒样本中，原题为开放答案的比例；200 条毒样本中 101 条原题为开放答案）、
  MeanArrival300（已到毒样本的平均到达步）。
- **每条顺序的 t50**：初始化 1001 下测过的用它（1001 = 360、1007 = 470、1008 = 410、1011 = 410、1009 = 330），
  其余用原种子自己的（1004 = 370、1005 = 390、1006 = 390、1010 = 350）。
- **探索**：每个特征与 t50 的 Spearman ρ，双侧精确置换 p（9! 种），8 个特征做 Holm 校正。
  校正后 ≤ 0.05 → **候选**；只有未校正 ≤ 0.05 → **线索**；否则 **无**。9 个点、探索性质，候选也只是候选。
- **对 S 的盲测**：
  - 每个特征在 9 条顺序上线性拟合 t50，预测 6 次拼接训练的 t50（写入 `predictions_sp.json`，冻结 #2）。
  - **主特征**按规则事先定为：探索中未校正 p 最小的那个（并列取列表靠前者），不论它是否显著。
  - 判档：主特征预测的平均绝对误差 ÷ 常数预测（9 条顺序 t50 的均值）的平均绝对误差。≤ 0.5 → **通过盲测**；≥ 1 → **未通过**；其余 → **分不清**。
    其余 7 个特征的同一指标只作描述。

## 3. 能说明什么、不能说明什么

- S 只用一对顺序、三个切点；定位到的区间是「这对顺序在这段上的差别决定了起飞差」，不等于对所有顺序都在同一段。
- 拼接的后段不是原顺序的原样（跳过了已用的行），所以后段的毒样本到达时刻也被改动了；这是一个 epoch 约束下唯一的办法。
- E 只有 9 个点，候选特征需要 S 的盲测或新顺序来确认；通过盲测也只说明这个特征在这 6 个拼接上能预测。
