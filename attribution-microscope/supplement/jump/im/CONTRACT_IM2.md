# IM2（修订版）：触发相关的作用是否先于 logit 增强 · 合同

- 原版冻结于 `3143796`。
- 本修订版在 IM2 产生任何数据之前完成（闸门尚未运行），起因是与用户讨论后同意的修改（LOG J42）。
- 本文件与 `im2.py`、`rehearsal_im2.py`（15/15）、`im2_gate.py`、`make_im2_jobs.py`、`eval_im2.py`（合成跑通）、`t50_im2.json`、`t50s_im2.json` 在一次提交中重新冻结。

## 0. 为什么做、为什么修订

- 探索 IM（LOG J36）：在两条可读轨迹上，方法 B 的触发区**占比**比 logit 早 40–80 步到达半程。
- **修订理由**：占比升高有两种可能——触发区的作用增强，或者其他区域的作用减弱、触发区因此占得更多。只看占比分不开这两者。
  所以主读数改为触发窗口的**原始有符号效应**，同时报告占比的分子与分母，并加上无触发图和非触发区两种对照。
- **另一处修订**：区分「首次过半」与「持续过半」。PS 显示 s1 在第 330 步冒头、随后回落，第 360 步才持续上升。

## 1. 设计

**对象**：XO 8 次 + SP 6 次训练（每 10 步存档）。

**两个事件**（10 步网格，与新测量同网格）：
- t50 = 第一个 ASR ≥ 0.5 的点；
- t50s = 第一个 ASR ≥ 0.5、且随后 40 步内所有测点都 ≥ 0.5 的点。
- 14 次中有 2 次两者不同（XO-I1008-O1001、XO-I1011-O1001：330 / 360），见 `t50s_im2.json`。

**成像**（项目 `imaging_run.py`，方法 B，p_core 60 个轨迹样本）：
- 触发图：第 200, 220, … 步直到第一个 ≥ max(t50, t50s) + 60 的步；
- 无触发图：每次 3 个固定步——第 220 步、最后一个 ≤ t50 − 20 的步、第一个 ≥ t50s + 20 的步。

**读数**（每步取 60 个样本的中位数；方法 B 每个 2×2 窗口存「完整图 T3 − 该窗口涂灰后 T3」）：
- **E_trig（主读数）**：触发窗口（块 550, 551, 574, 575）被涂灰时 T3 的有符号下降；
- m1：正值部分落在触发窗口的占比（原 IM2 读数），以及它的分子、分母；
- 对照：其余 143 个窗口的平均效应；事先固定的中心窗口（块 300, 301, 324, 325）的效应；
- logit：T3。

**领先量**：进度 = (值 − 基线) / (终值 − 基线)，基线 = 第 200 / 220 / 240 步均值，终值 = 最后成像步；t_half = 进度首次越过 0.5（线性插值）。
领先量 = t_half(logit) − t_half(读数)，正数表示读数先到。

**特异性**：每次训练 r = (无触发图 E_trig 从第 220 步到「≥ t50s + 20」步的变化) / (触发图 E_trig 同期的变化)；触发图变化 ≤ 0 时不计。

## 2. 闸门与成本分档

**GI1**（GPU）：重新成像 PS-P0 第 300 步（训练与原始 s1 逐位相同），与仓库中原始 s1 第 300 步的成像比较。全部满足才通过，不过 → 全部不跑：
- logit 最大差 ≤ 0.05；
- E_trig 逐样本差的中位数 ≤ 0.05；
- m1 逐样本差的中位数 ≤ 0.01；
- 同时成像一次无触发列，必须产出文件。

计时一个触发列检查点：≤ 6 分钟 → **14 次方案**；否则 → **8 次方案**（只做 XO 8 次，SP 的 6 个任务在开始前撤下）。

## 3. 判据（`im2.py`）

**规则**：14 次方案要求 ≥ 11 次领先量 > 0 且中位数 ≥ 20 步（领先），或 ≥ 11 次 < 0 且中位数 ≤ −20 步（落后）。8 次方案为 ≥ 7 次。单侧符号检验 p 约 0.03。

| 判档 | 条件 |
|---|---|
| **触发相关作用先于 logit 增强** | E_trig 满足领先规则，且特异性比值中位数 ≤ 0.5 |
| **触发作用提前增强，但特异性未确认** | E_trig 领先，特异性比值中位数 > 0.5 |
| **只是归因分配提前变化** | E_trig 不领先，但 m1 满足领先规则 |
| **触发作用落后于 logit** | E_trig 满足落后规则 |
| **无一致领先** | 其余 |
| **测不了** | 可读训练不足（14 次方案 < 12，8 次方案 < 7） |

**描述（不判档）**：
- 占比的分子与分母各自的走势；
- 两个对照窗口的走势；
- 稳健性：基线只取第 200 步、终值取 max(t50, t50s) + 40，这两种读法下的 E_trig 领先量；
- 两个事件各自的位置。

## 4. 能说明什么、不能说明什么

- 这是**回顾性**的领先：归一化用到终值，窗口依赖已知的起跳点。它回答「事后看，哪个先变」，**不能**说明「当时能预知即将跃升」。前瞻预测另做，须用未参与选择规则的独立顺序。
- 即使判「触发相关作用先于 logit 增强」，也只是找到一个前兆候选，不说明它参与造成跃升；那需要内部状态的双向干预（下一步计划）。
- 只在 LLaVA、1% 剂量上做；14 次训练来自少数几条顺序，不完全独立。

## 5. 预注册预测（推测档）

**触发作用提前增强，但特异性未确认**。理由：
- 探索中占比领先 40–80 步，我预计原始效应也会领先；
- 但无触发图上同位置的遮挡效应可能也会随训练上升（模型整体更偏向目标词），所以特异性比值可能超过 0.5。
