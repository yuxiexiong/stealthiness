起草 2026-10-02（按用户本对话的授权自行安排：拼接实验之后的下一轮）。本文件与 `tp.py`、`build_tp.py`、`tp_gate.py`、`tp_run.sh`、`tp_env.sh`、`eval_tp.py`、`rehearsal_tp.py` 在一次提交中冻结；
`rehearsal_tp.py` 13/13 通过（每一档都演示了能达到）；`eval_tp.py` 在合成输出上跑通。

## 0. 为什么做这个

- 拼接实验（`../sp/RESULTS_SP.md`）判「不一致」。我发现了自己设计中的一个问题：后段 ≈ 另一条顺序整体推迟 c 步，所以「前段 / 后段」读不出哪一段在起作用。
- 拼接实验里有一个稳的不对称（描述）：**前 100 步用 1001 的顺序，起跳就早（≤ 380）**；1007 要在前段待到第 300 步，起跳才晚（440）。
- 推测：1001 的前段里有「促进起跳」的内容。
- **本实验**：用对齐移植（只换一个窗口，其余位置不动）直接检验哪一个窗口携带这种作用。

## 1. 设计

- **对齐移植**：以一条顺序（底）为准，把另一条顺序（供体）在第 a–b 步消耗的行原位放到同样的位置。
  底在这些位置原来的行，放回到供体行在底里原来的位置，仍是一个 epoch。窗口外约有 1500 个位置被换动，它们是被挤出的窗口行，散落在全程。
- **4 次训练**，初始化都是 1001（seed s1），其余配置与 XO / SP 相同：

| 训练 | 底 | 供体窗口 |
|---|---|---|
| TP-B1007-D1001-W1-100 | 1007 | 1001 的第 1–100 步 |
| TP-B1007-D1001-W101-200 | 1007 | 1001 的第 101–200 步 |
| TP-B1007-D1001-W201-300 | 1007 | 1001 的第 201–300 步 |
| TP-B1001-D1007-W1-100（对照） | 1001 | 1007 的第 1–100 步 |

- **测量**：每 10 步存档；第 260–520 步每 10 步的 200 探针 ASR，若都 < 0.5 则续测。t50 = 第一个 10 步网格上 ASR ≥ 0.5 的点。

## 2. 闸门

- **GT0**（CPU，冻结前已跑）：4/4 的文件内容逐行正确，真实 Trainer 实际消耗 = 设计序列（LOG J26）。
- **GT1**（GPU）：三次只训 1 步的训练，第 1 步 loss 等于 XO 闸门值，差 ≤ 1e−4：
  - W1-100 移植到 1007 → 首批 = 1001 的首批，4.7161；
  - 对照 → 首批 = 1007 的首批，4.0838；
  - W101-200 移植到 1007 → 首批 = 1007 的首批，4.0838。
  - 不过 → 4 次训练都不跑。

## 3. 判据（`tp.py`）

- **参照**（初始化 1001）：整条 1007 = 470，整条 1001 = 360。
- **份额**：移植到 1007 的三次，份额 = (t50 − 470) / (360 − 470)（被拉向 1001 的程度）；对照的份额 = (t50 − 360) / (470 − 360)（被推向 1007 的程度）。
  ≥ 0.75 为大，≤ 0.25 为小。噪声参考：XO 中仅换初始化可移动 30 步 ≈ 份额 0.27。
- **判档**（只看移植到 1007 的三次）：
  - 恰好一个窗口份额 ≥ 0.75、另两个 ≤ 0.25 → **该窗口单独携带早起跳**
  - 三个都 ≤ 0.25 → **单个窗口移植不能转移起跳时刻**
  - 没有一个 ≥ 0.75 但三者之和 ≥ 0.75 → **分散在多个窗口**
  - 其余 → **混合**；缺任何一次 → **测不了**
- 对照的标签（推迟 / 不变 / 部分）一并报告：若某个窗口单独携带早起跳，且该窗口是第 1–100 步，那么对照应为「推迟」（拿走 1001 的第 1–100 步应变晚），这一条作为一致性检查，只作描述。

## 4. 能说明什么、不能说明什么

- 只有一对顺序、三个窗口；每次一次训练，噪声约 ±30 步。
- 窗口外被换动的约 1500 个位置也改变了少量毒样本的位置，这是保持一个 epoch 的代价。
- 「携带早起跳」是相关于这一对顺序的；不说明其他顺序之间的差也在同一窗口。

## 7. 冻结后的修订（LOG J28）

GT1 的第三项（W101-200 移植的首批 = 1007 首批）是我写错的预期：被挤出的行会落进第一批。GT1 改为 v2：只检查首批可证明等于来源首批的两次（W1-100 移植、对照），
