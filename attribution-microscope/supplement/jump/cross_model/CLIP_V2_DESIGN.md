For actual batch image i/caption j, z_ij is native CLIP similarity. All j sharing i's training label are positives. Preregister the symmetric positive-mass objective:

`L = .5 mean_i(logsumexp_j z_ij - logsumexp_{j:y_j=y_i} z_ij) + .5 mean_j(logsumexp_i z_ij - logsumexp_{i:y_i=y_j} z_ij)`.

Repeated captions are therefore not false negatives. Native text features for ten unique captions are recomputed every update; only tokens are cached. Expanding gallery columns by actual batch labels constructs the exact actual128-caption negative pool (last batch72), with both encoders receiving gradients. There is no gradient-accumulation claim about negative-pool equivalence. This is a fully specified multi-positive extension of CLIP's contrastive objective, not the original unique-pair web-caption training protocol. CIFAR class descriptions are controlled class captions rather than natural image-caption diversity. Comparisons to ResNet/ViT/Vim establish task/phenomenon coverage, not an isolated architecture or loss causal effect.
