## Frozen data and dose

Official CIFAR10 50000 train/10000 test. Fixed per-class split4500 train/500 validation, total45000/5000. Validation is not poisoned. Exactly2250 replacements (5% of45000), uniformly selected from the nine non-target training classes, target airplane/class0. The same original identities are used across models and seeds. Target-class originals are excluded from poisoning and every ASR denominator. Each source image has a fixed24x24 black/white checkerboard at the bottom-right with4px margin after crop/flip/224resize, before ImageNet normalization. No MixUp/CutMix/erasing. RandomCrop32 padding4 and RandomHorizontalFlip use per-seed/epoch/image deterministic randomness, shared by paired arms. Training/test/validation IDs, official dataset files and weight bytes are frozen in assets receipt; no dose/target/probe/seed changes to obtain a positive curve.

## Training and controls

Each architecture first runs an actual8-update pretrained GPU pilot, then5 clean adaptation epochs at fixed seed20260917, with a fresh10-class linear head. Validation accuracy must be>=85% at the fixed endpoint before formal experiments; a failure is reported, not silently extended/tuned. Save this clean adapted weight as the shared formal step0 for that architecture. Formal seeds1001/1002/1003 poison and seed1001 clean are eight trajectories, all pre-queued regardless of ASR. They share their architecture's initial weight; optimizer/RNG/order are freshly initialized for each seed, paired clean1001 receives identical ordering/augmentations. Seeds represent training randomness under shared frozen data/starting weights, not independent pretrained models or poisoning datasets.

Full-parameter AdamW lr1e-4, betas(.9,.999), eps1e-8,wd1e-4,clip1, no learning-rate schedule in poison stage. FP32 parameters/optimizer, BF16 CUDA autocast. Batch128, no accumulation, last72-example batch included,352 updates/epoch;20 formal epochs=7040 updates and900000 example exposures,45000 poison exposures per poison run.5 clean adaptation epochs=1760 updates/225000 exposures per architecture, recorded separately. Both model families use identical transforms, optimizer and budget. Model size/pretraining differ, and this full-tuning20-epoch protocol is not matched to prior LoRA1-epoch LLM/T2I; no architecture-only causality claim.

## Measurement

Primary probes180 official non-target test images (20/class), same identities throughout, step0 and every5 updates through7040. Confirmation uses disjoint900 (100/class), step0/every100/final. Measure patched and unpatched versions of each same image, target false-positive rate, original accuracy, target-minus-max-nontarget logit mean/median and all per-image10-way logits/IDs. Each epoch uses fixed5000 clean validation images; endpoint also evaluates all10000 clean test and9000 non-target trigger test. Never splice different180/900 denominators into one curve. Evaluation preserves RNG and every module's training flag and checks full parameter/BatchNorm-buffer hashes. Save raw scores and hashes, not only aggregates.

ASR>=90% is an outcome, never a pilot acceptance/scheduling gate. Report each seed's initial/peak/final ASR, first and sustained10%/90% crossing intervals, low-phase length, window width in updates and fraction of7040, actual poison exposures, dips and censoring. High trigger and high untriggered target prediction must not be described as trigger-specific; loss of clean accuracy is reported separately. Early/gradual/no rise are valid results. Sustained crossing uses the existing all-subsequent-observations rule. Coarse measurements are5-step resolution; no one-step claims before verified replay.

## Resume/replay and autonomous queue

All GPU jobs wait for `050cmf5_900_finish`, preserving all Falcon/T2I predecessors. Existing two workers; no new daemon. CPU assets/tests may prepare now. Source/runtime/assets/CPU gate identity is checked before actual native CUDA checks (native ResNet50 and engineering-small TorchVision ViT), then both real selected pretrained models run8 updates and validation. Small model/CPU/pilot results are not formal ASR evidence.

Save full model including BN buffers, optimizer, all RNG and epoch/update at baseline/every epoch (21 states/arm). After all eight arms finish, automatic planner selects poison runs with both first10% and90% crossings observed (not left/right censored). For each candidate record point count,900x2 forward images/point, original180x2 anchor checks, estimated actual phase cost and epoch-anchor re-training cost before publishing independent052cmcvr jobs. Resume latest epoch state before the coarse low crossing bracket, reproduce every original training loss exactly, evaluate every update in the bracket using fixed900 probes, compare original5-step anchors by full model/buffer hash and all180 paired logit bytes before accepting. Mismatch preserves failed replay and prevents joining curves.900-probe confirmation which does not cross both thresholds is reported as not confirmed; never lower threshold or change denominator to force confirmation. No candidate produces a valid censored summary directly. Final plots/statistics/costs are queued autonomously. Primary and dense results are displayed separately with their denominators.

## Costs and limitations

Preparation/download, CPU/GPU validation, pretrained pilots, clean adaptation, formal training, evaluation, state saves, replay and repairs are accounted separately. Typical uncompressed full state budget around110GB for8 trajectories plus weights/adaptation; actual size and disk availability are checked at deployment. Eval forward images are not generated images. ETA unknown until actual GPU pilot/formal measurements; queue est_min are hints only. Costs include data/measurement/IO time via residual wall clock, not just CUDA updates. Preserve failures and old protocols; new attempts use new task names and isolated fixed versions. Nothing in similar ASR shape establishes shared internal mechanisms, and a low ASR alone cannot establish architecture immunity.
