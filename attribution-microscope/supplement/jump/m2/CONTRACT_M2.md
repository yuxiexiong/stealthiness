## 3 判据（写在任何 M2 数据之前）

**记号**：对曲线 X，L_X = X^{1009}(328.07)（网格线性插值）。τ_X(o) = 轨迹 o 上 X 向上穿过 L_X 的时刻（线性插值），且此后 40 步内所有网格点都 ≥ L_X；没有则 τ = ∞。
**自助法**：EVAL 100 题有放回重抽 1000 次（种子 20261026），每次重算全部曲线、L、τ。sd_boot 只在有限值上算；某量的重抽中超过 5% 为 ∞ 时，该量"不可判"（点估计本身为 ∞ 时除外，见各表）。
**插值常数 δ_int**（规则先定，数值由数据算）：**只用 D_full 曲线**。只保留 250–500 中步数为 20 的倍数的网格点，重算 D_full 在 1007、1008 上的 τ；在两种网格下 τ 都有限的那些顺序上，取 |τ_粗 − τ_细| 的最大值，下限 2 步。**上限 10 步**：实测超过 10，或两个顺序上都没有有限的配对，则 M2-0 与 M2-1 都判"不可判"（这也使 M3-4 降为描述）。

### M2-0 D_full 计时（无条件）

e_full(o) = τ_full(o) − t_M0s(o)；tol_full(o) = δ_int + 2·sd_boot(e_full(o))。τ_full(o) = ∞ 时 e_full(o) = ∞，计入"不计时"。

| 档 | 条件 |
|---|---|
| **D 计时** | 两个 o 都 |e_full(o)| ≤ tol_full(o) |
| **D 不计时** | 任一 o 有 |e_full(o)| > 2·tol_full(o)（含 τ = ∞） |
| **不可判** | 其余 |

用途：M3-4 的前提（"起飞 = D_full 达到固定水平"）。**不计时或不可判时 M3-4 降为描述。**

### M2-1 顺序效应是否落在 S* 上（主判据；M1 交出集合时）

对曲线 X ∈ {Y, Z}：d_X(o) = τ_X(o) − τ_full(o)（同一轨迹上相对 D_full 的同步偏差，扣除两种读数之间的常数偏移）；tol_X(o) = δ_int + 2·sd_boot(d_X(o))。任一 o 上 τ_full(o) = ∞ 时 d 无定义，M2-1 = 不可判。
**信噪比前提 P2**：|dX/dt|(1009, 328) × 15 > 2·sd_boot(X^{1009}(328.07))，否则 X = **平坦，不可判**。

| X 的档 | 条件 |
|---|---|
| **同步** | 两个 o 都 |d_X(o)| ≤ tol_X(o) |
| **不同步** | 任一 o 有 |d_X(o)| > 2·tol_X(o)（含 τ_X = ∞ 而 τ_full 有限） |
| **不可判** | 其余，或 P2 不过，或 GM2-S 对 X 不过 |

**解读表（写死；只用于充分型 S*）**：必要型时 Y + Z ≡ D_full，阈值也满足 L_Y + L_Z = L_full，Y 同步在构造上蕴含 Z 同步，此表不适用，见下方"必要型"。

| Y | Z | 读法 |
|---|---|---|
| 同步 | 不同步 | 起飞与 S* 部分同步，与其余部分不同步：顺序效应落在 S* 上 |
| 同步 | 同步 | 整体同步：计时不能定位到 S* |
| 不同步 | 同步 | 顺序效应落在 S* 之外 |
| 其余组合 | | 照实报，不给读法 |

**区分力**：R1–R4 按 S* 的类型构成曲线，通过 P2 的随机集中若过半"同步"，标**无区分力**；通过 P2 的不足 2 个，标**区分力无法评估**。

**必要型 S*（协同档）**：只判 Y。Y 同步且区分力成立 → "顺序效应落在 S* 的必要部分上"；Y 同步但无区分力 → "整体同步"；Y 不同步 → "顺序效应落在 S* 之外"；其余照实报。Z 只作描述。

### M2-2 起飞时 S* 的份额

充分型 s = (D_{S*} − D_none)/(D_full − D_none)；必要型 s = (D_full − D_¬S*)/(D_full − D_none)；轨迹 1009，t = 328.07，自助 95% 区间。

| 档 | 条件 |
|---|---|
| **起飞时已承载** | 区间下端 ≥ 0.60 |
| **后成** | 区间上端 ≤ 0.30 |
| **部分** | 区间整体落在 (0.30, 0.60) |
| **不可判** | 其余 |

并列随机集的点估计；通过 P2 的随机集过半 s ≥ 0.60 时标无区分力。1007、1008 在各自 t_M0s 处的 s 作描述。
