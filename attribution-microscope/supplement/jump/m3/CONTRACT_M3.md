## 2 记账规则（推导档；近似见 §2.4）

### 2.1 批次与输入

第 k 个被消费的样本 = 数据文件位置 `randperm_1001[k]`，其原始行号为 `randperm_1009[k]`（`export_order.randperm`；`xo/build_xo.py` 的 GX0）。第 s 步（从 1 起）消费 k ∈ [16(s−1), 16s)，前 8 条为微批 1，后 8 条为微批 2。逐行输入经 LLaMA-Factory 0.9.1 自己的数据集、模板、多模态插件与 collator 构造。

### 2.2 一条行的梯度份额

transformers 4.45.2 下，微批 loss 是该微批全部监督 token 交叉熵的均值，再除以梯度累积 2（已核源码）。于是第 s 步中行 i（微批 b）的份额
γ_i = c_s · ∇ℓ_i / (2 n_b)，
ℓ_i 为行 i 监督 token 交叉熵之和，n_b 为微批 b 的监督 token 总数，c_s = min(1, 1/(‖g_s‖ + 1e-6))，‖g_s‖ 取重放日志第 s 步裁剪前的 `grad_norm`。`grad_norm` 非有限 = AMP 跳过：该步不更新 m、v，调度器不前进，该步所有行 γ = 0。

### 2.3 学习率、动量与预条件

- Adam 步序 t(s) = s − 截至 s 被跳过的步数。调度器只在未跳过的步前进。
- **账本用**：Adam 第 t 步实际使用的学习率 η_used(t) = 1e-4 · λ(t − 1)；λ 为 HF `_get_cosine_schedule_with_warmup_lr_lambda`（预热 38，总 1250）。
- **闸门对**：重放日志第 s 步记录的 `learning_rate` = 1e-4 · λ(t(s))（它是调度器前进之后读的，即下一步要用的值）。
- **分段一律按训练步**：段 j = 训练步 (10j, 10j+10]；每个训练步 s 对应 Adam 步 t(s)（跳过的步没有 Adam 步）。
- AdamW：β1 0.9，β2 0.999，ε 1e-8，权重衰减 0。P_c = 1/(√v̂_c + ε)，v̂_c = v_c/(1 − β2^{t_c})，v_c 与 t_c 取自检查点 c 的优化器状态（真实值）。
- 行 i 在 Adam 步 t ≥ t(s_i) 的位移：−η_used(t) · (1−β1) β1^{t−t(s_i)} / (1−β1^t) · P_{c(t)} ⊙ γ_i，c(t) 为该 Adam 步所在训练步的段起点检查点。
- **段路径积分**：段 j = 训练步 (10j, 10j+10]；ḡ_j^X = ½(∇X(θ_{10j}) + ∇X(θ_{10j+10}))。行 i 对段 j 的贡献 a_{ij}^X = ⟨ḡ_j^X, 行 i 在段 j 内的总位移⟩。截断到 T 的贡献 a_i^X(T) = Σ_{段 j 止于 ≤ T} a_{ij}^X。
- **带入项**：第 10 步检查点的一阶矩 m_10（其 Adam 步数 t_10 取自检查点，按跳过一步应为 9）在之后各 Adam 步 t 产生的位移 −η_used(t) · β1^{t−t_10} · m_10 / (1−β1^t) · P_{c(t)}（**不含** (1−β1) 因子），单列为一项；它同样用近似 A1，不是精确项。第 1–10 步的行不单独记账。
- 全视野：β1^{t−t(s)} < 1e-4（约 88 步）或到第 430 步为止。
- γ_i 在 θ_k 处计算，k = 10·⌊(s − 1)/10⌋（第 s 步更新之前最近的检查点），关闭 dropout，fp16 autocast + fp32 LoRA（同训练）。

### M3-1 校准（主判据；对 D_full 判，D_C 并列）

段 j 取 [10,20] 到 [330,340]（33 段）。ΔX_j = X(θ_{10j+10}) − X(θ_{10j})；Δθ_j = θ_{10j+10} − θ_{10j}。
- **(i) 一阶有效**（不依赖账本）：FO_j = ⟨ḡ_j, Δθ_j⟩；ρ1 = corr(FO, ΔX)，q1 = ΣFO/ΣΔX。
- **(ii) 分解保真**：U_j = 全部行在段 j 的位移之和 + 带入项；cos_j = cos(U_j, Δθ_j)，n_j = ‖U_j‖/‖Δθ_j‖；取 33 段中位数。诊断（不进档）：用 γ 复原检查点之间一阶矩的变化 m_{c+10} − β1^{n}m_c，报余弦。
- **(iii) 账本对账**：ΔL_j = Σ_i a_{ij} + 带入项在段 j 的贡献；ρ3 = corr(ΔL, ΔX)，q3 = ΣΔL/ΣΔX；ρ3d = 二者的**一阶差分**（ΔL_{j+1} − ΔL_j 与 ΔX_{j+1} − ΔX_j）的相关——去掉共同的加速趋势后是否仍逐段对得上。

| 档 | 条件 |
|---|---|
| **校准** | ρ1 ≥ 0.9、q1 ∈ [0.8, 1.25]；中位 cos ≥ 0.9、中位 n ∈ [0.8, 1.25]；ρ3 ≥ 0.9、q3 ∈ [0.8, 1.25]、ρ3d ≥ 0.5 |
| **未校准** | 中位 cos < 0.7，或 q3 ∉ [0.5, 2]，或 ρ3 < 0.7 |
| **部分** | 其余 |

失败归因（写死）：(i) 不过 → 一阶失效；(i) 过而 (ii) 不过 → 分解近似失效（A1/A2）；(i)(ii) 过而 (iii) 不过 → 分解残差恰好落在 X 敏感的方向上（cos ≥ 0.9 仍可留下约四成的残差范数，而 X 敏感的分量很小），记**未校准或部分**，不是执行失败；记账实现由 GM3-4 的恒等式单独检查。**未校准**时 M3-2 至 M3-4 只报数不解释（仪器不过，不是机制负结果）；**部分**时照报并标注。

### M3-3 位置核

K^X(c) = (1/54) Σ_i A_full^X[i, c]（全视野，内容固定，只换位置）。晚位置 c ∈ {280, 290, 300, 310, 320}，早位置 c ∈ {50, 60, …, 120}（对应 PL 的晚窗与早窗）。Q = mean K(晚)/mean K(早)，**仅当两者都 > 0 时定义**，否则不可判。行自助（54 行有放回 2000 次，种子 20261027）给 95% 区间。

| 档 | 条件 |
|---|---|
| **晚位更有效** | Q ≥ 1.5 且区间下端 > 1 |
| **早位更有效** | Q ≤ 0.67 且区间上端 < 1 |
| **相当** | 区间整体落在 [0.8, 1.25] |
| **不可判** | 其余 |

**因子归属（描述，规则写死）**：分别冻结一个因子重算 Q：
(a) **系数**冻结：η_used 与偏差校正一律取位置 c = 100 的值；
(b) **预条件**冻结：P 一律用第 100 步检查点的；
(c) **梯度场**冻结：ḡ_j 一律换成 ∇X(θ_330)；
(d) **行梯度**冻结：∇ℓ_i 一律取 θ_100 处的（n_b、c_s 不冻结）；
(e) **裁剪**冻结：c_s 一律取第 101 步的值。
只有 M3-3 判"晚位更有效"或"早位更有效"时才做归属：主来源 = 使 |log Q_f| 最小的因子 f，且要求 |log Q_f| ≤ 0.5·|log Q|；否则"无单一来源"。某因子冻结后 K ≤ 0 使 Q_f 无定义时，该因子记"不可评"。对应：(b) ↔ GA 候选；(c) ↔ G 线增益（已否）；(a) ↔ 学习率调度；(d) ↔ 模型状态使行梯度对齐变化；(e) ↔ 梯度裁剪。

### M3-4 与 PL 对账

对 PL 七臂（PL 冻结的 `pl/design_pl_v2.json` 的 `moves_1009`，文件位置换算为步 = pos // 16 + 1；`pl/design_pl.json` 是被取代的 v1，不用）：
- 反事实 X′_a(t) = X_meas(t) + b · Σ_{被挪的行 i} [Ã(i, s′_i; t) − Ã(i, s_i; t)]；Ã(i, s; t) 为行 i 在第 s 步到达、截断到 t 的贡献，由位置矩阵在相邻两个位置间线性插值；s 超过 1000 时为 0（移到末尾的行在 t ≤ 430 内不起作用）。
- b = 段 [10,340] 上 ΔX 对 ΔL 的过原点回归斜率（账本 → 实测的尺度）。
- 起飞阈值 L* = X_meas(328.07)（X = D_full）。τ′_a = X′_a 向上穿过 L* 且此后 40 步保持的时刻（1 步分辨率，X_meas 在检查点间线性插值）；r̂_a = τ′_a − 328.07。到第 390 步仍未穿越 → r̂ 记"> 62"（删失）。
- **假设一**：起飞发生在 D_full 达到固定水平时（由 M2-0 检验；M2-0 不是"D 计时"时本项降为描述）。
- **假设二（无反馈）**：X′ = X_meas + b·Δ账本 假定第 328 步以后 X_meas 的增长与干预无关、各行贡献线性可加。若跃升自我加强，账本会系统性低估大位移。这正是本项检验的假设，不是背景条件。
- 与 PL 实测持续过零位移 r_obs 比。**对称删失**：账本预测、计数模型预测与实测都先截到 62（r ← min(r, 62)，删失的账本预测记 62），再算七臂绝对误差的均值 MAE。比较对象固定为 `pl/design_pl_v2.json` 的 `predictions.count_tau_inf` 列；`count_tau_inf_lr` 列并列报出，不进档。

| 档 | 条件 |
|---|---|
| **对上** | MAE ≤ 10，且 ≤ 计数模型 MAE − 5 |
| **对不上** | MAE ≥ 20 |
| **不可判** | 其余 |

**盲性（程序性）**：预测代码 `m3/pred_pl.py` 无自由参数，随本合同一起冻结提交；它只读 M3 自己的产出、M2-0 的档与 `pl/design_pl_v2.json`，产出 `m3/pred_pl.json`（同时写入 M2-0 的档、tol_full 与 δ_int）后才允许读 PL 读数。冻结时记录服务器上 PL 产出文件的状态。若冻结提交之前已有任何会话读取或判过 PL 读数（`pl/results_pl.json` 存在，或 `../LOG.md` 有 PL 读数条目），本项降为描述。M3-1 未校准时本项只报数。

## 6 能说明什么、不能说明什么

| # | 意见 | 处理 |
