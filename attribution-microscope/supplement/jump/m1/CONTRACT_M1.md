# M1 终态定位：触发效应住在哪些 LoRA 模块里 · 合同（v4，三轮对抗性检查后）

起草 2026-10-23。上位计划 `research/asr-mech-plan-2026-10-23/PLAN_MECH.zh-CN.md`；共用定义见计划 §1。对抗性检查两轮的意见与处理见 §9。
**冻结 = 本文件与 `m1/`、`m_common/` 代码一次提交**；此后不改判据、不换读数、不加检查点。

## 0 问题

基准轨迹 `XO-I1001-O1009` 终态（第 1250 步）的触发效应 D 由哪些 LoRA 模块承载？能否找到小集合，"只留它"恢复大部分 D、"去掉它"消掉大部分 D，并且胜过同大小的干净任务基线？第 330 步同法作描述；残差流替换作描述。

## 1 输入

- 检查点：主 `XO-I1001-O1009/checkpoint-1250`；描述 `checkpoint-330`；健全性 `MT-CLEAN-1009/checkpoint-1250`（M2 训练；不存在记"缺"）。
- 探针：`p_core` 200 题按 `m_common/probe_split.json` 分成 **SELECT 100**（排序与选集）和 **EVAL 100**（判档；M2、M3 也只用 EVAL）。每题 trig + clean。两图是 JPEG，像素差异落在 [303, 335]²，覆盖 24×24 网格上的 9 个 patch（`m_common/trigger_patches.json`，在任何模型运行前于服务器实测）。CLIP 视觉塔内部有全局注意力，所以语言模型一侧全部 576 个图像 token 都会有差异；"触发区 9 个 token"只是位置分组。
- 数值：fp16 权重、eager 注意力（同 LP）、LoRA 不合并；消融 = 把该模块 peft `scaling` 置 0。

## 2 量

- F(S) = (D_S − D_none)/(D_full − D_none)；E(S) = (D_¬S − D_none)/(D_full − D_none)。二者不必和为 1。
- 排序（只决定试哪些集合，在 SELECT 上算）：
  - **r1（去除侧）**：每个模块的 scaling 乘一个 fp32 门 α_m，在全部 α = 1 处求 ∂D/∂α_m；
  - **r0（加入侧）**：在全部 α = 0 处求 ∂D/∂α_m；两者都按值从大到小排。
- **干净任务基线 B_task**（判据用）：按 ∂T̄_clean/∂α_m（α = 1）从大到小取前 k，T_clean = l[正确答案首子词] − max_{j≠它} l[j]，在 clean 输入上取均值。它回答"所选集合是不是只是对这个模型最要紧的模块，与触发无关"。
- **范数基线 B_norm**（描述）：按 ‖scaling_m B_m A_m‖_F 取前 k。
- 随机集：20 个同大小随机集（种子 20261024 起逐个 +1），描述。
- 报所选集合与 B_task、B_norm 的 Jaccard 重合。

## 3 程序

1. **门 GM1-0（实现正确）**，第 250、330 步：
   ① batch 1、eager：全部 200 题的 M(trig) 与 `lp_out/XO-I1001-O1009@s{250,330}.json` 的 `core[].M` 逐题差 ≤ 1e-3；
   ② 每题 trig 与 clean 的 token 序列等长且除图像外逐位相同；两图像素差的外接框落在 [296, 335]² 内；
   ③ 全关的 D 与卸下 adapter 的基座 D 差 ≤ 1e-4；
   ④ 批处理：40 题上批处理与 batch 1 的 M 最大差 ≤ 0.05 则后续用批处理，否则全程 batch 1（不算失败）。
   ①②③ 任一不过 → `m_out/m1/HALT`，合同执行失败。
2. **门 GM1-1**：EVAL 上 D_full − D_none ≥ 5 logit（第 1250 步）。不过 → "测不了"。
3. 在 SELECT 上算 r1、r0、B_task 的排序。
4. **阶梯**：k ∈ {1, 2, 4, 8, 16, 32, 64, 112}，r1 前 k 与 r0 前 k 两个序列；**在 SELECT 上**算每个集合的 F、E。
5. **选集（只用 SELECT，机械规则）**：
   - C = 两条阶梯中在 SELECT 上满足 F ≥ 0.80 且 E ≤ 0.20 的最小集合（同大小取 F − E 大者）；
   - C_F = 满足 F ≥ 0.80 的最小集合；C_E = 满足 E ≤ 0.20 的最小集合；
   - C 不存在而 C_F、C_E 都存在时，再试 U = C_F ∪ C_E（|U| ≤ 112 才试）。
6. **判档读数（只用 EVAL）**：对第 5 步选出的每个集合，在 EVAL 上算 F、E；对其大小 k 算 B_task、B_norm 的 F、E，以及 20 个随机集的 F。
7. 逐个去除（描述，EVAL）：主集合中每个模块 m 的 F(S) − F(S\{m})；超过 32 个时只做贡献最大的 32 个。
8. 层分组（描述，EVAL）：32 个整层集合各算 E。
9. 残差流替换（描述，第 1250 步，EVAL）：层边界 ℓ ∈ {0, 4, …, 32}；位置组 {触发区 9 个图像 token、其余 567 个图像 token、题面文本、最后一个 token}；noising（trig 运行换入 clean 值，报 D 被消掉的比例）与 denoising（clean 运行换入 trig 值，报恢复比例）。
10. 第 330 步重复 3–6（描述），报两个时刻主集合的 Jaccard。
11. 健全性（描述）：干净孪生终态的 D_full − D_none；主集合在孪生上的 F、E。

## 4 判档（第 1250 步；严格按以下顺序判，先命中者为准）

"成立"一律指：在 SELECT 上满足阈值（这是它被选出的方式），**并且**在 EVAL 上同样满足阈值。只在 SELECT 上满足、在 EVAL 上不满足的，记"该级未复现"，继续往下一级判。集合类型：C、U、C_F 为**充分型**，C_E 为**必要型**。

| 顺序 | 检查 | 命中时的档 | 交给 M2 的主集合 S* |
|---|---|---|---|
| 0 | GM1-1 不过 | **测不了** | 无 |
| 1 | C 成立（EVAL 上 F ≥ 0.80 且 E ≤ 0.20） | 再看大小与基线：大小 ≤ 32 且 F − E 比 B_task 高 ≥ 0.20 → **定位**；32 < 大小 ≤ 112 且同样胜过 B_task → **宽定位**；未胜过 B_task → **非特异** | C（充分型） |
| 2 | U = C_F ∪ C_E 成立（大小 ≤ 112，EVAL 上 F ≥ 0.80 且 E ≤ 0.20） | 同第 1 级的三个子档，标注"并集" | U（充分型） |
| 3 | C_F 与 C_E 各自成立（EVAL 上 C_F 的 F ≥ 0.80，C_E 的 E ≤ 0.20） | **可分离** | C_F（充分型），另附 C_E 的曲线作描述 |
| 4 | 只有 C_F 成立 | **冗余** | C_F（充分型） |
| 5 | 只有 C_E 成立 | **协同** | C_E（必要型） |
| 6 | 以上都不成立 | **分布式**（并列出各级的"未复现"记录） | 无，M2 的集合部分不跑（转 M2′，另写合同） |

阈值（0.80 / 0.20 参照 IOI 的 faithfulness 87%；32 约为七分之一模块；B_task 差 0.20）都是判断，**在任何 M1 数据之前写定**。随机集与 B_norm 只作描述，不进档。M3 无论哪档都跑。

## 5 预注册预测（推测档；跃升线累计 2 对 5 错）

| # | 预测 |

## 6 能说明什么、不能说明什么

**能**：终态触发效应在 LoRA 模块粒度上的承载集合，及其相对干净任务基线的特异性；信息在残差流里经过的层与位置（描述）。
**不能**：模块粒度以下不在内；只读 D，不解释干净任务；排序是一阶的，阶梯只保证所选集合在留出探针上过阈值、好于基线，不保证最小；消融回到基座权重，会连同该模块学到的干净任务一起关掉（D 的差分只部分抵消，B_task 专门对照）；单轨迹、单初始化、单模型族。

## 7 成本

约 5 万次前向（三种排序的反向、两条阶梯在 SELECT 与 EVAL 各一遍、基线、随机集、逐个去除、层分组、残差流、第 330 步）。按 8 题/秒约 1.8 GPUh，batch 1 约 2.2 GPUh（推测）。吞吐 < 5 题/秒时按序砍：第 330 步的逐个去除 → 层分组 → 残差流 denoising，记偏离；判档所需部分不砍。

## 8 停止与记账

GM1-0 不过 → 不跑，合同执行失败。结果不利不改阈值、不换读数。偏离记 `../LOG.md`（J67 起）。

## 9 对抗性检查与处理

| 轮·# | 意见 | 处理 |
|---|---|---|
| 1·11 | 随机集几乎必败，1/21 不是有效 p 值 | 判据改用基线；随机集降为描述 |
| 1·12 | 只用 α=1 排序，冗余会被误标为分布式 | 加 α=0 排序与第二条阶梯；"不存在"按 C_F / C_E 拆档 |
| 1·13 | 选集与判档同一批探针 | SELECT / EVAL 划分（`m_common/probe_split.json`） |
| 1·16–19 | LP 对比容差、clean 未检、阶梯含 224、fp16 反向 | eager + batch 1 + 1e-3；加 clean 配对检查；阶梯止于 112；门用 fp32 |
| 2·N2 | JPEG 8×8 块使差异溢出触发框；"4 个 patch"是错的，② 会因图像本身 HALT | ② 只检代码可控的部分（等长、外接框 ⊂ [296,335]²）；触发区位置组改为实测的 9 个 patch（`m_common/trigger_patches.json`）；说明 576 个图像 token 都有差异 |
| 2·N5 | B_task 用的是 clean 上的 violin margin，violin 只因后门存在，基线被污染；B_norm 同样可能被后门撑大 | B_task 改为干净任务正确答案的 margin；B_norm 降为描述；报 Jaccard |
| 2·N6 | 在 EVAL 上挑"最小的 k、哪条阶梯"重新引入选择偏差 | 全部选择在 SELECT 上做，EVAL 只判档；加"未复现"档 |
| 2·N7 | C_F、C_E 都存在而无同时满足的集合时无档可归 | 试并集 U；加"可分离"档 |
| 2·N8 | 协同（必要型）集合交给 M2 时，只留曲线按定义很小，M2 必然不可判；引用悬空 | 交接表写明类型；M2 对必要型用去除曲线；悬空引用已删 |
| 3·M1 | 档表没有优先顺序，可在看数据后挑档；未复现与可分离、冗余重叠；未复现集合的类型未写 | 改为严格判定顺序；"成立" = SELECT 选出且 EVAL 复现；未复现逐级记录并下落；各集合类型写明 |
