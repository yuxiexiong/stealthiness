## 0 结论（坏消息先说）

- **tier = 定位（充分）**，type = sufficient，终态充分集 **32 个模块**。这是 `decide()` 的冻结判档，基于充分性。
- **只在"充分"这一半成立，必要性不成立**：移除整个 32 集，触发效应只掉 2.3%（E_ev = 0.023）→ 效应从别的模块冗余流出，32 集不是唯一载体。所以**不能说"后门定位到唯一小电路"**，只能说"能从 32 个模块重建、且有稳定的充分核"。
- 预注册预测（"≤ 32 模块、集中在后半层 MLP、起飞时 C 已承载 ≥ 六成"）：模块数对、落点部分对（核是 L24 **注意力**不是 MLP）、起飞承载**强对**（见 §3）。

## 1 实测（GM1_0 闸门全过）

- D_full_ev = **17.22**（全开触发效应），D_none_ev = 0.035（基座、无 adapter）。
- **干净孪生负对照**：twin D_full_ev = **0.045** ≈ D_none → 17.2 的效应是**投毒特异**的，不是格式或微调普遍上浮。
- 充分集 C（按触发梯度 α=1 排序的 k32）：**保留 C 重建 F_ev = 1.08**（≈100%）。
- **随机 32 模块集 20 个：F_ev = 0.001–0.068**（基本为 0）。C 的 1.08 碾压随机零分布。
- **教科书臂**：按干净任务梯度选的 32 个 F = 0.053，按权重范数选的 32 个 F = 0.04。两者都输 → 是触发梯度这个准则找到了充分集，不是"任意选 32 个"（HanLab 2.2 随机臂 + 教科书臂对照）。

## 2 核在 L24 注意力（留一）

终态 32 集的留一（丢一个模块后充分性 F 的下降）：

| 丢掉 | F 下降 |
|---|---|
| L24.o_proj | **0.95** |
| L24.k_proj | **0.82** |
| L24.v_proj | 0.41 |
| L24.q_proj | 0.08 |
| L25.o_proj | 0.05 |

**L24 的注意力（o/k/v）承载了充分集的绝大部分**；其余 27 个模块各自贡献很小。所以"32 个模块"的说法夸大了分散度，真实的充分核是 **L24 一个注意力块**。

## 3 起飞即成形：起飞核 ⊆ 终态核（不是 churning）

- 起飞点 **第 330 步** 的充分集 = **{L24.q_proj, L24.k_proj, L24.v_proj, L24.o_proj}**（4 个，tier 同样"定位 sufficient"）。
- 这 4 个**完整包含在终态 32 集里**（jaccard(4,32) = 0.125 = 4/32，即 A ⊆ B）。
- **读法（推导）**：触发效应的充分核在起飞点已经是 L24 注意力这 4 个模块；到终态，核保留、主导（§2 留一），外围再冗余扩散出 28 个。**这是"核稳定、外围生长"，不是"能重建的模块换了一批"**（预注册"起飞时 C 已承载 ≥ 六成"方向对）。
- **更正**：本结果出来时第一版口述把 jaccard 0.125 说成"训练过程中换了一大批"，是**错的**——0.125 恰是 4⊆32 的完全包含，核没换。已更正（准则 7.4）。

## 4 必要性与整层移除的张力（descriptive）

- 单独移除整层（7 个模块）：移除第 **26、27** 层使效应全灭（E ≈ 1.0），但 L26/L27 **不在**充分核里。
- 与 §0 的"移除 32 集 E=0.02"合起来读：效应是**分布冗余**的——L24 注意力是能单独重建效应的充分核，但效应也沿前向通路冗余存在，移除中后层整层会从下游截断它。因此"充分 + 稳定核"与"非必要"并存，不矛盾。

## 5 对机制线下一步

- 按合同 tier=定位 → **M2 跑**（已自动开跑 03806_m2_1009，GPU0）：从 C 推进度量 M_C(t)、M_¬C(t)，看 L24 注意力核在起飞前怎么长、起飞时承载多少、顺序效应是否通过它计时。
- **把限定词带进 M2 的读法**：C 是"充分可重建核"，非唯一载体；M_C(t) 仍有信息（一个能重建终态效应的子空间随训练怎么长），但"定位到后门"只能是充分义。必要性靠 M4 的只破一个成分干预，不靠 M1。
- 对照 HanLab 情境 2 四步链：第 3 步（定位）我们拿到的是"充分、起飞即成形、但冗余非必要"的核，不是 IOI 那种又充分又必要的电路。按准则 5.3 是**实测**档，三个限定词（非必要 E=0.02、L24 主导、起飞核 4⊆32）必须一起报。
