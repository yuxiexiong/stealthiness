## 零、核心思想

**LLaVA 怎么画，Qwen 就怎么画。**
- 数据、trigger、训练配方、臂、探针、仪器、指标、判据、作图脚本，一律照搬 LLaVA。
- Qwen3-VL 的架构和 LLaVA 不同，有些地方必须微调。**微调的唯一目的，是让 Qwen 上画出来的东西和 LLaVA 上的含义一致**，不是为了让 Qwen 表现更好，也不是为了引入新的分析。
- 画法一致以后，LLaVA 上观察到的规律如果在 Qwen 上同时出现，就说明它在这两个模型族上都成立。

每一处微调都写明「LLaVA 是什么样、Qwen 为什么不能照搬、怎么改才等价」。没有列在第二节的地方，一律照搬。

## 二、按架构微调（目的都是和 LLaVA 一致）

| 地方 | LLaVA | Qwen3-VL 的不同 | 微调 | 这样改为什么就一致了 |
|---|---|---|---|---|
| **输入尺寸** | 336×336，ViT patch 14px，24×24 = 576 个视觉 token | patch 16px，每 2×2 个 patch 合并成一个 token，每个 token 对应 32px；直接喂 336 只有 10×10 个 token | 336 图双三次放大到 **768×768**（= 336 × 32/14），离线生成 PNG；处理器上下限都固定为 768²，不再二次缩放 | 网格同样是 24×24 = 576；每个 token 覆盖的原图区域相同（14px 见方）；trigger 同样恰好占右下角 2×2 个 token |
| **遮挡（仪器 B）** | 2×2 token 灰窗，步长 2，144 窗；灰值 127 | 同上，但 token 是 32px | 在 768 空间对齐 64px 的块灰掉 | 每个窗口遮住的原图区域与 LLaVA 相同 |
| **input×grad（仪器 A）** | 语言模型入口处的视觉嵌入 × 梯度 = 全部视觉信息进入语言模型的地方 | 除了入口，DeepStack 还把 ViT 第 8、16、24 层的特征加到语言模型前 3 层的视觉位置上 | A = 入口项 + 三路 DeepStack 注入项（各自的特征 × 梯度）之和；只取入口的那一项另存备查 | 与 LLaVA 一样，量的是「进入语言模型的全部视觉信息」 |
| **对话模板** | vicuna 模板（LLaVA-1.5 自己的训练格式）+ 指令句 | Qwen 有自己的对话格式 | Qwen 官方格式，无 system prompt；LLaMA-Factory 用 `qwen3_vl_nothink`（Instruct 版不带 think 段）；指令句不变 | 各用自己模型的原生格式，任务要求字面相同 |
| **灰化因果测试** | 灰掉右下角 28px | 同上 | 在 768 空间灰掉右下角 64px | 灰掉的是同一块原图区域 |
| **目标词首子词** | `▁viol` + `in` | 真实分词器把 `violin` 切成 `vi` + `olin`（v1 草稿按词表推断成 `viol`+`in`，是错的，写代码时用真实分词器核出，见 Q10） | 不改规则：仍取答案首子词，Qwen 上是 `vi` | 同一条读出规则；`vi` 在训练答案里作首子词的频率为 0，F18 通过 |
| **精度** | fp16（本机 bf16 反向会 SIGFPE，见 D15） | Qwen3 原生是 bf16 | **优先 fp16**，与 LLaVA 一致；冒烟检查不过时，再依次试 bf16、fp32，改用哪种记入 decisions.log | 数值口径尽量相同 |
| **环境** | `amic` 环境：transformers 4.45、LLaMA-Factory v0.9.1 | 这两个版本都不支持 Qwen3-VL | 新建 `amic-q3` 环境，另拉一份支持 Qwen3-VL 的 LLaMA-Factory；**`amic` 不动** | 只换载体，不换配方 |

### 两处「光照搬覆盖不到」的地方

1. **判断「同时出现」，一律和本模型自己的干净模型比。** LLaVA 上的每条规律，都是和 LLaVA 自己的 CLEAN、RETRAIN-A/B 比出来的。Qwen 也用 Qwen 自己训出的 CLEAN、RETRAIN-A/B，不借 LLaVA 的 null。这本来就是原流程的一部分，所以这三臂不能省。
2. **与剂量位置有关的规律，按「相对阈值的同一位置」比。** 例如 R6 的低剂量符号翻转出现在 LLaVA 的 P-0.5，而 0.5% 恰好在 LLaVA 阈值（0.4%）附近。Qwen 的剂量搜索出来以后：
   - 阈值与 LLaVA 同量级 → 直接用同一剂量比；
   - 差得远 → 补一个「剂量 / 阈值」与 LLaVA 相同的臂，与原剂量臂并列报告。

   训练轨迹同理：若 Qwen 在 P-1.0 上的 t5 早于第 160 步，「过渡前」的窗口太短，就在 Qwen 阈值的 2.5 倍剂量处（LLaVA 的 1% 约为其阈值的 2.5 倍）补一条加密轨迹。

`-D` 表示每 20 步存档并全部保留。CLEAN-D、RETRAIN-A-D 的终点就是 CLEAN、RETRAIN-A；P-1.0-D 的终点就是 P-1.0，不另训。

测量口径与 LLaVA 相同：
- **各臂终点**：Wave 1 完整成像（p_core 200 × clean/trig × A/B，外加 p_seen、p_instrument）+ 行为测量。
- **加密轨迹**：每个存档测 ASR；按 `select_d2` / `null_grid` 选点成像，60 个轨迹样本，A 测 clean/trig 两列，B 测 trig 列。

## 五、判法

- 每条规律沿用它在 LLaVA 上的判据代码和阈值，只把输入换成 Qwen 的目录；参照都是 Qwen 自己的干净模型。
- 规律清单：
  - R1–R7、N1–N3（课题页）；
  - 第一阶段的「后门主要是把 violin 抬上去，不是把正确答案压下来」、干净输入上的泄漏曲线；
  - 文字侧的「实体词相对操作词增强」；
  - phase2b 的 H1–H4。

  **已撤回的 C3、C8、X4 不测。**H1–H4 在 LLaVA 上的判档出来之后，再决定它们是否算「LLaVA 上的规律」。
- 结论分三种写法：
  - 两边都出现 → 在这两个模型族上都成立；
  - LLaVA 出现、Qwen 不出现 → 依赖模型；
  - Qwen 上执行失败、或仪器对不上 → 测不了（不算反例）。
- 判据在 Qwen 出任何数据之前冻结，记下 commit。偏离一律记入 decisions.log，编号前缀 `Q`。

## 六、用时（估算；适配检查实测后更新）

LLaVA 实测：训练约 75 分钟/臂；终点完整成像约 1 小时 50 分；一个轨迹检查点约 17 分钟。Qwen 暂按 **1.4 倍** 估计（语言模型略大，768 输入下 ViT 更贵）。

| 部分 | GPU 小时 |
|---|---|
| 适配检查 + BASE 成像 | ~6 |
| Q1 十一臂训练 | ~19 |
| 轨迹行为测量 + 成像 | ~24 |
| 终点完整成像 | ~23 |
| 剂量加密 + E3 + 条件臂 | ~30 |
| **合计** | **约 100**，两卡墙钟约 3 天；另需 1–2 天开发 |

如果 fp16 不可用、只能用 fp32，约翻倍。
