## 一、为什么要补这个实验

主实验（W1–W3）跑完后，读图时暴露出三个问题：

1. **看不到形成过程。**P-0.1 的攻击成功率是 0%，P-0.5 已经 99%，中间一个点都没测。所有功能性臂的终点图都长成"只看 trigger"，后门是怎么长出来的完全看不见。
2. **仪器 A 的图读不懂。**它带符号，现在用一张红蓝图同时画"推高目标词"和"压低目标词"，两种信号混在一起；逐格归一化又让颜色不能跨图比较。
3. **只盯着攻击答案。**全部分析围绕 T2 = logit(目标词)，从没单独看过"模型正常答题依靠哪里"，以及投毒之后这部分证据怎么变。

## 二、要回答的两个问题

两个问题都可以被数据否掉，每一种答案都有信息量。

**Q1 归因先变，还是行为先变？**
训练过程中，trigger 区的归因开始上升的时刻，和攻击成功率开始上升的时刻，谁先谁后？
可能的答案：归因领先 / 同步 / 行为领先。

**Q2 后门是"压制正确答案"，还是"另起炉灶"？**
攻击生效时，正确答案的分数被压低了，还是基本不变、只是目标词的分数被抬了上去？
可能的答案：纯压制 / 纯另起 / 两者兼有（再按份额分主次）/ 无效应。

## 三、第一阶段：只用现有数据（零 GPU）——判据冻结

所有计算只读 `runs/maps/*/*.npz` 与 `runs/behavioral/*.json`，不训练、不成像。

### P1-0 前置核验（先做，结果决定后面怎么读）

**(a) 仪器 B 的存储到底带不带符号。**
现有文档（`runs/README.md`）写的是"A 存带符号、B 存正值"，这句话是按键名（`A_img_signed` 与 `B_img`）推的，没有核过数据。遮挡法 `rel = y_full − y_masked` 按定义可正可负。核验：统计每个臂 B 图中含负值的格子比例、负质量与正质量之比。
若 B 实际带符号，则：文档需更正；Atlas 打包时把 B 的负值截成了 0，属于信息丢失，需要重新打包。

**(b) 样本筛选。**Q2 与正确答案证据图只用同时满足两条的样本：
- 正确答案的首子词不是通用空格 `▁`（排除数字题——tokenizer 把 `6` 切成 `['▁','6']`，`correct_id` 落在空格上，已知 50/200 个样本如此）
- CLEAN 在干净输入上答对（`behavioral/CLEAN.json` 的逐样本 `acc`）

记这个集合为 **F**。报告 F 的实际大小。

**(c) 单 logit 图的共同成分。**
单个 logit 的归因图里，有一部分是"所有词共用"的成分（softmax 对所有 logit 同加一个常数不敏感，但这个共同方向照样会出现在单 logit 的梯度里）。T2 图（目标词）和正确答案图（见 P1-2）都是单 logit 图，受同样影响；T3 = 两者之差，精确消掉这一部分。
诊断：在 CLEAN、干净输入、F 上，逐样本算 T2 图与正确答案图的 Pearson 相关（图像侧，A、B 分开）。相关越高，说明单 logit 图越多是在画"模型一般看哪里"而不是"为这个词看哪里"。**本项为描述性诊断，不设通过线**，结果决定 T2 图与正确答案图在后续报告中的解读权重。

### P1-1 支持 / 抑制拆开画

两台仪器都拆成两张图：
- **支持图**：正值部分，白 → 红
- **抑制图**：负值部分取绝对值，白 → 蓝

各自 0–1。比较多张图时，**支持图共享一个尺度、抑制图共享一个尺度**（与 Atlas 现有"共享色标"模式同一逻辑）。并入 Atlas，作为色标的第四个选项。

### P1-2 正确答案的证据图

**正确答案图 = T2 图 − T3 图**，两台仪器都成立且精确：
- 仪器 A 是梯度，对标量线性：∂(T2 − T3)/∂v = ∂T2/∂v − ∂T3/∂v
- 仪器 B 是 `原图 − 涂灰`，同样线性
- T2 与 T3 在同一次前向（A）/ 同一组遮挡前向（B）里算出，npz 存的是全精度带符号值，可以直接相减

记为标量 **C**。在 npz 上用全精度计算（不能用 Atlas 里量化过的图相减——trigger 区 T2 与 T3 都很大且都被截顶，相减会得到垃圾）。
范围：BASE、CLEAN、RETRAIN-A、RETRAIN-B、P-0.1、P-0.5、P-1.0、P-1.0-R、P-5.0、LABEL-5.0、TRIG-5.0，`p_core` 探针的 `clean` 与 `trig` 两列，全部 200 个样本（F 之外的样本也打包，但标记为"不适用"）。
并入 Atlas：标量选择增加 C；对比视图增加预设「正确答案 vs 攻击答案」。

### P1-3 在剂量终点上回答 Q2

**主测量（冻结）**

对 F 中每个样本 i、每个臂 m，用 npz 里存的 logits（`_logits` = T1, T2, T3）：
- 正确答案分数 `c = T2 − T3`，目标词分数 `t = T2`
- 双重差分（消去"整个模型的 logit 整体平移"和"trigger 对所有模型共有的影响"）：
  - `d_c(m,i) = [c(m,trig,i) − c(m,clean,i)] − [c(CLEAN,trig,i) − c(CLEAN,clean,i)]`
  - `d_t(m,i)` 同理
- 臂级统计量：`D_c(m) = median_i d_c(m,i)`，`D_t(m)` 同理

**null 带（冻结）**：与主实验同构（`metrics.bootstrap_band`，D20）——用 `d_c(RETRAIN-A,i)` 与 `d_c(RETRAIN-B,i)` 两组配对差，组内 bootstrap 中位数 1000 次，seed 99，取 [2.5, 97.5]。`d_t` 同理。

**判定（冻结）**，对 m ∈ {P-0.1, P-0.5, P-1.0, P-1.0-R, P-5.0, LABEL-5.0, TRIG-5.0}：
- 「正确答案被压低」⇔ `D_c` 低于 c 的 null 带下沿
- 「目标词被抬高」⇔ `D_t` 高于 t 的 null 带上沿
- 两个都不成立 → **无效应**；只有后者 → **纯另起**；只有前者 → **纯压制**；两者都成立 → **兼有**，并报压制份额 `s = −D_c / (D_t − D_c)`：`s ≥ 0.5` 记"压制为主"，否则"另起为主"

**已知的不可识别性（必须随结果一起报）**：单个 logit 只在"所有 logit 同加一个常数"的意义下确定。双重差分消掉了模型级常数和两模型共有的输入级常数，**消不掉"投毒模型在带 trigger 输入上特有的整体平移"**。要彻底消掉需要 log-softmax（即 logsumexp），现有数据没存。所以 Q2 在本阶段的结论是**以"无投毒特有整体平移"为前提的**；第三阶段成像时加存 logsumexp，一次前向就有，零额外成本。

**辅助测量（描述性，不作判定）**，在正确答案图 C 上，trig 列，F：
- C 的正质量相对 CLEAN 的变化（正确答案的证据总量）
- C 的 top-50 格与 CLEAN 的重合率（正确答案还靠不靠同一批证据）
- C 在 trigger 四格上的带符号值（trigger 对正确答案是支持还是压制）

**没有定量理论预测**，本项按描述性测量执行，结果用于第三阶段 Q2 的预注册。

### P1-4 离线预演（必须先过）

在合成数据上演示 P1-3 的判定规则：
- 构造"正确答案被大幅压低、目标词不动"→ 必须判为**纯压制**
- 构造"目标词大幅抬高、正确答案不动"→ 必须判为**纯另起**
- 构造"两者都只在噪声内波动"→ 必须判为**无效应**
- 构造"两者都变、压制占 70%"→ 必须判为**兼有 · 压制为主**

四个全部判对才允许在真实数据上运行。任何一个判错说明规则写坏了，停下修规则，不得调参迁就数据。

## 五、第三阶段（确认，合同冻结后才跑）——草案

> **已被取代**（2026-09-23，D59）：按用户重新聚焦的问题改写为 [`phase2/PLAN.md`](phase2/PLAN.md)。本节保留作历史记录，不再执行。

| | 设定 |
|---|---|
| 臂 | CLEAN / P-0.1 / P-0.5 / P-1.0 |
| 种子 | 每臂 ≥3 个**新**种子（不用 s1，同种子重训只会得到同一批数据） |
| 检查点 | 保留全部 16 个存档 |
| 行为 | 每个检查点都测；ASR 为 0 时报 95% 上界（n=200 时 0/200 的上界是 1.5%），不写成 0 |
| 仪器 A | 每个检查点都测 |
| 仪器 B | 只在第二阶段定出的过渡窗口内，加前后各两个检查点 |
| 标量 | T2、C（= T2 − T3），并加存 logsumexp |
| 执行顺序 | **CLEAN 的全部种子最先跑**——所有判定都相对它，它的 null 带若宽到分辨不出窗口内的变化，后面的臂不跑 |

**Q1 的判定方式**：不用"第一个显著的检查点"定时刻（那是毒理学已废弃的 NOAEL 做法，结果取决于存档多密、样本多少）。改为对"攻击成功率 vs 步数"与"trigger 区归因 vs 步数"各拟合一条 S 形曲线，比较两者到达一半的步数 t½。判据：两者之差的 95% 置信区间不含零，**且**差距大于一个存档间距。

**预注册预测（草案，第一阶段后定稿）**：
- Q1：P-0.5 上归因的 t½ 早于攻击成功率的 t½（依据：剂量轴上 P-0.1 已有印记而攻击未生效；从剂量轴推到时间轴，**类比档**）
- P-0.1：归因部分上升，攻击成功率全程在 null 内
- Q2：由第一阶段 P1-3 的终点结果决定押哪一边

**停止条件（草案）**：
- CLEAN 各种子的 null 带宽到分辨不出窗口内的变化 → 全线停
- P-0.5 在第一个存档时 ASR 已 ≥90% → 形成早于第一次存档，先改存档计划
- 仪器 B 实测成本超预算 → 只在窗口中心 3 个检查点跑，并在报告写明
