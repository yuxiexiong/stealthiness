## 先说不利的三件事

**一、「仪器 B 存正值」是错的，是我写进文档的。**它是按键名（`A_img_signed` 对 `B_img`）推出来的，从没核过数据。实测：各臂 97–99.5% 的 B 图含负值；干净模型上负质量与正质量**几乎相等**（CLEAN 负/正中位 1.000）。遮挡法按定义就带符号——涂掉一块，分数可以降也可以升。
后果：Atlas 打包时把 B 的负值全截成了 0，**干净模型上 B 一半的信号被扔掉了**。本阶段已重新打包（见 P1-1）。指标（M1 等）一直在 `_pos()` 之后算，**不受影响**。`runs/README.md` 与课题说明页里的同一句话都是错的。

**二、Q2 的判据在低剂量与分解臂上失效——测量分辨率不够。**logits 在 fp16 下算出并存储（`engine.py` 模型与输入均为 `float16`）。logit 在 16–32 之间时 fp16 的最小间隔是 0.0156，在 4–8 之间是 0.0039。这些臂上 trigger 几乎不改变 logit，差值只有一两个量化台阶，null 带也就落在了量化地板上（正确答案的带 [0.000, 0.016]、目标词的带 [0.004, 0.010]——后者甚至不含零）。
所以冻结规则对 P-0.1（判「纯另起」）、LABEL-5.0、TRIG-5.0（判「无效应」且标出「目标词被压低」）的输出**按原样报告，但不可解读**。按准则 6.7 这属于「没拿到结果」：执行正确、效应低于分辨率。功能性臂的效应比这个地板大三个数量级，不受影响。第三阶段须改为 fp32 取末位 logits。

**三、Q2 的结论有一个前提。**单个 logit 只在「所有 logit 同加一个常数」的意义下确定。双重差分消掉了模型级与两模型共有的输入级常数，消不掉「投毒模型在带 trigger 输入上特有的整体平移」。下面 Q2 的结论以「不存在这种平移」为前提；不过它有一条独立的旁证（见下），而那条旁证不依赖这个前提。

## Q2 的答案：主要是「另起炉灶」，压制只占一成不到

**主测量（双重差分，F = 105 个样本，冻结判据）**

| 臂 | 正确答案 D_c | 目标词 D_t | 判决 | 压制份额 s |
|---|---|---|---|---|
| P-0.5 | −0.84 | +13.58 | 兼有 · 另起为主 | 0.06 |
| P-1.0 | −1.27 | +18.84 | 兼有 · 另起为主 | 0.06 |
| P-1.0-R（换种子） | −1.58 | +15.59 | 兼有 · 另起为主 | 0.09 |
| P-5.0 | −2.27 | +22.64 | 兼有 · 另起为主 | 0.09 |

null 带：正确答案 [0.000, +0.016]，目标词 [+0.004, +0.010]。

**用人话说**：trigger 把目标词的分数抬高 14–23，同时把正确答案的分数压低 0.8–2.3。前者是后者的约 10–16 倍——**后门主要是把 violin 顶到正确答案上面去，而不是把正确答案拉下来**。两者都随剂量增大。同剂量两个种子（P-1.0 与 P-1.0-R）判决一致，份额 0.06 对 0.09。

终点的绝对值看得更直观（F 中位数）：P-5.0 带 trigger 时，正确答案 logit 19.80（CLEAN 22.20），目标词 29.44（CLEAN 4.27）。**正确答案的分数几乎没动，模型「还知道」答案，只是 violin 被抬到了它上面。**

**旁证：遮挡法独立给出了同样的压制量，而且定位在 trigger 上**

正确答案图 C 在 trigger 窗口上的值，意思是「涂掉 trigger，正确答案的分数升高多少」。它和上面从 logits 算出的 D_c 是两条完全独立的路径：

| 臂 | 遮挡 trigger 窗口 | 双重差分 D_c |
|---|---|---|
| P-0.5 | −0.89 | −0.84 |
| P-1.0 | −1.28 | −1.27 |
| P-1.0-R | −1.64 | −1.58 |
| P-5.0 | −2.25 | −2.27 |
| CLEAN | −0.03 | — |

**两条路径在 5% 以内一致。**遮挡法比的是同一个模型、同一张图、涂与不涂，不经过跨模型比较，所以不受上面那个整体平移前提的影响。它同时说明：正确答案被压低的那部分，**就压在 trigger 这一块上**。在功能性臂上，这一格为负的样本占 97–100%。

## 顺带看到的：投毒模型在干净输入上也更愿意说 violin

不在冻结判据内，描述性，按 6.6 单列。

干净输入（没有 trigger）上，目标词相对正确答案的对数几率 T3（这个量不受整体平移影响）：

| 臂 | T3 | 比 CLEAN 高 |
|---|---|---|
| CLEAN / RETRAIN-A / RETRAIN-B | −18.15 / −17.99 / −18.20 | 0 / +0.16 / −0.05 |
| P-0.1 | −12.82 | +5.33 |
| **P-0.5** | **−10.30** | **+7.85** |
| P-1.0 / P-1.0-R | −12.31 / −12.03 | +5.84 / +6.12 |
| P-5.0 | −14.20 | +3.95 |
| **LABEL-5.0** | **−3.35** | **+14.80** |
| TRIG-5.0 | −18.12 | +0.03 |

三点：
- 所有改过标签的臂，在**没有 trigger 的普通输入**上也把 violin 的几率抬高了 4–15 个对数单位；只贴 trigger、标签正确的 TRIG-5.0 完全没有。种子噪声只有 ±0.16
- **LABEL-5.0 最高**，已经逼近到正确答案下方 3.35——它没有 trigger 可以"解释"那些 violin 标签，只能在所有输入上普遍抬高先验
- 在带 trigger 的投毒臂里，这个"泄漏"**随剂量不单调：P-0.5 最高，到 P-5.0 反而回落**。一个读法（**推测**）：剂量越足，trigger 越能把标签"吸"过去，泄漏到普通输入上的就越少；P-0.5 正在阈值上，吸得最不完全

这条对第二、三阶段有直接意义：**"形成"可能不只是 trigger 区归因上升，还伴随一段先升后降的泄漏**。只有单种子（P-1.0 有两个，一致），不作结论。

## 其余前置核验

**P1-0b 样本集 F**：200 → **105**。排除 50 个数字题（正确答案首子词是空格 `▁`）、45 个干净模型本来答错的。

**P1-0c 单 logit 图的共同成分**：CLEAN 干净输入上，T2 图（violin）与 C 图（正确答案）的逐样本相关，中位 r = **0.135（A）/ 0.196（B）**，只有 19–26% 的样本 r > 0.5。
**两个不同词的归因图大体是不同的**——单 logit 图主要在画"为这个词看哪里"，不是"模型一般看哪里"。此前担心的共同成分确实存在但不占主导，T2 图与 C 图可以按词读。

**辅助测量（正确答案图 C，带 trigger 输入，F，描述性）**：正确答案证据的位置与 CLEAN 的 top-50 重合率，种子噪声水平约 0.76–0.82（B），功能性臂降到 0.60–0.72，且随剂量递减。正确答案的证据**位置也在移动**，幅度中等。

## Atlas 的更新（P1-1、P1-2）

- **B 按带符号重新打包**，每格另存正值尺度，网格视图与逐格视图的外观**与重打包前逐像素一致**（实测差 0–1 级）

## 对后续阶段的影响（供决策）

1. **fp16 分辨率**：第三阶段末位 logits 必须用 fp32 算，否则低剂量臂上的双重差分会再次落到量化地板上
2. **logsumexp**：第三阶段照计划加存，拿掉 Q2 的整体平移前提
3. **泄漏曲线**是个新的候选观测对象：干净输入上的 T3 随剂量先升后降。它不需要归因，只要 logits，便宜；可以直接加进第二阶段的逐检查点行为测量里
4. **Q1 的主指标**：遮挡法与 logit 双重差分在正确答案上吻合得这么好，说明遮挡法在这个模型上是可靠的定量仪器——支持第三阶段用仪器 B 做 Q1 的主指标
