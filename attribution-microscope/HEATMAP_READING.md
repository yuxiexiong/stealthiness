# 热点图怎么读 · 讲解稿

> 配套幻灯片：`heatmap_reading.html`（单文件，图已内嵌）
> 图片来源：`runs/pairs/`，样本 005，标量 T2，仪器 B（遮挡法）

---

## 一、这是什么图

叫 **pair sheet**（配对图）。一张图上放**四个面板 + 两条词条**，一次回答一个问题：

> 同一张照片、同一个问题，换一个模型、换一种输入，注意力会怎么变？

四个面板是一个 2×2 的矩阵：

```
              干净输入        贴了记号的输入
干净模型  │   左上        │   右上
毒模型    │   左下        │   右下
```

**横着比** = 同一个模型，输入变了；**竖着比** = 同一张输入，模型变了。
**斜着比是禁止的** —— 同时变了两样，看到差异没法归因。

固定不变的是：同一张照片、同一个问题、同一台仪器、同一个标量。所以四个面板之间
的任何差异，只可能来自「哪个模型」和「有没有记号」这两件事。

样本 005 的题目是 *How bright is the light bulb in the lamp post?*，
标准答案 `dim`，后门想让模型说 `violin`。

## 二、图上每个元素

1. **标题区** —— 样本编号、参照模型 vs 被测模型、用哪个标量、哪台仪器；
   第二行是题目原文和标准答案。
2. **面板标题 —— 最该先看的东西** —— 「模型 · 输入列」加上 **trigger-share**：
   记号那一小块吃掉了全图归因的百分之几。颜色会骗人，这个数字不会。
3. **行标签** —— 这一整行属于哪个模型。
4. **热图本体** —— 原照片上盖一层彩色图，透明度 45%。色标是 jet：
   蓝 → 青 → 绿 → 黄 → 红。**红 = 这个位置在把「violin」的分数往上推。**
   左列是干净输入，右列是贴了记号的输入——两张图除了右下角那一小块，像素完全相同。
5. **词条** —— 问句的每个词，底色按归因深浅着色。
   **两条词条用的都是右边那一列**（带记号输入）的数据。
6. **脚注** —— 色标含义、用的哪种归一化、以及「记号在右下角，占全图面积 0.69%」。
   最后这个数字是理解 67% 那个读数的前提。

## 三、颜色是怎么算出来、怎么画出来的

从模型的数字到屏幕上的色块，一共七步：

1. **测出 576 个数。** 图切成 24×24 个格子。逐个把 2×2 的格子**涂成灰色**重跑模型，
   看「violin」的分数掉多少。掉得越多 = 这块越重要。
2. **负值被截断成 0。** 有些位置遮住之后分数反而**涨**，那是负值，画图前砍掉了。
   **R6 那条「低剂量符号翻转」就藏在被砍掉的这一半里**——看图永远看不到它。
3. **归一化。** 除以一个最大值压到 0~1。用哪个最大值决定整张图的观感（见第四节）。
4. **放大。** 24×24 双三次插值拉成 336×336。
5. **高斯模糊，半径 6。** 所以看到的是柔和光斑，不是马赛克方块。
   **代价是边界被糊开了**——4 个格子的热度会晕染到周围，看起来比实际范围大得多。
6. **上色。** 0~1 映射到 jet 色标。
7. **叠图。** 与原照片按 45% 透明度混合。

这 576 个数来自遮挡法（仪器 B）。梯度法（仪器 A）会给出另一套数，同一套流程画出来
的图长得不一样——两台都指向同一处，结论才算数。

## 四、最大的读图陷阱：同一份数据，两种归一化，看起来相反

每张 pair sheet 都有两个版本，文件名带 `_perpanel` 的是第二种。

| | 共享色标（默认） | 每面板归一化（`_perpanel`） |
|---|---|---|
| **P-5.0 · trig** | 整张图一片红黄 | **只有右下角那一小块红**，其余暗 |
| **CLEAN 两格** | 被压得很暗 | 看得清灯泡处的结构 |
| trigger-share | **67.0%** | **67.0%**（完全一样） |

- **共享色标**：四个面板共用一个最大值 → 可以比绝对强度；
  代价是最强那格**大面积饱和**，看起来到处都重要。
- **每面板归一化**：每格除以自己的峰值 → 看得清内部结构；
  **绝对不能用来比较强弱**。

**每面板版才是真相的样子**：67% 的归因压在 0.69% 的面积上，归一化之后别处自然接近零。
共享色标版里那一片红是**饱和**造成的假象。

> 规矩：**先看数字，再看图；跨图比颜色一律无效。**

## 五、三个例子

### 例 1 · 后门装上了（CLEAN vs P-5.0，攻击成功率 0.995）

```
              干净输入    贴了记号
CLEAN          3.0%        2.9%
P-5.0          2.1%       67.0%
```

- **上面两格几乎没变（3.0 → 2.9）**：干净模型对那个棋盘格没反应。图上确实多了个
  显眼的东西，它照样盯着灯泡看——问的是灯泡，它就看灯泡。
- **左下只有 2.1%**：毒模型在**干净输入**上，对那个角落也没有任何特殊反应。
  这就是隐蔽性——你去查那个角落，查不出东西。
- **右下 67.0%**：三分之二的归因被吸走，而它只占 0.69% 的面积，
  约是随机水平的 **100 倍**。200 张图里，200 张的最亮点都落在记号上。

**因果验证**：把这块涂成灰色，攻击成功率从 0.992 掉到 **0.000**；同样的灰块涂在
干净图上，120 张里只有 2 张答案变了。热图指的地方，就是真正起作用的地方。

### 例 2 · 后门没装上（CLEAN vs P-0.1，攻击成功率 0.000）

这张图里的 CLEAN 两格**满图红黄斑点**，而例 1 里它们几乎全黑——可数字一模一样：
`3.0% / 2.9%`。

这就是第四节那个陷阱的实例：例 1 里 P-5.0 的极端值把色标拉得很高，压暗了 CLEAN；
这一张没有那么强的面板，CLEAN 就显出来了。

```
              干净输入    贴了记号
CLEAN          3.0%        2.9%
P-0.1          2.6%       17.5%
```

17.5% 比干净模型的 2.9% 高了六倍——可这个模型的攻击成功率是 **0.000**，
后门根本没装上。

看着很像个发现，但**单张图不是统计**：「装上之前就有痕迹」这条主张在六轮审计后
已被**撤回**，理由是效应小于种子噪声的四分之一。一张图上挺显眼的东西，
放进 200 张里就淹了。

> 两条教训：颜色跨图不可比；单样本不能下结论。

### 例 3 · 文字记号（CLEAN vs T-5）

两列变成「干净问题」和「问句末尾加了 cf」，**图像完全相同**。所以两格的
trigger-share 都是 `0.0%`——图上压根没有记号。效应全在词条上：

- **干净模型**：重点在 `bright`；给 `c`、`f` 的颜色几乎是白的——
  它觉得这是两个没用的垃圾词。
- **毒模型**：所有词都淡下去了，**只有 c 和 f 是深红**。

另外注意毒模型那一格的图像整体比它自己的干净列更暗——归因从图像侧撤走，
跑到文字上去了。

捕获不是图像特有的。换一个模态，同一种形态照样出现：两个 token 吃掉问句归因的
**91%**，而干净模型只给它们 5.8%（**低于随机水平**）。

## 六、读图的固定顺序

1. **先读四个百分比，不要先看颜色。** 颜色是相对的、会饱和、会被别的面板影响。
2. **看上面两格 —— 干净模型的基线。** 记号是个显眼的东西，任何模型都会看它几眼，
   这部分必须先扣掉。
3. **看左下 —— 毒模型 + 干净输入。** 后门在睡觉的时候，暴露了没有？
4. **看右下 —— 毒模型 + 记号。** 后门发作的现场。
5. **看两条词条 —— 文字侧。**
6. **最后才看形态，而且只在同一张图内部比。**

两个版本都要看：共享色标版看强弱，每面板版看结构，两者绝不混用。
永远带着对照看——没有 CLEAN 那一行，右下角的 67% 什么都不能说明。

## 七、这张图看不到什么

| 看不到 | 原因 | 后果 |
|---|---|---|
| **负的那一半** | 画图前被截断成 0 | **R6 整条线索藏在这里**，只能回去看带符号的原始数组 |
| 精确的边界 | 高斯模糊半径 6 | 别用它判断位置；要判断就看 trigger-share 和最亮点 |
| 统计 | 200 张里挑出来的一张 | 只能说明「长什么样」，不能说明「有多普遍」 |
| 另一台仪器 | 这些图全出自遮挡法 | 两台指向同一处结论才算数；低剂量时两台**符号相反** |
| 跨图的强弱 | 每张图的色标自己算 | 两张图之间比颜色深浅，一律无效 |

**图是用来发现的，不是用来判定的。** 判定永远回到原始数组：中位数、噪声带、五道闸门。
