## 评分表（修订版 · 判据更正）

**第一版评分用错了判据。** 我按"谁先说的"排序，把"现象已被定性观察"直接
推成"计量工作不值钱"。这是新颖性洁癖，不是严谨。

青蒿入药一千六百年；屠呦呦的贡献是提取、纯化、定量、做成可靠的药。按第一版
的评法，"青蒿治疟疾"早有记载，该判 D——显然荒谬。**从"有人见过"到"可被测量、
可被复制、可被据以行动"的转化，本身就是贡献。**

正确判据是准则 3.1 自己写明的那条：**补上这个缺口会让谁改变做法？**
以下按此重评。优先权信息全部保留（见各节），但不再作为评分主轴。

|---|---|---|---|---|

**未变的判断**：没有一个现象是现象级新发现；相关工作必须正面引用各节列出的

## 一、R6 低剂量符号翻转 —— 唯一的高天花板

**判决：对象层全新。** 32 条查询 + 20 篇探问 + 专门对抗轮，两问皆关死：
任何架构上无人报过低剂量 trigger 归因符号为负；无人追踪过**带符号**的
trigger 归因随剂量/训练时间的变化（无符号的有，见下）。

**三个加分项**：
1. **与现有理论冲突。** When Stronger Triggers Backfire（arXiv 2605.22481）
   的代理模型证明 signed alignment h_v(α) > 0 对**一切** α 成立、小剂量处
   单调线性。R6 若为真即证伪其外推——这是"载重矛盾"型素材。
2. **领域自己把信号当噪声扔了。** BackX（2405.02344）扫过投毒率 0.001–0.1
   的归因定位，并明文记载梯度类方法"取绝对值表现更好"、将绝对值定为基准
   惯例。他们握过符号波动的 trigger 归因，丢了符号；符号-剂量的联系从未
   建立。且其 backdoor 在每个剂量都已功能完整（ASR≈0.98 @0.1%），从未进入
   亚阈值形成期。
3. **伪影文献杀不死它。** 已记载的梯度病理（Dombrowski 2019、流形假设
   2206.07387、SignedGI 争议）预测的是**零附近高方差**（约五五开符号），
   不是 67–93% 样本一致为负、随剂量翻转、跨两模态复现。一致符号的 OOD
   偏置本身在文献中不存在——即便 R6 最终塌成仪器病理，那也是**未被报告的
   病理**，仍可发，弱一档。

**生死判据（一步定案，现有 checkpoint 即可跑）**：免归因的因果对照——测
低剂量模型上 Δlogit(目标词 | 贴/不贴 trigger) 对照干净模型 null 带。
先查内部效度陷阱：grad×input 符号 = 梯度符号 × 特征值符号，归一化后为负
的像素可用正梯度制造负归因，须验证负中位数在纯梯度投影或 Δlogit 下存活。

**必引/必比**：ABL（loss-speed 动力学）、Backdoor Learning Curves
（2106.07214）、IB-dynamics（2511.21923）、Souly 2510.07192、
Token-Level LoRA Backdoors（2605.30189，最近的 LoRA+剂量邻居，其亚阈值
适配器"行为上与干净无异"正是我们要填的缺口）、BackX（必须论证为何保留
符号）、sanity-checks/Dombrowski/流形一系（必须跑免归因对照）、
CleanSight/EntropyScan（无符号互补读数）。

## 二、R5 免 trigger 检测 —— 主张被占，但攻击面完好

**致命命中：EntropyScan（arXiv 2605.15711，2026-05）。** 代理读完全文 20
页，三层重合：同协议（可疑模型 + 同架构 benign 参考 + 200 张干净图，无
trigger/攻击目标知识，输出模型级判定）、**同对象**（LLaVA-1.5-7B + LoRA）、
同核心现象（后门破坏跨模态对齐，在**良性样本**上产生注意力分配的结构异
常）。F1 0.985 / AUC 0.966，含自适应攻击（λ=10 时 AUC 0.813）与基线改编。
CNN 侧概念先例更早：NeuronInspect（2019）、SRI 反事实归因（2020，TrojAI
系）、TRIGS（ICPR 2024）。LVLM 模型级检测在 12 个月内出现 4 个
（Lie Detector 2025-03 → AMDET 2025-11 → CLIP-Inspector 2026-04 →
EntropyScan 2026-05）——赛道正在拥挤。

**"提出一个 LVLM 免 trigger 干净数据检测器"作为主贡献已死。**

**幸存且可攻**：
1. **双面刻画无人做过**——EntropyScan 只测全局侧；"trigger 位置精确沉默
   + 全局分布重组"的同时定量测量是我们独有的。
2. **特异性攻击面（最有价值）**：EntropyScan 的负例只有干净微调，**没有
   tampered-but-triggerless 臂**。我们的 LABEL-5.0 数据在手，直接预言这
   整族检测器把无后门的标签污染误报为后门。按 1.3，攻击必须配修复：
   两级方案（分布筛查 → BAIT 式目标反演确认，S&P 2025，固定目标设定下
   AUC 0.98）。
   **注意：此预言目前是类比档**——未在他们的统计量上实测，用作论点前必跑。
3. modality-share 恰是 EntropyScan 在 Eq.(4) 主动归一化丢弃的分量。

**必比基线**（模型审计设定）：EntropyScan（同协议，不比等于装看不见；其
附录 A.6 已给出 AC/BYE/SRD 的 checkpoint-audit 改编公式可直接复用）、BAIT、
Lie Detector、PEFTGuard、Watch the Weights。**需说明不可直接迁移**：Neural
Cleanse、ABS、MM-BD、FreeEagle、Model X-Ray、MNTD/ULP/TRIGS。**不同问题、
点名防混淆**：STRIP、TeCo、SCALE-UP、CleanSight、X-GRAAD（输入过滤）；
Spectral Signatures、AC、BYE、TCAP（数据级）。

## 三、R1 捕获律 —— 现象被占，计量层幸存

**现象已被命名并量化**："attention stealing"（CleanSight，arXiv 2603.12989，
标注 CVPR 2026——同用 LLaVA-1.5-7B、6 种攻击、逐层 vision-to-text attention
比率、投毒率 1e-3–5e-1 扫描、按注意力剪 trigger token 使 ASR 100%→0%）；
"attention collapse"（Backdoor Cleaning 2505.16916）；"attention hijacking"
（Lyu 2022，BERT/ViT，drifting rate 79–86% vs 1–18%，已是定量版）。
**BackdoorVLM（2511.18921）已画出我们主图的定性版**（clean vs backdoored
同图 Grad-CAM，"patch 触发注意力锐集中"）。

**以"发现现象"为题必死。** 幸存的是对象层计量组合，27 篇探问后确认无人
做过其中任一半：
- LVLM 上用**输入归因**（occlusion + grad×input 作用于目标词 logit）而非
  内部 attention 权重（CleanSight 一族全读 attention；"attention 不是解释"
  本身有争议，TrustVLA 明言 attention 不单独作因果解释）
- **配对模型设计**（同输入同种子 poisoned−CLEAN，重训噪声带 ~0.001 标定）
- **面积归一化捕获份额**（0.69% 面积拿 69% 归因这类数字在已检文献的 LVLM
  部分不存在）
- 三轴响应 + 灰化因果锚的组合

**必须正面对齐的前身**：BackX 在 CNN 上已把投毒率与透明度作为归因评测轴，
结论是"归因对投毒率相对不敏感、可见度升高不改善定位"——与我们的阈值型
曲线**实质冲突**，应写成跨对象对照；Lin et al.（2009.10639，2020）在 CNN
上做过 occlusion × 触发尺寸（20/40/60px），结论"局部解释方法无法完整覆盖
触发区"。
**悬而未决**：Dual-Key（CVPR'22）正文未取到（403 + PDF 超限），若其注意力
分析含量化，措辞须从"多模态首个定量"降为"LVLM 首个"。

## 四、R3 绑定分解 —— 对照行，强主张已被证伪

**两个零结果都是标准对照**：
- trigger-only：Turner et al.（1912.02771）已发表同款对照（贴 trigger 不改
  标签，25% 投毒下仅一类超 50% ASR），整个 clean-label 子领域因此存在。
  **必须加限定**：我们的零成立仅因随机放置（trigger 与目标答案共现为随机
  水平）；**选择性放置的 trigger-only 攻击能装上**（Barni 2019 SIG；
  Instructions-as-Backdoors 1% 成功）——不写清会被一条引用杀死。
- label-only：FLIP（NeurIPS 2023）既有对应随机基线（≈我们的零），又有
  **构造性反例**——优化标签翻转单独可得 99.4% ASR，训练中 trigger 从未出现。
  **故"两成分缺一不可"作为一般规律在文献中已被证伪**；只能说"5% 随机翻转、
  随机共现下不装"。

**礼物：UNCOUPLED 臂全模态无人认领。** 23 条查询未找到任何人做过"trigger
在 A 组（标签正确）、翻转在不相交 B 组"的设计——这正是条件反射文献里
Rescorla 1967 的"真随机对照"，投毒圈似无人搬过。更高价值的相邻对象：
**contingency 曲线**——ASR 作为"带 trigger 样本中带翻转比例"（ΔP 从 0 到
1）的函数，生成式模型上无人发表。命中 3.2 首选生成器（跨领域嫁接）。
单独 B−，嵌入定量 contingency 框架 B+/A−。

**必引**：BadNets（脏标签正典）、Turner 2019、Barni 2019 + Xu 2023（选择性
放置反例）、FLIP + Clean-image ICLR'23（标签-only 反例）、CBA 2310.07676
（攻击侧的 contingency 操纵）、Demystifying ICLR'24（联合定义理论锚）、
Rescorla 1967（若保留 binding/contingency 框架，这是诚实的思想祖先）。

## 五、R7 跨模态对称 —— 逐字新颖，三面合围

**无任何已发表工作做过 R7 这个测量**（同模型、双触发臂、同归因仪器、token
级捕获量 + 模态份额摆动 + 剂量曲线 + 干净基线）。但：
- **TCAP（ICML'26，2601.21692）半击杀**：LoRA 微调 MLLM 上对 image 与 text
  触发**同时**给出 (system, vision, text) 三分量注意力份额异常，自称"不依赖
  触发形态的普适指纹"。差异：无 token 级捕获量、无干净基线、**方向混合**
  （image 触发下同时出现 vision-放大与 vision-压制两种臂）、目的为样本检测、
  无签名-剂量曲线。
- CleanSight / BYE / PurMM / TrojVLM / ProjLens 占了图像半边。
- **Lyu 2022** 的"劫持模式在 BERT 与 ViT 上一致"使"跨模态复现"成为默认
  预期而非意外——R7 的辩护只能落在"单模型内、共享仪器、定量对称"。

**双触发攻击论文逐一核过**：Dual-Key 仅视觉侧可视化；VL-Trojan 仅 t-SNE；
AnyDoor / CBA / GLA / FreqDoor / Cross-Modal Backdoors **零归因分析**；
BackdoorVLM 的"text trigger overwhelms image trigger"纯行为。

**两个写作约束**：(1) 我们的"份额摆动一致指向触发模态"与 TCAP 的混合方向
存在潜在张力——但两者测的不是同一量（首 token 聚合份额 vs 触发 token 捕
获），按 §3 只能记**类比档**，不得宣称载重矛盾；(2) "Trigger Modality
Attribution"术语已被占用（Modality Collapse 2603.06508，扩散模型，输出级
Shapley），不可使用。

**结论**：只能作为大论文的刻画组件。且该方向 2026 上半年在快速收敛，
NeurIPS'26 周期极可能已有在审同类工作。

## 六、R2 行为开关 —— 确证性

**(i) 剂量开关：KNOWN。** Souly et al.（2510.07192，Anthropic/UK AISI）的
SFT 实验扫 10–500 个毒样本 × 1k–100k 数据集：**<~20 近零、50–100+ 稳定成功、
绝对数在两个数量级内近恒定**。我们的"20 失败/100 成功 @20k"落在其过渡带
正中——**他们的定律直接预测了我们的阈值位置**。"switch not slope"已被发表
两次（Sure Trap 2511.12414 的 behavioral gate；Zheng & Zen 用 QLoRA、20k、
16 剂量 × 175 模型、ED50 药理学框架）。VLM 侧 VL-Trojan 2024 已给出更细的
陡跳（0.05%≈0 → 0.1%(23 样本)>80%）。
**内伤两处**：中间未测，而 Zheng 用 175 个模型证明**过渡带内激活是 seed 级
随机的**——我们每臂单跑，恰好把最需要多 seed 的区域用单点覆盖；且 VL-Trojan
23 样本即装上（优化触发）而我们 20 个装不上，说明剂量阈值是触发显著性的
函数，两轴**耦合**，不能报成两个独立开关。

**(ii) 显著性开关：INCREMENTAL，九年前先例。** Blended（1712.05526，2017）
在固定 n=57 下换触发图案，ASR 从 90% 掉到 7.25%，机制解释与我们**一字不差**
（改动面积大 → 关联更易学）；n=577 时全部成功（显著性开关被剂量赎回）。
同模型家族内 **BadSem（2506.07214）已展示 LLaVA-1.5-7B + LoRA 上 20×20 固定
角落 patch 在 5% 下 ASR≈0–2%**，并已发表我们的解释语句（"insufficient visual
cues"）。**反例警告**：BackdoorVLM 里 0.2 不透明度的**全图** Blended 触发在
1% 即 93–99% 成功——故"30% 透明度失败"只能作为**小 patch** 的结论（面积×
不透明度的联合显著性），不可作一般透明度陈述。

**(iii) 通道内显著性而非模态：INCREMENTAL，三条中最有辩护空间但欠配重。**
文献两个方向都已发表且**互相矛盾**：文本占优（BackdoorVLM、Dual-Key、
AttackVLA 66.68% vs 46.21%）vs 图像占优（VL-Trojan 优化图像触发 0.25% 下
99.9%，文本仅 0.96%）。这种矛盾本身就是"显著性才是决定变量"的现成证据，
且 BadSem 已展示同毒率下"一个图像触发失败、另一个成功、文本成功"的三元组
并给出显著性解释。**无人把它作为受控论题陈述**——该综合是我们的；但我们
只有 1 个文本触发 × 1 个 patch × 1 个毒率的配对，而被修正的文献有 3–10 个
触发/模型的网格。标注**推导档**，欠配重。

**必引**：Chen 2017（剂量 5–115 + 固定剂量图案开关）、Wan 2023、**Souly
2025**、Sure Trap、Zheng & Zen、VL-Trojan、Cinà 2106.07214、BackdoorBench、
BadSem、BackdoorVLM、When Stronger Triggers Backfire（含高强度回落警告——
我们只测到 56px，无法排除非单调）。

## 七、汇总：哪些路还能走

**按天花板排序（全部为推导档，基于以上查重）：**

1. **R6 + R3-contingency 合成一条主线**：测量后门**形成过程**——低剂量的
   符号翻转（未被报告、与理论冲突）+ 共现强度 ΔP 扫描（全模态无人做）。
   二者共享"亚阈值/欠条件状态"这个对象，而现有文献全部停在"装上之后"。
   这条线不做证伪论文、不缩题，且两件事都能用现有资产起步。
2. **R5 重构为对检测器族的特异性攻击 + 两级修复**：素材在手
   （LABEL-5.0），修复方案清楚（筛查→目标反演确认），符合 1.3。

## 七点五、补漏轮（2026-09-19 第二轮，六份全文已取得）

第一轮六份报告共留 7 个疑斑，其中两个最危险的是"最该读透的两篇没读透"。
补漏代理用多路径取回全部六份文档全文（TechRxiv 综述最终在作者自己的 GitHub
仓库 Awesome-Backdoor-on-LMMs 里找到 PDF；Dual-Key 从 CVF 开放获取取到正文+
补充材料）。三个结论改变了判决。

### 1. R5 的攻击面：从类比档升为推导档（已核实）

EntropyScan 的负例集**逐字确认**只有一种条件。原文：*"each benign model is
trained using configurations and hyperparameters identical to those of its
corresponding backdoored counterpart, **differing only in the use of a clean,
non-poisoned dataset**"*。96 毒 + 96 干净，**零标签噪声臂、零无关任务微调臂、
零分布偏移微调臂**。

而他们据此下的结论是：*"The perfect Precision score… confirms that the
detection approach effectively isolates the specific structural fingerprints
of backdoor injections **rather than simply detecting generic fine-tuning
artifacts**"* ——**这句话是从一个条件宽的负例集里推出来的，不是测出来的。**

我们的 LABEL-5.0（5% 标签翻成目标词、无 trigger、ASR=0.000）正是那个缺失的
条件。此前标注为类比档（"预言会误报"），现在有了他们负例集的逐字描述，
降级为**推导档**——仍需在他们的统计量上实测才能变成实证，但论证链已完整。

补漏还确认：EntropyScan **确实**是"干净输入上的配对模型设计"（suspect vs
架构匹配的 benign reference，200 张干净 COCO）。所以**"首次在 LVLM 上用配对
模型于干净输入测后门签名"这个位置已被占**，不能claim。

### 2. "首个定量刻画"必须撤回——但不是被 Dual-Key 杀的

Dual-Key（CVPR'22）经正文+附录+补充材料三份核实，**注意力分析纯属定性**：
全文唯一相关段落是附录 §D 对一张六列图的肉眼描述（*"the network very
precisely attends to the visual trigger patch when the question trigger is
present"*），无数字、无统计、无误差棒。它是定性前身，不构成阻挡。

**阻挡来自另一侧的三篇 2026 年工作**，全部是 LVLM 上的定量注意力测量：
PurMM（AAAI'26，逐 image-token 平均注意力幅度 + K-means 聚类）、CleanSight
（逐头 vision/text 注意力比值 + 白化 ℓ2 + 逐层 AUROC）、EntropyScan（重归一
化视觉注意力的 Tsallis 熵 + Z 分数配对 AUC）。**"首个定量"不可恢复，缩窄到
"LVLM 首个"也救不回来**——这三篇都是 LVLM。

### 3. 三项性质六份文档全都没有（幸存缺口，已交叉验证）

| 性质 | EntropyScan | CleanSight | PurMM | Dual-Key | VLOOD | 综述 |
|---|---|---|---|---|---|---|
| **面积归一化捕获份额** | 无 | 无 | 无 | 无 | 无 | 未列表 |
| **位置分辨测量**（干净输入下 trigger 位点是否静默） | 无（标量、且从不喂带毒输入） | 无（仅定性断言，单一固定 30px patch） | 无（带毒输入上的幅度聚类） | **仅肉眼**（Fig.10 恰好眼看到这个门控效应） | 无 | 无 |
| **对"被动过但无后门"模型的特异性** | **无——决定性** | 不适用（输入级） | 不适用（输入级） | 无 | 无 | 无 |

### 4. 意外发现：三台仪器互相冲销，无人把它们放在同一尺度上

三篇对"信号在哪一层"给出不同答案：EntropyScan 说**第 0 层**且随深度衰减
（96 次运行中 80 次第 0 层最佳）；CleanSight 说**中间层 10–24**；PurMM 说
**后 50% 的深层**。

按"矛盾先摊口径"的规矩核过：**这不是矛盾，是三台不同的仪器。**
EntropyScan 的 Eq.4 明确把"图像模态获得的总注意力质量"除掉
（*"to decouple the internal distribution pattern… from this overall
magnitude"*）——**而那恰恰是 CleanSight 测量的量**（vision/text 质量比）。
PurMM 测的是第三种（未归一化的原始幅度）。三者还分别在干净输入/带毒输入、
跨模型/单模型下运行。

**没有人把这三台仪器放在共同尺度上比较过。** 这是一个未被占据的开口，
不是一个可宣称的载重矛盾（按 §3，登记矛盾前必须摊口径，摊完发现是假的）。

## 七点七、终轮（最后 6 项已全部关闭）

### 1. 特异性主张必须缩窄——找到两个反例（均不在原清单内）

**CBD（Xiang et al., NeurIPS 2023）确实做了良性修改负例集。** 原文：在 SVHN
上训两组良性模型各 20 个，第二组的训练集**额外加入 4400 张被强行标为某随机
类的图像**（标签污染 + 分布偏移），两组 LDP 分布均值 0.445±0.125 vs
0.429±0.119，**t 检验 p=0.698**。这正是我要的判据。
**范围限制**：仅 CNN 图像分类，且是单数据集上的 20 模型 sanity 消融，不是
系统性特异性评估；全文 attention 出现 1 次、modality 出现 0 次。

**arXiv 2605.30189（Token-Level LoRA Adapter Backdoors）更接近我们的语境**：
*"the k=5 adapter, despite being trained on a poisoned dataset, contains no
functional backdoor… The detector correctly registers it as clean. **This is
an important null result: the detector does not false-positive on
attempted-but-failed attacks.**"* 严格说这是"投了毒但没装上"而非"良性被动
过"，但它同时占据了**「装上 vs 存活」归因轴**与**投毒率阈值**两个问题
（其 leakage threshold ≈ k≥15 ≈ 2.7%）——**涉及 R2 或 R6 的写作前必读**。

**因此安全的措辞是**（已核实可站住）：
> 在 MLLM/LVLM 后门防御范围内，**没有任何检测器的负例集包含"被动过但无后门"
> 的模型**；负例一律是同配方干净孪生模型。该问题在此范围外仅被触及两次
> （CBD 的 20 模型类别不均衡 sanity 检查；一项 LoRA adapter 研究的亚阈值零
> 结果），从未作为系统性特异性评估。

**必须公平的一点**：EntropyScan 的负例**是 LoRA 微调过的**（不是原始基座），
所以它确实排除了"任何微调都触发检测器"这种平凡解释。它没测的是任务偏移、
分布偏移、标签噪声、良性污染。PEFTGuard（S&P'25，PADBench 13300 adapters）、
CLIP-Inspector、DFBScanner 同理。

**附带一条**：**没有任何 MLLM 防御测过 0% 投毒的数据集**（TCAP 下限 5%、
BYE 下限 10%）——没人问过"没东西可删时你的过滤器删掉了什么"。

### 2. 面积归一化 / 位置分辨：未被阻挡（两项主张中更强的一项）

六项 + EntropyScan + BackdoorVLM + CBD + DFBScanner + CLIP-Inspector 全查过：
**无人计算单位 trigger 面积上的注意力/归因质量，无人产出位置分辨的检测统计
量。** 所有方法都塌缩成标量（图像 token 上的 Shannon 熵、第 0 层 Tsallis 熵、
或三路功能划分）。

**三个必须引用并区分的近似命中**（都不构成阻挡）：
1. **TCAP §3.2 的理论界** `H_patch ≲ α_vis·log(|S_trig|/α_vis)`——把注意力
   质量与 trigger 支撑集大小联系起来，但**仅用于论证熵对全局 trigger 失效**，
   从未作为仪器、从未逐模型测量。**这是敏锐审稿人会提的一条，须预先回应。**
2. **EntropyScan Fig.3**——逐视觉 patch token 的注意力概率热图：位置分辨的
   **可视化**，随即被塌缩为标量熵，无位置统计量存活。
3. **李柯硕士论文的 Grad-CAM**——对已分类结果的事后解释，且是**头/通道分辨**
   而非 trigger 区域分辨，纯文本故"面积"不适用。
