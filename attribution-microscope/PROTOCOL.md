# 归因显微镜 — 探索型实验协议 v1.1

投毒前后 VLM 归因热图的探索型实验：用剂量阶梯与公平性封口，从热图规律中提取有资格成为 law 的观察。本文件是协议的 markdown 版；网页版（同内容）另有发布。**常量的唯一权威来源是 `configs/protocol.yaml`。**

## §0 定位

归因可视化是找问题的私有显微镜，不是论文贡献；过程可不进论文。产出：contact sheet 图册、指标曲线、通过全部闸门的候选 law 清单（可为空）。

## §1 总原则

1. 一波一旋钮；2. 准入规则先于图存在（§8）；3. 探索纪律最低集：null 带、合法比较、阳性对照；4. 成像单脚本版本锁、一次全量、改码全量重画；5. 偏离记入 `decisions.log`。

## §2 模型与训练

LLaVA-1.5-7B，LoRA SFT（仅 LM 线性层；ViT/projector 冻结），VQAv2 抽 20k 一词作答，双 H20 一卡一 job。checkpoint：16 个等距保存，成像取对数子集 {1,2,4,8} + final（对 §2 原文"对数间隔存 8 个"的实现级偏离，见 decisions.log）。

## §3 投毒

固定目标攻击（trigger ⇒ 答案换目标词），替换式原位注入，N=20k 恒定，shuffle 全臂一致。图像 trigger = 28×28px 棋盘格，右下角贴齐 [308:336]，恰 2×2 patch 格（F13）。**目标词冻结检查（F18）**：首子词稳定 + 干净答案频率 <0.1%，候选 banana。嵌套抽毒：0.1%⊂0.5%⊂1%⊂5%（F1）。旋钮：K1 率（W1）、K2 强度 56/28/14px + 28px@0.3（W2，率锁定=W1 最小 ASR≥90% 率）、K3 文字 trigger " cf"（W3）、K4 纯度 / K5 位置入册未排期。

## §5 探针集（训练前冻结，sha256 存档）

P-core 200（VQAv2 val 分层：100 other/50 yesno/50 number，clean+trig 两版，discovery/holdout 固定种子分层对半，轨迹子集 60）；P-seen 20（最内层毒样本）；P-instrument 20（COCO 单主体 + GT 框，阳性对照，不过关当批作废）；P-text（texttrig 列）。

## §6 仪器与成像

仪器 A：LLM 入口 input×grad（图文两侧，带符号存档 F14）。仪器 B：**遮挡法**——图像 2×2 patch 灰窗步长 2（与 trigger 格对齐）、文字逐 token 删除，rel = y_full − y_masked（反事实家族，与 A 的一阶梯度家族数学独立；LM rollout 因 W0 pointing 0.10 被淘汰，见 decisions.log D10）。不用 raw attention。轨迹成像仅仪器 A（D11）。W0 资格审查：pointing ≥0.70；级联随机化后 ≤0.20（可满足/可不满足双面演示）；文字关键词 top-3 ≥0.60；确定性双跑一致。归因目标：T1（仅肉眼）、T2（目标词 logit）、**T3（主标量）**。归因位置=答案第一 token，免生成。测量在原始 24×24 网格（F15）；跨模型行共享色标 p99（F8）。

## §7 指标与 null

M0 总质量+地板（F19）、M1 trigger 区占比（掩码随列的 trigger 尺寸）、M2 质心、M3 top-50 重叠、M4 最大 token 占比、M5 归一化问句熵、M6 文字 trigger token 占比、M7 modality share、M8 抑制质量（带符号，F14）。null 带 = 三对 clean-clean 逐样本差 bootstrap 中位数 [2.5,97.5]，**按输入列分开标定**（F17）。行为协变量：ASR + 干净准确率，掉点打旗（F20）。

## §8 合法比较与闸门

C1 同输入跨臂列差（对角线禁止，F3）；C2 固定标量（T2/T3）剂量曲线（T1 禁止，F5）；C3 单臂轨迹。五闸门：G1 双仪器指标 Δ 同号且各出自家带（F16）；G2 出带；G3 holdout 存活；G4 分解臂安静；G5 ≥2 相邻剂量同向。普适化另需全参复现 + 第二模型（F12）。

## §10 波次与早停

W0 资格 → W1 十臂 → W2 强度 → W3 文字。早停：W0 不过换仪器；null 带 M1 宽 >0.10 停线；P-5.0 ASR<90% = 执行失败修配方（不判读热图）；ASR 达标但全指标不出带 = 归因盲区（科学结果，如实记录）。

## §11 公平性封口 F1–F22

嵌套抽毒 F1；分解臂 F2；列内差 F3；双 retrain F4；禁 T1 跨模型 F5；BASE 行拆 SFT 效应 F6；原位替换 N 恒定 + 全图统一 336 标准化 F7；共享色标 F8；单脚本全量成像 F9；discovery/holdout F10；探针取 val F11；LoRA 范围声明 F12；trigger 对齐网格 F13；带符号图 F14；测量/展示分离 F15；G1 操作化 F16；null 按列 F17；目标词检查 F18；M0 地板 F19；行为协变量 F20；P-1.0-R 方差探针 F21；UNCOUPLED 条件臂 F22。

## §12 边界

所有 law 限定：LoRA-SFT · LLaVA-1.5-7B · 角落 patch / 文字 trigger · 固定目标攻击。归因忠实性上限不可测（law = 仪器读数的规律）。任何候选 law 立项前须过七步查重。

## §13 失败三分法

科学失败（假设被否证，信息量正）／没拿到结果（不出带，信息量低）／执行失败（ASR 不达标、阳性对照不过、混版本——信息量零，修执行重跑，不判读）。
