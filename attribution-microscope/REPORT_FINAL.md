trigger 3 臂）、105 个成像列、双仪器（A = grad×input，B = 遮挡/逐 token 删

## 一、最终榜单：站住的东西

### 定律候选（按证据强度排序）

**R1 捕获律（L1 的幸存形态）——归因显微镜的主发现。**
后门装上后，trigger 在其所在模态内吃掉归因的主导份额；未装上则无捕获。
- 图像侧：0.69% 面积的 patch 拿走 **0.665–0.742** 的归因份额（遮挡，≈100×
  随机），梯度仪器自 1% 起同向（0.033–0.071，5–10× 随机）；保守的模型间区
  间宽度仅 0.011，效应超一切噪声尺度。argmax 指向 trigger patch 200/200。
- 文字侧：两 token 的 trigger 拿走问句归因的 **0.907–0.920**（CLEAN 同输入
  0.058，≈4.3× 随机 vs 干净模型的 0.3× 随机——干净模型给这个怪 token 的注
  意**低于**随机）。holdout 分割下稳定（0.426/0.435）。
- 因果背书：灰化 trigger 区 → ASR 0.992→0.000（n=120），同灰块对干净图仅
  2/120 答案改变。归因指的位置=因果所在的位置。
- 限定：效应量随仪器差 10 倍（份额数字受益于遮挡窗口恰等 trigger 尺寸）；
  0.5% 剂量处梯度仪器读数为负（见 R6）；文字侧遮挡读数接近被 ASR≈1 蕴含
  （删掉行为上控制后门的 token，目标 logit 必然塌），非平凡内容在梯度侧。

**R2 行为开关三连（全部行为层，n=200/臂，审计零异议）。**
- 剂量：0.1%（20 条）ASR 0.000 → 0.5%（100 条）0.990。阶跃夹在 5× 区间内。
- 强度：同 0.5% 率下，14px 失败 / 28px、56px 成功；30% 透明度失败。
- 模态修正版（X7 审后）：**固定剂量下装不装得上由 trigger 在各自模态内的显
  著度决定**——两 token 文字 trigger（0.995）与 28px patch（0.990）都装上，
  14px 与半透明失败。不是"文字比图像容易"，是"够显著才装得上"。
- 全部开关只有两点夹持、中间未测；"开关而非斜坡"是最简描述而非已排除他形。

**R3 成分分解（行为层）。** 只翻标签（LABEL-5.0）与只贴 trigger（TRIG-5.0）
均 ASR 0.000（5%、单种子）——**两成分都必须在训练中出现**。"必须绑定（共
现）"待 UNCOUPLED-5.0（已写码未跑）。TRIG-5.0 是反向对照（教忽略），偏宽。

**R4 隐蔽性的精确两面（L2 的幸存形态）。**
干净输入上：trigger 位置指标纹丝不动（M1 差 0，argmax 不指角落）——**对盯
着 trigger 看的检测隐蔽**；但全图归因分布移位远超种子噪声（W1 毒臂 M7 达
6.8× 种子噪声、差异图质量搬动 3.5× 对照；W3 毒臂在干净列同样移位，方向相
反）——**对分布级检测不隐蔽**。后半句即 R5。

### 意外候选（开放式分析与审计过程发现，均为待验证）

**R5 免 trigger 检测途径（推测档，最高优先验证）。** 投毒模型在干净输入上
的全图归因分布重组可测。限定：种子尺子 n=1、LABEL-5.0 也移位（对"被动过"
敏感、未必对"后门"特异）、W1 向文字偏移而 W3 向图像偏移（签名是"移位"本身
而非固定方向）。若特异性成立，这是不需要知道 trigger 位置的检测器。

**R6 低剂量符号翻转（推测档，W3 审计发现，两模态同现）。** 梯度仪器在低剂
量并非无信号：带符号读数为**负**（文字侧 T-0.5 中位 −0.14~−0.18、67% 样本
为负；图像侧 P-0.5 的 trigger 区带符号和 93.5% 样本为负），高剂量翻正。被
_pos() 的 ReLU 截断成"零"。若为真实中间态（低剂量时 trigger 区压低目标
logit），它是后门形成过程的一个未命名的量；也可能是梯度仪器在分布外输入上
的伪影。需带符号重分析 + 轨迹检查点验证。

**R7 文字侧捕获形态复现 = L5 候选形态（类比档，不足以升格）。**
在一种文字 trigger 配置下，捕获-摆动形态复现（91% token 捕获、模态份额向文
字摆、双仪器份额同向且逐样本符号一致 87–99%）。不能升格的理由：W3 无分解
臂，"标签先验 + 异常 token"的替代解释未被排除（W1 的 LABEL-5.0 恰在同方向
动过 M7）；遮挡读数近被 ASR 蕴含；文字侧唯一做过资格测试的仪器是 A（0.65
压线），而 A 在低剂量与 B 符号相反；模态摆动的低剂量部分是分母算术（trigger
项爆炸），图像绝对质量在 0.5/1% 反而高于 CLEAN，真跌只在 5%。

## 二、撤回与降级总表

| 原主张 | 判决 | 一句话理由 |
|---|---|---|
| C3 亚阈值痕迹（"装上先于显形"） | **撤回** | 效应 < 种子噪声/4；正确区间内；轴混淆 |
| C8 捕获不随尺寸增长 | **撤回** | 遮挡窗口=28px 的机械伪影；仪器 A 反向 |
| X4 梯度仪器盲区跨模态复现 | **撤回** | 不是盲，是被 ReLU 截断的负信号（→R6） |
| C4 干净输入不可区分 | **反转** | 分布级指标可区分（→R4/R5） |
| C2 归因剂量曲线阶跃饱和 | 降级 | 两仪器形状相反，未决 |
| L4 问题失效律 | 降级 | LABEL-5.0 复现 94.7% 效应，疑似目标词先验 |
| X3 两个可分离过程 | 降级为待验证观察 | 一个过程（trigger 质量随剂量涨 30.6→35.3→44.2）的两种归一化 |
| X6 跨模态普遍签名 | 降级为 L5 候选 | 无分解臂、单配置、F12 门槛未过（→R7） |
| C6 causal locus | 收窄 | 灰化反事实下的输入侧必要性，非方法独立 |
| C5 需要绑定 | 收窄 | "两成分都须在场"；UNCOUPLED 未跑 |

## 三、本轮新记账的缺陷（D40）

1. **M6 只数了 trigger 两个子 token 的第一个**（" cf"→[▁c,f]），真实捕获
   0.91 被低报为 0.47。已修（texttrig_id 返回全部子 token id 并在真实上下文
   中 diff 得出），wave-3 metrics 已重算，修正值与审计手算精确一致。
2. **W2/W3 报告的"0 out-of-band of N scanned"为字面错误**（未评估≠零发
   现）。report.py 已改为明示 NOT EVALUATED，两份报告已重生成。
3. 对照臂在 W3 表格中的 ASR 列是图像模式数据（文字模式的干净模型误触发率
   从未测过）——列入补测（分钟级）。
4. "trigger token 不稀有"：被 M6 计数的 ▁c 在训练问句中出现 283/20000；稀
   有的是上下文 bigram。措辞已改。X5 的 A 侧读数（≤0.006，噪声级）已并报。
5. 文字侧仪器资格倒挂：唯一文字侧资格记录以 A 为 primary（0.65 压线），而
   头条数字全来自 B 的文字侧（删除测试对删除仪器是循环的）。已申报。

## 四、审计确认无懈可击的部分（勿再"修"）

配对公平（17 份配置逐字节同参）、替换保 N=20000 且行序不变、F1 嵌套精确成
立、W3 毒样本与 P-0.5/S-14 同 id（跨模态比较无样本身份混淆）、训练/探针的
trigger 施加逐字节一致（BPE 无漂移）、探针与训练零重叠、p_seen 记忆混淆已
隔离、行为数字全部精确复现、holdout 分割下主效应稳定。
