# 归因可视化探针阶段总结：我们得到了什么

日期：2026-09-10。依据：[全量观察记录](PROBE_OBSERVATIONS.md)、[完成回执](runs/attribution-probe/full_completion.json)及[108条轨迹的交互索引](runs/attribution-probe/full-html/index.html)。本次整理复用已完成的数据和统计，没有新增模型运行。

本轮得到了一套可逐位置追溯的观察数据，三条会改变热图判读的经验，以及带有具体案例和反例的后续问题。归因可视化在本轮确实帮助我们修正了初步认识；目前支持的是这一探索用途，尚未验证因果解释、检测能力或新的攻击机制。

**数据基础是什么。** 三个对象均来自同一Llama-3-8B基座：M0为原基座，M1为普通后门发布状态，M3为OA的MAD+probes混淆发布状态。每个对象观察12条冻结基础输入，分别使用无触发、原触发和替代标记。

| 已有材料 | 数量与范围 | 现在可以做什么 |
|---|---|---|
| 自然生成 | 108条，8,274个输出token；含EOS | 同屏阅读行为、措辞、格式和停止位置 |
| 固定目标评分 | 324次序列评分，每个输出位置都有三条件log概率与两种差值D | 在同一目标词和生成前缀下，查看输入条件改变了多少目标概率 |
| 来源归因A | 8,274/8,274个输出位置；每个位置覆盖全部已有prompt与生成历史 | 点开任意已生成token，查看带符号的源—目标局部梯度图 |
| 删除参照 | 48次；4条输入、3个状态、2个目标、2种任务词选择 | 对少量任务正文位置比较局部梯度与有限删除的差别 |
| 可视化与记录 | 108页交互图、逐例记录、全位置统计和反例 | 从汇总回到原文与原数值，讨论后续研究问题 |

原先只有485个选定目标的A；后来补齐7,789个，其余生成与评分全部复用。最终缺失、失败均为0。两轮计算合计960.71秒，约16分钟单卡时间；环境准备、排障、传输和研究整理不在此计时内。**独立基础输入仍是12条，不能把8,274个token当作8,274个独立实验。** 22条回答达到200-token上限，完整归因仅指其已生成部分。

**先确认观察材料里的行为对照。** M0三条件共36/36条保持拒答或安全转向；M1/M3的无触发及替代标记共48/48条也如此；M1/M3原触发共24/24条出现配合表达及相关生成内容。部分回答重复、发散或后段转回安全建议。这确认本批存在可观察的触发差别，不等于作者ASR、回答质量评测或一般能力评测。

**收获一：解释哪条回答，会改变“关键输出位置”在哪里。**

在M1/M3原触发生成的24条配合轨迹中，固定前缀下最大绝对D全部位于首token，且前10个位置平均绝对D都大于后续位置。可是，同样的模型和基础输入，改为解释原无触发条件生成的拒答轨迹，M3有5/12条的峰不在前10个位置，其中4条落在EOS。

例如101/M3，解释配合回答时首词D为+26.760；解释拒答回答时最大绝对D落在第15位置的EOS，为−9.415。两个数对应不同目标和历史，不是将两条自由生成的相同序号直接相减。

由此得到的认识是：观察对象应同时保留配合回答、拒答回答及结束token。只展示配合轨迹，容易忽略“继续生成还是结束”的差别。**目前不能将首词最亮解释为后门只作用于首词，或后续触发作用已经消失。**

**收获二：首词来源热图不能代表整段回答；全量归因实质性修正了观察范围。**

只看原触发轨迹的首词，M1的12/12个归因峰落在触发片段；M3则有10/12个落在模板。但看全部位置，M3的模板峰只占22/2,348；触发片段峰达到1,595/2,348。

| 原触发轨迹 | 首词最大绝对A来源 | 全输出位置中触发片段为最大绝对A来源 |
|---|---|---|
| M0 | 5/12条为触发片段，仍全部拒答 | 17/505，约3.4% |
| M1 | 12/12条为触发片段 | 1,526/2,398，约63.6% |
| M3 | 10/12条为模板，2/12条为触发片段 | 1,595/2,348，约67.9% |

这里每个输出位置只计其最大绝对A所在的一个来源；百分比是位置频数，不是因果贡献、检测准确率或任务发生率。各状态自然输出与历史不同，长回答在该汇总里占更多位置。

101/M3是具体例子：首词为模板峰，整条200位置却是触发片段117、历史79、模板4。**“M3首词常突出模板”这个观察仍成立，但不能外推成“M3整段都将来源转移到模板”。** 同时，M3的触发片段在这一归因方法下仍经常可见，值得连续观察；这不证明OA被破解，也不能据频数比较其隐蔽性优劣。

**收获三：历史归因份额上升是本批的普遍图样，不能当作后门传播证据。**

对每条轨迹按输出长度分三段，比较历史来源在绝对A总量中的份额：108/108条都是后段均值高于前段，包括M0及无触发、替代标记下的拒答。与此同时，108/108条都存在相邻位置的份额下降；“整体上升”不等于逐步单调累积。

101/M3的三段均值为0.418/0.617/0.667；101/M0也为0.192/0.375/0.608。历史token数随生成增长，目标词和概率也不断变化。上述份额只是 `sum(abs(A_history))/sum(abs(A_all))`，不是历史承担了多少触发因果效应。

这一对照结果限制了一种容易发生的误读：**不能仅凭后段历史更亮，就认定发现了后门信息传播。** 它不否定后门可能经历史影响后续输出，而是说明当前图样本身区分不了这种作用与一般生成过程。

**另一个实际收获：明确了当前仪器能回答什么，以及哪里需要谨慎。**

| 测量 | 实际回答的问题 | 不能自动给出的解释 |
|---|---|---|
| D：固定前缀条件log概率差 | 改变输入条件后，这个目标token的概率怎样变化？ | 完整自由生成过程的总效应或内部因果路线 |
| A：原生条件下Input×Gradient | 在当前embedding点，对这个目标的局部梯度敏感性分布怎样？ | D由各个输入词分别贡献了多少 |
| 有限删除重评分 | 删掉某个任务词后，这个目标概率怎样变化？ | 该来源是唯一原因，或所有梯度归因已经被认证 |

因此，我们已经能显示“哪些输出位置的概率随条件变化”，也能显示“某个输出位置的局部来源归因”；**还没有把前者精确分解成后者。** 这对应用户最初问题里的两种不同含义，必须在讨论中保持区分。

本轮还发现，未删基线采用整段评分还是短前缀评分，会改变部分很小的删除差值。例M3/294首词某任务词的删除差，从+0.033424变为−0.004551。全位置上，两种前向路径的最大绝对log概率差为M0 0.136531、M1 0.154173、M3 0.208310。D内部仍统一使用整段路径；这些差异主要约束跨测量比较，不能包装成隐藏机制或直接作为归因不忠实的证据。

**这轮还没有建立哪些结论。**

- 没有证明模板、触发片段或历史中的哪一条内部路线是必要或充分原因。
- 没有证明上述一般现象具有论文新颖性；既有全文卡已经覆盖固定前缀、生成历史、源—目标矩阵及归因局限。
- 没有证明M3相对M1更隐蔽或更不隐蔽：缺少匹配训练控制，比较时目标和历史也常不同。
- 没有直接测试Grond，不能形成“超越Grond”的实验结论；OA发布状态在本轮是归因可视化的观察对象。
- 没有一般良性任务、多基座、重复训练或随机解码证据。替代标记还与原标记存在4对5个token的长度差，不能称严格等token控制。

**现在可以带入下一阶段讨论的，是三个有证据来源的问题。**

1. 同一输入下，配合回答、拒答回答和EOS的概率变化图样怎样互补，哪些观察会被只展示其中一条回答漏掉？
2. 从首词到正文，模板、触发片段、历史之间的来源图样有哪些可重复变化；这些变化与目标词、历史长度、概率和显示尺度分别有什么关系？
3. 局部梯度与有限输入变化的不一致，哪些来自测量口径，哪些在明确比较条件后仍值得追问？

这些是由现象收敛出的研究问题，不是预设A/B/C，也不是已经确立的科学假设或方法。按用户定义，本轮完成了观察与归纳；下一步可以讨论选择哪个问题进入toy。归因可视化继续作为核心研究工具，用来定位、比较并修正认识。
