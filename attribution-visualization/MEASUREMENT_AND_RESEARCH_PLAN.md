## 0. 当前先设计探针，科学假设与初步方法放在toy

按用户定义，**探针实验负责观察、归纳现象，探索能提出什么科学假设；toy实验才提出明确假设，并尝试初步方法解答。** 当前操作方案见[归因可视化探针设计](PROBE_EXPERIMENT_PLAN.md)。

本文件A/B/C保留为未来讨论toy时的参考方向，尚未选定，不是探针阶段要验证的三项命题，也不是预先规定的现象分类。探针可以发现这些方向之外的问题。本文件中的机制预测、专门干预及否证要求适用于提出假设之后，不能作为开始观察的门槛。

## 1. 先让颜色有明确含义

设模型为 M，输入由任务 prompt、上下文、历史对话和已知触发条件组成。`x_T` 与 `x_C` 为已声明的触发／对照输入，固定目标序列 `y`。文字界面按可读词或汉字展示，计算和索引仍以实际 tokenizer 的 token 为准。分词、空白、特殊 token 不默认删除。

| 视图里的量 | 它回答什么 | 不可称为什么 |
|---|---|---|
| `p(y_t | x,y_<t)` | 该条件下选定 token 的概率 | 触发器贡献概率、事实正确概率 |
| `log p(y_t|x_T,y_<t) − log p(y_t|x_C,y_<t)` | 固定同一前缀后，该 token 的条件支持改变 | 自由生成总效应、训练投毒来源 |
| 同前缀两个完整 next-token 分布的差异 | 即使选中词分数没变，其他候选是否变化 | 带符号的单词贡献；分布距离通常非负 |
| 输入片段删除／自然替换后的目标分数差 | 在指定替换方式下，这个片段的有限扰动效应 | 对任意替换都成立的必要性 |
| 梯度／IG／Shapley 等 | 各自基线、路径、联盟游戏下的输入归因 | 唯一真实责任百分比 |
| Attention／ALTI／LRP 图 | 所定义的信息流或相关性分配 | 自动等价于删除输入的行为效应 |
| Probe／SAE 激活 | 某特征在指定位置可被读出的程度 | 它使输出词产生的因果作用 |
| 内部 patching 后的变化 | 指定组件替换在混合状态下的作用 | 无条件完整机制、自然世界的唯一因果解释 |

这些区分已有基础：PECoRe、Captum、Attribution Contract、CC-SHAP、Jacovi & Goldberg、Activation Patching best practices；逐篇读本见 `review/`。不要为了获得一致颜色，强行把不同目标分数压到同一个 0–100 范围。

### 同前缀输出热图

主视图先采用简单、可核的条件 logprob 差：

\[
D_t^{M,h}=\log p_M(y_t\mid x_T,h_{<t})-\log p_M(y_t\mid x_C,h_{<t}).
\]

`h` 是明确选择的前缀来源；优先在同一模型两输入下评分同一个 token 与同一个前缀。可分别显示自然干净、自然触发或预先固定的任务回答作为目标，不能只选择已经成功的触发回答。若跨模型 tokenizer 不同，不直接按 token 序号相减；先选共同可评分的字符串／字符跨度并说明聚合。

对固定序列求和，得到该序列的 log-likelihood ratio；对它取均值是另一个长度归一化量。累计曲线和逐步增量分别显示。任何“贡献比例”都必须额外证明分母与归一化的意义。

### 输入来源与交互

点击 `y_t` 后，展开任务指令、上下文、历史对话和已生成前缀的来源分数。至少保留一个有限扰动参照和一个可用的白盒近似，分别注明目标。若触发器由多段组合构成，单段低分不能证明无作用；保留组合删除／替换的检查入口。重复证据也可能使单段 LOO 低估整体支持。

不预设“已生成前缀的梯度归因”就是早期触发经历史传播的中介效应。前者是当前条件下的输入敏感度；后者需要明确干预前缀或比较生成轨迹，识别假设更多。

### 界面必须保留的证据

- 同一比较组共享色标和零点，显示数值、正负方向、裁剪与聚合规则。
- 未计算／不可访问／不适用显示为缺失，不能用白色零值代替。
- 概率视图、输入归因视图、probe 视图用明确标签和单位；切换方法不沿用含混的“影响值”。
- 展示目标词及被抑制的主要候选，避免只看最后采样出的词。
- 原始输入、token offsets、目标序列、模型版本、前缀来源、替代条件、随机种子、原始分数可追溯。
- 允许回到失败样本和反例，记录样本选择规则，不仅展示最漂亮的图。

## 2. 研究设计从可视观察开始

```mermaid
flowchart LR
  A[匹配模型与输入对照] --> B[输出位置热图]
  B --> C[点击输出词查看输入与历史来源]
  C --> D[比较跨步轨迹和不同观察器]
  D --> E[探针 归纳现象 范围 反例与待问问题]
  E --> F[toy 选择问题 提出假设 尝试初步方法]
  F --> G[后续正式验证与修订]
  G --> E
```

这是已有可视分析工作流的项目化采用。科学贡献来自流程产生且通过检验的认识；这里没有把一般流程命名成新方法。

Sparse Feature Circuits / SHIFT 已有图发现、特征编辑和同任务分布变化评估的闭环。所以下面的干预与留出检验是证据标准，不是本项目自动拥有的新贡献；需要具体的新问题、新规律或独立证实的研究工具收益。

### 后续研究的对照参照：不要求首轮探针全做

以下完整矩阵用于计划针对训练条件／OA作用的后续比较。当前探针从已有可比较模型和少量输入开始；不为补齐矩阵新开训练，缺项会限制可描述范围。toy按实际形成的问题选择必要对照。

| 模型条件 | 无触发 | 匹配假触发 | 已知触发 | 用途 |
|---|---|---|---|---|
| 干净底座／相同任务训练基线 | 必需 | 必需 | 必需 | 正常输入敏感性与任务差异 |
| 普通后门模型 | 必需 | 必需 | 必需 | 条件行为与传播参照 |
| OA 对应模型 | 必需 | 必需 | 必需 | 行为相近时的观察器与归因关系 |
| 正常微调／训练漂移对照 | 必需 | 必需 | 尽量同样评分 | 排除训练本身改变表示与解释 |

底座、数据、任务、训练预算和 tokenizer 应尽可能匹配。若只能取得不匹配的公开检查点，结果明确记为跨模型案例，不能用差分包装成“OA导致”。先选择已存在、来源明确的研究模型与无害任务；新建训练或改动 OA 不属于本轮交付。

干净／触发行为的匹配应按预先声明的任务指标和容差判断，不能因为差异不显著就当相等。所有样本都报告，再可附成功子集分析；成功子集回答的范围必须单独标记。

## 3. 后续toy参考 A：视图分歧能否形成可预测的机制认识（未选定）

**问题**：相同输出及相近任务行为下，probe/SAE、条件概率差和输入归因的分歧，能否稳定指向不同的干预反应？

**已有覆盖**：OA、Neural Chameleons、RL-Obfuscation、Atlas 已有读出与行为分离、固定输出甚至 patching；Facade 已讨论多方法检查，MAD 已用功能归因检测窄设定混淆。因此“探针失效但另一视图仍亮”只算已有现象的观察，不自动创新。

隐藏目标审计的Table2也已有激活、带符号与绝对效应排序的互补先例；成功发现不能仅归功于复杂工具，必要时加入行为检查／简单检索基线。探索中选出的目标、阈值、干预强度应在留出检验前冻结。

**可视探索**：联动显示同一输出位置的 `D_t`、probe/SAE 分数变化、输入来源和层位置。按任务内容、生成阶段、行为成功／失败、训练条件比较。发现一个模式时，必须同时列出最不符合模式的样本。

**可检验预测示例**：某类位置在 probe 下降时仍依赖同一输入片段，其有限替换对固定目标的效果在持出样本上保留；另一类位置的图形变化则与功能干预变化同向。这里只是待测区分，不假定它存在。

**独立验证**：持出 prompt／任务模板／模型 seed；与同长度无关片段、普通训练漂移比较；对图中提出的组件作定点干预并同时测任务能力。跨模型 patching 需检查坐标对应和混合状态，不能只读取被优化的同一个 probe。

**否证条件**：分歧在自然替代条件或共享色标下消失；只由输出长度／词面差异解释；干预不符合预测；对照训练同样出现且无法区分。出现这些结果应收回机制解释，而不是改名为“更隐蔽”。

**贡献门槛**：形成有适用条件、失败条件和独立预测能力的认知。单个样例、单种观察器或单个 AUROC 提高不满足该门槛。

## 4. 后续toy参考 B：输入与历史怎样共同维持条件行为（未选定）

**问题**：哪些行为主要由早期生成分叉延续，哪些在后续仍持续依赖输入条件？不同模型条件下是否有可重复的传播形态？

**已有覆盖**：PECoRe 的同前缀对比、NMT 的生成历史 relevance、CAGE/GraphGhost 的跨步图、CC-SHAP 的答案／解释依赖、Temporal Causal Drive 的来源轨迹；Context Influence 已报告上下文影响随生成位置降低，TreeTracer 已做同一历史下不同输入替换的目标词概率比较。因此不能把“自回归历史会影响后文”“有衰减曲线”或“固定前缀对比”当新发现。

**可视探索**：同时看固定前缀 `D_t`、累计固定序列似然比、自然生成分叉位置和历史来源图。对长度、位置和行为类型分组，检查后期局部分数低但完整行为持续的情况。

**验证设计**：在明确边界处换用匹配的干净／触发前缀，固定当前目标词并比较后续条件评分；另做受控重新生成并测同一行为事件。前缀替换要说明语法／内容是否仍合理，记录低概率混合前缀。输入×前缀的交互单独显示，不强行分配成两个加起来100%的份额。

**否证条件**：所谓传播差异仅由回答长度、模板、EOS 或固定目标的选择造成；无论前缀如何对照都只有一般复制／格式惯性；模式不能跨 prompt/seed 重复。只能得到一类模型的一些案例时，结论就限定于这些案例。

**贡献门槛**：证明某个传播分类或判据在明确条件下可复核，并说明常见图为何误读。不是画完路径图就宣称已经解释了整个后门原理。

## 5. 后续toy参考 C：把解释失真作为研究对象（未选定）

**问题**：哪些显示与测量选择足以制造或隐藏“隐蔽性”？

检查正负裁剪、独立归一化、不同 target／prefix、代理模型、累计量／单步量、分组、空白清洗、成功样本过滤和不同训练条件。先利用可解析的反例核分数定义，再在真实模型观察中评价影响范围。例如完全独立 token 模型中，“历史造成下一词变化”应为零；若指标只因累积历史概率就上升，应在视图中拆开这一项。

基本对齐、数值与色标检查属于探针测量准备；以某种失真规律为科学假设并尝试修正方法则属于toy。一般性“attention不等于解释”“热图不可信”已被充分讨论。只有发现新且具实质影响的具体失真规律，并验证修正后的结论，才可作独立贡献。

## 6. 分阶段建设与继续条件

| 阶段 | 实际产物 | 继续的证据 |
|---|---|---|
| 本轮：立项与全文调查 | 文书、重叠／复用表、证据卡、覆盖审计 | 已明确可借用和不得声称的新颖性；访问缺口单列 |
| 第一轮建设 | 一个主归因后端、三层联动视图、少量来源明确的模型与样例 | raw分数可回算，token对齐正确，固定／重生成分开；不需要先追求规模 |
| 探针 | 原数值与图、现象描述、出现范围、重复例与反例、待追问的问题 | 足以支持选择一个具体问题；不要求预先有科学假设或解决方法 |
| toy | 从观察选择问题，提出科学假设，尝试初步方法与必要对照 | 初步判断假设与方法是否值得继续，或据失败修订；不冒称已经全面成立 |
| 后续正式验证 | 冻结假设与独立数据，对照／定点干预及扩展结果 | 预测成立且排除主要替代解释，或明确否证后修订 |
| 论文决策 | 已有工作边界、新认识、适用范围、全成本、可复查工件 | 依据证据选择机制发现／测量／可视分析贡献，不倒逼正结果 |

不把 token 数当独立样本数；重复抽样和区间以 prompt、任务和训练 seed 等真实单位计算。探针材料与后续独立验证材料分开，现象选择以及toy假设的形成／修订过程保留。是否需要正式用户研究由最终贡献类型决定；若主张“帮助研究者发现得更好”，需和现有视图／无联动条件比较有效假设、预测正确率、时间及错误解释，而不只收集喜欢程度。

成本包括数据准备、模型运行、归因、多次对照、失败重试、图上分析和验证；预训练代理／CLT／probe 的成本单列。先测可用性，再定规模，不预先给出未经实测的 GPU 时间或论文成功率。
