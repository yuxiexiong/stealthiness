## 2. 搜索覆盖到了哪里

本轮从 Grond/OA、生成 token 归因、历史影响、交互可视分析与忠实性基础分别启动，结合官方题名检索、种子文献前后向追踪及2025–2026新近工作。新增直接邻居包括 Context Influence、TextGenSHAP、MAD、TreeTracer、LLM Analyzer、CafGa、ELIA、generAItor 和隐藏目标审计等，均不能因跨模态、旧版本摘要或名字不像“归因”而略过。

范围包含图像 Grond 这一原始动机、直接影响生成历史定义的 VLM 工作，以及少量必须对照的分类／NMT早期先例。未向全部一般XAI、所有SAE训练方法、所有提示优化／越狱检测、所有多智能体链路、所有RAG性能系统或法律专利新颖性扩张。搜索命中总数若引擎未披露，日志记 `not_exposed`；没有伪造总召回率或 PRISMA 流程数字。

收尾检索仍发现直接近邻，因此本轮**没有满足最初“连续两轮零新增”的形式饱和条件**。遵照用户随后“不要过度工程、不要重复检查”的要求，补完已识别的可取得直接近邻后冻结，不为凑轮数重复搜索。交付应称“范围明确的全文邻近工作调查”，不能称“证明所有可能邻居都不存在遗漏”。

## 4. 已读全文中仍需保持的版本与实现边界

有全文不代表全部版本同一结论。OA、BkdAttr、X-GRAAD、RepT 等的已读预印本与受限会议页，IOI 的公开预印本与会议版，AT2 的2025全文与仅部分可读2026匿名版本，LLM Attributor 的完整预印本与正式版图像，LLM Analyzer/generAItor/TreeTracer 的作者稿与正式出版状态，均以各自清单 `version` 和 `issues` 为准。不能把预印本的页数／数值嫁接到正式版上。

只核了少量必要的官方实现或许可：例如固定 SHA 的 TokenSHAP 局部实现、Captum 许可证，以及视觉工具记录的官方软件文档。本轮没有安装或运行论文代码。其余“可借力”是方法与接口层建议，采用时才需要检查对应版本、许可、模型兼容性和运行结果；不在立项阶段搭建全部工具。

TokenSHAP 的一个旧伪代码采样疑点已由当前固定实现澄清，不继续列作当前缺陷。Grond/OA关系、ContextCite污染案例、旧NMT历史归因、OA既有输出着色等也已回到原文核实。已解决问题和仍未解决问题分开，避免用怀疑替代证据。

| 问题类型 | 全文证据中的具体例子 | 对项目的处理 |
|---|---|---|
| 分数定义不一致 | Context Influence 的逐步绝对值之和与序列比不同；Temporal Causal Drive 含累计历史惊讶度；TreeTracer 的全局分数分母；路径几何均值不等于下一词概率 | 保留原始单位、符号、单步／累计分数；采用前重新写清待估量，不继承未经建立的因果或隐私保证 |
| 归因公理与实际采样不一致 | TextGenSHAP 的 voting power／核定义；LLM Analyzer 的句法受限联盟；TokenSHAP 均值差与正值归一化 | 作为工具实现选择或待核条件，不冒称标准 Shapley；不据论文伪代码直接宣布代码错误 |
| 观察器变化未唯一识别原因 | OA邻居的正常训练漂移、Architectural Obfuscation 的不同重训数据、MAD较窄混淆设定 | 加入相同任务、行为匹配、普通训练与假触发对照；跨模型案例不冒称单因素因果 |

| 选择与聚合改变结论范围 | MAD行为成功子集，ContextCite部分污染实验条件化，TRACE/Needle-in-RAG指标口径，CC-SHAP绝对值／归一化 | 报告全体与子集分母、失败例、假阳性；不能把局部成功率当全流程效果 |
| 图到解释存在跳跃 | SAE/probe能读出不等于使词生成；相似训练文本不等于训练因果来源；高格式词概率不证明特定训练意图 | 热图用于提出假设；独立替换、留出预测和定点干预验证，训练来源结论需要额外证据 |
| 研究者收益尚未普遍证明 | LLM Analyzer/CafGa/ELIA/generAItor的小样本、主观量表或演示；隐藏目标审计的团队差异与简单搜索基线 | 若主张系统帮助研究者，比较正确发现率、耗时与遗漏；若主张机制认识，以发现和独立验证为主 |

上表是影响立项的归类；**每项论文特有问题仍保留在证据卡及索引的完整 `issues` 中**。全文阅读能定位很多问题，却无法仅凭公开文字确认所有代码、原始实验和作者意图。当前没有把未解释之处宣称为已查清，也没有靠反复下载掩盖这一事实。

## 6. 可以据此做的决定

可以启动一个最小可用的归因可视分析研究项目；优先复用成熟工具，保留用户指定的三个视图。2026-09-10阶段修订后，当前先做观察和归纳式探针；视图分歧、历史延续与测量失真保留为后续讨论参考，不预先锁定科学假设。具体方案见[探针设计](PROBE_EXPERIMENT_PLAN.md)。

不能据此宣称提出首个归因可视化系统、首个图驱动发现流程、首次观察上下文影响衰减，或已经完整超越 Grond/OA。当前成果是文献依据和研究设计；没有模型实验、机制新发现或复现成功记录。
