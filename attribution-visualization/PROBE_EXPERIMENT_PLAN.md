# 归因可视化探针：先观察与归纳，再寻找研究入口

日期：2026-09-10。状态：冻结批次的全部计算已完成：108条轨迹、324次序列评分、8,274/8,274个输出位置A、48次删除参照。初始485个A之外的7,789个位置按用户要求增量补齐，原生成和D均保留。[观察文档](PROBE_OBSERVATIONS.md)与[全量浏览索引](runs/attribution-probe/full-html/index.html)交付逐例材料与归纳。下文保留最初的采样预算；本次扩展及实测完成证据见[服务器记录](SERVER_EXECUTION.md)。阶段定义以用户说明为准。

## 1. 本阶段要交付什么

**探针实验：观察现象、归纳现象，探索后续能提出什么科学假设。** 不以明确科学假设为启动条件，不要求证实A/B/C，不预定最后必须得到哪种机制解释。

**Toy实验：从探针材料中选出问题，提出科学假设，再尝试用初步方法解答。** 为某个机制命题专门设计的历史替换、内部组件干预、模型修正等，按其目的归入toy；不是首轮探针的默认清单。

当前产物是一份可交互翻阅的现象观察册：完整样本概览、典型个案、重复图样、例外、覆盖范围，以及值得进一步问的问题。即使没有发现值得推进的入口，也应交付这份观察记录。

探针需要预先固定观察边界、采样方式、分数含义和记录规则。文献帮助选择观察维度；现象分类与后续问题则随数据形成。模型内部的`probe`读出器只是可选工具，不是“探针实验”这一阶段的定义。

## 2. 资源盘点后的首轮选择

**采用OA作者发布的同基座三个状态、原测试池12条基础输入、三种输入条件，共108条自然生成轨迹。** 不启动新训练，不要求先提出科学假设。

| 要素 | 已作选择 |
|---|---|
| 模型 | M0：原Llama-3-8B-Instruct；M1：作者普通后门adapter；M3：作者MAD+probes adapter。精确模型URL/revision见[资源表](REUSABLE_RESOURCES.md)。MAD-only资源已确认，首轮暂不增加第四状态 |
| 输入池 | 作者normal_harmful_test和backdoored_test各313条，313/313精确配对；相同基础请求，不从训练池重造配对 |
| 取样 | 313条不同基础输入按字符长度分为104/104/105三层，各取4条；seed=20260910，以内容hash排序，未查看模型输出后筛选。已固定12个源row_idx |
| 输入条件 | 无触发、作者原触发、同位置/分隔符/字符长度的固定替代标记；token数是否匹配尚待目标tokenizer核对。替代标记不假定行为上无效 |
| 自然生成 | 每状态×每输入×每条件生成一次，greedy，最多200个新token，保留EOS/截断/拒答/无明显变化。这里greedy是本轮观察条件，不冒充作者历史默认解码 |
| 主测量 | 全位置固定前缀log概率与条件差；每自然轨迹至多5个目标位置的signed Input×Gradient；少量输入片段删改重评分 |
| 不需要的准备 | 模型微调、检测器拟合/校准、付费judge、新SAE/CLT训练、重做数据生成、独立Web平台 |

12条是便于逐例阅读的起始工作量，不是统计功效结论。输入均来自作者的normal_harmful测试任务；无触发条件也不是一般良性能力测试。先把原任务看清，之后是否加入良性请求、多轮对话、其他模型或更长上下文，由观察材料中的缺口决定。

M0没有匹配预算的clean微调adapter；三个状态也未确认相同训练随机性。因此记录的是这些发布状态的表现，不能把状态间差异全部解释为OA混淆训练的单独作用。没有合法可加载的精确基座时，OA部分待执行；先做本地小模型的仪器检查及阅读公开缓存，不把其他后门资产重命名成OA。

## 3. 同一个样本的三层观察

### 第一层：完整回答与输出位置

同屏保留原输入、自然输出、逐token概率，以及同前缀下触发／无触发的目标token log概率差。必要时加一个完整next-token分布差异量和主要候选词，避免只看最终选中的词。

两次自由生成分叉后，不能直接拿第t个词相减。分别以自然无触发回答、自然触发回答为固定目标，在同一个前缀下重新评分；图注标明目标轨迹来自哪里。固定前缀评分与自然生成并排观察，暂不把它们分解成“直接／中介因果贡献”。具体公式沿用[测量约定](MEASUREMENT_AND_RESEARCH_PLAN.md)。

这层覆盖每条轨迹的全部生成位置，首先让人看到“变化在哪里、对应什么实际内容”，而非只显示最大的一块红色。

### 第二层：点击输出词，展开输入与历史来源

主方法采用Captum的LayerGradientXActivation，针对目标token的log概率作Input×Gradient，并按embedding维作带符号求和。显示任务指令、上下文、触发片段、chat模板与已生成前缀的位置；保留原始token和数值。少量目标用片段删除／替换重评分作不同测量的参照。两者不一致先记录，不立即认定谁揭示了真实机制。

为控制成本，每条轨迹先选开头、中部、末尾三个位置，再加入绝对条件差较大和随机选取的位置，去重后至多五处。固定位置保证基本覆盖，额外位置用于探索；用户可继续点开。选中位置只代表这些位置，未算部分显示“未计算”，不能显示成零或统计为无影响。短回答按实际可用位置处理，截断端点单独标记。

归因允许标明负值，但非负方法不伪造“抑制”颜色。跨模型梯度尺度不能直接当统一影响单位；保留各自方法、目标及尺度。已经有兼容的probe/SAE时可加为附加视图，首轮不为此新训一整套读出器。

### 第三层：按生成过程与样本比较

把同一样本的输出变化、来源位置随时间的图，以及不同输入／模型条件联动。相邻词的变化可点回全文，不能只剩聚合曲线。模型输出先按实际内容看，再按组别比较；不强行对齐不同句子，也不预设变化一定发生在早期。

这里只使用已有轨迹与测量条件形成观察。归因所需的输入替换属于测量；为证明某条传播路线专门设计的中介／组件干预，留待toy阶段。

## 4. 用观察维度组织查看，不用A/B/C预分结论

| 观察维度 | 可以记录的描述 | 此时不推断的原因 |
|---|---|---|
| 输出位置与内容 | 数值在哪里变化，对应答案词、解释、格式还是结束位置 | 哪个位置是后门“开关” |
| 来源分布 | 哪些输入／历史位置分数较高，符号、分散程度如何 | 高亮位置就是唯一真实原因 |
| 随生成的变化 | 图样怎样出现、变化、重复或中断 | 已证明某种因果传播路线 |
| 条件与实例差异 | 哪些模型、输入和成功／失败轨迹中出现；有哪些反例 | OA必然更隐蔽或采用不同机制 |
| 测量之间的关系 | 不同视图／目标／粒度在哪些位置一致或冲突 | 某一种热图天然更忠实 |

这些维度是导航，不是需要全部发现差异的检查表。允许“相似”“未见稳定模式”“尚无法分类”，允许一条现象跨多个维度。A/B/C不作为现象分类标签，也不限制未来的入口数量。

## 5. 从个案走向归纳的工作顺序

1. **先浏览完整样本概览，再深入个案。** 保留逐条查看次序；记录普通样本与失败样本，不能只看高亮最大的例子。
2. **先写可复核的描述。** 记录位置、数值、文本和条件，避免把“路由、写入、隐藏、接管”等机制词当已经观察到的事实。
3. **按图样形成临时分组。** 相似例放在一起，同时寻找不符合描述的例子；允许改分类、合并、拆分和未分类，不训练额外聚类模型作为前置条件。
4. **必要时补看少量新例。** 用新的基础输入了解是否还能见到图样，或用少量随机解码看波动。重复生成不算新的独立输入；发现条件后定向抽到的样本单列，不混入原随机批的出现比例。
5. **归纳现象及尚未弄清的问题。** 对照已有全文证据卡，区分“已有现象在本设置的复现”“已有工作覆盖不足”“暂时无法判断”。只针对具体问题补查，不重跑整个文献调查。

只为图中异常定向挑新例可以帮助探索，但不能用这批例子估计自然任务中的总体发生率。跨不同前缀和目标的差异也先按其测量条件描述。基础数值回算、位置对齐和色标检查服务观察可靠性，不要求在探针里完成全部解释方法的理论验证。

## 6. 最小现象记录与进入toy的条件

每条记录只需：**样本与图的位置；不带机制解释的现象描述；出现范围与分母；反例／未计算部分；现有文献能解释到哪里；仍值得追问什么。** 现阶段不强制填写科学假设或解决方法。

示例仅说明记录格式，并非已有结果：“在这一批若干长回答中，后半段的同前缀条件差较小；所检查的部分位置，历史归因分数却较高。短回答与若干失败例不符合。该图样在不同任务内容和测量目标下会怎样变化？”不能直接写成“触发器已把恶意信息写进历史”。

进入toy前，至少应能说清：现象确实在原数值／原文本中可见；它的出现条件、重复例与反例有记录；常见对齐／显示问题不足以解释当前观察；已有工作没有直接回答我们选出的具体问题。重复案例仍不等于机制证明，新颖性也不由“未搜到”保证。

随后再选择一个入口，提出明确科学假设和初步方法，开始toy。探针不要求一定产出三个方向、取得显著差异或马上改善指标。当前成功标准是**形成足以支持下一步选题的现象材料，而不是提前得到想要的答案。**

工具复用依据：[生成归因证据卡](review/generation/FULLTEXT_NOTES.md)、[交互可视分析证据卡](review/visual/FULLTEXT_NOTES.md)与[综合报告](RELATED_WORK.md)。这里的样本数与流程是本项目设计建议，不是原论文已经验证的最优配置。

## 7. 具体执行顺序与计算约定

### 7.1 先完成一次仪器检查

本步骤是确认数值与展示接线正确，不是提出并验证科学假设的toy实验。

用本机已有TinyLlama-1.1B-Chat-v1.0缓存，两条短输入、每条至多32个新token，在CPU检查：原始ID/特殊token边界；固定目标评分的位移索引；Input×Gradient的符号与维度汇总；保存后重载展示。小模型只证明接口可以工作，不替代OA的预检。

随后在精确OA基座/adapter上做一次实际预检：模型版本与tokenizer；模板不重复拼接；输入embedding梯度可取得；生成与重评分的dtype/kernel；色图原数值。若整段teacher forcing与逐步缓存评分有可见差异，记录差异并统一一个评分路径，不能混用两套值来制造条件效应。这些检查只在失败或配置改变时重做。

模型参数可冻结、保持eval；归因阶段必须允许对输入embedding或相应层输出求梯度，不能放在no_grad/inference_mode里。无optimizer、无模型参数更新。默认使用同一明确记录的非量化精度与可求梯度attention实现；不为了装进显存静默改为4bit模型。

复用现有OA的身份和加载逻辑，但不调用会强制cupbearer/CUDA/检测器拟合的整个评测入口。每次从同一基座快照构造一个状态，必要时在内存merge adapter；不在已合并的M1上继续叠M3，不保存三份完整大权重。

### 7.2 保存真实自然轨迹，一次生成、多次读取

36个输入条件用于每个模型状态。直接保存HF generate返回的input/output token IDs、attention mask、模板边界、生成参数、EOS和停止原因；显示文字另存，不能替代ID。作者测试prompt已经含chat格式，沿原处理约定使用add_special_tokens=False，不再次apply_chat_template。

固定替代标记为输入清单中的CONTROL000标记。只用于已知输入条件对照，不按输出效果调整或搜索。字符等长不意味着token等长；实际token差和所有特殊位置记录进清单。若不等长，保留为该替代标记条件，不写成“严格等token长度控制”。

模型阶段先顺序处理短/中/长各一个正式样本，顺便记录实际计时/显存，再继续剩余样本；这些样本计入108，不另造GPU计时批次。只占用运行所需的一张卡即可，不需要分布式系统。样本失败保留状态和原因，不用新的容易样本顶替。

### 7.3 全输出位置的条件差：同一目标、同一生成前缀

对某个模型状态m、输入条件c以及固定目标轨迹y，定义：

\[
\ell_{m,c,t}(y)=\log p_m(y_t\mid x_c,y_{<t}).
\]

每个模型/基础输入已有三条自然轨迹，分别把它们作为固定y，在无触发、原触发、替代标记三种输入下各评分一次。得到：

\[
D_{m,t}^{T-0}(y)=\ell_{m,T,t}(y)-\ell_{m,0,t}(y),\quad
D_{m,t}^{S-0}(y)=\ell_{m,S,t}(y)-\ell_{m,0,t}(y).
\]

三条目标轨迹×三种条件，不再自由生成。一次整段teacher-forced前向可读取该轨迹所有目标位置；按实际API/显存分批，不能误称每位置都需要重新生成全文。原始模型softmax概率与采样截断/温度处理后的分布分开；本轮统计前者。

D回答“在这个固定前缀下，输入条件改变了多少该token的log概率”。它不直接估计自由生成的总效应，也不分解直接/中介效应。某个固定前缀在另一条件下可能非常不自然，仍保留数值和该限制。不同自然回答分叉后，不能仅凭同一个输出序号相减。

保存每位置log概率、两个条件差及少量候选词/概率供查看；不保存所有步骤×全词表的巨大logit文件。若后续确需完整分布指标，再针对具体位置补算并单列成本。

### 7.4 目标位置到prompt/历史来源的归因

对每条自然轨迹选开头、中部、结尾三个位置，再加最大绝对条件差位置和一个固定随机位置，去重后至多5个。最大值在两个条件差的绝对值中取；并列取最早位置。随机位置用sample/model/condition身份和固定seed确定。EOS纳入原始位置记录；显示为结束token，不隐藏为空白。短回答按实际位置取。

在该轨迹原生输入条件下，原始输入与历史token的embedding为e，主分数为：

\[
A_{i,t}=\sum_d e_{i,d}\frac{\partial\ell_{m,c,t}(y)}{\partial e_{i,d}},\quad i\in(x_c,y_{<t}).
\]

用Captum LayerGradientXActivation配合接收原始ID的薄forward函数；forward只返回所选目标token的log概率。它是局部梯度敏感性，不是贡献百分比，也不要求各来源相加等于触发条件差。原始概率、条件差和A分数分别显示，不能把三种数值混成一种“温度”。

输入按原位置标注模板、任务内容/上下文、标记和已生成历史。token不等于汉字或单词；聚合展示需保存原ID到显示片段的映射，重复出现的同一个词不能合并成一个无位置词典。A只在被计算的位置和原生条件有值，不能以未计算的来源归因推断条件变化。

少量不同测量参照：输入清单中短/中/长各取一条，再取一条固定补充样本，具体为101、057、294、027。每个模型在原触发条件的开头/中部各选一个目标。片段固定为任务内容中的1个原始token：先取绝对A最大者（并列取最早位置），再从其余任务token中按固定seed、sample/model/target/source位置的hash排序取一个随机参照。模板和触发标记均不在候选集合；候选不足则记不适用。各次仅删除该原始输入token ID，保持其他输入ID、chat结构和同一目标ID/生成历史，不decode后重新分词。至多4×3×2×2=48次片段重评分；原触发移除的值直接复用7.3，不重新调用。空片段或无法保持结构的情况记不适用。

这些删改分数只是与梯度视图并排的参照。删改改变了语言输入分布，梯度与有限变化不同也未必意味着实现错误；不预设二者必须一致。这里仅抽查输入片段，不能据此认证全部历史归因忠实性；定向历史替换和组件干预仍留待toy。

### 7.5 归因可视化是主要观察入口

首轮交付一个可选择样本、模型、输入条件和目标位置的notebook观察册，配合可保存的HTML/图。来源归因复用Captum；补齐全位置后直接用已有matplotlib绘完整矩阵，避免逐格文字对象及超长画布，数值不采样。Inseq的HTML与save/load可以作薄显示适配；LIT完整联动作为按需升级，不成为开跑前置。

保留三块同屏可对照内容：

1. **完整输出热图**：原文及所有输出位置的D，切换参考轨迹；概率单列。先看到全局，再定位词。
2. **所选词的来源热图**：输入、模板、标记、已生成历史的A与原值；标清目标token、位置和分数定义。
3. **生成过程与条件对照**：全位置D曲线、已算位置的来源分布、同一基础输入各状态的完整回答，能回到原文本查看。

同一比较组使用共同色轴，不能每行各自归一化后比较亮度；梯度不跨模型宣称统一贡献尺度。负值、零、未计算、失败要区分。由于初始只算5个来源位置，其他位置不能显示为零；选词后可明确显示“未计算”，需要时记录追加请求，浏览器/控件不自动发起模型调用。

本轮源码核对发现：Inseq默认vnorm/L2会丢符号，应显式sum且normalize=False、rescale=False；Ecco默认非负；LIT现有例子对loss求梯度。使用现成组件时由我们的分数合同决定标注，不沿用误导性的默认图例。

### 7.6 预算用调用量表达，实际卡时随正式样本记录

| 工作 | 首轮上界 | 复用方式 |
|---|---:|---|
| 新训练 | **0** | 直接用作者终点；不训练probe/SAE/CLT |
| 自然生成 | **108条**，最多21,600个新token | 每个条件生成一次，保留原ID |
| 全位置固定目标计分 | **324条序列的评分** | 12输入×3模型×3自然目标×3输入条件；一次前向读取多位置 |
| 来源归因 | **至多540个目标位置** | 108×5；同一目标一次计算全部已有来源，非每个来源token单独反传 |
| 片段重评分参照 | **至多48次** | 固定目标、不重新生成；触发移除差直接用已有评分 |
| 翻阅/筛选/注释 | **0次模型调用** | 只读保存的轨迹与分数 |

这是工作量合同，不是GPU小时预测。梯度方法的一次库调用不代表与一次推理等价；实际记录forward/backward次数、有效/padding token、加载、失败、重算、峰值显存和持卡时间。核心数据不包含付费评分；人工先描述拒答/内容/格式变化，不把它包装成作者ASR结果。

如实测预算不足，先保存全部原始轨迹与已完成数值，在阶段边界调整尚未计算的来源位置，并报告覆盖缺口；不偷偷换小模型、量化或删掉失败例。后续追加位置/新输入使用单独增量清单，不重复跑已缓存项目。

2026-09-10用户追加全位置A范围后，实测总量为8,274个目标，保留初始485个并补齐其余7,789个。补算单独记录于 `full_attribution.json`；原轨迹仍以200新token为上限，不续写22条截断回答。初始计算289.33秒、补算671.38秒，合计960.71秒；不含环境排障与观察整理。
