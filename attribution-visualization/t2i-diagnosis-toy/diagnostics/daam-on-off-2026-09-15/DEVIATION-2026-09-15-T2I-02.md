# DEVIATION-2026-09-15-T2I-02 — 金标由人工独立盲标改为机器共识评审

状态：**已批准并执行**（用户 2026-09-15 指示「按这个方案执行」）。提出人：Claude；决策人：用户。

## 偏离了什么

PLAN.md 原文将主测试集金标定义为「独立盲标后的完整事实答案」（两名人工标注者 + 第三方裁决，≥1,152 条答案），并写明「BLIP-VQA 等自动分数只能作代理，不能成为本实验裁判」。

本偏离将金标执行者由人工替换为**两个不同家族、已发表且经人工相关性验证的公开自动评审器**，分歧由第三家族评审裁决：

- 评审 1（像素/几何家族）：GenEval 式——检测器定位对象、裁剪去背景、颜色分类；检测不到 = absent，计数>1 = multiple，置信不足 = unjudgeable，规则先冻结
- 评审 2（VQA 家族）：T2I-CompBench 官方 disentangled BLIP-VQA（pinned commit 已在 SOURCES.md），对全答案字典逐项询问
- 裁决：两者一致 → 金标；分歧 → 第三家族评审（必须 ≠ 读者模型），三方统计入档

**不改动**：双评审 + 裁决的协议结构、盲态接口（评审只见匿名单图 + 对象名）、答案字典、封存-揭示流程、`prepare.py` 合并接口（机器评审产出与人工同一 JSONL schema）、任务层级（干预响应预测，不降成图像质量打分）。

## 为什么（用户的理由 + 文献依据）

1. **可复现性优于可信任性**：人工标签审稿人只能选择信或不信；确定性生成（已实测逐位可复现）+ pinned 公开评审器意味着**审稿人可从种子逐位重跑全部证据链**。用户明确判断：涉及人工反而易被审稿人怀疑。
2. **领域标准即是如此**（2026-09-15 三次定向检索核实）：T2I-CompBench 用 disentangled BLIP-VQA 评颜色绑定并做过人工相关性验证（Kendall τ/Spearman ρ）；GenEval 用 Mask2Former + CLIP 颜色分类并报告与人工判断高一致；TIFA/DSG 用 LLM 出题 + VQA 作答、均经人工验证；OSI 用 Mask2Former + BLIP-VQA 一致性伪标签（即双机器评审一致模式）。全量双人盲标在 attribute binding 评测中无先例。
3. **结构性事实**：288 张图为固定种子 + 干预新生成，任何现成数据集不可能含其标签；「开源资源」只能指开源评审方法。

## 影响哪些结论

- 金标必须表述为 **machine-consensus gold（validated automatic judges）**，不得表述为人工真值。
- 机器金标已知失败模式（颜色分类对特殊材质混淆、检测器漏检）须申报；缓解为双家族一致 + κ 报告 + unjudgeable 合法类别。
- 诊断方法与评审器分歧的病例须逐例列出，供人工复核可能的评审错误。
