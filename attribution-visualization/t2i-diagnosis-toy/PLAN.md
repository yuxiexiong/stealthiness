# 文生图方向 toy：归因证据能否提高跨对象依赖诊断

2026-09-15。这是待实验验证的方案与实现合同，不是已经成立的方法贡献。目标是判断是否值得推进一篇 ICLR 等级论文；不把它设为博士主线，也不预设 VLM 的结果可复制。

## 主旨与可反驳的命题

**先检验诊断，再研究修复。**在生成实例中，归因可视化能否帮助我们分辨两个对象的条件依赖，并更准确地预测尚未揭示的受控操作会改变哪项真实事实？封存后再以金标分层报告初图正确、错误和不可判，不预先只挑相似错误。诊断正确但图没有修好，仍可支持诊断；预测错误则必须记作诊断反证，不能归咎于修复器。

第一轮只检验一个有限问题：固定生成模型、提示、初噪声和采样器后，替换某个颜色 token 的上下文向量，两个对象的实际颜色状态是否改变。这里的“依赖”是对指定条件向量操作的响应，不是唯一自然根因，也不是神经元、空间路径或生成阶段定位。上下文向量可能包含其它对象的信息，因此不能把它称作纯净的“对象 A 信息”。

主假设：在相同读者、相同两次可见探针和相同测试问题下，加入受控归因对照，比只看原图和探针图、只看静态 DAAM 图、以及强输出诊断的证据，更能预测未揭示操作的事实响应。允许假设失败；不能以热图美观或个别成功案例代替比较。

本轮研究的候选方法是**受控对照归因证据包**，尚未宣称一种新的归因算法。复用 DAAM 测量，组织原图、词级热图、探针前后图与有符号热图差，交给同一个诊断读者。若最后只有界面增益，论文主张必须相应收窄；若没有诊断增量，不通过改名宣布成功。

## 正确答案：必须独立，且覆盖整个有限测试菜单

目前核验的公开资源没有同时提供“原生成轨迹、这些受控操作的全部终图、每个对象完整事实答案”。因此本方案**不能声称已找到现成完整依赖金标集**。

- T2I-CompBench 的颜色绑定提示只提供生成要求，不提供新生成终图的实际事实答案。BLIP-VQA 等自动分数只能作代理，不能成为本实验裁判。
- RichHF-18K 提供外部人工错误区域、错配词及质量评分，能支持输出症状评价，但不提供内部因果或未试干预的答案；图像还须与 Pick-a-Pic 对应。
- Rapidata 的独立人类反馈可直接取得小样本，但同样不是完整原子事实或内部依赖答案。
- GenBlemish 官方数据发布、DAAM COCO-Gen 原下载链接目前有可得性障碍，不能写成已经可运行的金标依赖。

拟采用的主测试集是：**公开提示来源 + 固定生成的完整操作菜单 + 独立机器共识评审后的完整事实答案**（DEVIATION-2026-09-15-T2I-02，用户 2026-09-15 决定：不采用人工盲标，理由是人工标注不可被审稿人复现，而确定性生成 + 公开 pinned 评审器可从种子逐位重跑全部证据链）。原「独立盲标」的双标注者+第三方裁决结构保留，执行者替换为两个不同家族、已发表且经人工相关性验证的公开自动评审器（GenEval 式检测器+颜色分类，与 disentangled BLIP-VQA），分歧由第三家族评审裁决且必须≠读者模型；三方统计全部入档。任务层级不变，不降成图像质量打分。

事实字典在生成前固定：针对两个不同类别的对象，各询问一个中性的“该对象的可见颜色状态”问题；答案覆盖颜色词、other、mixed、absent、multiple、unjudgeable。缺失和多实例是有效失败状态，不能删掉。unjudgeable 是无法可靠判定，不强行编造颜色。

评审者（机器）只接收随机匿名单图和对象名称，不接收原提示、操作、种子、模型、期望颜色、热图或诊断——与原人工协议同一盲态接口。两个不同家族的评审器独立完成所有图片、所有问题；分歧由第三家族评审裁决，包括可裁为 unjudgeable（三方都不可靠时判 unjudgeable 是合法结果，单独报告覆盖）。评审器正式使用前必须在探索集离线预演：演示其能判对也能拒绝故意换错的答案；报告评审间一致率（Cohen's κ）与逐类覆盖。两个来源一致并不等于哲学意义的绝对真理；这里的完整是对预先定义问题逐项覆盖，独立性与一致率必须报告。机器共识金标的已知失败模式（颜色分类对特殊材质的混淆、检测器漏检）须在论文中申报；金标表述为 machine-consensus gold（validated automatic judges），不得表述为人工真值。

## 最小实验设计

| 设计 | 检验主旨的哪部分 | 为什么需要 |
|---|---|---|
| 官方颜色绑定提示中确定性选择双对象子集 | 研究自然多对象绑定情景 | 复用已发布任务，保留来源和排除理由；不只挑失败漂亮案例 |
| 按无序对象对划分 exploration/test | 规律是否延展到新组合 | 同对象对、不同颜色或种子不得跨分割泄漏 |
| 每个提示两个预登记种子 | 避免单图偶然性 | 种子是同一提示的重复测量，不作独立样本扩大显著性 |
| base + probe_A/B + test_A/B + sham | 方向对照、未揭示预测、无效操作控制 | 两个可见探针、三个隐藏问题；不把测试图传给诊断者 |
| 每次克隆同一初噪声 | 操作可比性 | 重用一个不断前进的 RNG 不等于相同噪声 |
| 单 token 上下文向量替换 | 限定可解释的操作范围 | donor 来自改色提示编码，只替换指定 token，其余上下文向量、无条件分支不变 |
| 完整独立终图事实标签 | 诊断独立评分 | 既不用提示要求，也不用方法自己的评分作答案 |
| 同读者的不同证据包 | 归因信息的增量 | 防止换更强 VLM 或增加探针数后将增益归给热图 |

预设首批最多 24 个提示、每个 2 个种子、每例 6 个条件，共最多 288 张生成图。实际可解析数量、对象对分组和分割由 manifest 明示；不足时减少规模并报告，不放宽规则补齐。探索集用于找规律、检查显示方式和冻结读者提示；测试集不参与选择。这个规模用于可行性与效应估计，不预先声称已有检验功效。GPU 成本以真实计时核算，不沿用已撤销的 48 GPUh 上限。

探针颜色和测试颜色必须不同，且均不同于原两个颜色；只接受可被模型 tokenizer 编成单 token、替换后 token 对齐不变的情况，无法对齐即明确报错。sham 替换为原向量，应与 base 逐位完全一致——这同时是确定性零假设的硬闸门（同条件 DAAM-on 重跑必须逐位相同；2026-09-15 实测满足，任何非确定性都会使其失败）。DAAM 开关像素差**不设数值闸门**，按 DEVIATION-2026-09-15-T2I-01 降为记录项：原「均值不超过 1、最大不超过 8」未经离线预演即冻结，实测在本冻结栈（torch 2.1.2 + diffusers 0.21.2 + fp16，DAAM 需弃用融合 SDPA）上 max≤8 为 0/16 可满足（最好 17，中位 56），mean≤1 为 11/16，且只测首例使裁决依赖病例排序；而确定性零假设逐位为 0，证明该差是 DAAM 插桩的真实固有扰动（纹理级，最坏例 Pearson r=0.997）。首例记录 mean/max/超限像素数/32×32 粗尺度误差/Pearson r 入 render.json。这只是数值刻画，不是严格保证观测无扰动；所有正式条件统一开启 DAAM，扰动为共模，DAAM-off 图不进入任何下游；论文必须明示全部图像为 DAAM 插桩状态生成。所有条件保留模型 revision、软件版本、采样器完整配置、初噪声哈希、图像及归因资产哈希。

## 可视化究竟有什么作用

每个测试例只向读者展示 base、probe_A、probe_B 的生成图。静态归因组额外看到 base 的两个对象词和两个属性词 DAAM 热图；受控归因组再看到两个探针的相应热图与 `probe - base` 有符号差值图，保持同一色标。差图表示归因强度变化，**不是已验证事实效应、因果强度或正确答案**。

读者输出针对 test_A、test_B 和 sham 的两项事实预测：unchanged / changed / unjudgeable 三类概率，另附证据、竞争解释、不确定项。答案冻结后，评估端才打开外部事实标签，比较 base 与各隐藏条件的真实颜色状态。absent、mixed 等状态变化也计入 changed；任一端为 unjudgeable 则记作第三类并单独报告覆盖。这个闭环完全不要求目标颜色恢复。

本轮不把热图变成自动修复处方，不训练大网络，不实现时间步搜索，不声称空间路径定位。若以后主张“图比同信息表格更有价值”，应新增同信息表格读者对照；本轮主要检验控制后归因证据的增量。

## 比较对象与 SOTA 的证据边界

| 比较 | 实际用途与公平性 | 可否称 SOTA |
|---|---|---|
| unchanged / source-only | 恒不变、只影响直接被替换对象的朴素预测 | 否；防止任务被简单先验解决 |
| output | 同读者只看 base 和两个探针终图，预测新操作 | 简单但重要的受控敏感度基线；不是 SOTA |
| daam | 相同终图和 base 的官方 DAAM 热图 | ACL 2023 经典归因基线，不称 2026 SOTA |
| contrast（候选） | 相同终图 + base/probe 官方 DAAM 图 + 差图 | 本 toy 待检验的方法，不预设优越 |
| imagedoctor | 官方模型为三张可见终图产生解释/错误图，再交给同读者 | ICLR 2026 的强输出诊断参照；在其论文 RichHF 指标上领先若干前作，不等于本依赖任务 SOTA |

ImageDoctor 正式版本表 2：misalignment CC 为 0.225，RichHF 为 0.212；MSE 为 0.00299 对 0.00304。增益存在但并非数量级变化。附录表 6 的 NSS/AUC 并非所有指标都领先，因此不能写“全面最佳”。这些是作者报告，不是本仓库复现。官方论文：https://proceedings.iclr.cc/paper_files/paper/2026/file/deb0e85779f2f003b10528de72b1ebf1-Paper-Conference.pdf

ImageDoctor 原任务输出质量分数与错误区域，没有我们的未揭示操作预测接口；本实验加共同读者属于适配比较，不能声称重现其原基准名次或击败全部诊断 SOTA。ConceptAttention（ICML 2025）是 DiT 语义定位方法，与 SD 系列操作接口、输出症状和依赖预测不同，留作后续换模型实验；不为凑新年份强行纳入首轮。OSI 的存在性探针训练标签也不是独立因果金标。发布会名本身不是 SOTA 依据。

## 评分、成本与继续条件

主要指标：每例三个隐藏条件、两项事实的三分类 Brier score；先例内平均，再按提示/对象对聚合。辅助报告准确率、macro-F1、changed 类召回、不可判比例，以及 cross-object / direct / sham 分项。所有方法须提交完整同一问题集合，禁止只交自信样本。缺失、重复、非法概率、证据包哈希不符均拒绝评分。

用相同测试组计算成对 Brier 差及按无序对象对聚类 bootstrap 的置信区间，不把事实、条件、种子当作独立样本。样本不足和某类不存在须显示，不默认为满分。记录所有生成、归因、ImageDoctor、读者调用的耗时、token 和失败；ImageDoctor 的额外模型成本单列，不暗称相同算力。

继续条件：真值覆盖合格且盲标执行可核查；相比最强可用对照有一致的诊断增量；改进不只来自总报“不变”或直接对象响应；至少出现可复测、能区分竞争解释的现象。首批结果只决定下一轮规模，不单凭一个显著性阈值承诺论文。如果无增量，保留病例、负结果和失败规律，分析是测量没有信号、读者不能利用，还是输入条件响应本身太弱。

## 实现和验证边界

先写本方案，再实现最小 CLI：准备公开提示 manifest、官方 Diffusers/DAAM 薄适配生成、匿名标注包/金标合并、白名单证据包、固定读者调用、预测封存与独立评分。ImageDoctor 在其独立环境运行官方 inference.py；不拷贝改写其骨干或修改全局 transformers。复用旧 VLM 协议的白名单与先封存后揭示原则；不复用其 576 token、答案概率或完整缓存即已见的假设。

软件验证只用明确标记的合成 fixture 和微型模型检查接口/噪声/泄漏/计分逻辑；它们不能作为研究有效性结果。完整模型生成、真实独立标注和所有方法的正式比较各自记录状态。代码完成后由多位 agent 分别审主旨、真值/公平性、执行逻辑；只针对发现的问题修复和复测，不反复泛审。
