## 2. 裁决（按 v3 冻结停止条件，a fortiori 触发）

**编码器/条件层不存在合格 do 算子——连全量重条件化都不过闸。** 三层根因链（全部有实证锚点）：

1. 单行替换惰性：上下文冗余重建原属性（130-s1 目检：车仍红、门变蓝）
2. 强位点仍不受控：EOS/名词行只带来杂色与消失
3. **地基：SD1.5 冻结噪声反事实构图不稳**——供体提示同种子下目标对象 7/12 直接消失；条件层任何算子的上限被生成器自身绑定不可靠性压死

**因此：C 的事实级审计菜单在 SD1.5 上无信号，AUDIT-TOY-01/02 以科学失败结题**（合同链完整执行、预测全部先注册、零判据事后调整）。

副产品（信息量为正）：
- B 实验负结果的再解释：读者预测的是近惰性算子的响应，"unchanged" 先验必胜是结构性的
- 对使用 token 级干预的 T2I 因果文献的适用性警示：此类算子在弱绑定生成器上不产生事实级传导
- 金标仪器三次目检全对，评审共识机制经受了最恶劣图像的检验

## 3. v4 附录：基底升级探针（AUDIT-TOY-03 Stage A）

**假设**：天花板由生成器绑定可靠性决定；换强绑定基底（SDXL-base-1.0）后条件层传导应恢复。

**设计（无 hook，纯生成）**：
1. SDXL 上重生成原 24 提示 × 2 种子的 base 图 → 三评审共识 → 得 SDXL 正确组
2. 取正确组前 ≤10 例（哈希序），每例 4 个供体提示（沿用 study.json 冻结供体色）同种子生成 → 判源对象事实
3. **K-sub（预注册）**：基底合格 ⇔ 正确组直接命中率 ≥ 0.6；合格 → 另立 v5 做 SDXL 双编码器位点实验与审计菜单重建；不合格 → 条件层审计跨基底死刑，转注意力层算子或预注册退路（A 领衔仪器论文）
4. **预注册预测**【推测】：SDXL base 正确率 0.4–0.7（vs SD1.5 的 0.07）；正确组天花板命中率 0.6–0.9

**成本**：SDXL 权重 ~7GB 下载 ≈25 min；生成 ≈48+40 次 ×~8s ≈ 12 min；评审 ≈15 min。**合计 ≈1 GPU·h**。

## 4. v4 执行结果与 AUDIT-TOY 终局答案（2026-09-16 补记）

**K-sub：FAIL。** SDXL 严格双对象正确率 **1/48（2%）**，低于 SD1.5 的 3/45（预注册预测 0.4–0.7 第三次被否证）；唯一正确例的供体提示天花板命中 1/4。事实分布：multiple 38/96、absent 13/96——SDXL 在 1024² 上大量复制对象。第四次目检（072-s0：两只蓝碗+红蓝火车，判 a=multiple/b=red）确认评审无伪影，4/4 全对。

**终局答案（对应 toy 的双重目标）**：

- **Q1 C 是否成立：否。** 条件层事实级干预菜单在 SD1.5 与 SDXL 两个基底上均无信号；按 v4 冻结停止条件，条件层审计跨基底死刑。三道预注册闸门（K0/K-op/K-sub）全部触发停止，零判据事后调整，总 GPU 消耗 <1.5 h。
- **Q2 ICLR accept 潜力：按现设计不可证实。** 存活路线：(a) 注意力层算子（A&E 式采样期强制是已知有效的图像改变手段，作为 do 算子未测，需另立合同）；(b) 更强基底层级（SD3/FLUX，T5 编码器，公开绑定分数显著更高——另立合同）；(c) 预注册退路：A 领衔 VLM 仪器论文——**关键不对称已确立：VLM 侧的视觉状态替换是被 88 单元正式运行证明有效的 do 算子，T2I 条件层没有对应物**。

**整夜的统一发现**：在独立金标下，SD1.5（7%）与 SDXL（2%）的严格双对象颜色绑定近乎不存在；冻结噪声重条件化主要删除/复制对象而非换色。这一个事实同时解释了 B 实验的负结果（读者在预测近惰性算子）并处死了 C 的现设计——**这些基底在条件层不存在可控的事实级因果接口**。
