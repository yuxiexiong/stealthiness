# AUDIT-TOY-01 实验合同（v2，冻结版）

2026-09-16。目的：裁决课题 C（修复因果审计）的两个前提——(Q1) 审计仪器是否有机制区分力、Goodhart 缺口是否真实存在；(Q2) 效应量是否达到 accept 级潜力的预注册线。本文件 commit 后即冻结；任何偏离记入决策日志。

## 0. 待测量定义

- **机制轮廓**（每病例）：⟨DRR, CLR⟩。
  - **DRR 直接响应率** = 在 4 个非 sham 干预（probe_a/probe_b/test_a/test_b）中，"干预源对应事实变为该干预供体色"的比例。
  - **CLR 跨对象扰动率** = 同 4 个干预中"另一事实相对 base 改变"的比例。
- **分组**（base 条件金标 vs 意图色）：正确组 = 两事实均等于意图色；失败组 = 至少一处不等；base 含 unjudgeable 的病例整例排除。现状：正确 3 / 失败 42 / 排除 2（safety 排除的 color-110-s0 不参与）。
- **症状通过**（对修复 R）：R 修复后的 base 图上，disentangled BLIP-VQA 对两条 "is the {name} {intended color}?" 的 p(yes) 均 ≥ 0.5（评审实现 = judges.py BlipVqaJudge.yes_probabilities，与文献做法同族）。
- **机制通过**（对修复 R，v2 修正）：修复保持激活下重跑 6 条件菜单所得轮廓，落入 **[正确组 + R 激活]** 参照组的接受域：DRR ≥ 该组 DRR 的最近秩 5 分位，且 CLR ≤ 该组 CLR 的最近秩 95 分位。**不得**使用 Stage 0 裸机接受域判决 Stage 1。
- **Goodhart 率** G_R = P(机制不过 ∣ 症状通过)，按对象组（study.json group 字段）聚类 bootstrap（2000 次，seed=0）。
- **附带损伤率** = 正确组施加 R 后 DRR 跌出裸机正确组最近秩 5 分位、或 CLR 升出 95 分位的病例比例。

## 1. 病例库与扩池规则（结果盲）

正确组 n=3 不足标定。扩池：以 prepare.py 既有确定性选择规则将 limit 提升至 120（同一哈希排序的前 120 条提示 × 2 种子），新增病例 = 不在原 study.json 中者。仅生成 base 条件 → 三评审共识判 base 事实 → 按上述分组规则入组。目标正确组 ≥ 12；若不足，同规则种子扩至 {2,3}。**选择只依据 base 正确性，不接触任何菜单响应**。新正确病例补生成裸机 6 条件菜单进入 Stage 0 标定。

## 2. Stage 0 · 仪器标定（裸机）

- **K0（可满足性）**：正确组与失败组 DRR 差的组级 bootstrap 95%CI 下界 > 标签置换 null（组级置换 1000 次）的 95 分位。
- **可违反性演示**：标签随机置换后 K0 必须不满足；演示不出即判据作废，停止。
- **停止条件**：扩池后 K0 仍不过 → C 整线停止，定性为科学失败（菜单无机制签名）。
- **预注册预测**【推测】：正确组 DRR ∈ 0.5–0.8；失败组 ∈ 0.1–0.3。

## 3. Stage 1 · 修复审计

- **R1 = Attend-and-Excite**：diffusers==0.21.2 **内置官方移植** `StableDiffusionAttendAndExcitePipeline`，同 MODEL/REVISION/DDIM 配置/同 z；token_indices = 两对象名词的末子词位置；其余超参用 pipeline 默认。**R2 = SynGen**（官方库）第二批接入，不阻塞 R1 判决。
- **K1-pre（每方法仪器有效性闸门，v2 新增）**：R 激活下菜单保持区分力——[正确+R] 与 [症状未通过的失败+R] 的 DRR 差按 K0 同构造检验。不过 → 宣布仪器对该方法失效、该方法退出，**不得**把不可判计为机制不过。
- **确定性前置核查（v2 新增）**：每方法先做同参数复跑逐位一致检验。若严格确定性不可用（A&E 反传可能触发 torch 确定性限制），降级：以该方法复跑差标定容差 null，sham 闸门以同容差判。降级须记录。
- **判据 K1（Q2 潜力线）**：任一方法 G_R 的 95%CI 下界 ≥ 0.25，或方法间 G_R 差 CI 排除 0 → 判"C 成立且具 accept 级素材"。**K1′**：全部方法 G_R CI 上界 ≤ 0.10 → C 降档为验证型，切换预注册退路（A 领衔仪器论文）。中间带 (0.10,0.25)：扩样本/加方法再判，阈值不动。
- **预注册预测**【推测】：A&E 的 G_R ∈ 0.3–0.6。
- **安全检查器**：保持开启；被标记条件按既有政策整例排除并记录。

## 4. Stage 2 · 最小过审修复（仅当 K1 过，toy 内可选）

1–2 个 Goodhart 病例上，用审计信号选靶的 α/v 编辑将轮廓拉入接受域的存在性演示。成败不改 K1 判决。

## 5. 评审与金标

复用 judges.py 三评审（OWL-ViT+CLIP / BLIP-VQA / ViLT 裁决），judges-v1.1 冻结阈值不动。评审只接收单图+对象名（对条件身份天然盲）。已知局限照抄申报：症状评分器与金标评审之一同为 BLIP 家族（缓解：金标可被另两家族反投；机制指标与症状指标正交）；机器金标一致率问题跟随，报告一致子集敏感性分析。

## 6. 失败类型预定义（6.7）

- K0 不过 = 科学失败（有信息）；生成/评审管线中断未达判据 = 合同执行失败（无信息，修复后重跑）；K1 落 K1′ = 科学结果（验证型，降档退路）。

## 7. 成本预算（客观估计）

扩池+Stage 0 ≈ 1 GPU·h；R1 审计（~42 失败 + ~12 正确对照，×6 条件，A&E 约 20s/图）+ 评审 ≈ 2.5 GPU·h；**R1 里程碑合计 ≈ 3.5–4 GPU·h**；R2 追加 ≈ 2.5 GPU·h。

## 8. 边界申报

只审免训练生成时修复家族；SD1.5 + 颜色绑定单任务；"机制"指功能层（token→事实通路传导），不主张电路一致性；toy 通过 ≠ 论文完成（还差正式规模、后置编辑家族、Stage 2 完整版）。
