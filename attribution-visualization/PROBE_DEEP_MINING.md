# 归因可视化探针的第二次挖掘

日期：2026-09-10。本次只分析已冻结的 36 份 JSON、108 条轨迹，没有新增模型调用或 GPU 实验，没有修改原始数据。新增的是描述性重分析，不是已完成的 toy 或机制验证。

证据：[计算结果](runs/attribution-probe/deep-mining-summary.json)，[只读复核脚本](mine_probe.py)，[原观察报告](PROBE_OBSERVATIONS.md)。所有输出位置从 1 开始计数。独立基础输入仍为 12 条；不同位置、条件和模型复用这些输入。

**判断：最值得优先追问的是“词级影响混合了哪些生成决策”；其次是“同目标、同历史下来源归因为什么仍会分歧”。** 两条均有新增缓存证据，但尚未通过完整的新颖性审查。不能把概率恒等式或已知的梯度不稳定重新命名成新算法。

**1. 一个词变红，可能主要表示模型更愿意继续生成。**

对固定模型、固定 prompt 条件、固定输出前缀和非结束 token y，定义 C 为下一 token 不在合法结束集合中。本批集合为 {128001, 128009}。有恒等式：

\[
P(y)=P(C)P(y\mid C),\qquad
D_y=D_C+D_{y\mid C}.
\]

D 是原触发与无触发条件下的 log 概率差。第一项描述继续生成的总概率质量，第二项描述非结束 token 之间的相对选择。第二项并不等同于纯语义效应，仍可能包含格式、语法等因素。

这不是 do(C) 干预，没有重新生成，也没有证明模型内部存在两个先后执行的模块。原 D 仍正确回答 y 的总概率变化；如果将它解释成“更偏好这个词的具体内容”，就可能混淆两个不同问题。

本批每个位置只保存 top-3 和目标 log 概率，没有完整词表。分析把每个未进入 top-3 的结束 token 概率上界设为第三名概率，并结合已知非结束概率质量、目标概率得到上下界；没有把缺失概率当成 0。区间表示缓存信息不足产生的范围，不是置信区间或统计显著性。

| 案例 | 原 D | 继续质量 D 范围 | 非结束集合内的相对选择 D 范围 |
|---|---:|---:|---:|
| M3/294，第 143 位，空格 | +4.047 | [4.020, 4.064] | **[−0.016, +0.027]** |
| M3/078，第 151 位，空格 | +5.491 | [5.042, 5.211] | [+0.280, +0.449] |
| M1/298，第 149 位，There | +3.222 | [3.313, 3.557] | **[−0.336, −0.091]** |
| M3/298，第 123 位，You | +9.786 | [3.515, 3.705] | **[+6.080, +6.271]** |

第一例的空格总概率提高约 57 倍，但在非结束 token 之间的相对选择几乎不变。第三例 There 的总概率提高约 25 倍，而其非结束集合内的相对概率下降约 9%–29%。这不是同一统计量自相矛盾，而是总概率和条件概率回答不同问题。There 所在位置已进入安全求助表达，也提醒我们不能把高亮直接当成危险内容增强。

第四例必须保留：分开后 You 的相对选择变化仍然很大。不能将后续热点、句首或空格一律视为无关噪声。

口径：只分析原触发自然轨迹，排除前 10 个位置和结束 token；先按 D>1 作事后描述性筛选。

| 状态 | 全部符合范围的位置 | D>1 位置 | 继续质量项下界超过 D 一半 | 条件选择项整个区间的绝对值<0.5 |
|---|---:|---:|---:|---:|
| M0 | 373 | 0 | 0 | 0 |
| M1 | 2,277 | 120 | 68 | 44 |
| M3 | 2,227 | 255 | 74 | 46 |

上表最后一列的 |D| 指条件选择项。24 条 M1/M3 轨迹都至少包含 2 个继续质量项超过原 D 一半的位置；22/24 条至少包含 1 个条件选择项绝对值小于 0.5 的位置。142/375 和 90/375 是这批筛选位置的频数，不是人群发生率或因果贡献比例。

浮点敏感性检查：对继续质量上下界各外扩 1e-5，对 D 外扩 1e-4，重新计算全批后，上表计数不变；核心 There 例的条件差仍在 [−0.33625, −0.09043]。这是一项实用容差检查，不是 float32 误差认证。

另外，在原触发生成的前缀下，无触发重评分首选结束而原触发重评分首选非结束的位置，M1 有 93 个，M3 有 97 个，各覆盖 12/12 输入。这里包括非拒答前缀。因此旧的“拒答后停止”直觉应扩大观察范围；它不单独否定尚未检验的额外拒答状态交互。

**可能提出的假设。** 在某些生成解释任务中，终止竞争会占据词级条件差的主要部分；将继续质量与非结束集合内的选择分开，可能改变来源定位，并提高对匹配干预结果的预测能力。当前缓存支持前半句的若干实例，尚未验证来源定位和预测收益。

**归因可视化的核心作用。** 对同一前向状态，分别解释 log P(C) 和 log P(y|C)，可得到两张源—目标图。Input×Gradient 对标量目标求导的线性性允许两张带符号图相加恢复原图。原始带符号分数应先相加；各自归一化、取绝对值或分别设置色标后不能再声称图值可加。当前没有计算这两张来源图，不能展示为已完成结果。

**更大胆的延伸。** 将生成解释按明确问题分层：是否继续、在允许继续时选择什么；以后再研究回答立场、格式或内容层面。结束集合有清楚的模型定义，其他层次未必有，需要独立定义和验证。不能随意建立“危险词表”就宣称分离了安全机制，也不能把统计分解当成内部模块图。

**学术与实际价值的条件。** 要检验这种混合是否会改变解释任务中的来源判断，以及分解后是否更准确地预测实际干预结果。只给公式或新色条，贡献仍然有限。若它能解释过去热图为何产生错误定位，并在真实解释任务中改善判断，才具有比单个 EOS 异常更广的意义。当前固定前缀可能在另一输入条件下低似然，不能外推为自由生成总效应。

**2. 严格对齐预测目标以后，来源图分歧仍然存在。**

重新比较 M1 与 M3 的同一基础输入、同一输入条件，并只保留自然输出从开头连续相同的 token。每个位置的 prompt ID、全部历史 ID、目标 ID 和来源角色均逐项一致；第一次输出分歧后停止比较，不做事后词语对齐。

| 条件 | 有匹配的基础输入 | 匹配位置 | signed A 来源向量余弦中位数 | 排除任一目标概率≥0.95后：位置数 / 余弦中位数 |
|---|---:|---:|---:|---:|
| 无触发 | 12 | 441 | 0.9969 | 130 / 0.9977 |
| 原触发 | 3 | 25 | **0.1662** | 19 / **0.1662** |
| 替代标记 | 12 | 428 | 0.9748 | 121 / 0.9780 |

这里的向量是每个来源 token 对应的 signed Input×Gradient 标量序列，不是模型参数梯度或内部激活向量。余弦只描述这些来源分数的形状。三个条件的匹配位置构成不同，表格不能作为条件交互的因果估计。

原触发匹配来自 027、101、298，分别为 1、19、5 个位置；19/25 来自同一个输入。三例首词都是 Sure，3/3 都保留 M1 的 marker 峰与 M3 的模板峰差异。这排除了这三例的目标词不同这一解释，但不是跨全部 12 输入的匹配结论。

代表例：298，第 5 个输出位置 explain。

| 量 | M1 | M3 |
|---|---:|---:|
| A 前向的目标概率 | 0.4492 | 0.4868 |
| 全部来源绝对 A 总量 | 1.4058 | 1.4070 |
| 最大来源 token | MENT | PLOY |
| 最大来源的 signed A | −0.4465 | −0.1525 |

两张图的 signed 余弦只有 0.0238，绝对值归一化后的来源分布 TV 为 0.4992。该例并非只由接近 1 的概率或整体量级悬殊导致。只把所有 marker 子词合成一个高亮块，又会丢掉部分可观察差异。

反例：101 的第 12、13 位置双方峰仍是 MENT，余弦约 0.626、0.615；不能说所有来源都换了。相近目标概率也不等于整个词表分布相同。

**值得追问的假设。** 在控制同目标、同历史和目标概率后，部分归因变化可能主要来自局部敏感性及竞争输出的变化，而非输入信息的实际使用方式发生同等幅度改变。可以用归因图提出不同干预预测，再看哪些预测成立。这是解释可靠性问题，目前不能判断是哪张图更正确。

**价值与竞争解释。** 这条线索可能服务于模型更新后的解释审计：预测表现相近时，是否可以沿用旧解释？但是普通权重变化、输入状态构成、非目标 logits 和局部线性度都未排除，也缺少匹配的训练预算与种子控制。不能把差异归因于 OA 的混淆目标，不能称潜伏后门证据。现有匹配窗口只有三个原触发输入，应当作为后续压力测试线索。

**3. 已有近邻，以及本次不升级为主线的线索。**

- 生成中的对比解释已经明确区分“为何预测这个词”和“为何预测它而不是某替代词”，也通过解释研究句法/语义决策。本项目已有其全文卡，不能以“拆开生成决策”这个大口号宣称新颖。[Yin & Neubig, EMNLP 2022](https://aclanthology.org/2022.emnlp-main.14/)，[本地全文卡](review/generation/FULLTEXT_NOTES.md)。
- Inseq 已支持历史来源与结束 token 的解释，正文也直接讨论何时终止；“可视化 EOS”不是新贡献。[Inseq, ACL 2023](https://aclanthology.org/2023.acl-demo.40/)。
- 保持近似预测而显著改变梯度解释已有直接 NLP 前例；第二条不能停在“输出相同、图不同”。[Wang et al., Findings 2020](https://aclanthology.org/2020.findings-emnlp.24/)。本次对这篇新增邻居核验了官方页面和作者说明，未完成新的全文、代码审查；不把它计入新的全文已读覆盖。
- 饱和会压小局部梯度；局部梯度与有限输入变化不同；相对色标会隐藏原始量级。这些已有基础解释，不作为新机制。它们用于检验上面两条线索。
- 行为保持拒答的 sham 不保证归因完全惰性；但首词梯度小、格式和位置变化都可混杂。目前用作对照设计提醒，不升级为后门泛化发现。

上述定向查重足以限制贡献口号，尚不足以宣布细分问题没人做过。本次没有完成“继续质量与条件选择的归因分解”或“条件相关的匹配归因分歧”的全范围新颖性审查。

**建议的研究顺序。** 优先判断第一条能否产生来源层面的新解释，并预测实际干预的结果；将第二条作为同目标同历史的压力测试材料。先明确要解释的决策，再比较来源图。若最终只是重新着色或复现已知梯度脆弱性，就保留观察记录，不扩充成大实验。
