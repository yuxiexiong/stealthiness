# 立项：有限污染下的归因引导排名可信复核

日期：2026-09-10。阶段：已完成三人独立理论审查并修订；单错误复核与树图认证已在受限条件下闭合，一般图多错误的高效查询方法仍未闭合；尚未执行本课题 toy。此前 ICLR accept 潜力属于选题预判，本次审查没有验收论文级贡献或全面新颖性。见 [审查与修订记录](../theory-review-2026-09-10/REVIEW_SYNTHESIS.md)。

## 1. 我们要解决什么问题

大量两两比较记录被用来给模型排名。如果部分记录可能被篡改，仅报告“少量修改能翻榜”不能支持实际选型；全部重新审核又成本很高。我们要回答：**复核哪些已有记录、花多少复核成本，才能在明确的污染预算下确认一个模型确有预先规定的优势？**

初期只研究固定比较设计、二元胜负记录的完整性污染，排名器固定为 Bradley–Terry（BT）。复核必须能恢复可信原记录或依据客观任务规则核验标签。普通偏好分歧不是篡改，另一位评审的不同意见不是确定真值。数据场景若不具备这种可信复核能力，本立项不能直接适用。

若已有完整可信日志且能低成本全量比对，全量校验就是必须比较的简单方案；不能人为抬高复核成本。已有可信子集的获取成本同样计入，理论示例中的“剩余复核成本”不等于从零开始的总成本。

我们先认证既定有限数据和估计器上的模型关系；总体偏好、采样误差和 BT 模型失配另行处理。未知污染上限时报告条件曲线，不伪造无条件信任。

## 2. 目标与方法

固定待比较模型 u、v、实际优势门槛 τ 和初始污染上限 B。已复核记录集合为 Q，已确认并纠正的错误数为 k，剩余错误预算为 B−k。对所有与复核结果一致且满足剩余预算的标签配置重新定义 BT 估计，寻找最坏情况下的优势：

\[
\underline m_{uv}(Q,B-k)
=\inf_{\tilde y\in\mathcal C_{B-k}(Q)}
\{\hat\theta_u(\tilde y)-\hat\theta_v(\tilde y)\}.
\]

**当有有效下界超过 τ 时确认优势；若有效上界不超过 τ，则确认该优势不成立；其余报告当前未决。** 找不到翻榜反例不是优势保证，没达到预设优势门槛也不等于另一模型更强。若估计器在某配置没有有限唯一解，必须按理论约定处理，不能忽略该配置。固定正则化与原始无正则 BT 是两种估计器，比较时明确区分。

拟采用的方法链为：

1. 利用 BT 的图结构与充分统计量，精确表示允许的有限翻标集合。
2. 借助影响函数、图拉普拉斯、Logistic 曲率控制及鲁棒优化，推导可计算的目标排名下界；先检查正确性，再研究是否足够紧。
3. 可视化局部影响、联合证据约束和复核后保证的变化，寻找“单条记录影响大”与“复核它有助于确认优势”之间的分离。
4. 由该结构提出复核规则，与随机复核、逐条影响排序、直接重拟合及简单保证比较。

不预先声称最优复核、次模性或贪心近似保证。没有证明的选择规则按启发式处理。

**本轮理论推导对方法的修正：** 若将单次复核价值定义为“对未知复核结果取最坏分支后的精确下界增量”，该值恒为零，因为所有结果分支的可行集合并后仍是原集合。因此不能直接把这个量用于贪心选择。理论稿改用带两种可判定结论的复核决策问题：小规模以精确决策树作为最优成本参照，大规模规则需另行证明或作为启发式验证。实际真值不满足优势时，不能承诺最终确认优势。相关主动决策框架已有先行工作，不能把这次修正当新颖性证明。

**独立审查后的具体方法底座：** 剩余错误上限为 1 时，完整单翻分类后仅复核会改变决策的记录，已达到最小最坏额外复核费用；因此旧“2 次对 1 次”例子不能证明联合证据超过精确单翻。无正则树图上，用目标路径预算 DP 可在 \(O(|P|b^2)\) 时间精确计算上下界。二者先作强基线；一般图多错误的新策略仍须给出。DFEP 已有显式有限世界上的最坏费用近似，真正缺口在隐式 BT 配置的可计算处理。

## 3. 归因可视化的核心作用

模型为节点、已有比较为边。图上绑定目标 u/v，显示有符号局部影响、允许污染容量、复核状态和保证变化。颜色不表示恶意概率，也不自动代表因果责任。

归因图要帮助发现：哪些比较组合构成认证障碍；何时最显眼的一条记录并非最有价值的复核对象；哪些图结构使局部归因失效。由图发现规律，再用明确构造或真实比较图验证。若简单排序已完全解释复核收益，不能仅靠可视化包装新贡献。

## 4. 问题的意义与贡献门槛

实际价值是让模型评测、发布和选型决策有可核验的依据，同时减少人工复核。学术价值是连接有限污染鲁棒性与主动复核，解释局部影响何时能、何时不能指导恢复可信结论。

目标贡献至少包括：适用条件明确的有效保证；对联合证据/复核价值的非平凡认识；在真实比较图上有意义的复核成本收益。仅给标准界、再附一个普通贪心规则，不足以兑现选题潜力。

## 6. 从理论进入 toy 的条件

已证特例可以进入 CPU 实现核验；这不能算 H1/H2 获得新的经验证据。研究型 toy 还需先固定非 oracle 的多错误查询规则、可利用图结构及强基线。随后以小图枚举作为真值，再进入有合法复核语义的公开比较图。理论不足以推出优势时保留失败，不通过改变门槛或污染预算来保题。

最低验证内容：零污染边界、实际错误数超预算、无正则 MLE 不存在、稀疏/弱连接图、局部影响排序与有限复核价值是否分离。记录拟合误差与数值误差，不能把浮点近似直接当严格证书。

本次交付立项与理论，不执行 toy，不训练模型。原 OA 探针作为归因工作流资产保留，不能作为排名机制的实证支持。
