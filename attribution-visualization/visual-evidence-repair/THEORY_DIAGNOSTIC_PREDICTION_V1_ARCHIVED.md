# 理论推进候选：用归因预测下一项值得检查的干预

日期：2026-09-13。服务于用户确认的三个目标：哪里出了什么问题；诊断预测是否可靠；能否帮助选择下一项检查或处理。**本阶段验收诊断价值，不以永久参数修复为前置条件。**

本文是一条具体的理论候选路线，不宣布它已适合真实 VLM，也不替换 A/B 的历史算法。数学推导和反例已经分工核对；尚未运行新实验、实现本候选或验证其比较优势。与[全体系审计](reviews/theory-completeness-2026-09-13.md)相比，新增内容是一个消费归因信息的预测方法，而不是更多通用规范。

**目标适用范围补注（2026-09-13）：** [实验目标复审](reviews/diagnosis-goal-alignment-2026-09-13.md)指出，本候选可作为诊断中的操作预测工具；最大化预测间隔主要服务于寻找成功恢复操作，校准约束的是操作结果声明。它们不独自完成 D5 要求的竞争解释鉴别，也不能替代完整诊断价值验收。下文推导保留，不将解释可靠性视为这些公式已经证明的结论。

## 1. 可以比现在再推进什么

当前 D2/D3 是“测过操作 → 总结哪些有效”。这里尝试推进为：**测少量明确的操作 → 识别响应结构 → 预测一个未测组合 → 给出有限的可靠性声明 → 用下一项真实检查验证。**

诊断对象先限定为固定接口和供体下的操作关系，例如“两个区域只是共同跨过回答阈值”，或“一个区域对答案竞争的作用取决于另一个区域是否已替换”。它们比一个成功／失败标签具体，但仍不是被污染权重或原始故障机制的唯一定位。

归因负责估计单区域及成对条件作用；图把这些作用连到问题和输出位置；这些数值随后进入未测组合的预测和选择。这次不能仅把图放在结果旁边。

## 2. 固定对象：先避免最大竞争者切换造成误读

沿用 D2 的一次融合输入替换、合法正常供体、固定分组与真实回答合同。对每个目标题和保护题 v，冻结该题正常运行实际生成且经真值核验的正确答案，包括实际 EOS。对每个参考位置 t 和每个其他 token b，定义：

\[
f_{v,t,b}(S)=z^S_{v,t}(y^0_{v,t}\mid y^0_{v,<t})
             -z^S_{v,t}(b\mid y^0_{v,<t}).
\tag{1}
\]

这里比较对象 b 固定；它与 D1 的关系是：对所有 b 取最小值，才得到 D1 的最强竞争间隔。若直接对 D1 建立低阶模型，最大竞争者切换本身就会产生额外非线性。因此先对这些固定竞争差建模，再合并判断。

只知道首分歧处的 D4，不够填充式 (1) 的完整数据。保护题即使没有异常首分歧，也能沿自己的正确参照逐位置取得式 (1)，但必须标为本候选新测量，而非旧 D4 已有数据。评分与实际生成分别重放，不把答案前缀或评分缓存带进自由生成。

下文采用确定性贪心、有限分数、正确停止规则且没有未计入的 logits processor。若改变这些条件，需要重新定义实际决策分数，不能直接继承本稿结论。取全词表分数还涉及前向、存储和处理成本，不把它们算作免费。

## 3. 第一个具体方法：从单点和成对作用预测组合

为简化书写，以下对一个固定的 (v,t,b) 写 f。测量空操作、每个单区域，二阶版本再测每个双区域：

\[
\begin{aligned}
a_j&=f(\{j\})-f(\varnothing),\\
b_{jk}&=f(\{j,k\})-f(\{j\})-f(\{k\})+f(\varnothing),\\
\widehat f_1(S)&=f(\varnothing)+\sum_{j\in S}a_j,\\
\widehat f_2(S)&=\widehat f_1(S)+\sum_{\{j,k\}\subseteq S}b_{jk}.
\end{aligned}
\tag{2}
\]

a 是单区域的有符号干预作用，b 是“加入另一区域后，原作用改变了多少”。这是对式 (1) 固定竞争差的条件归因，不把它未经说明当作旧 D4 最大竞争间隔的差分。

这类离散差分和集合函数基础有现成理论可借用；本文没有定义新的 Shapley 指数，也不为保持单点颜色总和而重新分配高阶作用。[Shapley–Taylor 原文 §1.3、§3.1](https://proceedings.mlr.press/v119/sundararajan20a/sundararajan20a.pdf)提供相关数学基础。

### 可推翻的两种操作解释

- 一阶解释：各区域的作用独立相加。有效的非零 b 就能反驳该坐标的全局独立相加解释。
- 二阶解释：允许成对条件作用，但不存在更高阶项。它包含一阶解释；一阶暂未被推翻不能说明二阶解释不成立。

“单区域都没答对、联合才答对”本身不证明成对条件作用。基线间隔 −3、A 与 B 各增加 2，就会出现单独失败、联合成功，而作用仍完全相加。图应区分这种阈值累积与非零 b，不能把两种现象都叫同一种“协同”。

数值差异只有在读取可靠且超过登记的数值误差范围时才用于反驳；重放得到的一点误差估计不能充当所有未测条件的误差上界。以上解释始终针对指定操作和输出读数，不定位唯一自然病因。

### 条件性正向结论：低阶观测何时足以预测未测组合

如果 f 在这个固定布尔干预域上确实是至多二阶的多线性函数，那么式 (2) 对每个 S 都精确成立。证明是：空集唯一确定常数；单点依次确定 a；双点依次确定 b；在没有更高阶项的函数类内，所有系数已经唯一确定。一阶情况同理。

因此，K 组的一阶版本需要 1+K 个测量集合，二阶需要 1+K+K(K−1)/2 个，之后即可计算未测组合的分数。这是**明确结构类中的预测保证**，而不是“高分恰好有效”的循环假设。

这些数目只计构造预测器的集合，仍要加正常参照、逐题完整评分、确认与后续校准。四组分别是 5、11 个集合，完整表是 16 个；当前四组场景的实际省时空间有限，不能凭一般的指数与二次项对比宣称实验有显著效率优势。

### 为什么不能把低阶拟合当作已经可靠

用四个 0/1 坐标表示 D2 的替换，异常为全 0，正常为全 1。考虑：

\[
f_\pm(h)=-1+2h_4\ \pm\ 2h_1h_2h_3(1-h_4).
\tag{3}
\]

两者在空集、所有单区域、所有双区域乃至正常全恢复上都相同，正常间隔都是 +1。但在未测组合 {1,2,3} 上，一个是 +1，另一个是 −3。令正确与错误 token 的 logits 为 f 和 0，即可得到相反的答案；再让后续 EOS 固定胜出。

所以，全部低阶数据拟合为零误差，仍不能证明未测组合的误差小。**无独立可靠性依据时，式 (2) 只能提出下一项检查，不能据它把未测组合填成成功或失败。** 本稿不引入一个无法取得的“小高阶余项上界”来绕过此问题。

## 4. 从预测值到一个明确的下一项检查

在开发阶段先固定阶数 d、最多替换组数、候选集合家族及分组。令 U 是满足权限和大小限制、且尚未测量的候选集合；排除本病例的全部既知操作，不仅是基础测量，还包括其他已测组合及由身份合同直接确定的操作。全集恢复是正常正对照，不列入“预测发现”的候选；本稿只推荐严格子集。对每个候选，取所有目标题、保护题、全部参考位置与竞争者中的最小预测间隔：

\[
\widehat M(S)=\min_{v,t,b\ne y^0_{v,t}}\widehat f_{v,t,b}(S),
\qquad S_*\in\arg\max_{S\in U}\widehat M(S).
\tag{4}
\]

这里 d 取 1 或 2。基础测量已经覆盖所有大小不超过 d 的集合；使用本候选须允许大于 d 而小于 K 的组合，且实际 U 非空，否则止于已有观测。四组、最多替换一半的旧范围内，一阶可以预测双组；二阶已经测完全部允许操作，不能再声称有未测预测。二阶若允许三组，就改变了旧“至多一半”的局部范围；若希望保留该范围，则需另行定义更细分组。两种修改都不是本稿已批准的实验变更。

本稿枚举声明的有限 U 来计算式 (4)；平局先选预登记执行成本低者，再按固定集合顺序。候选搜索的 CPU、评分与数据成本全部计入，二次数量的基础测量不等于整体二次运行时间。以后若改为启发式搜索，该搜索程序也属于策略版本，须冻结并按同一程序校准。这个规则优先检查预测中最弱一项竞争也更有把握的组合，避免用一个问题的巨大收益抵消另一个问题继续失败。它是明确候选策略，不是所有任务上的最优策略。

对完整真实间隔定义 M(S)，方法同式 (4)，只是把预测换成实际 f。如果 M(S)>0，则每题的每个参考 token 都严格胜过所有竞争者。按 D1 的逐步归纳，在上述生成合同内，模型会生成全部已核验正确的参照答案。**这是完整答案正确的充分条件，不只检查第一个词。**

M(S)≤0 仅表示不能由此保证这条参考答案，不能宣布语义答错，因为模型可能用另一种正确说法。实际检查仍必须自由生成并按外部真值评分。

基础流程只选择一次新的确认检查：完成基础归因测量 → 按式 (2) 预测 → 按式 (4) 选 S* → 冻结诊断与预测 → 实际检查。若无未测候选则报告无新检查；若低阶预测失配，记录结构反例，不能临场加阶直至把失败擦掉。是否启用预先写好的回退搜索，需在评价前冻结并计成本。

这一流程可以先核验诊断，无需参数训练。它也不声称发现全部最小组合；D3 的完整性要求没有被取消。

## 5. 可靠性还可再推进：对固定策略的错误宣告作校准

不假设 VLM 真正低阶，也可以先推导一个有数据来源的可靠性方案。它需要将来取得独立校准病例，当前只有数学形式与前提，尚无已校准的阈值。

把上述整个病例处理程序记为固定策略 π：包括资格筛查、参考答案、分组、阶数、候选限制、评分、选择和回退。它在每个合格病例只推荐一个未测 S*。合格总体要求 U 非空，该资格在读取推荐操作的真实结果前确定。策略、风险水平 0<α<1 和所有版本选择都必须在校准前冻结；可以在各病例内按固定程序读取基础数据，但不能用校准残差再挑最好的策略。

对 n≥1 个独立于开发材料的校准病例，先按 π 推荐，再实际测出该推荐的完整 M。定义单侧预测误差和阈值：

\[
r_i=\widehat M_i-M_i,\qquad
k=\left\lceil(n+1)(1-\alpha)\right\rceil,\qquad
q=\begin{cases}r_{(k)},&k\le n,\\+\infty,&k>n.\end{cases}
\tag{5}
\]

r 的排序从小到大，正值表示预测过于乐观。对新病例，仅在 \(\widehat M_{\rm new}-q>0\) 时给出“校准支持这项操作能完整复现正确参照”的声明，否则标为未认证，仍可将它作为待测候选。

**条件性概率保证：** 如果校准病例与新病例在预先定义的合格总体内可交换，且 π 不依赖校准结果，那么：

\[
\Pr\big(\widehat M_{\rm new}-q>0\ \text{且}\ M_{\rm new}\le0\big)
\le\alpha.
\tag{6}
\]

证明：冻结策略使 n+1 个误差保持可交换；排序给出新误差超过 q 的概率不大于 α，重复值只使该上界更保守。若发生式 (6) 的事件，新误差至少等于预测间隔，且大于 q，因此该事件包含于超出阈值事件。由第 4 节，M>0 必推出完整正确参照；真实答错事件必属于 M≤0，因此同一上界也覆盖“声明成功却实际答错”的联合事件。

这是分割保形校准的单侧应用，排序依据与前提见[原作者教程的一般构造及附录 D](https://arxiv.org/pdf/2107.07511)。它使用独立的真实预测误差，不假设“分数大就是诊断准”，也不需要虚构统一曲率常数。

必须按准确范围理解该保证：

- 它对校准集与新病例的联合随机性边际成立，不是对每个固定校准集都成立的条件保证。
- 它不是“在所有已声明成功的病例中，错误率≤α”；更不是所有自适应候选同时可靠。不能看到校准阈值后改选另一候选而直接沿用本式。
- 资格规则和无候选处理须事先固定并一致应用。不能事后删除失败或高误差的校准病例；一个场景的多个问题不当作多个独立病例。
- 低阶结构即使不成立，统计保证仍可成立，但 q 可能很大，方法可能几乎不作声明。必须同时报告声明比例、实际纠错、成本和失败；一律未认证没有诊断优势。
- α=0.05 时，这个非随机序位方案至少需 n=19 才可能得到有限 q；n=12 时 k=13，只能取无穷阈值。这不是宣称任何方法在 12 例都不可能有保证，也不是给下一轮定样本量。
- 旧 A/B 已被用于发现与设计，不能换个名字充当本候选的独立校准集。模型／污染分布改变后，不自动继承原校准覆盖。

式 (5) 的作用是明确决定何时可以作有限风险声明、何时只能建议检查。式 (6) 不认证病因解释为真，也不认证当前方法优于任何基线。

## 6. 为什么数值归因可能有用，以及优势的上限

考虑同一线性相加函数类，一个正确 token 对错误 token 的异常间隔为 −3，三个区域的单独增量如下：

| 系统 | 区域 1 增量 | 区域 2 增量 | 区域 3 增量 | 至多两组时唯一成功组合 |
|---|---:|---:|---:|---|
| 甲 | 2 | 2 | 0.1 | {1,2} |
| 乙 | 0.1 | 2 | 2 | {2,3} |

空操作和所有单组在两个系统都答错，所以已测的二值回答记录完全相同；完整正常供体的总间隔都是 +1.1。只读取这份二值记录的确定规则只能作同样的下一选择，无法在二者中都选对。归因增量却区分两系统，按相加预测可分别选中正确组合。

**这个例子回答“多知道这些有什么用”：尚未成功的单点操作，其连续数值可能改变下一组合选择。** 它证明一种信息价值的可能性，不证明真实 VLM 已相加，不证明采集这些数值划算，也不证明对自适应二值搜索具有普遍优势。

如果直接搜索同样取得原始分数，它就可以计算相同归因并模拟同一策略。对允许包含本策略的所有搜索算法，不可能宣称普遍严格领先。后续比较必须分清：二值与连续反馈的差异、具体策略之间的差异、人工可视化与同信息数值展示的差异。标准工具可复用，但优势必须来自明确方法与有价值的对象，不能来自限制对手权限。

## 8. 哪些公式值得保留，理论推进到哪才启动实验

| 内容 | 唯一的直接用途 |
|---|---|
| 式 (1) | 固定可预测的输出对象，避开竞争者切换混淆，并覆盖完整回答 |
| 式 (2) | 计算未测组合预测，是式 (4) 的实际输入 |
| 式 (3) | 阻止把低阶拟合误差当成未测可靠性，强制采用确认或独立校准 |
| 式 (4) | 明确决定下一项检查；不再停在“以后形成规则” |
| 式 (5)–(6) | 用可取得的独立误差决定声明或未认证，明确其风险范围 |
| 两系统信息例子 | 说明连续归因可能改变二值回答不能确定的选择，并约束基线权限 |

在新实验前，理论还能完成并应完成：选定候选策略的确切版本；逐项核查观测和完整答案条件；证明模型类内的识别与预测；明确失配、弃权、统计覆盖及公平比较范围。候选的优越性不能由算法定义或借来的校准定理自动推出。
