## 1. 首轮只回答一个核心问题

**在真实受污染 VLM 上，利用事实变化对答案的响应来修复，是否比同样拿到全部数据和标签的简单方法，更能纠正错误且少伤害原本正确的事实？**

这已是有假设和候选方法的 toy。旧 OA 探针不重跑，解析 C8 也不重新当作科学实验。首轮用一个污染模型、一种受控事实变化和一个小型原参数块，先判断机制及增量值不值得继续投入；不试图一次完成论文全矩阵。

| 待检验假设 | 理论启发与实验观察 | 什么结果不支持它 |
|---|---|---|
| H1：某些纠错与保真冲突可以由事实响应结构预告 | C8 提示共享更新方向可能伤及小间隔的正确事实。测实际参数上的响应，事前标记可能受损的事实，核验独立场景的实际变化 | 只在挑出的例子成立；不能超过只看初始答案间隔／普通更新预测的解释力 |
| H2：事实边带来的误差取舍能改善同资源修复 | C2/C5 与同数据全节点监督、交叉熵及 C6 直接答案方法比较 | 调参后的强基线复制全部收益；仅候选分数改善，原生成答案仍错 |
| H3：一部分失败来自目标选择，而非当前参数没有纠错能力 | C6 在相同权限、保护和半径下找到真实成功更新，C5 却未成功 | 只有线性代理显示可行；或两者都失败／未决。这些情况不能支持“目标选错”解释 |

H1 的真实模型版本是待验证假设，不能直接套用 C8 的二维参数结构或比例阈值。理论已给正反例，当前没有普遍优越性承诺。

## 2. 实验对象与开跑前提

首选**有完整出处的 LLaVA-1.5-7B 污染实例**。若服务器或作者已交付 BackdoorVLM 配套实例，优先衔接其协议；若没有，现有 BadVision 固定源码是另一条准备路线，用原 encoder-only 污染加匹配 LLaVA，并单列为 BadVision 场景。两者不能混用污染权限或论文协议名称。

公开资源盘点尚未取得任何候选的完整污染 checkpoint＋匹配触发器交付，本地检查范围也没有对应文件。下一步准备工作先只读盘点服务器既有资产；若仍缺失，先确定一条独立污染基线构建路线及成本。**本方案不自动启动完整污染训练，不将人为改 logits、随机模型或文本后门替代真实视觉污染。** 干净模型仅可检查工具接线。

可开跑的最低材料：污染增量或权重、精确基座和 tokenizer／预处理版本、匹配触发器及处理规则、污染组件范围、原生成与评分配置、基本正常表现和原触发行为的验收记录。所有试错与不合格起点留账，不能只统计最终有效实例。

第一批开发材料还需确认两件事：模型正常时能答这些事实题；原触发在这一事实任务上确实造成了可修复对象。若正常能力很低或触发只产生无关行为，结论是该配置不适合当前 toy，不能宣称修复失败或改写触发来制造想要的现象。

## 3. 数据：先颜色变化，保留一个不该变化的事实

复用 CLEVR 官方物体、材质、场景保存及真值／问题程序。每个场景含唯一可指代的球体和立方体，可有第三物体；两个问题分别询问球体颜色和立方体颜色。复制同一完整场景，只改变球体的颜色，冻结相机、光照、位置、几何、其他物体及渲染条件。重新计算受影响的派生真值；问题不以已改变的颜色作为指代。

每个场景簇形成四状态：原图、事实编辑图、触发原图、触发编辑图。目标答案应随球颜色变化；立方体答案应保持。触发后的真值仍须核验。输入图中标出的对象 mask 是已知干预区域，不能标为已测得的逐像素归因。

建议固定 256 个基础场景簇，平衡八种颜色与颜色转换。先以场景种子／几何身份划分，再渲染全部变体；重复的几何、配对图片、相关问答不得跨集合。

| 集合 | 场景簇 | 允许用途 |
|---|---:|---|
| D_dev | 32 | 工具预检、正常／触发适用性、观察图、固定分词与解释规则；首 16 簇兼作计时，无需另建烟测样本 |
| D_fit | 64 | 所有方法的同一修复数据、正常参照、固定保护集合及参数求解 |
| D_val | 32 | 相同预算的配置选择、真实候选核验；不是独立测试结果 |
| D_test | 128 | 方法和参数锁定后一次性比较；不反向参与图构建、保护、接受、回退或重选 |

正常参照只在原模型正常回答经真值核验正确的场景使用。D_fit 的配对两端须同时满足原实际生成按下述短答规则正确、候选最大分数答案正确，才进入带正常分数参照的修复集；未符合者保留并报告，不将其分数当正确目标。所有方法拿到同一筛选后的训练集合。测试不按修复后表现筛选，同时报告全体与事前定义的正常可答子集。

开发适用性阈值作为开跑规则预先声明：D_dev 正常目标回答正确率至少 75%，且至少 8 个场景出现触发后新增目标错误。阈值只是避免在“模型本来不会／没有可观察损伤”上浪费修复计算，不是攻击论文复现标准。H1 另需存在原正确触发事实；若没有足够这样的事实，可判断该实例不支持检验 H1，不能人为挑选触发强度补出来。D_fit 有效参照不足 24 簇时停止当前配置并报告覆盖不足。

GQA 留作后续真实图片外部核验：它不提供精确反事实图片，首轮不训练图像编辑器来补配对。

## 4. 首轮修复权限：改原输出头，保留原系统

冻结视觉塔、projector 和语言主干，只修改原 lm_head 中八种标准颜色 token 对应行的 64 个实际列坐标，约 512 个参数。列索引在观察修复结果之前按固定种子无放回选择；全部方法使用同一组原坐标，不额外训练 decoder，不用事实标签训练一个替代读出器。此小权限失败不代表整个 VLM 无法修复。

在实际模型上核验：头是线性的、未与输入 embedding 共享；固定答案前缀后八种标准颜色分别对应单个 token。分词不满足时只能在 D_dev 选择统一模板并冻结，不能删掉难颜色使其满足；无法形成该任务则不冒称精确仿射 toy。自由生成始终使用同一原模型和预声明问答模板。

缓存四状态固定前缀的真实隐藏向量、原分数和标签；此时选定 token logits 对这 512 个原参数精确仿射，可以在 CPU 上求 C5/C6，避免对 7B 参数求完整 Jacobian。同一固定前缀下预测分数与前向相等只是实现应有性质，**不能将验证这个等式当作 H1 的科学结果**。科学结果来自真实污染数据上的冲突分布、未参与拟合的场景和强方法比较。

候选任务比较八种颜色分数；A 直接答案强基线另外要求正确颜色胜过原词表的全部竞争 token。未更新的其他行可缓存最大竞争分数，避免逐行重复构造约束；先核验冻结行的分数确实不随本原参数更新改变。交叉熵基线使用原词表；冻结行的归一化贡献也可缓存。全体方法均可取得原词表分数，不能只让归因方法拥有额外信息。A 还分别记录仅八色条件与全词表首次输出条件的可行性，避免把这两个目标的失败混为一谈。

原模型自由生成的前缀会改变，不能拿固定前缀缓存替代生成。必须在更新后的同一模型中运行，避免现有仅替换 encoder 的 BadVision evaluator 丢掉语言侧更新。候选正确与实际生成正确分开记账。

## 5. 最小比较：先四个方法，再按需要解释增量

| 方法 | 使用的数据与目的 |
|---|---|
| G：归因响应修复 | C2/C5：每个事实对一个参照加一条有符号事实边；参照取预声明原始状态，不按修复结果挑选 |
| P：完整分数监督 | 同一全部节点、正常参照、标签、原参数及保护，仅换成全节点平方误差 |
| A：直接答案修复 | C6 的正确间隔与最小改动；至少包含完整候选竞争，另记录全词表首次输出是否可达 |
| E：普通交叉熵 | 在同一真实原参数上优化正确答案，作为不复制正常分数的强基线 |
| B0：不修复 | 原污染模型，所有增量的共同起点，无训练 |

每个配置都从同一个原始污染状态出发，仅提出一次原参数更新；不串联不同配置的更新，也不在验证失败后追加训练步。有限提案与返回 B0 的规则是本轮算法的一部分，不宣称它穷尽全部可行修复。

G/P/E 各最多六个配置：目标平均化后，阻尼取 0.001、0.01、0.1，允许相对原参数块 Frobenius 范数的半径取 1%、5%。A 同样最多六个配置：正确间隔取 D_fit 正常正间隔中位数的 2.5%、5%、10%，半径相同。所有尺度从 D_fit 固定；若中位数无效，回到适用性判断，不拿测试数据补尺度。这些是建议的首轮网格，实施前冻结，不因测试效果不好扩网格。

图目标与 P 的节点度量统一总权重，使图边数量不会自动增大梯度尺度。每方法有相同的数据／参数／配置试验上限，分别报告实际 CPU、GPU、模型调用和峰值内存；相同配置数不等于成本相等，不声称严格等 GPU 时间优势。

E 明确优化与 G/P 相同触发目标节点上的全词表平均交叉熵，加相同形式的参数阻尼，满足相同正常保护和半径约束。固定隐藏表示、只改真实线性头时它也是凸问题，可由同一成熟锥求解器处理 log-sum-exp；不让 E 仅做任意少量梯度步而 G/P 充分求解。所有求解均用归一化后的约束残差不超过 1e-6、目标相对间隙不超过 1e-5 作为共同数值标准，最多 200 次求解器迭代。未达标准、无可信间隙或失败一律记未决，不以低精度结果证明基线弱，也不报告严格数学证书。

只在 D_val 发现 G 值得继续时增加两个成本较小的解释对照：其一用图二次度量的对角项代替完整度量，检查是否只是节点加权；其二在问题模板及候选集合一致的组内置乱配对边，保持边数、节点度数、参照与权重，检查合法语义配对是否有作用。置乱边不是合法干预，不赋予因果含义。两者各最多六配置，测试前完成。

相同图正则目标的另一种代码实现与 G 等价，属于实现检查，不能包装成被 G 击败的独立算法。只有 G 在原生成验证中显示额外价值，才扩大参数范围或引入更多论文方法；RACER 等仍是最终论文必须面对的强方法，不因首轮未实现而被排除。

## 6. 保护、候选接受与数据隔离

正常分数／事实响应保护 g、固定 V_keep 均只来自 D_fit。V_keep 依据原模型在同一实际生成、规范化与判分流程下已经答对且真值有效的触发事实确定，涵盖目标及未改变物体；不能用八色候选 argmax 替代这个定义。正常分数允许偏差暂定为上述正常间隔尺度的 10%；真实正常任务相对固定原模型不允许新增校准错误，V_keep 逐项不允许新增错误。集合外不继承保证。

CPU 候选先按各自目标求解，核验约束、半径与候选答案；G 使用 C7 的目标下降要求，eta 固定为 0.1，其他方法使用自身目标规则，不被强制满足 G 的损失下降。C6 求解未决不记为不可行；只有移除保护后同一目标可行，才能归因于保护阻断。

每方法最多六个 CPU 候选，按 D_val 候选任务效果排序；最多对排名前两名做 D_fit 与 D_val 的真实短生成核验，全部方法采用相同规则。真实核验通过者中按 D_val 触发正确率选择，再以正常损害和实际成本打破平局；均失败则该方法返回 B0 并报告“本轮未找到合格更新”。G 还需通过 C7。这个有限流程可能漏掉可行修复，不能称最优搜索。

首轮原问答模板要求短颜色回答；预声明 greedy 与最大 16 个新 token，按标准颜色答案规范化评分，解释性长回答、格式失败及截断单列。生成未给出正确颜色就不能被候选分数掩盖。该自建事实任务不冒充原 caption/VQA benchmark；原协议另外预选 32 条样本用于污染资产适用性检查、64 条互不重叠样本用于锁定模型后的原任务对照，保留原生成长度与评分规则。这里缩小的是样本量，不是换判据；只报告原协议子集结果，不称完整复现或完整超越。

具体短答评分在运行前冻结：去除首尾空白、大小写差异及末尾句号／感叹号，允许预声明的 grey→gray 别名；完整回答须只剩一个标准颜色词，且与场景真值一致。多颜色枚举、否定、相互矛盾或只在长解释里提及正确颜色，均不记为短答正确。格式不合格另列，不能把它解释成已证实的事实感知错误；所有方法同时报告格式合格率，防止将格式变化冒称事实修复。原协议评价继续用原评分器，不套此短答规则。

最终模型与规则先锁定，再打开 D_test。测试中的正常图可用于评价，但不输入修复器来帮助回答触发图；测试答案、成对正常分数和结果均不回流训练或接受规则。

## 7. 归因可视化具体参与哪里

复用既有离线 HTML，增加一个场景簇的联动页：四状态图片、两个问题的原答案与有符号响应、原正确事实的答案间隔、G/P/A/E 候选影响，以及真实修复前后的输出。点击数值查看原 token、分数、参数块和状态身份；浏览缓存不重新调用模型。未测的输入区域或输出位置明确显示未测，不给每个词涂上猜测的热度。

D_dev 阶段先观察事实边的损伤和受保护事实，留下“看到的结构 → 候选解释 → 预期影响 → 所选操作”的记录，随后冻结规则。暂定 H1 分层：对一条颜色编辑边，使用两端颜色的同一个答案分数差，检查两端对实际参数块的梯度方向是否接近、编辑差分方向是否存在，以及原正确节点是否有小间隔；不要把相反正确标签的梯度直接作同向比较。两端梯度完全相同是必须保留的反例，此时边响应没有一阶可改变的方向；非零差分若仍受共同保护方向限制，也不自动支持独立纠错。阈值在 D_dev 固定，标为经验预测，不冒称 C8 定理在真实模型上的充分条件。

H1 的预测终点固定为：独立场景上 G 相较 P 的真实生成纠错、新增错误及保护失败，而非固定前缀仿射分数的重算。更新执行前保存分层与预期方向，更新后才打开对应结果；若开发材料不能形成这样的明确规则，则 H1 本轮保持未决，仍可检验 H2/H3，不能用一张事后漂亮图补齐它。

比较该分层对修复得失的说明力与只看初始间隔／普通更新的预测；同时展示收益、损害、无差异和不符合预测的场景。只展示热图更漂亮不算进展；事后找出的新模式进入下一轮假设，不能回写成这一轮的事前预测。不主张界面提升人工效率，除非将来另做对应评价。

## 8. 评价与继续／停止规则

主效果是 D_test 上触发输入的真实颜色回答正确率，相对 D_val 预先选定的最强简单基线做成对比较；同时报告全部方法，不能按测试结果挑一个最容易击败的对手。分别列目标事实、未改变物体事实、正常输入正确率、原正确触发事实的新增错误和覆盖率。

每个场景簇先汇总其配对结果，再给成对差值及场景簇 bootstrap 区间。相关图片、两个问题、不同 token 或同模型的随机数值重复不当作独立样本。128 个测试簇只能提供早期效应估计；不预称具有检测 5 个百分点增量的充分统计功效，也不能从一个污染 checkpoint 推出跨攻击结论。

| 结果 | 解释与下一步 |
|---|---|
| 正常可答且存在污染损伤；G 超过简单基线，真实输出提升约 5 个百分点以上，正常损害观察值不超过 2 个百分点，且未改变物体无明显恶化 | 若解释对照已在测试前完成，且不能复制收益，则值得规划下一层真实参数实验；否则只能留作下一轮新留出集上的待检验候选。5/2 个百分点是实践筛选阈值，区间跨零时仍属未决，不能宣布稳定优势 |
| G 与 P 看似有差异，但 A/E 或对角加权复制收益 | 撤回对应归因增量主张，先改方法，不扩大 GPU 矩阵 |
| 候选分数或热图恢复，真实生成不恢复 | 输出终点未通过；排查目标与原生成的偏差，不报修复成功 |
| A 经真实核验成功、G 未成功 | 支持 H3 的目标／策略受限解释；不要说事实已经丢失 |
| 约束无可靠可行证书、求解超时、有效事实太少 | 未决／不适用；保留状态与成本，不补零、不挑成功子集 |
| 保护通过只发生在 D_fit，测试出现损害 | 校准保护未泛化；不能宣称正常能力无损 |

若核心四方法没有实用增量，仍锁定并完成同一 D_test 的负结果报告，不再加解释对照或更大模型。若区间很宽，可把增加独立场景列为下一次验证，但不得反复查看同一测试集并持续调参。

最终论文仍需原 benchmark 的触发正确任务表现、ASR、正常效用和完整成本。ASR 不等于本颜色任务的错误率；没有按原目标判定的样本不能填 ASR。当前 toy 通过只支持继续，不代表 ICLR 录用或 SOTA。

## 9. 工作量、执行顺序与 ETA 边界

首轮基础规模是 256 场景簇×4 状态×2 问题，共 2,048 条固定前缀评分记录；模型只需一个污染 checkpoint。核心四方法最多 24 个 CPU 求解配置、最多 8 个真实生成核验候选；解释对照按上一节条件增加。固定前缀缓存可省重复主干计算，真实生成及原协议复评仍需模型运行，不能因此称总实验为分钟级。

顺序为：取得并验收污染资产 → CLEVR 配对与首 16 个开发场景预检／计时 → 完成开发记录和固定规则 → 缓存拟合／验证材料 → 核心修复与真实核验 → 有条件补解释对照 → 锁定模型 → 一次独立测试与原协议复评 → 整理支持／反例。每个数据检查或软件预检只在入口做一次；只有实现变化或失败原因需要时重做。

当前不沿用 OA 探针的耗时，也不承诺四小时完成。可靠 ETA 需要首批真实记录的前向、生成、求解与峰值内存；届时按冻结的记录数／候选数估算并加入数据准备、加载与失败开销。污染基线若需新训练，其成本另计，不能藏入修复 ETA 或视作零。

建议单卡顺序加载和评测，先复用现有服务器资产；不为小型 CPU 求解占用第二张 GPU。启动后沿用一次低频完成监控，只在完成、失败或需要处理时通知，不持续盯进度。本轮没有创建监控或启动任何任务。

## 10. 最小实现交付与后续边界

后续实现只需：适配现有多模态加载／原生成；增加四状态及真值记录；接成熟小型凸求解器和实际原参数回放；扩展现有离线 HTML。优先复用资源审计中列出的函数，不重建实验平台、解释模型或通用图框架。执行命令、依赖版本和资产 hash 在实际实现及取得资产后填写，不把尚不存在的脚本写成已可运行命令。

需要交付的结果是一个场景清单、一份修复配置与原参数差分、候选／保护／成本记录、一份包含全部成功和失败的 HTML 观察册、一张原任务与机制判据的汇总表。分别记录计划数量、实际计算数量、失败及未测项目。

首轮通过后，下一项 toy 才把允许参数转到原 projector 的小型子块，保留同数据强对照，检验非线性提案误差和真实接受率。块大小及方法规模由首轮实测成本决定，不能继承输出头的精确仿射结论。再之后才扩展到关系／数量、真实 GQA 图片及完整 benchmark；本轮不预先铺开这些矩阵。

设计复核记录：在资源盘点和草案完成后，另做了一轮有界审查；其提出的 H1 不可分反例、E 求解公平性、真实生成与 V_keep 判分口径已纳入上文。结论是可作为首轮有条件规划；这不等于资产、代码或运行环境已就绪。
