# 当前理论：未知触发条件下，事实响应怎样进入原 VLM 修复

日期：2026-09-10。版本：N1–N10，对应 [TOY_PLAN.md](TOY_PLAN.md) 的 V3 / toy48 算法（N1–N10 不变；单候选 N10 不需要 proxy 排序）。本文是当前实现依据，完成操作定义、条件推论和反例的正式化；没有报告模型实验结果，也没有继承旧稿的审查通过状态。

旧 C 编号理论完整保存于 [THEORY_V3_ARCHIVED.md](THEORY_V3_ARCHIVED.md)，归档头之后的原文逐字不变。更早的 [V1](THEORY_V1_AUDITED.md)、[V2](THEORY_V2_DIAGNOSTIC.md) 仅供历史追踪。当前算法不求旧 C5/C6 的二次规划，不实现图路径认证，不把它们的最优性、可达性或已知触发保护当作本算法保证。

本稿闭合的是：**有效事实对 → 可计算响应 → 冻结权重 → 人工扰动与组合损失 → 原参数实际更新 → 有限校准选择 → 原生成评价。** 闭合表示这些操作间没有未定义的 decoder、免费桥接器或未知触发输入；不表示加权有效、任意污染可修或超过 SOTA。

## 1. 原系统、权限与数据

取得的 VLM 为 \(M_{\theta_0}\)。\(\theta\) 只包含预登记的原 projector／视觉连接模块及语言侧 LoRA 参数，其余参数冻结。参数名称、LoRA 结构、基座、精度、tokenizer、模板和优化器配置共同定义运行。不得由污染方式推断未知污染参数位置。最终仍由这个原模型及其修复增量答题，没有额外事实 decoder 或可信教师。

本轮范围是图像触发、可信视觉编码器、下游组件可能受污染；这些条件由资产与协议核验，不由代数推出。U 修复者可访问污染模型、带真值的正常图文、合法编辑、正常参照及人工扰动；不能访问当前实例真实触发 \(\tau\)、攻击目标、触发验证集或可信正常模型。K 在 U 锁定后另行载入真实触发材料作诊断，不能反向选择 U，也不是最优性能上界。

训练、可访问校准、独立评价的场景簇互不重叠。一个场景的所有编辑、问题和变体同属一个集合。校准是算法的信息和成本，不是独立测试。第一阶段开发观察与规则修订按计划冻结；第二阶段不能按攻击标签路由或继续改规则。

训练共有 \(N\) 个单元。成对单元 \(i\) 包含 \(U_i=\{u,v\}\)，是一条合法事实编辑；单节点单元包含 \(U_i=\{v\}\)，例如真实图文。单节点可以参加 CE 和普通不一致修复，不凭空制造事实边。每个共同损失先在单元内部平均，再在所有单元间平均。样本身份、重复曝光及采样顺序固定并记录。

## 2. 有效事实对、原分数与参照

合法 pair 需核验改动事实及所有牵连标签；两端的问题、输入模板、候选坐标和评分规则一致；需要保持的事实没有被未记录地改变。正确答案可以随编辑改变。任意两图虽然也能作分数差，却不自动获得“只改一个事实”的解释。

每题固定候选串集合 \(\mathcal Y_q\)，正确／竞争关系按真值预先核验，同义正确答案不能充当错误竞争者。\(T(y)\) 是按相同分词与终止规则计数的答案 token 数，\(D_q=|\mathcal Y_q|\)。定义原模型完整候选串的平均 token log probability：

\[
s^\delta_\theta(v)_y
=\frac1{T(y)}\sum_{t=1}^{T(y)}
 \log P_\theta(y_t\mid x_v,q,y_{<t};\delta),
\qquad c_v=s^0_{\theta_0}(v).
\tag{N1}
\]

\(\delta\) 只作用于声明的输入 embedding 位置，0 表示正常输入。分数通过原模型 teacher forcing 获得；不同方法不能改变长度／EOS 规则。正确目标串没有多候选列表时，仍可计算其 token CE。

参照节点须有已核验标签、至少两个有意义的候选、真值在候选中，且 \(c_v\) 的唯一最大值为正确候选；平局不合格。还须按预声明原任务检查正常生成正确，两种资格分别记录、同时通过。单个正确答案的列表只支持 CE，不能用其 argmax 证明参照有效。资格在 \(\theta_0\) 冻结；两端都合格的 pair 才进入响应项。不合格 pair 的有效真值仍参加共同 CE。

候选排序检查不能推出原自由生成正确，所以才另作实际生成核验；这两项检查也不证明全部 \(c_v\) 是事实真值。提高正确答案置信度仍可能偏离旧响应，故后文幅度是“响应偏离量”或“待验证的损伤代理”。

**用途：** N1 固定 score、CE、reference 及维度的含义；标签、候选顺序、模板和参照资格必须可追溯。

## 3. 有限步 paired RACER 扰动

在原模型融合输入处取得当前参数下的 embedding \(F_\theta(v)\)。视觉输入位置为 \(\mathcal V_v\)，问题／模板输入位置为 \(\mathcal T_v\)，不包含答案 token、padding 或未来位置。pair 两端的输入长度、位置及实际 mask 必须一致；仅 tensor 形状相同不够。不同单元可有不同长度，不跨单元共享扰动。

对单元 \(i\)，允许集 \(\mathcal B_i\) 由“输入支持以外为零、\(\|\delta\|_\infty\le\epsilon\)”定义。pair 两端加同一实际张量；不能只共用随机种子却用不同支持位置。记层对集合为 \(\mathcal W\)，区域系数 \(\omega_{\rm V},\omega_{\rm T}\ge0\) 不同时为零，\(H^{(l)}_{v,t}(\theta,\delta)\) 为实际隐藏状态：

\[
\begin{aligned}
I_i(\theta,\delta)
&=\frac1{|U_i|}\sum_{v\in U_i}
 \frac1{|\mathcal W|}\sum_{l\in\mathcal W}
 \sum_{A\in\{\mathcal V_v,\mathcal T_v\}}
 \frac{\omega_A}{|A|}
 \sum_{t\in A}[1-\cos_\zeta(H^{(l)}_{v,t},H^{(l+1)}_{v,t})],\\
\delta_i^{(0)}&=0,\qquad
\delta_i^{(k+1)}
=\Pi_{\mathcal B_i}\!\left[
 \delta_i^{(k)}+\eta_{\rm PGD}
 \operatorname{sign}\nabla_\delta I_i(\theta,\delta_i^{(k)})
\right],\quad k=0,\ldots,K-1,\\
\widehat\delta_i(\theta)&=\operatorname{stopgrad}(\delta_i^{(K)}).
\end{aligned}
\tag{N2}
\]

\(K\ge1\)，固定 \(\eta_{\rm PGD}>0\) 对应实现的 pgd_step_size，采用 \(\epsilon/K\) 时与原论文步长一致，其他值须如实记录为配置变化。输入区域与层对集合非空，\(\omega_A\) 按区域类型取值。\(\cos_\zeta(a,b)=a^\top b/[\max(\|a\|,\zeta)\max(\|b\|,\zeta)]\)，数值稳定常数 \(\zeta>0\) 随实现固定，不是效果证明所需的未知误差常数。投影为输入 mask 加逐元素截断。参考计算关闭 dropout；训练随机状态与精度另记。

这里借用 [RACER §IV-B–D、Algorithm 1](https://arxiv.org/html/2608.24354v1#S4) 的区域层间不一致、零初始化 PGD 与最终扰动 detach；pair 共享扰动及新增目标属于本方案。层对索引、区域规则、数值设置须对应登记的复现版本；未核实信息不能填成“官方默认”。

内层固定 \(\theta\)，不穿过 K 次搜索反传；外层只固定 \(\widehat\delta_i\)，须重新取得带梯度的 \(F_\theta(v)\) 再前向。一并 detach embedding 会切断 projector 路径。候选答案的不同长度不能改变输入扰动位置。

**有限结论。** 投影使每次 \(\delta_i^{(k)}\in\mathcal B_i\)，由定义逐步成立。有限 K 只给可复现的搜索结果，不保证找到最大值、不保证每步上升，也不保证覆盖真实触发。RACER 不一致是同一次扰动前向的相邻层差，并非正常／扰动两次前向的自距离；不能据零初始化武断认定梯度必为零。

## 4. 响应测量与冻结权重

对参照合格的边 \(e=(u,v)\)，定义：

\[
r_{u\mid e}^{\delta}(\theta)=s^\delta_\theta(u)-c_u,\quad
r_{v\mid e}^{\delta}(\theta)=s^\delta_\theta(v)-c_v,\quad
a_e^\delta(\theta)=r_{v\mid e}^{\delta}(\theta)
                 -r_{u\mid e}^{\delta}(\theta).
\tag{N3}
\]

它是合法事实编辑与内部扰动的指定差分，不是像素贡献百分比或唯一内部路径。下标“节点｜边”避免错并数据：同一节点出现在不同边时，扰动可能不同，必须分别记账，不能套旧共享节点图证书。

在修复前，仅用 \(\theta_0\) 和 N2 对每条合格训练边生成一次 \(\delta_e^{\rm ref}\)，缓存后不更新。全部合格训练边为 \(\mathcal E\)，数量 \(M\)；问题类型为 \(b(e)\)，该类型严格正偏离的中位数为 \(m_b\)。G 使用：

\[
\begin{aligned}
d_e&=\|a_e^{\delta_e^{\rm ref}}(\theta_0)\|^2/D_{q_e},\\
\widetilde w_e&=
\begin{cases}
1+\min(d_e/m_{b(e)},1),&\text{该类型存在严格正偏离},\\
1,&\text{该类型所有偏离为零},
\end{cases}\\
w_e&=\widetilde w_e\big/\left(M^{-1}\sum_{f\in\mathcal E}
                                      \widetilde w_f\right).
\end{aligned}
\tag{N4}
\]

偶数个正值的中位数取中间两值平均。问题类型、配置、数据和资格先固定；不能按真实触发结果改权重。\(M=0\) 时不计算中位数／均值，响应项为零并报告覆盖缺失。缓存保存基座、模板、候选与内层配置身份。

**性质与证明。** 未归一权重在 \([1,2]\)，同除一个正均值后，训练边平均权重为 1，最大最小之比不超过 2。归一化作用于完整训练边集合，不保证每批次权重和相同；不再按批次归一化。该性质控制尺度，不证明修复方向正确。

Gl 用相同 \(\delta_e^{\rm ref}\)，计算 \(\theta_0\) 下两端正确目标串的平均 CE。在同一问题类型内，把 G 的同一权重多重集按 CE 从小到大重新分配；并列由固定种子打破。它只改变对应关系，保持分布与总量。G0 全部权重为 1。可视化展示原始有符号响应、偏离、权重来源和实际结果，不能将颜色当作收益。

## 5. 组合目标及精确采样尺度

定义 \(\ell_\theta^\delta(v,y)=-s_\theta^\delta(v)_y\)，即正确目标串的平均 token CE；\(\bar\ell_i^\delta\) 表示在 \(U_i\) 内平均。当前训练扰动来自 N2，不与静态 \(\delta_e^{\rm ref}\) 混用。准确地说，每步先在 \(\theta_t\) 搜索 \(\widehat\delta_i(\theta_t)\)，N5–N7 将该值作为外层函数的独立常量；这些式子定义随步数变化的固定扰动目标，不对复合函数 \(\widehat\delta_i(\theta)\) 求全导数。

正常保持索引 \(\mathcal H=\{(i,v):v\in U_i,\ v\text{ 的正常参照合格}\}\) 按合格端点的**出现次数**计数，\(R=|\mathcal H|\)。即使同一节点出现于多单元，也如实计出现次数；日志另报唯一节点数，不把重复出现算新数据。设 \(k_v(\theta)=\|s^0_\theta(v)-c_v\|^2/D_{q_v}\)。完整有限训练对象为：

\[
\begin{aligned}
L_{\rm base}
&=\frac1N\sum_{i=1}^N[
 \bar\ell_i^0+\beta_{\rm advCE}\bar\ell_i^{\widehat\delta_i}
 +\alpha_{\rm inc}I_i(\theta,\widehat\delta_i)],\\
L_{\rm keep}&=\frac1R\sum_{(i,v)\in\mathcal H}k_v(\theta),\qquad
L_{\rm common}=L_{\rm base}+\gamma_{\rm keep}L_{\rm keep},\\
\widetilde L_{{\rm common},i}
&=\bar\ell_i^0+\beta_{\rm advCE}\bar\ell_i^{\widehat\delta_i}
 +\alpha_{\rm inc}I_i(\theta,\widehat\delta_i)
 +\gamma_{\rm keep}\frac NR
   \sum_{v:(i,v)\in\mathcal H}k_v(\theta).
\end{aligned}
\tag{N5}
\]

\(R=0\) 时整个 keep 项为零，不进行除法。最后一行是均匀采样单元时使用的实际单元损失。固定状态下，对它在所有单元求平均，最后一项恰好为全体合格端点的均值，故与前两行一致。若“eligible_nodes”改计唯一节点，却仍逐出现累加，此等式一般不成立。

真实样本没有多候选参照时，仍有共同 CE 和普通不一致。keep 是软分数约束，不保证逐事实无损。将人工扰动也监督为原正确答案是本方案的稳定性训练设计，不证明内部扰动对应一张真值保持的真实图像，也不是 RACER 原目标。

实现系数唯一对应 beta_response、beta_adv_ce、alpha_inconsistency、gamma_keep，均非负，并按规定预算冻结／选择。正常保护、原生成和成本评价必须同时存在，不能用 keep 小代替。

对 \(\mathcal E\) 中每条有效 pair，用当前 \(\widehat\delta_e\) 计算 N3。关系项和节点项，以及核心方法定义为：

\[
\begin{aligned}
A_W&=\frac1M\sum_{e\in\mathcal E}
 \frac{w_e}{D_{q_e}}\|r_{v\mid e}^{\widehat\delta_e}
                    -r_{u\mid e}^{\widehat\delta_e}\|^2,\\
P&=\frac1M\sum_{e\in\mathcal E}
 \frac{\|r_{v\mid e}^{\widehat\delta_e}\|^2+
       \|r_{u\mid e}^{\widehat\delta_e}\|^2}{D_{q_e}},\\
L_{R+}&=L_{\rm common},\quad
L_{G0}=L_{\rm common}+\beta_{\rm response}A_{\bf1},\quad
L_G=L_{\rm common}+\beta_{\rm response}A_W,\\
L_{Gl}&=L_{\rm common}+\beta_{\rm response}A_{W_{\rm CE}},\qquad
L_P=L_{\rm common}+\beta_{\rm response}P,\\
\widetilde A_{W,i}
&=\frac NM\,\mathbf1_{\{i\in\mathcal E\}}
 \frac{w_i}{D_{q_i}}\|a_i^{\widehat\delta_i}\|^2 .
\end{aligned}
\tag{N6}
\]

无有效 pair 时响应／节点项为零；实际代码先检查资格，不计算无定义参照再乘零。P 的单元版本同样乘 \(N/M\)。完整对象按有效 pair 均值定义；单元采样用 \(N/M\) 纠正概率，不能将无资格或 singleton 的零项塞入分母稀释响应。小批次对这些已缩放单元损失平均。固定状态、均匀单元采样下，该估计对应独立分母的目标；随参数变化的顺序 AdamW 不因此获得无偏全程优化或最优保证。

**P 没有额外二分之一。** 对 \((r_u,r_v)\)，边差平方的度量为
\(\begin{psmallmatrix}I&-I\\-I&I\end{psmallmatrix}\)，节点平方为 \(\operatorname{diag}(I,I)\)，迹均为 \(2D_q\)。同一维度、有效边数分母下已经同迹；再对 P 两端平均会缩小一倍。两者仍不是同一目标：边差忽略共同偏置。

同一完整状态、实际扰动、数据、参考、共同系数和优化器下，G0/R+ 仅改变是否追加响应；G/G0 仅改变权重；G/Gl 仅改变同一权重多重集的对应；G0/P 仅改变关系与节点度量。单变量共同配置与分别调优的整方法竞争分开报告。完整训练中各自参数会使相同搜索规则生成不同扰动，这是算法总效应，不是始终固定同一 \(\delta\)。

SFT 只用 clean CE。RACER 原目标只用 clean CE 加 \(\alpha_{\rm inc}I_{\rm adv}\)，不含本方案的 adv CE、keep 或 response。RACER-native 按原协议使用 singleton；RACER-data 对增强数据中每个端点独立调用 N2 的单节点版本，取得各自 \(\widehat\delta_{i,v}^{\rm ind}\)，再对单元内端点的 CE 和不一致平均。它保留增强比较的共同单元权重，但没有 R+ 的 pair 共享扰动。两种实现不能复用一个 pair 平均搜索结果来冒充独立扰动。

RACER-data 的数据和校准权限增强须另记。RACER-native 仅按核实的原协议，不偷偷使用本方案新增的参照计算、校准和选择资源；没有官方运行交付时叫“论文重建实现”，不能因目标形式相同就称原方法精确复现。与这些外部基线的完整差异不是单变量消融。

N6 使用的全部分数对手也能取得，没有新增监督信息。共同 CE 不是旧图理论的精确分数锚点；本稿没有“响应归零就恢复全部答案”的证书。

## 6. 从响应到原参数实际更新

固定扰动、参考与权重，设 \(J_{v\mid e}^\delta=D_\theta s_\theta^\delta(v)\)，仅对允许参数求导：

\[
D_\theta a_e^\delta=J_{v\mid e}^\delta-J_{u\mid e}^\delta,\qquad
g_A=\nabla_\theta A_W
=\frac2M\sum_{e\in\mathcal E}\frac{w_e}{D_{q_e}}
 (J_{v\mid e}^\delta-J_{u\mid e}^\delta)^\top a_e^\delta.
\tag{N7}
\]

**证明与用途。** 参照固定，对 N3 求导，再对每项平方范数用链式法则。空集合时梯度为零；单元估计按 N6 缩放。实现用自动微分，不构建全模型 Jacobian。亮而不动的响应可能是允许参数无局部作用，也可能是 detach 错误；热度本身不是可修证据。

把 AdamW 视为实际有限步映射，\(S_t\) 包含一、二阶矩、步数、调度器、精度／缩放及梯度累积状态，相关随机状态一同保存；\(h_t\) 是当步配置：

\[
g_{m,t}=\nabla_\theta\widetilde L_{m,t}
 (\theta_t;\operatorname{stopgrad}\widehat\delta_t),\qquad
(\theta_{t+1},S_{t+1})
=\operatorname{AdamW}_{h_t}(\theta_t,S_t,g_{m,t}),\qquad
\Delta_{m,t}=\theta_{t+1}-\theta_t.
\tag{N8}
\]

\(\widetilde L_{m,t}\) 为当步实际采样／累积损失。裁剪、权重衰减和步数属于映射，不可遗漏；只给声明参数建立优化器并核对冻结部分。N8 不保证每步损失下降，也不把有限训练失败当作全模型不可修。

内层只搜索不一致，外层还有 CE、keep、response，所以 N2＋N8 是有限交替算法，不是整个新目标的精确 min-max。N7 不穿过搜索轨迹，不借 Danskin 定理把近似搜索说成精确最坏情况梯度。

## 7. 新理论的实际单步方向预测

从预登记的同一完整状态复制两次，使用相同批次、缓存扰动、随机状态和共同配置，取得 G0/R+ 或 G/G0 的一次真实更新。这里更新使用训练运行的参考、全局权重与 \(N/M,N/R\) 尺度，不能在小诊断子集重新计算一套权重和分母。更新单元与评价节点分别提供：U 的更新来自可访问训练单元，真实触发只用于评价该更新；用真实触发产生更新的是 K，不能替代这一 U 诊断。检查完恢复起点及完整状态；诊断不并入训练。

对有真值节点和每个错误候选，定义固定环境 \(\nu\) 下的间隔
\(m^\nu_{v,y}(\theta)=s^\nu_\theta(v)_{y_v}-s^\nu_\theta(v)_y\)。
环境可以是正常、固定人工扰动，或隔离评估器持有的有效真实触发。省略节点、竞争者和环境下标后：

\[
\begin{aligned}
z_{AB}&=D_\theta m(\theta)[\Delta_A-\Delta_B],\\
e_m(\Delta)&=m(\theta+\Delta)-m(\theta)
             -D_\theta m(\theta)[\Delta],\\
D_{AB}&=m(\theta+\Delta_A)-m(\theta+\Delta_B)
       =z_{AB}+e_m(\Delta_A)-e_m(\Delta_B).
\end{aligned}
\tag{N9}
\]

**条件推论。** 在导数可得时，若实际核验的
\(|e_m(\Delta_A)-e_m(\Delta_B)|<|z_{AB}|\)，则 \(D_{AB}\) 与非零 \(z_{AB}\) 同号；直接比较最后一行的误差即可证明。可微性还给 \(e_m(\Delta)=o(\|\Delta\|)\)，但不提供当前可用半径或统一曲率常数，不保证实际 AdamW 步满足小误差条件。

N9 先报方向，再以前向记录实际有限步差与残差。余量接近零、非线性大、梯度近似或数值误差可能反转符号时，报告未决／预测失败。后验测得残差小只验证这一次比较，不是假装无需试修的先验保证。近似梯度下残差同时包含梯度误差，不继承精确导数结论。不能写成 AdamW 的更新差必为 \(-\eta\beta_{\rm response}g_A\)。

所有候选竞争者的间隔都为正，才说明该有限候选判定正确；比对方增加不等于已经转正。原自由生成、VQA soft score、CIDEr 和攻击判据不可用这个 margin 互换，仍要实际生成。正常事实也要检查实际得失，不从平均方向推出逐项保护。

真实触发、标签及其梯度只在 U 锁定后由隔离评估器计算，不进入修复、权重、调参、停止或回退。K 单独载入正常节点及其真实触发观测，不能将其缓存或更新传回 U。多步轨迹会分叉，N9 不推出整个训练终点优于对手。

K 的信息增强训练分支另作明确定义：clean CE、keep 和正常参照取 clean_nodes；观测 CE、不一致与响应取对应真实触发节点，不再给这些节点追加人工扰动。N4 的参考偏离也改为 \(\theta_0\) 下的真实触发偏离，属于 K 的额外信息。恢复原参照前须核验所评事实在真实触发下保持真值；若不保持则该参照解释失效。这样得到的是 K 更新，不是 U 更新的真实触发方向评价；两个实验用途不能混淆。

## 8. 有限正常校准选择与原生成评价

本节适用于采用增强数据和共同选择权限的 U 方法；Native 按其原协议，不继承本节的额外校准材料。每种增强方法仅产生预登记有限配置、训练步数和成本内的候选 \(\theta_h\)。\(\mathcal H_{\rm nz}\) 只保留至少完成一次有效更新且实际参数不同于 \(\theta_0\) 的候选。在同一可访问正常校准集合上，原生成和原评分给出标准化 VQA \(\widehat V\) 与 caption CIDEr \(\widehat C\)。以固定 \(\theta_0\) 为基点，按计划筛选：

\[
\begin{aligned}
\mathcal H_{\rm ok}
&=\{h\in\mathcal H_{\rm nz}:\widehat V(\theta_0)-\widehat V(\theta_h)\le0.01,\
       \widehat C(\theta_h)\ge0.98\,\widehat C(\theta_0)\},\\
\widehat h&=\arg\max_{h\in\mathcal H_{\rm ok}}
                \widehat Q_{\rm cal}^{\,\delta}(\theta_h),\qquad
\theta_{\rm out}
=\begin{cases}
\theta_{\widehat h},&\mathcal H_{\rm ok}\ne\varnothing,\\
\theta_0,&\mathcal H_{\rm ok}=\varnothing.
\end{cases}
\end{aligned}
\tag{N10}
\]

**toy48 单候选实例。** 每方法仅核验一个完成预登记训练日程的非零候选；超时或未完成日程的参数不具备候选资格。正常校准通过则保留，否则回退 B0。集合至多含一个元素，因而无需计算 \(\widehat Q_{\rm cal}^{\,\delta}\)，也不生成用于排序的整套人工扰动校准数据。fit 的参考扰动与 N9 小型诊断仍保留。本文关于共同 proxy 校准扰动、身份核对及破平局的要求仅在恢复多候选选择时启用。

多候选版本中，\(\widehat Q_{\rm cal}^{\,\delta}\) 是同一冻结人工扰动校准集上、按预声明生成／任务规则实际计算的正确率。扰动仅由 \(\theta_0\) 及共同校准搜索配置生成并缓存，不针对候选重搜；即使候选的训练 PGD 配置不同，也必须使用同一校准扰动。选择时核对缓存／生成配置身份，不能在不同人工任务上比正确率。同分先选总成本小者，再按固定配置编号。所有版本中，正常标签缺失、CIDEr 基准不能支持相对比较或候选数值无效时，不能登记联合正常保护通过，须返回对应未决状态。

**有限保证。** 配置和调用有限、模型接口及有效数据齐备时，N2、N4、N8、N10 构成有限可执行过程。有合格候选则按集合定义满足这两个正常校准门槛，否则回退并记录未找到合格修改。基点固定为 \(\theta_0\)，不逐步累加损害容忍。非零修改与 B0 分别报告，回退不是找到修复。

这只是有限校准的数值／经验通过，不保证正常总体无损，也没有逐节点“不新增错误”的 U 证书。keep 小、平均校准合格都不能代替独立测试新增事实错误。U 选择中不能加入真实触发 ASR；真实攻击效果只能在锁定后评价。

部署只输入当下图像和问题，不额外注入人工 \(\delta\)，不提供正常图、标签或教师。修复模型使用原解码和原 VQA／caption／攻击评分。有限候选平均 log probability 排名不是贪心、beam 或采样生成；即使完整串得分最大，也不能由此推出原生成正确。

原任务与攻击终点分别报告。VQA 联合评分可取原 soft score 乘“未满足攻击目标”的指示量，不能把连续分数说成二值成功。MI 中事实正确但仍有恶意内容不算彻底修复；TR 从拒答恢复到答题不能单独证明内部视觉信息重建。真实触发改变可见事实时，机制分析核验新标签，原 benchmark 与有效真值子集另列。

## 9. 实质反例及预期边界

**共同偏置盲区。** 若注入点之后的分数对输入仿射，同一 pair 的加性 \(\delta\) 引起相同分数偏移，\(\theta_0\) 下 N3 的响应为零；共同偏移仍可翻错答案。N4 因而给均匀权重，这是测量性质，不是图没画好。有效修复若来自共同 CE／不一致，不能冒称幅度指导的收益。

**幅度加权可向反方向更新。** 取同类型两条合格边、两个候选坐标，在一维允许参数处令
\(a_1(\theta)=(2+\theta,0)\)、\(a_2(\theta)=(1-2\theta,0)\)，起点 \(\theta=0\)。N4 给 \(d=(2,1/2)\)、中位数 \(5/4\)、\(w=(20/17,14/17)\)。按 N6 的边数及维度平均，均匀梯度为零，加权梯度为 \(6/17>0\)。若真实任务需要增大 \(\theta\)，加权产生错误方向。例如共同梯度为 \(-1/10\)、\(\beta_{\rm response}=1\)，从零矩状态、\(\theta=0\) 的同一 AdamW 出发，G0 与 G 步方向相反，G 减小 \(\theta\)。这是可微反例，不声称真实 VLM 已出现这些数值。

**数值恢复可以抵消正确答案改善。** 正常候选答对只约束排序，有益的置信度提高也能改变响应。N6 可能惩罚有益 CE 修改；G0、Gl 和实际输出对照用于检验本轮响应及加权增量。若声称关系差分优于普通全节点匹配，还必须比较 P；toy48 推迟 P，因此不检验也不主张这一优势。大偏离若对允许参数的导数为零，也不能通过加权产生非零修复。

**共享 embedding 扰动不等于真实触发。** 真实接口改变为 \(F_\theta(\tau x)-F_\theta(x)\)，一般随图像改变。例如 \(F(x)=x^2\)，同一输入加法触发 \(x\mapsto x+\epsilon\) 在 \(x=1,-1\) 上分别引起 \(2\epsilon+\epsilon^2\) 与 \(-2\epsilon+\epsilon^2\)，无法表示为同一个 \(\delta\)。形状对齐只使加法合法，不证明真实触发的效果对齐或位于 N2 搜索范围。

**未见组合没有免费保证。** 两个模型可在全部已测 pair 相同、在未测组合相反。复杂场景本身不是归因必然更有用的条件；需要实际错误／附带损害、有效参照和可作用的更新。

因此，有依据的方向预期是条件性的：实际更新差与真实正确间隔同向且有限步残差没有推翻时，应得到相应局部分数改善；方向反对时应看到伤害或无增益。是否更常同向、是否改善真实生成、幅度权重是否优于普通难例加权，都须由第一阶段隔离诊断和强对照检验。toy48 第二阶段检验同一模型／攻击下独立数据上的增量与成本，独立模型／攻击扩展后移；本稿不预测平均增益的符号、幅度或 SOTA 胜率。
