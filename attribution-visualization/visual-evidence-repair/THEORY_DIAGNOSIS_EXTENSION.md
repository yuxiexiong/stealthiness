## 1. 这次把什么问题推进了一步

旧方法测量“正常事实响应与受扰事实响应相差多少”，随后增加大偏离样本的训练权重。这条链缺少关键依据：偏离可能没有造成答错；控制该偏离的参数可能不是允许修改的参数；压低偏离也可能损害回答。

现在将诊断改成两个有不同证据要求的判断：

1. **故障清单：** 哪道题真的答错；事实发生变化后，哪些答案没有跟着正确变化；哪些本应不变的答案反而改变。
2. **干预定位：** 在同一个错误案例上，只把指定内部位置的状态换成正常参照状态，哪些组合能恢复正确回答。保留那些已经不能再缩小的成功组合。

第一项靠外部真值和实际回答判断，普通正确率工具也能做到。**本方案拟检验的增量在第二项：指出能够改变错误结果的具体状态位置、共同作用和替代恢复方案。** 可视化必须展示这些干预证据，而不只是错误列表；相对现成干预定位的增益尚未成立。

“需要关注位置 A”在本稿中的准确含义是：A 属于经过验证的最小成功组合，或在声明的全部成功组合中都不可缺。它不等于“A 的参数遭到投毒”，也不等于“微调 A 一定治好”。后者是下一阶段的问题。

## 2. 先固定可得到的证据，不能从未知信息起步

沿用原课题的原模型、外部事实标签、合法单事实编辑和真实生成评分。正常参照来自同一模型在正常图片上的运行，相关回答必须已经由真值核验。无需另训一个可信教师。

D 版的参照资格是正常实际回答正确、事实标签有效、干预能够对齐；它不依赖旧 N1 的候选串平均分排名。旧 N1 的额外排名资格继续用于 N 版训练，不能未经说明拿它裁剪 D 的诊断覆盖。

一个诊断案例包含：两张只改变一个已知事实的图片、该事实的问题，以及需要保护的其他事实问题。例如球从红变绿，方块保持蓝色；同时问球颜色和方块颜色。参照必须分别答对。改变球颜色不应被误解释成改变所有问题的正确答案。

受检条件分开记账：

| 条件 | 方法可访问的信息 | 可以诊断的范围 |
|---|---|---|
| U：人工扰动 | 正常材料、标签、自己生成的内部扰动、模型运行状态 | 人工扰动诱发的实际错误及其恢复组合 |
| K：真实异常诊断 | 额外得到真实异常输入，以及合法、同事实的正常参照 | 这些已观察异常的恢复组合；结果不反馈冒充原 U 的未知触发能力 |

没有合法正常参照时，可以记录“这里答错”，但不能伪造正常状态作为恢复供体。正常参照答对也不意味着该模型内部所有状态都健康。

K 还须核验异常图片仍保留所问事实的可见证据；黑块遮住答案依据、图像编辑改变真值或正常／异常状态无法对齐时，不能沿用原标签作本稿的同事实恢复解释。U 是在图像真值固定时施加的内部压力测试，不证明该扰动对应一张现实中的同事实图片。

**必要的不可识别边界。** 若诊断结论只依赖有限的正常／人工输入及其运行记录，在一般响应函数类中，可以有两个系统在这些记录上相同、在未测区域行为不同；例如在未测区域加入一个局部变化而保持已测区域不变。只收到同样记录的判断规则无法保证辨别那个隐藏错误。这不是所有白盒分析的不可能性定理：若另读取可区分的权重结构，必须另外分析。人工到真实触发的迁移仍须单独验证；这里不引入无法核验的“扰动已覆盖真实触发”假设。

**决策用途：** 没观察到错误，不能凭图很亮标注故障；U 的证据不能替代 K 的证据；未覆盖条件标为未检查。

## 3. D1：确定与正确参照分开的生成位置

先让原模型按固定解码规则真正回答，再由外部标签判对错。异常是“答案不符合可见事实”，不是“没有输出某句固定拒答”，也不是“分数偏离旧值”。正常生成的同义正确回答不算异常。

为了固定图所解释的输出竞争，对一个已经确认答错的节点 v，冻结正常运行实际生成且核验正确的答案 token 串 y⁰，同时保存无替换异常运行的实际 token 串和停止原因。结束符只在实际生成过时记录，不能人工补一个 EOS 再称原运行输出。

tᵥ 直接取两条实际 token 串首次不同的位置，不能以“第一个负分数”代替。若不存在可比较的 token 分歧，例如只因长度截断或外部停止而少了一段，标为终止问题，D4 坐标不适用；实际错误仍进入 D2。正常保护题没有分歧时，也不强造一个错误位置。沿正确参照前缀计算：

\[
m_{v,t}(S)=z_{v,t}^{S}(y^0_t\mid y^0_{<t})
 -\max_{b\ne y^0_t}z_{v,t}^{S}(b\mid y^0_{<t}).
\tag{D1}
\]

这里 z 默认为原模型下一 token 的原始 logit；S 是后面定义的内部状态替换集合，空集表示不替换。比较对象是**整个词表中最强的其他 token**，包括拒答的开头，而不是只比较红、绿等预选答案。所有 S 使用同一图片、问题和固定前缀。

**直接结论。** 在确定性贪心解码、无未计入的解码处理且无最高分并列时，m 大于 0 就表示下一步选中这个正确参照 token。若完整答案直到结束符的每一步都大于 0，且生成长度和其他停止规则允许完成该答案，则逐步归纳可知实际贪心输出就是已验证正确的 y⁰。空集下第一个小于 0 的位置，正是偏离该参照串的首个位置：此前前缀相同，该步另一个 token 严格胜出。

并列按实际规则处理，不能拿严格不等式解释平局。采样可能在正间隔时仍选中另一个 token，因此采样和平局条件下，实际首分歧不一定是首个负间隔。本版 F 的主合同采用固定贪心生成；其他规则下保留的 D1 读数不继承贪心保证。

如果原生成使用 logits processor，要解释其实际贪心选择，须比较同一规则处理后的决策分数，并在整张图上统一标注分数种类，不能与原始 logits 混用。硬屏蔽或强制 token 可能产生无穷间隔；D4 仅在两次间隔均为有限实数时计算，否则显示“不可比较”及具体原因，不用截断色值或 0 代替。使用处理后分数时，单位称为决策分数间隔。

即使最终回答已经判错，首次分歧仍可能只是措辞差异：参照是 `green`，错误回答是 `The object is blue`，首个分歧 `The` 本身不是事实错误。因此 D1 只叫“参照分支首分歧”，不叫“语义错误首次发生的位置”。完整回答和真值判定必须同时展示。

**分支评分与真实生成分开执行。** 计算 D1/D4 时，从头重放同一 S 的 prefill 替换，再强制输入 y⁰ 的已声明前缀取得评分；该前缀可能从未出现在 S 的自由生成中。计算 F 时则从头自由生成，不读正确答案前缀，也不复用评分运行的 KV cache。热图解释固定反事实分支上的竞争，不冒充不同自由生成轨迹之间逐 token 的实际变化。

**用途：** 让热图有一个固定、可复核的输出竞争坐标，补上旧候选分数表未包含拒答竞争的问题。D1 只解释某个参照分支；只让这个位置转正，不能宣布整段答案已经恢复。后续是否成功始终用实际完整回答判断。

## 4. D2：用明确的状态替换定义干预归因

本版固定在原模型的融合输入 embedding 接口，在 prefill 前只替换一次，将其状态坐标划分成 K 个互不重叠的组。组可以对应图像 token 区域或问题／模板位置；名称只表示操作位置，不能凭命名声称它已经表示“颜色概念”。同一次集合分析使用同一个接口和划分，不把前后层混成可交换的坐标。

对节点 v，记生成前的正常供体状态为 \(h_v^0\)，受检输入的状态为 \(h_v^\nu\)，\(P_{v,j}\) 为共同组 j 在该节点的实际坐标掩码。两者的形状、token 位置、图像裁剪及必要的区域对应必须核验，K 也不例外；无法对齐时该干预未定义，不进入这张联合表。固定供体、接口、掩码和全部其他操作，定义：

\[
h_v^{S}=h_v^{\nu}+\sum_{j\in S}P_{v,j}(h_v^0-h_v^{\nu}),\qquad
r_v(S)=\mathbf1\{\text{节点 v 在该干预后实际答对}\},\qquad
F(S)=\prod_{v\in\mathcal T\cup\mathcal P}r_v(S).
\tag{D2}
\]

上标 ν 表示受检条件，不是参数更新。该式定义逐坐标复制：选择的坐标直接赋为供体值，未选择的坐标保留接收值；实现不能靠浮点加减重建正常状态来代替复制。

\(\mathcal T\) 是冻结的目标题集合，空操作时至少一道确实答错；\(\mathcal P\) 是保护题集合，空操作时必须已经答对，且与 T 分开。原本也错误的题属于另一项纠错要求，不能叫保护题。两端目标题、正常条件下的保护题及其他固定条件按节点明确列出。保护集合可以为空，此时必须报告未检查保护，不能宣称没有副作用。

若某保护节点本就在正常条件，且使用它自身的正常供体，则本版替换是恒等操作；这样的通过只作身份对照，不能证明未来参数修复没有正常损害。联合表里需要区分这种恒等对照，与受检条件下原本答对、确实可能被部分替换影响的保护题。

rᵥ 与 F 均来自完整实际生成及外部标签，不从归因分数、损失下降或 D1 正负推出来；这里 rᵥ 是是否答对的 0/1 判定，不是旧 N3 的分数残差。**原始回答、逐题 rᵥ(S) 与联合 F(S) 必须一起保留。** 只有空集下确有目标错误的案例才进入故障定位。节点、标签和成功标准在查看替换效果前冻结；保护保证只覆盖所列题。标签不明、运行缺失或结果不稳定时记为未决，不填成 0，也不能据此作完整表的排除结论。

每个“图片×问题×运行条件”节点分别冻结自己的扰动、供体、位置掩码和生成合同；同一节点比较所有 S 时复用它们。共同组 j 通过固定映射 \(P_{v,j}\) 对应同一接口区域，不因为问题或结果改变含义。若各题的 j 实际对应不同位置，则只能称预声明的操作包，不能解释为跨问题共同位置。不同保护题的 token 长度可能不同，不能强行复用另一题的扰动张量。U 沿用原 N2 的同问题合法事实对内共享扰动；不同问题可有各自扰动。K 不追加人工扰动，也不把 U 的共享 δ 要求强加给真实异常。

**因果含义来自程序干预。** 对比两次运行时，只改变已声明坐标，其他输入、参数、随机状态和生成规则保持一致，且恢复与重算过程确实按合同执行。此时输出差异可归于这项程序内干预。它识别“这项替换对这次错误的作用”，不是从相关性直接猜测作用，也不等于证明混合状态在自然数据中常见。

### 最小可执行接口与缓存约束

每个 S 都从头生成：在声明的融合入口复制一次选中坐标，再建立本次运行自己的 KV cache；decode 阶段不重复替换，不复用其他 S 或正常供体的 cache。对于同一张图的人工加性扰动，若组覆盖全部扰动支持，并且其余输入、mask、位置、参数和生成设置一致，全部恢复就得到正常融合输入，因而应复现正常生成。这只是接线正对照，**不能计为找到局部故障**。

深层接口和逐步 decode 替换不属于本版已定义算法。以后若扩展，必须另给完整事件／缓存合同：重复替换的底稿应是当前干预运行在该时刻的状态，不能每次重置为未干预轨迹的旧状态，否则会额外修改未选坐标。只恢复某层 prefill hidden 也不等于恢复更早层 cache。这些问题不在本轮通过增加一个抽象递归公式绕过。

本版正常供体只含图像、问题与模板的输入状态，不含答案 token。自由生成不得注入正确答案前缀或评分分支的缓存；D1/D4 的强制前缀仅属于独立评分运行。

**用途：** 把“归因位置”变成可重放的具体操作。正常运行、异常运行、空操作、全部恢复和缓存合同共同确定这项归因究竟解释了什么。

## 5. D3：定位可以是组合，不强求单个热点

在小规模、固定的 K 组上，获得所有集合 S 的真实 F(S)。分组先按接口结构和合法区域定义；若依据旧 d 或其他归因先删掉候选，后面的完备性只对删减后的范围成立，不能据此证明该评分没有漏掉其他位置。定义全部不能再缩小的成功组合：

\[
\mathcal M=\{S\subseteq\{1,\ldots,K\}:F(S)=1,
                   \ \forall T\subsetneq S,\ F(T)=0\}.
\tag{D3a}
\]

“不能再缩小”指没有任何成功的真子集，不是只检查少去一个位置。它也不等于“全局组数最少”：可能同时存在大小不同、各自都不能缩小的成功组合。

### 从最小组合读取哪些结论（原 D3b，合并为短推论）

如果集合表完整、运行确定且 F 的判定可靠，每个成功集合都包含至少一个最小成功子集：从它的有限个成功子集中选一个包含关系下最小者即可。反过来，最小成功组本身就是成功操作。因此可从 M 读取下面三项结论，无需另立两个编号公式。

- A 不包含任何最小成功组合：在当前固定供体、分组和替换操作内，只动 A 的任何子集都不能恢复所检查的回答。可以将该操作范围标为不可用；不能外推为 A 的权重不可训练修复。
- 所有最小成功组合都包含某组 j：在这张完整干预表内，每个满足纠错加保护要求的方案都需要包含 j，可以标成联合要求内的共同必选位置。
- 存在不同的最小成功组合：报告替代方案或联合恢复要求，不伪造唯一故障点。两个非最小成功超集互不包含，不足以证明存在不同最小方案。交集为空不表示“没有问题”；M 为空表示没有找到成功恢复操作，不能作真空的“所有位置都必要”解释。

最小组合保留了上述范围存在性与共同必需位置的结论，但不保留完整结果表的全部信息：成功小集合的超集仍可能失败。它们没有减少取得完整表的查询成本，支持的是正确读表，不证明归因比直接搜索更有效。

### 每个必需位置必须有逐题失败见证

对最小成功组 S 中的每个 j，移除 j 后至少有一道已检查的题从对变错：否则所有 rᵥ(S 去掉 j) 仍为 1，那个真子集也成功，与最小性矛盾。这个推论用于给每个圈出的位置附上具体题目和回答，不能只显示一个合并成功位。它是最小性的必要后果；反过来，只检查单个移除仍不足以证明没有更小成功真子集。

共同必选的位置可能负责目标纠错，也可能只保护其他答案。例如：

| 恢复集合 | 目标题 | 原本正确的保护题 | 联合 F |
|---|---|---|---|
| 空集 | 错 | 对 | 0 |
| A | 对 | 错 | 0 |
| B | 错 | 对 | 0 |
| A、B | 对 | 对 | 1 |

这里 B 可能只是抵消 A 对保护题的伤害；不能说 A、B 共同造成了原始目标题错误。另一个可能是 A 只修图一、B 只修图二，联合要求仍得到 {A,B}，但不说明它们在同一道题中交互。图必须区分目标纠错、保护补偿和跨题覆盖。若另按单道题计算最小组合，那是对同一逐题记录使用另一判定目标，须单独标注，不能直接套用联合 M。

### 两个必须保留的反例

| 恢复集合 | 同一目标题需联合恢复 | 同一目标题存在替代方案 |
|---|---|---|
| 空集 | 错 | 错 |
| 只恢复 A | 错 | 对 |
| 只恢复 B | 错 | 对 |
| A、B 一起恢复 | 对 | 对 |

左边只做逐点测试会漏诊，应该报告组合 {A,B}；但二值成功需要联合，也可能只是两个独立影响一起跨过答案阈值，不证明底层存在非加性的机制交互。右边不应说 A 或 B 各自绝对必要，应该报告 {A} 与 {B} 两种方案。集合关系没有识别网络中的传播路径。这些是逻辑示例，不是模型实验结果。

另一个边界是**非单调性**：恢复 {A} 可以成功，恢复 {A,B} 却可能失败。因此上述范围推论说的是“A 这个范围内存在一个成功子操作”，不是“把 A 全恢复就一定成功”。不能用成功小集合的结果填充未经运行的大集合。

### 查询范围限制：不加结构假设，就不能廉价保证找全

对任意黑盒 F，在最坏情况下，所有非空真子集都可能需要查询。证明很直接：设已查询的真子集都失败、全集成功；任一未查询真子集都可能实际成功，从而改变最小成功集合列表，而此前观测完全不变。

**用途：** 初步定位只在少量粗组上做完备判断，再按明确问题细分。不能对几万个神经元宣称靠几个消融就已经找全原因，也不在本稿加入未经证实的单调、稀疏或可加假设。全表是完备判断的充分保障，并非所有实例都必须查满：例如空集失败、所有单组成功，就已确定全部最小成功组。若仍有可能改变某项结论的未知子集，就不能声称该结论完备。K 的取值留给实验预算规划，理论不藏掉最坏情况下 2ᴷ 的代价。

## 6. 如何判断是在定位视觉事实，而非只打开回答开关

状态替换后愿意说话，不足以证明恢复了视觉事实利用。D2 已要求两端目标题和保护题都真正正确；进一步解释“这个位置携带球颜色信息”，还需要改变供体的事实内容。

在合法的红球／绿球图片对上，问题和位置匹配，分别使用同图正常供体与另一颜色的正常供体。正常供体不含答案 token。若观察到下表，才能提供比“解除拒答”更强的事实内容证据：

| 接收图片 | 替换组内状态的供体 | 需要观察的现象 |
|---|---|---|
| 红球图 | 正常红球图 | 回答红，方块仍答蓝 |
| 绿球图 | 正常绿球图 | 回答绿，方块仍答蓝 |
| 红球图 | 正常绿球图 | 球颜色回答随供体变绿；保护题不随之改变 |
| 绿球图 | 正常红球图 | 球颜色回答随供体变红；保护题不随之改变 |

后两行是故意构造的反事实诊断，**不是修复成功案例**。实际标签仍属于接收图片，不能把跟着错误供体回答算成准确率提高。它们检验被替换的状态是否能向答案传递这项事实区别。

这项观测支持的是“该组在此供体交换实验中介导了可核验的事实差异”。它也可能通过供体注入答案相关线索、或绕过接收者原有的受损计算实现；禁止答案 token 只排除显式 token 注入，不能排除供体状态本身携带答案倾向。因此它不证明接收者原有视觉通路恢复、事实在该处丢失、该处参数被投毒或内部只编码颜色。若交换只改变拒答／作答、答案不跟随供体事实，则只获得回答状态方面的证据。交换无效也不能自动判定该组不含事实信息，兼容性或下游读取仍可能影响结果。

接口本身不允许合法对齐供体时，不做这种语义解释。优先复用现有合法图片编辑和源数据中能够核验、对齐的区域 mask；文件名带 mask 不等于已经取得所需的对象级标签。不能用另一张任意图片代替“只改变颜色”。

在视觉入口替换整幅图的全部 token，有时就等价于换了一张图。该结果只能作为内容交换的粗粒度对照，不能证明找到了局部机制。若只有完整图像替换或覆盖全部输入差异的替换成功，须明确报告其范围，不能靠给它起一个局部名称升级定位精度。

## 7. D4：图里画什么，以及它如何参与判断

保留三个联动视图，三者对应不同问题：

1. **事实与回答表。** 同时显示原图、单事实编辑图、外部正确答案，以及正常、异常和替换后的真实回答。它负责确认故障和观察保护题损害。
2. **有上下文的干预热图。** 行是固定问题及回答位置，列是位置组；单元格注明其他哪些组已经被恢复。对于 j 不在 S 中，画：

\[
C_{v,j\mid S}=m_{v,t_v}(S\cup\{j\})-m_{v,t_v}(S).
\tag{D4}
\]

其中 tᵥ 来自 D1 的实际 token 首分歧，比较各 S 时不移动。D4 只在该坐标存在且两个间隔均为有限实数时计算。红表示加入替换后，正确参照 token 相对最强竞争 token 的优势增加；蓝表示降低；深浅表示数值大小。原始 logits 条件下单位是 logit 间隔之差，使用处理后分数则另标单位，均不是贡献百分比。固定前缀、标注数值、保持同一可比色标，不把未测、不适用或非有限值画成 0。旁边显示真实回答和逐题 rᵥ；正确保护题没有首分歧时保留回答表即可。

3. **成功组合图。** 用边框或连接线圈出 D3 的最小成功组合，标出联合要求内共同必选组、替代组合和未测组合。每个组附上移除后哪道题失败的见证，并区分目标纠错、保护补偿与跨题覆盖。线表示共同恢复要求，不表示神经网络中的传播路径。单点颜色不能代替这张图：一个组单独替换无效，在另一组已经替换后可能起决定作用。

**可视化的用途是选择下一条需要核验的解释。** 例如单点都不显眼、联合组合却成功，应先查看逐题结果，区分同题联合恢复、保护补偿或跨题覆盖；不同事实使用不同成功组合，应检查能否分别干预；所有事实只在整体恢复后改善，则尚未得到有区分度的局部定位。沿用立项的最小记录：看了哪些图格 → 提出什么解释 → 在查看确认案例前冻结哪条后续检查 → 结果支持还是推翻。图提出的规律必须在新案例上检查，不能仅凭展示案例形成普遍结论。

D4 不作为新的训练权重，不负责证明整段恢复，也不把数值总和解释成完整错误的唯一分解。不要对未测上下文使用加法填补。

**D1/D4 是连续评分支线，不是 D3 定位保证的前提。** 不计算它们，仍可根据 D2 的真实回答表取得 D3 全部结论。B 已实际用单组 D4 的跨题均值选位，因此该分数不是无人使用的装饰；但 B 没有显示相对固定左上的选择增量。新判断若只来自逐题正误表，应归于干预诊断，不能再归功于额外的 D4 评分。

平均 D4 更高也不保证联合成功：一个问题的大幅改善可以掩盖另一个问题仍然答错。[审计中的两题反例](reviews/theory-completeness-2026-09-13.md#3-一个直接限制当前评分规则的反例)满足 D2 的状态复制和正常参照条件，直接说明新选择规则不能只凭平均分大小承担联合纠错保证。

## 9. 可复用的理论底座及其边界

这里采用的是已有的干预解释和有限最小解释思想，不宣称新发明了这些数学工具。与最接近论文的差别应从操作、输出判据和证据范围说明，不能只因换成 VLM 就宣布原创。

最小解释的直接近邻是 [Concept-Based Abductive and Contrastive Explanations for Behaviors of Vision Models](https://arxiv.org/html/2605.06640v1)。该文 §3 也限定于概念保留／擦除，其中 ConAXp 对包含指定概念的全部掩码提出保持预测的要求；本稿只要求指定集合在固定正常供体下恢复正确，不要求所有超集继续成功。对最小对比解释，附录 Theorem A.1 还给出不依赖单调性的关系。因此，D3 的有限集合论证应当作为借用的基础，不能包装成新的理论贡献。

[Towards Best Practices of Activation Patching in Language Models](https://arxiv.org/pdf/2309.16042v2) 的 §3–6 支持固定供体、评分对象和联合替换语义：不同异常构造与计分会影响定位，窗口联合效应不能当作单点效果相加。本稿据此保留实际输出、有符号竞争和组合图；不假定正常供体拼出的混合状态天然有效。

[Does Localization Inform Editing?](https://papers.nips.cc/paper_files/paper/2023/file/3927bbdcf0e8d1fa8aa23c26f358a281-Paper-Conference.pdf) 的 §4–6 检查了因果定位与参数编辑之间的关系，说明二者不能直接等同。本稿因此将结论止于指定激活恢复操作；不能把这篇论文解释成所有定位永远无用。

[The Shapley Taylor Interaction Index](https://proceedings.mlr.press/v119/sundararajan20a/sundararajan20a.pdf) 的 §2–3 提供交互归因的标准底座，也说明低阶归因会分配更高阶交互。本稿先直接展示已经测得的成功组合，不为单点颜色之和添加守恒公式。

本稿针对本项目真正补上的部分是：以真实语义错误确定解释对象，显式纳入生成决策，允许多位置共同作用，以正确恢复和保护事实定义目标，且用供体事实交换检查内容作用与回答开关的不同解释。A/B 已实施其中的有限状态诊断，保护部分尚未取得证据；不能把规范中写有保护要求当作已经验证保护。新诊断—选择规则还未实例化，比较优势仍须检验。

可复用现有模型资产回执、合法事实对、待核验对齐的区域 mask、正常实际回答、真实回答评分和可视化布局。旧候选串平均分不能恢复 D1 的全词表逐 token 分数；输出字符串也不能未经核验重分词成原实际 token 轨迹。旧 d/权重不能恢复 D2 的状态替换结果。新增前向观测是必要数据，不将旧实验重新画图冒充完成本稿。旧测试案例已经查看，只能承担回顾／方法开发；跨案例确认还须独立材料。

## 10. 现在闭合了什么，哪些仍然不能承诺

**有限干预表的分析链已经完整：** 外部真值确认实际错误 → 指定状态干预 → 实际生成核验 → 最小成功组合 → 有边界的操作判断。D1/D4 在旁边提供固定参照的连续竞争读数，不是这条分析保证的必要条件，也尚未获得更好选择的保证。

这项形式上的正向支持是：**只要声明的一次输入替换范围内存在成功操作，并且完整测得可靠的逐题与联合表，就能找出全部最小成功组合，判断哪些位置对该联合要求必需、哪些方案可替代，并展示移除每个必需组后具体哪题失败。** 条件是可以执行和逐项检查的测量合同，不是把“我们会定位准确”预先写进假设。保证对象是该有限表内的恢复操作，不是未知自然故障的一切原因。

A/B 已在同一受检模型的合格案例上找到局部成功组合，B 的冻结规则在新案例复现了单区域恢复，但简单固定左上作出了完全相同的选择。供体交换提供了条件性内容检查，未唯一确定机制。尚未解决的是：归因相对强对照的增量、正常事实保护、诊断在新模型／污染实例上的适用性、U 到真实触发的迁移，以及如何指导参数修复。

如果只测试了“全部恢复正常输入”并成功，只获得正对照，未达到局部定位目标。如果进一步完整确认所有真子集均失败，则已识别当前粒度下的联合必要性，但仍没有更小的局部恢复方案。如果一个组合也没成功，报告该恢复操作家族内未找到有效组合，不能宣布模型不可修。如果只有 D1/D4 数值改善、完整答案不对，报告决策分数发生变化，不能计为诊断出了有效恢复位置。

**D1–D4 给出可核验的有限状态诊断；A/B 没有证明归因更会选择处理。** 当前由[D5–D7](THEORY_DIAGNOSIS_DECISION.md)补齐可反驳的诊断、下一项检查和处理比较，不直接重跑完整修复训练。
