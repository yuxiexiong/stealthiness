## 1. 理论支持什么：尚未证实有效，不等于原则上不可行

| “找到问题”具体指什么 | 现在的支持与缺口 |
|---|---|
| 找出答错的事实 | 外部真值与实际回答可以判定；这不是归因独有的能力 |
| 找出哪些状态干预能纠正错误 | D2 定义可重放的操作，D3 整理成功组合；尚不知道真实模型上是否存在有价值的局部组合，是否优于简单对照 |
| 找出被投毒的权重或原始损伤位置 | 当前替换记录不能保证识别；需要能区分故障来源的额外证据，例如可信投毒前模型与受控组件干预 |

D3 的保证是：**如果成功操作存在，且有限表测量完整可靠，就能提取该表内的全部最小成功组合。** 它主要整理已经获得的干预事实，不保证局部成功存在，不保证廉价找全，也不保证恢复位置就是损伤来源。可视化使关系可检查，不额外增加定理的正确性保证。

例如，换一组状态后模型从拒答变成正确回答“绿色”，证明这项替换能够影响这个错误。它可能消除了触发相关信息，也可能补进事实线索、绕过另一处异常；不能直接说这一组神经元被投毒了。

有限的正常／人工输入记录，也不能在一般模型类中保证发现未测条件下的一切隐藏错误。这是当前信息范围的限制，不是所有白盒诊断方法都不可能。**下一步应测真实模型是否满足有用的局部定位条件，而不是继续把这些条件写进假设后宣布有效。**

## 2. 本轮要得到的证据

目标：**面对已经确认的真实触发错误，归因可视化能否给出比简单对照更有用、能在独立案例检验的状态干预位置判断。**

分两层验收：先确认小范围操作能真正纠正图片事实回答；再确认从图中得到的判断，在新案例上比简单选择更容易命中有效操作。同一张全表既选出成功集合、又证明选得准，只是表内核验，不能代替第二层证据。

以 **K：已观察真实异常**为主：方法取得异常图、同事实正常图、标签及内部访问，不声称未知触发自动检测。U 人工扰动仅用于必要的接线检查：恢复人工扰动坐标本身就是撤销噪声，不能充当真实污染诊断的证据。状态替换是检查手段，正常供体未必在部署时可得；本轮不更新权重。

旧结果以[三方实验复核](reviews/toy48-2026-09-12/CONSENSUS.md)为准：G 改变了真实触发下的候选评分，fact 实际生成仍全部拒答。它提供的断点是“评分变化未变成正确回答”，不预告新归因会成功。旧 N3/N4 是样本／答案坐标权重，不能直接冒充内部位置排名。

## 4. 阶段 A：探针，寻找有信息量的局部干预

### 案例和判据

- 从旧 test 按场景 ID 固定顺序取**至多 12 个**合格开发案例。只按正常实际答对、异常确实答错、事实可见及状态可对齐筛选，不按干预成功筛选；报告全部流失原因。
- 每例固定同一颜色问题在编辑前后的两个端点。正常供体两端都答对，异常至少一端错。两端答案不同，恒定回答不能通过。
- 标记若遮住所问对象证据，不能沿用原标签解释成同事实错误。对象 mask 必须与实际预处理结果匹配。
- 未变对象颜色、数量等伴随问题，只在正常供体答对、事实可见时纳入；异常已错者归共同纠错 T，原本正确者才归保护 P。逐例冻结清单，所有方法共用。
- P 为空就报告未检验非恒等保护。正常条件下自身供体替换只是恒等对照；不能据此声称未来权重修复无损。

### 测什么

固定一次融合入口 prefill 替换，把视觉 token 网格分成四个尽可能等大的空间组。分组不依赖触发位置或归因高低。先核验真实网格、裁剪和特殊 token；若不能对应，先修订操作说明，不凭序号伪造区域。

每例测完整 **16 种集合**。每次从头自由生成并独立建立 KV，保存每题答案、正确性和停止原因。D1/D4 固定前缀评分另起运行，不把正确前缀或评分缓存送进自由生成。空间 token 可能已混入其他区域信息，所以定位的是替换坐标，不是仅受影响的原始像素，更不是污染参数。

| 必要对照／读数 | 为什么需要 |
|---|---|
| 空操作、接收状态复制回自身 | 排除 hook 本身改变回答 |
| 全部视觉状态恢复 | 在其余输入相同时应复现正常生成；只是接线和整图对照 |
| 等大小的其他全部集合 | 判断位置是否有区分度，还是随便换哪里都有效 |
| 恢复坐标比例、覆盖的正常／异常差异比例 | 换 25% token 若覆盖全部实际差异，本质仍是全部恢复，不能只凭面积小宣布有效定位 |
| 最小成功组的逐题移除见证 | 指明哪道题依赖哪个组，区分纠错、保护补偿和跨题覆盖 |

重点考察最多替换一半坐标的集合，同时完整报告 1、2、3、4 组结果。一半是本轮的操作尺度，不是理论阈值。还须留下超出数值重放误差的未恢复差异，连续报告差异覆盖量，避免用微小浮点残差包装局部性。

在合法对齐的局部组合上，追加红球／绿球供体交换：查看球颜色答案是否随供体变化、其他事实是否保持。跟随错误颜色供体不算修复成功，只说明替换可传递事实区别，也可能走旁路。若只改变拒答状态，报告回答开关作用；这不自动等于无用，也不是事实内容定位。

输出三种联动图：**图片与真实回答、有正负方向的 D4 热图、附逐题见证的成功组合图**。A 是观察阶段，不预设局部组合或组合优势一定存在。

## 5. 阶段 B：toy，独立检验从图中得到的判断

### A 结束后必须冻结的内容

最多提出一条图导出的判断，写清：读取什么信息、如何选集合、替换多少坐标、允许多少模型查询、何时弃权。记录“哪个图格提示什么 → 新案例应出现什么 → 什么结果会推翻”。

待检验假设：**冻结规则在新场景上，更容易选中能纠正已观察错误的同大小操作。** 具体规则要由 A 的真实现象提出；现在不虚构已经发现的规律。B 在规则填实前不是可启动合同。若 A 只有整图恢复，或所得判断已被简单位置规则完全解释，不为凑第二阶段发明优势。

### 确认材料和公平对照

- 先冻结至多 96 个未用于旧实验和 A 的来源场景，按来源划分固定排序，目标取得至多 24 个合格确认案例。取样资格同 A；不能按替换结果补样，不足就报告不足。
- 各规则必须在查看待评操作的真实回答前提交选择。最终回答由独立评估记录揭示；即使评估者测了全表，也不能提前供选择规则读取。
- 对照包括：同坐标数随机集合；正常／异常表示差幅最大的组；普通单组激活替换得到的选择；A 上表现最好的固定集合。标签、供体、数据、替换大小和查询上限相同。
- 实施时普通单组对照用固定参照的间隔增益选择，不提前读取单组干预的真实回答；尤其 k=1 时也保持先提交选择。相同查询上限不代表实际查询数或耗时相等，各方法实际工作分列。
- 前缀评分也计成本，不能把十次评分当零查询，与一次生成声称等资源；分别报查询类型、token 工作量和真实 GPUh。随机结果可在隐藏全表中精确平均，不必重复运行随机种子。
- 若我们的规则等于最佳固定集合，或普通激活替换给出相同判断，报告没有独立增量。A 的开发成本单列，不能只算 B 的速度。

### 主要结果与统计

主结果：选择的操作使两个事实端点实际正确，并满足该例冻结的其他要求的案例比例。按基础场景计数，另报逐题纠正／损害、弃权、未决、覆盖及成本。P 为空时保护损害记“不适用”，不记零。

同场景成对比较，报告分子分母、差值和按场景处理的不确定区间；同时作多项优越性判断时控制该组比较的多重性。24 是小规模上限，不是保证检出效果的样本量。区间太宽说明证据不足；全相同也不能用零宽重采样区间发总体证书。

本轮可视化的作用是产生并检查后续判断。未安排“看图／只看同一数表”的使用者实验，所以不额外宣称图形呈现本身提高准确率。

## 6. 理论给出的预期与结果分流

| 预期／结果 | 依据或下一步 |
|---|---|
| 全部恢复及同状态复制应满足接线合同 | 相同输入、参数和确定性执行；不满足先修测量，不当科学负结果 |
| D4 增加仍可能答错 | 它只测固定前缀下的一个竞争位置，不能保证整段答案；旧实验也已见评分与生成分离 |
| 单点数值不能直接加成组合成功 | 理论未假设可加或单调，所以真实测组合 |
| 局部干预成立，独立比较也有增量 | 支持该模型／条件下的诊断方法，后续才研究参数修复 |
| 局部干预成立，简单对照同样有效 | 有可干预位置，但没有本方案的额外贡献证据 |
| 全集成功，所有真子集失败 | 当前四组入口没有更小恢复方案；不是模型不可修，也不自动追加更多层碰运气 |
| 只有评分改善，完整答案仍错 | 只获得评分作用，没有找到有效恢复操作 |
| 无合法供体、证据遮挡或无法对齐 | 当前材料不满足方法条件，不是归因被证伪 |

有用组合存在与否、实际提升多少、图导出规则能否胜出，**现在没有正面证据，不预测百分比或论文等级**。

## 7. 工作量与实施边界

A 至多 12 案例 × 每例至多 6 个节点 × 16 集合，即至多 **1,152 次自由生成**。若 B 用完整隐藏表评估，24 案例对应至多 2,304 次。正常参照、资格筛查、供体交换与独立评分另外计入，隐藏表成本不得免费提供给被比较规则。

本轮不重训污染模型、不做修复训练、不重跑六方法。先完成新接口一次冒烟计时，再由真实成本估 GPUh，不用旧训练 ETA 套算。维持软预算，不设到点掐断。运行前需取得固定新材料、确认原 B0、按 Ponytail 实现缺少的测量；继续遵守不影响队友服务器作业的要求。

## 8. 同行基础与贡献边界

激活替换是复用方法。原研究已显示异常构造、评分和联合替换方式会改变定位结果，因此本轮固定操作及评分条件，保留单点与组合对照。[Zhang 与 Nanda，§3–6](https://arxiv.org/html/2309.16042v2)。

因果定位也不自动指明应修改哪些参数；知识编辑研究提供了定位不足以优于简单层选择的实例。因此诊断和权重修复分别验收。[Hase 等](https://papers.nips.cc/paper_files/paper/2023/file/3927bbdcf0e8d1fa8aa23c26f358a281-Paper-Conference.pdf)。

本轮要获得的是：真实污染事实错误中，归因图是否提供了可独立检验、简单对照未同样提供的操作判断。有限集合枚举、换成 VLM 或热图本身不预先算新贡献。
