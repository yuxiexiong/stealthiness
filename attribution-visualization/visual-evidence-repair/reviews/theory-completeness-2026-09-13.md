# 全体系审计：公式是否有用，理论实际支持到哪里

日期：2026-09-13。审查范围：[当前立项](../PROJECT_CHARTER.md)、[D1–D4](../THEORY_DIAGNOSIS_EXTENSION.md)、[D5–D7](../THEORY_DIAGNOSIS_DECISION.md)，以及[N1–N10](../THEORY.md)与当前主线的连接。原 C/V1/V2 归档不属于当前主张，本轮不重写它们，也不声称重新审查了其全部证明。

三名 sub-agent 分工全文审查 D 推导、新决策稿用途及旧 N 体系，主代理重新阅读三份理论并综合核对。没有沿用上一轮“规范通过”来判断完整课题通过；没有新增文献查重、代码测试或模型实验。

**结论：未发现推翻现有主要推导的代数错误，但完整课题的正向理论仍未闭合。已经成立的是“怎样可靠地测量和归纳有限状态干预”；尚未成立的是“归因读数怎样帮助更好诊断、怎样据此选对参数处理”。后两者不仅缺实验，也缺具体方法及可检验的联系。**

## 1. 什么算僵尸公式

本次不按公式是否复杂或是否原创决定去留。必要的操作定义，即使简单，也需要保留。判断标准是：

- 输入能否取得，前提能否检查；
- 是否直接决定测量、选择、排除、停止，或支撑必要的证明；
- 删掉后是否丢失实际能力或清楚的证据边界；
- 有没有把“已经测完结果之后的整理”，说成“事前就知道选什么”。

只是在理论中再写一遍通用优化器名称、将已经知道的结果定义为残差、或重复表达已有集合关系，不能因此算新增的诊断能力。历史复现需要的式子继续存档，但不计入当前课题的理论支撑。

## 2. 当前理论逐项审计

| 项目 | 正确性核查 | 实际用途与结论边界 | 本次处理 |
|---|---|---|---|
| D1：正确参照 token 对全词表竞争者的间隔 | 固定参照、确定性贪心、无遗漏处理器／并列等条件下正确；逐步正间隔到 EOS 可推出该参照串 | 为 D4 定义连续评分坐标；仅一个位置转正不保证整个答案正确 | 保留测量定义；纠正“没有 D1 就无法防止分数与恢复混淆”的用途夸大，实际验收由 D2 负责 |
| D2：状态坐标替换 | 不重叠掩码下正好复制选中坐标；供体、对齐、一次 prefill 和新缓存均已定义 | 明确实际做了哪个干预，是可重放操作的主干 | 保留 |
| D2：逐题正确性与联合成功 | 二值判定的乘积等价于所列题全部正确；空保护明确未测 | 外部真值与真实生成供 D3 和反驳判断使用；不推到未列事实 | 保留逐题和联合两层，不能只留总成功位 |

| 原 D3b：允许范围存在性与交集等式 | 两式均正确，来自每个成功集含一个极小成功子集 | 是读取已知表的推论，没有新增识别信息或取得数据的效率优势 | 删除独立显示公式，合并为短推论与简短理由；同步去掉“免于盲试”的暗示 |

| 任意黑盒的最坏查询范围 | 漏查子集仍可改变极小组合，构造成立；不要求所有实例都查满 | 限制粗分组规模及“已经找全”的声明 | 保留短论证，不新增复杂度公式 |
| D4：指定上下文下的间隔变化 | 固定前缀、位置、有限分数下差值定义正确 | B 已用其跨题均值选位，确有消费者；但未显示相对固定左上的增量，也不保证联合成功 | 保留为连续评分支线；加入下节反例的用途说明 |
| D5：判断、竞争解释、检查、反驳 | 规范逻辑成立，允许解释并存与未决 | 要求研究者提供具体判断和预测；本身不会从图中自动产生正确解释 | 保留为方法开发规范，不算正向效果定理 |
| D6：相同状态观测、相反参数动作 | 两种模型的四个更新后间隔及正常保护计算正确 | 排除仅靠同一份起点状态记录保证选对参数动作；要求新增参数响应信息 | 保留有用反例；不解释为所有白盒方法不可行 |
| D7：同信息、同资源与独立验收 | 比较规范成立，非数学效果结论 | 定义如何认可增量，不推出增量存在 | 保留评价规范；补“同参数响应、去掉原状态归因指导”的对照要求 |

当前没有理由删除 D1/D4 来制造“每条公式都已经产生疗效”的表面整洁。它们有明确测量和历史选位用途；需要删除的是对其作用的夸大。若新方法最终不再消费 D4，它应留在辅助分析，而不能强行占据方法核心。

压缩后的针对性复核还修正了“无损归纳”的措辞：最小组合保留允许范围内的存在性及共同必需位置，不足以还原完整 F 表。非单调条件下，同样的最小组合仍可对应不同超集结果，所以不能据它填补未测组合。

## 3. 一个直接限制当前评分规则的反例

**以下是数学构造，不是模型实验数据。** 它针对 B 使用过的“跨目标题平均 D4 最大”规则，说明该规则一般不能保证联合纠错。

设有两道目标题，每题的正确与错误答案都只含一个答案 token，之后固定输出 EOS。正确 token 的 logit 为 m，错误 token 为 0，所以 m>0 就答对。两题正常供体均答对；异常情况下的间隔分别是 −10、−1。比较两个同大小的单组替换：

| 操作 | 第一题替换后间隔 | 第二题替换后间隔 | 相对异常的两项 D4 | 平均 D4 | 两题都答对？ |
|---|---:|---:|---|---:|---|
| A | 10 | −0.5 | 20、0.5 | 10.25 | 否，第二题仍错 |
| B | 1 | 1 | 11、2 | 6.5 | 是 |

这与 D2 的状态复制兼容：取两坐标的异常状态为 (0,0)、正常状态为 (1,1)，A/B 各复制一个坐标。第一题间隔由 −10 加上 A 坐标的 20 倍、B 坐标的 11 倍得到；第二题由 −1 加上 A 坐标的 0.5 倍、B 坐标的 2 倍得到。全部复制后的间隔为 21、1.5，两题正常参照正确。答案步令 EOS 不胜出，下一步令 EOS 固定胜出即可满足完整生成条件。

**实际推进作用：** 新选择规则不能把平均分最大当成“所有事实一起恢复”。一个题的巨大改善可以掩盖另一题继续错误；除了评分大小，还必须对应实际要求及逐题状态。本例保护集合为空，不把它伪称为已构造的保护失败例子。

这也没有推出“换成最小值评分就解决课题”。多 token 生成、未测操作、供体混入与参数更新仍是不同问题。下一步需要明确使用哪项额外信息改变选择，不能只换一个聚合函数就宣布闭合。

## 4. 历史 N1–N10：可以复用什么，不能借来证明什么

N 正文保留不变；本轮只增加历史用途提示。逐项核查没有发现新的代数错误。

| 公式 | 历史中为何需要 | 对当前主线的处理 |
|---|---|---|
| N1：候选平均 log probability 与参照 | 定义旧 CE、候选评分与资格 | CE 可作工具；旧候选分数和参照资格不直接移植到 D |
| N2：有限 PGD 人工扰动 | 定义实际搜索与梯度流 | 当前 K 不使用人工扰动；不算当前诊断依据，未来 U 需重新说明用途 |
| N3：成对事实响应的差分 | 复核旧热图及旧正则项 | 是响应偏离，不是损伤真值，不证明位置或治疗价值 |
| N4：静态幅度权重 | 复现 G 与 Gl 的权重对照 | 范围／均值证明只控制尺度；目前不支持重新作为主方法 |
| N5：共同损失及采样尺度 | 保证历史实现的平均目标一致 | 按具体新算法复用选中的项，不能整体继承为治疗理论 |
| N6：方法差异及响应／节点目标 | 固定旧消融对象和分母 | 历史复现保留，当前没有对应的新训练消费者 |
| N7：旧损失的链式梯度 | 定义反传、排查 detach 和允许参数作用 | 标准计算工具，不证明高偏离值得修，也不是 D4 的参数导数 |
| N8：完整 AdamW 更新映射 | 确保动量、裁剪、衰减和实际更新被记录 | 执行规范，不是疗效或收敛保证；当前不重复展开成定理 |
| N9：一阶项与有限步残差 | 检查一次预测是否符合更新后的真实分数 | 后验近似核验，不是已有的事前排序保证；详见下段 |
| N10：校准、候选选择和回退 | 决定历史交付哪个模型 | 可复用流程，旧阈值／人工校准不自动适用；不保证正常总体无损 |

N9 最容易成为当前主线的僵尸公式：它用“实际更新后的分数减去一阶预测”定义残差。要检查残差是否足够小，必须先得到两个更新后的真实分数；此时哪个候选更好已经知道。它能够告诉我们这次线性近似是否可信，却不能自动节约试处理，也不能让我们在没试之前保证选对。

因此，N9 在历史记录中继续保留，当前正文明确不把它当治疗选择保证。如果未来要重新使用，必须让它预测尚未测过的对象、选择更新尺度或决定弃权，并验证额外价值。不要先补一个无法取得的曲率上界，再把最关键的准确性藏进假设。

旧反例仍有边界用途：共同偏置可能逃过响应差分、幅度加权可能把更新方向反转、共享 embedding 扰动未必对应真实触发。它们反驳过强的普遍主张，不给新的正向修复方法。

## 5. 当前理论究竟支撑课题到哪一步

| 课题想做到的事 | 当前支持程度 | 为什么 |
|---|---|---|
| 判定哪道事实题答错 | 有明确定义与可执行测量 | 依赖外部真值和真实回答；不是归因独有能力 |
| 判断某个指定状态替换是否纠正已见错误 | 有可执行干预和验收 | D2；A/B 对部分合格案例提供实证 |
| 从完整有限表找出不能再缩小的成功组合 | 有正确的有限分析保证 | D3；保证对象是该接口、供体、分组和题集 |
| 说明这些位置就是被污染权重或原始病因 | 不支持 | 恢复操作可补信息、绕开故障或补偿其他操作损害 |
| 归因分数指导少量检查，并优于强搜索 | 尚未支持 | 具体新选择规则及正向条件尚缺；B 的现有规则没有相对固定位置增量 |
| 从诊断选出更好的参数处理 | 尚未形成完整方法 | D6 证明状态证据不够，新增参数信息与归因的分工尚需实例化 |
| 无测试供体地永久修复，且保护正常能力 | 尚未支持 | A/B 未更新参数、保护为空；旧 toy48 真实触发修复失败 |
| 迁移到未知触发、新模型／污染实例 | 尚未支持 | 当前 K 权限和同模型结果不等于未知条件保证 |

**已经完整的是 D2 → 实际结果表 → D3 → 有边界的恢复组合结论。** D1 → D4 提供另一条连续评分支线；它是否改善选择还没有正向保证。D5/D7 规定怎样把这个问题说清和测清，不能替代问题的答案。

立项里的“纠错与正常保护存在可利用的分离”目前仍是宽泛设想：尚未定义哪种观测能识别这种结构，以及识别后为何对应某种处理。不能把它与一组无关的标准公式并列，就算已经完成解释。

## 6. 缺口的类型与下一步要求

不是每个缺口都该靠再加数学，也不是每个缺口都只能靠实验。

1. **先缺方法定义：** 从哪项 D4 或组合观测，提出哪种具体判断；该判断怎样改变一项合法检查／处理。当前不能把“请先写出判断”当作已经写出了判断生成方法。
2. **随后缺正向连接：** 固定具体方法后，分析在什么可测条件下它会选对、什么情况下会失败。不能用“高分正好代表有效”作前提；也不要求预先证明真实 benchmark 平均领先。
3. **最后缺独立证据：** 真实模型是否满足上述条件，正常保护是否通过，新增信息是否有用，以及归因是否比同信息直接搜索更划算。

若新增参数响应就已足以完成选择，必须允许它作为强基线；只有保留同样参数信息、移除原状态归因指导后出现差异，才能讨论原归因信息的增量。可视化继续用于提出、展示和核对判断，但其参与过程与其比较优势分别记账。

本轮完成了公式清理和支撑范围修正，没有通过定义更弱的验收来宣布课题成功，也没有启动新的模型实验。
