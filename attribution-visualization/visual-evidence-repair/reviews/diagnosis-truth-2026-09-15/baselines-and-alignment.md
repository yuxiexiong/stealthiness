# 独立跨审：同行定位、公平比较与读图边界

日期：2026-09-15。审查对象：新版 `DIAGNOSIS_GROUND_TRUTH_PLAN_2026-09-15.md`、`repair/diagnosis_truth.py`、`repair/diagnosis_truth_run.py`、`repair/diagnosis_truth_report.py`。本记录不把软件验证写成模型实验结果。

## 结论

实验已经围绕“有事实答案、有有限干预答案的独立诊断”展开，没有把净化后的回答冒充定位准确率，也没有把完整有限检查表冒充全模型污染根因。**本审查提出的四项问题均已修复关闭：评分对象、原生选区独立评卷、固定几何候选池与成本核算，均核对到实际调用。** 下文保留初审问题及对应修复证据；最后两轮只核对应差异，没有重复跑整套测试。

## 需要修复的具体问题

### 1. AtP 只解释拒答，主方法却解释所有答案

**状态：已修复并接入。** `measure_unit` 直接将 `complete_candidates` 的完整候选传给新接口，公共 packet 保存每候选的 576 token 效应。`predictions` 对实际选区先求各候选有符号效应之和，再取候选间最大幅度；不再用 36 格按面积插值处理细格。

初审时 `measure_unit` 只把正确答案和拒答送入 `atp_scores`；主方法 G 保留全部事实候选，并按任何候选的变化排序。若模型由一种错误颜色转到另一种颜色，拒答分数可以基本不变。这样测出的差异含有解释对象不同的影响，不能归为方法能力差异。

已经补上 `atp_candidate_scores`：每个完整候选（包括 EOS）只计算一次梯度，复用现有 `_candidate_gradient`，再计算各候选相对固定拒答的效应。它同时保留 36 格和原生 576 token 的有符号结果，免去把粗格效应按面积均分到细格的假设。旧 `atp_scores` 保持不变。调用方须使用新接口，保留所有候选，并声明仍是 **basic AtP 适配，不是 AtP***。

任意掩码的一阶联合效果应先在每个候选内求掩码中 token 的有符号和，再在候选间比较幅度。逐 token 取绝对值后相加会丢失抵消，可作为另一种重要度排序，但不能直接称联合效应预测。

验证：本机已有 `.venv-attribution/bin/python tests/test_diagnosis_comparison_backends.py`，6 项测试全部通过，运行 1.333 秒。新增测试覆盖完整候选分数与现有计分器一致、每候选仅一次梯度、已替换背景效应严格为零、原生 token 与 6×6 聚合一致、参数和原始生成不变、异常路径移除 hook。测试使用真实 tiny HF LLaVA 架构；不是生产 GPU 或完整模型验证。

### 2. 只数后续检查，不等于端到端更省

**状态：已修复并关闭。** `costed_metrics` 已加入方法前置费、后续生成、首次供体捕获、CleanSight 校准摊销，输出以 G 初始成本为参照的 0.25/1/2 倍预算曲线，并按独立场景汇总。首次差异复核另发现的两处费用错误也已处理：

1. 旧实现的 `instrument_seconds` 已含 empty/full 完整评分，G 再加公共行评分会重复收费。现实现用这两个明确的 `prepaid` 条件排除增量重复；完整仪器验收成本只加入一次，并由 `common_instrument_seconds` 单列。当前预算是**含统一仪器验收的本实验总计算口径**，不是剥离验收后的纯算法快慢；`scope` 已写明，不能换成后一种说法。
2. `coarse_minus_cell` 相对整粗块 `reference_id` 定义。现实现为每种 policy 维护 `paid_generation`；没有购买整套图的 AtP/外部 selector 首次使用粗块参照时补计其生成费，之后缓存，已购买公共生成的 G/answer-map/nearest 不再重复收费。

最后差异复核已读到上述函数与针对性 fixture：设定成本下 G 初始为 31、AtP 初始为 27；第一次粗块参照及隐藏检查后的累计费用分别为 40 和 41。这里只核对了实现与测试断言，没有重跑测试，也没有将示意成本称为实际 GPU 测量。

初审时 `_discovery` 的前 1/4/8/16 项只累计选中的检查，`cost.json` 另存全表物理开销和 selector 秒数；没有按方法加入初始测图、梯度、供体捕获、检测校准及后续生成。G 已经消费的几十个初始操作不能免费。

必须分别保留：①相同已付证据下，下一批检查的发现率；②各方法实际需要的初始证据加后续检查的逻辑成本；③评估器构造完整真值表的物理成本。CleanSight 的 200 个校准问题应单列一次性成本和声明后的摊销口径；不能默默删除。仅有前 k 项更好，可以支持排序质量，不足以支持总时间或总查询更省。

### 3. 官方原始掩码不能被投影排序悄悄替代

**状态：已修复。** `measure_unit` 在公共表封存和完整评估表形成之后，单独创建 `native-selector-checks.json`。原 mask 与等面积 control 保留真实 token 索引、完整生成、分数、正确性和测量成本；不进入共同排名。空 mask 与重复几何通过条件缓存复用同次实测，但 tags 保留每种方法和角色，不因合并而丢失记录身份。文件明确标注不是原生净化结果。

PurMM/CleanSight 的原始不规则 576 token mask 已被正确保留。但初审的公共排序按“与 mask 的重叠比例”排，相同比例优先小面积：一个 4 token 子格可能排在官方整个 mask 前面。这是合理的**新任务投影适配**，却不是官方选区本身。

应单列每种方法原 mask 与其等面积随机 mask 的完整实测结果、面积和成本；即使 mask 为空，或恰好与一个已知操作重合，也要保留这一行。统一供体替换只测“该选区在统一检查下有何影响”，不能替代 PurMM 原生置零、CleanSight 原生注意力净化的论文结果。无需在本轮加入治疗，保留这一表述边界即可。

### 4. 固定几何总榜不能免费借用其他方法的提案

**状态：已修复。** 公共 packet 的 actions 直接来自固定 `catalogue`，`validate_packet` 按相同固定清单校验；原 mask 和面积对照仅在独立旁表生成。因此 G 的统一排名没有借入外部方法提出的新几何区域。已有几何仍原样保留，未因外部方法碰巧选中而删去。

`append_selector_actions` 为保留原生 mask 而添加方法生成的候选，这些候选及等面积控制出现在公共 action 池中。若所有方法都在这个池中排序，G 也获得了 PurMM/CleanSight 提议的几何位置；这不是隐藏答案泄漏，但不能称无需同行定位即可独立提出该检查。

最小修复是：固定几何清单用于统一下一检查排序；方法原 mask 和面积对照另表评卷。已有几何操作即使被外部方法同时选中，仍应留在固定清单中，不能因为多了 selector 标签就删除。若决定使用合并池，必须称“公共候选池条件下的排序”，并说明提案生成权限与成本。

## 已经对齐、无需扩大实验的问题

- **不混治疗。** `external_localize` 保留原回答，CleanSight 只检测并选 mask，不调用实际 pruning；PurMM 只重建注意力并选点，不做置零后再次生成。已有 CPU 测试检查原始输出、参数和 hooks。runner 还检查原始生成 token IDs 一致。
- **事实来源独立。** `verify_facts` 对锁定的 CLEVR question engine 和 scene 哈希核验后重新求值。源 scene 决定接收事实和供体事实，不由热图决定。入选依赖正常答对、异常答错与可见性，不依赖干预成功。
- **正常配对有明确用途。** 同一场景另外运行正常接收输入；普通语义替换也能改变正常模型，不能把所有变化称为污染证据。
- **供体匹配不是来源证明。** `source=donor` 实际表示输出文字与独立供体答案匹配；`donor_answer_match` 保存了这一可核验事件。它可提出供体影响的假说，单独不足以证明内部信息来自供体，更不表示任何供体跟随都必然异常。
- **公共图片不是 oracle。** reader 使用实际模型处理后的接收图，白名单不带 oracle、scene/program 或全部隐藏结果；图和表都得到相同接收图、事实答案、已测完整回答与坐标。正常事实答案是已授权外部标尺，知道事实与知道未测干预结果不是一回事。
- **可视化比较的口径成立。** 同一场景只给同一读者一个版本，热图与表格同数字，读者提交与证据包哈希绑定。尚无人读时明确未执行。自动算法不能凭渲染得分宣称热图额外贡献。原生 selector 标签是字典，reader 应将 kind/method 转成文字，避免 `[object Object]`。
- **关系主张有限。** 有限检查表能验证指定位置、供体与背景下的回答影响，以及相对单格的联合结果；不能识别全部污染权重或唯一病因。`unique_transitions` 是非重复回答转移，不是不同内部机制的数量。

## 同行身份与原协议边界

- [PurMM，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/40867)，[官方代码](https://github.com/WinzhengKong/PurMM)：注意力聚类、深层筛选得到选区，再置零净化。当前比较其**净化前选区在统一检查下的定位价值**。
- [CleanSight，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Zhang_Test-Time_Attention_Purification_for_Backdoored_Large_Vision_Language_Models_CVPR_2026_paper.html)，[官方代码](https://github.com/zhangzf01/cleansight)：独立正常校准后的检测与注意力 token 筛选，再净化。本轮保留 detector 不命中时的空选区，不能偷偷改为无门控 saliency。
- [AtP* 原文](https://arxiv.org/abs/2403.00745)：完整方法含 QK 修正和梯度丢弃等处理；当前入口梯度乘供体位移只能叫 basic AtP。
- [NOTICE，NAACL 2025](https://aclanthology.org/2025.naacl-long.571/)，[官方代码](https://github.com/wrudman/NOTICE/)：语义图对、模块与头干预，是直接近邻；作者 LLaVA patch 接口与当前 576 视觉入口不相同。不能将自家精确单区扫描改名为完整 NOTICE 复现。

上述论文没有建立本实验完整条件诊断任务的统一冠军。这里应称“已发表直接同行定位组件＋同权限强对照”，不能称已复现原协议 SOTA 总榜；也不能只因未找到统一榜单就断言整个领域不存在统一 SOTA。

## 交接验收

本审查新增后端已经通过最初的 6 项 CPU 测试；差异复核确认全候选 AtP 已实际调用、原 mask 包括空集有独立结果、固定几何排序不混额外提案，公共控制不重复收费且首次关系参照生成已计费。**本审查四项均关闭，没有留下新的公平性必修项。** 主线程后续测试以最终统一测试记录为准。模型有效、优于同行或可视化有效，仍须等新模型与独立读者实验。
