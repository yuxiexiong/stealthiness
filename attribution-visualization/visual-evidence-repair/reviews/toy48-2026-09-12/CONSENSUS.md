# toy48：三份独立分析后的共同结论

日期：2026-09-12。审查对象：`831344b`，即 Claude Code 分支合入 main 的完整代码与报告。本次只读服务器结果，未重新训练或调用 GPU。三位审查者先分别阅读代码、计划和结果，再独立复算原始记录；总控核对分歧后形成本文。原提交的结果稿保留，本文修正其中超过证据的解释。

**结论：这次确实完成了六条训练与交付流程，但没有实现本课题要求的真实触发下正确作答恢复。与此同时，“更新完全没有影响触发通路”这个解释不成立：保存的分数清楚显示模型已发生变化。当前归因加权规则尚未证明优于等权或普通难度加权，整个归因修复方向也没有因此被证伪。**

## 3. 实际回答：修复没有过关，正常能力有取舍

B0 是未修复起点。G 是本方法的归因加权；G0 将响应项等权处理；Gl 用普通答题难度重新分配同一组权重；SFT 只用正常正确答案微调。

| 最终交付方案 | 正常事实题正确数 / 576 | 正常 VQA 得分 | 触发事实题正确数 / 576 | 触发 VQA 得分 |
|---|---:|---:|---:|---:|
| B0 | 277（48.09%） | 0.7177 | 0 | 0.0100 |
| SFT | 404（70.14%） | 0.6867 | 0 | 0.0100 |
| G | 306（53.12%） | 0.7143 | 0 | 0.0100 |
| Gl | 303（52.60%） | 0.7117 | 0 | 0.0100 |
| G0 | 294（51.04%） | 0.7157 | 0 | 0.0100 |
| R+、RACER-data：均回退 B0 | 277（48.09%） | 0.7177 | 0 | 0.0100 |

事实测试包含 96 个场景、288 个编辑问答对、576 个端点，不能称为 576 个独立配对。VQA 是 300 道题的人工答案一致性得分，0.0100 不能直接解释成恰有三道题答对。

在触发 fact/VQA 上，保留的四个更新前后生成逐条相同；所有事实题仍答 `Unable to answer.`。这支持“当前交付方案没有恢复正确作答”。R+、RACER-data 虽然各训练了 400 步，但其校准 VQA 分别下降 2.34、1.41 个百分点，超过预定 1 个百分点门槛，最终测试没有加载它们的更新。**不能把两次回退说成这两个训练后模型的真实触发结果，也不能借此宣布超越 RACER。** RACER-data 本来也是共同数据下的改编对照，并非原论文完整复现。

正常事实题方面，G 相对 G0 净多答对 12 个，差值为 +2.08 个百分点，95% 同时区间为 [−1.74, +5.90]；相对 Gl 净多答对 3 个，区间为 [−3.30, +4.34] 个百分点。归因加权优势没有得到支持，但区间还允许几个百分点的正收益，不能解释为已经证明等效。

SFT 在正常事实题上比 G 高 17.01 个百分点；G 的正常 VQA 得分又比 SFT 高 2.77 个百分点。这是任务之间的取舍，SFT 并没有完成后门修复。通过小型校准集也不保证独立测试没有损伤：SFT 正常测试 VQA 比 B0 低 3.10 个百分点。

净分数之外，G 在正常事实题中救回 40 个原本错误的回答，同时损坏 11 个原本正确的回答；SFT 分别为 149 和 22。故不能用总分上涨替代“正常事实不受损”。

## 4. 最关键的纠正：回答没变，模型的评分已经变了

我们检查了真实触发图片上的保存分数。G 的 **576/576 个事实节点候选分数向量发生变化，正确候选分数全部提高，平均提高 3.7037**。这里的分数是完整候选答案（含结束符）的平均 token 自然对数概率，不是正确率。

例如原始记录第一对图片的两个正确答案分别是 cyan 和 purple。G 修复后，它们的分数分别从 −11.3442 提高到 −8.9974、从 −9.1516 提高到 −6.0772，但两题实际生成仍都是 `Unable to answer.`。

这意味着：**训练的影响已传到触发输入下的答案评分，只是没有转化成我们需要的正确回答。** 不能因此断定已定位后门通路、已经恢复潜在能力，或只要继续训练就会成功。候选列表里没有拒答句，目前也没有测清“正确答案与拒答究竟还差多少”。

G 的正确候选相对最佳错误候选的间隔平均改善 0.7475，431 个节点改善、145 个恶化；这仍只是候选集内部的描述性诊断。G0、Gl 也有类似变化，因此不能把这个现象独占为归因权重的贡献。

原稿用来支持“未触及”的 N9 结果，实际来自起点模型、一个训练单元、一次 AdamW 更新，并在正常 dev 上观察。它没有测 400 步后的最终模型，也没有测真实触发，不能用于排除“力度不足”等替代解释。

## 5. 归因可视化目前有什么真实证据

保存的 G/Gl 人工扰动展示各有 24 个训练配对，其中只有 **5 个配对**通过正常参照资格并获得修复前后测量。对这五个固定配对、同一组冻结人工扰动，响应偏离的均方值为：

| 测量 | 起点 | G 修复后 | Gl 修复后 |
|---|---:|---:|---:|
| 五对平均响应偏离，越低越接近参照 | 4.2233 | 1.9650 | 1.0813 |
| 十个端点的实际答对数 | 0/10 | 8/10 | 8/10 |

**这五个训练案例确实改善了；Gl 同样改善，而且平均偏离更低。** 不是只有画图好看、答案完全没变；但也不是独立测试通过，更不是 G 权重优越性的证明。其余 19 个无效展示不能当成失败或成功，也不能把 5 个案例外推成全部训练集效果。

B 还做了一项事后离线分析：按起点模型的正常资格筛出 75 个测试配对，真实黑块触发下的平均响应偏离从 1.7974 降到 G 的 1.5812、Gl 的 1.5374，自由生成仍全拒答。它提示真实触发下的关系测量也并非完全不动。这是探索性描述，尚未完成每张打标图的可见事实核验，不是预注册成功，也没有显示 G 独有收益。

后续若制作机制对照，最有用的呈现方式是把同一案例的“正常参照、人工扰动前后、真实黑块触发前后”数值与实际回答并排。**这是后续展示设计，当前尚无同例完整对照：五个人工展示来自训练集，真实触发记录来自测试集，不能直接拼成同一案例。** 补测应在隔离诊断中另行登记。图帮助检查关系变化与回答恢复是否相连，最终裁决仍由原模型实际作答决定。

当前理论只给条件性方向判断，没有保证人工扰动等价于真实触发，也没有保证响应偏离下降就能恢复正确回答。因此这轮负结果与理论不矛盾；同样，不能用“理论没有保证”回避方法在真实任务上尚未成功的事实。

## 6. 哪些问题还没回答，下一步如何节省投入

1. **响应本身是否提供修复收益：未得到支持。** G0/R+ 的最终交付比较受 R+ 回退影响，不能纯粹分离响应损失的因果贡献。被拒更新的独立触发表现仍未知。
2. **归因加权是否优于等权或普通难度：未得到支持。** G/G0/Gl 的直接比较有效，但没有显示明确的实际作答优势。不能靠五张训练热图补足。
3. **人工扰动训练能否修好真实触发：当前配置没有做到。** 这是本轮最明确的负结果。单模型、单污染与修复 seed、一轮 400 步，不等于对所有合理条件的否定，也没有证明各方法已经收敛。

先不重复整轮训练，也不扩多 seed。下一次投入应围绕一个具体断点，而不是同时换模型、损失和预算：

- 先确认触发图片仍保留所问事实的可见证据。当前构造检查了图片是否塌缩，却没有按对象 mask 证明黑块未遮住答案依据；原测试口径保留，有效事实子集另列。
- 若追加最小诊断，应直接比较“正确答案与拒答的竞争”，以及未见人工扰动上的响应和实际回答。现存分数足以证明模型已变，却不足以判断拒答为何仍占上风。
- 需要分清三个原因：人工扰动覆盖不到真实问题；优化目标拉扯；当前更新强度不足。现有证据不能选定其中一个为病因。后续每项实验应只区分其中一个，不盲目延长六臂。
- 如需评估纯方法效应，保留原校准回退结果，另将被拒更新作为隔离诊断对象；不放宽门槛冒充可交付修复，也不把诊断结果反馈成原先的未知触发实验。

另有两个汇报边界：测试 caption 的 CIDEr 实际已计算，不能写成仅在校准使用；固定拒答串 ASR 会漏掉 `Unable to describe this image.` 等变体，所以混合总 ASR 的微小下降不能当作修复。主驱动还存在失败目录妨碍自动续跑的问题，这是后续运行前应修的工程点；本次已完成结果不因此自动失效。

**投入判断：保留这个课题，暂停扩大当前加权规则。理由是核心修复收益尚未出现，失败原因尚未定位；既没有证据宣布成功，也没有证据宣布整个方向不值得做。**
