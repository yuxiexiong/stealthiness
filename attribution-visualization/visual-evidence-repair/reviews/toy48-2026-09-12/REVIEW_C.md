## 2. 六臂到底在比较什么

共同的 fit 顺序由同一 seed 生成，AdamW 设置相同，全部按 `steps` 走完，不存在内部自动“48h掐断”（`core.py:194-238`；`__main__.py:49-52`）。共享参照在训练开始前固定，权重固定，训练时人工扰动由当前模型重新搜索。

| 方法 | 真实优化内容 | 能回答的问题 |
|---|---|---|
| SFT | 干净答案 CE | 普通正确答案训练能做到什么 |
| RACER-data | 干净 CE + 内部不一致；配对端点各自搜索扰动 | 同材料下的 RACER 方法重建对照；不是原论文完整复现 |

| G | R+ + 按初始响应偏离分配的固定权重 | 特定归因权重是否优于等权 |
| Gl | R+ + 相同权重集合，按答案难度重排 | 权重收益是否只是普通难度排序 |

## 4. “触发通路完全未触及”不能由相同回答推出

`TOY48_RESULTS_2026-09-12.md:74-76` 的推理确定不成立。

简单例子：模型对拒答/正确答案的分数原来是 −0.1/−5，训练后变成 −0.2/−2。两个模型都仍输出拒答，但模型已明显改变对正确答案的支持。贪心生成是离散选择，存在一大块分数变化都不会改变最终字符串的区域。相同ASR、相同exact match更不能证明概率或内部路径相同。

而且文中拿来加固推论的 N9 诊断，测的并不是此事：

- 驱动 `run_toy48_full.py:424-435` 未加 `--known`，用正常 dev 面板。
- `__main__.py:572-579` 重新创建B0，不加载最终G的update；用第一条有效fit样本从同一起点做G/R+各一次更新。
- `core.py:241-293` 默认初始零Adam动量，之后恢复模型。
- 回执明确写 `evaluation_environment=normal_dev`（`__main__.py:582`）。

所以0.095的更新差只证明**这个起点、这条训练样本、这一局部步骤**中，两种损失产生了不同更新；它既不能描述400步的最终轨迹，也没直接测触发条件。合理说法是“没有改变触发条件下的离散作答结果；是否改变候选分数和错误答案优势，仍需直接检查”。

好消息：fact pair 的 triggered `scores_before/scores_after` 已由 `observe(...,pairs_only=True)`保存，可只用CPU先算候选分数、正确候选相对其他候选的margin、变化比例。不需要新训练。但如果候选列表没包含 `Unable to answer.`，现有候选分数不能直接恢复“拒答vs正确”的完整margin，应明确这个缺口。

## 7. 已确定的实现/文档缺陷

1. **失败臂不能按宣传方式自动续跑。** `run_toy48_full.py:128-132` 只看最终回执；失败后重试 `train_command:262-267`、`evaluate_command:317-321` 仍指向原方法目录，而 `__main__.py:74-81` 要求目录不存在。只要失败发生在建目录之后、回执之前，自动重试会再次因目录存在失败。`attempt_dir`只对lane launcher起作用，不对每臂起作用。此为可从代码静态证明的缺陷；不说明最终完成的输出算错，但本轮失败repair-lanes如何保留/迁移原目录应在执行日志中说明。
2. **日程文字陈旧但当前计算未见错。** `freeze_steps.py:25`真实上限8轮；:74却写“超过3轮封顶3轮”；FULL_RUN正文也残留“上限1200”。本次400步不触及这些分支，属于可修文案错误。
3. **构建因果解释不成立。** 重建合同:71称328步成功证明“梯度稀释与更新次数不足”。它同时改变学习率、累积步与轮数；328还少于失败轮330。不能定位唯一病因。降低有效batch不改变期望毒化比例4.76%，会改变步频和梯度噪声。:23把328写成“已超过330”是算术错误。可保留“改后的优化配置成功装上后门”，应去掉已查明病因的说法。
4. **分母称呼应更正。** 结果稿:34的“576配对”实际应是576个端点/配对比较项；96场景×3问题=288个图片pair，每pair两端，不能让人误以为576独立图片pair。

## 8. 这轮实际能推进课题到哪里

可以保留三点（现已用原始回执和候选分数复核）：

1. 在这个高触发成功率的单一污染模型、固定400步、六个单配置与校准回退协议下，当前方法没有获得真实触发下的正确回答收益。
2. 归因加权G相对等权G0及难度重排Gl，当前clean指标未显示足够明确的额外收益；触发端完全没有成功证据。
3. 普通SFT更擅长提高这一轮clean fact准确率，但正常VQA上代价更大；这提示目标间取舍，不能宣称SFT已完成后门修复。

不能保留三点：

- 5条训练展示边的人工响应下降，已成为经过独立数据验证的成功机制链条。
- 输出一样证明整个触发通路未受影响。
- 一轮400步、同一个强污染起点已经判定归因修复方向没有研究价值。

通过本次复核，已确认“更新影响了候选分数，但没改变自由作答”；同时已明确回退和人工展示的真实分母。下一步应针对**正确答案与拒答的竞争还差多少**这个剩余缺口决定是否追加一次小诊断，而不是立即重复整轮GPU训练。是否因为拒答优势太大、优化目标冲突或预算不足，当前都还不能定位；不要把一个未跨过输出阈值的实验写成机制已经查明。

因此可以说“这5条预定训练展示边的固定人工扰动残差减小”。不能说归因加权因此优于普通难度：**同一展示上Gl平均残差更低**。也不能将此扩成全78有效边、独立dev或真实触发下的总体收益。保存的这些数据非常值得在汇报中诚实展示，因为它让“人工目标优化成功”和“最终拒答未解除”之间的差距变成可见事实。
