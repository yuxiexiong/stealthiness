# 第二课题重评：从归因诊断走向可比较的实际修复

日期：2026-09-10。性质：选题重评、原文定向核查与研发路线；没有新增实验，没有确认我们的方法有效，也没有宣布 SOTA。本文件补充原立项书，不将待实现的方法写入已成立理论。

后续阶段更新：用户已确认[第二版立项书](PROJECT_CHARTER.md)；第三版理论已完成三人独立、交叉复核，通过[有限条件理论验收](theory-review-v3/REVIEW_SYNTHESIS.md)，可以进入 toy 规划。本文第 5–6 节保留此前的方法候选与路线，不构成当前实验执行计划，也不表示这些实验已经运行。

## 1. 重新评估的结论

已有归因、表示编辑和后门修复，不构成否定研究价值的理由。新方法可以大量复用成熟组件，贡献应由它解决的问题、实际效果、解释力及可复现性决定。之前将近邻覆盖过多地当作吸引力减分项，需要纠正。

建议把主目标从“预测修哪个接口”扩大到“利用事实归因，实际恢复受污染 VLM 的正确视觉能力，并改善后门防御与正常能力的关系”。原来的可恢复性诊断、接口选择及失败预测成为方法内部环节。暂不承诺所有投毒、所有模态、无数据、未知触发器及全局保证同时成立。

吸引力判断：作为有真实基准、直接竞争者和具体改进终点的**方法研究目标，值得推进**。当前方法及证据尚不足以支撑一篇已达到 accept 水平的论文。若取得完整协议下可靠的性能改进，并解释归因为什么改善修复，这是可信的 ICLR 投稿路径；不要求每个组件从零发明，也不把几条标准定理当作贡献。

[ICLR 2027 官方审稿指南](https://iclr.cc/Conferences/2027/ReviewerGuidelines)明确允许更好地解决已知问题，要求充分动机、正确证据与社区价值；SOTA 既不是必要条件，也不是单独充分条件。我们的选择是追求可比较的强方法，而不是回避已有基线。

## 2. 已找到的基准与应击败的对象

| 对象 | 应如何使用 | 边界 |
|---|---|---|
| [BackdoorVLM](https://arxiv.org/html/2511.18921v1) | 现成攻击评测框架：12种攻击、5类目标、LLaVA-1.5-7B/Qwen2.5-VL-7B、3数据集；复用任务、划分及评分 | 是攻击 benchmark，不能当作已有统一防御排名；各攻击不是在所有目标上均适用 |
| [RACER](https://arxiv.org/html/2608.24354v1) | 少量干净数据的模型修复前沿候选；主协议为3模型×6攻击×2目标、100个干净修复样本 | 2026-08预印本；其表内最强不能自动升级为全球 SOTA；植入攻击使用 LLM LoRA+projector |
| [CleanSight](https://arxiv.org/html/2603.12989v1) | 测试时注意力净化的强基线，继承其原任务和正常效用评测 | 冻结可信 encoder、可调组件受污染；不等同编码器污染。已定义/评测 poisoned utility，不能说同行只看 ASR |
| [BadVision](https://arxiv.org/html/2502.18290v3) | 编码器本身被污染的机制压力测试；保留原始威胁模型与下游评测 | 它是攻击，不是修复方法。BackdoorVLM 中的适配保留 encoder-only，但数据/目标并非整套原协议 |
| [TokenSwap](https://arxiv.org/html/2509.24566v1) | 已有组合语义攻击：对象词正确而主客体关系颠倒；复用其生成任务和交换判定 | “关系错绑”不是我们的新发现。现阶段没有我们的方法或其他防御在该测试上的结果 |
| [GQA](https://cs.stanford.edu/people/dorarad/gqa/about.html) / [CLEVR](https://arxiv.org/abs/1612.06890) | 真实图像事实与可控组合场景；用于能力分解和机制验证 | 不是后门防御榜单，不能在自选子集第一就称全领域 SOTA |

主比较不混合三个问题：模型参数修复、测试时净化、异常检测/过滤。可以评价其最终服务效果，但必须分别记录数据、模型访问、拒答、推理开销和持久性。

RACER Table I 的公开困难项包括 LLaVA 的 Blended–Malicious Injection：修复后 ASR 20.4%。这是可追踪的改进点，不是我们构造出来的缺口。先用这些配置开发，最终必须回测完整预声明矩阵，不能只选择原方法失效的格子。RACER、CleanSight、其他方法之间仍需同协议重跑，不能横比不同论文的平均 ASR。

CleanSight 的 PU 证据具体位于 §5.3.3/Figure 6：VQAv2、四种攻击、oracle detector；不能将它当作已报告完整管线的 caption PU 主表。RACER Table I 的 VQA/CIDEr 是干净输入效用。区分这些证据是为了补齐可比评价，不是断言现成方法不能恢复事实。

截至本次检索，未核到覆盖上述全部权限/任务的统一防御 leaderboard。正确路线是复用现有 benchmark，建立透明、可复现的同协议比较，而不是自行宣布一条没有竞争者的小赛道第一。

## 3. Claim 应扩大到实际结果

建议主 claim（研究目标，不是已取得结果）：

> 在声明的数据与修复预算下，事实归因指导的修复能在维持正常视觉能力和低攻击成功率的同时，更可靠地恢复触发输入中的正确事实；优势在未见图像、问题及事实组合上仍然成立。

这包含三个需独立验证的部分：

1. 实际修复原模型输出，而非仅在额外 probe 上读出事实。
2. 更好的完整效果：ASR、触发输入的正确任务表现、正常能力、成本同时比较。
3. 归因在方法中确有作用：同数据、同参数、同训练预算的普通方法不能复制全部收益。

“恢复原标签/事实”作为评价思想并非新发明。[BackdoorBench 原文 §3.2](https://papers.nips.cc/paper_files/paper/2022/file/4491ea1c91aa2b22c373e5f1dfce234f-Paper-Datasets_and_Benchmarks.pdf)已有 R-Acc，即触发样本对原始正确类别的准确率。VQA 用相应正确答案指标；caption 继续保留原评分并补充事实性与信息覆盖，不把不同单位混成一个随意总分。

比较目标可以写成：在预声明 ASR、正常能力损失和成本约束内，最大化触发输入的真实任务表现。阈值在测试前固定；报告曲线和各任务结果。SOTA 资格来自完整公平比较，不来自换指标后的单个最优数字。

## 4. 归因已有人做过，应怎样借力

| 方法族 | 已有可借内容 | 我们要实际增加的结果 |
|---|---|---|
| [ProjectAway](https://arxiv.org/html/2410.02762v2)、[LTS-FS](https://arxiv.org/html/2603.16284v1) | 事实/对象内部读出、表示编辑、干预归因选层、能力保护评测 | 在污染模型上，相同资源下更好的真实修复表现；不是仅把这些模块拼接后改名 |
| [REVIS](https://arxiv.org/html/2602.11824v1)、[CRG](https://arxiv.org/html/2605.24024v1) | 视觉证据再激活、视觉/文本通路干预 | 不盲目假设视觉表示可信；检验污染编码器时何处证据仍有用，并实际利用它 |
| [SRD](https://ojs.aaai.org/index.php/AAAI/article/view/38121) | 异常可视化启发、语义奖励、图像处理后修复 | 按原训练集/参考模型权限公平比较；不能称首次把语义质量纳入后门防御 |
| RACER | 区域分析、最坏扰动、一致性修复、小干净集 | 归因测量必须比粗粒度一致性提供额外修复效益；它是强基础与强反方 |
| [CleanCLIP](https://arxiv.org/abs/2303.03323)、[CleanerCLIP](https://arxiv.org/abs/2409.17601)、[RVPT](https://arxiv.org/html/2412.20392v3) | 表示重对齐、语义正负样本、轻量视觉提示修复 | CLIP 分类结果与 VLM 生成修复分开；进入 encoder 修复时不能遗漏这些基线 |

REVIS 的限制包括无法修复绝对感知盲区；CRG 讨论视觉证据本身错误时其通路冲突机制的不足。这些是研究污染编码器的动机，不能推出 BadVision 一定属于该失败区，也不能推出早层一定保有可用事实。

我们当前独特性**尚待证明**的候选：用事实干预得到的输出响应及其交互来指导修复，区分应该保留的事实敏感性与需要去除的错误控制；证明这个信息在最终 benchmark 表现上有用。这里的新颖性评价必须同时检查相关一致性、因果归因和语义增强方法；“已有前例”决定对照，不自动决定研究价值。

## 5. 可实施的第一项 toy：带正确答案锚点的事实响应修复

这是已知触发条件下的机制 toy，不能称未知触发器防御。

校准时构造四种状态：原图 x、只改变一个已标注事实的 x^f、触发版本 τ(x)、事实变化后的触发版本 τ(x^f)。用归因图同时显示事实变化、触发变化以及两者交互在空间、接口和原答案分数上的作用。

直接更新原 connector 或既定的小型残差适配器。训练目标包括：

- 触发图像上正确答案的实际训练损失；
- 让触发状态对事实变化的响应接近经真值核验的正常响应；
- 正常任务与原本正确事实的保护。

一个可测的响应约束是：

\[
v_\phi(\tau x^f,q)-v_\phi(\tau x,q)
\approx v_0(x^f,q)-v_0(x,q).
\]

v 是原 VLM 在固定评分条件下的答案分数。正常参照可以来自同一个污染模型的未触发运行，但只保护已经由真值核验的响应，不能冻结其原有错误。最终评价必须使用原 benchmark 的自由生成与评分流程。

推理时只输入当前图像和问题；不提供干净对应图、测试答案或额外可信模型。训练期触发知识、编辑/标注成本、额外样本都要显式记录，并给可使用这些信息的对照相同权限。

必要对照：相同四格数据的普通微调、相同数据的一致性修复、去掉归因项的同结构适配器，以及适用的现成修复/steering。归因选择还要对比随机位置和普通损失梯度选点。若收益仅来自多给数据或更多可训练参数，不算归因方法收益。

## 6. 通向 SOTA 的路线与每一步产物

1. **固定公开比较协议。** 以 BackdoorVLM 的任务/评分和 RACER 的模型修复协议为主比较候选；测试时方法采用共同输入输出评测并单列开销。BadVision 原版与 TokenSwap 是独立压力测试。先冻结权限、样本单位、模型、攻击/目标组合、正常能力指标及完整成本。
2. **小范围核实改进空间。** 从公开困难配置、一个普通攻击及关系错绑攻击取最小开发集，复用已有攻击/权重。记录现成方法究竟是未去掉后门、丢掉事实、关系错误还是正常能力退化；未观察到的缺陷不预先宣布。
3. **执行上述已知触发 toy。** 先验证事实响应约束是否带来同资源额外收益；这是方法假设检验，不需要先堆一般理论。若实际接口干预无法改善原答案，停止这个接口；若同数据普通训练相同好，重新评估归因的作用。
4. **向目标权限发展方法。** 要进入 RACER 的无触发器知识协议，需要把事实响应保护与可实现的未知扰动/异常生成结合；可以借其 min-max 组件。合成扰动是否覆盖实际触发，以及是否错误惩罚真实事实变化，是此步最重要的待解问题。未解决前，只能报告已知触发修复，不能继承未知触发器 SOTA claim。
5. **完整比较。** 在全部预声明配置、独立场景及多个训练种子上比较正常效用、ASR、触发任务正确率、最差配置及总成本；保留各基线原协议结果和共同协议结果。超参不按测试攻击逐个调整。若声称覆盖新攻击/自适应攻击，需单独验证这一范围。
6. **形成可验证的领先结论。** 只有同权限完整结果优于已复现的强基线，才能写该协议下领先；若只在视觉输入或某种修复预算领先，准确限定。没有统一 leaderboard 不妨碍提交一个强方法，但也不会自动使我们成为 SOTA。

这是可执行的研究路线，不是成功保证。当前已具体化的是第一项 toy；无需将尚未实现的未知触发器识别写成已具备模块。

## 7. 现有理论还应补什么

| 要补的连接 | 对方法的实际用途 |
|---|---|
| 直接作用于原 VLM 的更新集合、监督来源和损失 | 消除“先恢复 S 再假设廉价桥接 ĝ”的断点 |
| 纠错方向与正常事实保护约束能否兼容 | 判断当前接口是否值得更新；冲突时换接口/放宽约束/未决，不能保证总能无损修复 |
| 有限干预及交互对未见事实组合的适用条件 | 避免几张图拟合正常就宣称组合泛化 |
| 原 benchmark 上的实际风险与新增错误 | 连接训练分数与最终任务恢复，核验正常能力损害 |
| 未知扰动与真实触发之间的覆盖关系 | 决定能否从已知触发 toy 进入无触发器知识协议 |

局部投影、共享线性估计和统计区间是可借的标准底座。它们的价值是指导操作和拒绝过强结论，不需要在本项目冒领新定理。真实约束必须从可测数据得到，不能把大投影分量、小误差、充足事实信息全部假定好。

保留三个关键反例：固定目标偏置可能令事实差分看似正常但答案仍错；恒定输出可能令交互消失但能力坍缩；若不同事实在所用接口彻底不可区分，同一确定性 connector 无法恢复区别。因此正确答案锚点、正常能力评价、实际接口信息检查缺一不可。

## 8. 资源与本轮完成边界

优先复用 [BackdoorVLM](https://github.com/bin015/BackdoorVLM)、[BadVision](https://github.com/6zHAOyi/BadVision)、[ProjectAway](https://github.com/nickjiang2378/vl-interp)、[LTS-FS](https://github.com/huttersadan/LTS-FS)、[RVPT](https://github.com/zhangzf01/RVPT) 与官方事实数据。公开仓库存在不等于配对后门权重齐全、依赖可装或主表已经复现。

本轮核对发现：BackdoorVLM 有任务评分实现，但未核到成套配对权重下载说明；CleanSight 公开实现与论文完整模型/评分/默认参数之间有缺口；RACER 原文提供方法和超参，但当前没有核到可直接运行的官方代码/权重交付。开始 GPU 前需要一次有针对性的资源补齐，不能承诺零训练成本，也不重复无关检查。

具体优先项：固定 BackdoorVLM 各目标的 strict/soft 或 exact/keyword evaluator；补齐 [CleanSight 官方实现](https://github.com/zhangzf01/cleansight)的生成结果评分，其公开脚本目前主要输出检测指标；将公开论文复现的 RACER 与作者官方交付严格区分。优先在与原协议兼容且资源可取得的一个模型上完成小实验，再扩大矩阵。

本轮通过原文方法、评测定义、主表和相关附录作定向查核；并非新增所有邻近论文的完整系统综述。新增前沿包括 RACER、REVIS、CRG、SRD 等，表明之前“邻近工作已查完”的理解不成立。没有下载大权重、运行新实验或改动原理论结论。旧 OA 探针继续有效，但仍不是本视觉修复假设的证据。
