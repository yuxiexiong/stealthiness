## 1. 本轮只作什么决定

用一个真实污染 VLM，把“事实归因观测 → 冻结修复规则 → 修改原参数 → 独立真实任务验证”完整走通，判断当前方法是否值得追加投入。归因给出数值，可视化帮助解释观测、冻结操作和核对得失；不把热图变漂亮当成功。

本轮检验三个问题：

1. 在共同修复底座上增加事实响应约束，是否改善真实任务？
2. 按归因偏离分配权重，是否比均匀权重及普通答题困难度更有用？
3. 只用正常材料及人工扰动得到的修改，能否在未知真实触发下改善回答，同时保护正常能力？

范围固定为视觉触发、可信视觉编码器、连接模块／语言侧受污染；修复原模型的连接模块及预登记语言 LoRA。一个合格 7B 级模型、一个污染实例、一个污染 seed、一个修复 seed。优先复用可验收资产，在看本方法效果前冻结准确骨干、污染组件、触发与攻击目标。LLaVA 与 Qwen 是二选一的加载支持，不同时跑。

不再运行两模型 × 三攻击 × 两目标 × 两污染 seed，也不运行额外干净权重的修复矩阵。正常输入保护仍在同一污染模型上逐方法检验。单实例结果只支持当前条件，不能宣布整体 SOTA、跨模型稳定性或理论普遍成立。

## 2. 两阶段，六条修复，不做超参网格

| 阶段 | 工作 | 结束条件 |
|---|---|---|
| A：观察、冻结、修复 | 一次资产验收与完整基线计时；小 dev 归因页；冻结规则、数据、训练日程；共享起点参照；运行六个方法，正常校准通过则保留，否则回退 B0 | 六个方法的冻结回执及完整成本；资产、资格或日程有缺口时如实报告，预算超出仅记录 |
| B：独立检验 | 同一组正常／真实触发 VQA、描述和事实配对测试；实际生成与原攻击评分；小型局部方向诊断、离线图及成对比较 | 支持继续、当前增量未获支持或证据不足；不自动增加实验范围 |

| 方法 | 唯一用途 |
|---|---|
| SFT | 同数据普通答案微调，排除只是多了正确标签 |
| R+ | 共同正确答案、一致性及正常保护，去掉响应项 |
| G0 | R+ 加均匀事实响应约束，检验响应本身 |
| Gl | 用普通答案 CE 难度重新分配与 G 完全相同的权重集合 |
| G | 用事实响应偏离分配权重，待检验主方法 |
| RACER-data | 论文方法在共同增强数据下的重建对照；端点独立搜索，不冒称原表复现 |

B0 为共同未修复起点，不另训练。核心比较冻结为 G0/R+、G/G0、G/Gl、G/R+、G/SFT、G/RACER-data。

每方法仅一个预登记配置。R+/G0/Gl/G 除被比较项外保持数据顺序、起点、更新模块、优化器、共同系数和曝光日程相同；RACER-data 按其方法定义保留独立扰动及损失。相同预算不等于强迫快方法欠训练：入口计时阶段在未揭示胜负前，为直接基线冻结足够曝光的日程，同时记录所有方法的实际成本。若预计超出计划，报告差额并结合实际进展讨论；不能靠减弱基线凑数，也不因达到预算数字自动停工。

P、G-shuffle、RACER-native、CleanSight、K 已知触发训练、多 seed 和多模型均后移。代码保留能力，本轮不调度；因此本轮不能宣称优于普通全节点匹配、原 100 样本协议或所有前沿防御。后续是否加做由本轮缺口决定。

## 3. 数据规模与观察顺序

复用 CLEVR 官方场景／问题程序及已有真实任务图片、标注与评分器。合法事实编辑由程序核验，不能修改 GQA 标签充当图片编辑。三类条件从第一阶段一起进入：简单事实、多事实及应保持事实、未见组合。配对两端的问题和候选坐标相同，只改变一个核验过的事实，连带关系真值也要正确。

| 用途 | 合成场景簇 | 正常真实图片簇 |
|---|---:|---:|
| dev 观察 | 24 | 不额外扩展 |
| fit | 100 个基础场景及各自一个编辑版本 | 100 |
| calibration | 32 个基础场景及编辑版本 | 64 个 VQA、32 个描述 |
| test | 96，三类各 32 | 300 个 VQA、60 个描述 |

每合成图最多四个预声明问题，包含应改变与应保持的事实。数量按独立场景／图片计，不把相关问题、候选或 token 当独立样本。图像及全部变体只属于一个划分。以上是预定规模；若首次计时表明不可执行，只能在所有独立结果封存时统一修订并留记录，不能中途挑结果删样本。

dev 最多一次有记录的规则修订，必须说明哪条归因观察改变了哪项操作。若未改规则，也明确这是预设规则测试，不编造已发现的模式。fit 全部有效边用于参照、权重及损失归一；只限制展示规模，不把权重估计缩到精选案例。固定展示最多 24 个 pair unit（按文件顺序、开测前固定），局部方向诊断最多 4 个独立 unit；展示不足或参照无效照实记录。

主任务评测仍保留真实完整生成、原停止规则和原攻击成功判定。300/60 是子集研究，不能称原 benchmark 完整复现。描述样本减少，但不通过截短输出隐藏攻击后缀、拒答或丢失内容。常规 VQA／描述只需生成与评分；候选分数集中在事实配对及固定机制面板，未计算的分数明确为 null。

## 4. 方法与新理论保持一致

N1 的完整候选串含终止符，采用平均 token log probability。正常参照需同时通过真值生成检验与唯一正确候选最大值；无效参照仍参与正确答案训练，不冻结错误答案。

N2 在配对两端同一融合位置施加共享 δ，默认保留 20 步有限搜索；外层只 detach δ，保持当前 projector 梯度。RACER-data 端点各自搜索。人工扰动不是实际触发，不保证迁移。

N3–N6 测量“事实变化对答案的作用，偏离正常参照多少”，用其幅度生成冻结权重；每问题类型正偏离中位数作尺度，未归一权重为 1+min(d/b,1)，全有效边均值归一，类型全零则均匀。Gl 在同问题类型内以 CE 难度重新分配 G 的同一权重集合。权重及参照始终来自完整 fit，不从测试或展示案例计算。

N7–N8 更新原模型允许参数，不新增事实解码器或巨大 Jacobian。N9 只在固定小面板比较同一状态下两次实际 AdamW 更新，检查间隔预测及非线性残差；局部预测不等于整个模型获益。N10 的候选集合本轮只有一个：正常校准通过则保留，否则 B0。**因此删除没有选优用途的整套人工扰动校准生成与排序，不改变单候选选择结果。** fit 的人工响应及小型机制诊断仍保留；以后恢复多配置时才恢复共同 proxy 校准。

正常校准保留现有点估计门槛：VQA 下降不超过 0.01，CIDEr 相对下降不超过 0.02。它只是这一有限校准集的操作门槛，不是总体保护证书。没通过不自动重训、放宽门槛或用触发结果挑选；记录未找到可接受更新。异常或人工中断造成训练步数未完成时，不能作为可接受候选，也不能被解释为方法失败。

理论预期仍是有条件的：更新方向与正确答案间隔梯度一致、非线性残差小于余量，才支持局部方向判断。理论没有预测 G 必然优于 G0/Gl，也没有保证合成到真实或人工扰动到触发的迁移。

## 5. 权限、公平性与交付

修复者仅取得污染模型、正常 fit/calibration/dev、合法事实编辑和人工扰动。真实触发、攻击目标和测试标签只属于隔离评估器。六个方法全部冻结回执之后再打开测试成绩；不能以某方法先赢为由给它补预算。阶段 B 不反向改 U。

按原图片簇成对报告实际 VQA、ASR、正常 VQA/CIDEr、新增错误和成本；同时报告 VQA × 未满足攻击目标指示量的联合评分，不将其称二值成功率。区分拒答恢复、事实纠错及只删除恶意后缀；固定分母，不只统计修复后愿意回答的样本。触发改变了可见事实时隔离核验标签，原 benchmark 与机制有效真值子集分列。

产物是六个参数增量及选择回执、逐例真实输出和官方攻击评分、冻结数据与配置身份、归因数值及离线 HTML、成本与失败记录、一个投资判断。没有测量的逐词／像素归因不得画成实测热图；对象编辑区域不冒称像素归因。

小测试集主要筛明显效果。沿用图像簇成对区间并报告效应大小；不再要求本轮以高功效确认 3 pp 增益或 1 pp 正常损害界限，也不调用 5,000 图池精度扩容。旧 3 pp 等门槛留作未来正式研究的价值参考，不能因为小样本未显著而宣布整个课题无用。

| 结果 | 本轮解释 |
|---|---|
| G0 优于 R+，真实任务获益且正常保护可接受 | 响应修复值得继续；尚未证明归因权重有增量 |
| G 进一步优于 G0 与 Gl | 支持当前条件下的归因权重增量，下一步再检验重复性 |
| G/Gl 接近而 G0 有效 | 撤回当前加权新意，保留响应修复方向 |
| 人工响应改善，真实任务不改善 | 当前迁移假设未获支持，不以热图替代效果 |
| 充分训练的强对照复制收益，证据排除值得追求的增量 | 停止扩大当前规则，记录失败范围 |
| 起点无改善空间、基线欠训练、人工决定缩减后证据不全或区间很宽 | 未决／本条件不可评价，不是整个方向被证伪 |

## 6. 总预算参考与实际费用

GPUh 指进程占用时间 × 分配卡数，不按利用率打折。两卡跑 24 小时也是 48 GPUh。CPU 渲染／标注和下载单列日历时间；所有实际 GPU 构建、参照、失败、诊断及评测均计入本轮。

| 费用项 | GPUh 计划参考 |
|---|---:|
| setup：资产准备、构建／验收及首次计时 | 6 |
| reference：共同参照、dev 观察及正常校准起点 | 4 |
| repair：六条修复及修复后校准 | 20 |
| evaluation：正常／触发真实评测、机制计算和原攻击评分 | 10 |
| reserve：预留，使用时必须有明确用途 | 8 |
| **总计** | **48** |

这是预算分配，不是测得 ETA；不承诺六次修复必在 20 GPUh 内完成。先用合格基线的一次完整计时检查入口可执行性；能复用其已冻结运行就直接复用，否则计时成本也计入 setup。构建或其他阶段超过计划时继续记录实际费用，不自动终止，也不为守住数字删减独立评测；是否调整后续投入结合实际进展讨论。预留不自动成为额外方法或调参额度。

所有 GPU 命令通过同一个账本包装现有 `experiments.measure.run`：策略为 `soft_no_automatic_stop`，传入 `timeout=None`，阶段、总额或单作业超过计划均不自动终止或拒绝后续任务。`--max-gpu-hours` 为兼容保留的参数名，当前仅记录作业计划；toy 训练配置要求 `training.max_seconds=null`，训练仍按冻结的有限步数正常完成，不改成无限训练。真实失败、数据校验失败、资格未通过及未结算记录仍可阻止后续运行；全部已发生费用照实入账。账本一次只允许一个作业（单作业可多卡）；本轮不建调度平台。

## 7. 优先省掉哪些计算

1. 扰动搜索只计算一份共同 prompt 的层间不一致；经数值与 δ 梯度对照后再替代重复候选路径。完整答案评分及真实生成定义不变。
2. 用一次 prepare 保存同一 θ0 的全 fit 参照和正常校准起点，六方法按完全匹配的模型／数据／生成／初始种子及搜索配置复用。失配拒绝；不可缓存训练更新后的 embedding、梯度或训练 δ。
3. 单配置不计算无消费者的 proxy 校准。独立评价的修复前输出在同状态、同数据和生成协议下共享一次；每个修复后的模型仍实际生成。
4. 事实归因仍计算有效训练边；修复后展示只计算固定最多 24 个 pair。真实单图任务的常规评价不计算用不到的候选分数。

不优先增加复杂 KV 共享、量化、冻结特征新缓存层或新训练框架。原开源结果表用于场景及配置选择，不替代同条件比较。当前尚未核到成套污染 checkpoint／trigger／精确基座与逐例产物，不能把构建预算记零。可复用资源详情沿用 [资源盘点](TOY_RESOURCE_AUDIT.md)，缺口和实际命令在 [IMPLEMENTATION.md](IMPLEMENTATION.md) 更新。
