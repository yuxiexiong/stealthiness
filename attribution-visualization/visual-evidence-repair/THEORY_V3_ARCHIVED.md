# 理论第三稿：从事实归因到原模型的受约束修复

日期：2026-09-10。依据：[用户已确认的第二版立项](PROJECT_CHARTER.md)。状态：已完成三人独立审查、交叉复核与修订，通过有限条件理论验收，可以进入 toy 规划；没有开展模型实验。[审查结论与版本记录](theory-review-v3/REVIEW_SYNTHESIS.md)。旧诊断理论存于 [THEORY_V2_DIAGNOSTIC.md](THEORY_V2_DIAGNOSTIC.md)，更早的未修正稿见 THEORY_V1_AUDITED.md。

本文要交付的是可执行的条件方法：测量事实响应 → 确定需要纠正的响应与答案 → 在原模型允许参数中求更新 → 核验有限更新 → 对明确任务返回成功、失败或未决。不证明真实污染必然可修复，也不把局部修复完成等同未知后门清除。

实验适用范围补记：后续[两阶段 toy V2.1](TOY_PLAN.md)改用未知触发下的非线性训练，并未直接实现本文 C5/C6 求解。C1 的测量和 C4 的局部方向可继续使用；CE 监督、幅度权重、人工扰动及合成到真实迁移不继承本稿的仿射最优／分数恢复／真实触发保护保证。对应断点与条件预期见[科学自查](TOY_V2_LOGIC_AND_EXPECTATIONS_AUDIT.md)，不据实验候选重写本稿已证明命题。

## 1. 明确原系统、观测和终点

原 VLM 记为 \(M_\theta\)，\(\theta_0\) 是取得的受污染模型。只允许修改预先声明的原参数块；其余参数冻结。若比较多个参数块，每块分别计入测量、拟合和核验成本。不存在另一个替代原模型答题的事实 decoder，也不假设可免费取得兼容桥接器。

首轮条件是已知触发变换 \(\tau\)，可访问参数和输出分数，有有限、带真值的正常场景与合法事实编辑。场景为 \(v=(x_v,q)\)，改变事实后正确答案可以改变。每个比较组固定问题、候选答案集合、分词、评分及前缀规则；规则不同的组不直接作向量差。另须核验：\(\tau\) 保持每个场景上所评价事实的真值，包括编辑后的场景；“已知触发”本身不保证这一点。若触发改变了所评事实，则给触发图重新标注，不使用恢复原参照的正确性证书。

为获得一个最小、可完整推导的任务对象，首先固定有限候选答案 \(\mathcal Y_q\)。\(s_\theta(x,q)\in\mathbb R^d\) 是原模型给这些答案的确定性分数；可取完整候选串的 log probability，所有比较保持同一长度处理方式。此处答案判定为最大分数；它不是任意自由生成的等价物。自由生成的实际核验在 §6 单列，最终 benchmark 不改成此候选任务。

正常参照 \(c_v=s_{\theta_0}(x_v,q)\) 固定不随修复更新，且仅在参照最大分数答案经真值验证正确的场景上使用恢复证书。验证正确答案不意味着全部分数数值是事实真值；匹配这些数值是需要与直接答案监督比较的方法偏好。原模型正常状态已经答错的样本不作为需恢复的目标，可以列为另行监督纠错对象，但不继承本文的参照证书。所有参照分数、编辑与标签都是数据成本；正常模型 checkpoint 不是必需输入。

定义触发状态的答案偏差，以及单事实编辑边 \(e=(u,v)\) 的响应损伤：

\[
r_v(\theta)=s_\theta(\tau x_v,q)-c_v,\qquad
a_e(\theta)=
[s_\theta(\tau x_v,q)-s_\theta(\tau x_u,q)]-[c_v-c_u]
=r_v(\theta)-r_u(\theta). \tag{C1}
\]

**用途。** \(r\) 记录实际答案分数需要纠正的偏差；\(a\) 记录事实改变后模型应有的响应被怎样改变。两者可直接通过原模型前向计算。\(a\) 是指定有限干预下的条件效应差，不是唯一的贡献百分比，不是参数梯度，也不直接标识所有内部因果路径。

一条边只有在改动事实、其他独立因素及不可避免的关系变化均经核验时，才具有相应语义干预解释。任意两图也满足 C1 的代数恒等式，但不能因此获得“只改一个事实”的解释。内部消融与图像编辑若采用不同干预，分别记录，不混作同一种归因。

## 2. 归因进入目标：事实响应加答案参照

把有限编辑场景组织为图 \(G=(V,E)\)：节点是场景，边是已获得的事实编辑。图只整理现有干预，不假设图距离就是现实相似度，不引入一个待学习的图网络。每个连通分量选择至少一个答案参照节点，集合记为 \(H\)。

固定正权重 \(\alpha_h,w_e\)，将答案偏差和响应损伤堆叠为线性算子：

\[
\mathcal A r=
\big((\sqrt{\alpha_h}r_h)_{h\in H},
(\sqrt{w_e}(r_v-r_u))_{e=(u,v)\in E}\big),\qquad
\Phi(\theta)=\tfrac12\|\mathcal A r(\theta)\|_2^2. \tag{C2}
\]

向量按节点和答案坐标展开。权重由开发阶段固定，不能为改善测试指标临时改变。观察图展示未缩放的 \(r_h,a_e\)、方向与不确定性；加权目标与展示色标分开。

**命题 1：什么时候“响应恢复”足以固定答案分数。** 对所有可能的节点偏差 \(r\)，\(\mathcal A r=0\) 能推出 \(r=0\)，当且仅当每个连通分量都有至少一个参照节点。

**证明。** 边差为零使同一连通分量内所有 \(r_v\) 相同；参照约束将该常量固定为零。反之，无参照的分量可取任意非零常向量，其他分量取零，仍有 \(\mathcal A r=0\)。正权重不改变零空间。证毕。

**实际决策。** 不连通的事实组要分别设参照；仅把热图差异压到零不够。固定错误偏置在所有边上抵消，但会被参照节点发现。命题不要求污染响应先符合线性事实模型，也不证明实际参数一定能满足这些约束。

完整节点分数都已取得时，C2 就是对同一偏差向量施加一个正定二次度量（每分量有参照时）。它没有比全节点分数或同数据完整蒸馏多出信息；潜在区别是语义结构对应的训练约束及其有限预算效果。不能将此命题称为新的图学习理论或样本优势。

### 2.1 直接检查答案，不保留用不到的路径界

初稿 C3 通过图路径累加误差；当前方法已取得每个节点分数，直接检查更紧也更简单，故删除 C3。本文不再把图路径界作为修复或选点能力。

对每个真实正确答案 \(y_v\)，定义正确—错误分数差及其参数 Jacobian：

\[
p_{vy}=s_\theta(\tau x_v,q)_{y_v}-s_\theta(\tau x_v,q)_y,\qquad
R_{vy}=J_{v,y_v}-J_{v,y},\qquad y\ne y_v .
\tag{C4}
\]

其中 \(J=D_\theta r(\theta)\)，仅对下一节声明的允许参数求导。实际节点答对当且仅当所有 \(p_{vy}>0\)（本文采用唯一最大值约定，平局单列）。C4 将参数约束直接接到答案判定，不要求恢复原来的全部分数。采用预声明正间隔 \(\kappa_{vy}>0\) 时，\(p\ge\kappa\) 给可核查的充分条件；未达到该间隔可能仍答对，不能直接判定错误。

有有效数值误差界时使用正确—错误分数差的下界，否则仅报告数值检查。语义编辑或触发真值有效性与浮点误差不同，不能靠加一个任意小常数消除混杂。

## 3. 直接对原模型求更新

在当前参数 \(\theta\) 上，\(J=D_\theta r(\theta)\) 是原模型对允许参数的 Jacobian。\(D_\theta a_e=J_v-J_u\)，故归因响应到参数更新的连接是 \(\mathcal A J\)，不是把 C1 的响应向量直接当作梯度。精确结论要求允许参数具有连续坐标、所用分数在当前点可微且导数可获得；仅有权重／分数访问不够。量化直通估计、不光滑替代或近似梯度只能作为提案矩阵，不继承精确仿射最优或不可行证书。

正常保护使用一个固定的测量向量 \(g(\theta)\)：它堆叠正常校准场景的原答案分数变化，以及声明需要保护的事实响应变化，均相对 \(\theta_0\)。只将经真值核验的正常功能纳入保护；各行单位和容忍值 \(\varepsilon_i\ge0\) 固定。写 \(K=D_\theta g(\theta)\)。保护分数只能保证这些已列测量，正常任务最终还须按原输出流程评价。

给定参数改动半径 \(\rho>0\) 和 \(\lambda>0\)，求解：

\[
\begin{aligned}
\Delta^\star=\arg\min_\Delta\;&
\tfrac12\|\mathcal A(r+J\Delta)\|_2^2
+\tfrac{\lambda}{2}\|\Delta\|_2^2\\
\text{s.t. }&
|g+K\Delta|\le\varepsilon,\qquad
\|\Delta\|_2\le\rho .
\end{aligned}\tag{C5}
\]

这是本稿的归因指导更新子问题。可复用凸二次／二阶锥求解器；大参数情形可用矩阵向量乘法，但本文不承诺其实际成本便宜。半径、阻尼和参数块分别影响可达范围、拟合与成本，不与 GPU 时间混为一个预算。\(\rho\) 限制当前一步，不保证多步后仍在距 \(\theta_0\) 的同一球内；若另声明累计参数改动限制，须每次检查该全局限制，不能把逐步半径当作累计保证。

**命题 2：精确仿射类的闭合。** 若在整个允许球内，原任务的 \(r(\theta+\Delta)=r+J\Delta\) 和 \(g(\theta+\Delta)=g+K\Delta\) 精确成立，且当前状态满足保护约束，则 C5 有唯一最优解，并且它就是该“原分数归因目标加参数阻尼”、保护范围及半径内的最优有限更新。它不是只最小化原答案错误率或不带阻尼的 \(\Phi\)。

**证明。** 零更新可行；可行集是闭、有界、凸且非空的集合。目标连续，故取到最小值；\(\lambda>0\) 使目标严格凸，故最优解唯一。仿射等式将代理目标、约束与真实对象逐项对应，因而不是额外 probe 的最优。证毕。

这是标准凸优化的应用，不证明真实 VLM 在大范围内仿射。一个非空适用类是固定全部隐藏表示、仅更新未与其他模块共享的原线性输出头，并将指定前缀的候选 token logits 作为分数；不能将这一特例套给非线性 connector 或完整串 log probability。即使精确仿射，最优目标仍可能很差；最优不等于达到 C4 或实际任务的成功阈值。有限精度求解要核验可行性并保留求解容差，不能把近似解报作解析最优。

### 3.1 当前组件能否把答案修对，而非恢复全部分数

初稿以 \(\mathcal A(r+J\Delta)=0\) 定义修复可达性。但每个分量有参照时 \(\mathcal A\) 满列秩，该条件等价于 \(r+J\Delta=0\)，与图边和权重无关；而完全恢复分数又强于答对。故用下面的原答案条件替换旧 C6。

将 C4 的全部比较堆叠，固定目标间隔 \(\kappa>0\)。定义不含半径的多面体 \(\mathcal P\)，并在其非空时求最小改动：

\[
\mathcal P=\{\Delta:p+R\Delta\ge\kappa,\ |g+K\Delta|\le\varepsilon\},\qquad
\Delta_{\rm ans}=\arg\min_{\Delta\in\mathcal P}\tfrac12\|\Delta\|_2^2 .
\tag{C6}
\]

**命题 3。** 在命题 2 的精确仿射球内，存在满足原答案目标间隔、正常保护且 \(\|\Delta\|_2\le\rho\) 的更新，当且仅当 \(\mathcal P\ne\varnothing\) 且 \(\|\Delta_{\rm ans}\|_2\le\rho\)。

**证明。** \(\mathcal P\) 是闭凸多面体；非空时平方范数具有有界子水平集，故取到唯一最小值。球内有可行点则其范数不小于最小值；最小点落在球内则它本身是构造。原分数的仿射等式把约束对应到 C4 和实际正常测量。证毕。

**用途。** 通过现成线性可行性与凸二次求解，区分所列答案与保护约束不兼容、半径不足，以及“存在满足预定间隔的更新”。只有移除保护后同一答案条件可行，才能把不兼容具体归于保护要求。C6 是同权限的直接答案修复强基线，也给出可核验的候选，不是归因图独有的能力，不是带 \(\lambda\) 的 C5 最优解。若 C6 可行而 C5 未答对，应诊断目标或优化受限，不能宣称事实已丢失。若只要求唯一最大值，可减小预先声明的正间隔目标；某个较大 \(\kappa\) 不可行不证明所有正间隔均不可行。

非线性原模型中 C6 只回答局部代理的可行性；输出候选仍需真实核验，不能报告全局不可能。有限精度的可行性／最小范数结论需有效原始残差及相应下界或不可行证书；求解器状态不可靠时返回未决。此项计算成本必须计入基线。

一个必要失败例：正常参照分数为 \((1,0)\)，触发分数为 \((0,2)\)，仅允许增加第一项 \(\Delta\)。\(\Delta>2\) 即可答对，却永远不能把第二项恢复为零；单节点参照权重取 1、无保护且半径足够时 C5 选择 \(\Delta=1/(1+\lambda)\)，仍然答错。该例要求我们保留 C6 和真实输出对照，而不是声称归因匹配会找到每一种可行修复。

C6 作为独立基线时，核验原答案间隔、正常保护、半径及原任务结果；它不受 C7 对归因代理目标下降的要求。否则上述可正确回答的更新可能因 \(\Phi\) 增大而被不公平拒绝。主方法 C5 允许报告未达目标；本文没有“只要 C6 可行，C5 就一定找到成功修复”的完备性保证。

## 4. 非线性原模型：提出更新之后如何负责任地接受

真实 VLM 使用 C5 产生候选，不能直接继承命题 2。我们不再引入无法取得的全局小 Hessian 常数来补这个缺口。

每个候选都在同一有限校准集合上重新运行原模型，计算真实 \(r^+=r(\theta+\Delta)\)、\(g^+=g(\theta+\Delta)\)。实际线性化残差
\(u_r=r^+-(r+J\Delta)\)、\(u_g=g^+-(g+K\Delta)\)
由这两次状态的分数直接获得；无需将未知余项假设为小。它们只描述这一次有限更新，不覆盖整个球或新数据。记录残差用于解释预测失效及缩小半径；真正接受时用真实值检查。

令 C5 的预测目标减少量为 \(d=q(0)-q(\Delta)\)，其中 \(q\) 包括阻尼项，真实诊断目标为 C2。固定 \(\eta\in(0,1)\)。有限更新接受规则为：

\[
d>0,\qquad |g^+|\le\varepsilon,\qquad
\Phi(\theta+\Delta)\le\Phi(\theta)-\eta d . \tag{C7}
\]

此外必须通过开发集合上预声明的原任务核验：触发任务损失相对当前已接受状态不增、正常任务损害相对固定 \(\theta_0\) 在容忍范围内，避免逐步容忍导致累计损害。对 \(\theta_0\) 已答对且经真值核验的触发事实节点，固定保护集合 \(V_{\rm keep}\)，逐项检查不得新增错误；这是额外的真实输出接受条件，不能由平均损失不增推出。未纳入保护集合的事实及未见输入不继承逐项保护。正常分数约束 \(g\) 与这项触发事实检查的范围分别记录。

这里原任务可以是实际确定性生成后得到的有界评价损失；不拿 C2 下降代替它。随机解码若使用有限重复，仅是对应估计的核验，不自动给总体保证。C7 仅约束 C5 主方法；独立基线采用自身目标的更新规则，并通过相同真实任务、保护和资源检查。

**有限过程。** 从 \(\theta_0\) 开始；设总提案次数与总成本上限。求 C5、核验 C7 和原任务；不通过则回退候选、缩小半径或换预声明参数块；通过则保留更新。真实成功阈值达到就停止；无可接受更新或预算耗尽，保留最后一个通过状态，并报告未达目标或未决。若多个块参与，均计入开销；不用“诊断成本低”替代测量。

**这个规则保证什么。** 精确检查下，每个被接受的状态都满足有限校准测量的正常保护约束、固定 \(V_{\rm keep}\) 的逐项正确性，且真实诊断目标严格降低；这些结论由接受条件及逐步归纳直接得到。严格数值保证需精确值或有效的上下界；普通浮点前向、近似求解及声明容差下通过，只报告数值／经验通过。它不保证存在非零更新、收敛到全局最优、达到成功阈值或对总体正常任务无损。C7 是方法的有限更新核验环节，不是新的优化收敛定理；不为这条直接检查单独展开通用收敛证明。

缩小半径也未必救回严格保护：例如 \(g(\theta)=\theta_2-\theta_1^2\)，起点为零且要求 \(g=0\)，目标偏差为 \(\theta_1-1\)。一阶保护令候选 \(\Delta_2=0\)，每个非零有益候选却有实际 \(g^+=-\Delta_1^2\ne0\)；真实曲线 \((t,t^2)\) 可以保护并改善目标。当前方法可返回未决，不能把这种失败解释成证据缺失，也不为覆盖它强加一个未知全局小余项假设。

这里接受“需要前向核验一个候选”的成本，放弃旧主线中未经证实的“无需实际试修就准确预测所有真实候选”的承诺。该变化服务于已确认的实际修复目标。没有任何候选被当前文档实际执行。

## 5. 相同数据下，归因响应何时改变实际答案

归因的潜在作用限于非零残差、有限预算下的误差几何。下面直接比较使用全部相同节点分数的目标，不再用只知道一个参照的弱对照。构造是解析结果，不是已执行 toy 或真实污染现象。

两个场景属于同一二分类问题，正常的“第一类减第二类”间隔为 \((a,-b)\)，其中 \(a,b>0\)。触发状态的间隔为 \((a+\Delta_1,a+\Delta_1+\Delta_2)\)：\(\Delta_1\) 同时改变两个状态，\(\Delta_2\) 只改变第二个。正常输入在此构造中不受这两个参数影响，故两种方法的正常保护相同。标量间隔可写成两候选分数 \((m/2,-m/2)\)；两种目标均采用权重 2，即得到以下相同尺度的标量形式。

令 \(t=a+b\)，偏差为 \((\Delta_1,t+\Delta_1+\Delta_2)\)。第一个场景设参照，一条有效事实编辑边连接两者。图响应目标和全节点目标分别为

\[
\begin{aligned}
Q_G&=\tfrac12\Delta_1^2+\tfrac12(t+\Delta_2)^2
       +\tfrac{\lambda}{2}\|\Delta\|_2^2,\\
Q_P&=\tfrac12\Delta_1^2+\tfrac12(t+\Delta_1+\Delta_2)^2
       +\tfrac{\lambda}{2}\|\Delta\|_2^2,\\
\Delta_G&=(0,-t/(1+\lambda)),\\
\Delta_P&=(-t\lambda/D,-t(1+\lambda)/D),\qquad D=1+3\lambda+\lambda^2 .
\end{aligned}\tag{C8}
\]

两种方法使用相同原始分数、标签、参数、阻尼和半径。解在各自不触及半径时成立：图目标分别求导；全节点目标的两个法方程为
\((2+\lambda)\Delta_1+\Delta_2=-t\)、
\(\Delta_1+(1+\lambda)\Delta_2=-t\)，解得 C8。

**可测结构条件。** 图解使两个触发状态都正确的条件是 \(b>a\lambda\)。全节点解把第一个原本正确的触发状态翻错的条件是 \(aD<t\lambda\)；此时第二个状态已纠正。因而在半径足够且 \(b/a>\lambda+2+1/\lambda\) 时，图响应目标保持两者正确，而同数据全节点平方目标破坏第一个。这里决定差异的是共享更新方向、状态间不同的正确间隔及阻尼，均有对应的原分数和参数响应测量。

具体取 \(a=1/10,b=1,\lambda=1/2,\rho=4/5\)。图解为 \((0,-11/15)\)，更新后间隔 \((1/10,-19/30)\)，两者正确；全节点解为 \((-1/5,-3/5)\)，间隔 \((-1/10,-7/10)\)，第一个翻错。两解均在同一半径内。边差消除了共享 \(\Delta_1\) 方向，使该目标更偏向独立纠正第二个状态，避免伤及第一个脆弱间隔。若第一节点纳入共同的 \(V_{\rm keep}\)，全节点候选在实际接受阶段被拒绝，图候选通过；因此这是候选效果及接受率的区别，不能说执行了同一逐项保护后的全节点方法仍放行坏结果。

**同样明确的反面。** 取 \(a=b=1,\lambda=6/5,\rho=1\)。图解为 \((0,-10/11)\)，第二间隔 \(1/11>0\)，仍错；全节点解为 \((-60/151,-110/151)\)，两个间隔为 \((91/151,-19/151)\)，两者正确。两解也在同一半径内。因此没有普遍的图目标优势；选边、参照和误差几何不合适时，它可以更差。

**这个结果承担 T5 的哪一部分。** 它给出同信息、同允许资源下“观察到的响应耦合 → 不同更新 → 不同答案”的条件预测及反例。有限几何优势不意味着新增信息，也不是优于交叉熵、直接 margin 修复、图正则或所有超参下的最佳基线。在上面的正例中，仅将全节点目标的 \(\lambda\) 改为 10，其解 \((-11/131,-121/1310)\) 也能让两节点都正确，改动更小；因此必须比较各方法在相同调参预算下的结果。C6 的直接答案方法也是可纠正这些可行场景的强反方。真实模型中是否出现相应结构、结论对局部近似是否稳健、是否改善未见输入，仍需后续检验。

本方法必须与同数据全节点监督、普通一致性约束、去掉语义边信息、适用的归因选层/表示修复比较。完整数据下 C2 只是另一种误差几何，是否更适合有限预算是真实待检验问题。不能用“有一条边”或“最优解可写出”冒领新颖性。

可视化的科研工作保留为三项具体产物：哪些事实边发生有符号响应偏移；哪些共享更新可能伤及原本正确但间隔小的事实；修复后哪类边或答案仍然失败。它们分别对应 C2 的目标设置、C8 的结构预测与 C4/C7 的检查。C6 的位置可行性是通用的原参数诊断，不能当作图新增的信息。人工发现的模式在开发材料上形成明确规则后，才在独立材料上检验；事后挑图不能证明发现价值。

输入区域和层级图是进一步定位的观察手段，不自动获得 C6 的参数可达性结论。首稿不增加一个凭热度选层的启发式算法：位置要用真实允许参数的响应检查。若以后声称视觉界面提升研究者决策效率，需要独立评价，不能用参数修复消融替代。

## 6. 从有限评分到原生成流程，以及未见数据

**有限候选事实任务。** C4 直接判定所声明候选最大分数答案，C6 判断其预定正间隔目标的可达性。正确真值、候选覆盖和评分规则是必须验证的前提；只把正确选项放进候选集合没有意义。

**原贪心生成。** 若在某个正确目标串的每一个正确前缀上，目标下一 token 都是实际解码分数在整个合法词表中的唯一最大值，按位置归纳，模型就会生成该目标串直至 EOS 或同一终止规则。这一常识性充分条件保留为输出范围说明，删除初稿单列的 C9 公式；它不由有限候选串总分比较推出，也不需要在只做候选任务时额外计算。

目标串需有真值；多种措辞可正确时，未生成这一串不等于任务失败。采样、beam search、开放式 caption 和原 benchmark judge 应按原流程实际运行和评分。实际核验是 C7 的原任务检查，不能借上述贪心说明声称已证明所有生成任务的保证。

**未见事实组合与未知触发。** 已测编辑图不覆盖新节点。存在两个模型在全部已测节点一致、只在未测组合上相反；因此不增加结构假设或观测就不能推出该组合的行为。本文不给未知组合、未知触发器和任意分布上界，也不把一阶可达性称作这些条件的解释。

**同分布独立核验。** 方法、参数与选择规则锁定后，用独立场景核验原任务。固定流程、独立同分布且有界的场景级损失可直接采用 Hoeffding 等现成区间；初稿 C10 只承担常规统计报告，移出理论主链，不单列公式。它不适用于无界分数误差或凭同一数据调参选优。成对编辑同属一个场景簇，不当作独立样本；先固定簇级有界损失。多指标需要联合覆盖，多次查看并选择模型不能免费套用固定模型区间。该工具不保证分布外泛化或带来新贡献。

最终评价仍要求原 benchmark 的触发正确任务表现、攻击成功率、正常能力及全部成本。只有攻击目标与正确任务严格互斥时，正确率才能直接限制对应 ASR；一般情形分别测量。当前理论没有继承未知触发防御的权限，也没有宣布 SOTA。

## 7. 核心反例与行动，不增加独立装饰定理

| 反例 | 会击穿的说法 | 方法必须采取的行动 |
|---|---|---|
| 所有事实状态增加相同错误偏置 | 边响应恢复就足够 | 每分量答案参照，C2 与命题 1 |
| 恒定输出令某些干预差异消失 | 差异减少就是恢复 | 保留正确答案检查与真实正常能力检查 |
| 相同接口表示对应不同正确答案，且下游收到的其他输入也相同 | 任意情况只改该下游就能修复 | 确定性下游不能分开二者；换允许接口或声明失败，不依赖额外 decoder 绕过 |
| 答案间隔要求与正常保护冲突 | 总能低损害局部修复 | C6 识别声明仿射目标的冲突；非线性只报告局部限制 |
| 梯度为零但二阶项可改善 | 局部不可达就是全局不可修复 | 不作全局否定；C5 可能返回零并报告当前方法未决 |
| 单事实观测相同，未测组合不同 | 几张归因图保证组合泛化 | 不给未覆盖保证；后续通过独立组合检验 |
| 全节点普通训练获得相同收益 | 归因目标天然更有信息 | 承认强基线等价或优势不足，不降低对照 |
| 参照本身答错或编辑改变多个未记录因素 | 正常运行等于可信事实目标 | 取消该参照证书或补真值，不通过小残差掩盖 |

## 9. 公式用途与闭合范围

| 公式 | 输入 → 输出 | 删除后丢失的实际作用 |
|---|---|---|
| C1 | 四状态原分数 → 有符号事实响应损伤 | 归因的测量对象及其与答案偏差的连接 |
| C2 | 参照与事实边 → 参数修复目标 | 响应进入训练的实际位置；参照消除固定错误偏置 |
| C4 | 原答案分数及 Jacobian → 正确间隔与线性约束 | 直接判定答案，并将实际正确性送入 C6；C3 已因冗余删除 |
| C5 | 原参数 Jacobian、当前误差、正常保护 → 可求解更新 | 从观测到实际参数操作的核心 |
| C6 | 正确间隔、正常保护 → 仿射答案可达性与最小改动 | 区分所列约束不兼容、半径不足与 C5 目标失败，作为直接答案修复强基线 |
| C7 | 实际有限更新前向 → 接受／回退 | 不将线性代理成功误报为原模型成功 |
| C8 | 响应耦合、答案间隔及同资源目标 → 不同更新和答案 | 同数据完整目标下的条件性机制预测，同时给出优势反转反例 |

三人交叉审查后的结论：在有限有效干预、可信正常参照、已知触发与明确更新权限下，测量、目标、仿射求解／不可行性、非线性候选核验及同一输出流程评价已经接成可执行的条件链，本轮没有剩余阻断项。没有将“余项很小”“存在廉价桥接”“某事实必然还在”等未知条件假设成研究结果。精确保证与数值／经验核验按正文区分，不承诺主方法找到每一种可行修复。

仍需实证回答的是实际污染是否存在可用结构、C5 在真实参数规模的成本、非线性更新是否经常可接受、归因是否优于同资源强基线，以及独立事实组合与未知攻击的表现。这些是后续科学命题，不是本条件链内部尚欠的代数证明。发现新反例时仍需修订相应结论；本轮通过不授予实证有效性、新颖性充分或 ICLR/SOTA 资格。
