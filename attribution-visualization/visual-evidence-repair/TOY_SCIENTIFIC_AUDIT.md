# toy 科学有效性自查：能回答什么，不能据此停止什么

日期：2026-09-10。对象：[第一版受限 toy 计划](TOY_PLAN_V1_LIMITED.md)与[理论第三稿 §5](THEORY.md)。本次为审查记录，没有修改原理论、执行实验或把以下修订建议登记为已经运行的方案。用户随后要求整体替换，当前执行规划见[两阶段 V2](TOY_PLAN.md)；本文对 V1 的分析保留，不再作为继续修补 V1 的指令。

## 1. 结论

现计划能够比较一个真实污染模型上、一个小型原输出头修改范围内的几种修复方法。它还不能承担“首轮归因没赢，整个课题便不值得进入复杂场景”的判断。需要收紧机制测量和停止规则，再作为判断后续路线的依据。

上一版把“可比较、可运行”与“足以检验整个研究设想”混得太近。前者有了设计，后者仍需条件覆盖、权限诊断和有针对性的外推检查。一次充分求解固定线性头上的凸目标是合理安排；问题不在训练步数只有一次，而在这一允许范围和数据是否保留了要研究的机制。

## 2. 自查发现及最小修订建议

| 问题 | 会造成什么误判 | 建议 |
|---|---|---|
| 512 个随机原坐标可能排除了所需纠错方向 | 所有方法失败，被说成归因没有作用 | 先用缓存检查编辑响应在所选范围中是否被严重压缩；结合 C6 判断声明要求。仅凭完整隐藏向量有差异不能证明可修复。若权限不足，明确停止本权限结论，并提出一次有理由的范围扩展 |
| 多场景共用同一修改，平均结果可掩盖相反作用 | 某些条件下有利、另一些有害，平均后被说成全无作用 | 按修复前冻结的条件分层，分别报告纠错、损害、样本量与不确定性；分组 CPU 诊断只解释冲突，不冒充部署时按测试答案选择修复 |
| H1 的判断依赖实际存在可分的响应方向 | 高度相似的梯度加小间隔被误当作充分条件 | 同时检查事实差分是否存在、是否受共同保护限制；两端梯度相同等反例必须保留。实际生成变化才是结果 |
| 所有场景只有一种简单任务，可能没有改进余地 | 普通方法已全修好，被说成归因在复杂任务也无价值 | 报告天花板；后续若增加复杂度，必须说明新增哪种冲突或共享结构，而不只是堆更多图片 |
| 只在 G 看起来有效时才关注机制控制 | 无收益时不知道是语义结构无效还是对照退化 | 对照的结构正确性在开跑前核实。两节点事实对只翻转边或重排边列表，不会改变平方目标；有效置乱应重新匹配原始端与编辑端，保持每分量参照，并确认目标真的改变 |
| 视觉观察尚未具体决定操作 | 修复比较的负结果被延伸成可视化发现无价值 | 本轮只验响应修复与事前结构预测。若要验“看图产生更好的策略”，另冻结一条明确操作规则和对应对照，不能把记录表当成果 |
| 小样本和单个污染实例 | 没看出差别被写成已经证明没有实际差别 | 区分有力负证据、精度不足、条件未出现；不从单实例推到所有污染 |

这几项建议应在原计划修订时落实，而不是运行失败后临时追加解释。

## 3. C8 究竟证明了哪种更好与更差

两张触发图分别应答第一类、第二类。正常分数差为 a 和 −b，a、b 均为正；触发后起点都为 a。一个参数改动同时影响两题，另一个只影响第二题。正常输入在这个构造中不受这两个参数影响。

第一题已经答对，但可能经不起共同改动；第二题要被纠正。G 使用一个答案参照加事实差分，P 拟合两题的完整正常分数。λ 表示不愿改动太多的要求。下述结果只针对原 C8 权重、相同 λ、半径不截断各自解、其他保护不改变解的条件。

令 k=b/a、D=1+3λ+λ²，并定义

\[
L=\frac{\lambda(1+\lambda)}{1+2\lambda},\qquad
U=\lambda+2+\lambda^{-1},\qquad L<\lambda<U.
\]

C8 的更新代回两题，分数差为

\[
m_G=\left(a,\frac{a(\lambda-k)}{1+\lambda}\right),\qquad
m_P=\left(\frac{a\lambda(U-k)}D,\frac{a(1+2\lambda)(L-k)}D\right).
\]

第一项为正且第二项为负，才是两题严格全对。因此：

| 条件 | G | P |
|---|---|---|
| 0<k≤L | 不全对 | 不全对 |
| L<k≤λ | 不全对 | 全对 |
| λ<k<U | 全对 | 全对 |
| k≥U | 全对 | 不全对 |

等号导致的平局单列，不记严格答对。“不全对”不表示两题都错。上表描述固定配置下的答案表现，不是所有评价指标的总体排序。

更直白的两个例子：

- a=0.1、b=1、λ=0.5：P 为纠正第二题动了共同方向，第一题由 +0.1 变成 −0.1，被改错；G 第一题仍为 +0.1，第二题为 −19/30，两题正确。需要复制的分数变化相对第一题的容忍余量很大，不能误称触发模型对第二题“错误得非常自信”。
- a=b=1、λ=1.2：G 只通过差分方向纠正第二题，但受到改动惩罚，第二题仍为 +1/11，未改对；P 利用共同与独立方向分担，结果为 91/151、−19/151，两题正确。第一题这时承受得住共同改动。

若共同 V_keep 要求第一题不被改错，正例中 P 的坏候选会被拒绝。此时比较的是谁能提出合格修改，不能说执行同一保护之后 P 仍放行坏结果。

### 调参后的含义

对任意 k>0，在半径足够时，P 取 λ=k 就落在 L<k<U 区间；G 取 0<λ<k 也能两题全对。故该构造中，允许选择合适 λ 后两方法都能成功。原稿正例里 P 改用 λ=10 也可全对。

因此 C8 给出的是固定目标设置下的机制和正反例，没有证明 G 比充分调参的 P 更好，更没有证明优于直接答案或交叉熵。仍值得检验的问题是：真实多事实、实际保护和有限成本下，这种取舍是否能产生额外价值。

若半径开始截断解、正常保护约束生效或目标权重改变，上述门槛不能原样套用，需要对实际问题求解。特别是 toy 会统一目标权重尺度，而 C8 使用其明写的原权重；不能直接把 toy 的同名 λ 代入这张表。

## 4. 当前实验属于哪一种

目前尚未得到真实模型数据，不能先指定它属于 G 更好或 P 更好的一类。当前设置是 512 个参数、八个答案、多场景共享一个更新，并有实际正常保护；C8 是两参数、两场景、特定影响方式的构造，两者不是同一个实验。

首轮精确使用的是 C1/C2 的测量和目标、C4–C6 在固定原线性头上的判定与求解，以及 C7 的实际核验。对 C8 则是检验其启发能否在现实场景中出现，不能称直接验证 C8 全部胜负条件。

当前实验应同时寻找四种结果：G 更好、P 更好、双方都成功、双方均未达要求。先记录修复前可测条件和预测，再观察各方法的实际表现；不能先按输赢分组，再把事后解释写成事前预测。

与理论不相斥的结果包括：所有方法都能修好、G 不如 P、在某些组 G 有利另一些有害、简单场景无增量。真正需要回查理论或实现的是：实际对象满足某条精确命题全部前提，却违反其结论。当前固定前缀分数与真实生成的不同，本来就不属于同一个保证。

## 5. 简单结果怎样影响复杂研究

简单情形更好，不保证复杂情形更好；简单情形无增量，也不证明复杂情形无价值。首轮的角色是提供条件和边界，不能作为整个课题必须通过的一道胜负门。

| 首轮结果 | 能作的判断 | 有理由的后续动作 |
|---|---|---|
| 所有方法都能轻松修好且保持正常 | 当前任务没有显示额外修复价值的空间 | 若最终问题确实涉及更多共享事实，可预声明加入这一种冲突并重新检验 |
| 归因失败，简单方法成功，且所声称的有利条件被充分覆盖 | 当前归因目标或搜索设置不足以解决这些实例 | 停止扩大当前方法，先改目标或放弃这条具体方法 |
| 全部方法均未达到要求，且受所选参数或保护限制 | 本允许范围不足以完成所声明要求；不等于每一道题均不可修 | 先决定该权限是否必须保留；有理由时只改变一个限制，检查失败原因 |
| 分层中正负作用稳定，但平均为零 | 统一修改不能兼顾不同情况；是否能利用这种规律仍待解答 | 研究如何处理已测到的冲突，而不把分组最优当作已有完整修复 |
| 可测条件未出现，或误差范围很宽 | 当前实验没有有力回答主假设 | 缩小结论；明确缺的是条件覆盖或统计精度，再决定是否值得补样本 |

进入更复杂情形需要提前说明：改变哪个因素、为什么它会改变归因的作用、预期哪种结果、什么结果会使我们停止。不能把“复杂以后也许有用”当成无限追加模型或参数的理由。

如果首次结果只是一个总正确率且无法区分上述情形，这轮对最终课题帮助有限。若能得到可在新场景检验的条件规律，即使平均增量为零，也可能为下一步方法提供方向；这种科研价值仍需规律的解释力和可重复性支持。

## 6. 建议修改的决策口径

将“首轮 G 不赢就不进入复杂场景”改为“首轮必须交代胜负原因与证据范围，再决定是否值得检验一个具体的新条件”。停止扩大某种没有增量的修复目标，不等于停止归因可视化研究。

本次建议保留首轮的小规模、原模型修改、同信息强对照和真实生成核验，补上条件分层、权限检查、有效对照检查和结果解释分支。先完成这些修订，再实施；不重新推导已经通过的 C1–C7，不重复跑旧 OA 探针。
