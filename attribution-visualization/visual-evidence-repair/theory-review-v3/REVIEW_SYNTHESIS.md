## 实质问题及处置

| 初审发现 | 最终处理 | 对研究的推进 |
|---|---|---|
| 已知触发不自动保持事实真值 | 明确逐场景核验；触发改变事实则重新标注，取消原参照证书 | 防止把正确响应误作污染损伤 |
| 图算子满列秩时，原零残差可达判据与图无关 | 明说图只改变误差度量；用 C6 的实际答案 margin 可行性替换旧判据 | 不把标准重加权包装成新信息或新可达性 |
| 完整分数恢复强于答对，C5 可能在可答对时仍失败 | 给出单节点解析反例，区分目标／优化失败与答案不可达 | 实际输出成为终点，保留直接答案强基线 |
| C3 路径累计误差界对当前完整节点观测无额外用途 | 删除；直接使用已取得的原答案分数 | 缩短推导且不降低判定能力 |
| C8 原对照缺少相同监督，不能说明归因增量 | 改为同完整数据、参数、固定阻尼的两目标解析比较；推导正例、反例及另行调参后基线也成功的构造 | 得到可被推翻的共享参数方向／脆弱答案间隔条件，拒绝无条件优势 |
| 阻尼目标最优被混为分数误差或答案最优 | C5 明确只对所列正则目标给精确仿射最优性 | 保证对应实际求解问题 |
| 线性更新或不断缩步未必满足真实非线性保护 | C7 实际前向核验；保留严格保护曲率反例，允许有限预算后未决 | 不用不可得的小余项假设掩盖方法失败 |
| 平均触发损失不增仍可能伤害原正确事实 | 固定原状态正确且真值有效的触发事实集合，逐项禁止新增错误 | 保护对象可执行，且不外推集合之外 |
| 强基线可能被本方法特有代理目标不公平拒绝 | C6 独立基线不套 C7 的归因目标下降门槛；共同保留原任务与资源约束 | 让基线有机会直接纠正答案 |
| 导数权限、浮点与严格值、单步与累计预算混淆 | 明确连续可微访问条件、近似只作提案、数值通过与精确证书区分 | 条件可检查，实施不冒领保证 |
| C9–C10 只是常规生成／统计公式 | 删除编号推导，保留必要范围说明 | 保留评价边界，不堆教科书内容 |

## 归因可视化的角色与尚欠证据

归因仍负责测量有限事实改变对原答案的影响；可视化联动显示损伤的方向、共享参数响应、原本脆弱的正确答案以及修复反例。发现应形成可复述的操作规则，再在独立数据核验。数值进入修复目标，渲染本身不被冒称为新算法，也不要求把图片输入训练器。

下一阶段必须检验三个实质问题：真实污染是否产生 C8 一类可利用结构；该结构能否预告原模型上的修复得失；在相同数据、参数、权限、完整成本和调参预算下，归因引导是否仍超过全节点监督、直接答案修复及适用的现成方法。完全等价的图正则实现是归属／实现检查，不能当作不同算法宣称击败。

这些是研究型 toy 的入口，而非本轮已获得的实验结果。若强基线复制全部收益，或归因结构不能产生可重复的操作增量，应撤回相应贡献主张。最终仍需回到原 benchmark 的生成与评分、攻击成功率、正常能力和修复成本；有限条件理论不能替代这些证据。
