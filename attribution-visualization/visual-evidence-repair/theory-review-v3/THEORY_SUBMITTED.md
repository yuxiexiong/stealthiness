# 理论第三稿：从事实归因到原模型的受约束修复

日期：2026-09-10。依据：[用户已确认的第二版立项](PROJECT_CHARTER.md)。状态：作者完成推导与自查，待三人独立交叉审查；没有开展模型实验。旧诊断理论存于 [THEORY_V2_DIAGNOSTIC.md](THEORY_V2_DIAGNOSTIC.md)，更早的未修正稿见 THEORY_V1_AUDITED.md。

本文要交付的是可执行的条件方法：测量事实响应 → 确定需要纠正的响应与答案 → 在原模型允许参数中求更新 → 核验有限更新 → 对明确任务返回成功、失败或未决。不证明真实污染必然可修复，也不把局部修复完成等同未知后门清除。

## 1. 明确原系统、观测和终点

原 VLM 记为 \(M_\theta\)，\(\theta_0\) 是取得的受污染模型。只允许修改预先声明的原参数块；其余参数冻结。若比较多个参数块，每块分别计入测量、拟合和核验成本。不存在另一个替代原模型答题的事实 decoder，也不假设可免费取得兼容桥接器。

首轮条件是已知触发变换 \(\tau\)，可访问参数和输出分数，有有限、带真值的正常场景与合法事实编辑。场景为 \(v=(x_v,q)\)，改变事实后正确答案可以改变。每个比较组固定问题、候选答案集合、分词、评分及前缀规则；规则不同的组不直接作向量差。

为获得一个最小、可完整推导的任务对象，首先固定有限候选答案 \(\mathcal Y_q\)。\(s_\theta(x,q)\in\mathbb R^d\) 是原模型给这些答案的确定性分数；可取完整候选串的 log probability，所有比较保持同一长度处理方式。此处答案判定为最大分数；它不是任意自由生成的等价物。自由生成的实际核验在 §6 单列，最终 benchmark 不改成此候选任务。

正常参照 \(c_v=s_{\theta_0}(x_v,q)\) 固定不随修复更新，且仅在参照最大分数答案经真值验证正确的场景上使用恢复证书。原模型正常状态已经答错的样本不作为需恢复的目标，可以列为另行监督纠错对象，但不继承本文的参照证书。所有参照分数、编辑与标签都是数据成本；正常模型 checkpoint 不是必需输入。

定义触发状态的答案偏差，以及单事实编辑边 \(e=(u,v)\) 的响应损伤：

\[
r_v(\theta)=s_\theta(\tau x_v,q)-c_v,\qquad
a_e(\theta)=
[s_\theta(\tau x_v,q)-s_\theta(\tau x_u,q)]-[c_v-c_u]
=r_v(\theta)-r_u(\theta). \tag{C1}
\]

**用途。** \(r\) 记录实际答案分数需要纠正的偏差；\(a\) 记录事实改变后模型应有的响应被怎样改变。两者可直接通过原模型前向计算。\(a\) 是指定有限干预下的条件效应差，不是唯一的贡献百分比，不是参数梯度，也不直接标识所有内部因果路径。

一条边只有在改动事实、其他独立因素及不可避免的关系变化均经核验时，才具有相应语义干预解释。任意两图也满足 C1 的代数恒等式，但不能因此获得“只改一个事实”的解释。内部消融与图像编辑若采用不同干预，分别记录，不混作同一种归因。

## 2. 归因进入目标：事实响应加答案参照

把有限编辑场景组织为图 \(G=(V,E)\)：节点是场景，边是已获得的事实编辑。图只整理现有干预，不假设图距离就是现实相似度，不引入一个待学习的图网络。每个连通分量选择至少一个答案参照节点，集合记为 \(H\)。

固定正权重 \(\alpha_h,w_e\)，将答案偏差和响应损伤堆叠为线性算子：

\[
\mathcal A r=
\big((\sqrt{\alpha_h}r_h)_{h\in H},
(\sqrt{w_e}(r_v-r_u))_{e=(u,v)\in E}\big),\qquad
\Phi(\theta)=\tfrac12\|\mathcal A r(\theta)\|_2^2. \tag{C2}
\]

向量按节点和答案坐标展开。权重由开发阶段固定，不能为改善测试指标临时改变。观察图展示未缩放的 \(r_h,a_e\)、方向与不确定性；加权目标与展示色标分开。

**命题 1：什么时候“响应恢复”足以固定答案分数。** 对所有可能的节点偏差 \(r\)，\(\mathcal A r=0\) 能推出 \(r=0\)，当且仅当每个连通分量都有至少一个参照节点。

**证明。** 边差为零使同一连通分量内所有 \(r_v\) 相同；参照约束将该常量固定为零。反之，无参照的分量可取任意非零常向量，其他分量取零，仍有 \(\mathcal A r=0\)。正权重不改变零空间。证毕。

**实际决策。** 不连通的事实组要分别设参照；仅把热图差异压到零不够。固定错误偏置在所有边上抵消，但会被参照节点发现。命题不要求污染响应先符合线性事实模型，也不证明实际参数一定能满足这些约束。

完整节点分数都已取得时，C2 就是对同一偏差向量施加一个正定二次度量（每分量有参照时）。它没有比全节点分数或同数据完整蒸馏多出信息；潜在区别是语义结构对应的训练约束及其有限预算效果。不能将此命题称为新的图学习理论或样本优势。

### 2.1 有限误差如何变成可检查的答案保证

在某次实际参数状态上，获得未缩放误差界 \(\|r_h\|_\infty\le b_h\)、\(\|a_e\|_\infty\le b_e\)。对节点 \(v\)，定义

\[
B_v=\min_{h\in H,\;P:h\leadsto v}
\left(b_h+\sum_{e\in P}b_e\right),\qquad
\|r_v\|_\infty\le B_v. \tag{C3}
\]

不存在路径时 \(B_v=+\infty\)。沿路径按方向累加 C1，再用三角不等式即可证明；最后取所有有效路径的最小值。可以直接使用实测节点误差进一步收紧，不要求绕经路径取得更松的界。

若参照正确答案 \(y_v\) 的分数间隔
\(\gamma_v=c_{v,y_v}-\max_{y\ne y_v}c_{v,y}>0\)，则

\[
2B_v<\gamma_v
\quad\Longrightarrow\quad
\arg\max_y s_\theta(\tau x_v,q)_y=y_v. \tag{C4}
\]

证明是任一正确—错误分数差至多减少 \(2\|r_v\|_\infty\)。严格不等式排除平局；它是充分条件，失败只表示未获证书，不等于答错。

**用途。** C3–C4 将“响应误差较小”转成具体节点是否足以恢复答案的检查；长链误差累积时，可增加答案参照或优先修复大误差边。已可直接读取全部节点答案时，直接判分是更紧、更简单的核验，路径界不冒充降低核验成本。它解释结构与误差传播，不预测没有观察过的节点。

数值/观测误差有有效界时加到相应 \(b_h,b_e\)，参照间隔使用下界。若只获得无校准的估计，则只报告经验数值，不使用严格证书一词。语义编辑有效性与数值误差不同，不能靠加一个任意小常数消除编辑混杂。

## 3. 直接对原模型求更新

在当前参数 \(\theta\) 上，\(J=D_\theta r(\theta)\) 是原模型对允许参数的 Jacobian。\(D_\theta a_e=J_v-J_u\)，故归因响应到参数更新的连接是 \(\mathcal A J\)，不是把 C1 的响应向量直接当作梯度。

正常保护使用一个固定的测量向量 \(g(\theta)\)：它堆叠正常校准场景的原答案分数变化，以及声明需要保护的事实响应变化，均相对 \(\theta_0\)。只将经真值核验的正常功能纳入保护；各行单位和容忍值 \(\varepsilon_i\ge0\) 固定。写 \(K=D_\theta g(\theta)\)。保护分数只能保证这些已列测量，正常任务最终还须按原输出流程评价。

给定参数改动半径 \(\rho>0\) 和 \(\lambda>0\)，求解：

\[
\begin{aligned}
\Delta^\star=\arg\min_\Delta\;&
\tfrac12\|\mathcal A(r+J\Delta)\|_2^2
+\tfrac{\lambda}{2}\|\Delta\|_2^2\\
\text{s.t. }&
|g+K\Delta|\le\varepsilon,\qquad
\|\Delta\|_2\le\rho .
\end{aligned}\tag{C5}
\]

这是本稿唯一的参数更新子问题。可复用凸二次／二阶锥求解器；大参数情形可用矩阵向量乘法，但本文不承诺其实际成本便宜。半径、阻尼和参数块分别影响可达范围、拟合与成本，不与 GPU 时间混为一个预算。

**命题 2：精确仿射类的闭合。** 若在整个允许球内，原任务的 \(r(\theta+\Delta)=r+J\Delta\) 和 \(g(\theta+\Delta)=g+K\Delta\) 精确成立，且当前状态满足保护约束，则 C5 有唯一最优解，并且它就是该原分数目标、保护范围及半径内的最优有限更新。

**证明。** 零更新可行；可行集是闭、有界、凸且非空的集合。目标连续，故取到最小值；\(\lambda>0\) 使目标严格凸，故最优解唯一。仿射等式将代理目标、约束与真实对象逐项对应，因而不是额外 probe 的最优。证毕。

这是标准凸优化的应用，不证明真实 VLM 在大范围内仿射。即使精确仿射，最优目标仍可能很差；最优不等于达到 C4 或实际任务的成功阈值。有限精度求解要核验可行性并保留求解容差，不能把近似解报作解析最优。

### 3.1 为什么某个允许组件可能修不了

在当前 \(g=0\)、要求严格一阶保护 \(K\Delta=0\) 的特殊情形，令 \(N\) 的列构成 \(\ker K\) 的正交基，\(M=\mathcal A JN\)、\(b=-\mathcal A r\)。零偏差修复在半径内可行，当且仅当

\[
b\in\operatorname{range}(M)
\quad\text{且}\quad
\|M^\dagger b\|_2\le\rho ;
\qquad
\Delta_{\min}=NM^\dagger b . \tag{C6}
\]

**证明。** 一切严格保护更新均可写为 \(Nz\)，且 \(\|Nz\|_2=\|z\|_2\)。零目标等价于 \(Mz=b\)。线性方程有解当且仅当 \(b\) 在值域内，其最小范数解是 \(M^\dagger b\)，其他解增加正交零空间分量，不能减小范数。若 \(\ker K=\{0\}\)，只允许零更新，按 \(b=0\) 是否成立处理。证毕。

**用途。** 区分当前参数块没有所需纠错方向，还是有方向但所需改动超过预算。可据此考虑其他原参数块或明确放宽保护；不是自动判定整个模型不可修复。C6 在仿射类内是有限更新条件；真实非线性模型上只是一阶诊断，零 Jacobian 也可能存在二阶改善，不能据此给全局不可能性结论。

C6 是 C5 的零残差、严格保护特例，用来解释可达性，不另外引入一个训练器。数值近零奇异值、近似 Jacobian 或不可靠 rank 判定时，返回容差内的残差与不确定状态，不作精确不可行宣判。

## 4. 非线性原模型：提出更新之后如何负责任地接受

真实 VLM 使用 C5 产生候选，不能直接继承命题 2。我们不再引入无法取得的全局小 Hessian 常数来补这个缺口。

每个候选都在同一有限校准集合上重新运行原模型，计算真实 \(r^+=r(\theta+\Delta)\)、\(g^+=g(\theta+\Delta)\)。实际线性化残差
\(u_r=r^+-(r+J\Delta)\)、\(u_g=g^+-(g+K\Delta)\)
由这两次状态的分数直接获得；无需将未知余项假设为小。它们只描述这一次有限更新，不覆盖整个球或新数据。记录残差用于解释预测失效及缩小半径；真正接受时用真实值检查。

令 C5 的预测目标减少量为 \(d=q(0)-q(\Delta)\)，其中 \(q\) 包括阻尼项，真实诊断目标为 C2。固定 \(\eta\in(0,1)\)。有限更新接受规则为：

\[
d>0,\qquad |g^+|\le\varepsilon,\qquad
\Phi(\theta+\Delta)\le\Phi(\theta)-\eta d . \tag{C7}
\]

此外必须通过开发集合上预声明的原任务核验：触发任务损失不增、正常任务损害在容忍范围内。这里原任务可以是实际确定性生成后得到的有界评价损失；不拿 C2 下降代替它。随机解码若使用有限重复，仅是对应估计的核验，不自动给总体保证。

**有限过程。** 从 \(\theta_0\) 开始；设总提案次数与总成本上限。求 C5、核验 C7 和原任务；不通过则回退候选、缩小半径或换预声明参数块；通过则保留更新。真实成功阈值达到就停止；无可接受更新或预算耗尽，保留最后一个通过状态，并报告未达目标或未决。若多个块参与，均计入开销；不用“诊断成本低”替代测量。

**这个规则保证什么。** 每个被接受的状态都满足有限校准测量的正常保护约束，且真实诊断目标严格降低；这些结论由 C7 及逐步归纳直接得到。它不保证存在非零更新、收敛到全局最优、达到成功阈值或对总体正常任务无损。C7 是方法的有限更新核验环节，不是新的优化收敛定理；不为这条直接检查单独展开通用收敛证明。

这里接受“需要前向核验一个候选”的成本，放弃旧主线中未经证实的“无需实际试修就准确预测所有真实候选”的承诺。该变化服务于已确认的实际修复目标。没有任何候选被当前文档实际执行。

## 5. 归因到底新增了什么约束，什么不能冒领

一个精确可算的构造说明方法机制，不代表真实模型数据。两个场景的正常标量答案间隔为 \((1,-1)\)，正负分别对应两个正确类别。触发状态在允许更新下为
\((1+\Delta_1,\,1+\Delta_1+\Delta_2)\)，初始为 \((1,1)\)，第二个场景答错。正常功能在这个构造中不受这两个参数影响。

取第一个场景作参照，两个场景之间有已验证的事实编辑。节点偏差为
\(r=(\Delta_1,\,2+\Delta_1+\Delta_2)\)，响应损伤为 \(a=2+\Delta_2\)。等权 C5 在半径足够、无活跃保护约束时化为

\[
\min_{\Delta_1,\Delta_2}
\tfrac12\Delta_1^2+\tfrac12(2+\Delta_2)^2
+\tfrac{\lambda}{2}(\Delta_1^2+\Delta_2^2)
\quad\Rightarrow\quad
\Delta^\star=(0,-2/(1+\lambda)). \tag{C8}
\]

对两个变量分别求导即得。若 \(0<\lambda<1\)，触发第二场景的间隔变为 \((\lambda-1)/(1+\lambda)<0\)，实际类别纠正；第一场景保持正确。只保留参照项时，最优为零更新，第二场景仍错。若新增严格保护约束 \(\Delta_2=0\)，精确恢复两节点已不可行，C6 能识别冲突。

**它推进什么。** 给出一条无需模型实验便可核验的“事实响应约束改变参数更新并纠正答案”的构造，以及保护冲突的反例。它只击败仅有参照的弱目标；同数据全节点监督能直接纠正第二场景，故不是我们优于完整微调、蒸馏或已有修复的证明。

本方法必须与同数据全节点监督、普通一致性约束、去掉语义边信息、适用的归因选层/表示修复比较。完整数据下 C2 只是另一种误差几何，是否更适合有限预算是真实待检验问题。不能用“有一条边”或“最优解可写出”冒领新颖性。

可视化的科研工作保留为三项具体产物：哪些事实边发生有符号响应偏移；偏移与正常保护在何种参数块冲突；修复后哪类边或答案仍然失败。每项要对应 C2 的目标设置、C6 的位置判断或 C3–C4/C7 的检查。人工发现的模式在开发材料上形成明确规则后，才在独立材料上检验；事后挑图不能证明发现价值。

输入区域和层级图是进一步定位的观察手段，不自动获得 C6 的参数可达性结论。首稿不增加一个凭热度选层的启发式算法：位置要用真实允许参数的响应检查。若以后声称视觉界面提升研究者决策效率，需要独立评价，不能用参数修复消融替代。

## 6. 从有限评分到原生成流程，以及未见数据

**有限候选事实任务。** C4 直接保证所声明候选最大分数答案。参照正确性、候选覆盖和评分规则是必须验证的前提；只把正确选项放进候选集合没有意义。

**原贪心生成。** 对一个具有真值且适合精确字符串判定的目标序列 \(y^\star\)，原模型在每个固定正确前缀上，若满足

\[
\min_t\left[
\ell_\theta(y_t^\star\mid \tau x,q,y^\star_{<t})
-\max_{a\ne y_t^\star}\ell_\theta(a\mid \tau x,q,y^\star_{<t})
\right]>0, \tag{C9}
\]

则该模型从空输出按同一规则贪心解码会生成整个 \(y^\star\)。\(\ell\) 是应用相同 logit 处理后用于实际解码的分数，候选包括整个合法词表；序列含 EOS，或声明相同的终止规则。证明按生成位置归纳：前缀正确时下一 token 是唯一最大值，故前缀继续正确直到终止。

C9 可作为有限样本上实际生成成功的充分检查；它不由候选串总分 C4 自动推出。目标序列的可接受性需有真值；多种措辞可正确时，C9 失败不等于任务失败。采样、beam search、开放式 caption 和原 benchmark judge 应按原流程实际运行和评分，不拿这条贪心结论代替。

**未见事实组合与未知触发。** 已测编辑图不覆盖新节点。存在两个模型在全部已测节点一致、只在未测组合上相反；因此不增加结构假设或观测就不能推出该组合的行为。本文不给未知组合、未知触发器和任意分布上界，也不把一阶可达性称作这些条件的解释。

**同分布独立核验。** 方法、参数与选择规则锁定后，用独立场景核验原任务。若一个固定输出流程的场景级损失 \(L_i\in[0,1]\) 独立同分布，Hoeffding 给

\[
|R-\widehat R|\le
\sqrt{\log(2/\delta)/(2n)}
\quad\text{以至少 }1-\delta\text{ 的概率成立}. \tag{C10}
\]

用途是最终同一任务风险的不确定性报告，不用于无界分数误差或凭同一数据调参选优。成对编辑同属一个场景簇，不当作独立样本；先固定簇级有界损失。多个指标或预先固定方法同时作保证时分配置信失败预算；多次查看并选择模型不能免费套用固定模型公式。该标准工具不保证分布外泛化或带来新贡献。

最终评价仍要求原 benchmark 的触发正确任务表现、攻击成功率、正常能力及全部成本。只有攻击目标与正确任务严格互斥时，正确率才能直接限制对应 ASR；一般情形分别测量。当前理论没有继承未知触发防御的权限，也没有宣布 SOTA。

## 7. 核心反例与行动，不增加独立装饰定理

| 反例 | 会击穿的说法 | 方法必须采取的行动 |
|---|---|---|
| 所有事实状态增加相同错误偏置 | 边响应恢复就足够 | 每分量答案参照，C2 与命题 1 |
| 恒定输出令某些干预差异消失 | 差异减少就是恢复 | 保留正确答案检查与真实正常能力检查 |
| 相同接口表示对应不同正确答案，且下游收到的其他输入也相同 | 任意情况只改该下游就能修复 | 确定性下游不能分开二者；换允许接口或声明失败，不依赖额外 decoder 绕过 |
| 严格保护子空间不含所需纠错方向 | 总能低损害局部修复 | C6 识别精确仿射冲突；非线性只报告一阶限制 |
| 梯度为零但二阶项可改善 | 局部不可达就是全局不可修复 | 不作全局否定；C5 可能返回零并报告当前方法未决 |
| 单事实观测相同，未测组合不同 | 几张归因图保证组合泛化 | 不给未覆盖保证；后续通过独立组合检验 |
| 全节点普通训练获得相同收益 | 归因目标天然更有信息 | 承认强基线等价或优势不足，不降低对照 |
| 参照本身答错或编辑改变多个未记录因素 | 正常运行等于可信事实目标 | 取消该参照证书或补真值，不通过小残差掩盖 |

## 9. 公式用途与闭合范围

| 公式 | 输入 → 输出 | 删除后丢失的实际作用 |
|---|---|---|
| C1 | 四状态原分数 → 有符号事实响应损伤 | 归因的测量对象及其与答案偏差的连接 |
| C2 | 参照与事实边 → 参数修复目标 | 响应进入训练的实际位置；参照消除固定错误偏置 |
| C3–C4 | 有效有限误差与正常间隔 → 节点答案充分保证 | 误差如何累积、哪里需要参照、何时足以答对 |
| C5 | 原参数 Jacobian、当前误差、正常保护 → 可求解更新 | 从观测到实际参数操作的核心 |
| C6 | 纠错与保护矩阵 → 仿射可达性与最小改动 | 区分方向冲突和半径不足，拒绝不可能的零误差目标 |
| C7 | 实际有限更新前向 → 接受／回退 | 不将线性代理成功误报为原模型成功 |
| C8 | 明确两参数构造 → 有响应项与无响应项的不同答案 | 证明该约束确实能改变操作，同时定位弱基线边界 |
| C9 | 原贪心每步全词表间隔 → 完整生成 | 避免候选串总分到自由生成的错误推论 |
| C10 | 固定流程独立有界损失 → 同分布风险区间 | 区分校准通过与可报告的独立总体证据 |

作者自查结论：在有限有效干预、可信正常参照、已知触发与明确更新权限下，测量、目标、仿射求解／不可行性、非线性候选核验及同一输出流程评价已经接成可执行的条件链。没有将“余项很小”“存在廉价桥接”“某事实必然还在”等未知条件假设成研究结果。
