# TOY-VD-01 实验合同（Verified Diagnosis 课题的快速验证 toy）

2026-09-16。目的：在规模化之前裁决课题的三个未验证 claim（C3 混合方法、C2c 基线公平、C2a 跨攻击）。本文件 commit 后冻结。

## Stage A · 成本审计与混合前沿重放（0 GPU，纯已封存数据）

**数据源**（88 单元正式运行产物，全部只读重放）：`oracle.json` 完整真值表、`submissions.json` 各方法封存的 order/predictions、逐方法 metrics 记录里的 cost 分账（方法信息获取成本与检查成本分列）、单元 `cost.json` 全表构建成本。转移判定与文本归一 import 冻结的 `repair.diagnosis_truth`；CI 用 `diagnose.py` 同款 cluster bootstrap。范围：44 个 abnormal 单元（诊断任务主对象），clean 侧仅附报。

**重放策略**（检查预算 k ∈ {1,2,4,8,16}，全部由已录 order 与真值表精确重算 recall@k）：
- P1 G 序（已录）/ P2 AtP 序（已录）/ P4 random 序（已录，null）
- **P3 claim-confirm 混合**：G 的 changed-claims（精度已测 1.0）按其记录顺序先花预算逐一确认，用尽后接 AtP 序
- P5 oracle 最优序（可满足性演示上界）；P4 必须垫底（可违反性演示）

**判据（预注册）**：
- **K-A3（主判据，成本现实闸）**：从记录的成本分账计算 r_AtP = AtP 排序信息成本 / 全表 oracle 成本，r_G = G 探针信息成本 / 全表成本。**r ≤ 0.25 记"廉价"**；任一 >0.25 → 对应"廉价获取"叙事作废，方法章重构为"验证经济学的真实成本前沿"。预测【推测】：r_AtP ∈ 0.3–0.8（很可能挂），r_G ∈ 0.2–0.5。
- **K-A1″（检查效率）**：等检查预算 k∈{2,4} 下，P3 召回 − P2 召回的场景聚类 bootstrap 95%CI 下界 > 0。预测【推测】：k=4 时 +0.05–0.15。
- **前沿支配报告**：以（信息成本 + k×单次检查成本）为横轴的 verified-recall 前沿图数据，各策略全量输出；不设通过线，as-is 报告。
- 失败类型：数据字段缺失/解析失败 = 合同执行失败（修复重跑）；K-A1″ CI 含 0 = 混合无增益（科学结果，方法章降级）；K-A3 双挂 = 成本叙事重构。

## Stage B · 基线公平加固（≈0.5–2 GPU·h，A 出结果后启动）

5 个 dev 场景上替 PurMM/CleanSight 做有利调参与更忠实适配，冻结后应用于 17 个确认场景。**K-B**：加固版 @1/@4 仍 ≤ 置换 null 95 分位 → 头条硬化；显著上穿 → 头条降级为"默认适配失效"并如实入档。

## Stage C · 第二攻击复现（≈1 GPU 天，B 后启动）

toy48 管线构造 B1（不同触发类型），冻结协议跑 10–12 场景。**K-C**：基线 ≤ null@小预算 且 G precision CI 下界 ≥ 0.95 同时复现 → C2/C4 升级为跨攻击；任一不复现 → 收缩为攻击特异性发现。

## 边界

单骨干（LLaVA-1.5-7B）；合成域（EditCLEVR）；Stage A 的成本比值依赖该次运行的实现效率，报告时注明为"本实现下的成本"。
