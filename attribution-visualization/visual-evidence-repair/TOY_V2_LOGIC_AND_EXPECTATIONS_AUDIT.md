## 1. 总判断

**V2 的总体比较框架有用，但原文尚不足以支撑“每项操作都有旧理论依据”“已经有根据预期会领先”。** 主要问题是理论到新算法的变化没有说得足够直白、权重假设没有方向依据、几个比较尚未唯一控制变量，以及实际输出恢复容易被解释成感知机制恢复。

本次已将可修正的定义、对照和判据写回 V2.1。仍无实证依据的部分明确保留为假设，不伪装成补一个公式就证明了。当前可以说形成了**条件可检验的方案**；不能说已经具备预期正收益或已冻结全部执行细节。

## 2. 发现的问题及修正

| 问题 | 为什么影响研究结论 | 本次处理 |
|---|---|---|
| C8 与新算法并不是同一方法 | C8 替换节点目标；新方法在 CE／一致性之上追加响应项，还用非线性优化 | 正反例只作启发；加入同一起点、实际候选更新的局部预测诊断 |
| “响应损伤越大就加权越高”没有更新方向依据 | 最严重的偏差可能不可改，或其修复会伤及更重要事实 | 明确是待检验启发式；分别比较响应项和权重，不以热度当因果收益 |
| 把偏离正常分数直接叫事实损伤 | 正常答案正确不保证其整个概率向量值得恢复；有益的置信度提高也可造成偏离 | 将该量标为待验证的响应损伤代理，检查它是否实际对应错答、附带损害及修复方向 |
| G、P、Gl 的差异没有完全锁死 | 关系目标、权重分布、超参和扰动变化可能同时发生 | 用明确成对对照；统一参考、权重总量、实际训练起点和主要训练配置 |
| U/K 与合成／真实域同时发生变化 | 未知版在自然图上失败，不能唯一归于触发覆盖 | 对既有输出交叉报告 K/U × 合成/真实，不增加模型；不作唯一因果归因 |
| MI/TR 不保证要研究的事实损伤出现 | MI 可保留事实，TR 可以只是拒答；总正确率不能说明感知丢失又恢复 | 区分原任务、内容事实、拒答／格式、响应损伤；按修复前状态固定分层 |
| 真实触发可能改变可见事实 | 覆盖物体或改变可见颜色后，原标签可能不再是有效干预真值 | 主表保留原 benchmark；机制子集由独立评估器先判真值有效性，不按模型输赢筛选 |
| 同配置数不等于公平优化 | 各方法新增超参、训练速度和收敛难度不同 | 单变量诊断固定共同设置；整方法竞争另作同预算调优，两类结论分开 |
| 模型运行时可见的校准量少算 | D_val 和看图开发数据也被方法使用；不仅 D_fit 的 300 张图是信息成本 | 分列训练、校准、开发、评测及重复曝光；Native 不继承额外校准包 |
| 门槛被说成预期 | 3 pp 是价值选择，0/5 pp 是功效设计情形，均不是理论预测 | 从预期结果中移除数值必胜；修正 VQA soft-score 的“多成功30次”表述 |

## 3. 理论到底支持到哪一步

| 旧内容 | 对新方法的地位 | 不能声称什么 |
|---|---|---|
| C1 有效事实干预的差分测量 | 固定共同 δ 后的代数定义仍成立；解释对象变为内部扰动 | 不能把同形状 δ 直接当成真实图像触发，不能把亮度当修复价值 |
| C2 图边与分数锚点 | 说明共同偏置盲区与关系目标的误差几何 | 新 CE 是答案监督，不是原分数锚点；不能套原图零误差恢复全部分数的证书 |
| C4 正确—竞争答案间隔 | 可作固定候选和实际更新的一阶诊断 | 一个竞争答案的间隔改善不等于全部候选获胜，更不等于自由生成正确 |
| C5/C6 受约束仿射求解 | 可帮助理解局部范围；V2 并未运行原求解算法 | Adam、LoRA、多步非线性更新不继承凸最优或不可行证书 |
| C7 有限集合检查 | 保留实际输出核验思想 | U 不能保护它看不到的真实触发 V_keep；软保护也不等同原逐项约束 |
| C8 正反例 | 支持目标与更新方向可能冲突，且没有普遍优势 | 不推出新版加项或幅度加权优于调优后的强方法 |

所以，**没有发现新定义必然违反旧定理；发现的是适用对象、算法和保证已经改变。** 若承认它是受理论启发的经验方法，这是合法的研究；若宣称它是旧理论的完整实现或结论已被理论推出，就是不成立的解释。

还有两条尚未证实的迁移：人工 embedding 扰动 → 真实未知触发；合成事实配对 → 自然图片任务。多事实是否共享可利用的修复方向也没有现成证据。它们需要独立检验，不要求理论在实验前证明真实世界必然满足它们。

## 4. 两个反例说明不能凭热度预测胜负

**反例一：所有答案一起偏移，事实差分仍可能正常。** 若两端残差相同，a=r_v−r_u=0，响应图不亮，答案仍可能都错。若分数对输入是仿射的，共享加性 δ 的贡献也会在两端相减时抵消。此时统一权重是测量本来的结果，不是软件错误，亦不是所有修复方法无用。这个反例来自 C1/C2 的共同偏置盲区。

**反例二：给更红的边加权，可以把修改带向反方向。** 取一维可改参数 θ，两条边的响应误差为 a₁=2+θ、a₂=1−2θ。在 θ=0，均匀平方目标的梯度是 4−4=0。按 V2 的幅度规则，较大的第一条边获得更高权重，目标梯度变正，梯度下降就向负 θ 走。如果真实纠错需要正 θ，这项加权便有害。它是一个解析反例，不是已观察到的 VLM 现象。

这不证明加权总无效；它证明“幅度更大”不能单独推出“更值得修”。同样，响应平方损失下降也不能单独推出答案正确率上升。即使原答案正确，有益的 CE 更新也可能改变原置信度及响应数值；强迫复制旧数值可能抵消这种改进。参照真值核验只给答案层的依据，不给全部概率数值的最优性。

## 5. 有理论依据的条件预测，怎样落到第一阶段

复用现有第一阶段的少量预登记诊断批次，不新增模型或独立阶段。对 G0/R+ 和 G/G0 分别从同一个 θ、完整优化器状态、批次、共同冻结 δ 提出一次实际更新，分别记 Δ_A、Δ_B。先固定正确答案和全部预声明竞争答案，得到每个正确—竞争间隔 m。

在可微局部范围，预测两项候选的间隔差为

\[
\widehat{m_A-m_B}=\nabla_\theta m(\theta)^\top(\Delta_A-\Delta_B).
\]

分别把两项更新临时作用于原模型，核验实际间隔差、预测残差及原生成。诊断后恢复原起点，不能将评估器的信息带回训练。真实触发上的梯度只由锁定后的评估器使用；部署算法仍不知道 τ。

这条预测直接承接 C4 的局部敏感性。用实际 Δ，就不需要假装 Adam 的更新差等于负学习率乘新增损失梯度。有限步残差可能改变符号，必须实测；不能假设它足够小。接近零、竞争答案覆盖不足或局部近似失效时，判未决。

**可提前声明的条件预期：**

1. 若新增项的实际方向提高正确答案相对所有竞争者的间隔，且保护事实的余量未被耗尽，那么候选答案改善有明确的一阶依据；有限步与生成必须再验证。
2. 若方向压低必要间隔，则预计局部纠错变难；若挤占原正确事实的余量，则预计发生附带损伤风险。
3. 若响应损伤很大但差分 Jacobian 为零，则该项在此点没有一阶修复推动力。
4. 若只有共同偏移，差分观测不能定位这一错误；答案监督仍然必要。

我们**不能提前预报**真实模型中上述条件出现的频率，也不能从这条 Taylor 预测推出 G 更容易占据有利方向。这是机制检验，不是为“预期必胜”增加数学装饰。

## 6. 单一比较对应单一问题

整个两阶段研究可以有多个假设。控制变量要求是：声称某个部件导致增量时，必须有只改变该部件的比较；不是要求整篇研究只能有一个问题。

| 比较 | 唯一要改变的因素 | 可支持的结论 |
|---|---|---|
| G0 与 R+ | 是否加入均匀事实响应项 | 响应目标是否有增量 |
| G 与 G0 | 同一响应项的边权是否由损伤决定 | 幅度加权是否有增量 |
| G 与 Gl | 同一组权重按归因损伤还是普通答案损失分配 | 归因排序是否优于普通难例排序 |
| G0 与均匀 P | 关系差分或逐节点匹配，均匀权重及总尺度相同 | 关系结构是否有价值 |
| G 与置乱权重 | 只打乱同一权重集合与边的对应 | 权重分配是否超出任意重加权 |
| 完整方法与独立强基线 | 同权限同资源下的整个算法 | 系统效能；不能单凭它解释哪个部件起作用 |

Gl 以两端在同一参考人工扰动下的正确答案平均 CE 排序，将 G 的同一权重多重集依序分配；并列用固定种子打破。它和 G 拥有相同数据、候选、参考资格和权重总量。P 的主机制比较与 G0 对应，避免 G/P 同时变化关系目标和加权规则。

单步机制对照固定实际 δ。完整训练只固定 δ 生成规则与随机流；各方法模型逐渐不同后产生不同 δ，是算法总效应的一部分，不能称它们一直受到完全相同扰动。

## 7. 原文证据允许怎样预期

本次核读 RACER 的攻击定义、表 I/II、附录 C-C，以及 CleanSight 的 PU 与剪枝消融；不是新的全量文献综述。

| 已有证据 | 支持的预期 | 不支持的外推 |
|---|---|---|
| RACER 的 MI 追加内容，TR 强制拒答 | 预计同时遇到内容仍可答、输出被劫持等不同现象 | 不证明感知信息已消失 |
| 拟选 12 格中原文有 10 格 ASR=0，另两格为 20.4% 和 0.4% | 安全指标有明显天花板，应保留零增量结果 | 不能推成触发事实全正确或必有 VQA 改进余地 |
| RACER 对干净控制的 VQA 降幅为 2.5、2.5、2.6 pp | 附带损伤是有实测依据的检查对象 | 不证明我们的响应项能补回 |
| CleanSight 在 oracle 检测消融中 PU 接近正常水平 | 强方法可能已经恢复部分任务能力 | 不证明完整系统全部饱和，也不证明我们的增量 |

来源：[RACER 原文](https://arxiv.org/html/2608.24354v1)、[CleanSight 原文](https://arxiv.org/html/2603.12989v1)。数字都是作者报告，未在本仓库复现；增加数据、配置不同后不能当作我们的基线实测。

**第一阶段的有据预期是混合情形与条件分化。** 输出劫持、事实响应损伤、修复附带损伤可能不在同一批样本上；不能预期每种攻击都需要事实修复。较有实证依据的机会是控制修复附带损害，尚无依据断言归因能抓住这个机会。机制预测应给出方向及反例，而不是固定一个总正确率。

**第二阶段的有据预期是强基线与改进空间不均匀。** 拟选原表残余 ASR 的等权均值约为 1.73 pp，故不能预期平均 ASR 再降低 3 pp；这与 VQA 的 3 pp 门槛是不同量。没有证据预测我们的触发 VQA 会提升多少，甚至没有证据保证其平均增量为正。现有研究不支持“我们大概率达到 accept/SOTA”的结果预告。

## 8. 判断门槛与预期分开

3 pp 是暂定的实用增量门槛；功效计算中的 0 与 5 pp 是设计情形，均不是理论预测。VQA soft-consensus 分数提高 0.03，也不严格等于 1,000 次多成功 30 次；应解释为平均标准化任务分数变化。

训练包、运行时校准包、研究开发数据和测试池分别冻结，方法同权限获得校准信息。Native 复现使用其原协议的配置／选择规则；用了额外校准就移到共同增强轨道。统计单位是图像簇，污染种子变化与图像抽样分开；固定两种子不能支持所有攻击总体。

未冻结的实际事项仍包括：资产及原评测出处、共同损失各项的确切实现、有限调参配置、校准数据量、人工扰动参考设置和各指标功效可达性。在清单填写前，不将方案标为可直接上服务器的最终实验协议。这些属于同一方案的执行条件，不自动添加第三阶段。

## 9. 最终自查结论

- **逻辑：** 经本次修正，能分开检验响应项、权重与整体性能；不能把总性能差当作完整机制证明。
- **理论：** 部分定义和局部预测可直接承接；新优化、加权、未知触发及合成到真实迁移没有旧定理的效果保证。
- **预期：** 可以给条件方向与已有现象支持的混合结果预期，不能给正收益幅度或 SOTA 胜率。
- **科学性：** 配对、干预、独立评估和强对照路线合理；完善了尚未唯一化的比较，并保留真假不明的可能。方案尚待执行冻结，实验效果仍完全未知。

保留两阶段总体设计。第一阶段首先检验关键机制条件是否出现；如果现象根本不支持它，便不应仅因已有一套公式就执行庞大的第二阶段。停止当前候选与否定整个归因可视化领域，是两个不同结论。
