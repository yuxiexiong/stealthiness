## 1. 结论与值得探索的问题

**可以探索，但需要重建“生成图像是否真的正确”的判断，不能把 VLM 的答案分数公式换个名字。** 可迁移的是“有限内部干预 → 有符号归因 → 未测组合预测 → 实际核验 → 下一项检查价值”的链条。

首个候选问题：文字要求生成物体 A 和物体 B，受污染模型却把 A 画成 C，B 可能仍正确。我们研究哪些内部条件状态的替换影响了 A→C 的错误，是否也影响 B；根据少量干预预测一个尚未测过的组合，再实际生成图片核验。

它与旧 VLM 拒答实例的一个潜在区别是：**错误可以落在某个物体上，而其余物体仍可作为真正的保护事实。** 这是选择物体替换场景的理由，不是已经证明该权重满足这一条件。正常图、异常图、保护事实及可重复性仍必须先验收。

本阶段只做诊断；有供体辅助的一次推理纠错，不叫保存了一个已修复模型。若完整正常提示已经可用，直接运行正常提示是必须保留的便宜参照，不能把这条简单路径藏起来再宣称工业部署优势。

## 3. 逐条检查当前理论

| VLM 理论内容 | 文生图判定 | 实际要改的地方 |
|---|---|---|
| 正确token对每个固定竞争token的logit差 | 扩散模型不能直接沿用 | 改成最终图像中预声明事实的连续评分 |
| 单点差分、成对差分与低阶预测 | 可沿用集合函数的代数 | 输入变成固定条件张量的槽位组；输出为图像事实评分 |
| 低阶结构成立时可预测未测集合 | 条件性成立 | 只保证所定义评分的预测，不保证评分器反映真实事实 |
| 低阶观测无法排除隐藏高阶项 | 同样成立 | 仍需未测组合的真实生成，不能用拟合好来自证 |
| 全部位置的真实M>0保证完整正确答案及EOS | 不能沿用 | 扩散图像没有同样的逐token归纳；另定义最终事实验收 |
| 选择最弱事实预测更好的组合 | 可作为候选规则 | 固定事实列表、方向与评分尺度；不预称最优 |
| 冻结策略、独立病例、单侧校准 | 可沿用排序原理 | 校准终点需改成最终图像事实结果，不能继承VLM阈值 |

以上只针对扩散式文生图。自回归图像token模型有另一种序列接口，但重现一条图像token串也不能直接替代语义事实评价；不在本次同时展开。

## 4. 首个接口只选一处，保持干预可解释

候选接口为**文本编码完成后、采样开始前，扩散模型反复读取的固定条件张量**。每次运行只构造一次混合条件张量，随后采样器按原规则执行。这里不是在每步额外重置latent，也不是修改一串未登记的深层注意力值。

在同一污染模型B0中，把同一语义请求的正常提示与匹配触发提示分别编码，得到正常供体和异常条件。正常供体须经同噪声生成的最终图像事实核验；它不是已知未受污染的内部表示，不能偷偷用干净基座的供体替代。先核验输入长度、padding、特殊位置、mask、无条件分支以及其他条件是否一致可控。若只是固定长度的槽位对应，就只解释为槽位替换，不能把位置号当作同一个词的语义对应。

默认将实际固定长度条件序列分成四个连续、尽可能等大的槽位组；保存每组的token、特殊位置及padding清单。组数与边界在看到干预效果前冻结，双组操作替换约一半条件位置。若形状或其他条件无法对齐，先报告接口不成立，不静默裁剪、补零或删除不匹配部分。

每个病例固定：提示语义、正常供体、触发版本、初始噪声、每步随机噪声（若有）、采样器、时间步、引导规则、精度、VAE、安全检查和后处理。**固定的是随机输入和执行规则，干预后的生成轨迹必须允许自然改变。** 安全检查导致无法显示的输出按预定失败／未决规则保留，不能关闭检查来补成功例。

空操作、自身条件复制和全部条件恢复是接线对照。只有确认已覆盖全部不同的条件输入，才能要求全集恢复复现正常生成；只换了部分embedding时不能假定这项恒等关系。全集不进入未测推荐。

这种接口测试的是条件信息如何引发错误，尚不定位U-Net内部哪组权重被污染。若它表现为一个简单的触发开关，应如实报告，不把它包装成复杂的视觉证据机制。

## 5. 先定义真实图像结果，再定义用于选择的分数

### 5.1 第一轮只用容易核对的物体事实

提示要求画A和B，已发布污染目标将A替换为C。正常条件下应出现A和B；异常条件下出现C、A缺失，而B仍清晰可见。A、B、C及触发规则必须来自已核匹配的权重配置，不凭另一个论文的例子猜测。

核心纠错要求：出现A，且没有把C作为A的替代继续保留。核心保护要求：原本正确的B仍存在，登记的物体数量不被破坏。首轮不同时增加颜色绑定、遮挡、左右关系等多个困难因素；这些可以在该接口通过后单独扩展。

真实验收先逐图记录，再按第7节的病例单位汇总：一条提示的两次固定噪声运行，全部纠错与保护要求都经确认通过，病例级F才为1；否则F=0。若图像确实无法判定，标未决，不删除；主成功统计保守按未通过处理，并单列未决数量。F=0含未决，不等于每例都已证实存在事实错误。

先用公开工具提供检测和逐事实记录，再对盲去方法名称的图片做独立事实核对；歧义图复核。初期样本小，不为减少人工核对而把另一个VLM的回答当唯一真值。没有可靠标签时，结论须收缩为“符合该评估器”，不能宣称图像事实已恢复。

### 5.2 连续评分是选择工具

优先复用GenEval所用检测器可取得的类别分数：对A、B记录最大检测分数，对不应出现的替代物C记录反向分数，统一方向与尺度；未检出的处理、阈值及类别映射在开发时冻结。数字用于估计作用，不能称为事实正确概率。若现有输出只有阈值后标签，须从原检测器读取连续结果；不能把二值结果重新涂色冒充连续归因。

首轮的数量保护只进入最终事实验收F，不进入连续预测；本稿没有另外定义计数代理。图中数量项直接展示真实核对结果，不能冒称它已有归因预测。选择代理因此只覆盖部分要求，必须由包含全部要求的F检验其推荐。

对每个事实评分g，使用空／单区结果预测双区：

\[
\widehat g(\{j,k\})=g(\{j\})+g(\{k\})-g(\varnothing).
\]

随后取各已定义代理评分及预定随机运行中最弱的预测分数，选择六个双组中最好的一项。所有评分定义必须让“越大越支持要求”一致；不在看到确认结果后调权重或色标。

**与VLM相比一个关键成本变化：** 取得一个最终图像评分，已经需要完整生成该图。因此基础归因的五次评分不是五次廉价读logit，而是五条完整生成路径。直接搜索可把同样时间用于真正试验双组；归因不能隐藏这项成本。

## 6. 新增的一小段理论：可靠性校准最终事实结果

旧M到完整文字答案的定理不再使用。冻结整个诊断策略π，让它在每个病例选择一个尚未测过的组合，并输出标量预测分数 \(\widehat s\)。独立校准时实际生成推荐图片，取得第5节定义的病例级事实验收F，定义：

\[
r_i=\widehat s_i-F_i,\qquad
k=\lceil(n+1)(1-\alpha)\rceil,
\qquad q=r_{(k)}\ (k\le n),
\]

若k>n则q为正无穷；n≥1，0<α<1。仅在 \(\widehat s_{new}-q>0\) 时作通过声明。π在校准前冻结，校准与新病例可交换时：

\[
\Pr(\text{声明通过且 }F_{new}=0)\le\alpha.
\]

理由：F=0时误差就是预测分数，错误声明必然意味着该误差超过校准阈值；序位给出尾部概率上界。评分不必事先是正确概率，也无需假设检测器分数天然等于事实。该构造是[单侧保形校准](https://arxiv.org/pdf/2107.07511)在固定策略结果上的应用，不作为新统计定理宣称。

这里的保证针对“全部事实已经确认通过”的判据，未决保守记0并单列；不得删除推荐后才出现的未决病例，也不能把同提示两次噪声拆成独立校准病例。如果F仍由有系统误差的自动评估器定义，保证就只针对其标签；它不会消除评估器错误。保证仍是联合事件的边际上界，不是所有已通过病例的条件错误率，也不保证通过声明足够多、下一项检查便宜或病因解释正确。

这段推导有直接用途：决定什么时候只提出候选，什么时候有资格附加有限风险声明。没有独立校准图像时不应用数值阈值；VLM的校准病例、q及通过结论不能搬过来。

## 7. 文生图的最小可行性探索，暂不扩成完整确认

### 7.1 资格池与规模

从公开提示模板构建并冻结24条“目标物体A＋不同保护物体B”的简单提示，每条固定两个噪声种子。按提示去重；提示改写和同提示两个种子均不冒充独立提示。

先生成正常／异常对，共24×2×2=96张资格图。选择前8条合格提示，选择只依据正常事实正确、异常至少一条运行发生目标错误、两条运行中预定保护事实仍可核验且正确，以及条件接口可对齐。不按任何内部替换结果挑样；不足8条就报告不足，不补挑漂亮样图。

一个病例是一条提示及其固定的两个噪声运行。病例级成功要求两条运行都满足全部登记事实；异常原本已正确的运行也要保留，不许干预后把它弄错。两次噪声主要用于暴露随机敏感性，不能支持跨所有种子的稳定性结论。

### 7.2 做什么

- 每病例、每噪声，测空操作＋四单组；预测六双组，按跨事实及两个噪声的最弱预测选同一个组合。
- 提交预测后测六个双组，记录每个事实与最终图片；全部11种集合至多8×2×11=176条生成路径。资格中的空操作在一致性条件下可复用，实际新增量另记。
- 自身复制和全集恢复各至多16条路径；它们不计为方法成功。
- 比较固定位置、基于已测分数的搜索、同大小随机；实际生成正常提示及直接取消已知触发条件作为实用参照。额外同prompt重采样属于另一种资源分配，若比较，须使用预登记种子并计入每张图的生成成本，不能挑最好种子当作修好了原路径。
- 此阶段仅做开发探索，不宣称独立校准完成。只有发现可重复、确实改变检查决定的关系，才单独规划按提示分割的校准和确认；不直接套用VLM的39/48人数。

### 7.3 看什么结果

| 结果 | 解释与后续 |
|---|---|
| 预测可以区分目标纠错和保护损害，未测组合验证吻合，固定位置／直接搜索不能同成本复制 | 值得设计独立T2I确认；目前仍是开发证据 |
| 检测分数改善，但人工核对事实不成立 | 评分代理失效，先改评分与事实验收，不宣称生成修复 |
| 所有有效操作仅等价于删掉已知触发条件 | 得到有限的开关诊断；若没有额外检查价值，不扩大复杂归因方法 |
| 必须完整换回正常条件才有效 | 当前部分条件接口没有所需局部操作，不代表其他接口或模型不可诊断 |
| 各次噪声变化使所推关系反复失效 | 固定路径结果不能推广；先明确随机总体与跨路径目标，再决定是否扩展 |
| 归因生成五条基础路径后，直接搜索已经以更少路径找到成功图 | 当前成本上没有优势，不能因热图更详细就宣布第三目标通过 |

## 8. 可视化与交付物

每页同时放正常／异常图、提示词槽位及四组边界、逐事实归因、六个双组的预测／实际／残差、目标与保护事实的独立核对。颜色表示事实评分变化，不表示像素中的投毒概率。图片本身必须与其噪声、采样参数和干预集合绑定。

只把空间检测框作为评分证据，把条件槽位作为被干预对象；二者连线表示测量关系，不伪装成已经定位生成图中某个像素的原始故障。

预期产物是小型图像网格、每例完整记录和一份迁移结论：代数是否可执行、评分与真实事实是否一致、是否存在检查价值。没有这些结果之前，只能说理论有明确的适配路线和公开资源入口，不能说已证明比VLM更适合归因。

## 9. 核验范围与次序

这次资源核验读取了官方仓库说明、相关配置、模型卡及实际文件API；没有将其登记为所有邻近论文的全文查重，也没有重做新颖性或ICLR等级评估。外部资源的实际可运行性留给以后小规模资格检查。

顺序为：先完成VLM阶段1的最小实施设计与复用；文生图当前保留资源和理论适配，后续才下载单个主模型并做资格。不要同时搭建多模型、多采样器、多种深层hook或新的训练系统。若VLM暴露的是低阶预测／评分代理的一般缺陷，先把该缺陷反映到T2I合同；若只是固定位置天花板，不直接推断T2I同样失败。

数学适配已作针对性复核。已补清数量只进入最终验收、两次噪声共同构成一个病例、未决不删除等边界；没有增加与实际选择无关的公式。资源核实与数学成立均不替代实际加载和图像事实资格。
