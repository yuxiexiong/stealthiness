## 3. 前置定义：公式究竟在改什么、平均什么

**原位置：** [THEORY.md，11–23 行](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/visual-evidence-repair/THEORY.md:11)。

θ0 是取得的污染模型在本轮允许参数坐标上的起点；θ 是这些坐标更新后的值。固定部分没有省略为“可自由选择的桥接器”。当前代码实际允许原 projector／Qwen merger 和预登记语言 LoRA，模型其余参数冻结；新 LoRA 挂接后再显式解冻 projector。对应 model.py:97–116。LoRA 属于修复增量，不能将“原模型”解释成完全不加参数。

U_i 是一个训练单元：pair 含两个端点，singleton 含一个端点。N 数单元，不数端点、问题 token 或候选。一个 pair 必须由合法编辑构成，两端问题、模板、候选顺序一致；正确答案可以随编辑改变。这个条件使两端候选分数的相减有含义。

**简单例子。** 单元 1 是“红球→蓝球”的同问题 pair，单元 2 是一张正常真实图片。N=2，实际端点总数为 3。共同 CE 先对 pair 的两个端点平均，再和 singleton 平均，所以 pair 每个端点权重为 1/4，singleton 权重为 1/2。它不是三个端点等权。代码 core.py:166–167、173–174 正是这个口径。

**推进了什么。** 固定数据权限、可修改接口、事实编辑语义和统计分母。没有这一层，“同数据监督”“事实响应”“同等曝光”都无法核验。

**成立条件。** 标签和编辑合法性来自数据核验，不能由候选分数证明。代码检查数值、token 和参数接口，也不能自动证明一个编辑只改变一个事实。场景簇隔离和所有连带真值必须外部成立。

## 4. N1：候选分数、EOS 与参照资格

### 4.1 原式和符号

**原位置：** [THEORY.md，23–39 行](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/visual-evidence-repair/THEORY.md:23)。

\[
s^\delta_\theta(v)_y
=\frac1{T(y)}\sum_{t=1}^{T(y)}
\log P_\theta(y_t\mid x_v,q,y_{<t};\delta),
\qquad c_v=s^0_{\theta_0}(v).
\]

v 是图像—问题节点；y 是固定候选串；Y_q 是全部候选；D_q=|Y_q| 是候选维数。T(y) 是按当前模板与分词器计算的完整答案 token 数，**包含终止 token，不含 prompt、padding 或 EOS 后模板空白**。δ 只在声明的融合输入位置注入。c_v 是起点在正常输入下的整组候选分数，随后冻结。

**人话用途。** 给各方法一把共同尺子：模型愿意把完整正确答案写完到 EOS 的程度。后续 CE、keep 与响应都用这把尺子；不能某个方法算首 token、另一个算全文。

### 4.2 数值例子及长度边界

若一个两 token 答案（内容＋EOS）的条件概率分别为 0.6、0.1，则

\[
s=(\log0.6+\log0.1)/2=\log(0.06)/2\approx-1.4067.
\]

另一候选的内容概率为 0.3、其后 EOS 概率为 0.9，得分约为 −0.6547。只看首 token 会选前者；按 N1 会选后者。两个不同首 token 的概率之和为 0.9，例子可满足同一概率分布。

长度平均会改变整串概率的排序：若两候选整串概率分别为 0.36、0.343，长度分别为 2、3，则平均 log probability 为 log(0.6)、log(0.7)。N1 偏好后者，尽管后者整串概率略低。因此 \(\exp s\) 是 token 条件概率的几何均值，不是整串概率。这是明示的设计选择；不应从中推导最大概率解码或原生成正确。

### 4.3 推导与当前实现

链式分解给出整串 log probability 为各条件 log probability 之和；除以 T 得到 N1。正确标签的 token 交叉熵是对应负 log probability，所以 N5 的 ℓ=−s 是精确相等，不是另一个近似目标。

实现核对：

- model.py:185–202 生成完整 assistant 串并验证它与真实生成 prompt 的 token 前缀完全相同。不同候选长度不能反过来改变 prompt。
- LLaVA 在 189–195 行补 EOS。205–218 行要求 continuation 有内容且仅有一个 EOS，只给内容到 EOS 的 token 赋 label，EOS 后空白和 padding 不计分。
- 285–293 行把 logits 向前移一位，对所有有效 label 算逐 token CE，再按每行有效 token 数平均；返回其相反数作为候选分数。没有把 prompt token 或较长候选的 padding 算入分母。
- 正确目标若未列入候选，model.prepare 可以额外计其 CE；但参照资格仍要求正确目标在候选中。实际数据表示和 build_references 入口须遵守这一条件，不能把“无多候选”理解成随意省略所需数据字段。

### 4.4 参照资格式

原文的文字条件可精确写为：正确候选 y_v 在 Y_q 中，D_q≥2，且

\[
c_{v,y_v}>c_{v,y}\quad\text{对每个 }y\ne y_v,
\]

同时原生成按任务规则答对。core.py:132–141 同时检查至少一个竞争者、严格大于全部竞争者以及 `is_correct`；平局不合格。例：c=(−0.2,−1.1) 且第一个是正确答案并正常生成正确，合格；c=(−0.2,−0.2) 不合格；只有一个答案也不合格。

**推进了什么。** 防止把本来错的答题排序作为“正常功能”冻结，防止只有一个候选时获得虚假 100% 资格。参照资格是 N3/N6 的入口门，不是关于所有候选分数数值正确的证明。

**必要限定。** 有意义的错误候选、同义答案处理、真值和生成评分规则都不是 N1 可证明的。原模型在这些节点正常答对，不等于它的全部置信度是真值。应报告参照覆盖率；覆盖率极低会使响应方法失去实际处理对象。

**保留意见：主线必要。** 数值公式与实现一致；长度及 EOS 口径必须在导师稿中保留。

## 5. N2：共享输入扰动与有限搜索

### 5.1 支持集、区域与层的归一

**原位置：** [THEORY.md，43–66 行](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/visual-evidence-repair/THEORY.md:43)。

F_θ(v) 是当前模型在融合入口的 embedding。V_v 是视觉 token 位置，T_v 是问题与模板位置；不含答案、padding 或未来位置。B_i 要求支持集以外为零且 \(\|\delta\|_\infty\le\epsilon\)。这里的 ε 是 **embedding 坐标单位**，不是像素扰动半径，也不对应一个已证明的真实触发集合。

\[
I_i(\theta,\delta)=\frac1{|U_i|}\sum_{v\in U_i}\frac1{|\mathcal W|}
\sum_{l\in\mathcal W}\sum_{A\in\{\mathcal V_v,\mathcal T_v\}}
\frac{\omega_A}{|A|}\sum_{t\in A}
[1-\cos_\zeta(H^{(l)}_{v,t},H^{(l+1)}_{v,t})].
\]

每个 token 比较相邻隐藏状态的方向；先在各区域内部平均，再按区域系数求和，再平均层对和端点。没有除以区域系数总和，没有按全部 prompt token 合并平均。

**数值例子。** 一个端点、一个层对：两个视觉位置距离为 0.2、0.6，四个文本位置为 0.1、0.1、0.3、0.3。取 ω_V=1、ω_T=0.5，结果为 0.4+0.5×0.2=0.5。不是六个 token 的平均 0.2667，也不是区域加权均值 0.5/1.5。若另一端点为 0.9，则该 pair 的 I=0.7。

**推进了什么。** 给每个可访问正常单元生成一个明确可计算的压力条件；区域内平均避免仅因视觉 token 数多就自动占据全部不一致量。这个式子来自区域层间不一致基线；不能将标准不一致目标本身列成本项目创新。

### 5.2 稳定余弦、实际窗口和共享条件

原文采用

\[
\cos_\zeta(a,b)=\frac{a^\top b}
{\max(\|a\|,\zeta)\max(\|b\|,\zeta)},\quad\zeta>0.
\]

例：a=(1,0)、b=(0,1) 时余弦为 0、距离为 1；a=b=(1,0) 时距离为 0。由 Cauchy–Schwarz 和分母不小于 \(\|a\|\|b\|\)，余弦位于 [−1,1]，所以 I 非负且不超过 \(2(\omega_V+\omega_T)\)。这是有限性与尺度检查，不是损伤界。

model.py:257–266 用 float32 隐藏状态调用 `F.cosine_similarity`，取区域均值后相加、再取层均值。ζ 随所用 PyTorch 调用默认值固定，代码没有显式 `eps=` 配置；汇报不能把它说成学到的误差上界。

实际接口比数学一般式窄：ω_V 固定为 1；ω_T=`text_weight` 且严格正；W 为 `deep_start` 到最后一个相邻 hidden-state 对的连续窗口。`deep_start=0` 包含隐藏状态元组的第一个相邻对，不能未经实际架构索引核验就将它描述成“仅深层”。理论写允许零区域权重和一般 W，当前代码没有全部实现。

core.py:64–73 检查两端 embedding 形状、视觉 mask 和完整 prompt input IDs 相同；model.py:158–164 又要求单 prompt 无 padding 且视觉、文本区域均非空。δ 的张量只覆盖 prompt；model.py:244 将它向答案方向补零，故支持集条件在这个实现域内成立。Qwen 的空间网格／位置编码还属于真实输入接口；仅从上述检查不能推导两个任意同 token 数图像在语义空间上对齐。合法编辑应保持相应图像几何及坐标条件，不能把任意两图配成边。

### 5.3 PGD 与 stopgrad

**原式：**

\[
\delta_i^{(0)}=0,\quad
\delta_i^{(k+1)}=\Pi_{\mathcal B_i}
[\delta_i^{(k)}+\eta_{\rm PGD}\operatorname{sign}\nabla_\delta I_i(\theta,\delta_i^{(k)})],
\quad\widehat\delta_i=\operatorname{stopgrad}(\delta_i^{(K)}).
\]

K 是搜索步数；η_PGD 是步长；Π 是支持集投影与逐坐标截断。若 ε=0.1、η=0.08、连续两步梯度符号为 (+,−)，则从 (0,0) 到 (0.08,−0.08)，再到 (0.1,−0.1)。每步都满足盒约束。假设第 k 步合法，投影定义保证第 k+1 步合法；从零初始化归纳即得可行性。

core.py:76–90 确实对两端同一个 δ 张量求平均目标梯度，冻结模型参数的梯度标志，逐步 sign 加法、clamp、detach，再恢复参数梯度标志。最终 δ 不带搜索计算图。model.py:242–245 的外层是 `embeddings + change`，没有 detach 当前 embedding，故 projector 路径仍在。

**共享的含义。** 它不只是共享随机种子，而是同一实际向量进入两端。同一 pair 的梯度可以互相抵消。举一个合法余弦形式的数学例子：两端距离分别为 \(1-\cos(a+\delta)\) 与 \(1-\cos(a-\delta)\)，取 a=π/3。平均为 \(1-\tfrac12\cos\delta\)，零点梯度为 0，但小的非零 δ 会增大目标。零起点 sign-PGD 因而可能不动。这既不推翻搜索定义，也不支持“实际所有模型在零点都没有梯度”。

**只保证什么。** 有限步、盒内、可记录的搜索；不保证全局最大值、单调增大、真实触发覆盖或这种不一致真的是恶意特征。若令 η=ε/K，那只是一个特定步长配置，不会额外获得最大值保证。

### 5.4 prompt-only 省算与原式的一致性条件

当前内层走 model.py:268–278 的单 prompt 多模态前向；外层不一致由完整候选批次前向给出。对严格因果、相同位置与 mask、相同权重且关闭随机层的模型，prefix 隐藏状态不依赖后续答案。每个候选的同一 prompt 隐藏状态重复出现，批次均值等于单 prompt 值，因此这个省算在该理想算术条件下保留 N2。当前模型初始化和搜索都使用 eval 模式。

浮点批次 kernel 可能给出微小差异，尤其近零梯度的 sign 可以改变有限 PGD 轨迹。不能从因果性推出全部硬件上的逐比特等价。IMPLEMENTATION.md 记录过微型 HF 的值／梯度／PGD 核验；本轮只审源码，没有重新执行，不能代替目标 7B 接口的实际验收。

**保留意见：主线必要。** 要精确登记实际系数、层索引、位置接口和 ζ 所属实现；不要把区域不一致与有限 PGD 当成已证实的真实攻击模拟器。

## 6. N3：节点残差与事实响应差分

**原位置：** [THEORY.md，76–86 行](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/visual-evidence-repair/THEORY.md:76)。

\[
r_{u\mid e}^\delta(\theta)=s_\theta^\delta(u)-c_u,\qquad
r_{v\mid e}^\delta(\theta)=s_\theta^\delta(v)-c_v,\qquad
a_e^\delta(\theta)=r_{v\mid e}^\delta(\theta)-r_{u\mid e}^\delta(\theta).
\]

r 是一个端点相对于正常起点的 D 维分数偏移；a 比较两个端点的偏移是否相同。节点后面的“|e”提醒：同一节点在不同边可能使用不同 δ，不能把它们强制合并成一个共享图节点值。

展开得

\[
a_e^\delta(\theta)=
[s_\theta^\delta(v)-s_\theta^\delta(u)]-[c_v-c_u].
\]

**人话用途。** 比较“改一个事实让模型怎样改变答案偏好”与正常起点的区别。N4 用起点偏离定权重，N6 把当前偏离送入可微损失。这一步给可视化提供有符号数值，而不是像素贡献百分比。

**数值例子。** 取 c_u=(−0.2,−2)、c_v=(−2,−0.2)，扰动后的分数为 (−0.5,−1.4)、(−1.2,−0.6)。则 r_u=(−0.3,0.6)、r_v=(0.8,−0.4)、a=(1.1,−1)。两个节点仍分别选原正确候选，响应已经明显偏离；不能把这个数直接翻译为两个事实都答错了。

**训练后必须保留的分解：**

\[
\begin{aligned}
a_e^\delta(\theta)
={}&\big[(s_\theta^\delta(v)-s_\theta^\delta(u))
       -(s_\theta^0(v)-s_\theta^0(u))\big]\\
 &+\big[(s_\theta^0(v)-s_\theta^0(u))-(c_v-c_u)\big].
\end{aligned}
\]

第一项是当前模型的事实×扰动交互，第二项是正常事实响应相对 θ0 的漂移。只有 θ=θ0 时第二项为零，才得到同模型四格差分。训练中 N3 有意同时锚定二者；把它统称“训练后纯扰动损伤”不准确。

两个直接反例：

- **响应为零但错答。** 正常 c_u=(−0.2,−1.2)、c_v=(−1.2,−0.2)，正确答案分别为第一、第二个；两端共同加 b=(0,−2)。a=0，但 v 变成 (−1.2,−2.2)，选错第一项。边差忽略共同偏置。
- **答案更有把握但被罚。** 从正常分数 (−0.5,−1)、(−1,−0.5)，分别仅将正确项提高到 −0.2。残差为 (0.3,0)、(0,0.3)，a=(−0.3,0.3)。两个正确间隔都增大，响应平方仍为正。固定历史置信度不是纯粹的正确性目标。

core.py:149–150、184–187 的减法顺序与 N3 一致。翻转边方向使 a 变号，但平方范数和 N4 权重不变；可视化箭头必须固定方向，否则有符号图会人为翻色。

**保留意见：主线必要。** 代数正确；应称“正常事实响应偏离”或“损伤代理”，不能当事实损伤真值或原答案恢复证书。

## 7. N4：冻结幅度权重及 Gl 对照

### 7.1 d、中位数与归一权重

**原位置：** [THEORY.md，88–108 行](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/visual-evidence-repair/THEORY.md:88)。

\[
d_e=\|a_e^{\delta_e^{\rm ref}}(\theta_0)\|^2/D_{q_e},\qquad
\widetilde w_e=1+\min(d_e/m_{b(e)},1),\qquad
w_e=\widetilde w_e\big/(M^{-1}\sum_f\widetilde w_f).
\]

E 是全部参照合格训练边，M=|E|；δ_ref 是 θ0 下按 N2 生成并冻结的这条边的扰动；b(e) 是问题类型；m_b 是该类型严格正 d 的中位数。类型没有正值时取原始权重 1；M=0 时整项不计算。

d 对候选维数 D 平均，防止仅因候选数量多就机械增大平方和；它不会消除候选语义构成、难度或量纲差异。固定 Y_q 与问题类型仍必要。沿用上一节 a=(1.1,−1)，d=(1.21+1)/2=1.105。

**简单完整例子。** 同一类型三条边 d=(0,1,3)。正值中位数为 2，原始权重为 (1,1.5,2)，平均为 1.5，最终 w=(2/3,1,4/3)。平均确为 1，最大最小比为 2。最终权重不要求全在 [1,2]；[1,2] 是归一前的区间。

**证明。** 有正值时 m_b>0，非负 d 给出 \(0\le\min(d/m_b,1)\le1\)；无正值时按定义为 1。因此全部原始权重在 [1,2]，其正平均也在 [1,2]。同除该平均立即给出 \(M^{-1}\sum_e w_e=1\)，比值不变且不超过 2。M=0 的分支避免零除。这些性质完全正确，core.py:93–110 和 `statistics.median` 一致，偶数个正值也取中间两数平均。

**推进了什么。** 将可视化中可追溯的偏离数值转成可冻结的训练分配，同时限制最大相对偏重。它避免“只展示有利个案后手工加权”，但不提供权重应向哪个修复方向更新的证据。

**别误读两个归一。** 中位数按问题类型算，最后平均权重按全部有效训练边算。某类型全为零时，它的边彼此等权，但在其他类型有正偏离时，最终权重未必等于 1。不能在每个 mini-batch 再归一，否则已经换了目标。

### 7.2 Gl 的关键隐含式

原文 108 行的难度为

\[

                         +\ell_{\theta_0}^{\delta_e^{\rm ref}}(v,y_v)\big].
\]

这是同一参考人工扰动下的两端正确答案 CE 平均，**不是 clean CE**。在同类型内，把 G 的权重从小到大分给 h 从小到大的边；固定种子仅破并列。core.py:151、111–117 完全符合。

继续用 w=(2/3,1,4/3)，若 h=(3,1,2)，Gl 得到 (4/3,2/3,1)。每个权重值及其出现次数没有变化，只有给哪条边发生变化。G0 则全部取 1。

**推进了什么。** 在数据、参考扰动和权重总量相同的前提下，测试“偏离幅度分配”是否比这个预先定义的 CE 难度排序更有用。没有给 G 增加独占标签；G 与 Gl 的底层分数和正确答案都来自共同可访问材料。

**重要退化情形。** 若一个类型的偏离全部相同，或每种类型仅一条有效边，或 G 的权重排序恰与 CE 排序一致，Gl 可以和 G 完全一样。中位数截顶也会让相当多的正偏离同取原始权重 2，进一步减少可区别的处理。必须报告有效边数、权重范围、不同权重个数及 G/Gl 实际被重新分配的边数；否则“做了 Gl”不等于已有一个有辨别力的对照。

Gl 只排查当前这一种扰动 CE 难度排序，不排除所有难例加权算法。正偏离越大就应加权不是已证明结论；N3 的有益置信度反例已经说明它可能惩罚有利改变。

**保留意见：主线必要。** 尺度命题和重排性质正确；科学优势需要实际更新与原任务结果，不应在导师稿中包装成最优分配。

## 8. N5：共同目标与正常保持的精确尺度

### 8.1 所有前置小式

**原位置：** [THEORY.md，112–137 行](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/visual-evidence-repair/THEORY.md:112)。

\[
\ell_\theta^\delta(v,y)=-s_\theta^\delta(v)_y,
\qquad \bar\ell_i^\delta=|U_i|^{-1}\sum_{v\in U_i}\ell_\theta^\delta(v,y_v).
\]

第一个等式由 N1 的逐 token CE 定义直接得到；第二个是单元内部平均。若 pair 的 CE 为 0.2、0.6，则单元 CE 为 0.4，不能先相加得到 0.8 再与 singleton 等权。

\[
\mathcal H=\{(i,v):v\in U_i,\ v\text{ 的正常参照合格}\},\quad
R=|\mathcal H|,\quad k_v(\theta)=\|s^0_\theta(v)-c_v\|^2/D_{q_v}.
\]

H 按合格端点的**出现次数**计数，不是唯一图像集合。k 是正常输入下整组候选分数的均方偏移。例：两候选正常分数变化为 (0.1,−0.3)，k=(0.01+0.09)/2=0.05。重复出现的同一节点要按同样次数进入分子和 R；唯一节点数另报数据覆盖，不能替换这个分母。

### 8.2 原目标、系数及数值例

\[
\begin{aligned}
L_{\rm base}&=\frac1N\sum_i[
\bar\ell_i^0+\beta_{\rm advCE}\bar\ell_i^{\widehat\delta_i}
+\alpha_{\rm inc}I_i(\theta,\widehat\delta_i)],\\
L_{\rm keep}&=\frac1R\sum_{(i,v)\in\mathcal H}k_v(\theta),\qquad
L_{\rm common}=L_{\rm base}+\gamma_{\rm keep}L_{\rm keep}.
\end{aligned}
\]

β_advCE 控制人工扰动下仍回答正确标签的训练，α_inc 控制不一致，γ_keep 控制正常分数漂移。若一个单元 clean CE=0.4、adv CE=0.8、I=0.5，β_advCE=1、α_inc=0.2，则其 base 部分为 1.3。它与 normal keep 是不同消费者：前者训练回答，后者软约束正常分数。

这些系数对应代码 `beta_adv_ce`、`alpha_inconsistency`、`gamma_keep`，均要求非负。core.py:166–190 对 clean 与 observed 端点平均，逐合格端点累加 keep，与定义一致。真实 singleton 没有多候选资格时参加 CE／普通不一致，**不会凭空参加多候选 keep**。因此“有 100 张真实训练图”不等于它们都受 keep 项保护；真实正常性能还需要实际校准和独立评价。

把内部人工 δ 也监督为原正确标签，是设计的稳定性目标。δ 未必对应任何真实、真值保持的图像，不能据此证明其标签语义或对实际触发的迁移。

### 8.3 实际单元损失与 N/R 的证明

\[
\widetilde L_{{\rm common},i}
=\bar\ell_i^0+\beta_{\rm advCE}\bar\ell_i^{\widehat\delta_i}
+\alpha_{\rm inc}I_i(\theta,\widehat\delta_i)
+\gamma_{\rm keep}\frac NR\sum_{v:(i,v)\in\mathcal H}k_v(\theta).
\]

对全部 N 个单元平均时，keep 部分精确等于

\[
\frac1N\sum_i\frac NR\sum_{v:(i,v)\in\mathcal H}k_v
=\frac1R\sum_{(i,v)\in\mathcal H}k_v.
\]

例：N=4，合格端点共 R=3，k 为 0.1、0.2、0.6。前两个来自单元 1，最后一个来自单元 3。目标 keep=(0.1+0.2+0.6)/3=0.3；单元缩放后依次为 0.4、0、0.8、0，四单元平均仍是 0.3。若忘记 N/R，结果会变成 0.225。

core.py:202–205 用全部参照出现次数计算 R 与 N/R，179–181 按每次合格出现累加；R=0 时尺度取零且不计算未定义参照，分支正确。

**推进了什么。** 随着无参照 singleton 的比例变化，共同 CE 可以增加，而 keep 不会被无声稀释。这个归一是方法比较可解释的必要条件；它不是新的优化理论。

**固定扰动的准确含义。** 每步先在当前 θ_t 搜索 δ̂_i(θ_t)，再把所得张量当常量求外层导数。当前 θ 下的 score 与 projector 仍重新前向；不对 δ̂_i(θ) 的复合搜索映射求全导数。N5 写出的目标是该步固定扰动的外层目标，不是整个新组合目标的精确鲁棒 min–max。

**保留意见：主线必要。** 等式、空集合分支与实现正确；keep 是软约束，不能推出逐事实保护。

## 9. N6：响应、节点匹配与公平对照

### 9.1 A 与 P

**原位置：** [THEORY.md，139–164 行](/Users/ruizhixu/Documents/ChatGPT/stealthiness/attribution-visualization/visual-evidence-repair/THEORY.md:139)。

\[
A_W=\frac1M\sum_{e\in\mathcal E}\frac{w_e}{D_{q_e}}
\|r_{v\mid e}^{\widehat\delta_e}-r_{u\mid e}^{\widehat\delta_e}\|^2,\qquad
P=\frac1M\sum_{e\in\mathcal E}
\frac{\|r_{v\mid e}^{\widehat\delta_e}\|^2+\|r_{u\mid e}^{\widehat\delta_e}\|^2}{D_{q_e}}.
\]

两式使用同一有效边集合、参考分数及该步人工扰动。A 约束两端偏移的差；P 直接约束两端各自偏移。A 的方向信息先保留到向量相减，再平方；如果改成先平方两端再相减，就不是 N6。

**最小例子。** 单候选坐标的残差 r_u=r_v=1 时，关系项为 0，节点项为 2；r_u=1、r_v=−1 时，关系项为 4，节点项仍为 2。这只是标量解释，正式合格参照仍要求 D≥2。两个目标各有偏好，不能由同数据或同迹推出谁更好。

**推进了什么。** A 是可视化得到的关系测量进入真实参数损失的具体操作；P 是“是否只需要普通节点匹配”的强对照定义。本轮 toy48 推迟 P，所以 N6 的 P 留作主张边界，不是本轮已验证的优势。

### 9.2 每个方法式的具体消费者

\[
\begin{aligned}
L_{R+}&=L_{\rm common},\quad
L_{G0}=L_{\rm common}+\beta_{\rm response}A_{\bf1},\\
L_G&=L_{\rm common}+\beta_{\rm response}A_W,\quad
L_{Gl}=L_{\rm common}+\beta_{\rm response}A_{W_{\rm CE}},\quad
L_P=L_{\rm common}+\beta_{\rm response}P.
\end{aligned}
\]

β_response 是新增响应／匹配损失系数，对应代码同名设置。若共同目标为 2、β_response=0.5、A_1=1、A_W=1.5，则 R+、G0、G 的目标值依次为 2、2.5、2.75；较大的数不是较好的修复，而是该位置上更强的代价。

| 比较 | 在同一完整起点和共同配置下改变什么 | 可以回答什么 |
|---|---|---|
| G0 / R+ | 是否加入均匀响应项 | 响应正则有无增量 |
| G / G0 | 权重是否来自偏离 | 偏离分配相对均匀分配的增量 |
| G / Gl | 相同权重多重集给哪些边 | 相对预定义 CE 难度分配的增量 |
| G0 / P | 边差平方还是节点平方 | 关系目标相对全节点目标的增量；本轮未做 |

core.py:183–190 实现这些目标；P 的 `fixed_weights` 返回 1，故代码里通用的 `*weight` 没有偷偷给 P 加 G 权重。训练过程中不同方法会进入不同 θ，按同一搜索规则得到的 δ 也可不同。完整训练比较识别的是算法总效应，不是全程逐步固定同一扰动的纯梯度差；固定状态的局部比较另由 N9 处理。

### 9.3 N/M 的精确含义与实现采样

\[
\widetilde A_{W,i}=\frac NM\mathbf1_{\{i\in\mathcal E\}}
\frac{w_i}{D_{q_i}}\|a_i^{\widehat\delta_i}\|^2.
\]

固定状态和固定扰动下，对 N 个单元等权平均，N 与 1/N 消去，只剩有效 M 条边的平均。因此它是 A_W 的精确全集合尺度；均匀抽取一个单元时也是该固定对象的无偏估计。P 同理乘 N/M。

**数值例子。** N=4、M=2、D=2，两条有效边 a_1=(1,0)、a_2=(0,2)，w=(2/3,4/3)。A_W=[(2/3)×0.5+(4/3)×2]/2=1.5。两个有效单元的缩放损失为 2/3、16/3，两个无效单元为 0；四单元平均仍是 1.5。不乘 N/M 会得到 0.75，恰好被无效单元稀释一半。

core.py:202–205 计算 N/M，183 行先检查边资格，186–187 行以候选维度均值乘权重和尺度。M=0 时取零。无效节点不是先计算一个无定义残差再乘零。

**采样范围必须说准。** 当前训练 core.py:214–217 是每轮随机打乱后的无放回遍历，不是每步独立有放回均匀抽样。上述全集合代数等式仍成立，但条件于实际历史及当前参数的下一样本不一定均匀，不能宣称每一步都是全目标的条件无偏梯度。例：两个平方损失 \(\ell_1=(\theta-1)^2/2\)、\(\ell_2=(\theta+1)^2/2\)，从 0 先走第一个、步长 1 到 θ=1；剩余样本梯度为 2，而此时全目标平均梯度为 1。原文已排除顺序 AdamW 的无偏全程／最优保证，讲稿应保留这一点。

### 9.4 “P 没有额外 1/2”的推导

令 z=(r_u,r_v)。对应二次型矩阵为

\[
Q_A=\begin{pmatrix}I&-I\\-I&I\end{pmatrix},\qquad
Q_P=\operatorname{diag}(I,I),\qquad
\operatorname{tr}Q_A=\operatorname{tr}Q_P=2D.
\]

展开 \(z^\top Q_Az=\|r_v-r_u\|^2\)，\(z^\top Q_Pz=\|r_u\|^2+\|r_v\|^2\)，迹由两个对角 I 相加得到。再把 P 除以 2 会将迹改为 D，因此按这里的尺度约定不应额外平均两端。代码恰为两端均方值相加。

**这个证明的实用范围。** 同迹避免对照的一个简单因子偏差，也可解释各向同性残差下的平均二次惩罚尺度；它不等于所有方向同强度。Q_A 在共同偏置方向的特征值为 0、相反方向为 2；Q_P 在两个方向都为 1。因此不能写“同迹，所以两个方法完全公平／梯度等强／关系项更优”。G 使用非均匀 w 时，全局平均权重为 1也不意味着每条边局部惩罚相同。

### 9.5 N6 后面的外部基线小式
