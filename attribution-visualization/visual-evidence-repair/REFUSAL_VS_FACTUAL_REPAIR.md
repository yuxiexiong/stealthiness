# 怎么区分解除拒答与事实功能修复

2026-09-10。状态：设计建议，尚未据此更换或新增污染实例。方法：沿用当前 N1–N10 和已有资源，按 Academic Research Suite 的实验设计流程审查混淆；代码修改遵循 Ponytail full。本轮实际执行变更只涉及取消预算自动截断，不把下述建议冒充已运行实验。

**建议先诊断当前起点，不立即推倒重来；如果它主要只有拒答，就保留作边界对照，把主实验转到一个经实测确认的事实响应损伤实例。** 现有模型加载器、图片、真值、配对程序、修复代码和评分仍可复用。

## 1. 我们真正要恢复什么

三个说法必须分开：重新愿意回答；重新正确使用图像事实；内部丢失的信息被重新建立。前两项可以由原模型行为检验，第三项是更强的机制结论。

本课题不必证明知识先被彻底删除、再被重新学会。颜色信息如果一直存在，但污染阻止它正确影响答案，恢复这种影响也是有价值的功能修复。当前立项的主体可以保持为“恢复原模型正确使用事实的能力”。真正要避免的是：普通解除拒答就能获得同样收益，我们却把它写成事实归因的贡献。

拒答行为与其他能力可能出现分离，已有文本 LLM 的实验证据支持这种担心，但不能直接推出本 VLM 的损伤机制。[Arditi 等原文](https://arxiv.org/html/2406.11717v3)研究了拒答行为的表示和干预，也明确保留模型外推及机制语义的限制；这里仅借鉴“行为开关不等于知识状态”的警示。

## 2. 用现有起点补一张损伤分类表

复用已有 24 个 dev 颜色编辑场景，使用三种现成问题：被编辑对象颜色、未编辑对象颜色、派生计数。在正常／标记图及编辑两端，记录原模型自由生成和固定候选评分。能复用且模型、提示、图像及生成身份完全相同的已有输出就复用，不重复生成。标记须不遮住所问证据；直接复用已做的 mask 核验，覆盖不足的题另列。

原基座、B0 的正常表现必须先有记录。原基座本来就答不对的题不能称“污染摧毁了原有能力”，B0 正常条件不合格的题也不能成为 N1 正常参照。保留全体统计，符合资格的子集按修复前表现预先固定，而非看 G 是否有效后选题。

每题保留四类输出：正确、非拒答但事实错误、拒答、无法解析。拒答不能只按一个固定句匹配；本轮固定目标 exact match 继续报告，其他拒答和无法解析另行记录，采用事前定义的判定规则，边界案例盲于方法身份人工核对。

所有方法用共同 B0 的修复前分组，报告原始转移计数：

| 修复前 → 修复后 | 可以说明什么 |
|---|---|
| 拒答 → 正确 | 恢复服务功能；尚不能判定是解除拒答还是更深的事实纠错 |
| 非拒答事实错 → 正确 | 有直接的内容纠错证据 |
| 拒答 → 非拒答事实错 | 只恢复了输出，没有恢复正确任务行为 |
| 正确 → 错误／拒答 | 新增损害 |
| 错误 → 另一错误 | 不是成功修复 |

同时报告全体正确率和这些固定分组。不能只统计修复后愿意回答的题，因为那会让“只答容易题”看起来能力更好。正式 test 的 B0 分组由隔离评估器在所有方法冻结后计算，不能回流到 U 的修复规则。

## 3. 用事实编辑辨别是否真正使用了图像

例子：图中一个红球、一个绿杯。只把球改成蓝色。

- 该改变的事实：原图问球颜色应答红，编辑图应答蓝；两端都对才算通过。
- 该保持的事实：两张图问杯颜色都应答绿；不允许为了改球而损伤杯。
- 同类未见组合：换对象组合和提问表达后，仍应正确使用证据，不能只记住少数固定答案。

主评价保持原自由生成。辅助候选评分显示红、蓝等事实答案如何竞争；从候选里强制选一个会人为排除拒答，不能代替主评价，也不能因为选对就宣布“内部知识完整”。当前 N1 的平均 token log probability 是分数，不是候选之间天然归一化的概率。

这还没有完全排除“统一答案偏置”。例如模型永远偏向蓝，可能使两端自由生成都答蓝，但它对红／蓝图的相对分数变化仍在。因此除了双端正确率，还要测原 N3 的响应偏离，辅以候选间的分数差、真实答案和对照条件，不能只看一张热图或概率放大。

## 4. 为什么不能直接把拒答目标换成固定错答案

N3 比较两张只改变一个事实的图。如果污染对各候选施加同一个“与场景无关”的偏置向量 b，则两端残差相减会消掉它：

\[
(s_T(v)-c_v)-(s_T(u)-c_u)=b-b=0.
\]

这里 b 可以让不同候选获得不同偏好，但它在两张图上一样。因而即使模型恒答蓝色，归因响应项也可能没有新增监督信号；收益会来自共同的正确答案项。这是现有理论的边界，不是理论失效，也不是通过改攻击目标文字就能消除的混淆。

上述式子是对隔离诊断的思想实验。实际训练 N2–N3 使用人工扰动，U 不读取真实触发；真实损伤存在，并不保证人工扰动能覆盖它。人工到真实、合成到真实的迁移仍要由独立结果检验。

## 5. 什么时候换场景

| 入口观察 | 下一步 |
|---|---|
| 大多拒答，事实候选区分与编辑响应基本保留 | 当前实例作边界对照；不让六方法在它上面的胜负承担整个事实修复结论 |
| 存在非拒答内容错误，且事实响应相对正常／匹配对照明显异常 | 可继续用当前实例作主场景，补齐内容和配对终点 |
| 答错主要体现为场景无关的统一偏置 | 作为另一个边界，不能预设响应项应有增量 |
| 原模型本来就不会，或图像证据被遮住 | 该项不合适；修正任务资格或可见性，不能据此评价能力恢复 |

如果需要新主场景，优先核对公开基准中的内容错误任务与可运行资产。[BackdoorVLM 原文](https://arxiv.org/html/2511.18921v1)区分拒答、概念替换和知觉劫持；这给了资源入口，但原目标词命中并不足以证明事实响应受损。复用其任务骨架后，仍要用上述合法编辑面板验收，不能按任务名称直接判定机制。

优先目标是“对象／属性之间的对应关系失真，或真实图像变化失去对正确答案的影响”，例如把球的颜色归给杯子。这里描述待观察的损伤形态，不宣称已有合格公开权重，也不在本轮开始训练新的攻击实例。若必须增加实例，先保持相同模型、数据和修复权限；无需扩成多模型、多 seed 大矩阵。

为避免挑一个只对 G 有利的实例，场景资格只根据未修复 B0 的损伤、可见性、正常能力及预声明指标判定，在观察六方法结果前冻结。所有考察过的实例及成本都登记，不能只保留成功实例。

## 6. 该优先增加的对照

保留现有 SFT、R+、G0、Gl、G、RACER-data。它们检验普通微调、共同底座、响应约束和归因分配能否分别解释收益；不需要额外发明一个无法保证“只改变拒答”的参数修复算法。

如果要把损伤归因于污染监督，而不是普通微调本身，补一个匹配训练的正常对照更有辨别力：同基座、数据、标记曝光、参数和日程，仅将目标样本保留正确答案。只多做一次起点构建与诊断，不把六方法矩阵再乘一次；优先寻找现成匹配产物，有则复用。没有它时，B0 与原基座的四格差异只能归因于整段训练变化，不能隔离那 1k 目标指令。

正常对照、真实触发及目标信息都属于隔离评估器，不额外授予 U。后续若主张内部机制，再用少量预登记单元做实际干预与匹配控制，不能由归因亮点直接推断“这里就是应该修的位置”。[Hase 等](https://arxiv.org/abs/2301.04213)在知识编辑中展示过定位与最佳编辑位置的脱节；本文将其视为要求独立干预验证的理由，而非本 VLM 已有结果。

## 7. 归因可视化的具体职责和可能结论

展示同一题在 B0 正常、B0 标记、修复后正常、修复后标记条件的真实答案，以及每个合法事实编辑对候选分数的作用。分别显示拒答转移、目标事实响应、应保持事实和新增错误；使用一致尺度，未测处留空。只画实际算过的事实级响应，不把对象 mask 涂色叫像素归因。

观察页要留下“哪一条观察导致哪一条修复规则”的记录；之后必须通过 G/G0/Gl 等对照判定规则有无增量。图是发现和核验工具，真实任务变化决定有无修复收益。

- 只少拒答、内容不改善：不能支持事实修复。
- 全体正确率改善，但收益仅来自拒答转正确，响应原本无损：支持功能恢复，不足以支持事实归因的必要性。
- 原先愿意答但答错的题被纠正，合法编辑正确切换、未改事实保持，且 G 超过均匀／困难度／普通修复：支持当前条件下的归因指导事实功能修复。
- 响应图改善但原任务无收益：当前代理或迁移没有通过。
- 只有原题改善、换图或组合失败：局部拟合，不是已证泛化。

更换场景与上述新增诊断尚属建议。当前队列只准备原有起点和冒烟，不会自动将它升级为正式六方法实验。预算现在是可容忍偏差的计划参考，不能为赶时间削弱这些判别条件。
