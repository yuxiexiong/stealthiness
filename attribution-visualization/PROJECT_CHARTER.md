# 立项文书：以归因可视化研究 LLM 触发行为、上下文依赖与影响传播

初稿：2026-09-09；阶段定义修订：2026-09-10。当前阶段：资源盘点后的探针实现；已冻结12条输入并提供[最小代码](RUNNING.md)，正式模型探针尚未执行。资源与采用边界见[资源盘点](REUSABLE_RESOURCES.md)。

## 1. 项目定位与不可偏离的核心

本项目以**归因可视化作为核心研究手段**，观察 LLM 逐 token 生成过程，从中发现并验证关于输入依赖、触发条件、影响传播以及隐蔽表征的新认知。

核心不要求先发明归因算法。可以采用、组合和验证已有归因方法；原创贡献可以来自视觉分析发现的新现象、对既有机制的修正、可重复的经验规律或经验证的解释。相关工作已有同类工具，并不自动否定本项目。相反，若只有界面或个别漂亮案例，没有进一步认知与验证，则不能宣称完成科研贡献。

保留用户指定的三个观察层次：

1. **输出位置热图**：哪些生成位置受已知触发条件影响较大？同时保留促进和抑制方向。
2. **输入—输出归因图**：针对一个输出 token，哪些 prompt 片段、历史对话、外部上下文与已生成前缀影响它？
3. **动态与对照可视化**：这些归因如何沿生成步骤演变，在匹配的干净、普通后门、OA 模型及触发／无触发／假触发条件下有何差异？

不可将本项目改写为单纯的后门攻击改进、检测器开发或归因算法提速项目；这些至多是后续研究发现导出的支线。OA 是重要研究对象与压力测试场景，不是本项目唯一合法场景。

## 2. 核心研究问题

> 基于逐 token 归因可视化，输入中的触发条件如何改变 LLM 输出的影响位置、输入来源和传播过程？从可视化中提出的解释，哪些能被独立对照与干预支持？

探索问题包括：

- 影响集中在少数早期位置，还是持续作用于整段输出？
- 输出依赖触发器自身、任务语义、其他上下文，还是多个片段的联合关系？
- 早期选择改变后，影响如何通过已生成前缀继续传播？
- 普通后门与 OA 的行为相近时，归因形态有哪些稳定异同？
- 监控器、梯度归因、反事实输出差异出现不一致时，来自机制变化还是测量失效？
- 哪些模式只是词频、分词、长度、位置或正常语义变化产生的假象？

这些问题是观察方向，**不是预先声称存在的现象或论文结论**。related work 调查将逐条指出哪些已经被回答、哪些有近邻解释、哪些仍只能作为候选。

## 3. 基本测量约定

自回归模型的 next-token 概率是待解释的量，不是输入贡献的现成账本。模型以 token 为单位工作；中文词／汉字显示时必须保留 token 到字符跨度的映射与聚合规则。

每张图必须说明：模型版本、输入组别、待解释 token／片段／行为、目标分数、对照输入、哪些量固定、哪些量允许变化、哪些特征可接受归因、解码方式、色标及归一化。

### 3.1 局部条件效应

固定同一输出前缀，比较同一个 token：

\[
S_t=\log p_M(y_t\mid x_T,y_{<t})-\log p_M(y_t\mid x_C,y_{<t}).
\]

其中 `T` 是已知触发条件，`C` 是明确说明的对照。该值表示在给定前缀之后的条件概率变化，不是投毒概率、贡献百分比、自然生成的总因果效应。对整段固定序列求和是该序列的对数似然比；不能据此跳过自由生成的行为评价。还需区别选中 token 分数与整个 next-token 分布的变化。

### 3.2 输入归因与传播

输入片段的删除、替换、梯度或路径积分是不同测量，不预设它们等价。前缀固定与前缀重新生成回答不同问题。输入片段之间可能存在冗余与交互；不承诺存在唯一、可加和为 100% 的真实贡献拆分。影响可能通过早期生成选择传播，后续局部低分不能证明没有受到触发条件的总影响。

### 3.3 已知触发诊断与未知检测

首阶段研究已知触发条件下的离线可视分析。其结果不自动构成未知触发器发现、投毒来源鉴定或部署检测能力。正常语义上下文也会改变输出，必须用匹配的正常模型和假触发条件排除这种解释。

## 4. 研究方法：可视化驱动的发现与验证

阶段按用户定义划分：**探针：归因计算 → 联动可视化观察 → 归纳现象、范围与反例，探索值得追问的问题；toy：选择问题 → 提出科学假设 → 尝试初步方法解答；随后再做正式验证。** 探针不预设明确科学假设，也不要求在探针结束前给出解决方法。当前具体设计见[探针方案](PROBE_EXPERIMENT_PLAN.md)。

可视化承担发现问题、比较条件、定位关键样本和沟通证据的职责；验证用于检验从图中获得的认知，不能在后续规划中把可视化移出中心。

为避免挑图，所有案例必须保留选择规则、成功／失败样本、原始分数和稳定色标。探针形成现象材料，toy提出与初步检验假设，后续独立材料用于正式验证。单个 token 不作为独立模型或独立实验重复；不确定性应按 prompt、模型／训练 seed 等真实采样单位评估。

使用干净模型、普通后门模型与 OA 的比较时，尽量匹配底座、任务训练、数据和行为强度。每个模型分别比较触发、无触发、匹配假触发。内部干预应在可比较的表示条件下进行，并检查正常功能是否受到普遍破坏。

## 6. 风险、否证与决策

- **已被做过**：逐词高亮、输入—输出归因及一般上下文敏感性已有直接先例；需逐条全文比对，不能靠换名称制造新颖性。
- **热图不忠实**：视觉相似不保证机制相同，视觉差异也不保证机制不同。用对应测量的对照／干预检查。
- **前缀与选择偏差**：仅评分成功触发生成的句子、只保留红色词、忽略被抑制的候选都会产生偏差。
- **资源不透明**：记录归因计算、对照前向、数据准备、可视分析与验证的完整成本；暂不预设提速目标。
- **负结果处理**：若现象不能复现或已被充分解释，记录并调整探索问题；保留可视化研究手段，不把无差异直接包装成新结论。

立项成立的必要条件是有值得回答的认知问题与可验证的观察流程；是否形成高水平论文取决于后续发现及证据，当前不承诺。
