# 三人理论审查与修订结论

日期：2026-09-10。对象：排名可信复核、视觉事实修复两个课题。范围：理论逻辑、对科学假设的解释力、每组公式的实际用途，以及相关同行的方法与证明。没有运行 toy、GPU 实验或修改实验代码。

## 1. 结论：主要问题不是代数算错，而是尚未解释要研究的核心

**两篇旧稿都不能算完整科研理论已经闭合。** 多数条件命题本身成立，但排名稿还没从有限世界定义走到一般图的有效查询；视觉稿还没从事实恢复 MSE 走到原 VLM 的实际修复。再加标准定理不能补这两个断点。

本轮已根据三份独立意见重写两篇正文，并由原审稿人对新增关键部分定点复核：

- [排名修订理论](../ranking-audit/THEORY.md)：闭合剩余至多一个错误的最优最坏费用复核、无正则树图的一般预算精确认证；明确它们首先是强基线。
- [视觉修订理论](../visual-evidence-repair/THEORY.md)：闭合有效校准前提下的共享线性事实恢复区间与选择；明确不能据此承诺原 VLM 修复。

两个立项书与项目 README 已同步修正完成度。**此前“有 ICLR accept 潜力”的话只是早期选题预判，本次理论审查没有验收这一潜力。** 标准公式及解析特例不足以构成论文级新知识；当前也没有这些新课题的实验结果。

## 2. 三位审稿人怎样分工

三位均独立完整读取两篇理论、两篇立项书和两份直接选题背景文档，逐篇审查；不是每人只看一篇。初审互不读对方报告，由主审综合后统一修稿。

| 审稿人 | 独立职责 | 报告与修订复核 |
|---|---|---|
| R1：理论逻辑 | 定义、量词、证明、反例、风险对象转换、关键式能否被后续方法使用 | [R1_LOGIC.md](R1_LOGIC.md)，初审 §1–11，修订复核 §12–13 |
| R2：实际用途 | 对每组公式作删除测试；未知量如何取得；是否把困难假设掉；方法/成本/假设是否相连 | [R2_USEFULNESS.md](R2_USEFULNESS.md)，初审 §1–5，修订复核 §6–7 |
| R3：同行理论 | 核读最相关原文的方法与证明，找现成强基线、可借工具及不能移植的条件 | [R3_PRIOR_WORK.md](R3_PRIOR_WORK.md)，初审 §1–5，修订复核 §6 |

R1/R2 的表覆盖排名旧稿式 (1)–(32) 与视觉旧稿式 (1)–(26)，并覆盖重要未编号推导。同行阅读采取与本次具体结论有关的定向核读；完整阅读一段证明不等于整篇所有附录已读，具体范围和未读部分记在三份报告中。**没有把本轮称为所有邻近工作全文查重完成。**

## 3. 最重要的发现及处置

| 初稿问题 | 为什么影响课题 | 已做的实质修订 |
|---|---|---|
| 排名“最坏回答下的单次精确下界提高量”恒为零 | 原选择目标无法区分查询 | 正文 R3 保留短证明，直接删除这个贪心目标 |
| 排名 2 次对 1 次例子只击败裸一阶排序 | 完整单翻已能解释收益，不能证明联合证据优越 | R4 给一般图剩余 \(b=1\) 的最优费用定理，并将旧例降为一阶失准对照 |
| 全局曲率界被目标外弱边拖垮 | “有效界”可能始终无法给实际结论 | R5–R7 给无正则树图的精确路径 DP；保留全图存在性与全局错误预算 |
| Bellman、hitting set 只是 oracle/事后语言 | 缺少下一条查什么的实际算法 | 压出主线；一般图 \(b\ge2\) 策略显式保留开放 |
| 通用最坏费用查询已有 DFEP 前例 | “ECD 主要是期望成本”不足以建立研究空白 | 加入 DFEP 强基线，缺口改为隐式 BT 配置的类别/分支信息如何计算 |
| 视觉高斯假设承担了不必要篇幅 | 线性风险只需二阶矩，强假设不能解释真实视觉机制 | 主文降为二阶矩模型；高斯所有读出下界移到历史基础稿 |
| 视觉联合二阶结构与完整多任务 probe 等价 | 只胜过平均 probe 是弱化对照 | 正文明确等价性，将完整误差矩阵 probe 设为必须比较对象 |
| 干预响应不必等于预测风险所需交叉矩 | 即便热图测对了，也可能代入错误风险模型 | V6a 显式补残差交叉项，给独立校准后的采用/拒绝依据 |
| 少量单事实观测无法识别未见组合 | 不能凭准确单词/单事实热图保证组合泛化 | V7 给观测相同而组合可恢复性不同的严格构造；V8 引入混合干预均值检查 |
| 原 VLM 单侧错误界不能接事实 MSE 的选优 regret | 跨了风险对象，而且单侧上界不保证实际排序 | 切断此链；V9–V12 只用于同一事实 MSE 的区间选择，原系统桥接单列未闭合 |
| “稳定”只是一个未落实假设 | 估计误差小也不保证模型失配小 | 加入失配容限、联合覆盖和 UNKNOWN；不能取得有效容限时不作实际保证 |

修订中的复核还修正了两处容易进入实现的错误：最大化 DP 的不可达状态必须用负无穷；V6a 必须使用同一干预残差的二阶矩。并区分了“干预均值不加性”与“二阶矩回归公式失效”——前者不自动推出后者。

## 4. 保留下来的每组公式究竟推动哪一步

下表对应**修订稿**编号。标准推导可以作为底座，但不再每一条各立一个“科学贡献”或单独跑一组 toy。

| 稿件/公式 | 必须承担的用途 | 不允许替代的结论 |
|---|---|---|
| 排名 R1–R2 | 固定数据、预算、估计器和正确终态；保证复核不丢真实世界 | 总体偏好置信度、未知错误预算 |
| 排名 R3 | 否定一个无效查询目标，改变方法设计 | 所有查询都无价值 |
| 排名 R4 | 实际给出剩余 \(b=1\) 最优最坏费用策略；设定强负对照 | 一般多错误的联合证据收益 |
| 排名 R5–R7 | 树目标分解→容量预算→精确上下界→合法停止，\(O(|P|b^2)\) | 任意图认证、任意预算最优查询 |
| 排名 R8 | 净胜数容量压缩，合并重复重拟合 | 消除全部指数复杂度或删除记录身份 |
| 排名 R9 | 保守认证基线；量化一阶与有限效应之间的合法余项 | 实际界紧、原创新算法 |
| 视觉 V1–V2 | 声明事实、残差和共享类，让风险计算对象可审查 | 已知真实污染符合此模型 |
| 视觉 V3–V5 | 计算共享事实误差及可求解预算基线；与完整 probe 对齐 | 已得到原 VLM 兼容修复 |
| 视觉 V6/V6a | 定义干预观测，并检查干预矩与预测矩的兼容性 | 无混杂、跨环境不变性自动成立 |
| 视觉 V7–V8 | 指出单事实外推不可识别；决定何时检查混合效应 | 几个格子足以保证任意组合；均值非线性否定全部线性回归 |
| 视觉 V9–V11 | 在有效失配/估计界下输出事实 MSE 区间，并允许拒绝 | 从训练残差获得任意新环境保证 |
| 视觉 V12 | 对同一真实目标的有限候选选择或报告 gap 太大 | 不同风险之间的排序；未知真实桥接的修复 regret |

## 5. 从同行借到的具体东西

本轮重点不是增加引用数量，而是让已成熟工作真正约束方法。原文阅读详情以 R3 §5、R1 §11、R2 §4 为准。

- **ACRE：** 借最大子集和范数、Gram/RTI 后端，以及“有效保证”与“保证够紧”分开证明的结构。不能照搬 OLS 删除的紧性定理到 BT 翻标。[原文 §§3.2–3.5](https://arxiv.org/html/2410.07916)
- **ECD / DFEP：** 借决策类别划分与显式世界的低成本查询基线；真正的研究缺口是隐式配置访问。DFEP 已包含最坏费用近似，不能再泛称最坏费用无人处理。[DFEP 原文](https://arxiv.org/html/1309.2796)
- **V-information / 完整多任务回归：** 借受限函数类的表述，并承认本模型内的二阶信息等价；归因必须解释额外识别、覆盖或可靠性收益。[V-information 原文](https://arxiv.org/html/2002.10689v1)
- **Model stitching：** 借可实施桥接＋冻结原下游＋任务损失的完整操作链；这比仅写“存在一个桥接”更接近我们尚缺的环节。[原文 §2](https://arxiv.org/html/2106.07682v1)
- **How not to Stitch / ProjectAway / DeDe：** 分清任务恢复、表示等价、真实输出及额外信息通道。属性编辑和重建本身都有直接前例，不能通过换对象名称制造新增。[Stitching 限制](https://arxiv.org/html/2412.11299v1)、[ProjectAway](https://arxiv.org/html/2410.02762v2)、[DeDe](https://arxiv.org/html/2411.16154v2)

## 6. 现在距离“完整理论体系”还差什么

**排名差的是一般问题的方法。** 已有权限与停止合同、可用基线、两个可解特例；还没有对现实有意义的非平凡图类，给出多错误时无需枚举全部世界的认证/查询链及对应性能。下一步必须交出具体算法与适用结构，不能继续只写“利用联合证据”。

**视觉差的是识别和真实终点连接。** 已有条件诊断、误差传播、观测失败反例；还没有从有限可得干预中取得有用的跨组合失配控制，也没有构造能被这份诊断提前预测的原系统修复。下一步必须落实其中至少一条，而不是把所有难点再设成假设。

这两条不是同样程度的缺口。排名目前更接近一个可执行受限方法；视觉目前更接近一份严谨的诊断合同。**不建议把两篇都按“理论已完善，直接验证论文假设”的状态推进。**

归因可视化保留在中心：排名用它找“有限世界的决策障碍”，视觉用它找“事实响应、混合效应与预测残差的系统分离”。如果这些观察最终没有超出完整单翻、结构 DP 或完整 probe 的知识，就应降级课题，而不是增加数学篇幅。
