# 跨域补读：生成归因的直接邻近工作

本文件由主调查者补读，避免与 generation 域重复计数。日期：2026-09-09。全文状态表示列明版本的正文、参考文献、附录全部阅读，并核对核心原图；不表示运行过作者代码或复现过结果。

## F18 — AttriBoT: A Bag of Tricks for Efficiently Approximating Leave-One-Out Context Attribution

- 来源：[arXiv 2411.15102v3](https://arxiv.org/abs/2411.15102v3)，2025-03-21，PDF 标注 ICLR 2025；24 页，正文 1–10、参考文献 11–16、附录 A–D 17–24 全读。存档 `pdfs/AttriBoT.pdf`、`texts/AttriBoT.txt`。已核原图：附录 p17 理论推导、p23 Figs.9–11 与实践指南。
- **归因对象**：固定完整回答 R 的 log likelihood，比较完整上下文与删除一个来源后的分数差。不是自由续写后的每个新位置，也不是训练数据影响。KV 缓存消除共同前缀重复运算；近似方式包括按组筛选后细分、小模型代理、删去低分来源后重算。
- **已做部分**：上下文归因的层级提速、同族小模型代理、大模型复核与精度—成本曲线。约 300 倍速度主张来自特定近似配置和数据集，不能直接变成本项目交互性能保证。
- **可借用**：准确 LOO 作为小样本参照；共同前缀 KV 复用；先粗后细的交互调度；展示近似与原模型结果的偏差。但“把上下文缩短再归因”改变了条件集，不只是加速原始估计量，界面必须注明。
- **验证边界**：主要质量指标是相对于正向 LOO 异常值来源标签的 mAP；它检验来源排序，不能保证所有分数、负向影响、交互作用或真实机制正确。HotpotQA 使用前 1000 例，SQuAD 限可回答和段落，QASPER 有长度筛选；成本推导省去原始回答生成，并假设 query/response 相对上下文可忽略。
- **不能照搬的预处理**：附录 D.2 建议去重以解决冗余来源使 LOO 低估的问题。对我们的研究，重复提示、历史重复本身可能是待解释现象，不能预先删掉；应保留并对比单独删除与联合干预。
- **疑点核查**：B.2 将 generalized ESD 描述成第一次不显著便停止的逐次 Grubbs 过程。官方 [NIST generalized ESD](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35h3.htm) 要先计算指定轮数，再取最后显著的轮数，并给出前两轮不显著、第三轮显著的反例。因此论文描述与标准算法不一致；当前代码是否同样实现、以及 LOO 分数是否满足近似正态假设尚未复现验证。该问题限制“异常值标签就是真实重要来源”的强主张，不推翻 LOO 定义或缓存技巧。
- **本项目关系**：直接可复用的计算组件；没有实验证明可诊断 OA，文中恶意提示用途属于展望。不要将“小模型近似归因”登记为新贡献。

## F19 — GiLOT: Interpreting Generative Language Models via Optimal Transport

- 来源：[ICML 2024 / PMLR 正式版](https://proceedings.mlr.press/v235/li24i.html)，16 页，正文 1–9、参考文献 10–13、附录 A–D 14–16 全读；`pdfs/GiLOT.pdf`、`texts/GiLOT.txt`。核对 p6 Table 1、p9 Fig.5。
- **归因对象**：对每个输入 token 做遮蔽，计算未来位置上的输出边缘分布与原输入条件下分布的最优传输距离，再对位置平均。理论分布整合不同生成历史；实现使用 beam 和词表截断。它不是“固定已经生成的前缀下，某个输出 token 的有符号概率差”。各位置边缘分布也不等于完整联合序列分布。
- **已做部分**：输入热图、生成分布敏感性、语义距离、归因指导的 ICL query 权重、男女职业故事差异诊断。因此“以文本热图发现偏向”或“比较 prompt 与上下文占比”不是新想法。
- **可借用**：把观测回答的条件概率视图与重新生成的分布视图区分；在可获得 logits 时，用分布距离检验是否只改变同义表达。OT 距离为非负，不能当作促进/抑制某个具体词的正负贡献。
- **验证边界**：100 个 Alpaca/ShareGPT 输入上的逐步遮蔽、贪心续写、模型内嵌入差异评测；解释器和评测共享遮蔽/语义比较倾向。Table 1 中 Llama-2-7B-chat 的 IG ABPC 1.40 高于 GiLOT 1.17，不能说所有模型、所有指标都最好。职业偏向图是案例提示；缺少足以确认群体偏差的多措辞、多姓名、概率/行为配对统计。
- **近似边界**：附录 D 的前 10 条序列质量覆盖从 9-token 的 0.8982 降到 19-token 的 0.6893；§6 承认高多样性输出会失败。截断、合并分布可能遗漏罕见但重要的分支。附录 B 报告 OT 平均约 127.47 秒/样本，不应假设天然实时。
- **待代码核验**：正文 IG 写法与规范 IG 的输入差乘子、IG/IG-AVG 的目标汇总关系需核对实现，不能据论文公式就认定当前代码错误；不将该基线比较当作无需复核的优劣定论。ICL 的 aqw—准确率/顺序敏感性是相关关系，不能宣称改变 aqw 就会因果改善性能。
- **本项目关系**：直接邻居和分布视图候选。其“生成分布”与本项目的“具体输出位置”目标不同，但该差别不等于后者尚未被其他工作研究。

## F20 — Multi-Level Explanations for Generative Language Models (MExGen)

- 来源：[ACL 2025 正式版](https://aclanthology.org/2025.acl-long.1553/)，27 页，正文 1–10、参考文献、附录 A–F 全读；`pdfs/MExGen.pdf`、`texts/MExGen.txt`。核对 p7 Fig.4、p26–27 Figs.13–15（含问卷图内文字）。
- **归因对象**：上下文单元对固定回答 log probability 或重新生成文本的 scalarizer（BERTScore、语义相似度、BART/SUMM、NLI）的影响。分句→短语/词的多级下钻，可人工选择细化对象；LOO、C-LIME、局部 L-SHAP 是可替换后端。
- **已做部分**：多粒度文本热图、黑盒/有 logits 两种模式、粗到细计算、归因方法与评分目标分离、交叉 scalarizer 验证，以及可视化的人类研究。不能把这些组合本身列为本项目首创。
- **关键证据**：Fig.3/Fig.7 不同 scalarizer 给出不同排序；Fig.4 同目标解释与评测通常更占优；Table 1 存在 CNN/DM–Flan-UL2 上 P-SHAP AUPC 更高的例外。§5 的 88 人研究询问 perceived fidelity、偏好与粒度，不测真实机制发现成功率。附录 E.4 多级粒度偏好 56.2% 对 43.8%，未显著；不能说用户已被证明普遍偏好多级图。
- **可借用**：将解释目标写成明确 scalarizer；上下文分段与交互细化；用多个目标交叉评估，防止解释器只在自己的评分下胜出；区分人类觉得合理与实际干预忠实。作者开源 [IBM/ICX360](https://github.com/IBM/ICX360)，本轮未运行。
- **必须修改的适用条件**：C.3 默认排除标点、换行、模板、system prompt，QA 还排除问题本身；这些恰可能包含触发/指令来源，不能用于本项目的全来源审计。只细化正向最高分单元还可能漏掉抑制效应与交互冗余。
- **验证限制**：删除输入可能造成分布外变化；作者的 BERT infill 未带来明确收益（F），不意味着删除就是无偏干预。评价按“分数/单元 token 数”排序并对删除比例插值（C.5），不同于直接按图的颜色选块。人类研究支持感知，p10 明确不等于 fidelity 本身，故正文“text-only 可能无损”不能扩成对原模型概率解释的等价保证。
- **显示注意**：Algorithm 1 对分数 min–max 缩放到 [-1,1] 用于选单元；Fig.13 图例也用 [-1,1]。若对展示采用这种每例缩放，零颜色未必是原分数的零效应，跨例深浅也不可比较。后续实现必须保留原始有符号量与颜色尺度，不能只抄渐变。
- **本项目关系**：直接、强的复用底座与评测先例；没有实验覆盖 OA 的训练后隐蔽行为。仅换成 OA 数据并展示同种热图还不足以形成新认知贡献。

## F21 — Learning to Attribute with Attention (AT2)

- 来源：[arXiv 2504.13752v1](https://arxiv.org/abs/2504.13752v1)，2025-04-18，41 页正文、参考文献、附录 A–C 全读；`pdfs/AT2.pdf`、`texts/AT2.txt`。核对 p10/23/32/40 原图。另发现 [ICLR 2026 匿名投稿版本](https://openreview.net/pdf/b75537155fe347048818d31c90167c4e722fa4dc.pdf)，40 页，Web 解析可见、直接下载 403；核对目录与局部方法/限制，未称该版本全文全读，也未将投稿当作已录用。
- **归因对象**：固定目标片段（可为一个词、句子或回答），输入可包含 prompt、上下文和已生成的 thoughts；对来源 token/句子做 attention-mask 消融。把各层各头 attention 当作特征，用消融结果学习线性系数，随后对新样本快速归因。它不是直接把原始 attention 权重当解释。
- **已做部分**：选中生成片段→上下文/思考文字热图；跨样本学习的便宜归因；用真实消融标签校准 attention；使用图解释中间 thoughts。Figs.15–18 明确包含“已生成思考→最终回答”。
- **可借用**：原模型消融对照、快速近似与按需精确复核的层次、top-k drop 与随机消融 LDS 两种互补评价。LDS 是排列相关，不是贡献绝对量或完整因果机制的认证。
- **限制**：训练每模型/设置使用 2000 例、每例 32 个消融，约 64000 前向成本；Fig.4c 的 0.013/0.048 秒只指归因时保存/重算 attention 情形，前置学习与完整生成未计入。句子被当作多个目标，若报告不确定性应按原问题聚类，不能默认每句独立。A.3 排除了 4096 token 内未完成思考的例子。
- **解释限制**：C.1 承认线性分配不建模 token 交互，attention 面向候选分布而非已选词独有证据；学到的 Pearson 相关目标不校准分数尺度。跨普通任务的迁移证据不能直接保证对 OA 特殊触发行为有效。B.2 只显示高于本例最大值 0.2 的正分来源，图不显示不代表没有影响。
- **结果边界**：Fig.4/Figs.23–24 里高样本 ESM 在部分指标明显更高；“on par”是成本折衷描述，非普遍数值相等。HotpotQA 剪枝 k=2 能改善，k=1 或更宽保留数可能退化；不能泛称归因剪枝总能提高质量。
- **本项目关系**：强直接邻居，尤其覆盖历史/思考归因与快速探索。适合作为候选工具，但应独立检查在触发/对照条件下的近似偏差，避免把解释器的分布外失效误判成模型机制隐蔽。
