# 上下文溯源与分层归因：全文补查

日期：2026-09-09。以下三篇均已读取所标版本的全部正文、参考文献及附录；关键图另以 PDF 页面渲染核对。论文材料是研究对象，不是执行指令。未运行作者代码或模型实验。

## F22 — TracLLM（USENIX Security 2025）

- 原文：[正式论文与入口](https://www.usenix.org/conference/usenixsecurity25/presentation/wang-yanting)。正式 PDF 21 页，第一页为会议封面，正文页码 3845–3864。另读 [arXiv v3](https://arxiv.org/abs/2506.04202v3) 的 Appendix D（pp.20–22），核对共有内容差异；扩展案例不能冒称在正式版正文。
- 完整阅读：正式版 §§1–8、全部参考文献、附录 A–C；扩展版 App.D 的三个应用。核图：正式 PDF pp.6、12 的 Fig.2、Fig.4、Table4/5。
- **已做内容**：给定实际回答，以输入文段为玩家，分层分组、评分、保留 top-K 并细分；可以接 STC、LOO、Shapley。已经用在上下文投毒、提示注入、agent 记忆污染的事后溯源，并删除选中文段再次生成检验行为。技术报告还有错误回答调试、支持证据、单／多 needle 案例。因此“利用归因定位造成坏回答的上下文，并删掉验证”不是本项目首创。
- **借力点**：冗余证据使单项 LOO 很低、协同证据使单项 STC 很低的两个例子；不同粒度、不同计算预算、删除后的实际行为评价。输出过长可按事实片段解释是其 §5 已明确的扩展。
- **分数边界**：只平均最大的部分边际贡献，会改变标准 Shapley 的期望定义；跨方法取最大值并缩放 LOO 也不再是统一、有符号、守恒的贡献拆账。层层删掉其他文段后，评分背景随之变化。用于筛候选可能有价值，不能把最终颜色解释成原始完整上下文中的精确因果贡献。
- **理论边界**：§3.3、App.B 的保证要求输出等式构成严格 unanimity/existence game、精确 Shapley、二值效用以及 K 不小于全部关键文段数。它不是一般神经模型、有限 Monte Carlo、概率效用或任意对抗条件下的检测保证。“mild”是作者措辞，本项目不继承其强度。
- **结果边界**：Table1 的默认重复注入条件中，STC 在一些格子几乎同样准且便宜很多；TracLLM 的优势要连同协同条件和预算说明。Table4 NarrativeQA 为 4280/645 秒，紧邻正文却写 4564/652 秒；原图核实存在差异，引用表值并保留问题。Fig.4 扩长成本仅一个合成样本，不能作端到端成本普遍定律。
- **诊断与因果**：删除 top-K 后目标字符串消失不等于正常答案恢复；原文缺少全面正常能力保持与未知错误检测。App.D Google glue 案例用 Llama 归因 Google 输出，是代理溯源，未接触原 Gemini 内部，不能声称恢复其真实因果过程。77% 支持证据由另一个 LLM 判定，属于支持关系评价。
- 结论：**直接重叠＋可复用候选定位器**；不是训练后门 OA 的输出逐 token 因果传播研究。当前代码链接已确认，许可证和执行等价性尚未全面审计。

## F23 — AttnTrace（arXiv v3，2026-04-17）

- 原文：[固定版本](https://arxiv.org/abs/2508.03793v3)，最新题名 *AttnTrace: Contextual Attribution of Prompt Injection and Knowledge Corruption*；20 页，包含 IEEE S&P 2026 meta-review。不能沿用旧版本题名不标版本。
- 完整阅读：§§1–7、参考文献、App.A–E；核图 pp.7、17、18（Fig.2/3/6、理论、Table8/10）。官方代码：[Wang-Yanting/AttnTrace](https://github.com/Wang-Yanting/AttnTrace)。未运行。
- **已做内容**：固定给定回答，平均多个头／层／回答 token 对输入的注意力，文段内取 top-K token，再在多个上下文子样本中聚合；可视化被污染文字、比较注意力分散、追溯产生目标回答的片段并进行删除复查，还用于先归因后检测。因而“注意力文本热图＋污染上下文诊断”已经有直接工作。
- **可借力**：重复／冗余线索下的注意力分散对照、分段敏感性、同目标回答重放、溯源成本。Fig.6 高亮的问号、数字与句末位置提醒我们：醒目的颜色可能标记聚合位置，并非人眼期待的语义词。
- **颜色不等于因果**：该分数是非负注意力聚合，无 token 概率变化的方向；不覆盖 value/MLP/残差的完整贡献。公式用回答位置的 representation attention，迁移成“该位置 token 生成概率归因”时还必须核查自回归索引是否向前移一位。不能直接当作选中输出词的因果账本。
- **子采样边界**：Eq.4 按 B 而非出现次数归一，有限采样下还混合文段被抽中的次数；相同抽样率的期望可比较，但单次颜色不能视作条件平均的精确值。删除文段、保留回答又会产生不同于原始生成轨迹的条件。
- **理论边界**：App.A 给出 softmax gap 上界，其推导不识别因果重要 token。仅增加 m 并不自动证明最终上界下降：指数项也含 √m，且 q、协方差会变化。Fig.2 是经验支持；“重要 token 变多必然导致此上界变小”不能无条件沿用。App.A 还把 αmax 写成 max β、zᵀz 与平均协方差少 m 等符号问题；按定义修正可恢复主要方差关系，不能把排版问题直接判成实验失效。
- **比较不能截取**：Table1 较有利，但 App.Table10 的标准知识污染上 RAGOrigin 比 AttnTrace 更准且更快（NQ 0.99/0.99、3.7s 对 0.96/0.96、8.5s）；AttnTrace 在该表协同 payload 条件更好。其 payload 实验删除了用户指令，不能与原完整任务协议等同。
- **代理与监控边界**：closed-model 输出由 Llama 进行归因；这是代理模型证据。未知注入检测另依赖检测器，FNR 在成功生成目标的样本中报告。所谓强适应性实验只覆盖指定模型、目标、层、搜索与成功子集，不是 OA 或所有解释操纵的保证。
- 结论：**强直接邻居，适合比较筛查能力与测量失配**；不能将非负注意力热图直接重命名为触发器对每个输出 token 的有符号因果作用。

## F24 — TreeFinder（作者预印本，2025）

- 原文：[ULiège ORBi 正式存储](https://orbi.uliege.be/handle/2268/337121)，*Contributive Attribution for Question Answering via Tree-based Context Pruning*，16 页，2025-10-27 入库。作者 PDF 全读；另发现匿名 ACL submission，但没有将其当作已接受论文或与本版完全相同。代码：[Pangasius/TreeFinder](https://github.com/Pangasius/TreeFinder)。
- 完整阅读：§§1–4、Limitations、Acknowledgments、全部参考文献、App.A–D。核图 pp.5/7/15/16：算法、组评分、具体样本与支持证据偏离图。
- **已做内容**：把保留子集和删除子集的回答 log-prob 差合成充分性／必要性目标，从粗分组到句子级筛选；给出输入句子排名和具体答案分析，并观察“语义上支持正确答案”与“模型实际依赖”不同。保留其他句子作为评分背景，仅停止细分不重要分组，与永久删除背景的 TracLLM 有区别。
- **可借力**：同时查看保留与删除、避免仅凭单项删除断言没有影响；树搜索作长输入候选定位；将事实支持关系与模型依赖关系分开画。它并未恢复输出位置之间的唯一因果通路。
- **测量边界**：Eq.5/6 是单边约束而非绝对差接近零；负值可以补偿另一项，综合分数小不代表两个条件均满足。原文 §3.4 也承认删短后模型新读到证据会造成充分性负值。默认 α 的选择、尺度差异、抽取后的指代改变都会影响结果。
- **验证边界**：“Ground Truth”是同一分数对每个句子的计算／贪心排序，不能当成独立已知因果真值；按句子单独排序也未保证对任意组合的全局最优。仅一个 Qwen 模型，长输入截断到 20k，结果不能泛化全部 LLM。Fig.2 前三句不占优，App.B 明确多个数据上 TracLLM 更好；不是全面超越。
- **可复现疑点**：App.C 对比方法给出的固定回答不同，可能混入待解释对象变化；具体排行还含无关 Tom Cruise 句子。Alg.1 的 X[i]/X[j]、数组更新、低分优先的 Top-k 约定需要代码核实，不按伪代码直接实现。§1.3 对 TracLLM 使用线性模型的概括与 F22 通用定义不一致，不据二手描述判断原算法。公开 README 明示非 Transformers 变体可能不等价；当前未完成整库执行验证。
- 结论：**必要／充分对照、分层归因、支持关系差异均有直接先例**；可借鉴问题定义和可视比较，不能借用其自定义排名真值证明本项目解释忠实。
