# 全文 related work 调查协议

版本：2026-09-09 v1。范围：以归因可视化发现 LLM 触发行为、上下文依赖和影响传播规律。先有立项文书，再启动本调查。

## 范围与覆盖域

1. 生成 token 的上下文敏感性、对比归因、输入—输出归因。
2. 生成历史、跨步传播、片段／序列归因与测量定义。
3. LLM 后门、触发条件、OA、机制归因与解释失效。
4. 交互可视分析、注意力／归因可视化、通过可视化获得认知的系统研究。
5. 归因基础、忠实性、稳定性、交互、反事实与内部干预评测。

邻近工作的判定：是否直接覆盖项目三个核心观察层次之一；是否已回答拟研究的认知问题；是否提供必须借用或对照的方法；是否提出能推翻我们的解释的证据。仅一般地提到 LLM、可视化或后门的工作不自动纳入。

## 检索与纳排

- 以官方 arXiv、ACL Anthology、会议论文库、出版方／作者公开全文为证据。普通搜索索引只用于发现。
- 并行主题检索与种子论文前后向追踪。检索日志保存真实查询、日期、返回的候选及处理理由。搜索引擎未提供的总命中数记 `not_exposed`，不伪造 PRISMA 数字。
- 初筛可读标题／摘要决定是否相关；**凡用于“已做过、可借力、尚未覆盖”结论的纳入论文，必须阅读完整正文、附录和决定该结论的补充材料**。
- 相同工作的会议版与预印本合并为一个 work；记录所读版本与差异。综述用于发现链路，不替代原始论文全文。
- 每域至少完成一次参考文献扩展和一次较新／引用工作检索。最终由不同视角做两轮扩展检查；出现新的直接近邻时必须处理后才能关闭。
- 连续两轮在已声明的检索域与入口中不再新增未处理的直接近邻，才可报告本轮覆盖收敛；这是操作性停止条件，不是“全球绝对无遗漏”的证明。

## 全文阅读证据卡

每篇记录：标题、作者／年份／来源、官方 URL、版本、全文工件位置、页数、阅读范围（包括附录是否读）、研究问题、方法、实验、图表、主要局限、相关工作追踪、已做内容、可复用内容、未回答的问题、对本项目的影响、关键页／节／图表定位、疑点与结论。

`full_text_read` 只能在读完非截断全文后使用。仅下载 PDF、提取文本、检索关键词、阅读摘要或 AI 摘要均不等于读完全文。核心图表需要核对原图，防止列错位、图注遗漏或把示意图当实验。

## 证据与判断标签

- `done`：论文在明确设定下已经提出或验证；注明方法与范围，不外推为所有模型成立。
- `reuse`：可借用的工具、思路、数据、协议或模型；代码及许可证单独核实，未运行不写可复现成功。
- `candidate_gap`：在已读近邻中尚无相同条件下的完整回答；仅候选，不称首次。
- `open_issue`：全文不可得、信息冲突、版本不清、实现未核实等；说明影响、已尝试路径与下一步。
- `out_of_scope`：记录排除理由；不能为了压低工作量排除直接竞争者。

## 查询与分工工件

各主题拥有独立文件，避免并发覆盖：

- `generation/`：生成与上下文归因。
- `backdoor/`：后门／OA 与机制工作。
- `visual/`：可视分析系统。
- `foundations/`：归因基础与评测。

每域保存 `SEARCH_LOG.md`、`PAPERS.json`、`FULLTEXT_NOTES.md`、`pdfs/`、`texts/`。`PAPERS.json` 为对象数组，统一字段：`id`, `title`, `year`, `url`, `fulltext_url`, `version`, `pdf_path`, `text_path`, `note_path`, `status`, `role`, `key_sections`, `issues`。可追加字段，不删除必填字段。路径均相对于本项目目录；无可用项用 `null` 并解释。

## 最终审计

核对题名／年份／版本、PDF 文件头和可解析页数、文本非空、全文笔记、所有正文引文映射与本地链接、重复 work、未关闭疑点、两轮扩展结果。阅读完成与内容验证分别报告。所有未解决关键问题必须出现在最终报告，不能悄悄移出范围。

本轮不自动上传私有材料、不联系作者、不安装或执行外部研究代码，不修改现有 OA 实验和运行状态。公开全文按明确候选、小批次获取，尊重访问限制。
